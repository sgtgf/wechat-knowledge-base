# **二、问题描述**

之前我们公司做过一个工业现场的控制器，控制有一个RS485接口，该产品在发布大概半年左右 ，陆续有客户反馈RS485端口无法使用，而产品是正常上电，指示灯都是正常的，尤其是在某客户A中的情况特别严重。客户希望我们马上解决。

# **三、原因分析**

客户的坏机返回研发，我们很快就定位到了原因，原因是RS485的端口PCB走线烧毁，但是端口的防护器件还是好的，这个就比较奇怪了，端口的防护器件还没有坏，PCB走线就先挂了。

后来我们查看了PCB的源文件，发现PCB工程师设计RS485 的走线的时候，由于硬件工程师提出了要求阻抗要连续，控制在120欧姆，由于板卡内部的空间比较小，PCB工程师在板卡内部的走线为5mil，因此为了阻抗的连续，走到AB外面端口时候，走线的宽度也是控制为5mil。而我们的板卡比较薄，使用的铜皮厚度是0.5oZ，根据经验计算，5mi为0.127mm，可以通过的电流约为0.1A，在RS485正常工作的情况下，没有问题，但是一旦遇到雷击、浪涌干扰的时候，能量需要从PCB走线到TVS、GDT等防护器件，如果PCB的走线太细，就有可能PCB走线先烧毁，但是防护器件还没损坏。

# **四、解决方案**

已经定位到原因，接来了就是要优化PCB的走线。其实RS485并不是真正的差分线，并且速率也比较低，一般的工业应用运行115200bps的速率已经足够了，因此阻抗控制不是首要考虑的，应该首先考虑的是端口防护，因此改版之后，我们将AB走线到GD、TVS之间的PCB走线增加到100mil，实测对RS485的端口的信号几乎没有影响。

# **五、总结**

对于大多数的端口，特别是低速的端口，对于端口的防护，其实比信号的阻抗是否连续，是否匹配更重要，也也是很多PCB工程师，入门级工程师经常犯的错误。
