# I 导读

这份文件可以看成两段内容：

前 8 页在讲一个很漂亮的发现：**日语五个元音，不是乱排的，而是在频率空间里呈现出一种对称秩序**。后 2 页像一个“课间思考题”：**为什么频谱图上每个频率只有一根柱子，但傅里叶系数明明有  和  两个数？**

先说前半部分。

作者先把五个日语元音 AH、EH、EE、UU、OH 放到**对数频率坐标**上看。为什么要用对数坐标？因为人的听觉更像“按倍数感受高低”，100 到 200、200 到 400、400 到 800，虽然差值不同，但“翻倍”的感觉差不多，所以对数坐标更符合耳朵的直觉。换到这种坐标后，五个元音的排布一下子变得很整齐，甚至出现了明显的左右对称：AH 和 OH 成对，EH 和 UU 成对，而 EE 像是站在中间的基准点。书里说这个中心频率通常在大约 830 Hz 左右。

这里最重要的新角色是 **F1 和 F2**。你可以先把它们理解成：**同一个元音里最显眼的两个共振峰**，也就是嘴巴和声道对声音“放大得最厉害”的两个主要频率。作者把每个元音都看成由 F1 和 F2 这两个点来刻画，然后分别画出男声和女声的图。结果发现：男声大约以 800 Hz 为对称轴，女声大约以 1 kHz 为对称轴；AH、EH 偏右，UU、OH 偏左；同时 AH、OH 的 F1 到 F2 间距较短，EH、UU 的间距较长。也就是说，这四个元音形成了“两组对立特征”：**左/右** 和 **长/短**。

作者接着指出：看起来不太“成对”的 EE，其实反而最关键。因为 **EE 提供了整个系统的参照标准**。书里说，EE 的 F1 是人声里 F1 能降到的低端，EE 的 F2 又是人声里 F2 能升到的高端，所以 EE 的两个共振峰几乎像是在帮我们标出“这个系统的左右边界”。正因为先知道了边界，才能找到中点；先知道了最大跨度，才能比较别的元音到底是“长”还是“短”。

所以，作者干了一件很聪明的事：把“元音像什么”这件事，改写成平面坐标上的两个量。

横坐标  表示 **偏移量 offset**：某个元音的 F1 和 F2 的中点，相对于整体中心偏左还是偏右。  
纵坐标  表示 **距离 distance**：这个元音的 F1 和 F2 相隔多远。  
这样一来，一个元音就不再只是“两个频率”，而是变成平面上的一个点。

你可以把这一步理解成：  
以前我们看元音，是在问“两个点分别在哪里”；  
现在作者换了问法，变成“这条线段的**中心偏哪边**，以及这条线段有**多长**”。  
一换视角，结构就跳出来了。

书里随后一步一步演示：如果固定 F1、移动 F2，或者固定 F2、移动 F1，那么所有可能的人声元音，会在这个新坐标系里围出一个菱形/方形区域。作者把这个坐标平面叫做 **formant diamond（共振峰菱形图）**。这个名字很形象，因为可达范围看上去像棒球场的菱形。

接着，作者真的把男女声的五个日语元音平均值都算出来并画上去。结果非常漂亮：AH、EH、UU、OH 四个点围成了一个**近似正方形**，而 EE 则位于上方的基准位置。作者想表达的核心不是“数学上绝对完美对称”，而是：**这五个元音被安排得尽可能彼此拉开、彼此区分。** 也就是说，在人类发声器官允许的范围内，日语挑出了五个非常容易彼此听清的元音。

这部分最值得你抓住的，不是某个具体数字，而是这个思想：

**复杂的语言声音，背后可能藏着简单而有序的几何结构。**  
作者把看似杂乱的发音数据，整理成“中心—偏移—距离”这套框架后，突然就看出了对称性。这正是科学里很常见的一步：**换一个表示方法，秩序就显现出来了。**

后面“Conclusion”这一页其实是在升华主题。作者说，人声理论上能发出非常多种元音，但日语只保留了五个；这说明语言并不是随便选音，而是经过长期演化，倾向于选那些**最容易区分、最适合交流**的声音。作者甚至进一步猜想：既然日语五元音里能发现这种对称，其他语言的元音、辅音，甚至语言的旋律和节奏里，也可能存在类似的秩序。

再说最后两页的“频谱之谜”。

这里作者提出一个很关键的问题：在前面学傅里叶展开时，我们通常会得到两组系数  和 ，分别对应余弦项和正弦项；可是 FFT 分析仪的频谱图上，对每个频率通常只显示**一个值**。那它到底把  和  怎么合并了？

作者先提醒你一个容易忽略的点：做傅里叶系数时，我们要先截取“一个周期”。可“一个周期从哪里开始截”并不唯一。对同一条周期波，你取 A 段也行，取 B 段也行，只要长度刚好是一整个周期就行。问题是：**你换个截取起点，算出来的 、 会变。** 书里给出的 A 段和 B 段例子，结果就明显不同。

这会带来麻烦：如果频谱图跟“你从哪里截这一段波”有关，那频谱就不稳定，也就没法拿来描述声音本身的特征。于是 FFT 采用的办法是：**不单独看  或 ，而是看它们合成后的长度**

这相当于把  和  当成平面上的横坐标和纵坐标，而频谱显示的是从原点到这个点的距离。

这样做的妙处在于：就算你换了采样起点， 和  会重新分配，像是在平面上“转了个角度”，但**长度几乎不变**。所以 A 段和 B 段虽然  不一样，合成后的  却几乎一样。于是频谱图就稳定了。换句话说：

**频谱图主要在显示“这个频率成分有多强”，而不是“它在周期里的起始相位是什么”。**

如果把这两部分连起来看，这 10 页其实在讲一件很统一的事：

前半段是在说，**把声音换一种坐标看，就能看见元音的秩序**；  
后半段是在说，**把傅里叶系数换一种方式合并，就能得到稳定的频谱表示**。  
本质上都是：**选对表示法，比死盯原始数据更重要。**

你可以把这几页记成 4 句话：

1.  人耳更适合用“对数频率”看声音。
    
2.  日语五元音可以用 F1、F2 的“偏移 + 距离”看出对称结构。
    
3.  这个结构说明五个元音被安排得尽量彼此分开、容易分辨。
    
4.  频谱图显示的是 ，所以不受截取周期起点影响。

## 第1页：五个元音的排序

![](https://mmbiz.qpic.cn/mmbiz_png/sVzeakRoocsEh0M7C3fGA9ZdyyCkGaibFvIuyKzgiaMfzwv6Ry3WTia6J7M78Icibn90P8H1ThwTLWKJbttvPTdW6XOoYr0Z5LsUvORXfWlq6lc/640?wx_fmt=png&from=appmsg)

  

这一页先把日语五个元音 **AH、EH、EE、UU、OH** 放到一种特别的刻度上看，这种刻度叫 **对数频率坐标**。作者说，人耳听声音时，不太像拿尺子量“差多少”，而更像在感觉“翻了几倍”。比如 100 到 200、200 到 400、400 到 800，虽然差值不一样，但“翻倍”的感觉差不多。于是，把元音放到对数坐标里看，会更符合人的听觉。结果一画出来，五个元音突然显得非常整齐，而且出现了对称：**AH 和 OH 成对，EH 和 UU 成对，EE 在中间像一个基准点**。作者还指出，这个对称中心大约在 **830 Hz** 附近。

中学生可以这样理解：  
原来这些元音看起来像“乱摆的五个点”，换了一种更适合耳朵的坐标后，它们就像排成了一个有规律的队形。也就是说，不是元音本身变了，而是**你换了一个更聪明的看法**。

## 第2页：男女声音里的对称规律

![](https://mmbiz.qpic.cn/mmbiz_png/sVzeakRoocvIH09OROM0zM9eWVjSpMthZAVJSiaicLja6S2wqzxxDfysqaRFBich4Ehtx1TrK68EHmrahePCOpmRX5UjxpFciaV3rhPsS7gLgow/640?wx_fmt=png&from=appmsg)

  

这一页把男声和女声分开看。作者发现：虽然男声、女声的具体频率不一样，但它们的结构关系很像。男声的对称轴大约在 **800 Hz**，女声大约在 **1 kHz**。不管男声还是女声，**AH、EH 都偏右，UU、OH 都偏左**。同时，F1 和 F2 之间的距离也有规律：**AH、OH 距离短，EH、UU 距离长**。所以作者把四个元音总结成：

-   AH：短，偏右
    
-   EH：长，偏右
    
-   OH：短，偏左
    
-   UU：长，偏左
    

而 **EE 虽然不像它们那样成对出现，但它恰恰是“标准尺子”**。

这里的 F1、F2，你可以先把它们想成“一个元音最重要的两个频率位置”。  
这页真正想说的是：元音不是随便分布的，而是在两个标准下同时有规律：

一个标准是 **偏左还是偏右**，  
另一个标准是 **短还是长**。

## 第3页：为什么 EE 是基准

![](https://mmbiz.qpic.cn/mmbiz_png/sVzeakRoocuLYCom7Sls25p5HtLib2a0WpjMsuxwcmiacgLO4aGS9LtCWkjuPTqwXgniah37ma7WacoDWibSYnXh3K9gpSQYhJl6KV3oOf7HCNg/640?wx_fmt=png&from=appmsg)

  

这一页专门解释：为什么偏偏是 **EE** 当基准。

作者说，要找一段范围的“中心”，你得先知道这段范围的两个端点。在这里，**EE 的 F1 和 EE 的 F2 正好像两端的边界**。因为在真实发音里：

-   F1 不能比 EE 的 F1 更低
    
-   F2 不能比 EE 的 F2 更高
    

也就是说，EE 给出了人声里 F1 和 F2 的“极限边界”。知道两端后，中点就能确定出来，所以男声大约 800 Hz、女声大约 1 kHz 的中心，就是这么找出来的。

不仅如此，EE 的 F1 到 F2 之间的距离也是最大的，所以 EE 还提供了“最长”的标准。别的元音只要拿来和 EE 比，就能判断自己是“长”还是“短”。作者进一步说：

-   F1 大致可以从 **EE 的 F1** 变到中心附近
    
-   F2 大致可以从中心附近变到 **EE 的 F2**
    

所以 EE 不只是五个元音中的一个，它更像是整个系统的**参照物**。

## 第5页：先画出“可活动范围”

![](https://mmbiz.qpic.cn/sz_mmbiz_png/sVzeakRooctPibluKYazt1BDiaB4wVpkNK0KO7KVj42FFUiaaUJ8toc5a5Hg76ppWIuKWuH6E2xnys7SInnmgTaTjLia5L7jgGcCXaicURef5uTg/640?wx_fmt=png&from=appmsg)

  

这一页作者还没急着画真实元音，而是先问：  
**如果 F1 和 F2 在它们允许的范围里移动，那么在新坐标平面上，能走出多大的区域？**

作者先从“尽可能偏左”的声音开始。把它换到新的 \- 平面上，就得到左边的一个点。接着：

1.  固定 F1，不动它
    
2.  把 F2 往右移
    
3.  当 F2 移到最右边时，就得到最长距离，也就是 EE 那种情况
    
4.  再固定 F2，把 F1 往右移
    
5.  就能得到尽可能偏右的声音
    

这一步步移动，其实是在描出这个系统的“边界”。

中学生可以把它想成：  
好像你先不画具体同学站在哪，而是先在操场上画一个“所有同学最多能站到哪里”的边框。先把“可走范围”找出来，后面再把每个元音放进去，就容易多了。

## 第7页：五个元音真的排成了“方形”

![](https://mmbiz.qpic.cn/sz_mmbiz_png/sVzeakRooctkG76mKd7SdQaXvicG6AUTzsiaiax8DCc1DaOkWMfAWGI2FQiaR8CVb3nDG2jZGkSiaSsRLJCxYAVNQmrIibQuoGw149ORUp1E50JMw/640?wx_fmt=png&from=appmsg)

  

这一页作者把女性平均值也列出来，然后把男女声的五个元音平均坐标一起画到图上。结果非常惊艳：

**AH、EH、UU、OH 四个点，几乎排成了一个方形。**

而 EE 在上方中间，像一个特殊的参照点。作者强调，这个“方形”不是数学上绝对完美的正方形，但已经非常接近了。

作者接着解释“对称”到底是什么意思。这里的对称，不是说图形一定要像镜子里一模一样，而是说这些元音在两组标准下形成了清楚的对立：

-   左 vs 右
    
-   长 vs 短
    

于是它们彼此差得很明显，很容易区分。作者还说，这张图还说明另一件事：**五个元音在允许范围内尽可能分得远**。分得越远，听起来就越不容易混淆。

这页最核心的一句话是：

**日语五元音之所以好区分，是因为它们在“声音空间”里被摆得很开。**

## 第8页：共振峰菱形图与语言中的秩序

![](https://mmbiz.qpic.cn/mmbiz_png/sVzeakRoocva8IkUJQOibicxvp4C51yhyvSQiaE215aR50xkIzKZeGg3Ra0AjhBoRONiasJU8ydPCPDIlPpQEs4jtEwQqUXNO12Ot0VTLy6ywj8/640?wx_fmt=png&from=appmsg)

  

这一页先给前面的图起名字：  
这个以“偏移量”和“距离”为坐标轴的平面，叫做 **formant diamond**，中文可理解为**共振峰菱形图**。之所以叫“菱形图”，是因为 F1 和 F2 可移动的范围看上去像一个棒球场的菱形。作者甚至说，EE 所在的位置可以想成“二垒”。

接着是总结。作者说：

1.  在允许范围内，F1 和 F2 原则上可以独立变化，所以人类其实能发出非常多种元音。
    
2.  但日语只选了五个元音，这说明语言不是乱选，而是挑了少数最适合交流的声音。
    
3.  这五个元音的排列，正好最大化了对称性和清晰度。
    
4.  科学常常是在复杂现象中寻找隐藏秩序；元音看起来乱，但一平均、一换坐标，秩序就出现了。
    
5.  作者还猜想，这种对称不只存在于日语元音里，也可能出现在别的语言、辅音、旋律和节奏中。
    

最后作者说：  
我们只是稍微用了点傅里叶分析，就在五个元音中发现了惊人的秩序。现在，书要从这个“支线故事”回到傅里叶主线。

## 第9页：Coffee Break——频谱之谜

![](https://mmbiz.qpic.cn/sz_mmbiz_png/sVzeakRooctia1Zj7ZkMichxxBYqeIfuNbumHfF1GyXfCrIhphY33gtU8OtHjcZEtVibMsw7fOnibUh3dOpCcicZZyodWuCNiacSrqYpEcHNLdiaHM/640?wx_fmt=png&from=appmsg)

  

从这一页开始，主题切换了。
