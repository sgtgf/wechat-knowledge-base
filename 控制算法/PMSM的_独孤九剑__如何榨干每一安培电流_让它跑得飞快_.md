# PMSM的“独孤九剑”：如何榨干每一安培电流，让它跑得飞快？

原创 傅存敬 电磁散人 2025-10-27 07:06 广东

> 原文地址: [https://mp.weixin.qq.com/s/jaSELvli7NZfCf2uZnKOWw](https://mp.weixin.qq.com/s/jaSELvli7NZfCf2uZnKOWw)

从今天开始，我将作为一个“电动三蹦子”爱好者，针对现在电动汽车里用的那种又猛又省电的“永磁同步电机（PMSM）”，来跟大家聊一系列与PMSM最优控制的话题，本周开启的是MTPA系列。

大家想一个问题，我们开电动车，无论是两轮的，三轮的，还是四轮的，无不希望它起步的时候“贼”有劲儿，高速上跑的时候又能“贼”快，还不能太费电。这鱼和熊掌怎么兼得呢？今天这篇“武林秘籍”（其实来源于一篇技术文档）就告诉了我们答案。

如果大家都很感兴趣，那咱们就正式开讲！

第一部分：认识我们的“主角”——一个脾气古怪的天才

我们今天的“主角”叫内置式永磁同步电机（IPMSM）。它是个天才，效率高，力气大。但它脾气有点古怪，不像我们以前学的那些直流电机那么“线性”，那么听话。

它的“古怪”体现在哪呢？它的内部有两个很重要的“性格参数”——电感，分别叫Ld和Lq。你可以把它俩想象成电机在两个不同方向上的“倔脾气指数”。你给它的电流（id, iq）不一样，它的这两个“倔脾气指数”也跟着变，这就叫非线性。

这就像什么呢？你推一个购物车，在光滑的瓷砖地上，你用1牛的力，它可能跑1米/秒。但你要是把它推到沙滩上，同样用1牛的力，它可能就挪不动了。这个电机的“路况”（磁场饱和度）是会随着你用的“力”（电流）变化的，所以它才“古怪”。

第二部分：核心秘籍一——“四两拨千斤”的艺术（MTPA）

既然电机脾气古怪，我们怎么才能最高效地驱使它呢？

请看这张图！这是我们今天这篇文章的“藏宝图”！

![](https://mmbiz.qpic.cn/mmbiz_png/Z8Iha3NiaCRH8NtXNRjLpGB2YuvbxVpwykwTUKxVAWmRhPP0iacAQKAdib0UEAD2Jb9cicePTYOBHcIRw0pNqSUzKQ/640?from=appmsg)

大家看图b里那条橙色的线条，上面标着MTPA。这是什么意思？Maximum Torque Per Ampere，翻译过来就是“用最小的电流，干最大的活儿”！

这是什么概念呢？想象一下，你要推开一扇很重的石门。你是铆足了劲儿在门的正中间傻推呢，还是找到一个最省力的角度和位置去推？MTPA就是那个最省力的“黄金路径”！

对于电机来说，我们的“推力”就是电流。电流会产生热量，浪费电。所以，控制器要做的第一件事，就是在电机没跑那么快的时候（在基速ωb以下），时时刻刻都走在这条MTPA路线上。这样，司机每踩下一点“电门”，我们都能用最少的电，输出他想要的那个劲儿（转矩）。这就是恒转矩控制区，主打一个高效节能！

第三部分：核心秘籍二——“突破极限”的智慧（弱磁控制）

好，现在问题来了。我们的电动车要上高速，速度要越来越快。当速度超过一个临界点，也就是图中的基速（Base Speed,ωb）时，问题就出现了。

电机转得越快，它内部越会产生一个反抗你的“力”，叫反电动势。就像你骑自行车，速度越快，风的阻力越大。当这个“风阻”大到和你的“腿劲”（逆变器电压）一样大时，你就没办法再加速了。

怎么办？难道就此认怂了吗？当然不！

物理的智慧告诉我们，可以想办法把“风阻”降下来！骑车时，我们可以趴低身体。对于电机，我们用一种叫弱磁（Field-Weakening）的方法。

我们通过注入一个特殊的电流（负的 id电流），去削弱电机内部永磁体的磁场。磁场一弱，那个反抗你的“风阻”（反电动势）就小了。虽然这么做会稍微牺牲一点效率（不再走MTPA黄金路径了），但我们换来的是什么？是更高的转速！

大家再看图b，当速度超过ωb，我们的工作点就进入了右边的弱磁区 (Field Weakening Region)。这时候，我们既不能让电流太大（被Current Limited Circle这个圈圈管着），又不能让电压太高（被Voltage Limited Ellipse这个椭圆管着）。我们的控制器就要像一个走钢丝的杂技演员，在这两个约束之间，找到一个点，既能满足用户的高速要求，又不出圈。

第四部分：终极法宝——“通关秘籍”查找表（LUT）

听到这里，新来的控制算法工程师同仁可能要哭了：“这又MTPA，又弱磁，又要考虑电压、电流限制，这背后的数学公式得有多复杂啊？让我电机控制器里那小小的芯片实时去算，它不得当场 ‘CPU’ 烧了？”

有这种疑问很正常，这正是这篇“武林秘籍”最精华的地方！

我们不让芯片自己算，我们提前算好了答案给它抄！

这个“小抄”，就是查表（Lookup Table, LUT）。

这是什么思想呢？这叫“离线计算，在线查询”。

-   离线计算（备课）: 电机本体设计工程师同仁们，你们的价值体现了！你们用专业的有限元软件（FEA），比如JMAG，把电机的各种“脾气秉性”（非线性的Ld, Lq随电流的变化）全都算得明明白白。然后，控制算法工程师们，你们再用一个强大的脚本（比如文中的mcbGenerateTables），基于这些数据，把所有情况都预演一遍。
    

“在1000转，需要0.3牛米扭矩时，最省电的id和iq是多少？” --> 算出来，记下！

“在5000转，需要0.2牛米扭矩时，又要弱磁又要保证不出圈的id和iq是多少？” --> 算出来，记下！

……

把成千上万种工况的最优答案，都做成一张巨大的表格。这就是我们的“通关秘籍”——LUT。

-   在线查询（上考场）: 现在，这本“秘籍”被植入了电机控制器中。当司机一脚电门下去，控制器一看：“哦，目标5000rpm，0.2Nm”，它不慌不忙，甚至都不用思考，直接在“秘籍”里一查：“第500行，第2列，答案是 id = -10A, iq = 25A”。然后指挥硬件工程师做的那个漂亮的逆变器，精确地输出这两个电流值。
    

整个过程，行云流水，快、准、狠！

所以，大家看：

-   对于电机设计工程师：你们不再是“纸上谈兵”，你们的FEA数据，是制造这本“秘籍”的源头活水，直接决定了最终性能的上限！
    
-   对于硬件工程师：你们要做的，就是保证你们的驱动电路能“指哪打哪”，完美执行“秘籍”上的每一个指令，不能有丝毫偏差。
    
-   对于控制算法工程师：你们是“军师”，你们的核心工作，就是“编写”和“运用”这本秘籍，并设计好外围的PI控制器等，确保电机这个“大兵”能忠实地听从秘籍的指挥。
    

总结

今天我们学的，就是用查表（LUT）这种充满智慧的工程方法，把一个复杂的、非线性的、多约束的优化控制问题，变成了一个简单的、高效的查表动作。它就像一座桥梁，完美连接了电机本体的物理世界和控制器算法的数字世界。

这种“降维打击”的思想，不仅在电机控制里，在很多工程领域都非常重要。希望同仁们能体会到其中的奥妙。
