### 如何从矩阵数据判断旋转、剪切和缩放

在 2D 线性变换中，一个通用的变换矩阵是：

 ![](矩阵连乘__连续几何变换_images/img_003_805b85dd927e.svg)，

它将向量 ![](矩阵连乘__连续几何变换_images/img_004_99d5dd4d5652.svg) 变换为 ![](矩阵连乘__连续几何变换_images/img_005_8ec6ad6c4616.svg)。

要判断矩阵代表旋转、剪切还是缩放，我们可以基于矩阵的结构、行列式（determinant）、正交性（orthogonality）和特征值（eigenvalues）等属性进行分析。下面我一步步解释判断方法，包括数学推理和示例。注意，这些变换往往是纯的（不组合其他效果），但实际矩阵可能混合多种变换。

#### 1\. 判断缩放（Scale）

-   **特征：缩放矩阵通常是对角矩阵（off-diagonal 元素为 0），即 ![](矩阵连乘__连续几何变换_images/img_006_5c4f779e41a3.svg) 和 ![](矩阵连乘__连续几何变换_images/img_007_31941ec56738.svg)，形式为 ![](矩阵连乘__连续几何变换_images/img_008_3dd4099b4aaa.svg)，其中 ![](矩阵连乘__连续几何变换_images/img_009_33b46fb9558c.svg) 和 ![](矩阵连乘__连续几何变换_images/img_010_65ff72231847.svg) 是 x 和 y 方向的缩放因子。**

-   如果 ![](矩阵连乘__连续几何变换_images/img_011_a8b1e359e70c.svg) 或 ![](矩阵连乘__连续几何变换_images/img_012_a88b2bc04002.svg)，则放大。
    
-   如果 ![](矩阵连乘__连续几何变换_images/img_013_1b39887d8688.svg) 或 ![](矩阵连乘__连续几何变换_images/img_014_72c6f2f2efc1.svg)，则缩小。
    
-   如果 ![](矩阵连乘__连续几何变换_images/img_015_8f989c9ee35e.svg) 或 ![](矩阵连乘__连续几何变换_images/img_016_30e122d7a934.svg) 为负，则涉及反射（flip）。
    
-   行列式 ![](矩阵连乘__连续几何变换_images/img_017_2876a5770f1f.svg)，表示面积缩放比率（正值保持方向，负值反转）。
    

-   **如何判断：**

-   检查矩阵是否对角化（非对角元素为 0）。
    
-   如果不是纯对角，但可以通过奇异值分解（SVD）得到对角部分主导，则可能包含缩放成分。
    
-   特征值：缩放矩阵的特征值为 ![](矩阵连乘__连续几何变换_images/img_018_a9eedf39bb8e.svg) 和 ![](矩阵连乘__连续几何变换_images/img_019_8c9c798e3f86.svg)（实数，无虚部）。
    
      
    

-   **数学推理：对单位向量 ![](矩阵连乘__连续几何变换_images/img_020_c3a4e17f8fc2.svg) 作用，得 ![](矩阵连乘__连续几何变换_images/img_021_0a88deac86b2.svg)，长度变为 ![](矩阵连乘__连续几何变换_images/img_022_624c98b0ae0e.svg)。类似对 y 轴。**
-   **示例**
    
    矩阵 C = ![](矩阵连乘__连续几何变换_images/img_023_fa05581001ea.svg)，对角形式，![](矩阵连乘__连续几何变换_images/img_024_ee3502dd50db.svg)（缩小），![](矩阵连乘__连续几何变换_images/img_025_760fb9431344.svg)（放大）。行列式 = 1，不改变面积方向但改变大小。
    
-   **一般步骤：**

-   计算非对角元素：如果 b=0 和 c=0，则是缩放。
    
-   查看对角元素：如果它们不相等，则是非均匀缩放；相等则均匀。
    

  

#### 2\. 判断旋转（Rotate）

-   **特征：旋转矩阵是特殊正交矩阵（orthogonal matrix with det=1），形式为 ![](矩阵连乘__连续几何变换_images/img_026_03e30fa3bae2.svg)，其中 θ 是旋转角度（逆时针为正）。**

-   行列式 ![](矩阵连乘__连续几何变换_images/img_027_d1267dd2f539.svg)（保持面积和方向）。
    
-   矩阵转置是其逆：![](矩阵连乘__连续几何变换_images/img_028_b535b5572d00.svg)（单位矩阵），表示保持长度（无缩放）。
    
-   元素关系：![](矩阵连乘__连续几何变换_images/img_029_7f8ebcb768b2.svg)，![](矩阵连乘__连续几何变换_images/img_030_c3fcc3d40fa2.svg)，![](矩阵连乘__连续几何变换_images/img_031_1665d3ce23c0.svg)，且 ![](矩阵连乘__连续几何变换_images/img_032_1ca9e4f9e12e.svg)，![](矩阵连乘__连续几何变换_images/img_033_e19745eba3c0.svg)。
    
      
    

-   **如何判断：**

-   检查是否正交：计算 ![](矩阵连乘__连续几何变换_images/img_034_b848dc9ac500.svg) 是否等于单位矩阵 ![](矩阵连乘__连续几何变换_images/img_035_5af03e83d92e.svg)。
    
-   如果 det=1，则纯旋转；如果 det=-1，则旋转+反射。
    
-   特征值：复数共轭对，如 ![](矩阵连乘__连续几何变换_images/img_036_07004e6eaca3.svg) 和 ![](矩阵连乘__连续几何变换_images/img_037_a15d72b7de8c.svg)，模为 1。
    
-   角度计算：![](矩阵连乘__连续几何变换_images/img_038_2ae4be508e22.svg) 或 ![](矩阵连乘__连续几何变换_images/img_039_d76ee0f13279.svg)。
    
      
    

-   **数学推理：旋转保持向量长度和角度。单位圆上的点 (1,0) 变换为 (cos θ, sin θ)。**
-   **示例**
    
    矩阵 A = ![](矩阵连乘__连续几何变换_images/img_040_af7d272d10e9.svg)，a=0, b=-1, c=1, d=0。检查：![](D:\电脑文件\公众号知识库\数学_线性代数\矩阵连乘__连续几何变换_images\img_000_c22052c051bf.svg)，det=1，是旋转 θ=90°（π/2 弧度）。
    
      
    
-   **一般步骤：**

-   计算 det(M) = ad - bc，必须为 1。
    
-   检查正交性：行向量或列向量的点积为 0，且长度为 1。
    
-   如果匹配，计算 θ。

#### 3\. 判断剪切（Shear）

-   **特征：剪切矩阵通常是上三角或下三角形式，其中一个非对角元素非零，对角为 1。即 x-剪切：![](矩阵连乘__连续几何变换_images/img_042_1982f7ff3916.svg)，y-剪切：![](矩阵连乘__连续几何变换_images/img_043_f31dedd965bc.svg)。k 是剪切因子。**

-   行列式 det=1（保持面积）。
    
-   不保持角度或长度比例，导致平行四边形变形。
    
-   一般形式：一个方向固定，另一个方向平移比例于坐标。
    
      
    

-   **如何判断：**

-   检查对角是否为 1，且只有一个非对角元素非零。
    
-   如果 det=1 且非正交、非对角，则可能为剪切。
    
-   特征值：均为 1（无缩放），但特征向量不正交。
    
      
    

-   **数学推理：对向量 ![](矩阵连乘__连续几何变换_images/img_044_86ee1b893278.svg) ，x-剪切使新 x = x + k y，y 不变。类似于滑动变形。**
-   **示例**
    
    矩阵 B = ![](矩阵连乘__连续几何变换_images/img_045_b6bd88a91482.svg)，对角为 1，b=1（x-剪切，k=1），det=1。
    
-   **一般步骤：**

-   计算 det(M)，必须为 1。
    
-   检查对角：a=d=1。
    
-   非对角：如果 b≠0 和 c=0，则 x-剪切；如果 c≠0 和 b=0，则 y-剪切。

### 1. ![](矩阵连乘__连续几何变换_images/img_053_024a82168d60.svg) 是一个点吗？

**既是一个点，也是一组点的集合。**

-   在数学公式 ![](矩阵连乘__连续几何变换_images/img_054_aad4c65b616f.svg) 中，它代表一个通用的**向量（点）**。
    
    但在图中，左上角的那个彩色方框是由无数个像 ![](矩阵连乘__连续几何变换_images/img_055_e4d793208457.svg) 这样的点围成的**边界**。
    
      
    

### 2\. 彩色方块代表什么？

那个彩色的“方框”实际上是**单位空间（或特定的输入区域）的集合表示**。

-   **追踪变换：**
    
     它是为了让你**肉眼可见**地观察到空间是如何被“拉伸”、“旋转”或“剪切”的。
    
-   **对应关系：**
    
     注意颜色的分布（红、黄、绿、蓝）。当它经过矩阵 ![](矩阵连乘__连续几何变换_images/img_056_a4d8c095445d.svg)、![](矩阵连乘__连续几何变换_images/img_057_8c27fe07b147.svg)、![](矩阵连乘__连续几何变换_images/img_058_e2a03ffae93a.svg) 的变换后，方块变成了平行四边形或被压扁。通过观察颜色的位置变化，你可以发现：
    

-   **左上图（初始）：**
    
     标准的正方形，代表原始坐标系。
    
-   **后续图：**
    
     随着矩阵相乘，颜色点的位置发生了偏移。例如，原本在顶部的红色/黄色边，在经过一系列变换后，变成了倾斜的线段。
