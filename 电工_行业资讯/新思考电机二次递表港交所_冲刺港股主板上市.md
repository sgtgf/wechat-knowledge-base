# 新思考电机二次递表港交所！冲刺港股主板上市

7月5日，位于浙江嘉兴嘉善县的**新思考电机股份有限公司**向港交所第二次递交主板上市申请，联席保荐人为**华泰国际、中金公司**——距离其**2026年1月2日**首次递表因届满6个月失效，刚好过去约半年。作为国内影像马达（VCM，音圈马达）赛道的头部玩家，新思考这次二递的招股书把"**光学防抖马达中国第一**"的标签摆在了最显眼位置：按弗若斯特沙利文2025年收入计，公司在全球影像马达市场排**第六（3.3%）**、中国**第二（9.8%）**；在光学防抖（OIS）影像马达这个高附加值细分里，则是**全球第四、中国第一**，份额**5.6%和14.0%**。这份二递材料，也是市场观察"手机光学升级+OIS国产替代+欧菲光系资本运作"三重逻辑的一个切口。

![](D:\电脑文件\公众号知识库\电工_行业资讯\新思考电机二次递表港交所_冲刺港股主板上市_images\img_003_4b9855015854.png)

把新思考的底子摊开看，这家**2014年9月**成立于嘉善的企业，技术渊源其实可以追溯到**日本思考株式会社**——后者1994年发明了全球第一颗手机音圈马达，是VCM行业的"祖师爷"级存在，新思考继承了这条技术线，做了十余年国产化推进。目前公司形成**"嘉兴+合肥"双生产基地、"中国+日本"双研发基地**的布局，产品覆盖开环/闭环马达、OIS马达、潜望马达、可变光圈马达、连续光学变焦马达等，技术路线涵盖音圈、压电、记忆合金三类，下游打向**智能手机、手持影像（大疆这类）、安防监控、机器视觉**，非影像侧还延伸到扫地机步进马达、汽车电子无刷马达。日系厂商（阿尔卑斯阿尔派、美蓓亚三美）长期把着高端OIS马达，新思考是少数能在国内安卓旗舰供应链里替代日系、把OIS和潜望马达做到大规模量产的国产厂之一。

财务面上，新思考这三年跑得不慢。**2023–2025年收入8.55亿→15.65亿→19.57亿元，CAGR 51.3%**；2023年还亏**3010万元**，2024年扭亏至**1.05亿元**，2025年进一步到**1.20亿元**；毛利率从**8.4%拉升到16.7%**。2026年前4个月营收**6.94亿元（+19.54%）**、净利**3645万元（+44.97%）**，增速虽较2024–2025的爆发段回落，但仍维持双位数。结构里有个亮眼分项：**手持影像及运动相机应用收入从2023年1680万元猛增至2025年3.37亿元，三年CAGR 393.4%**——这基本是大疆生态带起来的增量，是新思考仅次于手机的第二条腿。

二递招股书另一个看点，是**欧菲光董事长蔡荣军的入主节奏**。蔡荣军现年53岁，**2025年12月**才加入新思考任董事长（非执行董事），而他本职是A股**欧菲光（002456.SZ）**董事长——也就是说，新思考二递的时间点，恰好是蔡荣军入主半年后的动作。股权上，蔡荣军直接持股7.50%、通过全资平台深圳和正间接持股27.04%，与外甥**蔡振鹏**（39岁，新思考执行董事、副董事长兼CEO）及深圳长鑫、嘉善长鑫、合肥嘉投构成一致行动人，**合计控制56.97%投票权**；IPO前投资者里嘉善经开区管委会、中金实体、屹唐华创、敦鸿资产分别持股8.33%、6.92%、5.53%、5.28%。这套"蔡荣军+蔡振鹏"的叔侄搭班子结构，加上欧菲光始终位列前五大客户，让新思考的"欧菲光系"色彩相当浓。

关联交易和客户集中度是二递材料里绕不开的隐忧。**2023–2025年及2026年前4月，前五大客户收入占比分别90.5%、93.7%、85.4%、86.2%**；其中欧菲光（蔡荣军控制的另一家上市公司）同期占比**37.9%、27.6%、30.4%、41.7%**——2026年前4月这一比例还在往上走。招股书自己也坦承：对关连人士（欧菲光）存在重大销售依赖，若主要客户尤其是欧菲光减少合作，会对经营业绩造成重大不利影响。叠加**2026年前4月经营活动现金净流出9281万元、现金从2025年末2.34亿降到5707万元、存货周转天数从47天拉长到61.3天**这些数据，二递虽然财务比首递时更好看，但现金流和客户结构这两项的问询压力不会小。

募资用途方面，二递版和首递基本一致，四个方向：**新品与驱动马达技术研发、南昌与东莞生产基地扩建、产线自动化数字化升级、补流**，并明确加码**机器人、低空经济**新兴赛道。节奏上，**南昌工厂预计2026年Q3完工，东莞工厂分阶段建设、2029年全面竣工**；非影像侧已经动了——**2026年已启动机器人灵巧手关节马达模组的商业化销售**，2025年11月就和一家头部机器人公司签了战略协议交付样品，打的是具身智能这波新需求。从"手机VCM"往"机器人关节马达+低空经济执行器"伸，是新思考想讲的第二增长曲线，但现阶段**智能手机马达仍占2025年收入79.0%**，转型还需要时间。

把新思考这单放回港股硬科技/IP的节奏里看，它和前面几篇的东微半导（功率器件+控制IC）、英飞凌德累斯顿厂（300mm功率）、菲力克斯浏阳（微特电机冲压）其实在同一条"电机/功率/精密驱动"的大链上——区别是新思考卡的是**消费电子光学升级（OIS、潜望）+手持影像+机器人关节**这个更偏C端升级的段。全球影像马达市场前十合计占57%，日系前两家的份额14.4%、10.7%，新思考3.3%排第六还有差距，但中国市场和OIS细分已经是第二、第一。二递能不能在2026年下半年闯过聆讯，看点不在"VCM还能不能卖"，而在两件事：一是**欧菲光关联交易和客户集中度的问询怎么答**，二是**机器人灵巧手马达从样品到批量、南昌东莞两厂爬坡**能不能接住蔡荣军入主后给出的估值预期。

一台手机摄像头里那颗几毫米大的VCM马达，新思考做了十二年，从嘉善走到港交所二递——中间隔的是日系垄断被国产安卓旗舰撬开一道缝的窗口期。蔡荣军把欧菲光和新思考两套资源绑在一起后，接下来要答的题是：这道题在港股市场，能给到"光学防抖国产替代+OIS中国第一"几倍PE。
