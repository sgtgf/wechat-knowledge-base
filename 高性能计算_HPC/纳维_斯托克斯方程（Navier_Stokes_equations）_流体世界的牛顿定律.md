# 纳维-斯托克斯方程（Navier-Stokes equations）：流体世界的牛顿定律


> 原文地址: [https://mp.weixin.qq.com/s/07rR4vycGq4hxaZz8DvhJg](https://mp.weixin.qq.com/s/07rR4vycGq4hxaZz8DvhJg)

# I 概述

提到**纳维-斯托克斯方程（Navier-Stokes equations，简称 N-S 方程）**，很多人的第一反应是“千禧年七大数学难题之一”或是复杂的偏微分方程组。但如果抛开晦涩的数学符号，它的核心物理思想其实非常直白、朴素。

一句话概括：**纳维-[斯托克斯](https://mp.weixin.qq.com/s?__biz=MzkzODgwODczMw==&mid=2247539516&idx=1&sn=3d8d90c8e9c48d8fdad6dadbd34e6132&scene=21#wechat_redirect)方程，就是流体世界里的“牛顿第二定律”（）。**

无论是茶杯里飘起的袅袅水汽、天气预报里的台风路径、飞机机翼周围的气流，还是血液在血管中的流动，背后都由这套方程在主宰。

* * *

### 一、 核心逻辑：流体的 

在固体力学中，如果我们想知道一个木块怎么运动，只需看它受了多少力（重力、推力、摩擦力），然后用  就能算出它的加速度和未来的位置。

但**流体（液体和气体）**有一个麻烦的特质：**它们没有固定的形状，会四处流动、形变、甚至撕裂。** 我们没法像盯住一块木头那样盯住整条河流。

为了解决这个问题，物理学家把流体想象成由无数个微小的**“流体微元”**（可以理解为极其微小的水滴）组成的群体。N-S 方程做的，就是计算**每一个小水滴在经历什么力，从而产生什么加速度**。

* * *

### 二、 解剖方程：流体受力的“四重奏”

让我们看一眼最经典、最纯粹的不可压缩流体 N-S 方程：

不要被微积分符号吓倒，我们把等式两边按  的逻辑拆开，它其实就像一份清晰的“账单”：

#### 1\. 等式左边：质量  加速度 ()

这里  是流体密度（相当于质量 ），括号里的部分就是加速度 ()：

-   **时间变化（）**：小水滴自己在原地加速还是减速（比如突然开大水龙头）。
    
-   **对流项（）**：**这是 N-S 方程最精彩、也最“臭名昭著”的一部分！** 它表示水滴因为**随波逐流**跑到了一个流速更快的地方而产生的加速。正是这个包含速度平方效应的“非线性项”，让流体变得反复无常，诞生了诡谲多变的**湍流（涡流）**。
    

#### 2\. 等式右边：流体受到的三种力 ()

水滴为什么会动？因为它受到了周围环境施加的三种力：

-   **压力梯度力（）**：**“人往高处走，水往低压流”。** 就像挤牙膏一样，流体永远从压力大的地方被推向压力小的地方。天气预报里高压区向低压区吹风，就是这个力在推动。
    
-   **黏滞力 / 内摩擦力（）**：**流体内部的“摩擦阻力”。** 这里的  是黏度。蜂蜜的黏度很高，流动起来慢吞吞；水的黏度很低，流动很轻快。这个力总是在**平滑和阻碍**速度的差异，试图把乱糟糟的漩涡拉平。
    
-   **外力（）**：来自外部世界的普遍作用力，比如**重力**（让水往低处流）、离心力等。
    

* * *

### 三、 秩序与混沌的博弈：雷诺数

N-S 方程告诉我们，流动的状态本质上是两股力量的拔河比赛：

-   **惯性力（对流项，喜欢捣乱）：** 它们让流体冲撞、折叠，试图制造混乱的漩涡。
    
-   **黏滞力（摩擦项，喜欢维持秩序）：** 它们像和事佬一样，试图抚平所有的速度差异，让流动保持平稳。
    

物理学家用一个简单的比值来衡量谁在主导，这就是著名的**雷诺数（Reynolds Number, ）**：

惯性力黏滞力流速特征长度运动黏度

-   **当雷诺数很低时（黏滞力主导）：** 比如糖浆缓缓流过汤匙。流动非常有秩序，分层前进，互不打扰，这叫做**层流（Laminar Flow）**。
    
-   **当雷诺数很高时（惯性力主导）：** 比如大风吹过高楼、剧烈的瀑布。水流或气流疯狂卷曲，产生大小不一的漩涡，进入高度混乱的**湍流（Turbulent Flow）**状态。
    

* * *

### 四、 为什么它能成为“千禧年难题”？

既然我们已经知道了方程的每一项代表什么，为什么数学家至今还没能完全“破解”它？

因为**对流项（）的非线性魔咒**。它会导致微小的扰动在瞬间被无限放大（类似蝴蝶效应）。数学家们至今无法证明：在三维空间中，给定一个极度平滑的初始水流状态，随着时间推移，N-S 方程的解是否会永远保持平滑，还是会在某个瞬间奇点爆发、计算出“速度无穷大”的物理学谬论（即**存在性与光滑性问题**）。

不过，工程学并不需要等待数学家的终极证明。通过计算机通过海量网格去近似求解（CFD 计算[流体力学](https://mp.weixin.qq.com/s?__biz=MzkzODgwODczMw==&mid=2247539667&idx=1&sn=cd0a411afb3d6f6926131caa1fa07de6&scene=21#wechat_redirect)），我们已经能用 N-S 方程设计高铁、预测风暴、优化气动布局了。

# 二十六、“千禧年难题”不是说 Navier–Stokes 完全不会解

这一点非常容易误解。

我们已经能求解大量 Navier–Stokes 问题。

例如：

-   管道流
    
-   Couette flow
    
-   Poiseuille flow
    
-   边界层
    
-   许多工程 CFD 问题
    

计算机每天都在数值求解 Navier–Stokes 方程。

真正没有解决的数学问题，大意是：

> 对三维不可压缩 Navier–Stokes 方程，从足够光滑、有限能量的初始速度场开始，是否永远存在一个全局光滑解？

或者会不会在有限时间形成奇点？

简单说：

```

```

我们还没有完整证明一般三维情况一定是哪一种。

# 二十八、图片中没有写出的另一条核心方程

这张图实际上主要展示的是**动量方程**。

> 不可压缩连续性方程。

## 它是什么意思？

想象一个小盒子：

```
      ↑   ┌─────┐→  │     │  →   │     │   └─────┘      ↓
```

如果水不可压缩：

> 流进去多少，就必须流出来多少。

不能：

```
进去 10 升出来 2 升
```

否则盒子里的水就不断神奇地压缩。

所以：

简单理解：

> 每一个微小区域都不能凭空产生或吞掉流体。

CFD 中，我们实际上必须同时满足这两个条件。

## 最后用一句“中学生版”总结整张图

> **Navier–Stokes 方程就是追踪一小团水：它一边被压力推、被黏性拖、被重力拉，同时它自己还会跑进不同速度的地方；这些作用共同决定下一秒水往哪里流。**

而真正麻烦的正是：

因为：

> **流动会搬运流动自己，涡旋会改变其他涡旋，于是整个系统产生层层相互作用。**

这也是为什么从一杯缓慢流动的水，到飞机尾流、卡门涡街、龙卷风和湍流，背后竟然都能由同一套基本方程来描述。
