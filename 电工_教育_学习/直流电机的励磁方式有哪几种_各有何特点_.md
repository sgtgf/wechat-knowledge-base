# 直流电机的励磁方式有哪几种?各有何特点?

直流电机的励磁方式主要有三种：他励、并励和串励。下面将详细介绍这三种励磁方式的特点和应用。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/GJ0wqfRCxtsytAg25mG5ickt6nRzgWvchrpibFjrUxqnh4OH4f4zxvUlqn6beuDN11dBIpl8XloXf9968u8fOMRg/640?wx_fmt=png&from=appmsg&wxfrom=13)

　　1、他励

　　他励，又称为外励，是指直流电机的励磁电源与电机的电枢电源分开，励磁电流由外部提供。他励方式具有以下特点：

　　1.1 励磁电流与电枢电流独立：他励方式的励磁电流与电枢电流是独立的，可以根据需要调节励磁电流，从而改变电机的磁场强度。

　　1.2 调速范围广：由于励磁电流可以独立调节，他励方式的直流电机具有较宽的调速范围，可以实现无级调速。

　　1.3 起动转矩大：他励方式的直流电机在起动时，可以提供较大的起动转矩，适用于需要大起动转矩的场合。

　　1.4 功率因数较低：由于励磁电流与电枢电流独立，他励方式的直流电机功率因数较低，需要较大的励磁电流来产生所需的磁场。

　　1.5 应用领域：他励方式的直流电机广泛应用于需要调速范围广、起动转矩大的场合，如轧钢机、起重机等。

　　2、并励

　　并励，又称为自励，是指直流电机的励磁电源与电枢电源并联，励磁电流由电枢电流提供。并励方式具有以下特点：

　　2.1 励磁电流与电枢电流相关：并励方式的励磁电流与电枢电流是相关的，励磁电流随着电枢电流的变化而变化。

　　2.2 调速范围较小：由于励磁电流与电枢电流相关，当电枢电流减小时，励磁电流也会减小，导致磁场强度降低，电机转速升高，因此并励方式的直流电机调速范围较小。

　　2.3 起动转矩较小：并励方式的直流电机在起动时，励磁电流较小，磁场强度较低，因此起动转矩较小。

　　2.4 功率因数较高：由于励磁电流由电枢电流提供，励磁电流与电枢电流相位相同，因此并励方式的直流电机功率因数较高。

　　2.5 应用领域：并励方式的直流电机广泛应用于调速范围要求不高、起动转矩要求较小的场合，如小型直流电机、家用电器等。

　　3、串励

　　串励，又称为复合励磁，是指直流电机的励磁电源与电枢电源串联，励磁电流与电枢电流相同。串励方式具有以下特点：

　　3.1 励磁电流与电枢电流相同：串励方式的励磁电流与电枢电流是相同的，励磁电流随着电枢电流的变化而变化。

　　3.2 调速性能较好：串励方式的直流电机在电枢电流变化时，励磁电流也会相应变化，从而改变磁场强度，实现调速。

　　3.3 起动转矩较大：串励方式的直流电机在起动时，励磁电流较大，磁场强度较高，因此起动转矩较大。

　　3.4 功率因数较高：由于励磁电流与电枢电流相同，励磁电流与电枢电流相位相同，因此串励方式的直流电机功率因数较高。

　　3.5 应用领域：串励方式的直流电机广泛应用于需要调速性能好、起动转矩大的场合，如电动汽车、电动工具等。

　　总结：

　　直流电机的励磁方式主要有他励、并励和串励三种。他励方式具有调速范围广、起动转矩大的特点，但功率因数较低;并励方式具有功率因数高、调速范围较小的特点，适用于调速范围要求不高的场合;串励方式具有调速性能好、起动转矩大的特点，适用于需要调速性能好、起动转矩大的场合。在选择直流电机的励磁方式时，需要根据具体的应用需求和性能要求进行选择。
