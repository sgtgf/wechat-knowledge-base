# 海尔吸尘器电路板有点复杂，想了很多方案

原创 电路一点通 2025-04-15 11:28 广东

> 原文地址: [https://mp.weixin.qq.com/s/vtBavA9LJQJaMQhl-tDP7g](https://mp.weixin.qq.com/s/vtBavA9LJQJaMQhl-tDP7g)

早些年的海尔无线吸尘器ZL1205C，120W，简单的有刷电机，用5节锂电。吸尘器用起来还可以，就是电池用起来和屎一样，很奇怪充电后一直插着电，到要用时拿下来就用不了多久马上就没电，要充完电马上用就可以。后来就每次充满电后，把主机取下来。太麻烦，后来再用定时器，每天不管有没有电都定时充。另外，强力档（电流可能6A多）用不了几分钟就没电，照理应该要能用近20分钟，实际远远不行。

  

虽然用了几年也没用几次，一周一次吧。电池不行了，充电了也一用就没电。原电池是用三星的，也是不错的品牌。可能是电路控制板的问题造成电池不好用。

于是全换成全新耐杰动力电池3000mAH，自己焊上，可以用了。仍是按定时器，每天定时充。

  

用的次数不多，2年后，不好用了，一用就没电，测了第一节电池电压高，很有电，最后一节没什么电，亏电。充不进电，也用不了。莫名其妙。

  

于是把原电路板拆了扔了，自行改造，想了很多方案，最后太麻烦了，采用最简单的。  某宝买5串锂电保护板（2.5V低压保护）装上。 改原充电器恒压输出电压调低到20V，直接充电器对电池充电，可以，会恒流500mA，最后恒压20V。  直接用机械按钮开关启动。  OK，挺好用了，强力档可以用十几分钟以上，非常好，符合电池容量、放电电流情况。

  

所以不是电池的问题，是海尔控制电路板做得和s一样。

一个可能是电池低电压检测设定值太高了，在大电流放电下，低压保护应该在2.5V，才能把电池容量全部放出来。不然强力档就是没几分钟就没电了。

另一个是可能控制电路有问题，造成充满电后，还在插充电器时电池会进行自放电，可能是三极管切换没做好。

还有一个就是不知道为什么电池会出现不严重均衡。

  

这个海尔电路板有点复杂，问题不知道出在哪。

  

L6015是5节串锂电池保护IC。N79E814AT20是单片机。除了MOS管，其它一堆的小三极管是控制切换的，太复杂了。没有充电均衡电路。

某宝买的5串锂电保护板，是单节DW01保护，多个DW01串起来再通过三极管控制MOS管。这种保护电路就是三极管太多了，比较复杂。  最理想的应该是单个IC来完成保护的吧，电路简单些。 还有那种多个DW01串起来再加多个光耦隔离的保护电路，也是挺复杂。   如果再加上充电均衡电路，那就是保护板上密密麻麻一堆东西。

这个5串锂电保护是多个DW01串的，做工还可以，但电路有缺陷，三极管e极少一个连接，自己飞线了。这个三极管是保证过放电后需要去掉负载才能继续使用。哎，所以，国内做的东西真的不靠谱。

Q10保证过放电后需要去掉负载才能继续使用，因为有可能在大电流过放后，放电管截止，电池电压可能马上会恢复到正常范围，又会造成放电管导通，这就不好了。Q12是放电管，电池过放低电时，Q8导通，使Q12截止。这时负载还在，则Q12的D和S之间电压高，使Q10导通，使Q12继续截止。电池恢复电压后，Q8截止，但Q10仍导通，只有负载去掉后Q10截止，这样Q12放电管才能导通。

改造的原因是，现在流行的新款吸尘器设计都和s一样，主机都放在吸尘杆的最顶端，那么高，离地那么远，吸什么吸呀！  买了一台新的小米的7节锂电的，感觉也不太好用，宣传吸力很大，实际用起来就那样。海尔的用惯了真不适应，老款型的已经买不到了。  用有线的，真的太讨厌，线缠来缠去。  无解了。
