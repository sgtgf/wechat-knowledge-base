# 一、什么是“图（graph）”？

在线性代数视角下，一个**图**就是：

-   一组**节点**（nodes / vertices）
    
-   一组连接节点的**边**（edges）
    

比如：

-   城市与道路
    
-   人与社交关系
    
-   网页与超链接
    
-   电路中的接点与导线
    
-   计算机中的机器与通信线路
    

如果边还带有更丰富的信息，比如：

-   方向
    
-   权重
    
-   容量
    
-   电流
    
-   距离
    
-   概率
    

那它更像一个**网络（network）**。

所以可以粗略理解为：

-   **图**：强调“连接关系”
    
-   **网络**：强调“连接 + 流动/权重/功能”
    

* * *

# 二、为什么线性代数能研究图与网络？

因为图虽然看起来是“点和线”，但它能被编码成**矩阵**。

一旦写成矩阵，就能用线性代数的方法研究：

-   解方程组
    
-   看秩、零空间
    
-   看特征值、特征向量
    
-   做优化
    
-   做分解
    
-   做传播分析
    
-   做聚类分区
    

也就是说：

> **图论对象 → 矩阵表示 → 线性代数分析**

这正是这张图的核心思想。
