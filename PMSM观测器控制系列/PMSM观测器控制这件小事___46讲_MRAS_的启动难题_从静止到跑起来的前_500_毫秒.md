## 一、调试现场：MRAS 跑得挺稳，电机怎么从 0 转起来？

你已经把 MRAS 的代码链路跑通了。在 1000 rpm 稳态下，转速估计偏差不到 1%，角度跟踪也没问题。你甚至做过负载突变测试——转矩阶跃 50% 时，MRAS 的收敛时间大约 20 ms，完全满足你的速度环带宽需求。

然后你把电机停下来，准备做**启动测试**。

你按下启动按钮。电机纹丝不动。你的 MRAS 观测器在中断里照常执行，但输出的是一团噪声——因为静止时反电动势为零，电压模型积分的是噪声和直流偏置，电流模型算出来的磁链角度完全随机。你的 FOC 电流环想跟着这个随机角度跑，三相电流立刻饱和，电机发出刺耳的高频啸叫。

你意识到一件事：**MRAS 和所有反电势类观测器一样，零速时无法工作。** 这不是 bug，是物理——没有反电动势，就没有可观测的信息。

那怎么办？行业里通用的做法是：先用开环策略（V/F 或 I/F）把转子从静止"拖"起来，拖到一定转速后，再切换到 MRAS 闭环。听起来简单，但你翻了几篇论文，发现每家说法都不一样：有的说拖到 10% 额定转速就行，有的说 20%，有的用硬切换，有的说必须渐变。你甚至看到一篇文献里写"切换后无角度不稳定"，但没告诉你切换花了多长时间、角度差是多少——你没法判断这个结论能不能搬到你的电机上。

本文要解决的就是这个工程问题：**开环拖到什么时候？切换时怎么避免电流冲击？渐变过程怎么设计？**

## 二、飞机起飞的直觉

想象一架客机从停机坪起飞。

**跑道滑行阶段**：飞机还在地面，自动驾驶无法工作——高度计读数为零，空速管还没感受到足够的气流。这时候由飞行员手动推油门、拉杆，沿着跑道加速。对应到电机控制，就是**开环 V/F 或 I/F 启动**：你给一个恒压频比的电压矢量，频率缓慢爬升，拖着转子跟着转。这时候你不知道转子实际在哪，你只是"相信"转子会跟着你的电压矢量走——前提是负载不大、加速度不高。

**离地瞬间**：空速达到阈值，自动驾驶的传感器开始获得有效信号。对应到电机，就是**反电动势足够大、信噪比可接受**，MRAS 的电压模型积分出的磁链不再被噪声淹没，电流模型算出的角度开始有实际意义。

**最关键的一步**：自动驾驶不是"啪"地瞬间接管——那样飞机会剧烈颠簸。实际控制权是通过一个**平滑的加权过渡**逐步移交的：飞行员的操作权重从 100% 降到 0，自动驾驶的权重从 0 升到 100%，持续数秒。对应到电机，就是从开环控制角度 `γ_guided` 逐步过渡到 MRAS 估计角度 `γ̂_MRAS`。

**硬切换 = 离地瞬间突然换驾驶员**。想象一下：飞行员正在拉杆，自动驾驶突然以另一种姿态介入——俯仰角立刻跳变，乘客会被甩到椅背上。电机里也一样：开环角度和估计角度如果差了 30°，硬切过去，d-q 轴坐标系瞬间旋转 30°，原本在 q 轴的电流突然有一部分跑到了 d 轴，转矩脉动、电流冲击、甚至失步——全来了。

**边界差异要心里有数**：飞机有明确的离地速度（由气动设计决定），自动驾驶有冗余传感器和故障保护。MRAS 没有这些——它的"最低工作频率"取决于电机参数、噪声水平、控制频率、SOGI 补偿效果，不是一个可以从论文直接搬的固定值。而且如果切换过程中 MRAS 发散，没有"第二套自动驾驶"可以接管，你只能依赖过流保护或看门狗停机。

## 三、什么时候可以切？两个条件必须同时满足

切换不是"到了某个转速就自动切"。你必须同时满足两个条件：

### 条件一：转速够高，观测器已经"看得见"

MRAS 的参考模型（电压模型）依赖反电动势。低速时反电动势幅值  和噪声/直流偏置同量级，电压模型的积分项会被偏置拖着漂移，输出的磁链角度失去物理意义。这就是为什么纯电压模型的最低工作频率通常在额定频率的 10%~20% 左右。

\[M-003\] 中做了一个直接对比：定子电压模型（纯积分）的最低工作频率约 18 Hz（对应 220 rpm），而配合 SOGI 的 MRAS 可以压到 10 Hz（约 130 rpm）——按对应机械转速算约降低 41%，按电频率算约降低 44%。这个提升来自 SOGI 对直流偏置和噪声的抑制能力，不是 MRAS 本身变魔术。

但注意——这是**特定电机**（轮缘推进器叶轮电机，5 极对，额定力矩 1.25 N·m，，）在**特定硬件**（STM32F407，20 kHz 控制频率，每周期两次电流采样取平均）上的数据。你的电机极对数、磁链、电感、噪声水平、ADC 分辨率都不一样，不能直接抄 130 rpm。

工程上的经验值是：**切换阈值设在 10%~20% 额定转速**，对应反电动势约为额定值的 10%~20%，此时信噪比足够让电压模型积分稳定。但这个阈值必须在你的电机上实测标定。

### 条件二：角度差够小，不会"跳变"

即使转速够高，如果开环角度和 MRAS 估计角度差了 60°，硬切过去照样翻车。\[M-003\] 的实验中设定了一个阈值： 才开始平滑过渡。

为什么是 60°？这是 \[M-003\] 在 5 极对轮缘推进器叶轮电机上采用的一个**工程经验阈值**——在该电机上，60° 电角度给开环策略提供了足够的容差空间，不会因为一点点扰动就反复触发/取消切换，同时又不至于在切换时产生过大的电流冲击。

**重要：FOC 的 d-q 轴坐标突变首先由电角度误差决定**，不是机械角度。60° 电角度对任何极对数都是 60° 的 dq 坐标误差；机械角度换算（）只影响机械位置解释，不会让 FOC 电流投影风险变小。M-003 没有给出"按极对数放宽"的依据。

如果你的电机极对数不同，**不要直接按机械角度比例缩放**，而应根据以下因素实测标定：

-   • 允许的电流冲击幅值（角度差越大，d-q 轴突变越严重）
    
-   • 电流环带宽和跟踪能力
    
-   • 观测器在目标电机上的收敛稳定性
    
-   • 负载惯量和机械共振敏感区
    

机械角度换算只用于诊断显示，不能用来推导切换阈值。

**两个条件必须同时满足，缺一不可。** 只满足转速条件但角度差太大 → 硬切翻车。只满足角度差条件但转速太低 → MRAS 输出的是噪声，切过去等于把控制权交给一个瞎子。

## 五、一个完整的切换流程与代码示意

下面我们把上述思路整理成一段**示意用代码**。这段代码展示了一个 PWM 中断里，从开环启动到 MRAS 闭环的完整切换逻辑。注意：这不是某个开源项目的直接源码，也不是 \[M-003\] 原文算法的逐行翻译，而是借鉴 M-003 平滑切换思想编写的示意用工程变体，你可以根据自己的硬件和电机参数调整。

`// 示意用示意：MRAS 开环启动 + 平滑切换策略   // 假设 alpha/beta 静止坐标系，SPMSM，20 kHz 控制频率      typedefenum {       STATE_OPEN_LOOP,      // 开环 V/F 启动       STATE_TRANSITION,     // 平滑过渡中       STATE_CLOSED_LOOP     // MRAS 闭环运行   } StartupState;      static StartupState state = STATE_OPEN_LOOP;   static float gamma_guided = 0.0f;     // 开环控制角度   static float gamma_blend = 0.0f;      // 混合输出角度   static float alpha = 0.0f;            // 过渡权重 [0, 1]   static float t_blend = 0.0f;          // 过渡计时器   static float omega_openloop = 0.0f;   // 开环电角频率（rad/s）      // 参数（需根据电机标定）   #define OMEGA_THRESHOLD   (157.0f)    // 切换转速阈值，电角速度 rad/s                                      // 157 rad/s ≈ 25 Hz（电），对 5 极对电机                                      // 对应机械转速 ≈ 300 rpm，约 10% 额定转速   #define GAMMA_THRESHOLD   (1.047f)    // 角度差阈值 = 60° = π/3 rad   #define T_BLEND_TOTAL     (0.1f)      // 过渡总时长 100 ms   #define OMEGA_OPEN_RAMP   (314.0f)    // 开环频率爬升率 314 rad/s²      void control_isr(void)   {    // ===== Step 1: 采样与电压重构 =====    float i_alpha, i_beta, u_alpha, u_beta;       adc_clarke_sample(&i_alpha, &i_beta);       voltage_reconstruct(&u_alpha, &u_beta);    // ===== Step 2: MRAS 观测器始终运行（但不总是用它的角度）=====    // 即使在开环阶段，MRAS 也在后台运行。    // 这样当切换条件满足时，MRAS 的角度已经收敛了一段时间，    // 不是"从零开始"。    float gamma_mras = mras_update_and_get_angle(i_alpha, i_beta,                                                     u_alpha, u_beta);    float omega_mras = mras_get_omega();    // ===== Step 3: 状态机处理 =====    switch (state) {    // -----------------------------------------------------------    case STATE_OPEN_LOOP:        // 开环 V/F 启动：频率线性爬升，电压按 V/f = const           omega_openloop += OMEGA_OPEN_RAMP * Ts;           gamma_guided += omega_openloop * Ts;           gamma_guided = wrap_2pi(gamma_guided);        // 输出到 FOC           gamma_blend = gamma_guided;        // 检查切换条件（统一用电角速度比较，避免 rpm 换算）        // angle_diff(target, source) 返回从 source 到 target 的有符号最短角度差        // 范围 [-π, π]；考虑 2π 环绕        // 注：本文示例默认正向启动；若需覆盖双向启动，应改用 fabsf(omega_mras)        float gamma_diff = fabsf(angle_diff(gamma_mras, gamma_guided));        if (omega_mras > OMEGA_THRESHOLD && gamma_diff < GAMMA_THRESHOLD) {               state = STATE_TRANSITION;               t_blend = 0.0f;               alpha = 0.0f;           }        break;    // -----------------------------------------------------------    case STATE_TRANSITION:        // 过渡阶段：S-curve 加权           t_blend += Ts;        if (t_blend >= T_BLEND_TOTAL) {               alpha = 1.0f;           gamma_blend = wrap_2pi(gamma_blend);        break;    // -----------------------------------------------------------    case STATE_CLOSED_LOOP:        // 完全闭环：MRAS 角度直接输出           gamma_blend = gamma_mras;       }    // ===== Step 4: FOC 电流环 =====       foc_current_loop(i_alpha, i_beta, gamma_blend, i_d_ref, i_q_ref);   }`

几个关键设计决策的说明：

**为什么 MRAS 在开环阶段也要运行？** 因为如果等到切换前一刻才启动 MRAS，它需要时间收敛。提前运行意味着切换时 MRAS 的角度估计已经稳定了一段时间——就像自动驾驶在接管前已经跟踪了飞行数据好几秒。

**为什么开环角度在过渡阶段继续更新？** 如果过渡过程中突然冻结 `gamma_guided`，而 `gamma_mras` 在动，混合结果会出现不连续的角速度跳变。保持开环角度继续旋转，确保两个输入信号都是"活的"，混合结果才平滑。

**为什么过渡结束后还要监控 MRAS 发散？** 因为切换完成不等于万事大吉。如果负载突变或参数漂移导致 MRAS 误差增大，转速估计可能暴走。安全监控是最后一道防线。

**关键观察点：**

1.  1. **开环拖行 500 ms**：这段时间内电机以 V/F 方式运行，没有电流闭环反馈，定子电流由电压指令和反电动势共同决定。低速区反电动势小，定子电阻压降占主导，电流容易偏大。拖行时间越长、负载越重、V/f 比设定越激进，电流偏大的程度越严重。长时间大电流拖行会导致电机发热，极端情况下可能引发永磁体退磁——风险大小取决于磁钢牌号、工作温度、电流方向和热模型，需查阅电机厂家规格。
    
2.  2. **MRAS 后台运行**：MRAS 从启动就开始运行，初期反电动势小、信噪比低，输出以噪声为主。随着转速爬升，反电动势增大、SOGI 逐渐抑制偏置，角度估计才开始可信。以上 200 ms、350 ms 等数字是本示例假设，实际收敛时间取决于电机参数、控制频率和噪声水平。
    
3.  3. **过渡 100 ms**：在这 100 ms 内，d-q 轴的等效旋转角速度由两个信号共同决定。如果开环角度和 MRAS 角度之间存在微小的转速差（比如开环频率 20 Hz，MRAS 估计 19.8 Hz），混合过程中会产生一个缓慢的"拍频"效应——角度差以 0.2 Hz 的频率周期性变化。S-curve 的平滑性可以抑制这种拍频带来的电流纹波。
    
4.  4. **切换后 1° 精度**：\[M-003\] 报告的"角度差不超过 1°"是在特定系统上测得的。你的系统未必能达到这个精度，但切换后角度差可作为项目验收指标来标定——例如把 5°~10° 设为报警线，超过即说明过渡过程可能有问题，需排查 S-curve 速度、MRAS 增益或角度差阈值设置。
    

## 七、调试 Checklist 与常见翻车场景

### 切换前检查

\[ \] **开环 V/F 比标定**：空载启动时转子能跟上电压矢量，不丢步、不振荡。如果空载都丢步，带载更不行。  
\[ \] **MRAS 后台输出监控**：在示波器或日志里观察  的波动。开环阶段它的波动应该逐渐减小，而不是持续发散。  
\[ \] **角度差收敛性**：在多个启动周期重复测试，确认角度差在切换前能稳定收敛到阈值以下。  
\[ \] **切换阈值标定**：从 5% 额定转速开始逐步提高阈值，找到"能稳定切换的最低值"。不要直接从论文抄。

### 切换中观察

\[ \] **d-q 轴电流波形**：过渡过程中 、 不应出现明显跳变或振荡。如果  突然从 0 跳到 5 A，说明角度切换不平滑。  
\[ \] **转矩脉动**：用手或传感器感受电机振动。S-curve 过渡应该是"无感"的，不应该有顿挫感。  
\[ \] **过渡时间**：记录每次切换的实际耗时。如果波动很大（如 80~150 ms 之间随机跳），说明角度差收敛不稳定。

### 切换后验证

\[ \] **稳态角度误差**：闭环运行后，对比编码器角度（如果有）和 MRAS 估计角度。目标值按项目精度要求设定——高精度伺服可能要求 < 0.5°，一般工业应用可能接受 3°~5°，具体取决于下游控制（如速度环、位置环）对角度误差的敏感度。  
\[ \] **负载突变响应**：在闭环状态下施加负载突变，观察 MRAS 重新收敛时间。收敛速度取决于负载大小、电机惯量、MRAS 自适应律增益和当前转速。验收标准按项目动态性能要求设定，例如是否能在速度环允许的超调范围内重新稳定。  
\[ \] **重复启动一致性**：连续启动 20 次（或按项目要求的样本量），统计切换失败率（过流、失步、角度发散）。具体合格率指标应按项目验收要求设定。

### 常见翻车场景

**翻车 1：切换条件设置不当**

**子情况 A：转速阈值设得太低**

-   • 现象：切换后电机抖动几下，然后过流保护跳闸，或者转速估计直接飙到上限。
    
-   • 原因：MRAS 还没收敛就把控制权交给它，它输出的是噪声+发散估计。FOC 跟着一个错误的角度跑，电流立刻失控。
    
-   • 对策：提高切换阈值 5%~10%，确认 MRAS 在阈值以上能稳定输出。
    

**子情况 B：角度差阈值设得太宽**

-   • 现象：切换瞬间电流冲击很大，电机发出"咔"的一声，但后续能稳定运行。
    
-   • 原因：虽然满足了转速条件，但开环角度和 MRAS 角度还差 50°~60°（甚至更多），硬切导致了 d-q 轴突变。
    
-   • 对策：收紧角度差阈值到 30°-45°，或延长过渡时间到 150-200 ms。
    

**翻车 2：S-curve 太快**

现象：过渡过程中电流有周期性振荡，频率约几十赫兹。

原因： 变化太快，电流环的带宽跟不上 d-q 轴的旋转速度。

对策：延长过渡时间到 150~200 ms，或临时降低速度环比例增益（如果速度环在过渡期间仍在工作）。

**翻车 3：极对数换算错误**

现象：切换后电机转速是预期的 2 倍或 1/2，或者根本无法稳定。

原因：电角度和机械角度的换算搞错了。MRAS 输出的是电角度，但你的切换阈值或速度显示可能按机械转速设的，中间忘了除以或乘上极对数。

对策：检查所有涉及极对数的换算。本文代码统一用电角速度比较，避免了这个问题——但如果你的系统在其他地方（如速度显示、速度环给定）需要机械转速，务必确认换算正确。

**翻车 4：SOGI 未启用或参数错误**

现象：低速区 MRAS 角度估计漂移严重，即使转速已经超过阈值，角度差仍然无法收敛。

原因：纯积分器的直流偏置累积没有被抑制。SOGI 的谐振频率需要与当前电气频率匹配，如果设得太高或太低，抑制效果差。

对策：确认 SOGI 已启用。谐振频率和阻尼系数需围绕当前电气频率实验整定（M-003 未给出通用设计公式）。常见做法是让谐振频率跟随估计电频率自适应调整；阻尼系数按噪声抑制和动态响应折中选择，具体最优值需在线调试标定。

## 八、总结

MRAS 的启动难题不是一个"开关"问题，而是一个**连续过渡问题**。核心工程判断如下：

1.  1. **所有反电势观测器都无法从零速启动**。这不是 MRAS 的缺陷，是物理。开环 V/F 或 I/F 拖行是必须的。
    
2.  2. **切换阈值不是固定值**。10%~20% 额定转速是一个经验起点，但必须在你的电机上实测标定。配合 SOGI 可以把阈值压得更低，但"能压多低"取决于电机参数、噪声水平和控制频率。
    
3.  3. **切换前必须确认角度差收敛**。只满足转速条件不够，开环角度和 MRAS 估计角度的差必须小到不会产生 d-q 轴突变。这个阈值是**电角度**，由 FOC 的 d-q 轴电流投影风险决定；不同电机应按允许电流冲击、转矩脉动和实测稳定性标定，不能简单按极对数缩放。
    
4.  4. **过渡过程用 S-curve，持续时间 50~200 ms**。不要追求瞬间切换。S-curve 的变化速度先慢后快再慢，给电流环足够的跟踪时间。
    
5.  5. **MRAS 在开环阶段就要后台运行**。这样切换时它不是从零开始收敛，而是已经稳定跟踪了一段时间——就像自动驾驶接管前已经在监控飞行数据了。
    
6.  6. **切换完成后不等于万事大吉**。MRAS 仍可能因负载突变或参数漂移而发散，安全监控和过流保护是最后一道防线。
    

如果你把以上六条做到了，MRAS 的启动过程应该是"无感"的——从开环到闭环，用户（或下游控制系统）感觉不到任何突变。如果切换时电机有明显顿挫、电流跳变或转速波动，回到本文的 Checklist 逐条排查。
