# 充电器防反接电路工作过程及故障判断分析

充电器没有防反接电路时，一旦电池接反就会造成充电器损坏，所以有些厂家设计了防反接电路。下图就是一种常见的设计，利用一个单向可控硅、一个PNP三极管来实现防反接功能。分几种情况来分析一下它的工作过程及故障判断方法。

下图是未接入电池时工作过程。未接入电池时由于可控硅阳极（A）与阴极（K）不通，三极管b极无电流回路，三极管截止，c极无电流，可控硅栅极（G）无触发电压，可控硅不导通。相当于充电器负极接线柱与电源负极是断路状态，无输出电压。

![](D:\电脑文件\公众号知识库\电工_教育_学习\充电器防反接电路工作过程及故障判断分析_images\img_003_f758b6d8a3c1.jpg)

下图是正常接入电池的工作过程，电池接入后，电池的余电导致三极管基极（b)有电流通路，如图中绿色线。这样三极管导通，充电器电流经e、c极流通，给可控硅栅极（G）一个触发电压，可控硅导通（阳极A与阴极K导通），如图中蓝色线的路径。接线柱负极与充电器负极接通，电流经电池可控硅到电源负极，如图中红色箭头所示，实现为电池充电。

![](D:\电脑文件\公众号知识库\电工_教育_学习\充电器防反接电路工作过程及故障判断分析_images\img_004_326b080f5054.jpg)

下图是电池反接的情况，由于电池反接，电池的正极与负接线柱相连，由于三极管反偏，电池的余电不能通过三极管，也就是三极管不能导通，可控硅栅极（G）得不到触发电压，可控硅截止，既负接线柱与电源负极断开，防止损坏充电器。

![](D:\电脑文件\公众号知识库\电工_教育_学习\充电器防反接电路工作过程及故障判断分析_images\img_005_01c013ddee5a.jpg)

故障判断过程。通过分析知道，要想充电电池必须正确连接，电池余电使三极管导通，进而可控硅导通，实现充电。如果怀疑反接电路有故障可如下判断：

①短接可控硅阳极（A）和阴极（K）后（把它的三个脚都短接也行），可以充电。

②取消短接。

③再短接三极管的e、c两脚（三脚全短接也可以）。

如果充电正常，说明三极管损坏；

如果不能正常充电，说明可控硅损坏。

如果能确保电池能正确接入电路，在可控硅损坏的情况下，可以直接将其短接，应急充电。
