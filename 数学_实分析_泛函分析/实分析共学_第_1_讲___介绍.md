## 五、它们之间的关系（一张图概览）

```
              复数 ℂ               │      ┌────────┴────────┐      │                 │   实数 ℝ            纯虚数 bi（b≠0）      │  ┌───┴───┐  │       │有理数 ℚ  无理数  │整数 ℤ  │自然数 ℕ
```

**关键关系总结：**

1.  **有理数 ⊊ 实数**，即有理数是实数的真子集
    
2.  **无理数 ⊊ 实数**，即无理数也是实数的真子集
    
3.  **实数 ∩ 虚数 = ∅**，两者互不相交
    
4.  **实数 ∪ 虚数 ⊂ 复数**，实数和虚数都属于复数
    
5.  **复数 = 实数 + 虚数**，即任意复数可写为  的形式（ 为实数）
    

* * *

## 六、补充：为什么需要虚数？

在实数范围内，方程  无解（因为任何实数的平方 ≥ 0）。引入虚数后，该方程有了两个解： 和 。虚数的引入使代数基本定理成立——**任何 n 次复系数多项式恰好有 n 个复数根（计重数）**，这在工程学、量子力学、信号处理等领域都有极其重要的应用。

## 16\. 为什么微积分一定依赖完备性

所以实分析先问的不是“怎么算”，而是：

> **你凭什么相信这些逼近过程最后真的落在一个实数里？**

答案就是：因为  是完备的。

## 25\. 一个很适合初学者的理解方式

你可以把这张图里的内容分成两类：

### 一类是“算术规则”

-   加法群
    
-   乘法群
    
-   分配律
    

这说明实数能算。

### 一类是“几何与极限规则”

-   顺序 ≤
    
-   绝对值
    
-   完备性
    

这说明实数不仅能算，还能：

-   比较大小
    
-   描述距离
    
-   支撑逼近和极限
    

而后者，正是分析学真正关心的部分。

* * *

## 26\. 最后给你一个整图总结

这张图的核心内容，可以浓缩成下面这条链：

实数是一个完备有序域

因此它能够可靠地支持：

绝对值、距离、收敛、极限、连续、导数、积分

所以这张图其实是在回答一个根本问题：

> **为什么微积分可以建立在实数上？**

答案就是：

> 因为实数不仅有代数运算，还有顺序结构，更重要的是它是完备的。
