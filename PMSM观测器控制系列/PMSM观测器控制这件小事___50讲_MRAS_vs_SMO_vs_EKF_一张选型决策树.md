## 一、先放下"谁最好"的执念

很多工程师选观测器时，第一步就错了：他们在问"哪个观测器精度最高"，而不是"我的约束是什么"。

这个问题就像你走进五金店买扳手。柜台上摆着三把：

**活动扳手**简单、快、便宜，拧大多数螺丝都够用，但拧紧了会打滑，精密装配不敢用。**数显扭力扳手**能精确到 0.1 N·m，拧航空发动机螺栓必须用，但贵、重、每次用前要校准，还得会读数。**自调扳手**的开口能根据螺母大小自动调整，不用你来回换头，但调整有延迟，遇到特大号螺母照样卡不住。

三把扳手没有绝对的"最好"。你在家里修水龙头，不会扛一把数显扭力扳手出来；你在装配卫星，也不会拿活动扳手凑合。**观测器选型也是一样——先搞清楚你要拧什么螺丝，再选扳手。**

但这里有一个边界差异：扳手是静态工具，拧完就完事了；观测器每 PWM 周期都在跑，选型还要考虑离散化精度、启动切换逻辑、一拍延迟补偿这些系统级因素。选错扳手，顶多拧坏一个螺母；选错观测器，电机可能直接失控。

## 二、三种观测器的"性格"画像

我们把三种观测器映射到工程指标上，先看各自的底色。

### SMO：活动扳手

**SMO（滑模观测器，Sliding Mode Observer）** 的核心动作是：用开关逻辑把估计电流"捏"到实测电流上，从切换动作里提取反电动势信息。优势极其明显——代码短、计算轻、动态响应快。在 M-002 的 MATLAB/Simulink 对比仿真中（经典型、SPMSM、单一电感参数变化），负载突变时经典 SMO 的响应时间只有经典 MRAS 的三分之一到七分之一。

但代价也直白：高频切换会引入抖振（chattering），需要低通滤波器（LPF, Low-Pass Filter）抑制，而 LPF 会吃掉相位裕量。经典 SMO 的稳态转矩脉动通常比经典 MRAS 大。它的"打滑"就体现在这里——拧得猛，但手感糙。

### EKF：数显扭力扳手

**EKF（扩展卡尔曼滤波器，Extended Kalman Filter）** 把状态估计当成一个"预测—修正"的贝叶斯迭代：先根据电机模型预测下一拍状态，再用实测电流修正预测。在模型可信、Q/R 整定合理的前提下，EKF 通常具备最高的稳态估计潜力。状态向量设计得当的话，还能同时估计转速、角度，甚至把磁链或负载转矩扩增为待估状态——但扩增会带来计算量和可观测性要求的双重上升。

但代价是沉重的。每拍要算雅可比矩阵、更新协方差矩阵、求解卡尔曼增益，计算量显著大于 SMO，5 维实现在低端 MCU 上可能是架构性过载。更磨人的是过程噪声 Q 和测量噪声 R 的调参——Q/R 定得不准，滤波器要么过度自信、要么过度敏感，收敛行为完全变味。数显扭力扳手用得好，得先学会校准。

### MRAS：自调扳手

**MRAS（模型参考自适应系统，Model Reference Adaptive System）** 让参考模型和可调模型"赛跑"，通过模型误差驱动自适应律修正转速估计。经典 MRAS 最大的卖点是：不需要像 EKF 那样调 Q/R，自适应律的 PI 增益直观得多。

但"自调"是有边界的。经典 MRAS 对电感参数极其敏感。\[M-002\] 的仿真中，电感增加 50%，经典 MRAS 直接失控，而经典 SMO 仍能维持工作。这不是说 MRAS 不行，而是说**经典 MRAS 的"自调"能力，覆盖不了太大的参数漂移**。改进型 MRAS（带在线参数辨识或高级自适应律）可以大幅扩展这个边界，但计算量和调参复杂度也跟着上来了。

## 四、决策树：四问定生死

真正的选型，不是看表打分，而是按优先级逐层过滤。下面这棵决策树，按工程上最常见的约束优先级排列。

### 第一问：你的 MCU 是什么级别？

算力是第一道硬门槛，它帮你直接淘汰候选。

如果你的 MCU 是 Cortex-M0 或者老的 16 位定点 DSP，主频 48 MHz、Flash 64 KB，那我建议你先把 EKF 从候选名单里划掉。5 维 EKF 的矩阵运算在低速 MCU 上 CPU 负载很高，协方差更新若被中断抖动打断，数值稳定性会出问题。这不是"优化一下就能跑"的问题，需要先做 ISR cycle budget 评估。

这种场景下，SMO 是更务实的起点。经典的 αβ 轴 SMO，核心计算就几步：电流观测误差 → sign 切换 → 等效反电动势 → LPF → 反正切函数（atan2）或 锁相环（PLL, Phase-Locked Loop）提角度。整套逻辑在 Cortex-M3 级别的 MCU（如 STM32F1 系列）上 20 kHz 控制频率常作为经验起点，但实际占用的 CPU 周期必须以 ISR cycle budget 为准，需结合具体实现、编译器优化和三角函数/PLL 实现方式实测。

MRAS 的计算量介于两者之间：每拍要更新两个磁链模型（参考模型 + 可调模型）、算误差矢量、跑 PI 自适应律、积分出角度。比 SMO 重，但比 EKF 轻很多。Cortex-M4 级别常作为经验起点，但仍需按控制频率做 ISR cycle budget 实测确认。

**第一问结论**：

-   • 算力紧张（Cortex-M0 / 16 位定点 / 无 FPU）→ **优先考虑 SMO**
    
-   • 算力中等（Cortex-M4 / 带 FPU）→ **MRAS 和 EKF 都进候选**
    
-   • 算力充裕（Cortex-M7 / 双核 DSP / 带 FPU 和 DSP 指令）→ **EKF 的门槛打通，可以认真考虑**
    

### 第二问：你的电机参数会变多少？

算力过关之后，第二根分叉是参数确定性。以下百分比边界为粗略工程分桶，具体容忍度需按样机扫参确认，并结合电机类型和实际工况验证。

如果你的电机运行在恒温环境、电流永远不超过额定值 50%、磁钢是低温系数的钐钴，那三个观测器都能用，随便挑。

但真实的电机要经历：冬天冷启动 −20°C、夏天绕组 120°C、弱磁时 d 轴电流把磁路推到饱和区。这时候定子电阻 R\_s 可能漂移 30%，q 轴电感 L\_q 可能因饱和下降 20%，钕铁硼磁钢的永磁磁链 ψ\_f 可能每 °C 掉约 0.11%。

**经典 MRAS 在这里会第一个亮红灯。** 它的自适应律只修正转速，不修正电感——自调扳手的"自动调整"覆盖不了这么大的形变。经典 SMO 对电感漂移的耐受度比经典 MRAS 好得多，因为 SMO 的核心是开关项"捏"电流，不依赖精确的电感模型。但 SMO 也不是免疫：电感偏差太大时，滑模面设计失配，收敛特性会变差，抖振也可能加剧。EKF 的应对策略最灵活：如果参数漂移是慢变的，可以通过增大 Q 矩阵让滤波器"更听测量的话"；如果漂移快，需要把待辨识参数扩增为状态，但这会进一步膨胀计算量和调参维度。

**第二问结论**：

-   • 漂移 < 10%（恒温、小电流、无去磁风险）→ 三种都行，看其他约束
    
-   • 漂移 10%~30%（常规温升、中等弱磁）→ 经典 MRAS 可用但需留裕量；SMO 更稳健；EKF 可通过 Q/R 调整降低对模型的信任，若漂移慢且可被扰动模型吸收，容忍度会提高——但系统性参数漂移通常需要增广状态或在线辨识
    
-   • 漂移 > 30% 或剧烈变化（宽温域、深度弱磁、严重磁饱和）→ **经典 MRAS 风险高**；考虑改进型 MRAS（带在线参数辨识）或增广 EKF
    

### 第三问：你的速域要求是什么？

三种观测器在低速区有一个共同点：**都难受**。

低速时反电动势幅值小，信噪比差。SMO 的开关项在弱信号里"捏"不住，抖振相对更严重；MRAS 的电压模型积分在低速时漂移累积，电流模型则信噪比不足；EKF 的模型在低速时同样不准，如果 Q 矩阵没调好，滤波器会过度自信地跟着错误模型跑。

所以低速不是选"哪种观测器低速更好"，而是选"哪种观测器在低速区没那么差，再配合 高频注入法（HFI, High-Frequency Injection）或 恒压频比（V/F）/ 恒流频比（I/F）开环拖行策略"。

高速区倒是三种观测器都能工作，但要注意**载波比（C/F）**。如果 PWM 频率 10 kHz、电机最高电频率 1 kHz，载波比只有 10，离散化误差会显著放大。这时候，离散化方法的选择（Euler 还是 Tustin 还是精确离散）比观测器类型本身更致命。载波比偏低（如 C/F < 15）时，优先保证离散化精度，观测器类型的差异被缩小。这个经验边界在本系列 [第48讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486893&idx=1&sn=99bb69637f5c663e72471a64a8af8054&scene=21#wechat_redirect) 和 \[D-002\] 中都有讨论。

**第三问结论**：

-   • 低速为主（< 10% 额定转速）→ 三种观测器都需配合 HFI / V/F / I/F 启动，观测器类型差异被启动策略覆盖
    
-   • 中高速为主（10%~100% 额定转速）→ 三种都行，看其他约束
    
-   • 高速低载波比（如 C/F < 15）→ **优先保证离散化精度，观测器类型次之**
    

### 第四问：你的团队有多少调参耐心？

这是最容易被低估的维度。

EKF 的 Q/R 调参，本质上是在问"我的模型有多不靠谱"和"我的传感器有多不靠谱"。这两个问题没有标准答案，需要系统辨识、大量试错、或者至少是对电机物理的深刻理解。很多团队有过这样的经历：先把 EKF 框架跑起来不算难，但 Q/R 调参可能消耗数周甚至数月，如果项目周期紧张，这一点必须纳入评估。

MRAS 的 PI 自适应律增益（K\_p、K\_i）直观得多，有经验的工程师半天就能拧到一个能工作的区间。但 MRAS 也有暗坑：自适应律增益和电压模型的积分抗漂移是耦合的，调了 K\_p 发现低速发散了，可能不是 K\_p 的错，是电压模型纯积分在低速区累积了偏置。

SMO 的调参维度是滑模增益 + LPF 截止频率 + PLL 带宽，三者相互牵制。滑模增益大了抖振大，LPF 截止低了相位延迟大，PLL 带宽高了噪声敏感。这三个参数的平衡，需要示波器上反复看波形，经验成分重。

**第四问结论**：

-   • 团队有系统辨识经验、有时间迭代 → **EKF 可以发挥最大潜力**
    
-   • 团队想"快点跑起来、参数漂移不大" → **经典 MRAS 是性价比之选**
    
-   • 团队习惯示波器调参、对抖振有容忍度 → **SMO 更直接**
    

## 五、那句"不愿意听的实话"

选型决策树讲到这儿，好像只要四维约束一摆，答案就清晰了。但有三句实话，很多文献不会告诉你。

**第一句：零速启动不是观测器的问题，是系统的问题。**

这里说的是不带高频注入或位置先验的经典反电势类模型观测器。三种观测器在零速或极低速时都失效——这不是它们设计得不好，是物理决定的：反电动势与转速成正比，ω ≈ 0 时信号被噪声淹没。选 SMO、MRAS 还是 EKF，零速都一样抓瞎。真正解决零速启动的，是 HFI（依赖凸极性或饱和可观测性）或 V/F / I/F 开环拖动。观测器类型的选择，对零速启动没有本质影响。

**第二句：离散化精度不够时，再好的连续域设计也白搭。**

你可能在论文里看到一个漂亮的 EKF 设计，收敛快、精度高，但那是连续域的。把它塞进 10 kHz 的定时器中断，用前向 Euler 离散化，载波比只有 10，矩阵运算还被中断延迟打断——效果可能还不如一个老老实实调好的 SMO。离散化方法（本系列 [第6讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486511&idx=1&sn=06f325c71240480625326415fe7f5c66&scene=21#wechat_redirect)、[第48讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486893&idx=1&sn=99bb69637f5c663e72471a64a8af8054&scene=21#wechat_redirect) 及 \[D-002\]）和代码时序（[第7讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486516&idx=1&sn=279cebb35232396591af925e5238c137&scene=21#wechat_redirect)）的优先级，在工程实现中常常高于观测器类型的选择。

**第三句：一拍延迟没补偿，三种观测器都会歪。**

这是本系列前10讲就讲过的老问题，但值得在这里再敲一次黑板。第 k 拍算的占空比，第 k+1 拍才生效；观测器如果用的是上一拍的电流电压，角度估计就会落后一拍。20 kHz 下 50 µs 的延迟，1 万转 4 极对电机对应约 12° 电角度。这个延迟与观测器类型无关，SMO、MRAS、EKF 都要面对。VESC 的 `foc_observer_offset`（`bldc/motor/mcpwm_foc.c`，commit `c59445545fa8f1a6093e882807b2ca46d1870f24`，补偿开关频率相位滞后）就是在解决这个问题。别指望换一个观测器就能消除一拍延迟。

## 六、最终工程判断

选观测器不是选"精度冠军"，而是**在算力、参数漂移、速域、调参耐心这四维约束里找交集**。

-   • 算力紧张、参数漂移可控、团队想快速落地 → **SMO**
    
-   • 参数漂移中等、不想调 Q/R、中高速为主 → **经典 MRAS**
    
-   • 算力充裕、团队有耐心、追求最高稳态估计潜力 → **EKF**
    
-   • 参数漂移剧烈、算力也充裕 → **改进型 MRAS（带在线辨识）或增广 EKF**
    
-   • 高速低载波比 → **先保证离散化精度，再选观测器**
    
-   • 零速启动是刚需 → **先选启动策略（HFI / V/F / I/F），观测器类型其次**
    

没有包治百病的万能药。活动扳手、数显扭力扳手、自调扳手，各有各的活法，也各有各的死法。把约束条件老老实实写在纸上，答案往往比想象中清晰得多。
