### 注意事项

在我们进行消去回代的过程中，如果主元素（位于主对角线上的元素  ）为 0，那么消去过程和回代过程都不能顺利进行。因为 0 乘以任何非 0 常数都为 0，达不到消去其他行的目的；而回代过程需要主元素做除数，所以主元素不能为 0。

_**定理**_

若方程组  的系数矩阵  为严格对角占优，那么使用高斯消去法求解时，不会出现为 0 的主元素。

除此之外，即使在进行高斯消去过程中不会出现主元素为 0 的情况，但是出现了主元素比较小（相对于其他元素）的时候，也不能直接使用高斯消去法，因为在回代过程中会放大舍入误差，严重影响解向量结果的精度。这个时候可以使用**选主元技术**在一定程度上可以避免这种情况。

## 高斯消去法的局限性

尽管高斯消去法在许多应用中表现出色，但它也存在一些局限性：

-   **数值稳定性**：在高斯消去法中，如果主元为零或接近零，可能会导致数值不稳定。通过部分主元法或完全主元法可以缓解这一问题，但并不能完全消除。
    
-   **计算复杂度**：高斯消去法的计算复杂度为 ，对于大规模矩阵，计算时间可能会很长。通过优化算法和并行计算可以提高计算效率。
    
-   **稀疏矩阵**：对于稀疏矩阵（即大部分元素为零的矩阵），高斯消去法可能会导致矩阵的填充（fill-in），即原本为零的元素变为非零元素。这会导致存储和计算的开销增加。针对稀疏矩阵，可以使用专门的算法，如稀疏 LU 分解。
