# 重磅！德尔股份拟投资3亿元加码智能电机

6月3日晚间，德尔股份(300473)发布公告称，公司决定与浙江省湖州市吴兴区织里镇人民政府签署《投资合作协议》，计划在织里镇投资建设固态电池中试及产业化项目和智能电机产业化项目，总投资约为3亿元。

![图片](D:\电脑文件\公众号知识库\电工_行业资讯\重磅_德尔股份拟投资3亿元加码智能电机_images\img_002_d8db4fb5d7f9.png)

  

根据德尔股份公告声明，本次投资不构成关联交易，也不构成重大资产重组。投资资金来源为公司自有资金及自筹资金。公司此次签署的《投资合作协议》旨在响应国家产业政策导向，通过整合政府与企业的资源优势，重点拓展新型锂电池和智能电机业务领域。公司同时提示，由于项目建设周期较长，短期内难以产生规模经济效益，预计不会对**2025年度经营业绩**产生重大影响

  

德尔股份是一家全球化布局的综合性汽车零部件供应商，成立于2000年，2015年于深交所创业板上市。公司专注于汽车零部件的研发、生产和销售，核心业务覆盖三大领域主要生产和销售汽车降噪（NVH）、隔热及轻量化产品，电机汽车电子产品。公司国内外主要客户包括奔驰、宝马、奥迪、保时捷、福特、上汽、吉利、奇瑞等。2024年公司营收45.13亿元（同比+4.98%），净利润3242万元（同比+151.73%），业绩显著改善。

  

德尔股份此次精准锚定新能源相关核心赛道，深度切入新能源核心零部件领域。

德尔股份此次固态电池项目涵盖中试环节，标志着其技术量产落地的关键跨越。同步推进的智能电机项目，直击新能源汽车电驱系统核心环节，通过强化自主配套能力降低外部依赖，构建完整的电池、电机、电控三电系统布局。项目选址湖州织里镇，实现与特斯拉、蔚来、吉利等长三角整车制造基地的近距离联动。此举大幅缩短供应链半径，增强主机厂协同效率，为订单获取提供战略性区位支撑。

  

据悉，2021年和2022年，德尔股份两次实施定增融资，但募投项目均未达预期，进展也极为缓慢。固态电池和氢能源业务最终能否见到成效，同样值得关注。

  

二级市场上，截至6月3日收盘，德尔股份下跌4.62%报33.48元/股，最新市值50.55亿元，今年来累计上涨约三成。
