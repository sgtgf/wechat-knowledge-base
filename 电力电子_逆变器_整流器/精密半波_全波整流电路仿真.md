# 精密半波/全波整流电路仿真

整流是将交流电转换为直流的方法。半波整流可用一个二极管完成，全波整流可用4个二极管搭成“H”桥完成。但是这两种方法仅对大电压交流电有效，因为二极管有0.7V的压降，所以这两种传统的整流方式无法对小于二极管压降的交流电进行整流。

使用PSIM仿真0.1V交流电整流。

为了能整流0.1V或更小交流电，这里介绍一种精密整流电路。如下图所示，这是一个精密半波整流电路。

![](D:\电脑文件\公众号知识库\电力电子_逆变器_整流器\精密半波_全波整流电路仿真_images\img_002_5ec70026932f.jpg)

  

当Vac > 0时，运算放大器的输出端必然为负，从而使二极管D2导通，D1截止。这样，电路就实现了反相比例运算，输出电压

Vo = -(Rf / R1)×Vac

当Vac < 0时，运算放大器的输出端必然为正，从而是二极管D2截止，D1导通，Rf中电流为0，因此输出电压Vo = 0。

仿真结果如下：

![](D:\电脑文件\公众号知识库\电力电子_逆变器_整流器\精密半波_全波整流电路仿真_images\img_003_831597dbf25e.png)

  

那如何才能实现精密全波整流呢？思路是将丢失的另一半波捡回来就是了，如下图所示：

![](D:\电脑文件\公众号知识库\电力电子_逆变器_整流器\精密半波_全波整流电路仿真_images\img_004_16763bb99d25.jpg)

  

这里需注意Rf = 2R1，这使得当Vac > 0时，Vo1 = -2Vac，所以Vop = Vo1 + Vac =Vac。当Vac < 0，Vop = Vac。
