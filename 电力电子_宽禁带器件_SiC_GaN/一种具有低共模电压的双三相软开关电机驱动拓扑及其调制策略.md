# 一种具有低共模电压的双三相软开关电机驱动拓扑及其调制策略


> 原文地址: [https://mp.weixin.qq.com/s/Cx6jF\_4B3dqCoqGF1v5hTA](https://mp.weixin.qq.com/s/Cx6jF_4B3dqCoqGF1v5hTA)

文章来源：中国电机工程学报

作者:邹辉，潘尚智\*，林子森，林文强，汪睿轩，宫金武，查晓明(综合能源电力装备及系统安全湖北省重点实验室(武汉大学电气与自动化学院)，湖北省武汉市 430072)

摘要：针对双三相永磁同步电机应用场景，提出一种新型双三相同步辅助谐振极软开关逆变器电机驱动拓扑及自适应边沿对齐调制策略。所提拓扑利用2 个谐振电感同步辅助实现所有主电路开关的零电压开通，有效降低主开关器件的开关损耗，所提调制策略通过同步辅助降低辅助支路的控制复杂度，减少对控制器资源的占用。通过对所提调制策略的开关矢量变化过程分析表明，所提策略同样能够抑制双三相系统共模电压至0.167Udc。最后，通过仿真和实验，证所提方法的有效性。  

关键词：双三相永磁同步电机(DT-PMSM)；软开关；电机驱 动；共模电压  

0 .引言  

高性能智能网联电动汽车领域对永磁同步电机(permanent magnet synchronous motor，PMSM)的高可靠、大功率和稳定的扭矩输出提出更高需求。多相电机提供强大的容错能力、更高的功率等级和较小的转矩脉动的潜在优势，得到广泛研究和应用。  

由于目前电机驱动器通常采用基于绝缘栅双极晶体管(insulate-gate bipolar transistor，IGBT)的电压源型逆变器，驱动器的开关频率受到IGBT 开关损耗的限制。而电机驱动器低开关频率会导致电机绕组的电流纹波增大，进而导致电机运行时产生较大的转矩脉动和温升，影响电机运行效率及使用寿命。同时，电压源逆变器在硬开关工作模式时存在较大的电磁干扰(electromagnetic interference，EMI)问题。此外，逆变器驱动电机带来还会带来较大的系统共模电压(common mode voltage，CMV)， 由于频率高、幅值大，共模电压会导致轴承失效和不良电磁干扰，因此，必须采用合适的措施减小系统的共模电压。软开关技术能够有效降低功率器件的开关损耗，同时，可以消除硬开关过程中过电压和过电流尖峰带来的EMI 问题，让电机驱动逆变器实现高频化运行，提高变换器及电机的运行效率和稳定性。

软开关逆变器按谐振电路可分为谐振极型软开关逆变器和谐振直流侧软开关逆变器。谐振直流侧软开关逆变器电路相比于硬开关电路，成功地降低器件的开关损耗，提高装置效率，但其开关管的电压应力是直流母线电压的2.5倍，不利于高压场景的应用。同时，使得母线电压具有很多过零凹槽，降低直流电压的利用率，且其辅助元件位于直流母线上，使辅助元件一直承受很大的导通损耗。  

文献\[13\]首次提出经典的辅助谐振极型软开关逆变器拓扑结构，具有如下优点：  

1）未增加主开关管的电压和电流应力，适用于高压场景应用；  

2）三相谐振电路之间相互独立，易应用各种调制策略；  

3）相互独立辅助谐振电路具备较强的多相扩展性。

但该拓扑在三相电路中具有3 个体积较大的谐振电感，如果扩展到双三相电机驱动场景，谐振电感体积占比将不可忽视。文献\[11\]提出一种应用于800V 高压平台的三电平辅助谐振极软开关逆变器拓扑，解决高压电机驱动损耗大的问题，但其每相采用一个辅助电感和一个耦合电感，增大逆变器体积，不利于多相电机的应用拓展。文献\[12,14\]提出双辅助谐振极软开关逆变器在每相辅助缓冲回 路中使用2 套辅助谐振元件，更加适用于大功率场合，但仍然采用较多无源元件，且其控制方式复杂。文献\[16\]提出一种单辅助电感的谐振极软开关逆变器拓扑，将辅助电感的数量降到了最低，但其对辅助支路开通时刻要求严苛，在调制上不够灵活，不利于系统共模电压的抑制。

共模电压的抑制措施主要有2 种：  

1）使用有源或无源滤波器来降低逆变器的共模电压，但这种方法需要增加额外的元件；  

2）对逆变器的脉宽调制(pulse-width modulation，PWM)进行修改以降低共模电压。

第2 种措施成本更低，具有较强优势。文献\[21-28\]提出一系列适用于三相和多相电机的低共模电压调制方式。为在xy 和αβ 2个平面上合成参考电压矢量的同时抑制共模电压，常规做法是通过预选具有低共模电压的矢量集。其中，文献\[23\]提出通过2 个相位相反的电压矢量作用相同时间等效构成零矢量作用，将使用的矢量数减少至5 个，有效减少开关动作次数。文献\[24\]提出一种无需预选矢量集而根据电流扇区进行死区开关控制从而对共模电压幅值进行有效抑制的调制策略。文献\[25\]基于三电平多相H 桥串联电机驱动提出一种载波翻转共模电压抑制策略，能在不影响输出电流谐波的情况下抑制系统共模电压。但上述文献都集中于普通的硬开关电压源逆变器分析，对于利用软开关技术在提高电驱功率密度、降低EMI 的同时降低系统共模电压影响方面的研究仍然较少。  

针对上述问题，本文提出一种应用于双三相永磁同步电机(dual three-phase PMSM，DT-PMSM)的双三相同步辅助谐振极软开关逆变器(dual  three-phase synchronous auxiliary resonant pole，DTSARCP)拓扑及其调制策略。详细分析所提变换器的运行原理、软开关条件，并提出一种具备低共模电压的自适应边沿对齐调制策略(adaptive edge  aligned pulse-width modulation，AEA-PWM)。同时，给出辅助电路参数优化设计方法。最后，通过仿真和6kW实验样机验证表明，采用所提软开关逆变器拓扑及其调制方式，仅利用2 个谐振电感和1个用于辅助开关控制的PWM 模块实现全部器件的软开关，且双三相系统的共模电压幅值降低至0.167Udc。

1.2 拓扑辅助换流过程分析  

在主电路中桥臂状态用Sn表示，如Sa1\=1表示a1 相上开关开通、下开关关断，Sa1\=0表示a1 相上开关关断、下开关开通。设定电流流出桥臂，流向交流负载为电流正方向。在负载电流为正的条件下，从“0”到“1”的切换过程为硬开关切换。在从“1”到“0”的状态期间，下管中的电流将首先流入其寄生二极管将开关管两侧电位钳位至零从而实现自然软开关切换。当负载电流反向后，从“0” 到“1”的切换过程为软开关切换，从“1”到“0” 的切换过程为硬开关切换。  

为简化分析过程，作如下假设：1）所有开关器件均工作在理想状态；2）负载电感远大于谐振电感，在每次开关动作时负载可当作恒流源；3）直流侧电容足够大，直流母线电位波动很小。同时， 双三相同步辅助谐振极软开关逆变器的各相换流原理完全相同，因此，可以分析单相电路的运行原理以简要说明整个电路的运行原理。

2 .调制方式及其共模电压分析  

2.1 辅助支路状态分析  

图6 为传统空间矢量脉宽调制(space vector  pulse width modulation，SVPWM)策略在1 个开关 周期内的PWM 波形。假设双三相电流的正负关系为：ia1\>0、ib1<0、ic1<0、ia2\>0、ib2<0、ic2<0。 因此，将各相硬开关时刻用虚线框标注。

![](D:\电脑文件\公众号知识库\电力电子_宽禁带器件_SiC_GaN\一种具有低共模电压的双三相软开关电机驱动拓扑及其调制策略_images\img_009_35c126ccb35a.png)

此时，双三相的硬开关动作在不同的时刻，辅助支路需要在不同的时刻开通使辅助电感反复充电。一方面，辅助支路的控制电路需要12 个相位可控的PWM 模块，造成了控制器硬件资源的紧张；另一方面，当辅助电路要对多相桥臂进行辅助时，以两相为例，可能出现3 种情况：独立、交叠、重合，分别如图7 所示。当两相硬开关时刻处于独立状态时，能够被辅助支路正常辅助2 个硬开关时刻。下文讨论交叠和重合2 种情况下的辅助支路工作模态。

交叠状态表示第2 相辅助支路正处在辅助阶段时，第1 相辅助开关Sx1\_N开通。第2 相主开关电压U2P\>0、U2N<Udc，Sx1\_N开通前电路状态如图8 所示， 此时，A 点和B 点电位为UB\=UA<Udc。当Sx1\_N开通后，由于Sx1\_N处于导通状态，此时，B 点电位被上拉至Udc，从而导致UB\>UA，Dx2\_N截止。由于二极管截止前电流不为零，因此，会在开关器件上产生极大的di/dt，导致开关器件产生过电压击穿。

当处于重合状态时，两相辅助开关Sx1\_N、Sx2\_N同时开通并为辅助电感Lr2 充电。此时电路不会出现因为辅助过程被打断而出现的di/dt 过大导致的严重过电压问题。相较于独立状态，重合状态不需要消耗过多的控制资源以避免电路出现交叠状态。  

综上所述，可以通过改变电路调制方式，使得所有的硬开关时刻处于重合状态，从而保证电路运行的安全性以及降低控制器资源占用情况。  

2.2 自适应边沿对齐调制策略  

为实现将所有硬开关时刻对齐至重合状态，本文提出一种自适应边沿对齐调制策略。考虑到各相硬开关状态由负载电流的方向确定，图9 给出双三相电机的电枢电流状态，通过各相电流的正负关系将1 个周期内电流分割成12 个电流扇区。对于双三相电机驱动逆变器而言，其开关状态的组合有64种开关模式，可向逆变器施加64 个不同的电压矢量。每个电压矢量的编号由Sc2Sb2Sa2Sc1Sb1Sa1 对应的二进制数转化为十进制数表示。

综上所述，所提软开关逆变器拓扑实现所有主功率器件的ZVS，所有辅助器件的零电流开关。同时利用所提调制方式，能够简化辅助电路控制，降低控制资源占用，有效抑制双三相电机系统的广义系统CMV。  

5 .结论  

为克服硬开关电压源型电机驱动器存在的开关频率低和传统调制策略共模电压高的问题。本文提出一种采用自适应边沿对齐PWM 调制策略的双三相同步辅助谐振极软开关逆变器拓扑。通过原理分析和实验结果，得到结论如下： 

1）所提软开关电机驱动拓扑中所有主开关管均能实现ZVS，辅助电路中所有开关管均能实现零电流开通和关断，有效降低开关器件的开关损耗。 

2）所提AEA-PWM 调制策略通过电流方向检测将所有硬开关时刻调整至重合状态，降低辅助电路的控制复杂度，减少对控制资源占用。 

3）AEA-PWM 调制策略能够将双三相系统共模电压幅值降低至0.167Udc，同样具有良好的广义系统CMV 抑制能力。 

4）DTSARCP 逆变器在6kW 时工作效率为98.7%，与相同条件下的硬开关电驱相比效能量转化效率提高1.1%。
