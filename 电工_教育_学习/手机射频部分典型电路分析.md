**收发器**

（ Transceiver ）

收发器即调制解调器

调制：发射时基带信号加载到射频信号

解调：接收时射频信号过滤出基带信

Transceiver 根据其工作频率可分为：单

频、双频、三频等

Transceiver 根据其中频特征可分为有中

频、零中频、近零中频等

**锁相环四个基本构成元素**

鉴相器（ PD ）鉴频器（ FD ）鉴相鉴频（ PFD ）：

PD/FD/PFD 是一个相位 / 频率比较装置，用来检测输入信

号与反馈信号之间的相位 / 频率差

环路滤波器 Loop Filter （ LP ）：

LP 一般为 N 阶低通滤波器

电压控制振荡器（ VCO ）：

VCO 是一个电压 -- 频率变换装置 ，输出振荡频率应随输

入控制电压线性地变化

参考信号源（ Reference signal source ）：

参考信号源提供与反馈信号鉴相鉴频用的对比输入信号
