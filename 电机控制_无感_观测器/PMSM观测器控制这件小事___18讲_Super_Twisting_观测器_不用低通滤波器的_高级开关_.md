你盯着上位机里反电势估计值的波形曲线，第 n 次调整 LPF 的截止频率。

这不是示波器探头直接夹出来的量——反电势是观测器算出来的估计值，这是你通过 DAC 导出到屏幕上看。当前电机在 3000 rpm 附近跑，电角频率约 200 Hz。一阶 LPF 切到 800 Hz，相位 lag 约 ，转速突变时角度跟着滞后。切到 2 kHz，lag 缩到 ，可波形上的毛刺又让你心里发毛。你把 `sat` 的  调大、调小、再调大，永远在"跟得上"和"不抖动"之间走钢丝。

同事老炮儿端着泡满了枸杞的保温杯路过，瞄了一眼屏幕："还在拧 LPF 啊？"

"不然呢，`sign` 输出的信号不滤波能看？"

"有人把开关逻辑本身改写了。不用 LPF，输出天然连续。"他顿了顿，"Super-Twisting，听说过没？"

也许你没吭声。但脑子里想的肯定是：`sign` 函数的根子就是非连续，不动 LPF 怎么可能让输出连续？除非……你把产生抖振的机制从源头上干掉。

这就是 Super-Twisting 观测器（STO, Super-Twisting Observer）的野心。它不归在"边界层法"那一支——`sat` 和 `tanh` 是给 `sign` 穿外套，STO 是把 `sign` 的底层逻辑重写了一遍。

## 电钻的两档扭矩，怎么就比锤子高级了

各位同仁用过电动螺丝刀吗？

廉价款只有一个档：按下去就全速转，松手就停。拧自攻螺丝进木板，第一下要么打滑要么拧歪——像极了 `sign` 函数，要么全开要么全关，产生的冲击（抖振）全靠你手劲缓冲。

好一点的电钻有两个模式。一个叫"快速旋入"：刚怼上去的时候大力输出，让螺丝牙快速咬进材料。一个叫"自动拧紧"：快要到位时扭矩自动衰减，电机改成低速持续加压，最后那一圈几乎无声无息地拧紧。

关键在这：输出轴的转速和扭矩是**连续变化**的。没有突然的机械冲击，不需要你在手里垫块海绵来吸收震动。

经典 SMO 的开关项只有一档：

按下去就是全力，松手就是零力。为了能用，你不得不在后面接个低通滤波器——相当于给电钻手柄缠海绵。`sat` 和 `tanh` 稍微高级一点，相当于给开关加了个弹簧，让按下去的过程软一点，但本质还是"一档开关"。

Super-Twisting 算法（STA, Super-Twisting Algorithm）直接设计了**两个联动档** \[L-001\]。

电流误差很大时， 也不算小，这一项出力猛，快速把估计值往真实值拽。这对应电钻的"快速旋入"——螺丝刚接触木板，需要大力咬进去。

可当误差逐渐缩小， 衰减得比线性**慢**。误差降到原来的 1/4，出力只降到 1/2——如果是线性项，这时候应该已经降到 1/4 了。误差降到 1/100，出力还剩 1/10。这个"衰减更慢"的特性恰恰是关键：它在接近零点时保留了比线性更多的推力，不像线性项那样一过小就撒手不管。

这恰恰解决了 `sign` 函数的死穴。`sign` 在误差为  和  时输出力度完全一样，所以永远在边界上来回硬切。而 STA 的第一项在接近零点时自动"收力"，切换的幅度天然变小。

打个比方：你开着一辆只有"地板油"和"空挡"两个状态的车，在拥堵路段只能一脚急刹一脚猛踩。现在这辆车升级了——油门踏板变成了非线性的，车速离目标越远踩得越狠，越近踩得越轻。虽然还是同一双脚在踩，但乘客不会再晕车了。

但光靠这一项还不够。误差趋近于零时， 也趋近于零，整个开关项快消失了——谁来保证稳态精度？谁来压制持续的参数漂移和负载扰动？

## 第二档：自动拧紧，记住方向

STA 的第二个输出项是个积分：

这玩意看起来土，实则关键。

 虽然在 ±1 之间跳变，但积分器把它变成了**连续累积**。如果误差持续为正，积分器就往负方向持续累积；误差翻负，积分器开始往回收。它记住了误差的方向历史，输出一个缓慢变化但连续的控制量。

把两项合起来，STA 在 α 轴的完整控制律是：

大误差阶段，第一项主导，快速收敛。接近稳态时，第一项衰减，第二项接手，用积分记忆持续压制扰动。最终输出的  是**时间上的连续信号**——不需要低通滤波器来事后平滑，因为它从机制上就是平滑的。

这对应的就是电钻的完整两档逻辑：快速旋入档负责动态响应，自动拧紧档负责稳态保持。两者配合，输出轴不会出现冲击。

> 注：STA 不是状态机——不是先开一档、再切二档。两项**同时**存在，只是在不同误差范围内谁占主导。大误差时第一项 "盖住" 了第二项；接近稳态时第一项衰减，第二项才"浮上来"。这个过程是连续的，没有明确的切换点。

## 那省掉的 LPF，到底去哪了

说句实话，不是 LPF "消失"了，而是它的功能被**内置**了。

经典 SMO 的链路是：

开关项（跳变）等效控制（平滑）反正切角度

STO 的链路是：

等效控制（收敛后）可直接解释反正切角度

中间少了一个环节，也就少了一个相位延迟的来源。在电流误差收敛到滑模面后，按等效控制原理，STA 输出可直接解释为反电动势估计，无需额外的 LPF 提取环节。

这个"内置平滑"是怎么做到的？核心在于二阶滑模（Second-Order Sliding Mode, 2-SMC）的定义 \[L-001\]。

经典一阶滑模只要求滑模变量 （这里是电流误差 ）被驱动到零。可  之后，系统的状态还在滑模面两侧高频穿梭——就像你在冰面上滑到了沟槽里，但身体还在左右晃。

二阶滑模的要求更狠：不仅 ，它的变化率  也要同时被驱动到零。系统不再是在滑模面上高频抖振，而是被"钉"在  这个点上。既然相对速度为零，哪来的抖动？

说白了，一阶滑模是"到了目的地还在原地踏步"，二阶滑模是"到了目的地直接坐下不动"。

当然，这是连续域的理想画像。实际在 DSP 里跑的时候，采样周期  会让理想打折。但即便打折，STO 通常仍能显著降低残余抖振 \[S-004\]，很多时候直接省掉 LPF 也能用。

## 有限时间收敛：最后十米反而加速

用 `sat` 或 `tanh` 做边界层近似后，系统在滑模面附近的动态被线性化，收敛变成渐近（asymptotic）的——理论上要无限长时间才能严格到达平衡点，虽然工程上很快就足够近了。

严格 `sign` 滑模在满足到达条件时，本来就是有限时间到达滑模面的。STA 更进一步：它不仅让滑模变量  有限时间到零，还让它的导数  也有限时间到零。后者是经典一阶滑模做不到的。

怎么做到的？秘密还在那个指数 0.5 上。

当  接近零时， 虽然也在减小，但它减小的速度比线性慢。换句话说，在"最后一公里"，STA 的"油门"并没有完全松掉，反而比线性衰减保留更多的推力。这让它有能力在有限时间内"冲线"，而不是无限接近终点线。

可以想象一下这个场景：百米冲刺。线性衰减的选手跑到最后十米开始减速，慢慢蹭过终点。STA 的选手跑到最后十米反而加速冲线——虽然总用时可能差不多，但 STA 在数学上保证了你**确实**在某一有限时刻踩过了终点线，而不是逐渐接近它。

这么做，工程上的意义是什么？

负载突变时，STA 的收敛速度通常比经典 SMO+LPF 快，因为没有 LPF 的相位延迟拖后腿。文献 \[S-005\] 中对比了传统 SMO、STO 与自适应 ASTO 的零穿越相位差：ASTO 的抖振几乎消除，相位差最小；传统 SMO 性能最差。

## 调参的时候，先扫 ，再扫 

两个增益互相牵制，不像经典 SMO 只有一个  好调。

建议的调参顺序：

1.  1. **先把  设为一个中等值**（比如按上述方法算出来的初值），固定不动。
    
2.  2. **从小到大扫** ，观察电流误差的收敛速度。 太小，收敛慢； 太大，电流环出现振荡。
    
3.  3. **找到  的"适宜区"** 后固定，再扫 。 太小，稳态有静差； 太大，积分饱和风险上升。
    
4.  4. **最后把两个数放在一起微调**，动态和稳态兼顾。
    

这个顺序的逻辑是： 主要影响动态响应， 主要影响稳态精度。先解决"能不能追上"，再解决"追得准不准"。

## 三个坑：STO 不是工程上的万能药

说完了美好的一面，咱们来泼点冷水。STO 在论文里看起来很香，但落到工程代码里，有三个坑等着你。

### 坑一：离散化让有限时间变成"准有限时间"

Levant 的收敛条件是在连续域推导的。你的 DSP 每隔  才算一次，连续域的数学保证在离散域会退化。

如果  太大（比如开关频率只有 5 kHz，），STA 的积分项更新太慢，第二档"自动拧紧"跟不上转速变化，连续域的收敛保证退化，可能抵消 STO 的优势，残余抖振是否降低需实测确认 \[D-001\]\[D-002\]。

经验法则： 最好小于系统电气时间常数的 1/20。对大多数 PMSM，这意味着开关频率至少 10 kHz 以上，STO 才能发挥出它的优势。

### 坑二： 和  的耦合让你永远调不到"两全"

经典 SMO 调一个 ，大了就抖，小了就跟不上，关系简单直接。

STO 有两个旋钮，而且它们不是正交的。 调好了， 一变，动态响应跟着变； 调好了， 一动，稳态精度又跑了。你经常发现：、 动态好但稳态有 2° 误差；、 稳态精度上去了，但负载突变时 lag 了 30 ms。

没有万能公式能一次性给你最优解。只能做参数扫描，画一张 \- 的性能等高线图，然后在里头挑一个你最能接受的折中点。

### 坑三：低速段仍然救不了

STO 消除的是**开关逻辑本身产生的高频抖振**，不是传感器噪声。

电机低速运转时，反电势幅值只有几伏甚至几百毫伏，和你的电流采样噪声、ADC 量化误差在同一个量级。反电势太低导致模型法的可观测性下降，信噪比恶化——误差信号本身就被噪声污染了，再聪明的开关逻辑也分不清"真实误差"和"噪声抖动"。

说白了，STO 解决的是"开关太粗暴"的问题，不是"信号太弱"的问题。低速段可观测性和信噪比差这个硬骨头，还得靠高频注入或者 I/F 强拖启动来啃 \[H-003\]。

## 伪代码：怎么把 STA 塞进 ISR

三个开源工程（ODrive、VESC、phobia）目前都没有 STO 的现成实现，所以这里给一套完整的 C 伪代码框架，各位同仁可以直接移植到自己的 FOC 主循环里。

`// STA-SMO 伪代码，每 PWM 周期调用一次   // 状态变量：i_hat_alpha, i_hat_beta   // 积分状态：z_alpha, z_beta（k2 的积分项）      typedef struct {    float i_hat_alpha;   // 估计电流 alpha    float i_hat_beta;    // 估计电流 beta    float z_alpha;       // k2 积分器 alpha    float z_beta;        // k2 积分器 beta    float k1;            // 快速收敛增益    float k2;            // 积分增益    float L;             // 定子电感    float R;             // 定子电阻   } STA_SMO_t;      void sta_smo_update(STA_SMO_t *smo,                    float u_alpha, float u_beta,  // 施加电压                    float i_alpha, float i_beta,  // 实测电流                    float Ts)                     // 采样周期   {    // 电流误差    float err_alpha = i_alpha - smo->i_hat_alpha;    float err_beta  = i_beta  - smo->i_hat_beta;    // 第一项：k1 * sqrt(|err|) * sign(err)    float sqrt_err_alpha = sqrtf(fabsf(err_alpha));    float sqrt_err_beta  = sqrtf(fabsf(err_beta));    float u1_alpha = -smo->k1 * sqrt_err_alpha * (err_alpha >= 0.0f ? 1.0f : -1.0f);    float u1_beta  = -smo->k1 * sqrt_err_beta  * (err_beta  >= 0.0f ? 1.0f : -1.0f);    // 第二项：k2 的积分（欧拉法离散）    // z_dot = -sign(err)  =>  z_{k+1} = z_k - Ts * sign(err)    // 注意符号：这里 z 是积分器状态，最终输出是 k2 * z    float sign_alpha = (err_alpha > 0.0f) ? 1.0f : ((err_alpha < 0.0f) ? -1.0f : 0.0f);    float sign_beta  = (err_beta  > 0.0f) ? 1.0f : ((err_beta  < 0.0f) ? -1.0f : 0.0f);          smo->z_alpha += -sign_alpha * Ts;   // 积分器更新       smo->z_beta  += -sign_beta  * Ts;    float u2_alpha = smo->k2 * smo->z_alpha;    float u2_beta  = smo->k2 * smo->z_beta;    // STA 总输出    float sta_alpha = u1_alpha + u2_alpha;    float sta_beta  = u1_beta  + u2_beta;    // 电流估计更新（电机电压方程 + STA 校正项）    float di_hat_alpha = (u_alpha / smo->L)                          - (smo->R / smo->L) * smo->i_hat_alpha                          - (1.0f / smo->L) * sta_alpha;    float di_hat_beta = (u_beta / smo->L)                         - (smo->R / smo->L) * smo->i_hat_beta                         - (1.0f / smo->L) * sta_beta;          smo->i_hat_alpha += di_hat_alpha * Ts;       smo->i_hat_beta  += di_hat_beta  * Ts;    // 反电动势 = STA 输出的等效控制（电流误差收敛后成立）    float e_hat_alpha = sta_alpha;    float e_hat_beta  = sta_beta;    // 接下来：丢给 PLL 或反正切提取角度    // pll_update(e_hat_alpha, e_hat_beta, ...);   }`

几个实现细节：

-   • `sqrtf(fabsf(err))` 在误差为零时导数无穷大？不，，没问题。但接近零时浮点精度要考虑。
    
-   • 积分器 `z_alpha` 没有显式的抗饱和。如果 `k2` 太大或 `Ts` 太大，积分器会 windup。建议加一个简单的限幅：`|z| < Z_MAX`。
    
-   • 这里的 `e_hat_alpha = sta_alpha`、`e_hat_beta = sta_beta` 是连续域的理论结果。离散实现中，如果 `Ts` 不够小，`e_hat` 上仍会有残余高频。可以选接一个轻量级 LPF（比如一阶 IIR，截止频率 5~10 kHz）做最后收尾，但不是必须的。
    

## 一句话总结

STO 不是给 `sign` 函数包软壳，而是把开关逻辑从"一档"升级成"两档联动"：快速收敛档负责动态，积分记忆档负责稳态。输出天然连续，LPF 不是消失而是被内置了。代价是多一个调参旋钮，以及离散实现时收敛条件会打折。

🔧 **调试 Checklist**

\[ \] 确认开关频率足够高（建议 ≥10 kHz），否则离散化会吃掉 STO 的优势  
\[ \] 先用 Levant 条件算出 / 的理论下限，再实验扫描  
\[ \] 调参顺序：先固定  扫 （找动态甜点），再固定  扫 （找稳态精度）  
\[ \] 给 `k2` 的积分器加限幅（`Z_MAX`），防止 windup  
\[ \] 低速段（<10% 额定转速）不要指望 STO 解决信噪比问题，该切换 HFI 就切换  
\[ \] 示波器对比：经典 SMO+LPF vs STO 无 LPF，重点看动态负载时的角度 lag
