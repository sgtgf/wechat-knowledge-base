# 做并行计算需要哪些计算机知识？


> 原文地址: [https://mp.weixin.qq.com/s/9W2u8boLR0QmotoORXiD\_Q](https://mp.weixin.qq.com/s/9W2u8boLR0QmotoORXiD_Q)

## 

# 提问

我是数学背景的，想做并行计算。请问只学MPI，OpenMP，CUDA这些并行工具是否足够了？是否需要补充一些计算机硬件方面的知识？如果需要，能否推荐一些好的入门的书籍？

# 一己之见，欢迎拍砖

数学专业出身，如果想从事并行计算领域，除了扎实的数学基础，确实需要补充一些计算机相关的知识。以下是几个关键领域的概述，这些是在并行计算中经常会用到的：

1.  **编程语言**：熟练掌握至少一种广泛应用于并行计算的编程语言，如C/C++、Fortran或者Python。对于并行编程，了解特定的并行编程模型和库也很重要，比如OpenMP、MPI（Message Passing Interface）、Pthread，以及GPU编程的CUDA或OpenCL。
    
2.  **算法与数据结构**：理解基本的算法和数据结构对于优化并行程序的效率至关重要。并行算法的设计往往需要对传统算法进行改造，以适应并行环境，减少通信开销，提高并行效率。
    
3.  **计算机体系结构**：熟悉CPU、GPU等处理器的基本架构，了解它们的工作原理、内存层次结构、缓存机制等，这对于优化并行代码和避免常见的性能瓶颈非常重要。
    
4.  **操作系统**：操作系统如何管理进程和线程、内存分配、I/O操作等，对并行计算有直接影响。理解这些概念有助于设计更高效的并行程序。
    
5.  **计算机网络**：对于分布式并行计算，理解计算机网络的基本原理，包括网络拓扑、协议（如TCP/IP）和数据传输机制，是必要的。
    
6.  **并行计算模型和理论**：掌握并行计算的基本概念，如任务并行、数据并行、Amdahl定律、Gustafson定律等，理解并行算法的性能评估方法。
    
7.  **性能优化与调试**：学习如何使用工具（如gprof, VTune, NVidia Nsight等）进行性能分析和调试，识别并解决并行程序中的负载不平衡、数据竞争等问题。
    
8.  **硬件知识**：虽然不需要成为硬件专家，但了解硬件基础对于优化程序至关重要。例如，了解不同GPU架构（如NVIDIA的Turing、Pascal架构）的特点，可以帮助设计更高效的并行算法。
    

综上所述，数学专业的学生转向并行计算时，不仅需要补充软件层面的知识，如编程语言、算法设计等，还需要对计算机硬件有一定的了解，以便更好地利用现代计算资源进行高效并行计算。
