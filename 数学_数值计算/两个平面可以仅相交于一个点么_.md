# 两个平面可以仅相交于一个点么？


> 原文地址: [https://mp.weixin.qq.com/s/4c7AJvbPwsnqDCNhS5Qq7A](https://mp.weixin.qq.com/s/4c7AJvbPwsnqDCNhS5Qq7A)

有些爬行动物（如蚯蚓）缺乏三维感知的能力。如果地面上放一个摊鸡蛋，蚯蚓若想吃到蛋黄，必须先啃掉周围的蛋清，然后才能品尝到蛋黄（图1）。

图1.蚯蚓吃蛋图。蚯蚓若想吃摊鸡蛋的蛋黄，必须先啃掉蛋清，然后才能品尝蛋黄

然而，蚯蚓万万没有想到，居然有像人类这样的高级生物，能在不破坏蛋清的前提下，轻松将蛋黄抠出来（图2）！ 

![已生成图片](https://mmbiz.qpic.cn/mmbiz_jpg/tbsNyKAwjm6atbJrBkQOwVeMGJoTwjqhB3MJso8cPzibxkES0NWcfwvKhJRf3413QDQVicg9VoTyjrlhxJ0q9rSA/640?wx_fmt=jpeg&from=appmsg)

图2. 人类抠蛋图。人类若想吃摊鸡蛋的蛋黄，不用破坏蛋清，直接抠掉蛋黄即可

然而，对于人类而言，若想吃煮鸡蛋的蛋黄，必须先剥去蛋壳，再将蛋清剥掉或吃掉，才能品尝蛋黄（图3）。那么，是否存在一种更高级的生物，它们能在不破坏蛋壳和蛋清的情况下，直接取出蛋黄呢？

用数学语言描述上面的问题，实际上是在问：一根直线能否穿过一个球体，且与球体只相交于一点？也相当于在问：两个平面是否可以仅相交于一点？

![](https://mmbiz.qpic.cn/mmbiz_jpg/tbsNyKAwjm6atbJrBkQOwVeMGJoTwjqheoZc1KJCmZ0BSG2eSNjh0WxeYf4gmfAucBbJPaX8dLohPyKiaJTv4kg/640?wx_fmt=jpeg&from=appmsg)

图3\. 人类幼崽剥蛋图。人类若想吃煮鸡蛋的蛋黄，必须先剥掉蛋壳和蛋清，然后才能取出蛋黄

上述问题也是我在中科院大学给研究生讲授《数据处理中的矩阵方法》课程时，提出的第一个课堂问题。几乎所有的同学都在这个问题上碰壁，未能给出正确的解答。他们大多理所当然地认为，两个平面必然相交于一条直线，怎么可能只交于一个点呢？

事实上，这个问题的答案是：两个平面确实可以仅相交于一点，只不过这种情况发生在四维或更高维的空间，而非三维空间。接下来，我们给出这个问题的代数解释。

我们知道，平面上两个变量，两个方程的线性方程组可以表示为

![](https://mmbiz.qpic.cn/mmbiz_png/tbsNyKAwjm6atbJrBkQOwVeMGJoTwjqhrbczwXGxYe9SREicwQ2AicNOrkT0nM2eXb8pibwBSnKibzDhgvMEK50xbQ/640?wx_fmt=png&from=appmsg)

该线性方程组的每个方程都代表平面上的一条直线。在系数矩阵非奇异的情况下，该方程组存在唯一解。这个方程组描述的几何现象（线性方程组的行空间图像）就是：平面上的两条直线（红色方程对应的直线和绿色方程对应的直线）相交于一个点。

同理，三维空间中三个变量，三个方程的线性方程组可以表示为

![](https://mmbiz.qpic.cn/mmbiz_png/tbsNyKAwjm6atbJrBkQOwVeMGJoTwjqhN82iael13pJDLbYIPGicNohwFjxyPnym1p7RLpl9ykoVOqTpyL7IX86w/640?wx_fmt=png&from=appmsg)

其中，该方程组中的每一个方程均代表三维空间中的一个二维平面。在系数矩阵非奇异的情况下，该方程组存在唯一解。并且，我们知道三维空间中两个平面可以相交于一条直线。因此，这个方程组的行空间图像就是：三维空间中的一条直线（两个红色方程决定的直线）和一个平面（绿色方程对应的平面）可以相交于一个点。

我们继续将方程组（2）拓展到四维空间，可以得到四维空间中四个变量，四个方程的线性方程组为

![](https://mmbiz.qpic.cn/mmbiz_png/tbsNyKAwjm6atbJrBkQOwVeMGJoTwjqhyfN6xJKialm2q3rn1wJfCj1m37SSMUqnGuC5kAWbEvOEiaQRZ30kmW8Q/640?wx_fmt=png&from=appmsg)

其中，该方程组中的每一个方程均代表四维空间中的一个三维超平面。我们知道，四维空间中两个三维超平面可以相交于一个二维平面。因此，在系数矩阵非奇异的情况下，方程组（3）中两个红色方程可以决定一个四维空间中的二维平面，而两个绿色方程则可以决定四维空间中的另外一个二维平面。由于系数矩阵非奇异，线性方程组（3）必定存在唯一解，而这个解正是上述两个二维平面的交点（图4）。

![](https://mmbiz.qpic.cn/mmbiz_gif/tbsNyKAwjm6atbJrBkQOwVeMGJoTwjqhh4h8SkSUqe9tv33v8pRibIboRicCCzGEnn0ks38OObAcLnHSUFT5yCEA/640?wx_fmt=gif&from=appmsg)

图4. 四维空间中相交于一个点的两个平面：由于我们无法直接观测到四维空间，因此上述动画给出了四维空间中相交于一点的两个平面在几个不同角度的投影

至此，我们从线性方程组的角度，严格推导出：四维空间中，两个平面可以仅相交于一个点！

总结而言，大多数同学之所以未能给出上述问题的正确答案，根本原因在于我们生活在三维空间，思考问题时自然受到三维认知的局限。这就像蚯蚓缺乏三维感知能力一样，我们眼中的世界是否也像它们一样，无法触及某些更高维度的真相呢？是否在某种高级智慧的眼中，人类也不过是局限于三维空间的“蚯蚓”呢？
