# 概述

## 一、本节内容

这一节其实只做了一件事：把“**向量函数**”这个数学概念，和“**电场**”这个物理对象连起来。主线是：

**电荷分布 → 产生电场 → 电场决定受力**

所以你看到的图，不是在单独画几何图，而是在训练你形成一种统一视角：

**空间中每一点，都可以对应一个箭头。**这个箭头可能表示速度、力、电场，统统都属于“向量场”。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/sVzeakRooctXPE7wvQ2DiafuleD7oMKEoX4c8S5ju9LQlPT30Xk3HWuicQ0gJouO1zFMHIVyuuLFXMeoDwsJUCN0YLfhdLWP5ibfn2qLID0N8k/640?wx_fmt=png&from=appmsg)

本节课用**静电学**做背景，带你进入**向量函数、库仑定律、电场、叠加原理、连续电荷分布**这些核心概念。它的写法不是先堆抽象定义，而是先问一个物理问题：**已知电荷如何分布，怎样求出空间中的电场？** 整章都围绕这个主线展开。

如果按内容脉络来抓重点，可以分成两段。前半段先解释“标量函数”和“向量函数”的区别：标量函数给每个点一个数，向量函数给每个点一个向量。后半段把这个思想立刻应用到静电学里：先给出库仑定律，再定义电场，然后推广到多电荷叠加，最后再过渡到连续电荷密度与体积分表达式。

### 图 1（Figure I-1）：什么叫“向量函数”

这张图画的是一个三维空间中的**向量场**：在很多空间点上都画了一支箭头，表示“每个点都对应一个向量”。借这张图说明，向量函数不是只给出一个方向，而是在整个空间里，**每一点都有自己的方向和大小**。箭头方向表示该点的方向信息，箭头长度表示大小。

从图形直观看，这个场在左侧较平行，往右逐渐展开、分叉，说明不同位置的向量不一样。想让你先建立一个几何直觉：**向量函数 = 空间里的“箭头分布图”**。这一步很关键，因为后面电场图像、流体速度场、引力场，本质上都能这样理解。

### 图 2（Figure I-2）：向量如何分解成分量
