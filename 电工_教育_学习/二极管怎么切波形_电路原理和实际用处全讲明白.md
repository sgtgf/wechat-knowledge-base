# 二极管怎么切波形？电路原理和实际用处全讲明白

最近学电路设计，发现二极管不仅能导电，还能切信号波形。限幅电路就是用二极管把电压控制在一定范围内，不破坏其他部分。这种电路简单但作用大，常见于电源保护、信号处理这些地方。

比如你要处理一个交流信号，但不要某部分电压。这时候二极管串在线路上，电压超过某个值就导通，把超出的那部分截断。正半周和负半周能分别处理，全靠二极管方向和接法不同。

![](D:\电脑文件\公众号知识库\电工_教育_学习\二极管怎么切波形_电路原理和实际用处全讲明白_images\img_002_8e84a57f5c8f.jpg)

串联限幅是最基础的。比如正限幅电路，二极管和负载串联。当正半周电压高了，二极管导通，但这时候反而没电流流过负载了。负半周电压低时二极管不导通，信号正常通过。加上电池能调节限幅起点，比如正偏差时，输入电压比电池电压高才会被截断。

![](D:\电脑文件\公众号知识库\电工_教育_学习\二极管怎么切波形_电路原理和实际用处全讲明白_images\img_003_b9bf00f70049.jpg)

并联限幅则是二极管并联在输出两端。正半周电压过高，二极管导通分流，让输出电压不超过设定值。负半周同样道理，反向并联的二极管起作用。带电池偏置时，能精确控制截断的电压位置。

![](D:\电脑文件\公众号知识库\电工_教育_学习\二极管怎么切波形_电路原理和实际用处全讲明白_images\img_004_4966e0334d7d.jpg)

要是想同时处理正负两半周，就得用双二极管加电池。两个二极管分别监控正负方向，超过各自的阈值电压就导通。这样信号被夹在两个设定值之间，不会超限。比如电源里常用这种电路防止电压波动太大。

![](D:\电脑文件\公众号知识库\电工_教育_学习\二极管怎么切波形_电路原理和实际用处全讲明白_images\img_005_f5ff5da62297.jpg)

齐纳二极管能反向导通，自带固定钳位电压。单个齐纳接在输出端，超过电压就泄放，这样正半周正常走，负半周被限到0.7V左右。要是接两个齐纳反向并联，就能双向限幅，正负都截断，适合需要严格控制信号范围的场合。

![](D:\电脑文件\公众号知识库\电工_教育_学习\二极管怎么切波形_电路原理和实际用处全讲明白_images\img_006_aa4f86e2bdcc.jpg)

实际应用中，这种电路用在好多地方。家里充电器里的过压保护，电台发射机滤除噪声，还有电视信号处理都会用到。有些设备还能生成方波或三角波，全靠限幅电路把信号整形。

![](D:\电脑文件\公众号知识库\电工_教育_学习\二极管怎么切波形_电路原理和实际用处全讲明白_images\img_007_a4fa8ea680f5.jpg)

工厂里机器供电系统，限幅电路能挡住瞬间高压，保护后面元件不烧坏。新能源车的电池管理系统，也是用这类电路监测电压是否超限。深海探测仪器这些极端环境，更需要可靠的限幅来维持电路稳定。

![](D:\电脑文件\公众号知识库\电工_教育_学习\二极管怎么切波形_电路原理和实际用处全讲明白_images\img_008_d0ea12c7aee9.jpg)

二极管限幅听起来复杂，其实就是开关元件配合电池调整阈值。自己动手做实验时，记得先算好电压值，别选错二极管型号。要是信号幅度频繁变化，还得考虑二极管导通后的压降影响。
