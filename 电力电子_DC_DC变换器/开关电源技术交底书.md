## 第一章 开关电源概述

### 1.1 开关电源的定义与核心本质

开关电源（Switching Mode Power Supply，SMPS）是一种利用电力电子开关器件（如 MOSFET、IGBT、二极管等）的高频通断特性，通过控制开关导通时间的占空比来调节输出电压 / 电流，实现电能变换与传输的电力电子装置。其核心本质是**电能的高频斩波 - 隔离 / 变换 - 滤波重构**，区别于线性电源通过串联调整管的线性压降来调节输出的工作模式，开关电源中的开关器件始终工作在饱和导通或截止的开关状态，理论上自身功耗极低，这是其高效率的根本原因。

开关电源的电能变换过程可概括为：原始输入电能（通常为工频交流电或直流电）→ 整流滤波为高压直流电 → 高频逆变电路将直流电逆变为几十 kHz 至几 MHz 的高频交流电 → 高频变压器实现电压变换与电气隔离 → 输出整流滤波将高频交流电还原为稳定的直流电 → 控制电路实时采样输出信号并反馈调节开关占空比，形成闭环控制。

### 1.3 开关电源的分类

开关电源的分类方式多样，不同分类维度对应不同的应用场景和技术特点，核心分类如下：

1.  **按电能变换类型分类**

-   AC-DC 开关电源：将工频交流电转换为直流电，又称整流器，是最常见的类型，广泛应用于消费电子、工业设备等领域。
    
-   DC-DC 开关电源：将一种直流电压转换为另一种直流电压，可实现升压、降压、反相或隔离变换，常用于板级电源、电池供电设备。
    
-   DC-AC 开关电源：将直流电转换为交流电，又称逆变器，应用于 UPS、光伏并网、电机驱动等领域。
    
-   AC-AC 开关电源：直接对交流电进行电压、频率变换，又称变频器，主要用于电机调速、变频电源。
    

3.  **按是否电气隔离分类**

-   隔离型开关电源：输入与输出之间通过高频变压器实现电气隔离，安全性高，适用于高压输入、人体接触的设备。
    
-   非隔离型开关电源：输入与输出共地，电路简单、效率高、成本低，适用于低压、安全电压范围内的板级供电。
    

5.  **按控制方式分类**

-   脉冲宽度调制（PWM）：开关频率固定，通过调节导通时间占空比调节输出，是目前应用最广泛的控制方式。
    
-   脉冲频率调制（PFM）：导通时间固定，通过调节开关频率调节输出，轻载时效率高，适用于电池供电设备。
    
-   混合调制（PWM+PFM）：重载时采用 PWM，轻载时切换为 PFM，兼顾全负载范围的效率。
    

7.  **按功率等级分类**

-   小功率开关电源：≤100W，应用于手机充电器、小家电、笔记本电脑适配器。
    
-   中功率开关电源：100W~1kW，应用于台式电脑电源、工业控制电源、通信基站电源。
    
-   大功率开关电源：1kW~100kW，应用于电动汽车充电桩、工业直流电源、光伏逆变器。
    
-   超大功率开关电源：≥100kW，应用于电网储能、轨道交通、冶金电解等领域。
    

### 1.4 开关电源的发展历程与技术趋势

开关电源技术的发展与电力电子器件、磁性材料、控制技术的进步密切相关，大致经历了四个阶段：

1.  **萌芽阶段（1950s-1960s）**
    
    ：以晶闸管为核心的开关电源问世，主要应用于工业领域，开关频率仅为几十 Hz 至几百 Hz，体积大、效率低。
    
2.  **普及阶段（1970s-1980s）**
    
    ：双极型晶体管（BJT）和功率 MOSFET 的出现，将开关频率提升至几十 kHz，开关电源开始在消费电子领域普及，反激、正激等经典拓扑得到广泛应用。
    
3.  **成熟阶段（1990s-2010s）**
    
    ：IGBT、超快恢复二极管、软开关技术的发展，进一步提高了开关频率和效率，LLC 谐振、移相全桥等高效拓扑成为中大功率电源的主流，数字化控制技术开始应用。
    
4.  **革新阶段（2010s 至今）**
    
    ：宽禁带半导体器件（GaN 氮化镓、SiC 碳化硅）的商业化应用，将开关频率提升至 MHz 级，实现了更高的效率和功率密度；数字电源技术日趋成熟，支持远程监控、智能保护和自适应调节；同时，绿色节能、高可靠性、小型化成为行业发展的核心方向。
    

当前开关电源的核心技术趋势可概括为：**高频化、高效率、高功率密度、数字化、智能化、绿色化**。其中，GaN 和 SiC 器件的应用是实现高频化和高效率的关键，数字控制技术则为智能化提供了基础，而全球对节能减排的要求推动了电源效率标准的不断升级（如欧盟 CoC V5、美国 ENERGY STAR 8.0）。

### 1.5 开关电源的主要技术指标

开关电源的技术指标是衡量其性能优劣的核心依据，也是设计、生产和验收的关键标准，主要分为电气性能指标、安全性能指标、电磁兼容指标和可靠性指标四大类。

1.  **电气性能指标**

-   输入电压范围：电源正常工作的输入电压区间，如 AC 85~265V（全球通用）、DC 12~24V。
    
-   输出电压 / 电流范围：额定输出电压及允许的输出电流范围，包括额定输出、最大输出和最小输出。
    
-   电压精度：实际输出电压与标称输出电压的偏差，通常为 ±1%~±5%。
    
-   负载调整率：输出电流从空载变化到额定负载时，输出电压的相对变化率，反映电源带载能力，通常≤±1%。
    
-   线性调整率：输入电压在额定范围内变化时，输出电压的相对变化率，反映电源对输入电压波动的抑制能力，通常≤±0.5%。
    
-   效率：输出功率与输入功率的比值，是衡量电源节能性能的核心指标，不同功率等级的电源效率要求不同。
    
-   纹波与噪声：输出直流电压中叠加的高频交流分量，通常用峰峰值表示，单位为 mV，纹波越小，电源质量越高。
    
-   动态响应：输出负载突变时，输出电压恢复到稳定值所需的时间和电压过冲 / 下冲幅度，反映电源的瞬态响应能力。
    

3.  **安全性能指标**

-   绝缘电阻：输入与输出、输入与外壳、输出与外壳之间的电阻值，通常≥100MΩ。
    
-   抗电强度：输入与输出、输入与外壳之间能承受的最高交流电压，持续 1 分钟无击穿、无飞弧，如 AC 3000V/1min。
    
-   漏电流：电源正常工作时，通过绝缘介质流向大地的电流，通常≤0.75mA（人体接触设备）。
    
-   保护功能：包括过压保护（OVP）、过流保护（OCP）、过温保护（OTP）、短路保护（SCP）、欠压保护（UVP）等。
    

5.  **电磁兼容指标**

-   电磁干扰（EMI）：电源向外界辐射或传导的电磁能量，需符合 IEC 61000-6-3、GB/T 17626 系列标准。
    
-   电磁抗扰度（EMS）：电源抵抗外界电磁干扰的能力，包括静电放电、电快速瞬变脉冲群、浪涌、射频场感应等。
    

7.  **可靠性指标**

-   平均无故障时间（MTBF）：电源在规定条件下连续正常工作的平均时间，通常≥100000 小时。
    
-   工作温度范围：电源正常工作的环境温度区间，如 - 20℃~+60℃。
    
-   存储温度范围：电源存储的环境温度区间，如 - 40℃~+85℃。
    
-   振动与冲击：电源能承受的振动和冲击强度，符合 GB/T 2423 系列标准。

## 第二章 开关电源核心原理与拓扑结构

### 2.1 开关电源基本工作原理

开关电源的核心是通过高频开关的通断来控制电能的传输，其基本工作原理可通过最简单的 Buck 降压变换器来理解。Buck 变换器由开关管 S、续流二极管 D、电感 L、电容 C 和负载 R 组成。当开关管 S 导通时，输入电压 Vin 加在电感 L 上，电感电流线性上升，电能以磁场能的形式存储在电感中，同时电容 C 充电，向负载 R 供电；当开关管 S 截止时，电感 L 通过续流二极管 D 释放磁场能，维持负载电流，电容 C 继续放电，保持输出电压稳定。通过控制开关管 S 的导通时间 Ton 和截止时间 Toff，即可调节输出电压 Vout=Vin×Ton/(Ton+Toff)=Vin×D，其中 D 为占空比（0<D<1）。

对于隔离型开关电源，其工作原理与非隔离型类似，只是在逆变环节加入了高频变压器，将原边的高频交流电耦合到副边，实现电压变换和电气隔离。原边开关管的通断控制原边电流，进而控制副边感应电压的大小，副边经过整流滤波后得到稳定的直流输出。

### 2.2 非隔离型 DC-DC 变换器拓扑

非隔离型 DC-DC 变换器是开关电源的基础拓扑，电路结构简单、效率高、成本低，广泛应用于板级电源、电池供电设备等低压场景。核心拓扑包括 Buck、Boost、Buck-Boost、Cuk、Sepic 和 Zeta 六种，其中前三种是最基本的拓扑，后三种是其衍生拓扑。

#### 2.2.1 Buck 降压变换器

Buck 变换器是最常用的降压拓扑，输出电压低于输入电压，输出电流连续，纹波较小。

1.  **工作原理**
    
    ：如前所述，分为开关导通和开关截止两个阶段。当开关导通时，电感电流上升；开关截止时，电感电流通过续流二极管续流。
    
2.  **关键波形**
    
    ：开关管漏源电压 Vds、电感电流 IL、输出电压 Vout 的波形。开关导通时 Vds≈0，IL 线性上升；开关截止时 Vds≈Vin，IL 线性下降。
    
3.  **工作模式**
    
    ：分为连续导通模式（CCM）、断续导通模式（DCM）和临界导通模式（BCM）。CCM 模式下电感电流始终大于 0，输出纹波小，适用于重载；DCM 模式下电感电流在开关截止期间会降到 0，轻载时效率高，但输出纹波大；BCM 模式是 CCM 和 DCM 的临界点，电感电流刚好降到 0 时开关再次导通。
    
4.  **关键参数计算**

-   输出电压：Vout=Vin×D（CCM 模式）
    
-   电感值：L=(Vin-Vout)×D/(f×ΔIL)，其中 f 为开关频率，ΔIL 为电感电流纹波，通常取额定输出电流的 20%~40%。
    
-   输出电容值：C=ΔIL/(8×f×ΔVout)，其中 ΔVout 为输出电压纹波。
    

6.  **优缺点与适用场景**
    
    ：优点是电路简单、效率高、输出纹波小、动态响应快；缺点是只能降压，输入输出共地。适用于输入电压高于输出电压的低压大电流场景，如 CPU 供电、5V/12V 板级电源。
    

#### 2.2.2 Boost 升压变换器

Boost 变换器是最常用的升压拓扑，输出电压高于输入电压，输入电流连续，纹波较小。

1.  **工作原理**
    
    ：当开关管 S 导通时，输入电压 Vin 加在电感 L 上，电感电流上升，存储磁场能，此时二极管 D 截止，输出电容 C 向负载供电；当开关管 S 截止时，电感 L 产生感应电动势，与输入电压 Vin 叠加，通过二极管 D 向输出电容 C 和负载供电，输出电压高于输入电压。
    
2.  **关键波形**
    
    ：开关管漏源电压 Vds、电感电流 IL、输出电压 Vout 的波形。开关导通时 Vds≈0，IL 线性上升；开关截止时 Vds≈Vout，IL 线性下降。
    
3.  **工作模式**
    
    ：同样分为 CCM、DCM 和 BCM 模式。CCM 模式下输出电压 Vout=Vin/(1-D)，DCM 模式下输出电压与负载电流有关。
    
4.  **关键参数计算**

-   输出电压：Vout=Vin/(1-D)（CCM 模式）
    
-   电感值：L=Vin×D/(f×ΔIL)
    
-   输出电容值：C=Iout×D/(f×ΔVout)
    

6.  **优缺点与适用场景**
    
    ：优点是输入电流连续、EMI 小、电路简单；缺点是只能升压，输入输出共地，开关管承受的电压应力等于输出电压。适用于输入电压低于输出电压的场景，如电池升压电路、光伏 MPPT 电路。
    

#### 2.2.3 Buck-Boost 升降压变换器

Buck-Boost 变换器既能实现降压，也能实现升压，输出电压极性与输入电压相反。

1.  **工作原理**
    
    ：当开关管 S 导通时，输入电压 Vin 加在电感 L 上，电感电流上升，存储磁场能，二极管 D 截止，输出电容 C 向负载供电；当开关管 S 截止时，电感 L 释放磁场能，通过二极管 D 向输出电容 C 和负载供电，输出电压极性与输入相反。
    
2.  **关键波形**
    
    ：开关管漏源电压 Vds、电感电流 IL、输出电压 Vout 的波形。开关导通时 Vds≈0，IL 线性上升；开关截止时 Vds≈Vin+|Vout|，IL 线性下降。
    
3.  **工作模式**
    
    ：CCM 模式下输出电压 | Vout|=Vin×D/(1-D)，当 D<0.5 时降压，D>0.5 时升压。
    
4.  **优缺点与适用场景**
    
    ：优点是既能升压也能降压，电路简单；缺点是输出电压反相，开关管和二极管承受的电压应力等于输入电压加输出电压，效率较低。适用于输入电压波动范围大，需要升降压的场景，如电池供电设备、车载电源。
    

#### 2.2.4 其他非隔离型拓扑

-   **Cuk 变换器**
    
    ：输出电压极性与输入相反，输入输出电流均连续，纹波小，适用于对纹波要求高的升降压场景，但电路复杂度较高，需要两个电感和一个电容。
    
-   **Sepic 变换器**
    
    ：输出电压极性与输入相同，既能升压也能降压，输入电流连续，适用于电池供电的升降压场景，如 LED 驱动电源。
    
-   **Zeta 变换器**
    
    ：输出电压极性与输入相同，输出电流连续，纹波小，适用于低压大电流的升降压场景。
    

### 2.3 隔离型 DC-DC 变换器拓扑

隔离型 DC-DC 变换器通过高频变压器实现输入与输出的电气隔离，安全性高，适用于高压输入、人体接触的设备，以及需要多路输出的场景。核心拓扑包括反激、正激、半桥、全桥和推挽五种，其中反激拓扑在小功率领域应用最广泛，半桥和全桥拓扑在中大功率领域占主导地位。

#### 2.3.1 反激变换器

反激变换器是小功率隔离型开关电源的首选拓扑，功率范围通常为 1W~150W，电路结构简单、成本低、元器件少，可方便实现多路输出。

1.  **工作原理**
    
    ：反激变换器的高频变压器既是储能元件，也是隔离变压元件。当原边开关管 S 导通时，原边绕组有电流流过，变压器存储磁场能，此时副边绕组的感应电压极性使二极管 D 截止，输出电容 C 向负载供电；当开关管 S 截止时，原边电流中断，变压器释放磁场能，副边绕组感应电压极性反转，二极管 D 导通，变压器存储的能量通过副边绕组传输到输出端，向负载供电并给电容 C 充电。
    
2.  **工作模式**
    
    ：分为连续导通模式（CCM）、断续导通模式（DCM）和临界导通模式（BCM）。
    

-   DCM 模式：原边电流在开关截止期间完全降到 0，变压器能量全部释放到副边，输出电压与负载电流无关，仅与占空比和匝数比有关，控制简单，适用于小功率、轻载场景。
    
-   CCM 模式：原边电流在开关截止期间不会降到 0，变压器始终存储部分能量，输出纹波小，适用于中大功率、重载场景，但存在副边二极管反向恢复问题，EMI 较大。
    

4.  **关键参数计算**

-   匝数比：n=Np/Ns=(Vin\_min×D\_max)/(Vout+Vf)×(1-η)，其中 Vin\_min 为最小输入电压，D\_max 为最大占空比，Vf 为副边二极管正向压降，η 为效率。
    
-   原边电感量：Lp=(Vin\_min²×D\_max²)/(2×f×Pout/η)（DCM 模式）
    
-   变压器磁芯气隙：反激变压器需要加气隙来防止磁芯饱和，气隙大小根据磁芯材料、最大磁通密度和电感量计算。
    

6.  **优缺点与适用场景**
    
    ：优点是电路简单、成本低、元器件少、可多路输出、无需输出电感；缺点是变压器利用率低、开关管电流应力大、输出纹波大、效率较低。适用于 150W 以下的小功率场景，如手机充电器、小家电电源、笔记本电脑适配器。
    

#### 2.3.2 正激变换器

正激变换器的功率范围通常为 50W~500W，变压器仅起隔离变压作用，能量通过变压器直接传输，效率高于反激变换器。

1.  **工作原理**
    
    ：当原边开关管 S 导通时，原边绕组有电流流过，变压器副边绕组感应电压使二极管 D1 导通，向负载供电并给输出电感 L 和电容 C 充电，同时变压器存储磁场能；当开关管 S 截止时，原边电流中断，变压器通过复位绕组释放磁场能，副边二极管 D1 截止，输出电感 L 通过续流二极管 D2 向负载供电。
    
2.  **关键特点**
    
    ：正激变换器必须设置变压器复位电路，否则开关管截止时变压器会因磁芯饱和而损坏。常见的复位方式有：复位绕组复位、RCD 钳位复位、有源钳位复位。其中有源钳位复位效率最高，适用于中大功率场景。
    
3.  **优缺点与适用场景**
    
    ：优点是变压器利用率高、输出纹波小、效率高、开关管电流应力小；缺点是电路比反激复杂，需要输出电感和变压器复位电路。适用于 50W~500W 的中功率场景，如台式电脑电源、工业控制电源。
    

#### 2.3.3 半桥变换器

半桥变换器的功率范围通常为 200W~2kW，采用两个开关管串联，开关管承受的电压应力等于输入电压，适用于高压输入的中大功率场景。

1.  **工作原理**
    
    ：半桥变换器由两个开关管 S1、S2 和两个分压电容 C1、C2 组成桥臂，高频变压器原边绕组接在桥臂中点。S1 和 S2 交替导通，导通时间各小于半个周期，变压器原边得到正负交替的方波电压，副边经过整流滤波后得到直流输出。
    
2.  **关键特点**
    
    ：半桥变换器具有自动平衡变压器直流偏磁的能力，不会出现磁芯饱和问题；开关管承受的电压应力等于输入电压，适用于高压输入（如 AC 220V 整流后的 310V 直流）。
    
3.  **衍生拓扑**
    
    ：LLC 谐振半桥变换器是目前中大功率电源的主流拓扑，利用变压器漏感和励磁电感与谐振电容发生谐振，实现开关管的零电压开通（ZVS）和副边二极管的零电流关断（ZCS），开关损耗极低，效率可达 95% 以上，广泛应用于服务器电源、LED 驱动电源、电动汽车车载充电机。
    

#### 2.3.4 全桥变换器

全桥变换器的功率范围通常为 1kW~100kW，采用四个开关管组成全桥，变压器原边得到正负对称的方波电压，功率传输能力强，适用于大功率场景。

1.  **工作原理**
    
    ：四个开关管 S1、S4 和 S2、S3 交替导通，变压器原边得到正负交替的方波电压，副边经过整流滤波后得到直流输出。通过调节开关管的导通相位差，可以调节输出电压的大小，即移相控制。
    
2.  **关键特点**
    
    ：移相全桥变换器可以实现开关管的零电压开通（ZVS），开关损耗小，效率高；变压器利用率高，功率密度大。
    
3.  **优缺点与适用场景**
    
    ：优点是功率传输能力强、开关管电压应力低、效率高、输出纹波小；缺点是电路复杂、控制难度大、成本高。适用于 1kW 以上的大功率场景，如电动汽车充电桩、工业直流电源、光伏逆变器。
    

#### 2.3.5 推挽变换器

推挽变换器的功率范围通常为 100W~10kW，采用两个开关管并联，变压器原边有两个中心抽头绕组，适用于低压输入的中大功率场景。

1.  **工作原理**
    
    ：两个开关管 S1 和 S2 交替导通，变压器原边两个绕组交替工作，副边得到正负交替的方波电压，经过整流滤波后得到直流输出。
    
2.  **关键特点**
    
    ：推挽变换器的开关管承受的电压应力等于 2 倍输入电压，适用于低压输入（如 24V、48V 直流）；变压器利用率高，输出功率大。
    
3.  **优缺点与适用场景**
    
    ：优点是电路简单、驱动电路简单、输出功率大、效率高；缺点是开关管电压应力高，容易出现直流偏磁问题。适用于低压输入的中大功率场景，如通信基站电源、车载电源。
    

### 2.4 拓扑结构选型原则

开关电源拓扑结构的选型直接影响电源的性能、成本和可靠性，选型时需综合考虑以下因素：

1.  **功率等级**
    
    ：小功率（≤150W）优先选择反激拓扑；中功率（50W~500W）可选择正激或半桥拓扑；大功率（≥1kW）优先选择全桥或推挽拓扑。
    
2.  **输入输出电压**
    
    ：输入电压高（如 AC 220V）优先选择半桥或全桥拓扑；输入电压低（如 DC 12V/24V）优先选择推挽拓扑；需要升降压时选择 Buck-Boost、Sepic 或反激拓扑。
    
3.  **隔离要求**
    
    ：需要电气隔离时选择隔离型拓扑；不需要隔离时优先选择非隔离型拓扑，以提高效率、降低成本。
    
4.  **输出路数**
    
    ：多路输出优先选择反激拓扑，可通过增加副边绕组方便实现多路输出。
    
5.  **效率要求**
    
    ：对效率要求高时选择 LLC 谐振、移相全桥等软开关拓扑；轻载效率要求高时选择 PFM 控制或混合调制方式。
    
6.  **成本要求**
    
    ：小功率场景优先选择反激拓扑，成本最低；中大功率场景在满足性能要求的前提下，选择电路结构简单、元器件少的拓扑。

## 第三章 开关电源关键元器件选型与特性

开关电源的性能和可靠性在很大程度上取决于关键元器件的选型，不同元器件的特性差异会直接影响电源的效率、纹波、EMI 和使用寿命。本章将详细介绍开关电源中核心元器件的工作原理、关键参数、选型原则和常见失效模式。

### 3.1 半导体功率器件

半导体功率器件是开关电源的核心，负责电能的变换和控制，主要包括二极管、MOSFET、IGBT 和晶闸管四大类。

#### 3.1.1 二极管

二极管在开关电源中主要用于整流、续流和钳位，根据应用场景的不同，可分为整流二极管、快恢复二极管、超快恢复二极管、肖特基二极管和碳化硅二极管。

1.  **整流二极管**
    
    ：主要用于工频整流电路，将工频交流电转换为直流电。关键参数包括：最大反向电压 VRRM、平均整流电流 IF、正向压降 VF、反向恢复时间 trr。整流二极管的反向恢复时间较长（几 μs 至几十 μs），仅适用于工频（50/60Hz）场景，不能用于高频电路。选型时，VRRM 应大于实际工作反向电压的 1.5~2 倍，IF 应大于实际工作平均电流的 1.5~2 倍。
    
2.  **快恢复二极管（FRD）**
    
    ：反向恢复时间较短（几百 ns 至 1μs），适用于几十 kHz 的高频整流和续流电路。与整流二极管相比，快恢复二极管的反向恢复电荷少，开关损耗小。
    
3.  **超快恢复二极管（UFRD）**
    
    ：反向恢复时间更短（几十 ns 至几百 ns），适用于几百 kHz 的高频电路，是中高频开关电源中最常用的续流和整流二极管。
    
4.  **肖特基二极管（SBD）**
    
    ：基于金属 - 半导体接触原理制成，正向压降极低（0.3~0.5V），反向恢复时间极短（几 ns 至几十 ns），开关损耗极小，适用于低压大电流的高频整流电路。但肖特基二极管的反向耐压较低（通常≤200V），反向漏电流较大，高温下漏电流会显著增加，选型时需注意温度降额。
    
5.  **碳化硅二极管（SiC SBD）**
    
    ：采用宽禁带半导体材料碳化硅制成，具有反向耐压高（可达 1200V 以上）、正向压降低、反向恢复时间极短（几乎为零）、耐高温等优点，开关损耗远低于硅基快恢复二极管，适用于高压、高频、高效率的开关电源，如电动汽车充电桩、光伏逆变器。
    
6.  **常见失效模式**
    
    ：过压击穿、过流烧毁、热击穿、反向恢复失效。选型时需留足电压和电流裕量，做好散热设计，避免二极管工作在反向恢复尖峰电压过高的场景。
    

#### 3.1.2 金属氧化物半导体场效应晶体管（MOSFET）

MOSFET 是目前开关电源中应用最广泛的开关器件，具有开关速度快、输入阻抗高、驱动功率小、无二次击穿问题等优点，适用于中低压、高频场景。

1.  **工作原理**
    
    ：MOSFET 是电压控制型器件，通过栅极电压控制漏源极之间的导通和截止。当栅源电压 Vgs 大于阈值电压 Vgs (th) 时，漏源极之间形成导电沟道，MOSFET 导通；当 Vgs 小于 Vgs (th) 时，导电沟道消失，MOSFET 截止。
    
2.  **关键参数**

-   漏源击穿电压 VDS：漏源极之间能承受的最大反向电压，选型时应大于实际工作漏源电压的 1.5~2 倍。
    
-   漏极连续电流 ID：MOSFET 能持续通过的最大漏极电流，选型时应大于实际工作漏极电流的 1.5~2 倍，并考虑温度降额。
    
-   导通电阻 RDS (on)：MOSFET 导通时漏源极之间的电阻，是影响导通损耗的关键参数，RDS (on) 越小，导通损耗越低。RDS (on) 随温度升高而增大，选型时需考虑高温下的阻值。
    
-   栅极电荷 Qg：驱动 MOSFET 导通所需的总栅极电荷，是影响驱动损耗和开关速度的关键参数，Qg 越小，驱动损耗越小，开关速度越快。
    
-   开关时间：包括导通时间 ton 和关断时间 toff，开关时间越短，开关损耗越小。
    
-   结温 Tj：MOSFET 芯片能承受的最高温度，通常为 150℃或 175℃，工作时结温应低于最高结温，并留足裕量。
    

4.  **选型原则**

-   电压等级：根据实际工作漏源电压选择合适的 VDS，如反激变换器中开关管的 VDS 应大于 Vin\_max+VOR（反射电压）+ 尖峰电压。
    
-   电流等级：根据实际工作漏极电流选择合适的 ID，并考虑温度降额和过载能力。
    
-   导通电阻与栅极电荷的平衡：RDS (on) 小的 MOSFET 通常 Qg 较大，导通损耗小但驱动损耗大；Qg 小的 MOSFET 通常 RDS (on) 较大，驱动损耗小但导通损耗大。选型时需根据开关频率和功率等级进行平衡，高频时优先选择 Qg 小的 MOSFET，低频大电流时优先选择 RDS (on) 小的 MOSFET。
    
-   封装形式：根据功率等级和散热要求选择合适的封装，如 TO-220、TO-247、DPAK、SO-8 等。
    

6.  **常见失效模式**
    
    ：过压击穿、过流烧毁、静电击穿、栅极过压损坏、热击穿。选型时需留足电压和电流裕量，做好静电防护和栅极保护电路，确保散热良好。
    

#### 3.1.3 绝缘栅双极型晶体管（IGBT）

IGBT 是 MOSFET 和双极型晶体管（BJT）的复合器件，结合了 MOSFET 开关速度快、驱动功率小和 BJT 导通压降低、电流密度大的优点，适用于高压、大功率、中低频场景。

1.  **工作原理**
    
    ：IGBT 是电压控制型器件，通过栅极电压控制集电极和发射极之间的导通和截止。当栅射电压 Vge 大于阈值电压 Vge (th) 时，IGBT 导通；当 Vge 小于 Vge (th) 时，IGBT 截止。
    
2.  **关键参数**

-   集射极击穿电压 VCE：集射极之间能承受的最大反向电压，通常为 600V、1200V、1700V 等。
    
-   集电极连续电流 IC：IGBT 能持续通过的最大集电极电流，选型时应大于实际工作电流的 1.5~2 倍。
    
-   饱和压降 VCE (sat)：IGBT 导通时集射极之间的电压降，是影响导通损耗的关键参数，VCE (sat) 越小，导通损耗越低。
    
-   开关时间：包括导通时间 ton 和关断时间 toff，IGBT 的开关速度比 MOSFET 慢，关断时存在拖尾电流，开关损耗较大。
    
-   结温 Tj：通常为 150℃或 175℃。
    

4.  **选型原则**
    
    ：适用于功率等级≥1kW、开关频率≤100kHz 的高压大功率场景，如电动汽车充电桩、工业直流电源、光伏逆变器。选型时需综合考虑电压、电流、导通压降和开关损耗，做好散热设计和缓冲电路设计，抑制关断过电压。
    
5.  **常见失效模式**
    
    ：过压击穿、过流烧毁、热击穿、静电击穿、关断过电压损坏。
    

#### 3.1.4 宽禁带半导体器件（GaN、SiC）

宽禁带半导体器件是新一代功率器件，与传统硅基器件相比，具有禁带宽度大、击穿电场高、电子饱和漂移速度快、热导率高等优点，可实现更高的开关频率、更高的效率和更高的功率密度。

1.  **氮化镓（GaN）器件**
    
    ：主要为 GaN HEMT（高电子迁移率晶体管），具有开关速度极快、导通电阻小、栅极电荷小等优点，开关频率可达几 MHz，效率可达 99% 以上。适用于中低压、高频、小功率场景，如手机快充、笔记本电脑适配器、服务器电源。
    
2.  **碳化硅（SiC）器件**
    
    ：包括 SiC MOSFET 和 SiC 二极管，具有反向耐压高、导通压降低、开关速度快、耐高温等优点，适用于高压、高频、大功率场景，如电动汽车充电桩、光伏逆变器、电网储能变流器。
    
3.  **选型注意事项**
    
    ：宽禁带器件的驱动电压范围较窄，对驱动电路的要求较高，需设计合适的驱动电压和栅极保护电路；开关速度快，容易产生较高的 di/dt 和 dv/dt，需优化 PCB 布局和布线，抑制 EMI 和过电压。
    

### 3.2 磁性元件

磁性元件是开关电源中实现能量存储、电压变换和电气隔离的核心元件，主要包括高频变压器、电感和磁珠，其性能直接影响电源的效率、纹波和 EMI。

#### 3.2.1 高频变压器

高频变压器是隔离型开关电源的核心磁性元件，主要作用是实现电压变换、电气隔离和能量传输。

1.  **磁芯材料**
    
    ：开关电源中常用的磁芯材料有铁氧体、铁粉芯、非晶合金和纳米晶合金。
    

-   铁氧体：最常用的磁芯材料，具有电阻率高、高频损耗小、成本低等优点，适用于几十 kHz 至几百 kHz 的频率范围。常用的铁氧体材料有 PC40、PC44、PC95 等，其中 PC95 的高频损耗更低，适用于高频场景。
    
-   铁粉芯：磁导率低、饱和磁通密度高、损耗较大，适用于低频、大电流的电感，如 PFC 电感。
    
-   非晶合金和纳米晶合金：饱和磁通密度高、损耗极低，适用于中高频、大功率的变压器和电感，如 LLC 谐振变压器、光伏逆变器变压器。
    

3.  **磁芯结构**
    
    ：常用的磁芯结构有 EE、EI、EC、ETD、PQ、RM 等。不同结构的磁芯具有不同的窗口面积、磁路长度和散热性能，选型时需根据功率等级、安装空间和散热要求选择合适的磁芯结构。例如，PQ 磁芯的窗口面积大、散热好，适用于中大功率变压器；RM 磁芯的漏磁小、EMI 性能好，适用于对 EMI 要求高的场景。
    
4.  **变压器设计要点**

-   磁芯选型：根据输出功率和开关频率选择合适的磁芯尺寸和材料，通常采用 AP 法（面积乘积法）进行磁芯选型，AP=Ae×Aw，其中 Ae 为磁芯有效截面积，Aw 为窗口面积。
    
-   匝数计算：根据输入输出电压、占空比和最大磁通密度计算原副边匝数，最大磁通密度 Bm 应小于磁芯的饱和磁通密度 Bs，并留足裕量，防止磁芯饱和。
    
-   气隙设计：反激变压器、储能电感等需要存储能量的磁性元件必须加气隙，气隙可以提高磁芯的储能能力，防止磁芯饱和。气隙大小根据电感量和最大磁通密度计算。
    
-   绕组设计：绕组的线径根据电流密度选择，通常电流密度取 3~5A/mm²，大电流时可采用多股线并绕或利兹线，以减小集肤效应和邻近效应损耗。绕组的排列方式会影响漏感和分布电容，原副边绕组采用三明治绕法可以减小漏感，提高效率。
    

6.  **常见失效模式**
    
    ：磁芯饱和、绕组短路、绝缘击穿、过热烧毁。设计时需留足磁通密度裕量，做好绕组绝缘，确保散热良好。
    

#### 3.2.2 电感

电感在开关电源中主要用于储能、滤波和限流，根据应用场景的不同，可分为储能电感、滤波电感和 PFC 电感。

1.  **储能电感**
    
    ：如 Buck、Boost 变换器中的输出电感，主要作用是存储和释放能量，维持输出电流连续。储能电感的设计要点包括：电感量计算、磁芯选型、绕组设计和气隙设计，与反激变压器类似。
    
2.  **滤波电感**
    
    ：如输入滤波电感、输出滤波电感，主要作用是抑制电流纹波。滤波电感的电感量越大，纹波抑制效果越好，但体积和成本也越高。
    
3.  **PFC 电感**
    
    ：用于功率因数校正电路，工作在工频和高频的混合频率下，需要承受较大的直流偏置电流，通常采用铁粉芯或铁硅铝磁芯，具有较高的饱和磁通密度和较低的损耗。
    
4.  **选型原则**
    
    ：根据电感量、额定电流、工作频率和损耗要求选择合适的磁芯材料和结构，确保电感在额定电流下不饱和，损耗在允许范围内。
    

#### 3.2.3 磁珠

磁珠是一种特殊的电感，由铁氧体材料制成，在低频时呈现低阻抗，在高频时呈现高阻抗，主要用于抑制高频噪声和 EMI。磁珠的关键参数是阻抗值（通常在 100MHz 下测量）和额定电流，选型时需根据噪声频率和工作电流选择合适的磁珠。

### 3.3 电容

电容在开关电源中主要用于滤波、储能、旁路和耦合，根据介质材料的不同，可分为电解电容、陶瓷电容、薄膜电容和钽电容。

#### 3.3.1 电解电容

电解电容是开关电源中最常用的电容，具有容量大、体积小、成本低等优点，主要用于输入滤波、输出滤波和储能。

1.  **铝电解电容**
    
    ：最常用的电解电容，容量范围为 1μF~10000μF，耐压范围为 6.3V~450V。关键参数包括：容量、耐压、等效串联电阻（ESR）、纹波电流、使用寿命。铝电解电容的 ESR 较大，纹波电流能力有限，使用寿命受温度影响较大，温度每升高 10℃，使用寿命减半。
    
2.  **固态电解电容**
    
    ：采用导电聚合物作为电解质，与传统铝电解电容相比，具有 ESR 低、纹波电流大、使用寿命长、耐高温等优点，适用于低压大电流的输出滤波电路，如 CPU 供电、显卡供电。
    
3.  **选型原则**

-   耐压：应大于实际工作电压的 1.2~1.5 倍，输入滤波电容的耐压应大于整流后的最高直流电压。
    
-   容量：根据纹波要求和储能要求计算容量，输入滤波电容的容量通常按每瓦 1~2μF 选取，输出滤波电容的容量根据输出纹波要求计算。
    
-   纹波电流：电容能承受的最大纹波电流应大于实际工作纹波电流，并考虑温度降额。
    
-   ESR：ESR 越小，滤波效果越好，输出纹波越小。
    

5.  **常见失效模式**
    
    ：电解液干涸、容量衰减、ESR 增大、过压击穿、过热鼓包。选型时需选择高质量的品牌电容，留足耐压和纹波电流裕量，避免电容工作在高温环境下。
    

#### 3.3.2 陶瓷电容

陶瓷电容具有 ESR 极低、纹波电流大、使用寿命长、体积小等优点，主要用于高频滤波、旁路和耦合。

1.  **分类**
    
    ：根据介质材料的不同，可分为 Class 1（NPO/COG）和 Class 2（X7R、X5R、Y5V）陶瓷电容。Class 1 陶瓷电容的容量稳定性好，温度系数小，适用于高精度电路；Class 2 陶瓷电容的容量密度大，成本低，但容量随温度、电压和时间变化较大，适用于滤波和旁路电路。
    
2.  **选型原则**
    
    ：高频滤波时优先选择陶瓷电容，与电解电容并联使用，可以有效抑制高频纹波。选型时需注意陶瓷电容的电压系数和温度系数，避免在高压和高温下容量衰减过多。
    
3.  **常见失效模式**
    
    ：过压击穿、机械应力开裂、容量衰减。
    

#### 3.3.3 薄膜电容

薄膜电容具有 ESR 极低、纹波电流大、耐压高、使用寿命长、无极性等优点，主要用于 EMI 滤波、谐振电路和高压滤波。常用的薄膜电容有聚丙烯电容（CBB）和聚酯电容（CL），其中聚丙烯电容的损耗更低，适用于高频场景。

#### 3.3.4 钽电容

钽电容具有容量密度大、ESR 低、使用寿命长、体积小等优点，但耐压较低（通常≤50V），成本较高，且过流能力差，容易发生短路失效，甚至起火爆炸。钽电容主要用于对体积和可靠性要求高的低压电路，如便携式电子设备。选型时需留足电压和电流裕量，避免在大电流冲击和高温环境下使用。

### 3.4 电阻

电阻在开关电源中主要用于采样、分压、限流、泄放和负载，根据功率和精度的不同，可分为普通碳膜电阻、金属膜电阻、功率电阻和采样电阻。

1.  **普通碳膜电阻和金属膜电阻**
    
    ：功率较小（1/8W~1W），精度较高，主要用于分压、限流和信号电路。
    
2.  **功率电阻**
    
    ：功率较大（1W~100W），主要用于泄放、限流和负载，如启动电阻、假负载电阻。常用的功率电阻有水泥电阻、铝壳电阻和绕线电阻。
    
3.  **采样电阻**
    
    ：精度高（通常为 ±1% 或 ±0.5%）、温度系数小、功率适中，主要用于电流采样和电压采样，如输出电流采样、原边电流采样。采样电阻的阻值应尽可能小，以减小功耗，但需保证采样信号的幅度足够大，提高采样精度。
    

### 3.5 控制集成电路（IC）

控制 IC 是开关电源的大脑，负责产生 PWM/PFM 信号、采样输出信号、实现闭环控制和保护功能。根据应用场景的不同，可分为 PWM 控制器、PFC 控制器、同步整流控制器和数字电源控制器。

1.  **PWM 控制器**
    
    ：最常用的控制 IC，产生固定频率的 PWM 信号，通过调节占空比调节输出电压。根据控制方式的不同，可分为电压模式控制和电流模式控制。电流模式控制具有动态响应快、逐周期限流、自动平衡变压器直流偏磁等优点，是目前应用最广泛的控制方式。常用的 PWM 控制器有 UC3842、UC3843、TL494、SG3525 等。
    
2.  **PFC 控制器**
    
    ：用于功率因数校正电路，提高电源的功率因数，减少谐波污染。常用的 PFC 控制器有 L6562、ICE1PCS01、NCP1654 等。
    
3.  **同步整流控制器**
    
    ：用于驱动同步整流 MOSFET，替代传统的二极管整流，降低整流损耗，提高效率。常用的同步整流控制器有 IR1167、NCP4302、LM5020 等。
    
4.  **数字电源控制器**
    
    ：采用数字信号处理（DSP）或微控制器（MCU）实现控制功能，支持远程监控、智能保护、自适应调节和在线升级，是开关电源的发展方向。常用的数字电源控制器有 TI 的 UCD3138、ADI 的 ADP1047、Microchip 的 dsPIC33 系列等。

## 第四章 开关电源电路设计详解

##   

开关电源的电路设计是一个系统工程，需要综合考虑性能、成本、可靠性和 EMC 等因素。本章将从输入电路、功率级电路、控制与反馈电路、保护电路四个方面，详细介绍开关电源的电路设计方法和要点。

### 4.1 输入电路设计

输入电路是开关电源的第一道防线，主要作用是抑制 EMI、防止浪涌冲击、整流滤波和提供输入过压 / 欠压保护。输入电路的设计直接影响电源的 EMC 性能和可靠性。

#### 4.1.1 EMI 滤波电路设计

EMI 滤波电路的作用是抑制电源从电网引入的传导干扰，同时防止电源自身产生的传导干扰传入电网。EMI 滤波电路主要由共模电感、差模电感、X 电容和 Y 电容组成。

1.  **共模干扰与差模干扰**

-   共模干扰：存在于相线与大地、零线与大地之间的干扰，干扰电流大小相等、方向相同。
    
-   差模干扰：存在于相线与零线之间的干扰，干扰电流大小相等、方向相反。
    

3.  **EMI 滤波电路结构**

-   一级 EMI 滤波：由一个共模电感和两个 X 电容组成，主要抑制低频共模干扰和差模干扰。
    
-   二级 EMI 滤波：在一级滤波的基础上增加一个共模电感和 Y 电容，进一步抑制高频共模干扰。
    

5.  **元器件选型**

-   X 电容：跨接在相线与零线之间，用于抑制差模干扰。X 电容的容量通常为 0.1μF~1μF，耐压为 250VAC 或 275VAC，需符合安全标准（如 UL、VDE）。
    
-   Y 电容：跨接在相线与大地、零线与大地之间，用于抑制共模干扰。Y 电容的容量通常为 1nF~10nF，耐压为 250VAC 或 400VAC，漏电流应符合安全标准（通常≤0.25mA / 个）。
    
-   共模电感：由两个匝数相同、绕向相反的绕组绕在同一个磁芯上组成，对共模干扰呈现高阻抗，对差模电流呈现低阻抗。共模电感的电感量通常为 1mH~10mH，根据 EMI 抑制要求和额定电流选择。
    
-   差模电感：单独绕制的电感，用于抑制差模干扰，电感量通常为 10μH~100μH。
    

7.  **设计要点**

-   EMI 滤波电路应靠近电源输入端子布置，输入线应尽可能短，避免干扰信号在滤波前耦合到其他电路。
    
-   共模电感的两个绕组应对称绕制，避免产生过大的差模电感。
    
-   Y 电容的接地端应直接连接到电源的安全地，接地阻抗应尽可能小。
    
-   对于大功率电源，可采用多级 EMI 滤波电路，提高滤波效果。
    

#### 4.1.2 浪涌抑制电路设计

浪涌抑制电路的作用是防止电网中的浪涌电压（如雷击、开关操作产生的过电压）损坏电源内部的元器件。常用的浪涌抑制器件有压敏电阻（MOV）、气体放电管（GDT）和瞬态电压抑制二极管（TVS）。

1.  **压敏电阻（MOV）**
    
    ：最常用的浪涌抑制器件，并联在输入相线与零线之间，当电压超过其阈值电压时，压敏电阻的阻值急剧下降，将浪涌能量泄放掉。压敏电阻的选型主要考虑标称电压和通流容量，标称电压应大于电网最高电压的 1.2~1.5 倍，通流容量应根据预期的浪涌能量选择。
    
2.  **气体放电管（GDT）**
    
    ：击穿电压高，通流容量大，响应速度较慢，通常与压敏电阻串联使用，提高浪涌抑制能力。
    
3.  **瞬态电压抑制二极管（TVS）**
    
    ：响应速度极快（几 ns），通流容量较小，主要用于抑制低压电路中的浪涌电压，如控制电路、输出电路。
    
4.  **设计要点**

-   压敏电阻应靠近 EMI 滤波电路的输入端布置，以最大限度地抑制浪涌电压。
    
-   压敏电阻的失效模式通常为短路，为防止压敏电阻短路后引起火灾，应在压敏电阻回路中串联保险丝或温度保险丝。
    
-   对于雷击浪涌要求高的场景，可采用 “GDT+MOV+TVS” 的三级浪涌抑制方案。
    

#### 4.1.3 整流滤波电路设计

整流滤波电路的作用是将工频交流电转换为平滑的直流电，为后级逆变电路提供输入电压。整流滤波电路主要由整流桥和输入滤波电容组成。

1.  **整流桥选型**
    
    ：整流桥的额定电流应大于电源最大输入电流的 1.5~2 倍，额定反向电压应大于电网最高电压的 2 倍。对于小功率电源，可采用分立二极管组成整流桥；对于中大功率电源，应采用集成整流桥模块。
    
2.  **输入滤波电容选型**
    
    ：输入滤波电容的作用是平滑整流后的直流电压，存储能量，为后级逆变电路提供稳定的输入电压。输入滤波电容的容量通常按每瓦 1~2μF 选取，对于全球通用输入电压（85~265VAC）的电源，输入滤波电容的耐压应不低于 400V。为减小 ESR 和提高纹波电流能力，可采用多个电容并联使用。
    
3.  **设计要点**

-   整流桥应安装在散热片上，确保散热良好。
    
-   输入滤波电容应靠近整流桥和逆变电路的输入端布置，减小引线电感，抑制电压尖峰。
    
-   对于功率因数校正（PFC）电源，输入滤波电容的容量可适当减小，因为 PFC 电路可以提高输入电流的功率因数，减小输入电流纹波。
    

#### 4.1.4 输入保护电路设计

输入保护电路主要包括输入过压保护、输入欠压保护和输入过流保护。

1.  **输入过压保护（OVP）**
    
    ：当输入电压超过设定值时，保护电路动作，切断电源输入，防止后级元器件损坏。输入过压保护可通过电压采样电路和比较器实现，也可采用集成的过压保护 IC。
    
2.  **输入欠压保护（UVP）**
    
    ：当输入电压低于设定值时，保护电路动作，切断电源输出，防止电源在低电压下工作时电流过大，损坏元器件。
    
3.  **输入过流保护（OCP）**
    
    ：当输入电流超过设定值时，保护电路动作，切断电源输入，防止电源过载损坏。输入过流保护通常采用保险丝或断路器实现，对于大功率电源，可采用电流采样电路和比较器实现电子过流保护。
    

### 4.2 功率级电路设计

功率级电路是开关电源的核心，负责电能的变换和传输，主要包括开关管驱动电路、逆变电路、高频变压器、输出整流滤波电路和同步整流电路。

#### 4.2.1 开关管驱动电路设计

驱动电路的作用是将控制 IC 输出的 PWM 信号放大，驱动开关管可靠导通和截止。驱动电路的性能直接影响开关管的开关速度、开关损耗和可靠性。

1.  **驱动电路的基本要求**

-   提供足够的驱动电流，确保开关管快速导通和截止。
    
-   提供合适的驱动电压，MOSFET 的驱动电压通常为 10~15V，IGBT 的驱动电压通常为 12~15V。
    
-   实现控制电路与功率电路的电气隔离，对于隔离型开关电源，驱动电路需要隔离。
    
-   具有过流保护和栅极保护功能，防止开关管损坏。
    

3.  **非隔离型驱动电路**
    
    ：适用于非隔离型开关电源和原边开关管的驱动，电路结构简单，成本低。常用的非隔离型驱动电路有直接驱动电路、图腾柱驱动电路和集成驱动 IC。
    
4.  **隔离型驱动电路**
    
    ：适用于隔离型开关电源的副边开关管驱动和高压侧开关管驱动，实现控制电路与功率电路的电气隔离。常用的隔离型驱动方式有：脉冲变压器驱动、光耦隔离驱动和磁隔离驱动 IC。
    

-   脉冲变压器驱动：结构简单，成本低，传输延迟小，但驱动信号的占空比受限，不能传输直流信号。
    
-   光耦隔离驱动：传输直流信号，占空比不受限，但传输延迟较大，驱动能力有限，需要外接放大电路。
    
-   磁隔离驱动 IC：集成了磁隔离和驱动电路，传输延迟小，驱动能力强，可靠性高，是目前隔离型驱动的主流方案。
    

6.  **设计要点**

-   驱动电路应尽可能靠近开关管布置，减小栅极引线电感，抑制栅极电压振荡。
    
-   在栅极回路中串联一个小电阻（10~100Ω），抑制栅极电压振荡，调节开关速度。
    
-   在栅源极之间并联一个稳压二极管，防止栅极过压损坏。
    
-   对于大功率开关管，应采用推挽驱动电路，提供足够的驱动电流。
    

#### 4.2.2 逆变电路设计

逆变电路的作用是将直流电压逆变为高频交流电压，通过高频变压器传输到副边。逆变电路的拓扑结构根据功率等级和应用场景选择，小功率电源通常采用反激拓扑，中大功率电源通常采用正激、半桥或全桥拓扑。

1.  **反激逆变电路设计**

-   开关管选型：根据最大漏源电压和最大漏极电流选择合适的 MOSFET，漏源电压应大于 Vin\_max+VOR + 尖峰电压，漏极电流应大于最大原边峰值电流。
    
-   RCD 钳位电路：反激变换器开关管截止时，变压器漏感会产生很高的尖峰电压，容易击穿开关管，因此必须设置 RCD 钳位电路，将尖峰电压限制在安全范围内。RCD 钳位电路由电阻 R、电容 C 和二极管 D 组成，并联在开关管的漏源极之间。
    
-   设计要点：RCD 钳位电路的参数应根据漏感大小和尖峰电压要求计算，电阻的功率应足够大，能够消耗漏感存储的能量；电容的耐压应大于钳位电压。
    

3.  **半桥逆变电路设计**

-   开关管选型：两个开关管的参数应一致，漏源电压应大于最大输入电压，漏极电流应大于最大原边峰值电流。
    
-   分压电容选型：两个分压电容的容量应一致，耐压应大于最大输入电压，容量应足够大，确保中点电压稳定。
    
-   隔直电容：在变压器原边回路中串联一个隔直电容，防止变压器直流偏磁饱和。隔直电容的容量应足够大，容抗远小于变压器原边阻抗。
    

5.  **全桥逆变电路设计**

-   开关管选型：四个开关管的参数应一致，漏源电压应大于最大输入电压，漏极电流应大于最大原边峰值电流。
    
-   移相控制：采用移相控制方式调节输出电压，通过调节两个桥臂开关管的导通相位差，改变变压器原边电压的有效值，从而调节输出电压。
    

#### 4.2.3 输出整流滤波电路设计

输出整流滤波电路的作用是将高频变压器副边的高频交流电压整流滤波为平滑的直流电压，为负载供电。输出整流滤波电路主要由整流二极管（或同步整流 MOSFET）、输出电感和输出电容组成。

1.  **整流电路设计**

-   半波整流：电路简单，成本低，适用于小功率、多路输出的反激变换器。
    
-   全波整流：适用于中心抽头的变压器副边绕组，整流效率高，输出纹波小，适用于中大功率电源。
    
-   桥式整流：适用于无中心抽头的变压器副边绕组，需要四个整流二极管，整流效率高，适用于高压输出的电源。
    

3.  **滤波电路设计**

-   输出电感：输出电感的作用是平滑输出电流，减小电流纹波。电感量根据输出电流纹波要求计算，通常取额定输出电流的 20%~40%。
    
-   输出电容：输出电容的作用是平滑输出电压，减小电压纹波。输出电容的容量根据输出电压纹波要求计算，为减小 ESR 和提高纹波电流能力，通常采用电解电容与陶瓷电容并联使用。
    

5.  **设计要点**

-   整流二极管的正向压降应尽可能小，以减小整流损耗。低压大电流输出时，优先选择肖特基二极管或同步整流 MOSFET。
    
-   输出电感和输出电容应靠近负载布置，减小引线电感，提高滤波效果。
    
-   对于多路输出的电源，主输出应采用 LC 滤波，辅助输出可采用电容滤波，以降低成本。
    

#### 4.2.4 同步整流电路设计

同步整流技术是采用低导通电阻的 MOSFET 替代传统的整流二极管，利用 MOSFET 的导通特性实现整流，大大降低了整流损耗，提高了电源效率。同步整流技术特别适用于低压大电流输出的开关电源，如 5V/12V 输出的服务器电源、CPU 供电电源。

1.  **同步整流的工作原理**
    
    ：同步整流 MOSFET 的导通和截止与原边开关管同步，当变压器副边电压为正时，同步整流 MOSFET 导通，电流从漏极流向源极，实现整流；当变压器副边电压为负时，同步整流 MOSFET 截止，防止电流反向流动。
    
2.  **同步整流控制方式**

-   自驱动同步整流：利用变压器副边电压直接驱动同步整流 MOSFET，电路结构简单，成本低，但驱动电压受变压器副边电压影响，轻载时效率较低。
    
-   外驱动同步整流：采用专门的同步整流控制器驱动同步整流 MOSFET，控制精度高，轻载时效率高，但电路结构复杂，成本高。
    

4.  **设计要点**

-   同步整流 MOSFET 的导通电阻应尽可能小，以减小导通损耗。
    
-   同步整流 MOSFET 的栅极驱动电压应合适，确保 MOSFET 可靠导通和截止。
    
-   应设置死区时间，防止原边开关管和同步整流 MOSFET 同时导通，造成短路。
    

### 4.3 控制与反馈电路设计

控制与反馈电路是开关电源的核心，负责采样输出信号，与基准电压比较，产生 PWM 信号，调节开关管的占空比，实现输出电压的稳定。控制与反馈电路的性能直接影响电源的电压精度、负载调整率、线性调整率和动态响应。

#### 4.3.1 电压采样与基准电路

1.  **电压采样电路**
    
    ：输出电压通过电阻分压采样，得到采样电压，输入到误差放大器的反相输入端。分压电阻的精度和温度系数直接影响输出电压的精度，应选择高精度、低温度系数的金属膜电阻。
    
2.  **基准电路**
    
    ：基准电压是误差放大器的参考电压，其精度和稳定性直接影响输出电压的精度。常用的基准电压源有 TL431、LM431、REF02 等，其中 TL431 是最常用的并联型基准电压源，具有精度高、成本低、使用方便等优点。
    

#### 4.3.2 误差放大器与补偿电路

误差放大器的作用是将采样电压与基准电压的差值放大，输出控制信号，调节 PWM 控制器的占空比。开关电源的闭环控制系统是一个二阶系统，存在稳定性问题，因此必须设计补偿电路，对系统进行相位补偿，确保系统稳定。

1.  **控制方式**

-   电压模式控制：仅采样输出电压，通过误差放大器调节 PWM 占空比。电压模式控制的电路结构简单，但动态响应慢，抗干扰能力差，需要设计复杂的补偿电路。
    
-   电流模式控制：同时采样输出电压和电感电流（或原边电流），电流环作为内环，电压环作为外环。电流模式控制具有动态响应快、逐周期限流、自动平衡变压器直流偏磁等优点，是目前应用最广泛的控制方式。
    

3.  **补偿电路类型**

-   单极点补偿：适用于电流模式控制的电源，电路结构简单，补偿效果好。
    
-   双极点 - 单零点补偿：适用于电压模式控制的电源，补偿效果好，但电路结构复杂。
    
-   三极点 - 双零点补偿：适用于对稳定性和动态响应要求高的电源。
    

5.  **补偿电路设计要点**

-   补偿电路的参数应根据系统的传递函数计算，确保系统有足够的相位裕量（通常≥45°）和增益裕量（通常≥10dB）。
    
-   补偿电路应靠近误差放大器布置，减小引线干扰。
    
-   应通过实验调试补偿电路的参数，确保系统在全负载范围内稳定工作。
    

#### 4.3.3 隔离反馈电路设计

对于隔离型开关电源，输入与输出之间电气隔离，因此反馈信号需要通过隔离器件传输到原边控制电路。常用的隔离反馈方式有光耦隔离反馈和磁隔离反馈。

1.  **光耦隔离反馈**
    
    ：最常用的隔离反馈方式，由光耦和 TL431 组成。TL431 采样输出电压，控制光耦的发光二极管电流，光耦的光敏三极管将电流信号传输到原边，控制 PWM 控制器的占空比。光耦隔离反馈的电路结构简单，成本低，但传输延迟较大，温度特性较差。
    
2.  **磁隔离反馈**
    
    ：采用磁隔离器件传输反馈信号，传输延迟小，温度特性好，可靠性高，但成本较高。
    
3.  **设计要点**

-   光耦的电流传输比（CTR）应合适，确保在全负载范围内有足够的调节范围。
    
-   应选择线性度好、温度特性好的光耦，提高反馈精度。
    
-   光耦的原边和副边应分别接地，避免共模干扰。
    

### 4.4 保护电路设计

保护电路是开关电源可靠性的重要保障，当电源出现异常情况时，保护电路应及时动作，切断电源输出，防止电源和负载损坏。开关电源的保护电路主要包括过压保护、过流保护、过温保护和短路保护。

#### 4.4.1 过压保护（OVP）

过压保护的作用是当输出电压超过设定值时，切断电源输出，防止负载因过压损坏。过压保护分为输出过压保护和输入过压保护，其中输出过压保护尤为重要。

1.  **输出过压保护实现方式**

-   稳压管钳位：在输出端并联一个稳压二极管，当输出电压超过稳压管的击穿电压时，稳压管击穿，将输出电压钳位在安全范围内。这种方式简单可靠，但只能实现钳位保护，不能切断电源输出。
    
-   晶闸管 crowbar 保护：在输出端并联一个晶闸管，当输出电压超过设定值时，晶闸管导通，将输出短路，触发输入过流保护，切断电源输入。这种方式保护可靠，适用于对过压敏感的负载。
    
-   控制 IC 内置过压保护：大多数 PWM 控制器都内置了过压保护功能，当反馈电压超过设定值时，控制器停止输出 PWM 信号，切断电源输出。
    

3.  **设计要点**

-   过压保护的动作电压应高于电源的最高输出电压，低于负载的最高承受电压。
    
-   对于重要负载，应采用双重过压保护，提高保护可靠性。
    

#### 4.4.2 过流保护（OCP）

过流保护的作用是当输出电流超过设定值时，切断电源输出，防止电源和负载因过流损坏。过流保护分为逐周期过流保护和打嗝式过流保护。

1.  **逐周期过流保护**
    
    ：每个开关周期都采样电流，当电流超过设定值时，立即关断开关管，直到下一个开关周期。逐周期过流保护响应速度快，适用于短路和瞬时过流保护。
    
2.  **打嗝式过流保护**
    
    ：当输出电流超过设定值时，电源停止输出，延迟一段时间后重新启动，如果过流仍然存在，再次停止输出，如此反复。打嗝式过流保护可以减小电源在过流时的功耗，适用于持续过流保护。
    
3.  **实现方式**

-   原边电流采样：通过在原边开关管的源极串联一个采样电阻，采样原边电流，实现逐周期过流保护。这种方式简单可靠，是目前应用最广泛的过流保护方式。
    
-   副边电流采样：通过在副边输出回路中串联一个采样电阻或电流互感器，采样副边电流，实现过流保护。这种方式采样精度高，但需要隔离。
    

5.  **设计要点**

-   过流保护的动作电流应高于电源的额定输出电流，低于电源的最大输出电流和元器件的最大承受电流。
    
-   应设置合适的过流保护延迟时间，防止误动作。
    

#### 4.4.3 过温保护（OTP）

过温保护的作用是当电源内部温度超过设定值时，切断电源输出，防止元器件因过热损坏。过温保护主要针对开关管、整流二极管、高频变压器等发热严重的元器件。

1.  **实现方式**

-   热敏电阻检测：在发热元器件附近安装一个负温度系数（NTC）热敏电阻，当温度升高时，热敏电阻的阻值下降，通过检测电路触发保护动作。
    
-   温度开关检测：在发热元器件附近安装一个温度开关，当温度超过设定值时，温度开关动作，切断电源输入。
    
-   控制 IC 内置过温保护：部分 PWM 控制器和功率集成器件内置了过温保护功能，当芯片温度超过设定值时，停止输出 PWM 信号。
    

3.  **设计要点**

-   过温保护的动作温度应低于元器件的最高工作温度，并留足裕量。
    
-   热敏电阻或温度开关应尽可能靠近发热元器件安装，提高温度检测的准确性。
    

#### 4.4.4 短路保护（SCP）

短路保护是过流保护的一种特殊情况，当输出短路时，输出电流急剧增大，保护电路应快速动作，切断电源输出，防止电源损坏。短路保护的响应速度应尽可能快，通常在几 μs 至几十 μs 内动作。

1.  **实现方式**
    
    ：通常采用原边电流采样的逐周期过流保护实现短路保护，当输出短路时，原边电流迅速增大，超过过流保护阈值，开关管立即关断。
    
2.  **设计要点**

-   短路保护的动作电流应设置得足够大，防止电源在启动和负载突变时误动作。
    
-   对于大功率电源，应采用限流型短路保护，限制短路电流的大小，减小对电源的冲击。

## 第五章 开关电源 PCB 设计工艺

##   

PCB 设计是开关电源设计中至关重要的环节，直接影响电源的性能、可靠性和 EMC。开关电源的 PCB 设计与普通数字电路和模拟电路有很大的不同，需要重点考虑功率回路的电流承载能力、接地设计、布线阻抗、散热和 EMI 抑制。

### 5.1 PCB 设计基本原则

1.  **分区布局原则**
    
    ：将 PCB 分为输入区、功率区、控制区和输出区四个区域，各区域之间相互隔离，避免干扰。输入区和功率区是强电区，控制区是弱电区，强电区和弱电区应分开布置，保持足够的安全距离。
    
2.  **最短路径原则**
    
    ：功率回路和信号回路的布线应尽可能短，减小引线电感和电阻，降低电压尖峰和损耗。特别是开关管、整流二极管、高频变压器和滤波电容之间的连线，应尽可能短而粗。
    
3.  **大电流原则**
    
    ：大电流回路的布线应足够宽，确保电流承载能力，避免导线过热。线宽与电流的关系通常为：1oz 铜厚的 PCB，1mm 线宽可承载约 1A 的电流。
    
4.  **接地原则**
    
    ：采用单点接地或多点接地，减小接地阻抗，避免地电位差引起的干扰。功率地和信号地应分开布线，最后在一点连接。
    
5.  **散热原则**
    
    ：发热元器件（如开关管、整流二极管、整流桥）应布置在 PCB 的边缘或通风良好的位置，便于散热。大功率元器件应安装散热片，散热片与 PCB 之间应留有足够的间隙，避免热传导到 PCB 上。
    
6.  **安全距离原则**
    
    ：强电区和弱电区之间、高压导线之间、高压导线与外壳之间应保持足够的安全距离，符合安全标准要求。例如，AC 220V 输入的电源，强电区与弱电区之间的爬电距离应不小于 6mm，电气间隙应不小于 3mm。
    

### 5.2 PCB 布局设计

PCB 布局是 PCB 设计的第一步，布局的好坏直接影响后续的布线和电源性能。布局应按照 “先大后小、先主后次” 的原则进行，先布置大的元器件（如高频变压器、电解电容、散热片），再布置小的元器件（如电阻、电容、IC）。

#### 5.2.1 输入区布局

输入区包括输入端子、EMI 滤波电路、浪涌抑制电路、整流桥和输入滤波电容。

1.  输入端子应布置在 PCB 的边缘，便于接线。
    
2.  EMI 滤波电路应紧靠输入端子布置，输入线应尽可能短，避免干扰信号在滤波前耦合到其他电路。共模电感应垂直于 PCB 安装，减小漏磁对其他电路的影响。
    
3.  浪涌抑制器件（如压敏电阻）应紧靠 EMI 滤波电路的输入端布置。
    
4.  整流桥应布置在 EMI 滤波电路之后，靠近输入滤波电容。整流桥的散热面应朝向 PCB 的外侧，便于安装散热片。
    
5.  输入滤波电容应紧靠整流桥和逆变电路的输入端布置，电容的正极接整流桥的正极输出，负极接功率地。多个电容并联时，应均匀布置，减小引线电感。
    

#### 5.2.2 功率区布局

功率区包括开关管、高频变压器、输出整流二极管、输出电感和输出电容，是开关电源中电流最大、电压变化最快的区域，也是 EMI 的主要来源。

1.  开关管应紧靠高频变压器的原边绕组布置，开关管的漏极接变压器原边绕组的一端，源极接功率地，栅极接驱动电路。开关管的散热面应朝向 PCB 的外侧，便于安装散热片。
    
2.  高频变压器应布置在功率区的中心，原边绕组靠近输入滤波电容和开关管，副边绕组靠近输出整流二极管和输出电容。变压器的引脚应尽可能短，减小引线电感。
    
3.  输出整流二极管应紧靠高频变压器的副边绕组布置，二极管的阳极接变压器副边绕组，阴极接输出电感和输出电容。二极管的散热面应朝向 PCB 的外侧，便于安装散热片。
    
4.  输出电感应紧靠输出整流二极管和输出电容布置，电感的一端接二极管的阴极，另一端接输出电容的正极。
    
5.  输出电容应紧靠输出电感和输出端子布置，电容的正极接输出电感，负极接功率地。多个电容并联时，应均匀布置，减小 ESR 和引线电感。
    

#### 5.2.3 控制区布局

控制区包括 PWM 控制器、误差放大器、光耦、基准电压源和其他小信号元器件，是开关电源的控制中心，对干扰非常敏感。

1.  控制区应布置在 PCB 的一角，远离功率区和输入区，避免强电干扰。
    
2.  PWM 控制器应紧靠开关管的驱动电路布置，PWM 输出引脚到开关管栅极的连线应尽可能短。
    
3.  光耦应布置在控制区和功率区之间，实现原边和副边的隔离。光耦的原边接副边反馈电路，副边接原边控制电路。
    
4.  小信号元器件（如电阻、电容、IC）应集中布置在 PWM 控制器周围，布线应尽可能短，减小干扰。
    
5.  控制电路的电源和地应单独布线，采用星形接地，避免功率地的大电流流过控制地。
    

#### 5.2.4 输出区布局

输出区包括输出端子、输出滤波电容和输出保护电路。

1.  输出端子应布置在 PCB 的边缘，便于接线。
    
2.  输出滤波电容应紧靠输出端子布置，减小输出引线的电感和电阻，提高输出电压的稳定性。
    
3.  输出保护电路（如过压保护、过流保护）应紧靠输出端子布置，便于检测输出电压和电流。
    

### 5.3 PCB 布线设计

PCB 布线是在布局完成后，将各个元器件连接起来，实现电路功能。布线应遵循 “先功率后信号、先大电流后小电流” 的原则，先布功率回路，再布信号回路。

#### 5.3.1 功率回路布线

功率回路是开关电源中电流最大、电压变化最快的回路，包括原边功率回路和副边功率回路。功率回路的布线质量直接影响电源的效率、纹波和 EMI。

1.  **原边功率回路**
    
    ：输入滤波电容正极→开关管漏极→开关管源极→输入滤波电容负极。该回路的电流变化率 di/dt 很大，会产生很强的电磁辐射，因此布线应尽可能短而粗，减小回路面积。
    
2.  **副边功率回路**
    
    ：高频变压器副边绕组→输出整流二极管→输出电感→输出电容→高频变压器副边绕组。该回路的电流变化率也很大，同样应尽可能短而粗，减小回路面积。
    
3.  **布线要求**

-   功率回路的线宽应根据电流大小确定，1oz 铜厚的 PCB，线宽应不小于 1mm/A，大电流回路应采用铺铜或多股线并联。
    
-   功率回路的布线应避免直角和锐角，采用 45° 角或圆弧过渡，减小高频辐射。
    
-   开关管和整流二极管的引脚应尽可能短，避免引脚电感引起的电压尖峰。
    
-   高频变压器的原边和副边绕组的引线应分开布线，避免相互耦合。
    

#### 5.3.2 信号回路布线

信号回路包括控制信号回路、反馈信号回路和采样信号回路，这些回路的电流小、电压低，对干扰非常敏感。

1.  **控制信号回路**
    
    ：PWM 控制器输出→驱动电路→开关管栅极。该回路的布线应尽可能短，减小引线电感，避免栅极电压振荡。栅极回路应串联一个小电阻，抑制振荡。
    
2.  **反馈信号回路**
    
    ：输出电压采样→误差放大器→光耦→PWM 控制器。该回路的布线应远离功率回路，避免强电干扰。反馈信号线应采用屏蔽线或差分布线，提高抗干扰能力。
    
3.  **采样信号回路**
    
    ：电流采样→PWM 控制器。电流采样线应尽可能短，采用差分布线，减小共模干扰。采样电阻应紧靠采样点布置，避免引线电阻影响采样精度。
    
4.  **布线要求**

-   信号回路的线宽通常为 0.2~0.3mm，对于高频信号，线宽可适当加宽。
    
-   信号线应远离功率回路和高压导线，保持足够的距离，避免耦合干扰。
    
-   信号线应避免平行布线，交叉时应采用 90° 交叉，减小串扰。
    
-   控制电路的电源和地应采用星形布线，每个 IC 的电源引脚都应并联一个 0.1μF 的陶瓷去耦电容，紧靠电源引脚布置。
    

#### 5.3.3 接地设计

接地设计是 PCB 设计中最重要的环节之一，良好的接地设计可以减小接地阻抗，抑制地电位差，提高电源的抗干扰能力。

1.  **接地方式**

-   单点接地：将所有电路的地都连接到一个公共点，适用于低频电路（<1MHz）。单点接地可以避免地电位差引起的干扰，但接地引线较长，阻抗较大。
    
-   多点接地：将各个电路的地就近连接到接地平面，适用于高频电路（>10MHz）。多点接地的接地阻抗小，但容易形成地环路，引起干扰。
    
-   混合接地：对于既有低频又有高频的电路，采用单点接地和多点接地相结合的方式，低频部分采用单点接地，高频部分采用多点接地。
    

3.  **开关电源接地设计要点**

-   功率地和信号地应分开布线，最后在一点连接，通常在输入滤波电容的负极或输出滤波电容的负极连接。
    
-   功率地应采用大面积铺铜，减小接地阻抗，提高散热能力。铺铜应尽可能完整，避免出现孤岛和狭缝。
    
-   信号地应采用星形布线，每个小信号电路的地都单独连接到控制 IC 的地引脚，避免功率地的大电流流过信号地。
    
-   安全地应单独布线，连接到电源的金属外壳，保护人身安全。安全地与功率地和信号地之间应保持足够的安全距离，通过 Y 电容连接。
    

#### 5.3.4 散热设计

开关电源在工作时会产生热量，热量如果不能及时散发，会导致元器件温度升高，性能下降，甚至损坏。PCB 的散热设计是电源散热系统的重要组成部分。

1.  **散热方式**

-   自然散热：通过 PCB 的铜皮和元器件的表面将热量散发到空气中，适用于小功率电源。
    
-   强制风冷：通过风扇将热量带走，适用于中大功率电源。
    
-   散热片散热：将发热元器件安装在散热片上，通过散热片将热量散发到空气中，是最常用的散热方式。
    

3.  **PCB 散热设计要点**

-   发热元器件（如开关管、整流二极管、整流桥）应布置在 PCB 的边缘或通风良好的位置，便于空气流通。
    
-   大功率元器件应安装散热片，散热片与元器件之间应涂导热硅脂，减小热阻。散热片的尺寸应根据元器件的功耗和热阻计算。
    
-   发热元器件的引脚应尽可能短，避免引脚成为热传导的瓶颈。
    
-   功率地应采用大面积铺铜，增加散热面积。铺铜应与发热元器件的散热引脚直接连接，提高热传导效率。
    
-   对于双面 PCB，可在发热元器件的背面铺铜，增加散热面积。
    
-   对于大功率电源，可采用金属基板 PCB，提高散热能力。
    

### 5.4 EMI 抑制的 PCB 设计技巧

EMI 是开关电源的主要问题之一，PCB 设计是抑制 EMI 的关键环节。通过合理的 PCB 布局和布线，可以有效降低电源的 EMI。

1.  **减小功率回路面积**
    
    ：功率回路是 EMI 的主要来源，减小功率回路的面积可以降低电磁辐射。原边功率回路和副边功率回路的面积应尽可能小。
    
2.  **屏蔽设计**
    
    ：对高频变压器、开关管等强辐射源进行屏蔽，可采用金属屏蔽罩将其罩住，屏蔽罩应可靠接地。
    
3.  **滤波设计**
    
    ：在电源的输入和输出端增加 EMI 滤波电路，抑制传导干扰。在 IC 的电源引脚并联去耦电容，抑制电源噪声。
    
4.  **接地设计**
    
    ：采用大面积铺铜接地，减小接地阻抗，抑制地电位差。功率地和信号地分开布线，避免地环路干扰。
    
5.  **布线设计**
    
    ：避免直角和锐角布线，采用 45° 角或圆弧过渡，减小高频辐射。信号线远离功率回路和高压导线，避免耦合干扰。
    
6.  **元器件选型**
    
    ：选择封装小、引脚短的元器件，减小引线电感。选择高频特性好的元器件，如陶瓷电容、快恢复二极管等。
    

### 5.5 PCB 工艺要求

1.  **铜厚**
    
    ：功率回路的铜厚应不小于 1oz，大电流回路可采用 2oz 或 3oz 铜厚。信号回路的铜厚通常为 0.5oz 或 1oz。
    
2.  **线宽和线距**
    
    ：功率回路的线宽应根据电流大小确定，线距应不小于 0.2mm。信号回路的线宽通常为 0.2~0.3mm，线距应不小于 0.15mm。
    
3.  **过孔**
    
    ：过孔的孔径应不小于 0.3mm，焊盘直径应不小于 0.6mm。大电流回路的过孔应采用多个过孔并联，减小过孔阻抗。过孔应避免打在焊盘上，防止焊接不良。
    
4.  **阻焊层**
    
    ：PCB 表面应涂覆阻焊层，防止短路和腐蚀。功率回路的焊盘应采用裸铜或喷锡处理，提高焊接质量和散热能力。
    
5.  **丝印层**
    
    ：丝印层应清晰标注元器件的编号、型号、极性和安装方向，便于生产和维修。
    
6.  **工艺边**
    
    ：PCB 应预留工艺边，便于生产时的传输和定位。工艺边的宽度通常为 5mm，上面应设置定位孔和光学定位点。

## 第六章 开关电源生产装配工艺

##   

开关电源的生产装配工艺直接影响产品的质量和可靠性，严格按照工艺要求进行生产装配，是保证电源性能的关键。本章将详细介绍开关电源生产装配的各个环节，包括生产准备、SMT 贴片工艺、插件工艺、手工焊接工艺、组装工艺和三防工艺。

### 6.1 生产准备

生产准备是生产装配的第一步，包括物料检验、工装设备准备和生产文件准备。

1.  **物料检验**
    
    ：所有元器件在入库前都应进行检验，确保符合设计要求。检验项目包括：型号、规格、数量、外观、电气性能等。对于关键元器件（如 MOSFET、二极管、电解电容、高频变压器），应进行抽样测试，测试其关键参数是否符合要求。不合格的元器件不得投入生产。
    
2.  **工装设备准备**
    
    ：根据生产工艺要求，准备好所需的工装设备，如贴片机、回流焊炉、波峰焊机、焊接台、电烙铁、万用表、示波器、电源测试仪等。所有设备都应进行校准和调试，确保工作正常。
    
3.  **生产文件准备**
    
    ：准备好生产所需的技术文件，如 BOM 表、PCB 丝印图、装配图、工艺流程图、作业指导书、检验标准等。生产文件应清晰、准确、完整，便于生产人员操作。
    

### 6.2 SMT 贴片工艺

SMT（表面贴装技术）是将表面贴装元器件焊接到 PCB 表面的工艺，具有生产效率高、焊接质量好、可靠性高等优点，是目前电子元器件焊接的主流工艺。开关电源中的小信号元器件（如电阻、电容、IC、二极管、三极管）通常采用 SMT 贴片工艺焊接。

SMT 贴片工艺的流程为：焊膏印刷→贴片→回流焊→检验。

1.  **焊膏印刷**
    
    ：将焊膏通过钢网印刷到 PCB 的焊盘上。焊膏的成分、粘度和印刷厚度直接影响焊接质量。印刷时应确保焊膏均匀、饱满，无漏印、少印、多印和连锡现象。钢网的厚度应根据元器件的引脚间距和焊盘大小确定，通常为 0.12~0.2mm。
    
2.  **贴片**
    
    ：通过贴片机将表面贴装元器件准确地贴放到 PCB 的焊盘上。贴片机的精度应满足元器件的贴装要求，对于引脚间距小于 0.5mm 的细间距元器件，应采用高精度贴片机。贴片时应确保元器件的型号、规格、极性和位置正确，无错贴、漏贴、反贴和偏移现象。
    
3.  **回流焊**
    
    ：将贴好元器件的 PCB 送入回流焊炉，通过加热使焊膏熔化，实现元器件与 PCB 的焊接。回流焊的温度曲线是焊接质量的关键，应根据焊膏的类型和元器件的耐热性设置合适的温度曲线。温度曲线通常分为预热区、保温区、回流区和冷却区四个阶段。
    

-   预热区：温度从室温上升到 150~180℃，时间为 60~120s，使焊膏中的溶剂挥发，防止焊接时产生气泡。
    
-   保温区：温度保持在 150~180℃，时间为 60~120s，使焊膏中的助焊剂活化，去除焊盘和元器件引脚表面的氧化层。
    
-   回流区：温度上升到焊膏的熔点以上，通常为 230~250℃，时间为 30~60s，使焊膏熔化，润湿焊盘和元器件引脚。
    
-   冷却区：温度迅速下降到室温，使焊锡凝固，形成牢固的焊点。冷却速度应适中，过快会导致焊点产生内应力，过慢会导致焊点晶粒粗大，强度降低。
    

5.  **检验**
    
    ：回流焊完成后，应对焊接质量进行检验。检验项目包括：焊点是否饱满、光亮，有无虚焊、假焊、连锡、桥接、立碑、移位等缺陷。对于不合格的焊点，应进行返修。
    

### 6.3 插件工艺

插件工艺是将插装元器件插入 PCB 的通孔中，然后通过波峰焊或手工焊接将其焊接到 PCB 上的工艺。开关电源中的大功率元器件（如电解电容、高频变压器、电感、连接器、散热片）通常采用插件工艺焊接。

插件工艺的流程为：元器件成型→插件→波峰焊→剪脚→检验。

1.  **元器件成型**
    
    ：对于引脚过长或形状不符合要求的插装元器件，应进行成型处理，使其引脚间距与 PCB 的通孔间距一致，便于插件。成型时应注意保护元器件的本体和引脚，避免损坏。元器件的引脚弯曲处应距离本体至少 2mm，弯曲半径应不小于引脚直径的 2 倍。
    
2.  **插件**
    
    ：将成型后的元器件插入 PCB 的通孔中，确保元器件的型号、规格、极性和位置正确。插件时应注意元器件的高度和方向，对于有极性的元器件（如电解电容、二极管、三极管），应确保极性正确。元器件插入后，应将引脚折弯 45°，防止元器件在波峰焊时脱落。
    
3.  **波峰焊**
    
    ：将插好元器件的 PCB 送入波峰焊机，通过熔融的焊锡波将元器件的引脚焊接到 PCB 上。波峰焊的工艺参数（如焊锡温度、传输速度、波峰高度、预热温度）直接影响焊接质量。焊锡温度通常为 240~260℃，传输速度通常为 1~1.5m/min，预热温度通常为 150~180℃。波峰焊时应确保 PCB 的焊接面与焊锡波充分接触，无漏焊、虚焊、连锡等缺陷。
    
4.  **剪脚**
    
    ：波峰焊完成后，用剪脚机将元器件过长的引脚剪掉，引脚长度应保留 1~2mm。剪脚时应注意不要损伤焊点和 PCB。
    
5.  **检验**
    
    ：对波峰焊的焊接质量进行检验，检查有无虚焊、假焊、连锡、漏焊、引脚过长等缺陷。对于不合格的焊点，应进行返修。
    

### 6.4 手工焊接工艺

对于一些无法采用 SMT 和波峰焊焊接的元器件（如大功率散热片、连接器、特殊元器件），以及返修的焊点，需要采用手工焊接工艺。手工焊接的质量取决于操作人员的技能和经验，应严格按照焊接工艺要求进行操作。

1.  **焊接工具**
    
    ：手工焊接通常采用电烙铁，电烙铁的功率应根据焊接元器件的大小和热容量选择。焊接小信号元器件时，采用 20~30W 的电烙铁；焊接大功率元器件时，采用 50~100W 的电烙铁。电烙铁的烙铁头应保持清洁，定期上锡。
    
2.  **焊接步骤**

-   准备：将电烙铁预热到合适的温度，准备好焊锡丝和助焊剂。
    
-   加热：将烙铁头同时接触焊盘和元器件引脚，加热 1~2s，使焊盘和引脚温度升高。
    
-   上锡：将焊锡丝接触焊盘和引脚，当焊锡熔化并润湿焊盘和引脚后，移开焊锡丝。
    
-   移开烙铁：焊锡润湿焊盘和引脚后，迅速移开烙铁，移开方向应与引脚成 45° 角。
    
-   冷却：让焊点自然冷却，不要用嘴吹或用手触摸，防止焊点产生内应力。
    

4.  **焊接质量要求**
    
    ：焊点应饱满、光亮、呈圆锥形，无虚焊、假焊、连锡、拉尖、气孔等缺陷。焊锡量应适中，过多会导致连锡，过少会导致虚焊。
    
5.  **注意事项**

-   焊接有极性的元器件时，应确保极性正确。
    
-   焊接 CMOS 器件时，应采取防静电措施，防止静电损坏器件。
    
-   焊接时间不宜过长，一般不超过 3s，防止元器件过热损坏。
    
-   焊接完成后，应清理焊点周围的助焊剂残留，防止腐蚀 PCB 和元器件。
    

### 6.5 组装工艺

组装工艺是将焊接好的 PCB 板、散热片、风扇、外壳、接线端子等部件组装成完整的开关电源产品的工艺。组装工艺应严格按照装配图和作业指导书进行，确保产品的结构牢固、接线正确、外观良好。

1.  **散热片安装**
    
    ：将开关管、整流二极管、整流桥等发热元器件安装到散热片上。安装时应在元器件与散热片之间涂一层导热硅脂，减小热阻，提高散热效率。导热硅脂的厚度应均匀，不宜过厚，通常为 0.1~0.2mm。用螺丝将元器件固定在散热片上，螺丝的拧紧力矩应适中，避免损坏元器件。
    
2.  **PCB 板安装**
    
    ：将焊接好的 PCB 板安装到电源的外壳或底板上。安装时应使用绝缘垫片和螺丝，确保 PCB 板与外壳之间绝缘良好，避免短路。PCB 板的安装应牢固，无松动现象。
    
3.  **接线**
    
    ：连接输入线、输出线、风扇线、接地线等。接线时应确保接线正确，极性正确，接触良好。输入线和输出线应采用合适线径的导线，确保电流承载能力。接地线应可靠连接到电源的金属外壳，保护人身安全。接线端子应拧紧，防止松动。
    
4.  **风扇安装**
    
    ：对于采用强制风冷的电源，应安装风扇。风扇的安装方向应正确，确保空气流通顺畅。风扇的电源线应连接到 PCB 板的风扇接口，确保风扇正常运转。
    
5.  **外壳组装**
    
    ：将电源的上盖、下盖、面板等部件组装起来。组装时应确保外壳的缝隙均匀，无变形、无划痕。螺丝应拧紧，确保外壳牢固。
    

### 6.6 三防工艺

三防工艺是指对开关电源进行防潮、防霉、防盐雾处理，提高电源在恶劣环境下的可靠性和使用寿命。三防工艺通常采用涂覆和灌封两种方式。

1.  **涂覆工艺**
    
    ：在 PCB 板表面涂覆一层三防漆，形成一层保护膜，防止潮气、霉菌和盐雾的侵蚀。常用的三防漆有丙烯酸酯、聚氨酯、有机硅等。涂覆工艺的流程为：PCB 板清洁→涂覆→固化。
    

-   PCB 板清洁：涂覆前应将 PCB 板表面的灰尘、油污、助焊剂残留等清理干净，确保涂覆质量。
    
-   涂覆：可采用喷涂、刷涂或浸涂的方式进行涂覆。涂覆时应确保三防漆均匀覆盖 PCB 板表面，无漏涂、流挂、气泡等缺陷。对于不需要涂覆的部位（如连接器、电位器、散热片），应提前进行遮蔽。
    
-   固化：涂覆完成后，将 PCB 板放在通风良好的地方自然固化，或放入烘箱中加热固化。固化时间应根据三防漆的类型和固化方式确定。
    

3.  **灌封工艺**
    
    ：将灌封胶灌入电源的外壳内部，将 PCB 板和元器件完全包裹起来，形成一个密封的整体。灌封工艺具有更好的防潮、防霉、防盐雾效果，同时还可以提高电源的抗震性和散热性。常用的灌封胶有环氧树脂、聚氨酯、有机硅等。灌封工艺的流程为：外壳清洁→灌封胶配制→灌封→固化。
    

-   外壳清洁：灌封前应将电源外壳内部的灰尘、油污等清理干净。
    
-   灌封胶配制：按照灌封胶的说明书要求，将 A 胶和 B 胶按比例混合，搅拌均匀，排除气泡。
    
-   灌封：将配制好的灌封胶缓慢灌入电源外壳内部，确保灌封胶完全覆盖 PCB 板和元器件，无气泡、无空隙。
    
-   固化：灌封完成后，将电源放在通风良好的地方自然固化，或放入烘箱中加热固化。固化时间应根据灌封胶的类型和固化方式确定。
    

### 6.7 生产过程质量控制

生产过程质量控制是保证产品质量的关键，应在生产的各个环节设置质量控制点，对产品进行检验和测试，确保不合格品不流入下一道工序。

1.  **来料检验（IQC）**
    
    ：对所有入库的元器件和原材料进行检验，确保符合设计要求。
    
2.  **过程检验（IPQC）**
    
    ：在生产过程中，对各个工序的产品进行检验，如 SMT 贴片检验、波峰焊检验、手工焊接检验、组装检验等。检验项目包括：元器件的型号、规格、极性、位置，焊接质量，组装质量等。
    
3.  **成品检验（FQC）**
    
    ：对组装完成的成品进行全面的检验和测试，包括外观检验、电气性能测试、安全性能测试、EMC 测试等。只有通过成品检验的产品才能入库出厂。
    
4.  **不合格品处理**
    
    ：对于检验中发现的不合格品，应进行标识、隔离和评审，根据不合格的严重程度采取返工、返修、报废等处理措施。同时，应分析不合格的原因，采取纠正和预防措施，防止类似问题再次发生。

## 第七章 开关电源调试与性能测试

##   

开关电源的调试与性能测试是验证电源设计是否符合要求、保证产品质量的关键环节。通过调试可以发现和解决设计和生产中存在的问题，优化电源的性能；通过性能测试可以全面评估电源的电气性能、安全性能、电磁兼容性能和可靠性。

### 7.1 调试前的准备

1.  **仪器设备准备**
    
    ：准备好调试所需的仪器设备，如万用表、示波器、电流探头、电压探头、电子负载、交流电源、直流电源、功率分析仪、示波器隔离变压器等。所有仪器设备都应进行校准，确保测量准确。
    
2.  **安全准备**
    
    ：开关电源调试涉及高压电，存在触电危险，调试前应做好安全防护措施。调试人员应穿戴绝缘手套和绝缘鞋，调试现场应设置警示标志。调试时应有人监护，严禁单人进行高压调试。
    
3.  **电源检查**
    
    ：调试前应对电源进行全面的外观检查和电路检查，确保元器件焊接正确，无虚焊、假焊、连锡、短路等缺陷。检查输入输出接线是否正确，极性是否正确，螺丝是否拧紧。
    
4.  **调试方案准备**
    
    ：根据电源的设计要求和技术指标，制定详细的调试方案，明确调试步骤、调试内容和合格标准。
    

### 7.2 分步调试

开关电源的调试应按照 “先空载后带载、先低压后高压、先控制电路后功率电路” 的原则进行，逐步排查问题，确保调试安全。

#### 7.2.1 控制电路调试

控制电路是开关电源的核心，首先应调试控制电路，确保控制电路正常工作。

1.  **断开功率电路**
    
    ：断开开关管的漏极或源极，使功率电路不工作，避免调试时损坏功率器件。
    
2.  **给控制电路供电**
    
    ：通过外接直流电源给控制电路供电，供电电压应符合控制 IC 的要求。
    
3.  **检查基准电压**
    
    ：用万用表测量基准电压源的输出电压，应符合设计要求，误差在允许范围内。
    
4.  **检查 PWM 输出**
    
    ：用示波器测量 PWM 控制器的输出引脚，应能看到稳定的 PWM 波形，频率和占空比应符合设计要求。调节反馈电压，PWM 占空比应随之变化。
    
5.  **检查保护电路**
    
    ：模拟过压、过流、过温等故障，检查保护电路是否能正常动作，PWM 输出是否能及时关断。
    

#### 7.2.2 功率电路空载调试

控制电路调试正常后，进行功率电路的空载调试。

1.  **恢复功率电路连接**
    
    ：将开关管的漏极或源极连接好，恢复功率电路。
    
2.  **输入低压调试**
    
    ：先给电源输入较低的电压（如额定输入电压的 50%），空载上电。用万用表测量输入滤波电容两端的电压，应正常。用示波器测量开关管的漏源电压波形，应能看到正常的开关波形，无明显的尖峰和振荡。
    
3.  **逐步提高输入电压**
    
    ：逐步提高输入电压到额定输入电压，观察电源的工作情况。测量输出电压，应接近标称输出电压，误差在允许范围内。用示波器测量输出电压纹波，应符合设计要求。
    
4.  **检查变压器和元器件温度**
    
    ：空载运行一段时间后，用手触摸高频变压器、开关管、整流二极管等元器件，温度应正常，无过热现象。
    

#### 7.2.3 功率电路带载调试

空载调试正常后，进行功率电路的带载调试。

1.  **轻载调试**
    
    ：给电源接轻载（如额定负载的 10%），上电运行。测量输出电压，应稳定，负载调整率应符合设计要求。用示波器测量输出电压纹波和开关管漏源电压波形，应正常。
    
2.  **逐步增加负载**
    
    ：逐步增加负载到额定负载，观察电源的工作情况。测量不同负载下的输出电压、负载调整率、线性调整率、效率等参数，应符合设计要求。
    
3.  **满载和过载调试**
    
    ：给电源加额定负载，运行一段时间，检查电源的稳定性和温升。然后逐步增加负载到 1.2 倍额定负载，检查过流保护是否能正常动作。
    
4.  **动态负载调试**
    
    ：使用电子负载的动态负载功能，模拟负载突变，测量输出电压的动态响应，包括过冲 / 下冲幅度和恢复时间，应符合设计要求。
    

### 7.3 性能测试

开关电源的性能测试应按照相关的国家标准和行业标准进行，全面评估电源的各项性能指标。

#### 7.3.1 输入特性测试

1.  **输入电压范围测试**
    
    ：调节输入电压从最小值到最大值，检查电源是否能正常工作，输出电压是否稳定。
    
2.  **输入功率和功率因数测试**
    
    ：使用功率分析仪测量电源在不同输入电压和不同负载下的输入功率和功率因数，应符合设计要求。对于带 PFC 功能的电源，功率因数应≥0.95。
    
3.  **输入电流谐波测试**
    
    ：使用谐波分析仪测量电源的输入电流谐波，应符合 IEC 61000-3-2 标准的要求。
    

#### 7.3.2 输出特性测试

1.  **输出电压精度测试**
    
    ：在额定输入电压和额定负载下，测量输出电压，计算输出电压精度，应符合设计要求。
    
2.  **负载调整率测试**
    
    ：保持输入电压为额定值，调节负载从空载到额定负载，测量输出电压的变化，计算负载调整率，应符合设计要求。
    
3.  **线性调整率测试**
    
    ：保持负载为额定值，调节输入电压在额定范围内变化，测量输出电压的变化，计算线性调整率，应符合设计要求。
    
4.  **输出纹波与噪声测试**
    
    ：使用示波器和电压探头测量输出电压的纹波与噪声，测量时应采用接地弹簧，减小引线电感的影响。纹波与噪声的峰峰值应符合设计要求。
    
5.  **输出电压温度系数测试**
    
    ：将电源放入高低温箱中，在不同的环境温度下测量输出电压，计算输出电压温度系数，应符合设计要求。
    

#### 7.3.3 效率测试

使用功率分析仪测量电源在不同输入电压和不同负载下的输入功率和输出功率，计算效率（效率 = 输出功率 / 输入功率 ×100%），应符合设计要求和相关的能效标准。

#### 7.3.4 保护功能测试

1.  **过压保护测试**
    
    ：缓慢升高输出电压，直到过压保护动作，记录保护动作电压，应符合设计要求。
    
2.  **过流保护测试**
    
    ：缓慢增加输出电流，直到过流保护动作，记录保护动作电流，应符合设计要求。
    
3.  **过温保护测试**
    
    ：用热风枪加热电源内部的温度检测元件，直到过温保护动作，记录保护动作温度，应符合设计要求。
    
4.  **短路保护测试**
    
    ：将输出端短路，检查短路保护是否能正常动作，电源是否能正常启动，无损坏。短路保护解除后，电源应能自动恢复正常工作。
    

#### 7.3.5 动态响应测试

使用电子负载的动态负载功能，设置负载从 10% 额定负载突变到 90% 额定负载，再突变回 10% 额定负载，用示波器测量输出电压的变化，记录过冲 / 下冲幅度和恢复时间，应符合设计要求。

#### 7.3.6 电磁兼容（EMC）测试

EMC 测试包括电磁干扰（EMI）测试和电磁抗扰度（EMS）测试，应在专业的 EMC 实验室进行。

1.  **EMI 测试**
    
    ：测量电源的传导干扰和辐射干扰，应符合 IEC 61000-6-3 和 GB/T 17626 系列标准的要求。
    
2.  **EMS 测试**
    
    ：包括静电放电抗扰度、电快速瞬变脉冲群抗扰度、浪涌抗扰度、射频场感应的传导骚扰抗扰度、工频磁场抗扰度等测试，应符合 IEC 61000-6-2 和 GB/T 17626 系列标准的要求。
    

#### 7.3.7 可靠性测试

可靠性测试是评估电源在规定条件下长期工作的可靠性，主要包括老化测试、高低温测试、温度循环测试、振动测试和冲击测试。

1.  **老化测试**
    
    ：将电源在额定输入电压和额定负载下连续运行 48~72 小时，检查电源的稳定性和温升。老化测试过程中，应定期测量输出电压、电流和温度，记录数据。老化测试结束后，电源应能正常工作，性能无明显下降。
    
2.  **高低温测试**
    
    ：将电源放入高低温箱中，分别在最高工作温度和最低工作温度下运行 2 小时，检查电源是否能正常工作，性能是否符合要求。
    
3.  **温度循环测试**
    
    ：将电源在 - 40℃~+85℃之间进行温度循环测试，循环次数为 10~20 次，每次循环时间为 2~4 小时。测试结束后，检查电源的外观和性能，应无损坏，性能符合要求。
    
4.  **振动测试**
    
    ：将电源固定在振动台上，按照 GB/T 2423.10 标准进行振动测试，振动频率为 10~500Hz，加速度为 1g，振动时间为 2 小时。测试结束后，检查电源的外观和内部结构，应无松动、无损坏，性能符合要求。
    
5.  **冲击测试**
    
    ：将电源固定在冲击台上，按照 GB/T 2423.5 标准进行冲击测试，冲击加速度为 15g，冲击时间为 11ms，冲击次数为 3 次。测试结束后，检查电源的外观和内部结构，应无松动、无损坏，性能符合要求。
    

### 7.4 常见调试问题及解决方法

1.  **电源无输出**

-   可能原因：输入电路故障（如保险丝熔断、整流桥损坏、输入滤波电容短路）、控制电路故障（如控制 IC 损坏、基准电压异常、PWM 无输出）、功率电路故障（如开关管损坏、变压器短路、输出整流二极管损坏）、保护电路误动作。
    
-   解决方法：检查输入电路，更换损坏的元器件；检查控制电路，测量基准电压和 PWM 输出，更换损坏的控制 IC；检查功率电路，测量开关管、整流二极管和变压器的好坏，更换损坏的元器件；检查保护电路，排除故障，解除保护。
    

3.  **输出电压过高**

-   可能原因：反馈电路故障（如分压电阻损坏、TL431 损坏、光耦损坏）、控制电路故障（如 PWM 占空比过大）、变压器匝数比错误。
    
-   解决方法：检查反馈电路，测量分压电阻、TL431 和光耦的好坏，更换损坏的元器件；检查控制电路，调节 PWM 占空比；检查变压器匝数比，重新绕制变压器。
    

5.  **输出电压过低**

-   可能原因：输入电压过低、负载过重、反馈电路故障（如分压电阻阻值变化、TL431 基准电压漂移）、功率电路故障（如开关管导通电阻增大、整流二极管正向压降增大、变压器漏感过大）、保护电路动作。
    
-   解决方法：提高输入电压到额定范围；减小负载到额定值；检查反馈电路，更换损坏的元器件；检查功率电路，更换损坏的开关管和整流二极管，优化变压器设计；检查保护电路，排除故障。
    

7.  **输出纹波过大**

-   可能原因：输出滤波电容容量不足或 ESR 过大、输出电感量不足、开关管和整流二极管的开关速度过快、PCB 布线不合理、接地不良。
    
-   解决方法：增加输出滤波电容的容量，或并联低 ESR 的陶瓷电容；增加输出电感量；在开关管和整流二极管两端并联 RC 缓冲电路；优化 PCB 布局和布线，减小功率回路面积；改善接地设计，减小接地阻抗。
    

9.  **开关管过热**

-   可能原因：开关管选型不当（导通电阻过大、电流裕量不足）、驱动电路故障（驱动电压不足、驱动电流过小）、开关损耗过大（开关频率过高、缓冲电路设计不合理）、散热不良（散热片面积不足、导热硅脂涂抹不均匀）、变压器漏感过大。
    
-   解决方法：更换合适的开关管，留足电流裕量；检查驱动电路，确保驱动电压和电流足够；优化开关频率，设计合理的缓冲电路；增大散热片面积，均匀涂抹导热硅脂；优化变压器设计，减小漏感。

## 第八章 开关电源常见故障分析与维修

##   

开关电源在使用过程中，由于元器件老化、环境因素、人为操作不当等原因，可能会出现各种故障。掌握常见故障的分析方法和维修技巧，可以快速排除故障，恢复电源的正常工作。本章将详细介绍开关电源常见故障的现象、可能原因和维修方法。

### 8.1 故障排查的基本原则和步骤

#### 8.1.1 故障排查基本原则

1.  **先外后内**
    
    ：先检查电源的外部情况，如输入输出接线是否正确、电源开关是否打开、保险丝是否熔断、外壳是否有损坏等，再打开电源外壳检查内部电路。
    
2.  **先静态后动态**
    
    ：先在断电状态下检查元器件的好坏，如用万用表测量电阻、电容、二极管、三极管的阻值，再上电进行动态测试。
    
3.  **先电源后负载**
    
    ：先检查电源本身是否正常，再检查负载是否有故障，避免负载故障损坏电源。
    
4.  **先通病后特殊**
    
    ：先检查开关电源的常见故障点，如保险丝、整流桥、开关管、电解电容等，再检查特殊的故障点。
    
5.  **安全第一**
    
    ：开关电源内部有高压电，维修时应注意安全，断电后应先对高压电容放电，再进行操作。
    

#### 8.1.2 故障排查基本步骤

1.  **了解故障情况**
    
    ：向用户了解故障发生的过程、故障现象和使用环境，如电源是否有异响、异味、冒烟，是否在雷击、电网波动后出现故障，是否过载使用等。
    
2.  **外观检查**
    
    ：打开电源外壳，进行外观检查，查看是否有元器件烧毁、鼓包、漏液、引脚断裂、焊点脱落等现象，是否有焦味、冒烟痕迹。
    
3.  **静态测量**
    
    ：在断电状态下，用万用表测量输入输出端的电阻，检查是否有短路现象。测量关键元器件的阻值，如保险丝、整流桥、开关管、整流二极管、电解电容等，初步判断元器件的好坏。
    
4.  **上电测试**
    
    ：在确保无短路的情况下，给电源通电，进行动态测试。测量输入电压、输出电压、各关键点的电压和波形，分析故障原因。
    
5.  **故障定位与维修**
    
    ：根据测量结果，定位故障点，更换损坏的元器件。
    
6.  **测试验证**
    
    ：维修完成后，对电源进行全面的测试，确保电源性能符合要求，故障已排除。
    

### 8.2 常见故障分析与维修

#### 8.2.1 无输出故障

无输出是开关电源最常见的故障之一，表现为电源通电后，输出端无电压输出。

1.  **输入电路故障**

-   故障现象：保险丝熔断，电源无任何反应。
    
-   可能原因：输入过压、浪涌冲击、整流桥短路、输入滤波电容短路、开关管短路。
    
-   维修方法：更换保险丝，检查整流桥、输入滤波电容、开关管的好坏，更换损坏的元器件。如果保险丝熔断且发黑，说明电源内部有严重短路，应全面检查功率电路，排除短路故障后再更换保险丝。
    

3.  **控制电路故障**

-   故障现象：保险丝完好，输入电压正常，输出无电压，PWM 控制器无输出。
    
-   可能原因：控制 IC 损坏、启动电阻开路、基准电压源损坏、反馈电路故障、保护电路动作。
    
-   维修方法：测量控制 IC 的供电电压，若供电电压正常但无 PWM 输出，更换控制 IC；检查启动电阻是否开路，若开路更换启动电阻；测量基准电压源的输出电压，若异常更换基准电压源；检查反馈电路和保护电路，排除故障。
    

5.  **功率电路故障**

-   故障现象：保险丝熔断或完好，输入电压正常，输出无电压，PWM 控制器有输出。
    
-   可能原因：开关管损坏、高频变压器短路、输出整流二极管损坏、输出电感开路、输出短路。
    
-   维修方法：测量开关管的漏源极电阻，若短路更换开关管；检查高频变压器是否有短路现象，若短路重新绕制变压器；测量输出整流二极管的好坏，若损坏更换二极管；检查输出电感是否开路，若开路更换电感；检查输出端是否短路，排除短路故障。
    

#### 8.2.2 输出电压异常故障

输出电压异常包括输出电压过高、输出电压过低和输出电压波动。

1.  **输出电压过高**

-   故障现象：输出电压远高于标称值，可能导致负载损坏。
    
-   可能原因：反馈电路故障（分压电阻开路、TL431 损坏、光耦损坏）、控制电路故障（PWM 占空比过大）、变压器匝数比错误。
    
-   维修方法：检查反馈电路，测量分压电阻的阻值，若开路更换电阻；测量 TL431 的参考电压和阴极电压，若异常更换 TL431；测量光耦的好坏，若损坏更换光耦；检查控制电路，调节 PWM 占空比；检查变压器匝数比，重新绕制变压器。
    

3.  **输出电压过低**

-   故障现象：输出电压低于标称值，带载能力差。
    
-   可能原因：输入电压过低、负载过重、反馈电路故障（分压电阻阻值变化、TL431 基准电压漂移）、功率电路故障（开关管导通电阻增大、整流二极管正向压降增大、变压器漏感过大）、保护电路动作。
    
-   维修方法：检查输入电压是否在额定范围内；减小负载到额定值；检查反馈电路，更换损坏的元器件；检查功率电路，更换损坏的开关管和整流二极管，优化变压器设计；检查保护电路，排除故障。
    

5.  **输出电压波动**

-   故障现象：输出电压不稳定，上下波动。
    
-   可能原因：输入电压波动、负载波动、反馈电路不稳定、控制电路振荡、输出滤波电容容量衰减、接地不良。
    
-   维修方法：稳定输入电压；减小负载波动；检查反馈电路的补偿网络，优化补偿参数；检查控制电路，排除振荡故障；更换输出滤波电容；改善接地设计。
    

#### 8.2.3 输出纹波过大故障

输出纹波过大表现为输出直流电压中叠加的高频交流分量过大，可能导致负载工作异常。

1.  **可能原因**
    
    ：输出滤波电容容量不足或 ESR 过大、输出电感量不足、开关管和整流二极管的开关速度过快、PCB 布线不合理、接地不良、输入纹波过大。
    
2.  **维修方法**
    
    ：增加输出滤波电容的容量，或并联低 ESR 的陶瓷电容；增加输出电感量；在开关管和整流二极管两端并联 RC 缓冲电路；优化 PCB 布局和布线，减小功率回路面积；改善接地设计，减小接地阻抗；检查输入滤波电路，更换容量衰减的输入滤波电容。
    

#### 8.2.4 过热故障

过热故障表现为电源工作时温度过高，可能导致电源自动关机或损坏。

1.  **可能原因**
    
    ：负载过重、环境温度过高、散热不良（散热片面积不足、风扇损坏、通风口堵塞）、开关管和整流二极管损耗过大、变压器设计不合理、电源内部短路。
    
2.  **维修方法**
    
    ：减小负载到额定值；降低环境温度；清理通风口，更换损坏的风扇，增大散热片面积；更换损耗过大的开关管和整流二极管；优化变压器设计，减小变压器损耗；检查电源内部是否有短路现象，排除短路故障。
    

#### 8.2.5 保护误动作故障

保护误动作表现为电源在正常工作条件下，保护电路频繁动作，切断输出。

1.  **可能原因**
    
    ：保护电路参数设置不当、采样电路故障、干扰导致保护电路误触发、元器件老化导致参数漂移。
    
2.  **维修方法**
    
    ：重新调整保护电路的参数，使其符合设计要求；检查采样电路，更换损坏的采样电阻和电容；优化 PCB 布局和布线，抑制干扰；更换老化的元器件。
    

#### 8.2.6 异响故障

异响故障表现为电源工作时发出 “吱吱”、“嗡嗡” 等异常声音。

1.  **可能原因**
    
    ：高频变压器磁芯松动、电感磁芯松动、开关管和整流二极管的开关噪声、风扇故障、元器件接触不良。
    
2.  **维修方法**
    
    ：紧固高频变压器和电感的磁芯，在磁芯缝隙处涂胶固定；在开关管和整流二极管两端并联 RC 缓冲电路，抑制开关噪声；更换损坏的风扇；检查元器件的焊接情况，重新焊接松动的焊点。
    

### 8.3 维修注意事项

1.  **安全注意事项**

-   维修前应断开电源输入，对高压电容进行放电，防止触电。
    
-   维修时应穿戴绝缘手套和绝缘鞋，使用绝缘工具。
    
-   通电测试时，应有人监护，严禁用手触摸高压部位。
    
-   维修完成后，应检查电源的绝缘性能，确保安全。
    

3.  **元器件更换注意事项**

-   更换元器件时，应使用与原型号相同或参数兼容的元器件，不得随意更换参数不同的元器件。
    
-   焊接元器件时，应注意焊接时间和温度，防止元器件过热损坏。
    
-   有极性的元器件（如电解电容、二极管、三极管）应确保极性正确，不得反接。
    

5.  **维修记录**
    
    ：维修完成后，应做好维修记录，记录故障现象、故障原因、维修方法和更换的元器件，便于后续的维护和故障分析。

## 第九章 开关电源安全规范与操作注意事项

##   

开关电源涉及高压电，若使用不当，可能会导致触电、火灾等安全事故。因此，必须严格遵守安全规范和操作注意事项，确保人身和设备安全。

### 9.1 电气安全基础知识

1.  **触电危害**
    
    ：电流通过人体会造成触电伤害，伤害程度与电流大小、电流路径、通电时间和电流频率有关。1mA 的电流会使人产生麻感，10mA 的电流会使人难以摆脱电源，50mA 的电流会导致心室颤动，危及生命。
    
2.  **高压防护**
    
    ：开关电源内部的输入整流滤波电容两端电压可达 310V 以上，属于高压电，接触后会导致触电。维修和调试时，必须先断开电源输入，对高压电容进行放电，再进行操作。
    
3.  **接地保护**
    
    ：开关电源的金属外壳必须可靠接地，防止外壳带电导致触电。接地电阻应不大于 4Ω。
    
4.  **绝缘要求**
    
    ：开关电源的输入与输出、输入与外壳、输出与外壳之间必须有足够的绝缘强度，符合安全标准要求。绝缘电阻应不小于 100MΩ，抗电强度应符合 GB 4943.1-2022 标准的要求。
    

### 9.2 生产操作安全

1.  **焊接安全**

-   焊接时应佩戴防护眼镜，防止焊锡飞溅烫伤眼睛。
    
-   电烙铁使用时应放在烙铁架上，不得随意放置，防止烫伤和火灾。
    
-   焊接时应保持通风良好，避免吸入焊锡烟雾。
    
-   焊接完成后，应及时关闭电烙铁电源，防止长时间通电损坏电烙铁和引发火灾。
    

3.  **调试安全**

-   调试前应检查仪器设备的接地是否良好，确保安全。
    
-   高压调试时，应设置警示标志，禁止无关人员进入调试现场。
    
-   调试时应单手操作，另一只手放在背后或口袋里，防止电流通过心脏。
    
-   调试过程中，若发现异常现象（如异响、异味、冒烟），应立即断开电源，停止调试，排除故障后再继续。
    

5.  **防静电安全**

-   生产和维修人员应佩戴防静电手环，穿防静电服和防静电鞋，防止静电损坏 CMOS 器件。
    
-   工作台上应铺设防静电垫，防静电垫应可靠接地。
    
-   元器件应存放在防静电包装中，运输和存放时应避免静电产生。
    

7.  **机械安全**

-   使用剪脚机、贴片机、波峰焊机等设备时，应严格按照操作规程进行操作，防止机械伤害。
    
-   设备运行时，不得将手伸入设备内部，不得打开设备的安全防护罩。
    
-   设备出现故障时，应立即停机，切断电源，由专业人员进行维修。
    

### 9.3 维修操作安全

1.  **断电放电**
    
    ：维修前必须断开电源输入，拔下电源插头。然后用螺丝刀的绝缘柄接触高压电容的引脚，对高压电容进行放电，放电时间不少于 3 秒。
    
2.  **绝缘防护**
    
    ：维修时应穿戴绝缘手套和绝缘鞋，使用绝缘工具。不得用手直接触摸高压部位，不得用湿手操作电器。
    
3.  **通电测试**
    
    ：通电测试时，应先接好负载，再接通电源。不得在无负载的情况下长时间通电，防止电源损坏。测试过程中，应密切观察电源的工作情况，若发现异常，立即断开电源。
    
4.  **维修环境**
    
    ：维修现场应保持整洁、干燥，通风良好。不得在潮湿、易燃易爆的环境中进行维修操作。
    
5.  **禁止带电维修**
    
    ：除非特殊情况，禁止带电维修开关电源。若必须带电维修，应有专人监护，采取严格的安全防护措施。
    

### 9.4 现场应用安全

1.  **安装安全**

-   开关电源应安装在通风良好、干燥、无腐蚀性气体的环境中，远离热源和易燃易爆物品。
    
-   安装时应确保电源的散热面朝向通风方向，散热片与周围物体之间应留有足够的间隙，便于空气流通。
    
-   电源的输入输出接线应牢固，接触良好，不得松动。输入线和输出线应采用合适线径的导线，确保电流承载能力。
    
-   电源的金属外壳必须可靠接地，接地电阻应不大于 4Ω。
    

3.  **使用安全**

-   使用前应检查电源的输入电压是否与电网电压一致，防止因电压不符损坏电源。
    
-   不得过载使用电源，负载电流不得超过电源的额定输出电流。
    
-   不得将输出端短路，防止电源损坏。
    
-   电源工作时，不得打开外壳，不得触摸内部电路，防止触电。
    
-   若电源出现异响、异味、冒烟等异常现象，应立即断开电源，停止使用，由专业人员进行维修。
    

5.  **维护安全**

-   定期清理电源表面和散热片上的灰尘，保持散热良好。
    
-   定期检查电源的接线和接地是否牢固，有无松动和腐蚀现象。
    
-   定期检查电源的输出电压和电流，确保电源正常工作。
    
-   电源长期不用时，应断开电源输入，存放在干燥、通风的环境中。
    

### 9.5 相关安全标准

开关电源的设计、生产和使用必须符合相关的安全标准，主要包括：

1.  GB 4943.1-2022《信息技术设备 安全 第 1 部分：通用要求》
    
2.  GB 7251.1-2013《低压成套开关设备和控制设备 第 1 部分：总则》
    
3.  IEC 60950-1:2005《信息技术设备 安全 第 1 部分：通用要求》
    
4.  UL 60950-1:2007《信息技术设备 安全 第 1 部分：通用要求》
    
5.  EN 60950-1:2006《信息技术设备 安全 第 1 部分：通用要求》
    

### 9.6 环保要求

开关电源的生产和使用应符合环保要求，减少对环境的污染。

1.  开关电源的元器件应符合 RoHS 指令要求，不得含有铅、汞、镉、六价铬、多溴联苯、多溴二苯醚等有害物质。
    
2.  生产过程中产生的废水、废气、废渣应进行处理，达标后排放。
    
3.  废弃的开关电源应进行回收处理，不得随意丢弃，防止有害物质污染环境。

## 第十章 开关电源的应用与发展趋势

##   

### 10.1 开关电源的应用领域

开关电源凭借其高效率、小体积、轻重量等优点，已广泛应用于国民经济的各个领域，成为电子设备不可或缺的组成部分。

1.  **消费电子领域**
    
    ：手机充电器、笔记本电脑适配器、台式电脑电源、电视机、机顶盒、音响、小家电等。消费电子领域对开关电源的要求是小体积、高效率、低成本、低待机功耗。
    
2.  **工业控制领域**
    
    ：PLC、变频器、伺服驱动器、工业机器人、仪器仪表、工业直流电源等。工业控制领域对开关电源的要求是高可靠性、高稳定性、宽输入电压范围、抗干扰能力强。
    
3.  **通信领域**
    
    ：通信基站电源、交换机电源、路由器电源、光传输设备电源等。通信领域对开关电源的要求是高可靠性、高效率、高功率密度、远程监控功能。
    
4.  **新能源领域**
    
    ：光伏逆变器、风力发电变流器、电动汽车充电桩、电动汽车车载充电机、储能变流器等。新能源领域对开关电源的要求是高效率、高功率密度、高可靠性、宽输入电压范围。
    
5.  **医疗领域**
    
    ：医疗设备电源、监护仪电源、呼吸机电源、核磁共振设备电源等。医疗领域对开关电源的要求是高安全性、高可靠性、低纹波噪声、符合医疗安全标准。
    
6.  **航空航天领域**
    
    ：飞机电源、卫星电源、航天器电源等。航空航天领域对开关电源的要求是高可靠性、高效率、轻重量、抗辐射能力强。
    

### 10.2 开关电源的发展趋势

随着电力电子技术、半导体技术和控制技术的不断进步，开关电源技术正朝着高频化、高效率、高功率密度、数字化、智能化、绿色化的方向发展。

1.  **高频化**
    
    ：提高开关频率可以减小磁性元件和电容的体积和重量，提高功率密度。宽禁带半导体器件（GaN、SiC）的应用，将开关频率从几十 kHz 提升到几 MHz，实现了开关电源的小型化和轻量化。
    
2.  **高效率**
    
    ：提高电源效率可以减少电能损耗，节约能源。软开关技术、同步整流技术、宽禁带半导体器件的应用，使开关电源的效率不断提高，目前 LLC 谐振电源的效率可达 96% 以上，GaN 电源的效率可达 99% 以上。
    
3.  **高功率密度**
    
    ：高功率密度是开关电源的重要发展方向，通过高频化、集成化、模块化设计，可以提高电源的功率密度。目前，服务器电源的功率密度已达到 100W/in³ 以上，GaN 快充的功率密度已达到 20W/in³ 以上。
    
4.  **数字化**
    
    ：数字电源技术采用 DSP 或 MCU 实现控制功能，与传统模拟电源相比，具有控制精度高、动态响应快、保护功能完善、支持远程监控和在线升级等优点。数字电源技术已广泛应用于服务器电源、通信电源、新能源电源等领域。
    
5.  **智能化**
    
    ：智能化是开关电源的发展趋势，通过集成传感器、微控制器和通信接口，实现电源的自我诊断、自我保护、自适应调节和智能管理。智能电源可以根据负载情况自动调节工作模式，提高效率和可靠性；可以通过网络实现远程监控和故障报警，便于维护和管理。
    
6.  **绿色化**
    
    ：绿色化是开关电源的发展要求，包括低待机功耗、高功率因数、低谐波污染、符合环保标准等。各国都制定了严格的能效标准和环保标准，推动开关电源向绿色化方向发展。例如，欧盟 CoC V5 标准要求电源的待机功耗≤0.3W，功率因数≥0.95。
    

### 10.3 开关电源新技术

1.  **宽禁带半导体技术**
    
    ：GaN 和 SiC 器件具有优异的性能，是未来功率器件的发展方向。GaN 器件适用于中低压、高频、小功率场景，SiC 器件适用于高压、高频、大功率场景。随着宽禁带半导体技术的不断成熟和成本的不断降低，将逐步替代传统硅基器件，推动开关电源技术的革新。
    
2.  **数字电源技术**
    
    ：数字电源技术将不断发展，集成更多的功能，如人工智能、机器学习等，实现电源的智能控制和优化管理。数字电源的成本将不断降低，应用领域将不断扩大。
    
3.  **集成电源技术**
    
    ：集成电源技术将功率器件、驱动电路、控制电路、保护电路等集成在一个芯片或模块中，实现电源的小型化和高可靠性。集成电源包括电源管理 IC（PMIC）、功率模块（IPM）、系统级封装（SiP）电源等。
    
4.  **无线电能传输技术**
    
    ：无线电能传输技术可以实现电能的无线传输，避免了电源线的束缚，具有方便、安全、灵活等优点。无线电能传输技术已应用于手机、电动汽车等领域，未来将在更多领域得到应用。
    
5.  **能量收集技术**
    
    ：能量收集技术可以收集环境中的微弱能量（如太阳能、热能、机械能、射频能等），转换为电能，为低功耗电子设备供电。能量收集技术与开关电源技术相结合，可以实现电子设备的自供电，延长设备的使用寿命。
    

### 10.4 开关电源行业面临的挑战与机遇

1.  **挑战**

-   能效标准和环保标准不断提高，对电源的效率、待机功耗、功率因数、谐波污染等提出了更高的要求。
    
-   市场竞争日益激烈，价格压力不断增大，对企业的成本控制和技术创新能力提出了更高的要求。
    
-   核心技术和关键元器件仍依赖进口，如高端控制 IC、宽禁带半导体器件等，制约了行业的发展。
    

3.  **机遇**

-   新能源、电动汽车、5G 通信、人工智能等新兴产业的快速发展，为开关电源行业带来了巨大的市场需求。
    
-   国家政策的支持，如 “双碳” 目标、新能源汽车产业发展规划等，推动了开关电源行业的发展。
    
-   技术创新不断涌现，如宽禁带半导体技术、数字电源技术、集成电源技术等，为行业的发展提供了技术支撑。
    

总之，开关电源技术作为电力电子技术的重要组成部分，在国民经济中发挥着重要的作用。随着技术的不断进步和市场需求的不断增长，开关电源行业将迎来更加广阔的发展前景。
