# 高光谱小目标检测的基本原理


> 原文地址: [https://mp.weixin.qq.com/s/zpErUvjJnkjOy9nLtgQdFA](https://mp.weixin.qq.com/s/zpErUvjJnkjOy9nLtgQdFA)

在[“约束能量最小化（CEM）”](https://mp.weixin.qq.com/s?__biz=Mzk4ODA1MDUyOQ==&mid=2247484056&idx=1&sn=ba00209b50dff7d533b2c23efccda5bc&scene=21#wechat_redirect)中我们知道，对于图像中的感兴趣小目标，基于混合像元分析方法和基于CEM算法本质上都是寻找一个滤波向量，并将图像中的所有像元跟该向量进行内积运算，从而得到感兴趣目标的检测结果。然而，出人意料的是，基于CEM算法的目标检测仅仅利用了目标的光谱信息，其检测结果却明显优于利用所有端元信息的混合像元分析方法。这里面究竟包含着什么未解之谜呢？接下来，我们将对此现象展开深入探讨。

我们知道，目标检测的核心在于如何衡量光谱之间的相似性。而光谱相似性的衡量，主要取决于两个因素：数据所处的空间结构以及数据在空间中的分布结构。其中，数据所处的空间结构决定了数据之间相似性度量的工具包。例如，在线性空间中，元素只能进行加减和数乘运算，而无法直接进行比较，因此，元素之间的相似性就无从谈起。为了在线性空间中比较两个元素的相似性，我们需要为线性空间赋予新的代数结构，比如内积。一旦在线性空间中定义了内积，我们就可以通过内积来表征元素之间的相似关系。进一步地，通过内积，我们还可以定义距离、角度、相关系数等多种相似性指标。

在具备了元素相似性度量的工具包后，接下来的任务是如何选择最合适的工具来检测感兴趣的目标。这一选择依赖于我们对数据分布的理解。就像量体裁衣，只有根据数据的具体分布特征，为其量身定制检测方法，才能有的放矢，达到最佳效果。

接下来，我们分析一下包含小目标的数据，在光谱空间中的分布结构。首先，感兴趣目标通常在光谱上与其他背景像元存在差异，这是小目标能够有效检测的物理基础；其次，在线性混合模型的假设前提下，图像中的所有像元在光谱空间中都分布在一个单形体内，小目标端元与其他背景端元分别对应于单形体中的各个顶点，这是小目标检测的几何结构或几何基础；最后，小目标在图像中往往只占据少量像元，甚至以亚像元的形式存在。在光谱空间中，它们通常分布在非主成分方向，并游离于大的背景云团之外，这是小目标检测的统计结构或统计基础（见图1）。

图1. 包含小目标的数据分布的统计结构

在[“高光谱图像小目标检测国内首个成功案例”](https://mp.weixin.qq.com/s?__biz=Mzk4ODA1MDUyOQ==&mid=2247483980&idx=1&sn=fc9d63a7dbc085fceaffc084a26ca6d1&scene=21#wechat_redirect)中，我们已经给出了基于数据分布的单形体几何结构下感兴趣目标的检测结果。接下来，我们将从数据分布的统计结构角度，对小目标检测进行深入分析。

从图1所示的数据分布的统计结构示意图可以看出，感兴趣的目标游离于背景云团之外。仍以包含小目标的西安高光谱数据为例，如果我们直接使用某个相似性度量工具（例如内积）对其中的感兴趣目标进行目标检测，则可以得到图2中的检测结果。从图2可以看出，目标在检测结果中并未被明显突显。究其原因，主要有两点：其一，内积算子同时考虑了模长和角度，因此，一些模长较大的像元（比如图像中的亮目标），尤其是主成分方向模长较大的像元，可能会产生较高的滤波输出；其二，小目标虽然游离于背景之外，但与其中某些背景像元的距离非常接近，导致在目标检测结果中，小目标与这些背景像元往往难以区分。

![](高光谱小目标检测的基本原理_images/img_001_42382f161d77.png)

图2. 直接基于内积的目标检测结果

为了缓解直接内积法所存在的两个问题，我们可以考虑在目标检测之前，首先调整数据结构，以实现以下两个目标：其一，通过减小数据在主成分方向的方差，降低该方向上模长较大像元的高输出问题；其二，通过增加数据在非主成分方向的方差，增强目标与相似背景像元之间的物理分离。

那么，如何具体实现这两个目标呢？幸运的是，有一个操作可以同时达到这两个目标，这个操作就是经典的数据白化。所谓数据白化，就是将一个白化算子作用于数据，使其在各个方向上的方差都相等。关于数据白化的详细内容，我们将在后续的推文中专门介绍，接下来直接展示一下数据白化的效果。

对于图1中的示意图，经过数据白化处理后，数据的分布将大致呈现图3的效果。此时，小目标和背景在物理上更容易区分，简单的内积算子即可有效地将目标和背景分离。图4展示了西安高光谱数据白化后内积的效果图，果不其然，感兴趣目标被成功检测！

有趣的是，可以证明，CEM正是白化后的内积（感兴趣的读者可以尝试推导这一点）。也就是说，表面上，CEM算子只利用了感兴趣目标的光谱信息，但实际上，它还充分利用了数据分布的统计信息。在CEM目标检测中，它首先通过数据白化改变了数据在光谱空间中的分布结构，使得小目标与背景像元在物理上更容易区分。随后，借助简单的度量手段（如内积），小目标便能够被有效检测出来。

事实上，对于白化后的数据，我们可以通过距离、角度、相关系数等其他手段，轻松地将目标和背景有效区分开来。换句话说，高光谱图像小目标检测的关键不在于具体的度量手段，而在于数据分布结构的白化。
