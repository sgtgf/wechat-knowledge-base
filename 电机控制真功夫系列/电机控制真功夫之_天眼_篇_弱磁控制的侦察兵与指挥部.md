你不能等撞上去了再想办法！你必须在离城墙还有一段距离的时候，就下令部队提前调整阵型，开始“破城”作业。

那么问题来了：

1.  你怎么知道离墙还有多远？
    
2.  你的“破城”力度（弱磁电流）应该给多大？
    

这两个问题，就是我们这篇文章要解决的，也就是**“侦察兵”**和**“指挥部”**的使命。现在，让我们深入代码`pm.c`中的`pm_loop_current()`函数，把他们揪出来！

```
static void pm_loop_current(pmc_t *pm)
```

#### 第一部分：“侦察兵”的天眼 —— 从`pm->vsi_DC`到`eDC`

我们的“侦察兵”部队，它的核心装备就是“天眼”——变量 **`pm->vsi_DC`**。这个变量到底是什么？

我们使用代码编辑器的“跳转到定义”功能，一路追查，会发现它的源头在 **`pm_voltage`** 函数里：

```
void pm_voltage(pmc_t *pm, float uX, float uY)
```

-   **`uDC = m_hypotf(uX, uY)`**
    
    这里的`uX`和`uY`是经过归一化的dq轴电压指令（除以了母线电压 `Udc`）。所以，`uDC`代表的是**当前期望输出的电压矢量 `|Us|` 占母线电压 `Udc` 的比例**。
    
-   **`pm->k_EMAX`**
    
    这个常量代表了SVPWM能输出的最大不失真圆上的电压幅值占母线电压的比例。对于三相系统，这个值是 `1/√3 ≈ 0.577`（基于恒幅值变换）或者是`2/3 * 1/√3`（基于恒功率变换）。
    
-   **`pm->vsi_DC = uDC / pm->k_EMAX;`**
    
    **【划重点！】** 这就是“天眼”的原理！它计算的，是**当前期望输出的电压幅值，占SVPWM理论上能输出的最大电压幅值的比例！**
    

-   如果`vsi_DC` = 0.5，说明你的电压才用了一半，离墙还远着呢。
    
-   如果`vsi_DC` = 0.99，说明你几乎已经把SVPWM的“油门”踩到底了，马上就要撞墙了！
    
-   这个`vsi_DC`，就是我们常说的**调制比 (Modulation Ratio)**。
    

好，现在“侦察兵”拿到了`vsi_DC`这个核心情报，他要把它翻译成指挥部能听懂的“军情汇报”—— **`eDC`**。

```
eDC = (1.f - pm->vsi_DC) * pm->const_fb_U;
```

这句代码的含义，简直就是艺术！

-   **`(1.f - pm->vsi_DC)`**
    
    这就是“离撞墙还有百分之多少的距离”。如果`vsi_DC`是0.99，那这个值就是0.01，代表还有1%的裕量。
    
-   **`* pm->const_fb_U`**
    
    把这个百分比，乘以当前的实际母线电压。
    
-   **`eDC`**
    
    最终得到的，就是**当前逆变器还剩下多少伏的电压潜力没有被使用！** 这就是我们宝贵的**“电压裕量”** ！
    

当电机转速升高，电流环为了维持电流，会不断要求更高的电压，`vsi_DC`就会逼近1.0，`eDC`就会从一个正值，慢慢减小，逼近0，甚至变成负数（代表理论需要的电压已经超过了实际能给的）。

“侦察兵”的任务，圆满完成！他为指挥部提供了最精准、最实时的战场情报！

#### 第二部分：“指挥部”的决断 —— 从`eDC`到`pm->weak_track_D`

指挥部拿到了“电压裕量”`eDC`这份十万火急的情报，现在必须做出决断。

```
pm->weak_track_D += eDC * pm->weak_gain_EU;
```

-   **`pm->weak_track_D`**
    
    这是一个**状态变量**，它代表了当前累积的弱磁电流指令。它就像一个水桶。
    
-   **`eDC`**
    
    这是输入，代表“水流”。当`eDC > 0`（电压有富余），水龙头是关的（或者说水流很小，取决于具体的PI实现，这里简化为只看I）。当`eDC < 0`（电压不够了），就打开水龙头，开始往水桶里“灌负水”。
    
-   **`pm->weak_gain_EU`**
    
    这是**积分增益 `Ki`**！它代表“水龙头开多大”。增益越大，电压越不够，负`id`的累积速度就越快，弱磁响应就越猛。
    

**这是一个典型的积分控制器！** 为什么不用完整的PI？因为在这里，**P环节的意义不大**。我们不关心“这一次”电压差了多少，我们关心的是“只要电压还差着，就得持续增加负id，直到它不差为止”。积分环节的“记忆效应”和“无静差”特性，完美地满足了这个需求。

**它的工作流程，就像一个自动调温的空调：**

1.  **初始状态**
    
    `vsi_DC`很小, `eDC`是正数。但由于 `pm->weak_track_D = (pm->weak_track_D > iMAX) ? iMAX : (pm->weak_track_D < iREV) ? iREV : pm->weak_track_D;` 这个限幅，`weak_track_D` 被牢牢地按在0（这个0是通过iMAX = 0.f实现的），不产生任何弱磁作用。
    
2.  **逼近弱磁点**
    
    转速升高，`vsi_DC` → 1, `eDC` → 0。一切风平浪静。
    
3.  **进入弱磁区**
    
    `vsi_DC` 试图超过1.0, `eDC` 变成一个负数！
    
4.  **积分器启动**
    
    `pm->weak_track_D` 开始累积负值。
    
5.  **弱磁生效**
    
    `track_D` 被加上了这个负的`weak_track_D`，总磁链减弱，BEMF下降。
    
6.  **建立平衡**
    
    BEMF的下降，使得电流环不再需要那么高的电压，`vsi_DC`回落到1.0附近，`eDC`也回到0附近。
    
7.  **动态稳定**
    
    此时，`eDC`在0附近微小波动，积分器`pm->weak_track_D`也就不再大幅变化，稳定在一个**恰到好处**的负值上，使得系统在当前这个高速下，电压刚好够用！
    

最后，那句限幅代码，则是“军法”的体现：

```
pm->weak_track_D = (pm->weak_track_D > 0.f) ? 0.f : (pm->weak_track_D < -pm->weak_maximal) ? -pm->weak_maximal : pm->weak_track_D;
```

它保证了弱磁电流只可能是负的，并且不会超过一个预设的最大值`pm->weak_maximal`，防止电流过大烧毁电机。
