## 2）矩阵乘法的三个等价理解（都对应同一个 y=Ax）

### 视角 A：**行·列（点积）= 输出每一行**

把 A 看成由 m 行组成：

![](https://mmbiz.qpic.cn/mmbiz_png/sVzeakRooctw8bbp0N1jl8vVxrCV0Y8PwwfjicKEiblbOPWe5bqrKC3KDNsfWExTfdZ3U0u3RdIcSCVk8NplEvJRlHKWicSae8aDicSQkIAu3aA/640?wx_fmt=png&from=appmsg)

那么输出 y 的第 i 个分量就是：

![](https://mmbiz.qpic.cn/mmbiz_png/sVzeakRoocvgMWGfPg3ItwKGodHTFHiaoKWJ68TdafU2qTgkhtmMzpwFWfDrgzGuKPMsvEtg7jdIicsJbpWE6tgz1ylbOLOdiculRrpRN9ZJwU/640?wx_fmt=png&from=appmsg)

也就是：**每一行和 x 做一次点积，得到一个标量；做 m 次得到 m 维的 y**。

  

* * *

### 视角 B：**列的线性组合（最直观）**

把 A 按列拆开：

![](https://mmbiz.qpic.cn/sz_mmbiz_png/sVzeakRoocses7ek05pviax9XiaHlB4PjKINyLSPuJyRnZhvkqrklAghKoOfb0fuOb6feiaTofMWfgFsuvz8rOIIRDAKfSP1lMe1NHoiaqq7RVw/640?wx_fmt=png&from=appmsg)

把 x 写成分量 ![](https://mmbiz.qpic.cn/sz_mmbiz_png/sVzeakRoocv7HDQIWA8BNiaF5eFSLd3FXAkWicrZmETDalQwGnXyyYhcXMGnd4kda3iabibjicp5YK35XibN4tiamia5D1tCHFAFXgw4aqq7e7Mq6zA/640?wx_fmt=png&from=appmsg)，则

![](https://mmbiz.qpic.cn/mmbiz_png/sVzeakRoocuS68y4QK1DC5r6FfNCxhAfe6AFjkeXgpYHx0dnckd5icR1Q5Y9vz6Z5dmClp5v3TFDmuLXlxQABWHZ1XQtibqFtNmWiarmNeYmtA/640?wx_fmt=png&from=appmsg)

这句话非常关键：

> **矩阵乘向量 = 用 x 的各个分量当系数，把 A 的各列加权相加。**

所以 A 的每一列都像一个“输出方向的基向量/特征图”，x 决定你把这些列混合成什么样的 y。

  

* * *

### 视角 C：**函数/变换：线性映射**

图中两块“斜着的平面”写着 ![](https://mmbiz.qpic.cn/sz_mmbiz_png/sVzeakRoocv9UtIEXcpIUmr0OgMFv13LZymlicsCDMGiarvnqPKjNEzYAt3Gf7p6GBvFCibRLGTQAkubicGYzEwTZH0XcjicXfwCkZ8Ys0kibMGEE/640?wx_fmt=png&from=appmsg) 和 ![](https://mmbiz.qpic.cn/sz_mmbiz_png/sVzeakRoocv3ddlHvR7a5VYFC8YJ9uJ9NcfGlqETVayzZrOkMHJPgBrYicYP5ErLMkzRqqsZOmMGDuM2aviaDkRwJflaBWBLL9SUZhJG9NPrU/640?wx_fmt=png&from=appmsg)，强调的是：

-   输入空间的点 x
    
-   经过 A 这个规则
    
-   变成输出空间的点 y
    

而且是“线性”的：满足

![](https://mmbiz.qpic.cn/sz_mmbiz_png/sVzeakRoocudpGl5HQH3jRSvJYibKcibsiaVrVjuAwedmpaEdF1rSLgpKcQ0GQEMFRxyCIAaicfLXBfBXk2N0mou5pXuVrJxkfwvyoaEewmFSgs/640?wx_fmt=png&from=appmsg)

这就是为什么矩阵能表示：旋转、缩放、剪切、投影、把 2D 嵌到 3D、把高维压到低维……（取决于 m,p 和 A 的结构）。

> **矩阵乘法 y=Ax 的几何意义：线性变换把“整个空间里的所有向量/点”一起搬家；而你只要看清楚它把三个**基向量 e1,e2,e3** 变成了什么，就等于看清了整个变换。**

## 2）几何上到底发生了什么？

可以把左边那个小彩色立方体当成**“单位立方体”**（或者一小块网格）。线性变换会把它变成一个平行六面体：

-   列向量 ![](https://mmbiz.qpic.cn/sz_mmbiz_png/sVzeakRoocuItS7UzTEI08ZRlqqZnor9X5ib6vXpVQTnjcCVJr46rhmrslJ5Fia9Qa4hBJ4wxC4SSI6c3X4UVOJCaDfug4lKhSWvicdRmLuLzA/640?wx_fmt=png&from=appmsg) ：就是变换后新的三条**“坐标轴方向”**（不一定互相垂直）。
    
-   单位立方体的 8 个顶点会被一起送到新位置，所以整体形状被拉伸/旋转/剪切/翻转。
    

> 记忆法：**列 = 新轴**，**立方体 = 被变形的空间小块**。

## 4）一眼看懂矩阵几何意义的“快法”

给你一个非常实用的流程（和图中间那列完全一致）：

1.  看列向量：第 1、2、3 列分别是 ![](https://mmbiz.qpic.cn/sz_mmbiz_png/sVzeakRoocvLv2qhfpORfrzbPsWYy4l27WhY409iaibBZmLqYomP6zp9Abiae5icWKnwZBhbJAN7WQjCkH0h1clticn6Z7dBhSrS6M1kmPLv6kyM/640?wx_fmt=png&from=appmsg) 
    
2.  判断三根新轴：长度（缩放）、方向（旋转/反射）、是否倾斜（剪切）
    
3.  判断体积与朝向：看 det⁡(A)
    

-   ∣det⁡∣>1：体积放大；∣det⁡∣<1：体积缩小
    
-   det⁡<0：发生镜像（朝向翻转）
    
      
    

我们继续把**矩阵乘法的几何视角**讲得更“能一眼看出来”。

## 6）矩阵乘矩阵 BA：为什么是“先 A 后 B”？

这是几何里最关键的一条：

![](https://mmbiz.qpic.cn/mmbiz_png/sVzeakRoocuuibdrHibh709Efz2hIicCMGHAWPpdSYc0aJRajuJXkHAwzZDWjjrjqhrlpBlIrEI4UnkxdecBx8vZJtP3QJAmK3vNRg8w2b5mDQ/640?wx_fmt=png&from=appmsg)

-   先用 A 把 x 从原空间变到中间形状
    
-   再用 B 在新形状上继续变
    

这也是为什么线性变换的“组合”用乘法表示。

## 7）det⁡(A) 的几何意义：体积缩放 + 是否翻面

你已经看到：

-   均匀缩放 2 倍：det⁡=8
    
-   镜像：det⁡=−1
    
-   剪切常常：det⁡=1
    

更通用地：

-   ∣det⁡(A)∣ = **体积缩放倍数**（3D 是体积，2D 是面积）
    
-   det⁡(A)>0：保持朝向（右手系还是右手系）
    
-   det⁡(A)<0：发生镜像，朝向翻转（右手系变左手系）
    

  

一个非常实用的“肉眼判断”：

-   三根列向量越“张得开”，∣det⁡∣ 越大
    
-   三根列向量越“挤到一个平面里”，∣det⁡∣ 越接近 0
    
-   如果三根列向量共面/共线，det⁡=0：体积被压扁成 0（不可逆）

## 8）秩（rank）与“压扁”：从 3D 变 2D/1D/0D 的几何解释

**秩 = 变换后能留下的维度**（输出子空间的维数）。

在 3D 中：

-   rank = 3：立方体变成某个“有体积”的平行六面体（det⁡≠0）
    
-   rank = 2：立方体被压成一个平行四边形“薄片”（体积 0）
    
-   rank = 1：压成一条线段
    
-   rank = 0：全变到原点
    

  

从列视角看最直观：

-   rank 就是 ![](https://mmbiz.qpic.cn/sz_mmbiz_png/sVzeakRoocticPxWjTibu6jAWt71wr0BE11vO9FPTd0xdNNoYNHbE3IjrWS4greplT31KCCmXEpGZokGH2icjqyKqfypKnwUFu5KLJIhVoU69g/640?wx_fmt=png&from=appmsg) 里**线性无关**的数量
    

-   三列不共面 → rank 3
    
-   三列共面但不共线 → rank 2
    
-   三列共线 → rank 1

## 9）当 m≠p：图一那种“从 p 维到 m 维”怎么理解？

这是图1  ![](https://mmbiz.qpic.cn/mmbiz_png/sVzeakRoocserLHuLibLIef7pMh6w9JrQfFrkDmxBgUK6YW83dy2n8rW3Nic15xL3Fc9Hjy4TxicBCT6JE5kOibicwAE5RgzX8vicoV7ib6SPY2t1c/640?wx_fmt=png&from=appmsg) 的延伸。

### (9.1)  m>p：升维（embedding）

比如 ![](https://mmbiz.qpic.cn/mmbiz_png/sVzeakRoocsKZiajib4EVgmvia48T9OAYWcKjZ576S0VCJ8pMC05399vZ2m8PTgRZ7ibJryyiaDedHV5vjTibK2y3YIEb1HXyx7wDBA3keJthtA9s/640?wx_fmt=png&from=appmsg)。几何上是：

-   一个 2D 平面被嵌进 3D
    
-   变换结果仍然只能落在某个 2D 子空间里（rank ≤ 2）
    

### (9.2) m<p：降维（projection / measurement）

比如 ![](https://mmbiz.qpic.cn/sz_mmbiz_png/sVzeakRoocsAcl8Y4Mw9HYGAZEJ67DjYMXfA164XiaulEvrrbRldAmxm2IFdSM4YUoH0YVWnQibiaryD0TS0EGMticlxwNIdFxls3icNvy8KDiceM/640?wx_fmt=png&from=appmsg)。几何上是：

-   你把 3D 点“测量”成 2 个数字（行视角非常贴切）
    
-   必然丢信息，所以一般不能唯一反推
    

这也解释了图1 底部那个“？”：  
**反推需要可逆**，但降维或 rank 不满时做不到，只能做最小二乘/伪逆那类“最接近”的逆。

> **矩阵乘法的几何本质：把基向量送到新位置（列），从而决定整个空间如何变形；组合变换就是矩阵相乘；体积与翻面由行列式控制；压扁程度由秩控制。**
