# 你的产品和人生，需要一个什么样的“控制器”？

原创 傅存敬 电磁散人 2026-02-22 07:06 广东

> 原文地址: [https://mp.weixin.qq.com/s/msyimpwGIIalxZ0gWt3jmQ](https://mp.weixin.qq.com/s/msyimpwGIIalxZ0gWt3jmQ)

我干了这么多年电机控制，从读研时懵懵懂懂的Simulink，到后来对着示波器一根一根地调PWM波形，总是在琢磨一个问题：我们天天挂在嘴边的“自动控制”，它的灵魂，究竟是什么？

最初，我想当然地认为是“**负反馈**”。

这太好理解了。你看我们做的FOC，电流环、速度环、位置环，哪个不是负反馈？给了个目标转速1000rpm，传感器测回990rpm，偏差10rpm进到PI调节器，立马加大Uq电压。只要有偏差，就修正。

我们为什么如此依赖它？因为现实世界充满了不确定性。电机参数会温漂，负载会突变，机械有间隙。如果没有“负反馈”这个机制，系统早就飞了。它就像一个忠诚的卫兵，死死地盯着输出，确保它不偏离预设的轨道。负反馈，是我们对抗熵增，在混沌中建立秩序最原始、也是最有力的武器。

直到有一天，我在翻书时，偶然读到曾子那句流传了两千多年的话：“**吾日三省吾身：为人谋而不忠乎？与朋友交而不信乎？传不习乎？**”

我突然愣住了。

这，不就是一个离散的闭环控制系统吗？

-   **目标值（Setpoint）**：是“忠”、“信”、“习”这些我们内心理想的德行标准。
    
-   **传感器（Sensor）**：是“省”（xǐng）这个动作，是对自己一天言行的观测和采样。
    
-   **误差（Error）**：是“乎？”这一问。问，就是在计算理想与现实的偏差。
    
-   **控制器（Controller）**：是发现偏差后的“愧疚感”和第二天的“修正行为”。
    
-   **采样周期（Ts）**：是“日”，24小时一次。
    

你看，一个卓越的人格，和一个高性能的控制系统，底层的逻辑竟然是相通的。一个团队，一家公司，如果失去了复盘和反思的机制，就等于拆掉了反馈环节，在“开环裸奔”，离失控和淘汰也就不远了。

**负反馈，定义了我们从“平庸”走向“优秀”的路径。它是一种“纠偏”的能力。**

那么，这就够了吗？

如果仅仅依赖负反馈，我们的系统永远是被动响应。负载来了，转速掉了，我再追上去。这很稳，但不够快，不够有预见性。一个顶级的伺服系统，一定有**前馈（Feedforward）**。

前馈是什么？它不关心误差，它关心模型。我知道要带动多大的转动惯量（J），目标加速度是多少，我就可以通过 _T = Jα_ 提前计算出需要的转矩，直接把这个转矩叠加给电流环。不等误差出现，我已经把动作提前“喂”给了系统。

这又让我想起一句老话：“**三岁看小，七岁看老。**”

初听，觉得有些宿命论。但用我们搞控制的眼光看，这不就是“**系统辨识**”和“**模型预测**”吗？

-   “**三岁看小**”，就是系统辨识（System Identification）。通过在系统早期施加一些“激励”（比如带孩子去各种环境），观察他的“响应”（性格、行为模式），从而“辨识”出这个“系统”的关键参数（时间常数、阻尼比、增益）。这孩子是内向还是外向，是急性子还是慢性子，模型基本就建好了。
    
-   “**七岁看老**”，就是模型预测（Model Predictive Control, MPC）。当这个孩子的“模型”被建立起来后，只要外部环境（输入u(k)）变化不大，我们确实可以根据他的性格模型，预测出他未来很长一段时间的行为轨迹。
    

说到这，宿命论和控制论的分野就出现了。常人“看老”是为了算命，然后认命。而我们搞控制的，“预测”是为了“干预”。

**真正的高手，“看小”是为了“改老”。**

正因为模型预测到这个孩子有某种不好的倾向，我才要在当下施加一个最有效的“控制输入”（教育、环境改变），去主动修正他未来的状态轨迹。

这才是前馈和模型预测的精髓：**基于对事物本质规律（模型）的深刻洞察，做出有预见性的、主动的、超前的动作，去引领系统的未来，而不是跟在误差后面被动地追赶。**

这是一种“引领”的能力。

现在，我们可以回答最初那个问题了。一个顶级的控制器，应该是什么样的？

它一定是一个**“前馈+反馈”的双环控制系统。**

-   **反馈（内环）**：保证了系统的稳定性和鲁棒性。它对应着我们的**执行力**和**纠错能力**。对于个人，是“三省吾身”；对于团队，是“复盘机制”；对于产品，是不断的测试、迭代和Bug修复。这是我们的基本盘，是活下去的保障。
    
-   **前馈（外环）**：决定了系统的响应速度和性能上限。它对应着我们的**战略力**和**洞察能力**。对于个人，是“三岁看小”的自知之明和对未来的规划；对于领导者，是对技术路线的精准预判和布局；对于行业操盘手，是对市场和商业模式的深刻理解。这是我们脱颖而出，赢得未来的关键。
    

所以，朋友们，不妨审视一下我们自己，我们的团队，我们呕心沥血做出来的产品：

-   **它跑在开环还是闭环？** 我们有没有建立起一个诚实的、持续的反馈机制，去不断修正与目标的偏差？还是在凭着惯性，在“开环裸奔”？
    
-   **它的控制器里，有没有“模型”？** 我们对我们自己、对我们的技术、对我们的市场，有没有建立起深刻的认知模型？还是只是一个被动的PI调节器，永远在追赶KPI的误差？
    

一个顶尖的系统，无论是电机、产品，还是人生，它的控制器里，一定同时住着一位精于计算的工程师，和一个深谙规律的哲学家。

**前者用“负反馈”守住底线，后者用“前馈”指引未来。**
