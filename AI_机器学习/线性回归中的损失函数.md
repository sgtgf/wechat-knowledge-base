# 线性回归中的损失函数


> 原文地址: [https://mp.weixin.qq.com/s/pBqeXe7t-OU\_5GmOCdRYhg](https://mp.weixin.qq.com/s/pBqeXe7t-OU_5GmOCdRYhg)

### 什么是线性回归？

线性回归是一种简单却强大的机器学习方法，用来预测两个变量之间的关系。想象一下，你想根据房子的面积来预测房价：面积越大，房价越高。这时候，我们可以用一条直线来**“拟合”**这些数据点，让这条线尽可能靠近所有点，从而做出预测。

简单来说，线性回归的模型就是：y = mx + b，其中：

-   y 是预测值（比如房价），
    
-   x 是输入（比如面积），
    
-   m 是斜率（表示变化率），
    
-   b 是截距（起始点）。
    

我们的目标是找到最佳的 m 和 b，让预测尽可能准确。

### 损失函数的作用

要找到最佳直线，我们需要一个“裁判”来衡量这条线拟合得“好不好”。这就是损失函数（Loss Function）的角色。它计算预测值和真实值之间的差距，通常用“均方误差”（Mean Squared Error, MSE）作为损失函数。

通俗解释：

-   对于每个数据点，计算预测值减去真实值的“误差”（也叫残差）。
    
-   把误差平方（这样正负误差不会抵消，还能放大大误差）。
    
-   然后取所有误差平方的平均值。
    

MSE 公式（别怕，很简单）： ![MSE = (1/n) * \sum (y_{real} - y_{pred})^2](线性回归中的损失函数_images/img_000_e5a773b6a3a8.png) 

-   n 是数据点数量，
    
-   Σ 是求和，
    
-   y\_real 是真实值，y\_pred 是预测值。
    

损失函数越小，说明直线拟合得越好。我们通过优化算法（比如梯度下降）不断调整 m 和 b，来最小化这个损失。

下面是一个例子：假设我们有一些随机生成的数据点（x 和 y），用线性回归拟合一条直线。

为了更直观地看误差，我们可以画出残差图：每个点的残差（y\_real - y\_pred）分布在零线附近。如果残差随机分布，说明模型不错；如果有模式，可能需要改进。

总之，损失函数是线性回归的**“核心裁判”**，帮助我们训练出可靠的模型。在实际应用中，如果你有数据，可以用Python的scikit-learn库轻松计算！

## 1) 损失函数到底是什么（一句话）

**损失函数 = 用一个数字衡量“模型预测有多错”，并用它来指导参数更新。**

它回答的是：

> “我这条红线（模型）画得好不好？差了多少？”

* * *

## 2) 回归任务里最常见的损失（对应这张图）

### (1) 平方损失 / MSE（最经典）

对每个点的误差平方后再平均：

![$\text{MSE}=\frac{1}{n}\sum_{i=1}^n (y_i-\hat y_i)^2$](线性回归中的损失函数_images/img_007_64632bcf1be9.png)

直觉：

-   误差越大，平方后惩罚**急剧变大**（对离群点更敏感）
    
-   数学性质好（可导、常见情况下可凸），优化方便
    
-   在线性回归 + MSE 的情况下，最小化 MSE 就是大家熟悉的 [](https://mp.weixin.qq.com/s?__biz=MzkzODgwODczMw==&mid=2247484824&idx=1&sn=6158f2e6bb26e5e597aee0c2934d745e&scene=21#wechat_redirect) ****[OLS 最小二乘](https://mp.weixin.qq.com/s?__biz=MzkzODgwODczMw==&mid=2247484824&idx=1&sn=6158f2e6bb26e5e597aee0c2934d745e&scene=21#wechat_redirect)****
    

### (2) 绝对值损失 / MAE

![$\text{MAE}=\frac{1}{n}\sum_{i=1}^n |y_i-\hat y_i|$](线性回归中的损失函数_images/img_008_3ce831314290.png)

直觉：

-   对离群点更“温和”（更鲁棒）
    
-   但在 0 附近不可导（实践中也能用次梯度/平滑近似解决）
    

### (3) Huber 损失（折中：小误差像 MSE，大误差像 MAE）

-   小误差：用平方（稳定、可导）
    
-   大误差：用线性（抗离群点）

## 3) 分类任务里常见的损失（图里没画，但同一思想）

分类不是“点到线的距离”，而是“你把正确类别的概率给得够不够高”。

### (1) 交叉熵（Cross-Entropy / Log Loss）

二分类常写成：

![$L = -\big[y\log p + (1-y)\log(1-p)\big]$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0tokXM7Evic6TL8hGYiaufr57QoIYsic0yYlBhoj42kpEk5L3icL29AsFibER0HhBA49sFmxXGFKKlTJXWA/640?wx_fmt=png&from=appmsg)

直觉：

-   预测得越自信但越错，惩罚越大（“错得离谱”惩罚最重）
    
-   与最大似然等价：最小化交叉熵 ≈ 最大化数据在模型下的概率

## 4) 损失函数在训练里怎么“驱动模型变好”

训练就是解一个优化问题：

![$\min_\theta \ \frac{1}{n}\sum_{i=1}^n L\big(f_\theta(x_i), y_i\big)$](线性回归中的损失函数_images/img_009_e57785f50fe3.png)

-   θ：模型参数（这张图里就是 w,b）
    
-   ![$f_\theta(x)$](线性回归中的损失函数_images/img_010_837a8005133e.png)：模型输出（红线给出的 ![$\hat y$](线性回归中的损失函数_images/img_011_1b7a117e990a.png)）
    

常用做法：梯度下降

![$\theta \leftarrow \theta - \eta \nabla_\theta \text{Loss}$](线性回归中的损失函数_images/img_012_57152ccf2478.png)

直觉：  
损失函数像“地形高度”，参数更新像“往山谷最低处走”。

* * *

## 5) 损失函数 ≠ 评估指标（经常被混用）

-   损失函数：训练时用（需要可优化，通常要可导/稳定）
    
-   评估指标：报告效果用（比如 Accuracy、F1、AUC、R² 等）
    

比如分类里，训练用交叉熵，但你最后可能更关心 Accuracy/F1。

* * *

## 6) 进阶：正则化也是“损失的一部分”

为了防止过拟合，常把“模型复杂度惩罚”加进来：

![$\text{Total Loss} = \text{Data Loss} + \lambda \cdot \Omega(\theta)$](线性回归中的损失函数_images/img_013_238f6de4a839.png)

-   L2 正则：![$\Omega(\theta)=\|\theta\|_2^2$](线性回归中的损失函数_images/img_014_c0889b721cfa.png)（让参数别太大）
    
-   L1 正则：![$\Omega(\theta)=\|\theta\|_1$](线性回归中的损失函数_images/img_015_86306ef4467e.png)（促稀疏）

## 3) 再看 Huber（更抗离群点）

取 δ=1，Huber 对单个误差：

-   若 ∣e∣≤1：![$\frac12 e^2$](线性回归中的损失函数_images/img_033_58850518aaf7.png)
    
-   若 ∣e∣>1：![$\delta(|e|-\frac12\delta)=|e|-0.5$](线性回归中的损失函数_images/img_034_d3e601590c2e.png)
    

### 线1（w=0.2,b=4）误差：0,1,3,3,4

Huber 和：

-   0 → 0
    
-   1 → 0.5
    
-   3 → 2.5（因为 3-0.5）
    
-   3 → 2.5
    
-   4 → 3.5
    

总和 =9.0，平均 =9/5=1.8

### 线2（w=0.28,b=3.2）误差：0,0.2,1.4,0.6,0.8

-   0 → 0
    
-   0.2 → 0.5·0.04=0.02
    
-   1.4 → 1.4-0.5=0.9
    
-   0.6 → 0.5·0.36=0.18
    
-   0.8 → 0.5·0.64=0.32
    

总和 =1.42，平均 =1.42/5=0.284

Huber 的感觉：大误差不会像 MSE 那样被“平方放大得离谱”。

## 4) 损失怎么“推着红线走”（用一次梯度下降演示）

用 MSE（更好算），但梯度通常用 ![$(\hat y - y)$](线性回归中的损失函数_images/img_035_32cd4f86fbe7.png)这个差：

![$d_i = \hat y_i - y_i$](线性回归中的损失函数_images/img_036_329650f02bf9.png)

![$\frac{\partial \text{MSE}}{\partial w}=\frac{2}{n}\sum d_i x_i,\quad \frac{\partial \text{MSE}}{\partial b}=\frac{2}{n}\sum d_i$](线性回归中的损失函数_images/img_037_77f68d88e59d.png)

对线1：w=0.2,b=4 时  
 ![$\hat y$](线性回归中的损失函数_images/img_038_1b7a117e990a.png) 是 6,8,10,12,14  
所以 ![$d=\hat y-y$](线性回归中的损失函数_images/img_039_c1cecaf42f39.png) 为：0, -1, -3, -3, -4

-   ![$\sum d_i = -11$](线性回归中的损失函数_images/img_040_4836707733f4.png)
    
-   ![$\sum d_i x_i = 0\cdot10 + (-1)\cdot20 + (-3)\cdot30 + (-3)\cdot40 + (-4)\cdot50$](线性回归中的损失函数_images/img_041_28d0dfe516ff.png)
    
    ![$= -20-90-120-200=-430$](线性回归中的损失函数_images/img_042_11693c92153d.png)
    

于是（n=5）：

![$\frac{\partial \text{MSE}}{\partial b}=\frac{2}{5}(-11)=-4.4$](线性回归中的损失函数_images/img_043_04dd249090ac.png)

![$w \leftarrow w-\eta \frac{\partial}{\partial w}=0.2-0.0005(-172)=0.286$](线性回归中的损失函数_images/img_045_ba4a00eef383.png)

## 1) OLS 的闭式解公式（简单线性回归）

常用两种等价写法：

**写法A（用均值/离差）：**

![$w=\frac{\sum (x_i-\bar x)(y_i-\bar y)}{\sum (x_i-\bar x)^2},\qquad b=\bar y-w\bar x$](线性回归中的损失函数_images/img_051_b41a945a9103.png)

**写法B（用各种求和）：**

![$w=\frac{n\sum x_iy_i-(\sum x_i)(\sum y_i)}{n\sum x_i^2-(\sum x_i)^2},\qquad b=\frac{\sum y_i-w\sum x_i}{n}$](线性回归中的损失函数_images/img_052_78816dbbb8c1.png)

![$0.04+0.04+0.64+0.04+0.04=0.80$](线性回归中的损失函数_images/img_067_40e1a3899ce3.png)

MSE（按 n平均）：

![$\text{MSE}=0.80/5=0.16$](线性回归中的损失函数_images/img_068_2a5f3d05aea2.png)

我们把 **闭式解从“最小化平方和”一步步推导出来**。你会看到它本质上就是：让“误差平方和”对 w,b的斜率为 0（到达最低点）。

* * *

## 1) 目标函数：平方误差和（SSE）

线性回归模型：

![$\hat y_i = wx_i + b$](线性回归中的损失函数_images/img_069_4148088c98cc.png)

残差：

![$e_i = y_i - \hat y_i = y_i - (wx_i+b)$](线性回归中的损失函数_images/img_070_a01fcaabbb53.png)

要最小化的函数（SSE）：

![$J(w,b)=\sum_{i=1}^n (y_i-(wx_i+b))^2$](线性回归中的损失函数_images/img_071_d7e0acd135ab.png)

> 为什么用平方？  
> 因为平方能把正负误差都变成正数，并且“大错惩罚更重”，而且数学上可导，方便求最小值。

* * *

## 2) 对 b 求偏导（找到最优截距条件）

令

![$r_i = y_i-(wx_i+b)$](线性回归中的损失函数_images/img_072_350ebab9a637.png)

则

![$J(w,b)=\sum r_i^2$](线性回归中的损失函数_images/img_073_6791f0f8c156.png)

对 b求偏导：

![$\frac{\partial J}{\partial b}=\sum 2r_i\cdot \frac{\partial r_i}{\partial b}$](线性回归中的损失函数_images/img_074_6cdec8c81f42.png)

而

![$r_i = y_i - wx_i - b \Rightarrow \frac{\partial r_i}{\partial b} = -1$](线性回归中的损失函数_images/img_075_b16437f13c09.png)

所以：

![$\frac{\partial J}{\partial b}=\sum 2r_i(-1)=-2\sum r_i$](线性回归中的损失函数_images/img_076_cf36842cc15e.png)

最小值点满足偏导为 0：

![$-2\sum r_i=0 \Rightarrow \sum r_i=0$](线性回归中的损失函数_images/img_077_68dd999629fb.png)

代回![$r_i=y_i-wx_i-b$](线性回归中的损失函数_images/img_078_a8aa62e2a117.png)：

![$\sum (y_i-wx_i-b)=0$](线性回归中的损失函数_images/img_079_a0813ff914e6.png)

展开：

![$\sum y_i - w\sum x_i - nb = 0$](线性回归中的损失函数_images/img_080_7c80383596ff.png)

得到第一条 **正规方程**：

![$\boxed{w\sum x_i + nb = \sum y_i}$](线性回归中的损失函数_images/img_081_7294fc0108df.png)

直觉：**最优时残差的总和为 0**（正负误差相互抵消）。

你可以把它理解成：**把整条红线整体上下挪一点点，看看总误差平方是变大还是变小；最优的那一下就是“再挪也不变好”的位置。**

* * *

## (2.1) 先把 b 看成“上下平移旋钮”

直线：

![$\hat y = wx + b$](线性回归中的损失函数_images/img_082_0917c75ecd33.png)

-   w 决定“斜不斜”（转动）
    
-   b 决定“整体上移/下移”（平移）
    

当你把 b 增加一点点 Δb，所有预测值 ![$\hat y_i$](线性回归中的损失函数_images/img_083_252474f0c82d.png) 都会 **同时加 Δb**：

![$\hat y_i \to \hat y_i + \Delta b$](线性回归中的损失函数_images/img_084_cdf29a1012fe.png)

所以，b 的作用非常简单：**让整条线整体往上或往下挪。**

* * *

## (2.2) 残差 ![$e_i$](线性回归中的损失函数_images/img_085_20a4dc286e9f.png) 跟 b 的关系

残差（真实值减预测值）：

![$e_i = y_i - \hat y_i = y_i - (wx_i + b)$](线性回归中的损失函数_images/img_086_a01fcaabbb53.png)

你看这里的 b 是 **减号**：

-   b 变大 ⇒ ![$\hat y_i$](线性回归中的损失函数_images/img_087_252474f0c82d.png) 变大 ⇒ ![$e_i = y_i - \hat y_i$](线性回归中的损失函数_images/img_088_0ba22966bc2c.png) 变小（更负）
    
-   b 变小 ⇒ ![$\hat y_i$](线性回归中的损失函数_images/img_089_252474f0c82d.png) 变小 ⇒ ![$e_i$](线性回归中的损失函数_images/img_090_20a4dc286e9f.png) 变大（更正）
    

更直接地写：

![$e_i(b) = (y_i - wx_i) - b$](线性回归中的损失函数_images/img_091_616672e309ca.png)

这说明 ![$e_i$](线性回归中的损失函数_images/img_092_20a4dc286e9f.png)  **是关于 b 的一条斜率为 -1 的直线**。

所以：

![$\frac{\partial e_i}{\partial b} = -1$](线性回归中的损失函数_images/img_093_94c04c08e070.png)

这一步是关键：

> 误差对 b 的变化率，就是 -1（因为 ![$e_i$](线性回归中的损失函数_images/img_094_20a4dc286e9f.png) 里有 −b）。

* * *

## (2.3) 为什么会出现 ![$2e_i$](线性回归中的损失函数_images/img_095_85d94a3734bb.png)（链式法则）

我们优化的是平方误差和：

![$J(b)=\sum_{i=1}^n e_i(b)^2$](线性回归中的损失函数_images/img_096_46a81f4c729c.png)

先看单项：![$e^2$](线性回归中的损失函数_images/img_097_d5b228761c22.png)。  
对 e 求导：

![$\frac{d}{de}(e^2)=2e$](线性回归中的损失函数_images/img_098_88b07651daaf.png)

这就是你看到的 **“2”从哪来**。

但我们要对 b 求导，不是对 e 求导，所以要用链式法则：

![$\frac{d}{db}(e^2)=\frac{d}{de}(e^2)\cdot\frac{de}{db}=2e\cdot\frac{de}{db}$](线性回归中的损失函数_images/img_099_5b893f37796e.png)

而刚才我们知道 ![$\frac{de}{db}=-1$](线性回归中的损失函数_images/img_100_821025e79d14.png)，所以：

![$\frac{d}{db}(e^2)=2e\cdot(-1)=-2e$](线性回归中的损失函数_images/img_101_07e60dbc8bdd.png)

* * *

## (2.4) 把所有点加起来：得到 ![$\frac{\partial J}{\partial b}$](线性回归中的损失函数_images/img_102_d92c9716b99c.png) 

因为 ![$J=\sum e_i^2$](线性回归中的损失函数_images/img_103_597816e95a5a.png)，所以：

![$\frac{\partial J}{\partial b}=\sum \frac{\partial}{\partial b}(e_i^2)=\sum (-2e_i)=-2\sum e_i$](线性回归中的损失函数_images/img_104_de930de79b08.png)

到这里就完全解释清楚了：

![$\boxed{\frac{\partial J}{\partial b}=-2\sum_{i=1}^n e_i}$](线性回归中的损失函数_images/img_105_720a97d1bbf5.png)

* * *

## (2.5) “最优截距条件”为什么是 ![$\sum e_i = 0$](线性回归中的损失函数_images/img_106_c04524a153c4.png) 

最优点（最小值点）满足“导数为 0”（坡度为 0）：

![$\frac{\partial J}{\partial b}=0$](线性回归中的损失函数_images/img_107_bb06042d3d2d.png)

代入上式：

![$-2\sum e_i = 0 \Rightarrow \sum e_i = 0$](线性回归中的损失函数_images/img_108_2abb7d929d9a.png)

也就是：

![$\boxed{\sum_{i=1}^n (y_i-(wx_i+b))=0}$](线性回归中的损失函数_images/img_109_a2348b4421b2.png)

直觉翻译：

> 如果红线太低，大多数点在红线上方 ⇒ 残差 ![$e_i$](线性回归中的损失函数_images/img_110_20a4dc286e9f.png) 多数为正 ⇒ ![$\sum e_i>0$](线性回归中的损失函数_images/img_111_2acc1f59887c.png)，此时把 b 调大（上移）能让误差更小。  
> 如果红线太高，残差多数为负 ⇒ ![$\sum e_i<0$](线性回归中的损失函数_images/img_112_1afde5087a26.png)，此时把 b 调小（下移）更好。  
> **只有当正负残差刚好“平衡”，总和为 0 时，上下挪都不会更好，才是最优。**

 ![$\frac{\partial J}{\partial b}$](线性回归中的损失函数_images/img_113_d92c9716b99c.png) 的意义可以用一句话抓住：

**它表示：当你把截距 b 轻轻调大一点点时，总损失 J 会往哪个方向、以多快的速度变化。**

* * *

## (2.6) 它到底在“问”什么

把 J(w,b) 看成一个地形高度（损失地形）：

-   w：控制斜率（线的倾斜）
    
-   b：控制上下平移
    

那么

![$\frac{\partial J}{\partial b}$](线性回归中的损失函数_images/img_114_d92c9716b99c.png)

就是在当前 (w,b)位置上，**沿着 “只改变 b” 这条方向走，地形是往上还是往下、坡有多陡**。

* * *

## (2.7) 更“微分”的定义（最精确的意思）

它等价于下面这个极限：

![$\frac{\partial J}{\partial b} =\lim_{\Delta b\to 0}\frac{J(w,b+\Delta b)-J(w,b)}{\Delta b}$](线性回归中的损失函数_images/img_115_ebb29027e7de.png)

也就是：

> b 增加一个极小量 Δb，损失 J改变多少；再除以 Δb，得到“单位 b 改变引起的 J 改变”。

* * *

## (2.8) 符号怎么读（非常重要的直觉）

-   ![\frac{\partial J}{\partial b} > 0](线性回归中的损失函数_images/img_116_a0c682446899.png)：**你把 b 调大一点，J 反而变大**  
      ⇒ 要让 J 变小，你应该把 b 往小调（下移）。
    
-   ![\frac{\partial J}{\partial b} < 0](线性回归中的损失函数_images/img_117_57c0f492001f.png)：**你把 bbb 调大一点，J 会变小**  
      ⇒ 要让 J 变小，你应该把 b 往大调（上移）。
    
-   ![\frac{\partial J}{\partial b} = 0](线性回归中的损失函数_images/img_118_7bf20ee24565.png)：**上下挪一点都不会让 J 继续变小**  
      ⇒ 在 b 方向上已经到“最低点”（最优截距条件之一）。
    

* * *

## (2.9) 为什么它最后会变成 ![$-2\sum e_i$](线性回归中的损失函数_images/img_119_0b7c637af114.png) 

如果 ![J=\sum e_i^2](线性回归中的损失函数_images/img_120_43a330e3774c.png)，且 ![$e_i=y_i-(wx_i+b)$](线性回归中的损失函数_images/img_121_417931f7a693.png)，那么我们推过：

![$\frac{\partial J}{\partial b}=-2\sum_{i=1}^n e_i$](线性回归中的损失函数_images/img_122_f5b015087cc7.png)

这句话的直觉翻译是：

> **若大多数点在红线之上（![$e_i>0$](线性回归中的损失函数_images/img_123_a88c9393c665.png)多），![\sum e_i>0](线性回归中的损失函数_images/img_124_937bd147db9e.png)，导数为负，说明“把线往上抬”（增大 b）能降低损失。**  
> **若大多数点在红线之下（![e_i<0](线性回归中的损失函数_images/img_125_2a16da3ec271.png)多），![\sum e_i<0](线性回归中的损失函数_images/img_126_053b417a009a.png)，导数为正，说明“把线往下压”（减小 b）能降低损失。**

## (2.10) 一句“训练更新”里的作用

梯度下降更新截距就是：

![$b \leftarrow b - \eta \frac{\partial J}{\partial b}$](线性回归中的损失函数_images/img_127_78c73725ed8d.png)

所以 ![\frac{\partial J}{\partial b}](线性回归中的损失函数_images/img_128_deb1a6de8f2b.png) 本质上是：  
**“告诉你：截距应该往上调还是往下调，以及调多少更合适（步子大小由 η 决定）”。**

## 3) 对 w 求偏导（找到最优斜率条件）

同理：

![$\frac{\partial J}{\partial w}=\sum 2r_i\cdot \frac{\partial r_i}{\partial w}$](线性回归中的损失函数_images/img_129_7fb8ad4eb03c.png)

而

![$r_i = y_i - wx_i - b \Rightarrow \frac{\partial r_i}{\partial w} = -x_i$](线性回归中的损失函数_images/img_130_f71fef9f2eaa.png)

所以：

![$\frac{\partial J}{\partial w}=\sum 2r_i(-x_i)=-2\sum x_i r_i$](线性回归中的损失函数_images/img_131_4e515dd73a94.png)

令其为 0：

![$-2\sum x_i r_i=0 \Rightarrow \sum x_i r_i=0$](线性回归中的损失函数_images/img_132_51d826f7348a.png)

代回：

![$\sum x_i(y_i-wx_i-b)=0$](线性回归中的损失函数_images/img_133_b225e5f2a11d.png)

展开：

![$\sum x_i y_i - w\sum x_i^2 - b\sum x_i = 0$](线性回归中的损失函数_images/img_134_b01ba0b8925c.png)

得到第二条 **正规方程**：

![$\boxed{w\sum x_i^2 + b\sum x_i = \sum x_i y_i}$](线性回归中的损失函数_images/img_135_b9cf2551bd78.png)

直觉：这是“带 x 权重的残差和为 0”，保证斜率方向也达到最优。

* * *

## 4) 两条正规方程联立，解出 w,b

我们现在有：

![$\begin{cases} w\sum x_i + nb = \sum y_i \\ w\sum x_i^2 + b\sum x_i = \sum x_i y_i \end{cases}$](线性回归中的损失函数_images/img_136_12ad09f43d44.png)

为了写起来更清爽，记：

![$S_x=\sum x_i,\quad S_y=\sum y_i,\quad S_{xx}=\sum x_i^2,\quad S_{xy}=\sum x_i y_i$](线性回归中的损失函数_images/img_137_2dc30723a718.png)

则：

![$\begin{cases} wS_x + nb = S_y \\ wS_{xx} + bS_x = S_{xy} \end{cases}$](线性回归中的损失函数_images/img_138_b145e49038cf.png)

从第一式解 b：

![$b=\frac{S_y-wS_x}{n}$](线性回归中的损失函数_images/img_139_180b2150e398.png)

代入第二式：

![$wS_{xx} + S_x\cdot\frac{S_y-wS_x}{n} = S_{xy}$](线性回归中的损失函数_images/img_140_c7476a469ba9.png)

两边乘 n：

![$nwS_{xx}+S_xS_y-wS_x^2 = nS_{xy}$](线性回归中的损失函数_images/img_141_088e7d31be5e.png)

把 w 的项合并：

![$w(nS_{xx}-S_x^2)=nS_{xy}-S_xS_y$](线性回归中的损失函数_images/img_142_db7ab0008324.png)

所以：

![$\boxed{w=\frac{nS_{xy}-S_xS_y}{nS_{xx}-S_x^2}}$](线性回归中的损失函数_images/img_143_a44a6aac0d74.png)

再带回：

![$\boxed{b=\frac{S_y-wS_x}{n}}$](线性回归中的损失函数_images/img_144_e78c5c983b54.png)

这就是你刚才看到的闭式解公式来源。
