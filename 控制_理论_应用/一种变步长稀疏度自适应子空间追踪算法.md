# 一种变步长稀疏度自适应子空间追踪算法

原创 自动化学报 2016-10-31 16:41 北京

> 原文地址: [https://mp.weixin.qq.com/s/Er9MOZCMDuxcyWA8xzszOQ](https://mp.weixin.qq.com/s/Er9MOZCMDuxcyWA8xzszOQ)

针对压缩感知(Compressive sensing, CS) 中未知稀疏度信号的重建问题, 本文根据重建残差与支撑集原子个数及信号稀疏度之间的关系, 针对由于SAMP 算法采用固定增加步长所带来的精度较低和可能由此产生的过度估计问题, 提出了一种新的变步长稀疏度自适应子空间追踪算法(Variablestep size sparsity adaptive subspace pursuit, VssSASP) 算法。该算法不需要知道信号稀疏度信息，先采用固定步长确定信号稀疏度的范围, 再用可变步长逐步缩小该范围并确定稀疏度, 对支撑集原子选择采用子空间追踪算法的回溯方法。

算法分为三个阶段: 首先确定固定迭代步长，通过一种测试方法估计稀疏度,把它作为固定迭代步长；然后以固定步长确定稀疏度的范围，以估计的估计稀疏度作为固定步长，增加信号支撑集的个数，进行SP恢复算法，检测相应的残差值，根据残差值得变化确定信号稀疏度的范围；最后，采用二分法, 根据恢复残差值，在该范围内逐步逼近并确定求出对应支撑集及其系数, 进而实现原信号的重建。

图1(a)中给出了信号稀疏度为20时, 不同采样点的信号准确重建率。从图中可以看出, VssSASP 算法重建概率明显超过OMP、ROMP 和SP 算法, 与SAMP 算法重建概率相当。对于同样的信号, VssSASP 算法能稳定重建信号所需的采样点数较少。图3 (b)中给出了采样数为128 时, 各重建算法对不同稀疏度的准确重建率。信号准确重建概率随着信号稀疏度K 的增大而减小,明显高于OMP、ROMP 和SP 算法, 与SAMP算法重建概率相当。对于同样的采样点数, VssSASP 算法能稳定重建稀疏度更高的信号。
