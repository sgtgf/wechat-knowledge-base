## 一个小故事

有这样一个数学故事。在古印度，一位非常聪明的人发明了国际象棋这个游戏。这个游戏极大地娱乐了国王，他如此沉迷于它，以至于提出要奖励发明者任何他希望的东西，甚至是他王国的一半领土。国际象棋的发明者非常聪明，也有点贪婪。他不满足于仅仅获得半个王国，于是向国王请求了以下礼物：

> “伟大的国王”，他说，“我只是一个小人物，不知道如何处理您的半个王国。不如让我们这样计算我的奖赏。在棋盘的第一个方格上放一粒大米。然后在第二个方格上放两粒，第三个方格上放四粒，以此类推，直到我们在整个棋盘上铺满大米。”

听到这个，国王非常高兴，因为他觉得这是相当便宜的交易。他迅速同意了发明者的要求。他叫人拿来一袋大米，开始数了起来。然而，他很快就用完了第一袋，还没有数到棋盘的一半。他又叫了第二袋，第三袋，越来越多，直到最后，他不得不承认失败，因为没有足够的大米来支付发明者。

棋盘的一部分看起来是这样的：

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/icVUVTFlBCVXlCxibdLIQrnvicMSLsaHQ4My1sGFTiaXSEvdgJyZQGKtNSbictOL6QrqIcJzdbdNT1ZNMN0erDAdugQ/640?wx_fmt=jpeg)

如果你数到第64个方格，将会是或9,223,372,036,854,775,808。那是超过9百亿亿粒大米。此外，如果你将64个方格的大米全部加起来，你将得到足够覆盖整个印度膝盖深的大米（18,446,744,073,709,551,615粒大米）。手工计算这个问题显然是一项相当繁重的任务。还能怎么做呢，只能通过程序。用什么语言？我们可以选择Fortran，因为它在数值计算方面做得非常好。

## 代码实现

```
PROGRAM rice   INTEGER :: i   INTEGER (KIND=16) :: grain, totalGrains   grain = 1   totalGrains = grain   DO i = 1, 63      grain = grain * 2      totalGrains = totalGrains + grain   END DO   PRINT*, "国王需要", totalGrains, "粒大米"END PROGRAM rice
```

编译运行一下，输出结果是这样的：

> 国王需要 18446744073709551615 粒大米

注意，与C不同，C需要一个长整型（`long long int`），Fortran使用单一的数据类型`INTEGER`，它允许用户指定字节大小。在这种情况下，整数的大小是16字节（或128位）。

有人会问为什么说Fortran比C更好一些？因为代码更容易阅读，实际上也更容易实现。程序员不需要为添加哪些标准库或者匹配某个数据的I/O说明符而操心。C程序的大小和Fortran的差不多，但需要使用一个长整型数据类型，另外还必须记住输出的说明符是 `%llu`，这些对于新手程序员来说确实是个挑战。

## 拓展阅读

#### Fortran的整数类型

整型变量是含有整数取值的变量，整型变量必须先声明后使用。声明整型变量的一般形式为：

```
INTEGER IINTEGER([KIND=n]) I
```

其中，`I`为整型变量名；`KIND`是**种类参数**，是现代Fortran新添加的特性，表示整型变量所占用的内存节数。对于整数，`n`一般为1、2、4、8、16。如果种类参数没有特别规定，则取缺省值，而缺省值受编译器选项影响。在没有编译器选项规定时，32位系统下缺省值为4。

不同种类参数的整数取值范围如下所示：

```
INTEGER(1) -128~127INTEGER(2) -32768~32767INTEGER(4) -2147483648~2147483647INTEGER(8) -9223372036854775808~9223372036854775807INTEGER(16) -170141183460469231731687303715884105728~170141183460469231731687303715884105727
```

现代Fortran还提供了`KIND`函数，用来获取缺省种类参数的值。`HUGE`函数则用来获得取值范围的上限，上限加1即为取值范围的下限，如下列代码段所示：

```
INTEGER :: I, K, Max, MinK = KIND(I)Max = HUGE(I)Min = Max + 1PRINT*, '缺省值：', KPRINT*, '上限是：', MaxPRINT*, '下限是：', Min
```

在不同平台下，相同的种类参数可能有不同的取值范围，这极大地影响了程序代码的可移植性，为此，现代Fortran提供了一些库函数与`KIND`描述搭配，可以增加程序代码的"跨平台"能力。

`SELECTED_INT_KIND`函数能够根据数据取值的十进制范围给出其种类参数值。一般句法为：

```
RESULT = SELECTED_INT_KIND(r)
```

`RESULT`代表整数在区间内时的种类参数。例如：

```
RESULT = SELECTED_INT_KIND(3) ! 结果为2
```

当返回值为`-1`时，表示无法提供想要的值域范围，没有可用的种类参数。

当要在不同的平台上表示内的整数`I`时，可采取如下的声明方式：

```
INTEGER, PARAMETER :: K = SELECTED_INT_KIND(r) INTEGER(K) :: I
```

即先声明依赖于特定平台上的种类参数，然后再以该种类参数声明变量。
