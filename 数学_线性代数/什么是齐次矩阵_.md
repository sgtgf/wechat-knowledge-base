# 什么是齐次矩阵？


> 原文地址: [https://mp.weixin.qq.com/s/6aCn\_-s\_03bs23WPeF3clg](https://mp.weixin.qq.com/s/6aCn_-s_03bs23WPeF3clg)

齐次矩阵（Homogeneous Matrix）是一种特殊的矩阵，主要用于计算机图形学、机器人学和3D建模中。它不是普通的矩阵，而是用来描述点或物体的“变换”（比如移动、旋转、缩放）的工具。简单来说，它让复杂的空间变换变得像乘法运算一样简单。

要理解齐次矩阵，先得知道“齐次坐标”（Homogeneous Coordinates）。平时我们用笛卡尔坐标表示一个点，比如2D平面上的点是(x, y)，3D是(x, y, z)。但齐次坐标会多加一个维度，通常是1，比如2D点变成(x, y, 1)，3D变成(x, y, z, 1)。这个额外的“1”就像给坐标加了个“标签”，让计算更统一。

为什么这么做？因为在普通坐标下，旋转和缩放可以用矩阵乘法，但“平移”（移动位置）得用加法。这样混在一起计算很麻烦。齐次坐标就把所有变换都统一成矩阵乘法，超级方便！

齐次矩阵长什么样？

对于2D图形，齐次矩阵是一个3x3的矩阵；对于3D，是4x4的。它的结构通常是：

-   上部分：描述旋转、缩放、剪切等线性变换。
    
-   右边或下边：描述平移。
    
-   最后一行：通常是\[0, 0, 1\]（2D）或\[0, 0, 0, 1\]（3D），保持齐次性。
    

  

“齐次矩阵”这词，其实是两件事绑在一起说：

1.  **齐次坐标（homogeneous coordinates）**
    
    把 2D 点 ![](什么是齐次矩阵__images/img_000_a63e246387fe.svg) 变成 3D 的 ![](D:\电脑文件\公众号知识库\数学_线性代数\什么是齐次矩阵__images\img_000_35020ea10bc0.svg)，并且**把“同一条射线上的比例点”视为同一个几何点**。
    
2.  **齐次矩阵（homogeneous matrix）**
    
    用一个更高一维的矩阵（2D 用 ![](什么是齐次矩阵__images/img_002_672c6c883e2d.svg)，3D 用 ![](什么是齐次矩阵__images/img_003_ea6662339264.svg)）去统一表示**平移、旋转、缩放、剪切、透视投影**等变换，而且可以像普通矩阵一样连乘组合。

在普通 2D 里，平移是：

![](什么是齐次矩阵__images/img_020_bf3ed13fc5e1.svg)

-   齐次坐标把 ![](什么是齐次矩阵__images/img_048_bf0d0da71a51.svg) 表示为一条射线上的等价类：![](什么是齐次矩阵__images/img_049_b1bacf08dca2.svg)。
    
-   齐次矩阵就是在这个坐标系里做线性变换：![](什么是齐次矩阵__images/img_050_c1792efa03e8.svg)，最后再除以 ![](什么是齐次矩阵__images/img_051_4eb3a12630d6.svg) 回到普通坐标。
    
-   这样平移也能写成矩阵乘法，且能和旋转/缩放/透视统一、可连乘组合。
