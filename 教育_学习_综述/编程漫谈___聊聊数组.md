数组对于新手程序员来说总是显得具有挑战性，因为现实生活中没有太多与之相似的事物。最接近的例子可能是盒子里的鸡蛋（2×5），或者箱子里的葡萄酒瓶（3×4）。这些都是二维数组，一维数组则更加难以捉摸。那么，如何传达一个只容纳一种类型物品的容器的概念呢？最接近的插图例子可能是分隔的储物盒。但即便如此，它也是一个有盖子的容器，而数组还要更简洁。数组本质上是没有墙壁、盖子或物理限制（不考虑内存限制）的容器。  


数组这一概念的定义是比较困难的，数组的实现更是如此。比如，从0开始的索引。虽然如果用得习惯了可能看起来也很自然，但对于初学编程的新手来说，通常都不太理解为什么一个容器会有被标记为“第0号”的部分……

首先让我们考虑C中的数组。以下是C中的一个包含100个元素的整数数组：

 int a\[100\];

这种定义的问题在于没有明确数组的概念。它只用了方括号来定义数组规格的大小。也没有表明索引从0开始（尽管在C中这是很常规的）。C的数组可能是所有编程语言中识别难度最高的，因为它并没有对新手程序员给出足够直观的信息。

我们接着来看看其他编程语言是如何定义数组的。

Pascal  ：`a :` `array``[1..100] of` `integer``;`

Ada      ：`a :` `array``(1..100) of` `integer``;`

Fortran ：`integer``,` `dimension``(1:100) :: a`

Julia     ：`a =` `array``(``Int64``, 1, 100)`

以上这些表述中，数组的类型都被明确指定了。数组的范围也很清晰。此外，还都标明了可以使用的索引（`1~100`）。Pascal、Ada和Julia，都使用了“数组”（array）这个词来表明它是一个容器。Fortran虽然没有明确使用“数组”（array）这个词，但它确实使用了形容词“维度”（dimension）来指定索引值的范围。此外，并非所有语言都像C一样限制了索引必须从0开始。例如，Pascal和Fortran允许使用正负索引，这就使语言能够更好地适应算法，而不是让算法适应语言。

对于上述的这些表达方式，新手程序员显然更容易理解`a`是一个数组。为数组指定了索引范围，对新手来说也更加友好。以Ada数组为例，我们要创建一个循环来处理这个数组，给每个元素赋值，你会发现这是很简单的：

 for i in 1..100 loop  
    a(i) := i;  
 end loop;

部分原因我想应该归功于这里的循环非常容易理解。考虑C中相同的循环：

 for (i\=0; i<100; i\=i+1)  
    a\[i\] \= i;

这个循环对新手程序员来说就没有那么直观，一个重要原因是它使用了索引0到99。新手程序员可能会写出以下几种形式的循环：

 for (i\=0; i\=100; i\=i+1)  
 for (i\=0; i\==100; i\=i+1)  
 for (i\=0; i!=100; i\=i+1)

第一个会导致无限循环，第二个会导致循环不执行，最后一个会工作，但非常不直观。这里有很多让新手犯错的机会。而使用Ada循环时，出现代码错误的几率则要小很多。

现在考虑Python中的数组。Python被誉为一种非常容易学习的语言。首先，由于Python没有自然数组（只有列表），我们需要使用Numpy来创建数组。与上述的其他语言一样，下面也定义了一个包含100个整数值的数组。

 a = numpy.arange(0, 100, dtype\=np.integer)

首先，这个语句并没有那么直观地表明“数组”。其次，对于新手程序员来说，可能最成问题的是需要将范围指定为`0~99+1`，因为指定`0~99`会导致定义出一个只有99个元素的数组。

在定义完成之后，数组的使用也会存在一些问题。使用方括号`[ ]`可能比简单的括号`()`要更直观。因此，像Pascal、Julia和C这样的语言，在这里可能比Fortran和Ada更好，因为后者更容易混淆数组括号和在函数调用或表达式中使用的括号的用法。当数组扩展到多个维度时，如何定位数组中的某个元素也会增加编程的难度。C使用单独的括号，例如**a\[i\]\[j\]**，这与Fortran使用的集成索引**a(i,j)**相比起来，就不是那么直观了。

最后，还有关于可以对数组做什么的问题。在一些语言中，例如Fortran，将整个数组设置为特定的值是十分轻松的。在Fortran中，以下代码创建了一个20×20的整数数组（theArray），将整个数组设置为值10，然后将中心的8×8区域设置为值5：

 integer, dimension(20,20) :: theArray  
 theArray \= 10  
 theArray(7:14,7:14) \= 5

这是通过整个数组操作和数组切片来实现的，这是许多编程语言具有的便捷特性。在C中，除非你想将整个数组设置为零，否则没有简单的方法来执行这个任务，而且不允许数组切片。这意味着C中的代码可能看起来会像这样：

 int i, j, theArray\[20\]\[20\];  
 for (i\=0; i<20; i\=i+1)  
    for (j\=0; j<20; j\=j+1)  
       theArray\[i\]\[j\] \= 10;  
 for (i\=6; i<=13; i\=i+1)  
    for (j\=6; j<=13; j\=j+1)  
       theArray\[i\]\[j\] \= 5;

Fortran或C，你觉得哪一个对新手程序员来说更容易理解和实现呢？我想答案应该是显而易见的。

总之，像C和Python这样的语言增加了新手程序员学习数组的难度，部分原因是使用了基于0的索引导致的不直观，部分原因是需要通过指定循环以操作数组，这样的操作通常来说是比较容易出错的。其他语言，像Fortran和Julia，则通过更明确的定义为理解数组提供了良好的基础，加上这些语言提供的附加特性，如允许数组切片等，让新手程序员可以更多地关注他们使用的算法和需要解决的问题，而不是语言的语法。
