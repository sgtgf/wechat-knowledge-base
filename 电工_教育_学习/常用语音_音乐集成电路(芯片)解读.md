# (一)语音集成路:

# 语音集成电路是指发出中文或外文语句的器件，这种器件内的“语言存贮器”一般都不大，只能发出简单的语句，如“欢迎光临”，“恭喜发财”，“祝你生曰快乐”，“早晨好，快起床”，“高压危险”，“请勿靠近”，“倒车请注意”，“抓贼呀”等等。

# 工作原理: 正电源、触发器、信号端和地，有的还需接入振荡电阻，而这个电阻一般都直接焊在集成电路的线路板上。对于该电路的应用设计需要为提供电压(一般为3一4.5v)，就可以在信号端输出所需要的音乐信号了。

对于触发端的电路设计一般有两种启动方式:

# 1.通过电子开关控制音乐集成电路的供电，从而控制音乐集成电路是否工作。这种方式的电路设计，必须把触发端直接和正电源端相接，这样只要一向音乐集成电路供电，其触发端便得到一个触发信号，启动电路工作，这种方式只要一直保证音乐块供电，它便会反复地演奏。

# 2\. 向触发端送入触发信号，这种方式的电路设计要求让音乐集成电路始终接入电源，而通过外电路向其送入触发信号，从而启动电路工作。这种方式每触发一次完成后便停止工作，当要求其连续工作时，必须在一个循环结束时向其触发端送入触发信号才能进入下一个循环周期。

# (四).使用注意事项:

由于电路采用CMos封装，容易受外界静电影响而损坏，在焊接这类封装片时，电烙铁最好外壳可靠接地，功率不要大于30w，同时焊间时间不能过长，否则容易使音乐集成电路上的铜皮脱落，重则损坏芯片。
