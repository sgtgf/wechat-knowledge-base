## 实例解析：热传导问题的模拟

考虑一个具体场景：有一根厚壁圆管，管道内部和外部的温度分别为0度和10度，圆管自身的初始温度为2度。要模拟这一热传导过程，我们可以利用上述差分方程进行迭代计算，找到介质内部稳态时的温度分布。

### 「Fortran实现」

利用Fortran语言，特别是其`forall`语句提供的便利性，我们可以高效地实现该问题的数值解法。代码中，通过逻辑数组`mask`来定义域的边界条件，区分需要固定和更新温度的几何区域。例如，外层循环设定整个网格的初始温度为10度，然后根据管道的形状和位置设定特定区域为0度或2度，最后通过迭代过程逐步更新媒介区域的温度值。本例中，取步长h\=1。

`program Heat     implicit none     integer, parameter :: n = 101     real    :: mesh(0:n + 1, 0:n + 1)     logical :: mask(n, n)     integer :: i, j, iter     ! define shape : concentric circle       mask = .false.            forall (i = 1:n, j = 1:n, (i - 51)**2 + (j - 51)**2 < 50**2) &     mask(i, j) = .true.     forall (i = 1:n, j = 1:n, (i - 51)**2 + (j - 51)**2 < 10**2) &     mask(i, j) = .false.     ! initial value     mesh = 10.0     forall (i = 1:n, j = 1:n, (i - 51)**2 + (j - 51)**2 < 50**2) &     mesh(i, j) = 2.0         forall (i = 1:n, j = 1:n, (i - 51)**2 + (j - 51)**2 < 10**2) &     mesh(i, j) = 0.0     ! solve Laplace's equation by iterative method     do iter = 0, 10000       if (mod(iter, 1000) == 0) then  ! character animation         call execute_command_line('cls')           print *, ' iteration =', iter         print '(52i1)', int(mesh(::2,::4))       end if         forall (i = 1:n, j = 1:n, mask(i, j)) &    mesh(i, j) = (mesh(i - 1, j) + mesh(i + 1, j) &         + mesh(i, j - 1) + mesh(i, j + 1)) / 4     end do    end program Heat   `

为了通过简单的动画来显示收敛的过程，我们每1000个迭代步输出一次温度值，并使用了`call execte_command_line ('cls')`。`execte_command_line`是Fortran2008中引入的命令，将参数传递到DOS并执行。`'cls'`是DOS的清除画面命令。

### 「收敛性和结果」


我们对打印结果作了取整处理，超过10度的部分是用\*表示。实际执行结果显示，收敛过程较为缓慢，需要大约5000次迭代才能达到稳定的解。通过打印迭代过程中的结果，我们可以直观地观察到温度分布逐渐平滑，最终趋于稳定。此过程不仅展现了热传导现象的物理本质，也验证了有限差分法在解决此类偏微分方程问题上的有效性。
