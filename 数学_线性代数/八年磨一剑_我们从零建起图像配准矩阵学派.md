# 八年磨一剑：我们从零建起图像配准矩阵学派

图像（精）配准是图像处理、机器视觉领域的基础技术，其中的非匹配区域和噪声干扰问题是长期制约该领域发展，影响亚像元配准精度的核心顽疾。八年来，本团队另辟蹊径，依托循环移位矩阵开展系统性研究，逐步搭建起一套原创理论与技术体系，并最终形成图像配准矩阵学派，现将整个研究历程与核心成果梳理如下。

3. 循环移位矩阵显神功，巧解经典非匹配区域难题

在投稿之前，我们最后一遍检查文章，其中摘要部分关于Stone方法的描述，让我惊出一身冷汗，因为这个方法的描述也提到了最小二乘法。我赶紧让杨炜噋添加与这个方法的对比实验，结果让我们面面相觑，Stone方法和我们方法的结果完全一致。

但好在Stone完全没有注意到循环移位矩阵的存在，可即便如此，那又如何呢？我不甘心，这么好的模型，这么好的结果，文章也写好了，就这么废了。

既然Stone没有注意到循环移位矩阵，我就在想，这个矩阵能带来什么额外好处呢？很快想到，可以通过迭代使用循环移位矩阵来缓解图像配准中的非匹配区域经典难题。具体而言，我们可以通过循环移位矩阵的幂来逐渐缩小两个待匹配图像的非匹配区域，从而不断降低非匹配区域对最终结果的影响。而实验结果也验证了我们这个策略的有效性。这样，我们不经意间，居然克服了在图像配准领域中长期存在而从未被彻底解决的一个经典难题。

于是我们调整策略，把这篇文章的重点从解析解调整为：引入新工具（循环移位矩阵）和缓解非匹配区域影响。我们很快改好文章，并投稿。文章不久便被顺利接收，我们在配准方面的工作就告一段落。

4. 白衣少年突发奇想，一举攻克相位噪声经典难题

在图像配准的相位相关法中，噪声干扰是制约图像配准精度进一步提升的核心瓶颈。图像去噪虽已发展为极为成熟的研究领域，但遗憾的是，现有各类去噪方法在抑制归一化互功率谱（Normalized Cross Power Spectrum，NCPS）的相位噪声方面，均未能取得理想效果。鉴于该问题长期未能得到有效解决，研究人员逐步退出了对其的持续探索，学界近乎形成共识——该问题已不再具备深入研究的价值。

在该问题的研究沉寂多年之后，时间的指针悄然指向2019年。彼时，课题组新来了一位名为朱亮亮的博士生。在学习了循环移位矩阵在图像配准中的应用后不久，他便敏锐洞察到NCPS相位噪声的核心玄机，天才般提出了自相关归一化互功率谱（ANCPS）的新概念（图3），一举攻克了图像配准中噪声干扰的国际难题！

![](八年磨一剑_我们从零建起图像配准矩阵学派_images/img_007_fb3c3b8e9547.png)

  
图3. NCPS与ANCPS的相位信息（左图：NCPS；右图：ANCPS）

具体而言，朱亮亮博士发现并证明，归一化互功率谱的自相关函数与其自身完全等价。这一天才般的发现意味着：当对NCPS进行自相关运算时，既能完美滤除其中的相位噪声，又能完整保留其固有信号信息。如此一来，长期困扰图像配准领域的噪声干扰这一国际性难题，便被我们以极具创新性的方式完美破解！

此外，朱亮亮博士又进一步完善算法，使得其可以适用于任意相似匹配问题。

5. 图像配准的李群李代数结构

很多同行，对于数学的认知，大都停留在工具层面，认为数学的主要价值在于可以用来解决各种应用问题。而本人对数学的品味，则深受杨振宁先生的影响。尤其是杨振宁下面这段对数学的评述，让我深以为然。

【杨振宁原话】我欣赏数学家的价值观，我赞美数学的优美和力量：它有战术上的技巧与灵活，又有战略上的雄才远虑。而且，堪称奇迹中的奇迹的是，它的一些美妙概念竟是支配物理世界的基本结构。

同样，对于图像配准问题，我也在思考其背后更本质的代数结构问题。经过一系列的推演，我们很快发现了图像配准的李群李代数结构，并证明了矩阵李代数角度与前面CSM解析解的等价性。

至此，关于图像配准，我们从工具层面、到技法层面再到代数结构层面，一气贯通。

7. 小结

从八年前的灵感一现，到现在的遍地开花，经过八年的持续探索，团队在图像配准，尤其是图像精配准领域经历了从零诞生工具、创建通用算法、解决行业顽疾、提升理论体系、落地工程应用、形成专属学派的全链条闭环原创体系。

在图像精配准领域，目前这套体系应该就代表着国际领先水平。后续或许有精度更高的配置算法出现，但很难绕过我们的循环移位矩阵和自相关归一化互功率谱的基本概念。

如今，我们还在带着学生在这个方向继续深耕，将来希望有更多，更好的算法诞生、落地。
