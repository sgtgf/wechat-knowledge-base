## 1）去括号：本质就是“分配律 + 符号规则”

### 核心规则

1.  **乘法分配律**
    
    ![$a(b+c)=ab+ac$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntIGhDGTCFmZicibOVBc0rW4g1ic79C30u2JhO8tg9KZkZ1IN7YOPnrb2p4Q/640?wx_fmt=png&from=appmsg)
    
2.  **括号前是减号，相当于乘以 -1**
    
    ![$-(b+c)=-b-c,\quad -(b-c)=-b+c$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntIib2GIiaZSSutDhK49qbcErhrIg2n64v6I4rL0AmibB4DVwA4G9kMDar3Q/640?wx_fmt=png&from=appmsg)
    

### 图里的例子怎么用“去括号”

题意：下半年比上半年每月少用 2000 kW·h，全年用电 150000 kW·h。  
设上半年每月平均用电 x kW·h，则下半年每月 x−2000 kW·h。

全年用电：

![$6x + 6(x-2000)=150000$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntILqTmRFskMuPBhjsDibvoKRqcDZ7OkcwbFcYxBNPh59sKfQIh235fHuA/640?wx_fmt=png&from=appmsg)

**去括号**（把 6 分配进去）：

![$6x + 6x - 12000 = 150000$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntI5WdW7mYPicf2BDic5GyPkiaffR3TibWcZauAia0qvyXtUKRw9aZfQdEicAWA/640?wx_fmt=png&from=appmsg)

然后就是常规一元一次方程：

-   移项：  ![$\;6x+6x = 150000 + 12000$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntI7yNibEPCRGef2H5XXibPqNw6eyOPibG2yHNQrmnd7tD11jmXnAJUadd4A/640?wx_fmt=png&from=appmsg)  
    
-   合并：  ![$\;12x = 162000$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntIkL9nY5H7kWYmLyia87a2gvI0BZAu6I3hAz2eHgC6ia7mBo5ReWsxhwMQ/640?wx_fmt=png&from=appmsg)  
    
-   系数化为 1：  ![$\;x = 13500$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntIkEsMBQzUUicdaUOHN53Dnd9L2HzeBMyib1jHlxQD9drGFeF8ZWn5iap9w/640?wx_fmt=png&from=appmsg)  
    

所以图最后得出：上半年每月平均用电 **13500 kW·h**。

### 去括号最容易错的点

-   **忘了乘括号里每一项**：比如 6(x−2000) 不能只写成 6x−2000，要写成 6x−12000
    
-   **减号分配符号出错**：−(x−3) 是 −x+3，不是 −x−3
    

* * *

## 2）去分母：本质就是“两边同乘最小公倍数（LCM）”

分母让人难受的原因：它让方程里出现分数。解决方法非常统一：

### 核心规则

如果方程里有分母，就找所有分母的**最小公倍数 LCM**，然后**方程两边同时乘 LCM**：

-   等式两边同乘同一个非零数，等式仍成立
    
-   乘完后，分母就被“约掉”，方程变整齐
    

### 小例子（典型分母消除）

![$\frac{x}{3}+\frac{x-2}{2}=5$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntIbC1erpYkkX8uoGuJvPthQ8ZI0icsyRCPL0dB8gibjhXg8NsWhg6YNf6g/640?wx_fmt=png&from=appmsg)

分母 3 和 2 的 LCM 是 6，两边同乘 6：

![$6\cdot \frac{x}{3} + 6\cdot \frac{x-2}{2} = 6\cdot 5$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntIQkib8icJpyOxFXKhKwUv14k0EdaCYmHnTgEuHyQcP42O8uzQviabngB2g/640?wx_fmt=png&from=appmsg)

约分：

![$2x + 3(x-2) = 30$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntI27WTmD9rSdKEcicz7lDlfpvFSaibVwaJMs5KKexSzPu1tS1zdvWn0E0g/640?wx_fmt=png&from=appmsg)

再去括号：

![$2x + 3x - 6 = 30 \Rightarrow 5x = 36 \Rightarrow x = \frac{36}{5}$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntIgRGWhzibIibqW8pC6YkFKvIE46XDBynwuajibOFKE6zcMZqq7x3lxb6iaw/640?wx_fmt=png&from=appmsg)

### 去分母最容易错的点

-   **LCM 没选对**（漏了某个分母或没取最小公倍数）
    
-   **只乘了某一项，没乘整个等式两边**（一定要“整条等式一起乘”）
    
-   **括号没带上**：比如 ![6\cdot\frac{x-2}{2}](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntISSCG7bFSicxro22ctYfzsq1bnnBvwYkhhhAs32V6aVrUem3BQso9xyg/640?wx_fmt=png&from=appmsg) 一定要理解成 3(x−2)

## 3）一个很实用的“标准解题流程”

遇到含括号、含分母的一元一次方程，基本都按这个顺序最稳：

1.  **先去分母**（两边同乘 LCM）
    
2.  **再去括号**（分配律展开）
    
3.  **移项**（含 x 的到一边，常数到另一边）
    
4.  **合并同类项**
    
5.  **系数化为 1**（两边同除以 x 的系数）
    
6.  **验算**（代回原式检查）
    

我们就沿着图里的思路，把“去括号 + 去分母”再讲得更“像做菜一样有套路”，并配几道典型题（含易错点）。

## 5）去分母的“标准动作”：两边同乘 LCM

### 关键提醒

-   你不是“给某个分数乘”，而是**给整条等式乘**
    
-   乘完后每一项都要乘到，不要漏项

## 7）一个“自检清单”（写完就扫一眼，错误率会大降）

1.  去分母时：**LCM 找对了吗？每一项都乘到了吗？右边也乘了吗？**
    
2.  去括号时：**括号前是负号吗？每一项都分配了吗？**
    
3.  合并同类项时：**只合并同类（同是 x 项 / 同是常数）**
    
4.  最后：**代回原式验算**（尤其是分式方程）
    

那我们把“去括号与去分母”继续往下走：更像课本的**应用题** + **带坑点的练习题**，并把“为什么这样做不会错”讲清楚。

* * *

## 8）把它当成一个“变形游戏”：等式两边做同一件事

无论去括号还是去分母，本质都只有一句话：

> **等式两边同时做同样的运算（且不做非法运算），等式仍然成立。**

-   去括号：用分配律把表达式展开（没改变值）
    
-   去分母：两边同乘 LCM（相当于把“分数”统一扩大成整数份）

## 12）带坑练习：分母里“有括号”时，先整体乘，再展开

解方程：

![$\frac{x-3}{4} - \frac{2(x-1)}{3} = 1$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntIzMiaS6mqicrBBXnkzb8icJF1tUVBibWTjYvGpWM3ibo7vOMzn9lnMOJNPeQ/640?wx_fmt=png&from=appmsg)

LCM 是 12，两边同乘 12（**每一项都要乘**）：

![$12\cdot\frac{x-3}{4} - 12\cdot\frac{2(x-1)}{3} = 12$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntIF1ImeFxvaYNUF7nXycteBBMVWOqNhsyhmObn0xszy98CjC7OJEBrlg/640?wx_fmt=png&from=appmsg)

约分：

![$3(x-3) - 4\cdot 2(x-1) = 12$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntITKmN7qt7LEME2CQiagoiawcLD823mWKlS9xic3ePL38j0HbKevSUIaygg/640?wx_fmt=png&from=appmsg)

也就是：

![$3(x-3) - 8(x-1)=12$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntIWLR14TfSa4icDxVtno3OUtSS4aZC4WZDq0icJBiaQQy4OdqJtX1tZCKKg/640?wx_fmt=png&from=appmsg)

去括号：

![$3x-9 - 8x + 8 = 12$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntI6vNCFJKyuV7dBv7GDjF2CYQfgNhZllcmqCWTqZGMYSQN7XCGjNMy5Q/640?wx_fmt=png&from=appmsg)

合并移项：

![$-5x -1 = 12 \Rightarrow -5x = 13 \Rightarrow x = -\frac{13}{5}$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntIDwh8ZD0cFRvl4azIagL3QEyIibX8s5SHaLxqsnW9rOe8Kh3klOESOrw/640?wx_fmt=png&from=appmsg)

\*\*最常见错法：\*\*把第二项乘 12 后写成 ![12\cdot\frac{2x-1}{3}](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntIZ8JSZmIysKs9EGnGunXFEjsDiaNTHGMDagiacnYrKgicdkZ5YsznXyjmw/640?wx_fmt=png&from=appmsg) 这种“把括号拆坏”的写法。  
正确做法永远是：**先乘整项，再约分，再去括号。**

## 13）一个重要补充：什么时候“去分母”必须加限制？

如果分母**只是数字**（比如 2、3、5），那你直接乘 LCM 很安全。

但如果分母里**含 x**（比如 ![\frac{1}{x-1}](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trKRPCNoZEyBEJ0R9O1ibntIfP9ibkdpqEia2hbLia0MiaKpksAeic2w1fKoRLaDvNXtibWvLbFI4cUozOpQ/640?wx_fmt=png&from=appmsg)），那严格来说已经接近“分式方程”了，这时必须先写：

-   **定义域限制**：分母不能为 0（例如 x≠1）
    
-   解出来还要**代回检查**，避免把非法值当答案
    

中学课本在“一元一次方程去分母”阶段，通常分母都是常数，所以一般不强调这个坑，但你知道它会更稳。
