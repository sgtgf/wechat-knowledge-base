# 在DC/DC电源转换器中过温保护的方式

原创 电路一点通 2025-02-02 11:28 广西

> 原文地址: [https://mp.weixin.qq.com/s/y209mA2A7KILtFHsNUkrdw](https://mp.weixin.qq.com/s/y209mA2A7KILtFHsNUkrdw)

近期许多电子设备因为内部温度过热而使功率电晶体损毁、变压器寿命减短，甚至造成系统_误动作_，故当_温度_过高时，电源转换器的保护线路成为一个必要的设计。接下来将介绍过温保护的线路设计，最后实作电源转换器结合温度开关，透过调整电阻值来决定温度保护点，以避免超过安全温度的风险。

**绪论  
**工厂内常见的CNC机台、家庭内的电热烤箱或其他大功率的电子设备，其内部电源转换器长期处于重负载或放置于高环境温度下，当外壳温度一旦高于规格书标示的最大温度时，容易使电源转换器内部零件受损。为了保护电源转换器以及后端的电路系统，故设计上需要温度保护机制。过温保护(Over Temperature Protection, OTP)用来防止电源转换器在过温情况发生之后持续输出造成零件损坏。

一般量测转换器外壳中心点的温度作为过温保护的标准温度，如图1，一旦此温度超过规格书的最大外壳温度，电源转换器则关闭。因此当转换器运作时，提供适当的冷却方式以将外壳温度保持在最大外壳温度以下，以减少过温情况发生。

![](D:\电脑文件\公众号知识库\电力电子_DC_DC变换器\在DC_DC电源转换器中过温保护的方式_images\img_001_12573041c8a0.png)

高可靠性的电源转换器设计有内建过温保护机制，可以快速侦测到温度变化，并能即时触发_保护机制。另一方面，如果使用者拿到无_内建过温保护机制的电源转换器时，又该如何实现过温保护功能呢? 此仍可以加入温度开关来实现。本文说明过温保护功能的概要，以及实作电源转换器搭配可程式化的温度开关器TMP708，相邻焊接于印刷电路板，以实现过温保护为本实验选用之重点。  

过**温保护结构**

应用在DC/DC电源转换器中，大都因为过电压或过电流持续一段时间，造成内部零件温度过高，再藉由侦测外壳中心温度，来判定过温保护的时机。过温保护会关闭电源转换器输出电压，并直到温度下降低于回复值，电源转换器会自动重新启动至输出电压恢复于标准值。

图2是返驰式转换器搭配内部温度感测器的基本架构，感测器测得电源转换器释放的热能，受到感测器放置距离不同而各有差异。温度感测器相邻于高温零件旁，能比较敏感于温度；反之温度感测器离高温零件较远的话，则无法取得当下最高_温度_讯号，故当外壳中心点温度已到最大值，但感测器温度尚未到温度临界点，并予造成危险。

大功率模式运作时，热能透过电路板传递到温度感测器，一旦感测到高于温度临界点时，会立即停止能量转换动作，以关闭转换器。

![](D:\电脑文件\公众号知识库\电力电子_DC_DC变换器\在DC_DC电源转换器中过温保护的方式_images\img_002_37307146ca87.png)

图3是返驰式转换器搭配外部温度开关的基本架构，首先选择一个提供正逻辑远端控制开关功能的电源转换器，能够透过控制引脚(Ctrl)使得转换器进入待机模式，或使转换器重新启动。再将温度开关器紧贴在电源转换器的发热零件(M1)外壳旁，以确保转换器温度能传递到感测器，当转换器温度过高时，温度开关开启使得控制讯号接地，以关闭转换器。

![](D:\电脑文件\公众号知识库\电力电子_DC_DC变换器\在DC_DC电源转换器中过温保护的方式_images\img_003_a0d774ca639e.png)

此方式虽然精准度不及内建温度感测器类型，但可以依照实际环境变化，动态地调整温度临界值，例如转换器于_工厂_作业区内_高温暴露环境时需提高温度临界值。尽管如此，_这不仅增加外部零件数量，也会增加线路设计的复杂度。若要简化设计，可选择具有内建保护功能的温度感测控制器，可以减少零件数量和印刷电路板大小。

_电源转换器不论搭配内部或外部的温度开关，都可以当转换器外壳到达指定温度时，输出电压会立即关闭，此时系统可切换至其他供电设备供电，直到外壳温度下降至恢复值以下时，转换器会自动重新开启，其行为模式如图4。_

 **实验**

**功能介绍**

下表为本实验选用的直流-直流电源转换器规格

Power Converter

3W, SIP8 package

Input Voltage

4.5-9Vdc, Nom. 5Vdc

Output Voltage

12Vdc

Output Current @full load

250mA

Operation Temperature

\-40~100°C

基本的过温保护动作是感应温度、判断温度是否过大、然后决定关闭转换器。本实验使用外部温度开关器的感测器去侦测转换器外壳温度，以及外加电阻R4来偏压转换器控制讯号、电阻REST决定温度临界值，系统方块图如下。

![](D:\电脑文件\公众号知识库\电力电子_DC_DC变换器\在DC_DC电源转换器中过温保护的方式_images\img_005_423cef585fec.png)

本实验选用一个积体化的可编程电阻的温度开关TMP708，此有过温度保护功能为本实验选用之重点，它内部有正/负温度相关的参考电压与比较器。

TMP708的SET 接脚与GND 接脚之间接上误差1% 电阻器RSET，此电阻可调整温度临界值；OT接脚接到电源转换器的控制开关，此根据转换器的开关逻辑来决定OT脚位输出是否需要加反向器；HYST 接脚允许将输入迟滞设置为10°C（当HYST = VCC 时）或30°C（当HYST = GND 时）。

**实作波形**

图6为电源转换器从正常运作模式进入保护模式，再回到正常运作模式的波形。将转换器放置于高温环境中，一开始送电输入电压，转换器开启而输出电压稳定于12V于重负载模式，此时机壳温度不断上升，直到温度临界点70°C时，OT讯号转成高电压准位且将控制脚位CTRL拉至地，转换器进入温度保护模式，输出电压也降为0V，将转换器移至室温环境，此时的机壳温度快速下降，直到回复温度值约55°C时，转换器会自动地从保护模式回复正常运作模式，保护模式状态解除，此时输出电压升到12V。

![](D:\电脑文件\公众号知识库\电力电子_DC_DC变换器\在DC_DC电源转换器中过温保护的方式_images\img_009_15d08a3ca77a.png)

 **结论**

大功率转换器使用外部温度开关，有效地防止电源转换器在过温环境时仍持续运作而造成系统损坏，以提高电源转换器可靠性。本文实作一个过温保护实验，使用可编程温度开关IC减少线路设计的复杂度并提高功能性，最后结合电源转换器，以实现过温保护功能。
