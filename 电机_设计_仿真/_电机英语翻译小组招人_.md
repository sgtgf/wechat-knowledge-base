# 【电机英语翻译小组招人】


> 原文地址: [https://mp.weixin.qq.com/s/yGFxh5l5nbAjxDYVPkpjqg](https://mp.weixin.qq.com/s/yGFxh5l5nbAjxDYVPkpjqg)

**翻译什么？**  

翻译顶级期刊的比较好的关于电机方面的文章；

翻译国外电机材料、制造设备、测试设备新闻；

传递比较新的研究热点、研究方法、解决方案、新材料、新工艺。

  

**为什么做这件事？**

国内很多电机从业人员的英语水平有限，阅读文献比较吃力，工作忙没时间关注最新的行业和技术发展趋势。希望他们通过阅读我们的最新文献摘要能把思想跟上电机行业全球发展热点、方向、方法。

希望通过这样的行动能为中国电机事业的发展做一点贡献！

  

**欢迎你加入！**

**加入条件，具备下列条件之一：**

1.  能翻译电机相关技术文献；
    
2.  能提供优秀的外文电机技术文献，包括文献、公司新闻、报告等；
    
3.  有志于促进中国电机事业的发展；
    
4.  想提升、保持自己的英语水平；
    

  

**加入方法：**

扫下方二维码，小编拉你入群。
