# 什么是齐次矩阵？


> 原文地址: [https://mp.weixin.qq.com/s/6aCn\_-s\_03bs23WPeF3clg](https://mp.weixin.qq.com/s/6aCn_-s_03bs23WPeF3clg)

齐次矩阵（Homogeneous Matrix）是一种特殊的矩阵，主要用于计算机图形学、机器人学和3D建模中。它不是普通的矩阵，而是用来描述点或物体的“变换”（比如移动、旋转、缩放）的工具。简单来说，它让复杂的空间变换变得像乘法运算一样简单。

要理解齐次矩阵，先得知道“齐次坐标”（Homogeneous Coordinates）。平时我们用笛卡尔坐标表示一个点，比如2D平面上的点是(x, y)，3D是(x, y, z)。但齐次坐标会多加一个维度，通常是1，比如2D点变成(x, y, 1)，3D变成(x, y, z, 1)。这个额外的“1”就像给坐标加了个“标签”，让计算更统一。

为什么这么做？因为在普通坐标下，旋转和缩放可以用矩阵乘法，但“平移”（移动位置）得用加法。这样混在一起计算很麻烦。齐次坐标就把所有变换都统一成矩阵乘法，超级方便！

齐次矩阵长什么样？

对于2D图形，齐次矩阵是一个3x3的矩阵；对于3D，是4x4的。它的结构通常是：

-   上部分：描述旋转、缩放、剪切等线性变换。
    
-   右边或下边：描述平移。
    
-   最后一行：通常是\[0, 0, 1\]（2D）或\[0, 0, 0, 1\]（3D），保持齐次性。
    

  

“齐次矩阵”这词，其实是两件事绑在一起说：

1.  **齐次坐标（homogeneous coordinates）**
    
    把 2D 点 ![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM57nAgJzRzdv1uiaeNwBQmFNPs9EfCC9jg74bNibjfSKyHVZib77UQUFATicJHEyG1XYwsGibSrEAa97ghfzqWlYHQV25BdO9bVBuEnp6KLngGTIlA/640?wx_fmt=svg&from=appmsg) 变成 3D 的 ![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM5QUQFrXvtqP9rOvkgHwp8rOHmgMibIqzrdNObsLrAibpRSf2dPx93nYdOxmca4icr7A6JQVTeiboRG2uJyC5qCJibJvaOlBHP8r93NRQKOISsejibA/640?wx_fmt=svg&from=appmsg)，并且**把“同一条射线上的比例点”视为同一个几何点**。
    
2.  **齐次矩阵（homogeneous matrix）**
    
    用一个更高一维的矩阵（2D 用 ![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM4Y559V5uMGT4G1HiaJhdZ949WQyEMrTjU6NMWpGbJrUibD1Fib5E5yTRW51vJx24SzQOGkO9bDl0wCjNNwav48Gn2xlgrZia6vTs2svjWic3k8mbA/640?wx_fmt=svg&from=appmsg)，3D 用 ![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM55V7C7hCRTTu7TjzAVjYLSMjpGyY3uHByRObszhvo38QEahgr40bs6MmErCicjarAPZrWAKdjM23qIgRiaiaEEC56uO5WuekGeYryEObzMd97JA/640?wx_fmt=svg&from=appmsg)）去统一表示**平移、旋转、缩放、剪切、透视投影**等变换，而且可以像普通矩阵一样连乘组合。

## 3) 为什么非要多一维？——为了把“平移”也变成矩阵乘法

在普通 2D 里，平移是：

![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM5jJ9QdfEibgUss673eDhAoLMibSjLrEiaVaDYLU8VYP0cXPWGsu8AtDM0nv9WGmavPbpaZx3KfVPiaC5OiafuAUOAtddtjSnaANsibdY0YKR6jZQew/640?wx_fmt=svg&from=appmsg)

这不是纯矩阵乘法（有加法项）。

但在齐次坐标里：

![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM6gjYBbn6Uh4MLcxLPKR25MCncsNLQgG2ACoocbiaD76wf5QR0oyn5oKnMZWvnuic7RZoOkWrStBHgungGEibnXkvXsGRm0rNanbSvaqZTiamds5g/640?wx_fmt=svg&from=appmsg)

平移被“塞进”矩阵最后一列里，于是**平移、旋转、缩放都能统一成一次矩阵乘法**，并且能直接连乘组合（先做 A 再做 B 就是 BA）。
