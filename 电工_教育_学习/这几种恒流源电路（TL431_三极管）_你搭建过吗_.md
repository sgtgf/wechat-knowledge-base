对于电源，我们最常接触的是恒压源，日常生活中也最常使用到。而还有一种电源叫恒流源，这种电源用得比较少，但也不是少得见不到，比如LED的驱动电源就是恒流源，还有在测量电阻的紧密仪器中也会用到恒流源电路。

1.  **使用两个NPN三极管搭建的恒流源。**
    

搭建电路如下：

![](D:\电脑文件\公众号知识库\电工_教育_学习\这几种恒流源电路（TL431_三极管）_你搭建过吗__images\img_008_300114f18f6f.jpg)

  

分析上述电路可知：

Ic + Ib\_NPN1 = Vbe / Rref – Ib\_NPN2

Vbe为三极管发射结压降0.7V，得出：

Ic = Vbe / Rref + Ib\_NPN1 – Ib\_NPN2

仿真结果如下：

![](D:\电脑文件\公众号知识库\电工_教育_学习\这几种恒流源电路（TL431_三极管）_你搭建过吗__images\img_009_f9c865a25f87.jpg)

  

据此计算可得：

Ic = 0.7V / 2Ω - 0.003466A + 0.000101A = 0.346635A。

一般来说，三极管的基极电流很小，可以忽略。所以，对于该电路，可以有如下公式：

Ic = Vbe / Rref

对于该电流源电路，由于三极管的Vbe容易受到温度影响，所以其精度较低。

1.  **使用TL431和三极管搭建的恒流源**
    

针对上一个电路的缺点，改善方法可以使用一个TL431替代其中一个三极管，也就是使用温漂系数小的TL431的2.495V基准电压替代三极管的Vbe。

![](D:\电脑文件\公众号知识库\电工_教育_学习\这几种恒流源电路（TL431_三极管）_你搭建过吗__images\img_010_0255fc8d3c8b.jpg)

  

分析该电路可知：

Vref / Rref = Io + Ib

其中，Vref = 2.495V。

仿真结果如下：

![](D:\电脑文件\公众号知识库\电工_教育_学习\这几种恒流源电路（TL431_三极管）_你搭建过吗__images\img_011_a72d6a802104.jpg)

  

据此可计算：

Io = 2.495V / 2Ω - Ib = 1.2475A – 0.00621 = 1.24129A

可以看出计算的Io与仿真结果有些许差距，这是应为TL431的反馈脚也会有电流流入。由于Ib和TL431反馈脚的电流很小很小，可以忽略不计，所以这个恒流源可以由下式计算：

Io = 2.495V / Rref

以上恒流源电路在合理范围改变Rload的大小，流过Rload大小不会改变。有兴趣的可以自己搭建电路试试。
