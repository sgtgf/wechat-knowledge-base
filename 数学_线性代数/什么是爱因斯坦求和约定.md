# 什么是爱因斯坦求和约定


> 原文地址: [https://mp.weixin.qq.com/s/6viMjfmMjbAhl2HGiXyvcA](https://mp.weixin.qq.com/s/6viMjfmMjbAhl2HGiXyvcA)

**爱因斯坦求和约定**（Einstein summation convention）是物理和工程中超级常用的一个“偷懒写法”，特别在**相对论**、**张量分析**、**机器学习张量运算**里几乎无处不在。

简单一句话概括：

**同一个下标（或上标）在同一个项里出现了两次，就默认要对这个下标从1求和到维度数，不用再写 ∑ 符号了。**

### 生活化比喻

想象你在超市买东西：

-   正常写法：把每种商品的价格 × 数量，然后把所有商品加起来 → ∑ priceᵢ × countᵢ
    
-   爱因斯坦偷懒法：priceᵢ countᵢ  （直接写，意思一样：自动把所有i项加起来）
    

他就是把“∑”这个动作藏起来了，只要看到**同一个字母出现了两次**，就知道“哦，这里要偷偷求和”。

### 4) 指标类型：自由指标 vs 求和指标

-   **自由指标**
    
    在等式一项里只出现一次，决定结果“长什么样”（结果的维度/形状）。
    
-   **求和指标（哑指标 / dummy index）**
    
    出现两次，被消去（被加总）。
    

一个很实用的检查法：

> 等式左右两边的自由指标集合必须一致；  
> 重复指标只能出现在右边表达式中（被求和消掉）。

比如 ![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM5kVRWP9Rovvv3r3SAebhJqwkEALuKXz1bHzpUmOrx8xJ3K5ThziaA23Qk5j8libx5Ft7JmOJSIOL3kkCoHva8nXJp8icvD4421I8dEe9LfNf2rA/640?wx_fmt=svg&from=appmsg)：自由指标是 ![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM6EoXJIuKFsARSdxu1FHvicOubspNY3RJXLZjutYicgA6390oGVUZibjYW7sgwfoOxIRJFu1Fanca2XPRwXuvnUsJ8KRVLqLKKMR1UzX90SrtSiaw/640?wx_fmt=svg&from=appmsg)，两边一致 ✅

### 5) 常见坑（写久了最容易踩）

1.  **同一个指标在同一项里出现 3 次或更多次**  
    
    经典 Einstein 约定里通常视为“不合法/歧义”，因为你到底怎么求和会变得不清晰。  
    （有些领域会扩展规则，但初学阶段别这么写。）
    
2.  **重复指标不一定要相邻**  
    
    只要在同一项里重复出现就会求和，例如 ![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM7IZWvUDD9ameibr2nPY5ViaqVfHibicLOUnibXoxqQ1U1IOcjHGM0NiaGDYial2Tjx9YWwA1qicG3ezySyTYyM7NmBKfYw4ZXqHVgVV0ib3hxoXmWtvVw/640?wx_fmt=svg&from=appmsg) 也会对 ![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM5EsjF1J9mGjY1LGjAFySTRAjxLjT6zlYLry1kDLISziaW7Pxvd2Bhc949efo1xk9M0mbr2F3JzTI8lEaeVhrTeSxsspL29IDeSUJvwagxP9sQ/640?wx_fmt=svg&from=appmsg) 求和。
    
3.  **上标/下标（协变/逆变）版本**  
    
    在相对论/微分几何里更严格：通常是“一上一下重复才求和”。  
    你现在这种线代/机器学习语境，常用的就是“同一项出现两次就求和”，不区分上下标也能用得很顺。

### 6) 和代码的直觉对应（numpy / PyTorch）

你可能会在代码里看到 `einsum`（就是 Einstein summation 的直接落地）：

-   矩阵乘法：
    

-   记号：`c_ik = a_ij b_jk`
    
-   numpy：`np.einsum('ij,jk->ik', A, B)`
    

-   矩阵-向量：
    

-   `y_i = A_ij x_j`
-   `np.einsum('ij,j->i', A, x)`

这基本就是把“重复指标自动求和、自由指标保留到输出”写成字符串规则。

这张图在讲一种把 **爱因斯坦求和** 画成“连线图/张量网络（tensor diagram）”的记号：

-   **每个圆点 = 一个张量（向量/矩阵也算张量）**
-   **圆点旁边标的字母 ![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM4I4Awoic9Cau5q4kAYDNwqkibI8egyl2LEUqWU7GwWkjmN8xibAibn52xiaicxgvzX537rz6IthwzibKmd4nD9H8tLsgn72BECeJz0PdcbFC274OD5Q/640?wx_fmt=svg&from=appmsg) = 这个张量的指标（维度方向）**
-   **两点之间连起来的一条线 = 这两个张量共享同一个指标，并且对这个指标求和（收缩 contraction）**
-   **没被连走、露在外面的线 = 自由指标（输出会保留的指标）**

### 3) 一个“看图秒判”的小口诀（很实用）

-   **两条腿连掉一条**
    
     → 对应矩阵乘法（留下两个自由指标）
    
-   **两条腿都连掉**
    
     → 标量（内积 / trace 类）
    
-   **连线若“交叉”**
    
     常出现 ![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM7ZBo5DU4FNRWmELCSDjxzVoCowBiae8oic8MYVhEdIBNJTc3ImiaicwJnC0LOr5P1mFbsoZoHicGx6Dvo3mptRDibNn2Z3ric6UzxYxDbLjH9QzWbFQ/640?wx_fmt=svg&from=appmsg) 这种转置/换序效果
    
-   **闭环**
    
     → trace；**闭环能旋转** → trace 循环不变性
