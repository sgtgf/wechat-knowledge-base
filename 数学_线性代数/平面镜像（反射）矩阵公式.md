### 1) 先把几何关系说清楚：反射 = “法向分量翻转，切向分量不变”

给任意向量/点（用列向量）x，相对于镜面（法向量为 n）我们做[正交分解](https://mp.weixin.qq.com/s?__biz=MzkzODgwODczMw==&mid=2247489540&idx=1&sn=90593d2b79425be1b6b01e1ec3fce6e6&scene=21#wechat_redirect)：

-   **沿法向的分量**
    
    （[投影](https://mp.weixin.qq.com/s?__biz=MzkzODgwODczMw==&mid=2247489081&idx=1&sn=9c11b39f9d77ecc0d8f035beb199c6d7&scene=21#wechat_redirect)到 n 上）![](平面镜像（反射）矩阵公式_images/img_001_240cbda23db5.svg)
    
-   **在镜面内的分量**
    
    （与 n 垂直）![](平面镜像（反射）矩阵公式_images/img_002_59afc918b831.svg)

-   法向的 ![](平面镜像（反射）矩阵公式_images/img_004_a21005f7020b.svg)**取相反数**

### 1) 这个 M 到底在反射哪个平面？

法向量 ![](平面镜像（反射）矩阵公式_images/img_059_226c3a73451f.svg) 且平面过原点，所以镜面（反射平面）是

![](平面镜像（反射）矩阵公式_images/img_060_17d53229aa2c.svg)

### 通用定义

-   在线性代数中，对于 ![](平面镜像（反射）矩阵公式_images/img_061_270de690067c.svg) 空间中的Householder反射（这里 d = 3，即三维空间），反射平面是一个**超平面**（在3D中就是一个二维平面），并且它**通过原点**。
    
-   这个平面**垂直于**给定的法向量 n。
    
-   数学上，平面由所有点 ![](平面镜像（反射）矩阵公式_images/img_062_36802d5d5f13.svg) 组成，这些点满足方程：![](平面镜像（反射）矩阵公式_images/img_063_9e040597fa21.svg)  
    
    这是一个点积条件：平面上的任何向量 x 都与 n 正交。
    

###   

### 针对 ![](平面镜像（反射）矩阵公式_images/img_064_1f0317a5f643.svg)

-   代入值：![](平面镜像（反射）矩阵公式_images/img_065_a1fdd6855302.svg)
    
-   这个方程定义了平面：所有坐标和为零的点（例如 (1, -1, 0)、(0, 1, -1) 等）。
    
-   几何上：这是一个与x、y、z轴等角度倾斜的平面，通过原点。
    
      
    

### 关键性质

-   反射矩阵 M 会将任何向量关于这个平面进行镜像。
    
-   平面上的向量保持不变（如果 x 在平面上，则 ![](平面镜像（反射）矩阵公式_images/img_066_eab6c07975ae.svg)）。
    
-   法向量 n 被反射为其负值（ ![](平面镜像（反射）矩阵公式_images/img_067_d51a49118b8b.svg)）。
