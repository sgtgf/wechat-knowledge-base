# 多类运动想象脑电信号的两级特征提取方法

原创 自动化学报 2016-12-30 16:40 北京

> 原文地址: [https://mp.weixin.qq.com/s/rBvXFv4\_4V4NsmoVfH8CZw](https://mp.weixin.qq.com/s/rBvXFv4_4V4NsmoVfH8CZw)

人在进行不同肢体运动或想象时，在大脑皮层运动感知区会产生特定的自发性的脑电信号（Electroencephalogram, EEG).运动想象型脑机接口（Brain-Computer Interface, BCI）通过捕捉和识别不同运动想象任务时的EEG，来实现大脑和外界的信息交换和控制.如何从高度复杂的运动想象EEG中提取出能有效识别运动任务的特征，对于BCI系统的性能至关重要. 

目前，共同空间模式（Common Spatial Pattern, CSP）及其改进方法是运动想象EEG分析中最有效的特征提取方法。CSP是一种针对两类运动想象EEG的处理算法，通过同时对角化两个协方差矩阵构建最优滤波器来进行特征提取，在两类运动想象任务问题上得到很高的分类准确率. 因此，许多研究者尝试将CSP推广到多类运动想象EEG分类问题上，提出多类CSP的改进算法.但是，这些方法在多类运动想象任务识别问题上并没有获得理想的结果. 

最近兴起的深度学习理论为提取任务区分度高的特征来提高识别正确率提供了可行方向。堆叠降噪自动编码器（Stacked Denoising Autoencoders, SDA）是一种典型的深度学习网络模型，通过组合低层特征形成更加抽象的高层次的特征表达，是一种自动提取表示属性类别的高层样本特征的方法.但是SDA是以半监督方式自动学习数据的特征，如果原始数据过于复杂或者信噪比较低，SDA直接学习到的可能并不是与类别属性紧密相关的特征，反而最终导致分类效果并不理想.

本文结合CSP和SDA方法各自的优势，针对多类运动想象任务EEG，先使用一对多CSP（One versus Rest CSP, OVR-CSP）进行变换和特征提取，然后将变换后的特征子集作为SDA网络的输入信号进行高层次特征提取，构成一个两级的多类运动想象EEG特征提取方法。由于SDA不具有分类能力，在SDA网络特征提取后，选取Softmax分类器实现对运动想象任务进行分类.

应用所提出的两级特征提取方法在BCI IV中的Data set 2a数据集上进行了四类运动想象任务分类测试，并与竞赛成绩排在前三名的分类结果进行了比较。竞赛前三名主要采用OVR或OVO方式将CSP扩展到多类，再使用贝叶斯分类器等进行分类。测试实验表明由于本文方法是在OVR-CSP基础上又进行了一级的SDA特征提取，总体Kappa系数均值比只采用CSP特征的方法有明显提高，对各个受试者数据的分类结果都比较稳定，具有较佳的鲁棒性.图1给出了组合使用OVR-CSP与SDA的两级特征提取方法与分别单独使用OVR-CSP和SDA特征提取方法的分类性能比较结果，可以看出两级特征提取方法明显优于单一的OVR-CSP以及SDA特征提取方法。

![](多类运动想象脑电信号的两级特征提取方法_images/img_000_8d8f06fb59e6.png)

在两级特征提取方法中，第一级的CSP特征提取能够得到使运动想象任务具有最大区别的特征，第二级的SDA网络通过自学习更加抽象的类别表达，能提取更高层次的低维特征，使得分类正确率得到明显提高，为多类运动想象脑机接口中的特征提取提供了一种新的思路。
