CMOS: 互补金属氧化物半导体 Computer-aided design (CAD): 计算机辅助设计 Circuit design: 电路设计 Field-effect transistor (FET): 场效应晶体管 Random access memory (RAM): 随机存取存储器 Very Large Scale Integrated Circuit (VLSI): 超大规模集成电路 Application Specific Integrated Circuit (ASIC): 专用集成电路 Bipolar Transistor (BIT): 双极晶体管 Current Mode Logic (CML): 电流模式逻辑 Large Scale Integration (LSI): 大规模集成 Microprocessor Unit (MPU): 微处理器单元 Medium Scale Integration (MSI): 中规模集成 Quantum device: 量子器件 Small Scale Integration (SSI): 小规模集成 System On Chip (SOC): 系统级芯片 Transistor-Transistor Logic (TTL): 晶体管-晶体管逻辑 Complementary Metal-Oxide-Semiconductor (CMOS): 互补金属氧化物半导体 Chip on Board (COB): 板上芯片 Chip on Chip (COC): 叠层芯片

Chip on Glass (COG): 玻璃板上芯片  

Failure Analysis Report (FAR): 失效分析报告 Field Programmable Gate Array (FPGA): 现场可编程门阵列 First Pass Yield (FPY): 首次合格率 Electrostatic Discharge (ESD): 静电放电 Proximity X-ray: 近距离X射线 Process control: 过程控制 Process capability: 工艺能力 Recipe: 工艺流程 Reliability: 可靠性 Schedule downtime: 计划停机时间 Schottky barrier diodes: 肖特基二极管 Random logic device: 随机逻辑器件 Scribe line: 划片槽 Spin webbing: 旋转带 Stacking fault: 堆垛层错 Steam bath: 蒸汽浴 Stress test: 应力测试 Surface profile: 表面轮廓 Symptom: 症状 Tack weld: 点焊 Taylor tray: 泰勒盘 Testability: 可测试性 Total fixed charge density (Nth): 总固定电荷密度 Ultrasonic bonding: 超声波键合 Wafer flat: 晶圆平边 Write enable (WE): 写使能 Computer-Integrated Manufacturing (CIM): 计算机集成制造 Controlled Collapsed Chip Connection (C4): 可控塌陷芯片连接 Direct Metallization System (DMS): 直接金属化系统 High Density Interconnect (HDI): 高密度互连 High Density Multilayer Interconnect (HDMI): 高密度多层互连 Hybrid Integrated Circuit (HIC): 混合集成电路
