# 山东3批次三相异步电动机不合格 汇能电机、兴恒电机、恒力电机等上黑榜

**来源：**齐鲁网****

**齐鲁网·闪电新闻6月6日讯，**山东省市场监管局日前发布2022年三相异步电动机产品质量省级监督抽查结果，结果显示，**汇能电机（山东）有限公司、山东兴恒电机有限公司、山东恒力电机有限公司、威海成冠创新机电有限公司**等生产、销售或使用的3批次产品不合格。

![](D:\电脑文件\公众号知识库\电工_行业资讯\山东3批次三相异步电动机不合格_汇能电机_兴恒电机_恒力电机等上黑榜_images\img_000_de3786319b0d.jpg)

2022年第4批省级监督抽查共抽查三相异步电动机产品29批次，其中，生产领域27批次，流通领域2批次,依据GB/T 14711-2013《中小型旋转电机通用安全要求》、GB/T 1032-2012《三相异步电动机试验方法》、GB/T 1971-2021《旋转电机 线端标志与旋转方向》、GB/T 10068-2020《轴中心高为56mm及以上电机的机械振动、振动的测量、评定及限值》等标准的要求，对三相异步电动机产品的旋转方向、接线盒及接线装置、接地、引线防护等项目进行了检验。

本次抽查发现**汇能电机（山东）有限公司、山东兴恒电机有限公司、山东恒力电机有限公司、威海成冠创新机电有限公司等生产、销售或使用的3批次产品不符合相关标准的要求，不合格项目为效率测定、热试验**。

对本次抽查发现的不合格产品生产者、销售者、标称生产者，山东省市场监督管理局已责成相关市场监督管理部门依据《中华人民共和国产品质量法》《产品质量监督抽查管理暂行办法》以及国家市场监督管理总局、山东省市场监督管理局关于监督抽查的有关规定，做好不合格结果处理工作。

**产品知识科普及消费提示**

三相异步电动机是将电能转换为机械能供给生产机械实现各种运动的一种动力设备，在机械、冶金、煤炭、石油、化工等工业领域应用十分广泛。绝大部分生产机械如各类机床设备、起重设备、运料装置、电铲、轧钢机、水泵、风机和纺织机械等都是采用三相异步电动机作为原动机来拖动的。三相异步电动机具有结构简单、起动方便、体积小、重量轻、效率高及检修方便等优点。选购时建议：

1.注意查看生产企业是否进行了能效标识备案。自2021年6月1日起，达不到3级能效限定值的电机不得生产、销售，使用单位不得采购。电机是被列入能效标识备案管理、工信部节能机电产品和能效之星目录、节能认证目录的产品。

2.不要只看中产品价格而不注重电动机品质，如果是用量较大或者长期需求，最好进行实地考察，这样才有保障。

  

3.如对产品有疑问，可以通过正规的第三方检验机构进行检验。
