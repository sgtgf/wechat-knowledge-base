# 椭圆曲线的“加法”群规则


> 原文地址: [https://mp.weixin.qq.com/s/DLydjzFEKErg5ftFFYArNg](https://mp.weixin.qq.com/s/DLydjzFEKErg5ftFFYArNg)

![](椭圆曲线的_加法_群规则_images/img_000_256625e1344c.png)

这四个式子是在讲**椭圆曲线的“加法”群规则**（chord-and-tangent）。核心口诀是：

> **同一条直线与椭圆曲线的三个交点（按重数计算）相加等于 0（单位元）**  
> 也就是：若直线与曲线交于 A,B,C，则 A+B+C=0。  
> 这里的 0（图里写 0）指的是**无穷远点** O，是加法单位元。

同时，点的相反数是关于 **x 轴镜像**：  
若 ![$P=(x,y)$](椭圆曲线的_加法_群规则_images/img_001_4e15b31d527d.png)，则 ![$-P=(x,-y)$](椭圆曲线的_加法_群规则_images/img_002_5851ec0da468.png)。

* * *

## 1) P+Q+R=0

第 1 幅里蓝线穿过曲线上的两点 P,Q，并与曲线**再交**于第三点 R。  
因此按规则：![$P+Q+R=0 \quad\Rightarrow\quad P+Q=-R$](椭圆曲线的_加法_群规则_images/img_003_e3a4eef5b4b8.png)  
所以**真正的“和”** P+Q 不是图上的 R，而是把 R关于 x 轴翻过去得到的 −R。

* * *

## 2) P+Q+Q=0（切线导致“重交点”）

第 2 幅里蓝线过 P 并在 Q 处**相切**。  
“相切”意味着这条线在 Q 处的交点**重数为 2**，所以这条线与曲线的三个交点（按重数）是：P,Q,Q。  
因此：![$P+Q+Q=0 \quad\Rightarrow\quad P+2Q=0$](椭圆曲线的_加法_群规则_images/img_004_73e95f4ad5a2.png)  
它表达的是一种**退化/特殊位置**：存在某个 P，使得“过 P 且在 Q 相切”的直线成立，于是第三个交点“又是 Q”。

* * *

## 3) P+Q+0=0（竖直线：互为相反数）

第 3 幅里蓝线是**竖直线**，它与曲线交于 P 和 Q，而第三个交点是无穷远点 0(=O)（可以理解为“竖直方向的无穷远处”）。  
因此：![$P+Q+0=0 \quad\Rightarrow\quad P+Q=0 \quad\Rightarrow\quad Q=-P$](椭圆曲线的_加法_群规则_images/img_005_ae35048712f3.png)  
几何上就是：P 与 Q **x 坐标相同，y 互为相反数**。

* * *

## 4) P+P+0=0（竖直切线：2 阶点）

第 4 幅里在 P 处的切线是**竖直的**，这通常发生在 P 的 y=0（点落在 x 轴上）。  
此时 P=−P（因为关于 x 轴翻过去还是自己），所以 2P=0。图中写成：![$P+P+0=0 \quad\Rightarrow\quad 2P=0$](椭圆曲线的_加法_群规则_images/img_006_a39b2d0cdb4d.png)  
这表示 P 是一个**阶为 2 的点**（加两次回到单位元）。

我把图里四种情况都对应到**代数计算公式**上（同一套规则，在实数域和有限域![$\mathbb F_p$](椭圆曲线的_加法_群规则_images/img_007_dfc5523a34ad.png) 里都成立；有限域里把除法换成“乘逆元”即可）。

下面用最常见的短 Weierstrass 形式举例：

![$E:\; y^2 = x^3 + ax + b$](椭圆曲线的_加法_群规则_images/img_008_fc6021f168b3.png)

并约定单位元（图里的 0）是无穷远点 O。

* * *

## 0\. 两个最基本的代数规则

### 0.1 取相反数（对应“关于 x 轴镜像”）

![$P=(x,y)\quad\Rightarrow\quad -P=(x,-y)$](椭圆曲线的_加法_群规则_images/img_009_eee173297462.png)

在有限域 ![$\mathbb F_p$](椭圆曲线的_加法_群规则_images/img_010_dfc5523a34ad.png)中就是 ![$-y \equiv p-y\pmod p$](椭圆曲线的_加法_群规则_images/img_011_0e933abbbf26.png)。

### 0.2 直线交点求和规则

任意一条直线与曲线相交（按重数算）得到三点 A,B,C，则

A+B+C=O

所以如果直线过 P,Q，第三交点叫 R，那么

P+Q=−R

* * *

## 1) 图 1：一般加法 P+Q+R=O

设

![$P=(x_1,y_1),\quad Q=(x_2,y_2),\quad P\neq Q$](椭圆曲线的_加法_群规则_images/img_012_c81ba356c515.png)

### 1.1 斜率

  

-   在实数域：
    

![$\lambda = \frac{y_2-y_1}{x_2-x_1}$](椭圆曲线的_加法_群规则_images/img_013_ec21dde8fbee.png)

  

-   在有限域 ![$\mathbb F_p$](椭圆曲线的_加法_群规则_images/img_014_dfc5523a34ad.png)（模素数 p）：
    

![$\lambda \equiv (y_2-y_1)\cdot (x_2-x_1)^{-1}\pmod p$](椭圆曲线的_加法_群规则_images/img_015_34973b2da17e.png)

这里![$(x_2-x_1)^{-1}$](椭圆曲线的_加法_群规则_images/img_016_b9c68d5c912a.png) 是模 p 的乘法逆元。

### 1.2 结果坐标

先得到第三交点的 x 坐标（注意这一步已经等价于“直线与曲线第三次相交”）：

![$x_3 = \lambda^2 - x_1 - x_2$](椭圆曲线的_加法_群规则_images/img_017_2824522c25ad.png)

然后：

![$y_3 = \lambda(x_1-x_3) - y_1$](椭圆曲线的_加法_群规则_images/img_018_b75c254213f8.png)

得到

![$P+Q=(x_3,y_3)$](椭圆曲线的_加法_群规则_images/img_019_393ec1b7523c.png)

### 1.3 与图中 R 的关系

图中那条直线的第三交点 R 实际上是![$(x_3,-y_3)$](椭圆曲线的_加法_群规则_images/img_020_e616b6794a4d.png)。  
因为图的规则写的是：

![$P+Q+R=O \Rightarrow P+Q=-R$](椭圆曲线的_加法_群规则_images/img_021_57e290d6c1b3.png)

所以你算出来的 ![$(x_3,y_3)$](椭圆曲线的_加法_群规则_images/img_022_9275580a50a6.png) 正是 −R。

* * *

## 2) 图 2：切线导致重数 P+Q+Q=O

这一幅表达的是：一条直线**经过 P**，并且在 Q 处**相切**（所以 Q 这个交点算两次），于是三点（按重数）是 P,Q,Q：

![$P+Q+Q=O \Rightarrow P+2Q=O$](椭圆曲线的_加法_群规则_images/img_023_f9dc3a5fb341.png)

这幅更像是在讲“交点重数”的概念：  
**相切 = 交点重数为 2**，所以写成 Q+Q。

> 代数上，若你真的要算“在 Q 点的切线与曲线第三交点”，那就是“点加倍”的公式（见下一节）。  
> 然后再取相反数得到 2Q。

* * *

## 3) 图 3：竖直线 P+Q+O=O

当![$x_1=x_2$](椭圆曲线的_加法_群规则_images/img_024_148d8b5ba10c.png)且 ![$y_2=-y_1$](椭圆曲线的_加法_群规则_images/img_025_41436bb9ccc3.png) 时，直线 ![$x=x_1$](椭圆曲线的_加法_群规则_images/img_026_4d075c518882.png) 是竖直线，它与曲线交于 P,Q，第三个交点是无穷远点 O：

![$P+Q+O=O \Rightarrow P+Q=O \Rightarrow Q=-P$](椭圆曲线的_加法_群规则_images/img_027_24ffafbf0858.png)

### 代数计算时怎么处理？

这是加法的一个“特判”：

-     
    
-   若![$x_1=x_2$](椭圆曲线的_加法_群规则_images/img_028_148d8b5ba10c.png) 且 ![$y_1 \equiv -y_2$](椭圆曲线的_加法_群规则_images/img_029_9fa96d0a0a4e.png)（实数里就是![$y_1=-y_2$](椭圆曲线的_加法_群规则_images/img_030_ba941a54f90b.png)）
    
      P+Q=O
    

并且这时斜率公式会出现![$x_2-x_1=0$](椭圆曲线的_加法_群规则_images/img_031_34f6831a2dac.png)的“除 0”，所以必须先特判。

* * *

## 4) 图 4：竖直切线 P+P+O=O（2 阶点 / y=0）

在短 Weierstrass 曲线中，若 ![$P=(x_1,y_1)$](椭圆曲线的_加法_群规则_images/img_032_9686afb6bbd1.png) 且 y1=0，那么切线在该点是竖直的（几何上会“冲到无穷远点”），对应：

![$P+P+O=O \Rightarrow 2P=O$](椭圆曲线的_加法_群规则_images/img_033_ba4f22d86f52.png)

这说明 P 是一个 **阶为 2 的点**（加两次回到单位元）。

### 代数计算时的点加倍公式（正常情况）

若 P≠O 且 y1≠0，点加倍 2P 这样算：

斜率（切线斜率）：

![$\lambda=\frac{3x_1^2+a}{2y_1}$](椭圆曲线的_加法_群规则_images/img_034_eeb00f3a0723.png)

有限域里：

![$\lambda \equiv (3x_1^2+a)\cdot(2y_1)^{-1}\pmod p$](椭圆曲线的_加法_群规则_images/img_035_e6966a1e4fe3.png)

结果：

![$x_3=\lambda^2-2x_1,\qquad y_3=\lambda(x_1-x_3)-y_1$](椭圆曲线的_加法_群规则_images/img_036_9dfc845f5d93.png)

![$2P=(x_3,y_3)$](椭圆曲线的_加法_群规则_images/img_037_d71809cb0e01.png)

### 但当 y1=0 时？

 ![$2y_1=0$](椭圆曲线的_加法_群规则_images/img_038_19736d4596df.png) 没有逆元（或会“除 0”），所以必须特判：

![$y_1=0 \Rightarrow 2P=O$](椭圆曲线的_加法_群规则_images/img_039_df78de26a491.png)

这正是图 4 的公式含义。

      先算斜率 λ，再算 ![$x_3,y_3$](椭圆曲线的_加法_群规则_images/img_040_7877ec61ddbd.png) 得到 P+Q。
    
      
    
-   **图2**：切线 = 重交点（重数 2），对应“加倍/或带重数的三交点和为 O”

## 1) 图1：割线三交点 P+Q+R=O ⇒ P+Q=−R

### 1.1 算斜率 λ

![$\lambda \equiv (y_2-y_1)\cdot(x_2-x_1)^{-1} \pmod p$](椭圆曲线的_加法_群规则_images/img_044_34973b2da17e.png)

-   ![$y_2-y_1 = 56-105 = -49 \equiv 174 \pmod{223}$](椭圆曲线的_加法_群规则_images/img_046_d335bee11161.png)

-   ![$48^{-1}\equiv 79 \pmod{223}$](椭圆曲线的_加法_群规则_images/img_047_87b49eb7912d.png)（因为 148⋅79≡1）

![$\lambda \equiv 174\cdot 79 \equiv 143 \pmod{223}$](椭圆曲线的_加法_群规则_images/img_048_893a6a550ae2.png)

![$x_3 \equiv \lambda^2-x_1-x_2 \pmod p$](椭圆曲线的_加法_群规则_images/img_049_c3cf357f8c8c.png)

P+Q=(170,142)

## 2) 图2：切线导致重数 P+Q+Q=O

这幅图的意思是：直线**经过 P**，并且在 Q 点**相切**，所以 Q 这个交点算两次：

![$P+Q+Q=O \quad\Rightarrow\quad P+2Q=O$](椭圆曲线的_加法_群规则_images/img_053_74138a784197.png)

它强调的是“**相切 = 重交点（重数为2）**”这一条群论/代数几何事实。

> 实操里最常用的是“在某点相切”对应的就是 **点加倍 2Q**（见下一条的公式）。

![$-P=(192,\; -105\bmod 223)=(192,118)$](椭圆曲线的_加法_群规则_images/img_054_d35d3e267552.png)

P+(−P)=O

这就是图3：竖直线 x=192 与曲线交于 P 和 −P，第三个交点是 O。

## 4) 图4：竖直切线 P+P+O=O（y=0 的 2 阶点）

找一个 y=0 的点：只要让

![$0 \equiv x^3+7 \pmod{223} \Rightarrow x^3 \equiv -7 \equiv 216$](椭圆曲线的_加法_群规则_images/img_055_82b5ce629cfe.png)

因为 T=−T（y=0 翻转还是自己），所以：

2T=O

这正是图4表达的“竖直切线/2阶点”。

# Delphi 实现要点（对应四种情况的“特判”）

下面给你一段**直接可用的核心代码**（短 Weierstrass，模素数 p）：

```
type  TEcPoint = record    X, Y: Int64;    Inf: Boolean; // True 表示无穷远点 OclassfunctionInfinity: TEcPoint; static;classfunctionCreate(AX, AY: Int64): TEcPoint; static;end;classfunctionTEcPoint.Infinity: TEcPoint;begin  Result.Inf := True;  Result.X := 0; Result.Y := 0;end;classfunctionTEcPoint.Create(AX, AY: Int64): TEcPoint;begin  Result.Inf := False;  Result.X := AX; Result.Y := AY;end;functionModP(A, P: Int64): Int64;begin  Result := A mod P;if Result < 0then Inc(Result, P);end;functionEgcd(A, B: Int64; out X, Y: Int64): Int64;var x1, y1, g: Int64;beginif B = 0thenbegin    X := 1; Y := 0;Exit(A);end;  g := Egcd(B, A mod B, x1, y1);  X := y1;  Y := x1 - (A div B) * y1;  Result := g;end;functionModInv(A, P: Int64): Int64;var x, y, g: Int64;begin  A := ModP(A, P);  g := Egcd(A, P, x, y);if g <> 1thenraise Exception.Create('No inverse (A and P not coprime)');  Result := ModP(x, P);end;// 曲线: y^2 = x^3 + a*x + b (mod p)functionEcAdd(const P1, P2: TEcPoint; a, p: Int64): TEcPoint;var  x1,y1,x2,y2, lam, x3, y3, num, den: Int64;begin// O + P = Pif P1.Inf thenExit(P2);if P2.Inf thenExit(P1);  x1 := P1.X; y1 := P1.Y;  x2 := P2.X; y2 := P2.Y;// 图3：x 相等且 y1 = -y2 -> 竖直线 -> 和为 Oif (x1 = x2) and (ModP(y1 + y2, p) = 0) thenExit(TEcPoint.Infinity);if (x1 = x2) and (y1 = y2) thenbegin// 点加倍：图4特判 y=0 -> 竖直切线 -> 2P=Oif ModP(y1, p) = 0thenExit(TEcPoint.Infinity);    num := ModP(3*x1*x1 + a, p);    den := ModP(2*y1, p);    lam := ModP(num * ModInv(den, p), p);endelsebegin// 普通加法：图1    num := ModP(y2 - y1, p);    den := ModP(x2 - x1, p);    lam := ModP(num * ModInv(den, p), p);end;  x3 := ModP(lam*lam - x1 - x2, p);  y3 := ModP(lam*(x1 - x3) - y1, p);  Result := TEcPoint.Create(x3, y3);end;
```
