# 1.1 凹槽数量及分布

  

这款小型有刷直流电机总共有五个磁极，经过观察可以看到五个磁极上的凹槽数量和大小不同。凹槽基本上位于磁极的中轴线上，分布在磁极靠近两端的位置。

  

五个磁极上的凹槽：  
磁极1：无  
磁极2：1个

磁极3：1个（偏小）  
磁极4：两个，其中一个偏小

磁极5：两个

  

![](https://mmbiz.qpic.cn/mmbiz_png/vibkgHlPVq0sy1CMniciaVSs1CKZg5HSxetNUAFueFMtibDKIWsG4pSyh1N3ib18etiaEXbCY5ibR3smPA08ZjOtm8TuQ/640?wx_fmt=png&from=appmsg)

图1.1.1 五个磁极上的凹槽分布情况

  

从磁极形状上来看，应该是磁极在装配后期经过打磨形成的凹槽。凹槽的数量和大小应该是为了某种目的而有意加工的。

#   

# **1.2 转子磁极与绕组**

为了消除直流电机的力矩死区，减小机械换流环火花，小型直流电机的转子通常具有三个磁极和五个磁极。三个磁极转子上的线圈是绕制在各自磁极柱上的。对于五个磁极转子上的线圈是绕制在相邻两个磁极柱上。

  

![](https://mmbiz.qpic.cn/mmbiz_png/vibkgHlPVq0sy1CMniciaVSs1CKZg5HSxetGzWKdq3xbUcHEYlXmVZ3lYtn05QdQ3auFfXPnm9MrdRjjZpEk8o1kQ/640?wx_fmt=png&from=appmsg) 图1.2.1 带有三个磁极和五个磁极的电机转子

无论三磁极还是五磁极转子，在任意时刻总有一个线圈绕组所缠绕的磁极正对着定子上的永磁铁表面，对应磁通量的变化为0。此时该线圈：

  

-   感应电压为0，在此期间通过机械换流环完成换流，不会产生火花；
    
-   不产生磁力矩，浪费了线圈资源；三磁极转子浪费1/3的线圈，对于五磁极转子浪费1/5的线圈。
    

#   

# **1.3 为何表面有凹槽？**

我们可以从网络上看到各种电机转子，奇怪的是它们表面所呈现的都是完整的，没有凹槽。此时需要对手边表面带有凹槽的转子进行仔细观察，可以看到转子上的五个线圈绕制并不是对称的，这与线圈被绕制的顺序有关系。

#   

# 1.3.1 使用凹槽进行质量配平

先绕制的线圈在里面，后绕制的线圈在外面，所以线圈的尺寸不同。如果线圈的匝数相同，那么线圈对应的质量也不同，这就造成转子质量分布不均匀了。在高速旋转时，就会产生周期转动现象，增加了运行噪声，加速电机的磨损。

  

![](https://mmbiz.qpic.cn/mmbiz_png/vibkgHlPVq0sy1CMniciaVSs1CKZg5HSxetSYc7HeKIRicU3RicxCckicejYaIgiaSZbQUDiaEvBiaktB3XtbKP8GIbObRw/640?wx_fmt=png&from=appmsg)

图1.1.2 转子绕组与对应的凹槽关系

因此，解决的方法就是在电机转子表面进行打磨凹槽，使得转子旋转中心位于机械轴上。上图中表明了转子表面上凹槽的数量，能够看出它们与线圈的大小是对应的。外部大的线圈所包围的转子表面具有两个凹槽，内部小的线圈对应的磁极则没有，或者只有小的凹槽。

  

# 1.3.2 为何别的转子没有凹槽？

**那么，为什么别的电机转子表面没有凹槽？**

下面是从网络上找到的五个磁极转子（左边），表面没有凹槽。与右边表面具有凹槽转子进行对比。也能够看到左边的转子的线圈实际上也存在着内部线圈和外部线圈，因此也存在着质量分布不均匀，使得质量转动对称轴心与机械转动轴不重叠。

  

![](https://mmbiz.qpic.cn/mmbiz_png/vibkgHlPVq0sy1CMniciaVSs1CKZg5HSxetcBia2df2R7OTiat0wcibBus1dfY7vMNY4EvcvSWbKmmMZxNDAkwgqnHCA/640?wx_fmt=png&from=appmsg)

图1.3.2 左边：表面没有凹槽的电机；右边：具有凹槽的电机

之所以存在表面没有凹槽的转子，可能的解释只能是：

  

-   这些转子的运行速度不高，偏心带来的转动影响不大；
    
-   电机功率不大，相应的线圈匝数和质量较小，从而偏心量不大；
    

# **※ 总  结 ※**

五磁极直流有刷电机转子表面的凹槽是为了配平转子线圈绕组质量分布不均匀所带来转动转动，使得电机在工作时的震动减小。相比于五磁极转子，三磁极转子就没有这种情况，这是因为三磁极转子上的绕组分布是对称的。

  

![](https://mmbiz.qpic.cn/mmbiz_jpg/vibkgHlPVq0sy1CMniciaVSs1CKZg5HSxetpfib0dseoNyfpaiaLgpx88BpVQMl2N1SCAe3f7rCic8AOvWrZlsuBhoDA/640?wx_fmt=jpeg&from=appmsg)
