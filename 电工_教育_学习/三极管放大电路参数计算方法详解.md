已知三极管输出负载最小为10K，电压放大倍数Av=5，三极管放大电路的电源电压VCC=15V,极管电流放大倍数β = 100，试计算R1、R2、Rc和Re的值?

![](D:\电脑文件\公众号知识库\电工_教育_学习\三极管放大电路参数计算方法详解_images\img_004_e84ff6d0648f.png)

注意：锗晶体三极管Vbe约为0.2V，硅晶体三极管vbe约为0.55-0.65V。  
当输出负载为RL时，Ro = Rc || RL，当输出为空载时，Ro = Rc  

因为ΔVo = – ΔIc \* Ro，ΔIe =(1+β) \* ΔIb， ≈ ΔIc = β \* ΔIb，所以ΔVo = – β \* ΔIb\* Ro  
因为ΔVi =ΔIb \* rbe+ ΔIe \* Re，所以ΔVi  = ΔIb \*  \[ rbe + (1+β)\* Re\]  
计算

Av = ΔVo / ΔVi

Av = – β \* ΔIb\* Ro / { ΔIb \*  \[ rbe + (1+β)\* Re\]  }

Av = – β \* Ro / \[ rbe + (1+β)\* Re\] 

Av = –  Ro / \[ rbe/β + (1/β+1)\* Re\] 

当β>100时，由于rbe很小，认为1/β=0，则 Av = – Ro / Re

当RL = ∞ 时，Av = – Rc / Re，Ro = Rc

已知电压放大倍数Av=5，则 Ro / Re = 5，为了满足静态工作点在中间位置，保证不出现饱和失真和截上失真所以取Vce = 0.5Vcc，即Vce = 0.5 \* 15=7.5V

取 le = 1mA，Re + Ro = (15 – 7.5)/1= 7.5K

又因为| Av | = Ro / Re = 5，所以得到: Re = 7.5 /(5+1) = 1.25K，Ro = 6.25K

当 RL=10K，则Rc\*10 /(Rc+10 )= 6.25，RL=16.66K，取Re=1.3K，Rc = 16.9K

当RL = ∞ 时，则Rc = Ro = 6.25K，取Re=1.3K，Rc = 6.6K

在直流电路中，计算旁路电阻:  
Ve = Ie \* Re = 1 \* 1.3 = 1.3V

Vbe通常取0.6V，则Vb = Ve + Vbe = 1.3 +0.6 =1.9V  
因为Ie =lmA，β = 100，所以 Ib = 1/100=0.01mA

流过偏置电阻的电流IB应该是Ib的数倍，这里取IB= 10 \* Ib，所以IB= Ib \* 10= 0.1mA  
R1 = ( 15 – 1.9) / 0.1 =131K，R3 = 1.9 / 0.1 = 19K
