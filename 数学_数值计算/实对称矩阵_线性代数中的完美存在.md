## 对称矩阵在稳定系统中的统治地位

物理系统中的能量函数通常是二次型。能量的 Hessian 矩阵（二阶导数矩阵）是对称的。

系统平衡点的稳定性由 Hessian 矩阵的特征值决定：

-   所有特征值 > 0 → 能量极小 → 稳定平衡。
    
-   存在特征值 < 0 → 鞍点 → 不稳定。
    
-   所有特征值 < 0 → 能量极大 → 不稳定。
    

**对称矩阵的特征值直接编码了系统的稳定性结构。**
