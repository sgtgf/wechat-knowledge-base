更准确地说，是每个点的箭头都**沿着圆的切线方向**。

所以这个场不是“向外散开”，也不是“整齐平移”，而是：

> **围着原点转圈**

这已经非常强烈地暗示：

**旋度不为零。**

* * *

## 3\. 为什么这个场特别像“刚体转动”？

你可以把它想象成一个圆盘在平面内逆时针转。

如果圆盘绕原点转：

-   右边那一点速度朝上
    
-   上边那一点速度朝左
    
-   左边那一点速度朝下
    
-   下边那一点速度朝右
    

这和  完全一致。

所以这个速度场其实就是：

> **平面刚体绕原点做逆时针旋转的速度场**

这类场最典型的特征就是：  
**局部小风车一定会被带着转。**

因此旋度显然不为零。

## 5\. 用“小风车判断法”再看一次

比如原点右边一点点，流向朝上；

-   小风车右侧的流体往上拉
    
-   左侧的流体往下拉

会，而且是**逆时针**。

同样：

-   上侧流体往左
    
-   下侧流体往右
    

也在帮它逆时针转。

所以这个场对小风车的作用不是“拉开”，而是“拧动”。

这就是旋度的本质。

# 3\. 用“小风车”判断最直观

这是最关键的地方。

想象你在这个场里放一个很小的小风车。

## 左右两边会怎样？

-   风车右边的流体往右拉
    
-   风车左边的流体往左拉
    

这不是在让它转，  
而是在把它**横向拉开**。

## 上下两边会怎样？

-   上边流体往上拉
    
-   下边流体往下拉
    

这也不是在让它转，  
而是在把它**纵向拉开**。

所以这个场对小风车做的事更像：

-   **把它撑大**
    
-   **把它往外拽**
    
-   **让它膨胀**
    

而不是让它自转。

因此：

**旋度 = 0**

# 1. ：向外发散的“源”

这个场最容易看懂，因为它在每个点都**沿着位置方向往外指**。

比如：

-    处向右
    
-    处向上
    
-    处向左
    
-    处向下
    

像这样：

```
      ↑   ↖     ↗←     •     →   ↙     ↘      ↓
```

它给人的感觉就是：

> 原点像一个喷口，把东西往四面八方推出去。

### 小风车判断

放一个小风车进去，不会被拧转，只会被“撑开”。

所以：

-   **旋度 = 0**
    
-   **散度 > 0**
    

### 一句话记忆

**这是“向外冒”的场，不是“绕圈转”的场。**

* * *

# 2. ：逆时针纯旋转

这是最经典的旋转场。

看四个点：

-    处是 ，向上
    
-    处是 ，向左
    
-    处是 ，向下
    
-    处是 ，向右
    

图像就是：

```
      ←   ↙     ↖↓     •     ↑   ↘     ↗      →
```

更准确地说，箭头沿着圆周切线方向，围着原点逆时针转。

### 小风车判断

放进去的小风车会明显转起来，而且是**逆时针**。

所以：

-   **旋度 ≠ 0**
    
-   **散度 = 0**
    

### 一句话记忆

**这是“只转不胀”的场。**

* * *

# 3. ：鞍点场，拉伸但不旋转

这个最容易让人误判，因为它也“变化很大”，但它**不是旋转**。

看四个点：

-    处向右
    
-    处向左
    
-    处向下
    
-    处向上
    

图像大概是：

```
      ↓   ↘     ↙←     •     →   ↗     ↖      ↑
```

这意味着：

-   左右方向在**向两边拉开**
    
-   上下方向在**往中间压**
    

所以它像什么？

> 像一块橡皮泥，左右被拉长，同时上下被挤扁。

这叫**鞍点型流场**。

### 小风车判断

小风车不会整体自转。  
因为它感受到的是“拉伸 + 压缩”，不是“拧动”。

所以：

-   **旋度 = 0**
    
-   **散度 = 0**
    

### 为什么散度也为 0？

因为“横向扩张”与“纵向压缩”刚好平衡了。

### 一句话记忆

**这是“变形场”，不是“旋转场”，也不是“发散场”。**

* * *

# 4. ：向内汇聚的“汇”

这个就是  的反方向版本。

看四个点：

-    处向左
    
-    处向下
    
-    处向右
    
-    处向上
    

图像像这样：

```
      ↓   ↙     ↘→     •     ←   ↖     ↗      ↑
```

它的感觉就是：

> 四面八方都在往原点收缩。

像一个排水口，把东西往中心吸进去。

### 小风车判断

小风车不会被拧转，只会被往中心压。

所以：

-   **旋度 = 0**
    
-   **散度 < 0**
    

### 一句话记忆

**这是“向内吸”的场，不是“绕圈转”的场。**

* * *

# 最核心的对比：四个场到底差在哪？

你可以直接背这四句话：

**向外喷**  
有散度，没有旋度。

**绕圈转**  
有旋度，没有散度。

**拉伸变形**  
既没有散度，也没有旋度，但有明显形变。

**向内吸**  
有负散度，没有旋度。

* * *

# 为什么  最值得单独记？

因为它能帮你彻底明白：

> **“场在变化”不等于“有旋度”。**

它变化很明显，但那种变化是：

-   左右分开
    
-   上下挤压
    

这叫**形变**，不叫**局部旋转**。

所以判断旋度，不能只看“箭头变没变”，而要看：

> 它是不是在把一个小物体“拧”起来。

# 再给你一个终极记忆口诀

## 看散度

看它整体是在：

-   往外冒 → 散度正
    
-   往里吸 → 散度负
    

## 看旋度

看它整体是不是：

-   围着某点打转 → 旋度非零
    

## 看鞍点

如果它表现为：

-   一个方向拉开
    
-   另一个方向压缩
    

那通常是形变，不一定有旋度，也不一定有散度。
