# 基于变压器移相 800VDC 超算中心直流供电系统

摘要：随着超算中心对供电功率要求提高，高压直流供电 (HVDC) 将成为其主要的供电方式法。目前，800VDC供电已成为AI超算时代的主流供电方案。获取800VDC主要三种方法：移相变压器方案、固态变压器 (SST) 方案及巴拿马电源方案。介绍采用移相变压器获取高压直流 800V 的技术方案。其技术路线为： AC10kV →移相变压器→ AC380V( 多相 ) → 整流器→ DC800V。

关键词：800V 高压直流供电；移相变压器；三相维也纳整流器； SiC+MOSFET PFC

1. 技术背景与架构分析

1.1 背景与必要性

（1）AI 数据中心单机机柜功率激增：AI 数据中心单机机柜的功率从200kW 飙升至 1MW+，传统 54V 架构要满足功率需求将面临着铜材消耗激增、转换效率低等瓶颈。  

54V 架构传输1000 W功率的电流：I=1000/54=18.52 A

800VDC传输1000 W功率的电流: I=1000/800=1.25 A

（2）多级电源转换对转换效率提升需求：AI 数据中心供电需经过多级 AC/DC 、DC/AC 的转换，每次转换将面临着转换效率问题，导致供电系统总的效率仅为 88-92%。

为解决AI 数据中心所面临的问题，采用了800VDC系统架构。  

1.2 800VDC 系统架构  

800VDC 系统组成：中压电网(10kV，市电) →中压开关→移相变压器→整流单元→直流母线(800V) →机柜PDU →服务器电源。  

2. 移相变压器工作原理与技术特性  

2.1 基本原理  

通过对变压器绕组的特殊设计 ( 星形、三角形及延边三角形)，使变压器的二次侧输出电压产生精确相位偏移。通过多组绕组输出形成多个相位差 ( 通常30° ) 的三相电源，为多脉冲整流奠定基础。如：12脉波整流，变压器移相为360 °/12=30° ；18 脉波整流，变压器移相为360° /  18=20° 。如果m为脉波数，则为变压器移相相位为360° /m。  

工作流程：原边绕组接入 10kV 三相交流电，副边为多绕组输出多个移相后的三相电压 ( 如 12 相、18 相、24  相)，各相电压经整流后叠加，输出800V 平滑的直流电。  

2.2 多脉冲整流技术  

谐波抑制：12 脉冲整流THD<3%，24 脉冲< 2%，远优于传统6 脉冲 THD~30%。功率因数提升：PF>0.99，无需额外 PFC 电路，简化系统设计降低开关应力：多相叠加使整流输出纹波频率提升，减小滤波电容的电容量。

3.2 整流与 PFC  

![](https://mmbiz.qpic.cn/mmbiz_png/w7mE225tvpNQCBfA0ANhX77H0QJNmGXdaHSoIYnV2SALfVFjQxQDcgPFWRkQYoO73YENumqgTaibxPGRxSr03NBiagTBbiaUc1d5wOM2XP9pY8/640?wx_fmt=png&from=appmsg)

图4 为三相维也纳整流器 ( 三电平PFC)，适配 SiC 器件，效率 98%+，单管电压应力仅400 V，其输出电压为800VDC，通过控制移相角和开关管导通的时序，使输入电流完全跟踪输入电压波形，实现单位功率因数控制，消除无功损耗，满足 IEEE 519 谐波标准。  

该整流器本质是通过高频 PWM 控制实现交流到直流的高效转换，同时维持高功率因数，核心围绕开关管动作、电流路径切换和中点电压平衡展开，具体过程如下：  

控制器实时采集三相输入电压、电流以及直流侧电容电压信号，使输入电流波形跟踪输入电压波形，实现单位功率因数，降低谐波污染。另一方面维持C1 和C2 的电压均衡，确保中点 O 电位稳定，避免器件因电压应力异常损坏。  

每相开关管以高频 PWM 方式通断，直接改变电流波形，实现电感能量的存储与释放。当开关管导通时：对应相电流通过开关管流向直流母线中点 O，或从中点 O 流出（取决于电流方向）。此时 Boost 电感处于储能状态，电流逐渐增大。如 A 相电流为正时，电流经 La、Sa 流向 O 点。当开关管Sa 关断时：电流无法通过开关管，只能经该相的箝位二极管续流。若电流方向为正，电流经二极管流向直流母线正极，此时，电源为 C1 充电；若电流方向为负，电流经二极管流向直流母线负极，此时，电源为 C2 充电。C1、C2 充电过程中电感释放能量，电流逐渐减小。  

借助直流母线中点 O 和箝位二极管，在输出侧可形成\+ Vdc/2、0、\-Vdc/2 三个电平。在实际应用中采用空间矢量调制（SVPWM）策略，通过合理选择开关组合及控制开关的通断时间，生成符合系统要求的电压矢量。在不同电压扇区内，通过切换 Sa、Sb、Sc 的通断状态，确保输入电流始终与电压同相，同时动态调整电容充放电时间，维持中点电压平衡。由于同一相桥臂无两个可控开关管的对顶结构，从拓扑上消除了桥臂直通的风险。且开关管两端电压被钳位在 Vdc/2，降低了对开关器件的电压等级要求，配合合理的调制策略，可实现低输入电流畸变率和高效率的能量转换。  

3.3 直流供电及UPS  

如图5 所示。双路市电进入超算中心，分别通过三相维也纳整流器整流，输出800VDC。

![](https://mmbiz.qpic.cn/mmbiz_png/w7mE225tvpNxx02R8ERQpQmVQJmpFz7z9109CiacmkYQWsFMsuLe1okJuXmRWHQmCq4P4ZBqybWlRFniaVDxyIRcvbLklp64ECeP19EsIuT4o/640?wx_fmt=png&from=appmsg)

直流供电采用双母线架构，并配备储能电池。当一组电源出现故障或停电时，另一组电源能保障正常供电。如果两组电源出现故障或停电时，系统自动切换到储能电池供电，储能电池供电时，启动备用供电采用发电机。储能电池直接挂接于 800V 直流母线，通过这种简化 UPS 设计，提高机柜级储能效率。  

4. 服务器机架内部供电  

服务器机架内部供电为54V 直流，服务器电源采用DC/DC电源直接将直流母线上800V直流转换为54V直流，为服务器机架内部供电。800V 直流通过滤波之后及EMC电路之后，采用SiC MOSFET 全桥逆变，高频变换电路采用LLC 全桥技术实现ZVS/ZCS，并采用高频变压器实现高压电路与服务器内部供电电路隔离，并采用SiC 二极管软开关整流技术，电路如图5 所示。

5\. SiC 器件的应用  

整流桥采用SiC SBD ( 肖特基二极管) 零反向恢复 (Qrr≈0)，高温稳定性(175℃ )，整流损耗降低60%，效率提升1-2%，PFC 开关SiC MOSFET 高频（100kHz+），低导通电阻（5-10mΩ）开关损耗降低70%，响应速度提升5 倍。DC/DC 采用SiC MOSFET+SiC 二极管软开关 (ZVS/ZCS) ，实现低开关应力。功率密度提升 2 倍，体积减小50%SiC+ 移相技术协同效应。移相多脉冲整流降低电流纹波，减轻 SiC 器件负担，SiC 高频特性允许移相角更精确控制，进一步提升谐波抑制效果。系统整体效率从传统硅基方案94-95% 提升至97.5-98.5%。

6.2 主要技术特点  

（1）磁路 - 电路融合设计  

移相变压器通过精确相位控制，实现 " 降压 + 隔离 +  PFC + 谐波抑制" 四合一。省去传统方案中的 PFC 电路、谐波滤波器等组件，简化系统架构。  

（2）多电平输出优化  

整流输出采用三电平拓扑，输出电压波动小 (±1%)。开关管电压应力减半，延长器了件寿命，降低电源系统的 EMI。 

（3）全链路模块化  

移相变压器、整流单元、监控系统均为标准化模块，支持热插拔维护。系统扩容时可灵活增加模块，不影响现有运行，MTBF>15 万小时以上。
