# 电源自动开关电路逻辑详解

原创 小D 电路一点通 2026-05-28 09:00 广东

> 原文地址: [https://mp.weixin.qq.com/s/c4Hz1PeVd42XzVcucfJQIQ](https://mp.weixin.qq.com/s/c4Hz1PeVd42XzVcucfJQIQ)

这个DIY电源自动开关电路包含两大核心功能：**可调稳压输出（3.7V~8.7V）** 和 **负载断开后自动延时关断总电源**。下面将为你详细解析电路工作原理、关键元件作用，并提供完整的电路图。

![](D:\电脑文件\公众号知识库\电力电子_DC_DC变换器\电源自动开关电路逻辑详解_images\img_000_fb11ba6ee968.png)

**核心逻辑**：

-   正常带负载时，电流流过VD1、VD2产生约1.3V压降 → VT2导通 → VT1导通 → 继电器K吸合 → 常开触点K-1自锁，维持总电源。
    
-   负载断开 → 无电流，VD1、VD2压降消失 → VT2截止 → 但C2储存的电能继续维持VT1导通一段时间（延时）→ C2放完电后VT1截止 → K释放 → K-1断开 → 整个电路断电，实现零待机功耗。
    
-   需要重新供电时，按下S1，强制给VT1基极注入电流，使电路再次自锁导通。
    

## 自动延时关断部分（VT1、VT2、C2、继电器）

### 元件作用

元件

功能

VD1、VD2

负载电流检测：正常时产生约1.3V压降，使VT2导通

VT2 (NPN, 如8050)

电流检测开关：基极接VD1正极，发射极接VD2负极（输出地）

VT1 (PNP, 如8550)

主开关：控制继电器K线圈

C2 (电解电容, 100~470μF)

延时定时：负载断开后向VT1基极提供维持电流

S1 (常开按钮)

启动触发：短接VT1基极与地（或接正极瞬间拉低基极）

K (继电器，线圈电压与电源适配)

总电源开关：触点K-1接在变压器初级或整流后主回路
