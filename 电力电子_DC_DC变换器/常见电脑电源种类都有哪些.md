## 常见的电脑电源种类

电脑电源是一种转换设备，其主要功能是将交流电转换为我们计算机硬件所需的直流电。不同类型的电脑电源会有不同的特性和应用场景。本文将详细探讨几种常见的电脑电源种类。

### 1\. AT电源

AT电源（Advanced Technology）是早期个人计算机使用的电源，现已基本被ATX电源替代。

class ATPower:  
    def \_\_init\_\_(self):  
        self.type = "AT"  

这种电源的主要特点是在开关电源后，无法通过键盘或鼠标来启动计算机，需要手动按电源开关。此外，它的电源线固定且不可更换。

### 2\. ATX电源

ATX电源（Advanced Technology Extended）是目前最常用的电源类型。

class ATXPower:  
    def \_\_init\_\_(self):  
        self.type = "ATX"  

与AT电源相比，ATX电源具有众多优势。例如，它支持软开关，即可以通过键盘或鼠标来启动或关闭计算机。此外，ATX电源提供了更多的接口，如SATA、PCIe等，以满足更多硬件的需求。

### 3\. SFX电源

SFX电源（Small Form Factor）是一种小型电源，通常用于小型计算机和一体机中。

class SFXPower:  
    def \_\_init\_\_(self):  
        self.type = "SFX"  

虽然尺寸小，但SFX电源的性能并未受到太大影响。它可以提供相当于ATX电源的功率，并且也支持各种现代接口。

### 4\. TFX电源

TFX电源（Thin Form Factor）是一种更为紧凑的电源，通常用于超薄台式机和一些小型企业服务器中。

class TFXPower:  
    def \_\_init\_\_(self):  
        self.type = "TFX"  

由于其尺寸限制，TFX电源的功率通常较低，但对于一些低功耗的应用来说，这仍然足够。
