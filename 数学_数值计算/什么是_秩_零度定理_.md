# 什么是“秩-零度定理”


> 原文地址: [https://mp.weixin.qq.com/s/y4rwnC1fT4VDp52qEq-rOg](https://mp.weixin.qq.com/s/y4rwnC1fT4VDp52qEq-rOg)

想象一下你手里有一台\*\*“果汁加工机”\*\*。这台机器的作用就是把“原材料”（向量）加工成“成品”（另一个向量）。

**秩-零度定理 (Rank-Nullity Theorem)** 其实就是在帮你算一笔账：**投入的总资源，去哪儿了？**

1\. 核心概念：三个关键词

为了理解这个定理，我们先把这台“加工机”拆解开：

-   **定义域 (V)：**
    
     也就是你的原材料仓库。如果你有 3 种不同的原材料（三维空间），那么总维度就是 **3**。
    
-   **秩 (Rank)：**
    
     这是机器的\*\*“产出能力”\*\*。比如原材料经过加工，最后只能产出一种面条（一维线段），那么秩就是 **1**。
    
-   **零度 (Nullity)：**
    
     这是机器的\*\*“损耗/吞噬能力”\*\*。有些原材料经过加工后，变成了没用的“废料”（零向量）。被机器彻底消灭掉的维度，就是零度。
    

  

## 2\. 定理的“大白话”公式

![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM6mfF2dEW7G1A0tSDFCv8HJbV4Jx3BMaJlrDfLnfW08NGUXCFOtu2Bcn17iaM6JYibDJwGp7fEuZVSIGNwnEHgb6qwWxzO8SMLF0Wy04nBDkaicQ/640?wx_fmt=svg&from=appmsg)

简单来说：**你投入的总维度，要么变成了看得见的产出（秩），要么被机器吃掉变成了零（零度）。能量守恒，维度也守恒。**

3\. 图解：压扁一个球

想象一个三维的球体（维度 = 3）：

1.  **场景 A（影子）：**
    
     你用一束光把球垂直投影在地板上。
    

-   **结果：**
    
     球变成了一个圆饼（二维）。
    
-   **算账：**
    
     总维度 (3) = 产出的圆饼 (秩=2) + 被压扁的高度 (零度=1)。
    

2.  **场景 B（挤压）：**
    
     你把球挤成了一根细线（一维）。
    

-   **结果：**
    
     产出是一根线（一维）。
    
-   **算账：**
    
     总维度 (3) = 产出的线 (秩=1) + 消失的面积 (零度=2)。

## 4\. 为什么这个定理很重要？

它就像线性代数里的“质量守恒定律”。

**应用领域**

**它的作用**

**方程组求解**

告诉你方程组是有唯一解，还是有无穷多解（零度越大，自由度越多）。

**图像压缩**

通过降低“秩”来丢弃不重要的信息，剩下的就是“零度”部分。

**数据降维**

帮我们理解在高维数据中，哪些维度是真正有用的，哪些是冗余的。

  

> **一句话总结：**
> 
> 一个线性变换（矩阵）就像一个过滤器，它把一部分信息转化为结果（秩），把剩下的信息抹除为零（零度）；而这两部分加起来，永远等于你最初拥有的信息总量。

### Image（像，值域）

![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM7Mc3BhicicgISbn2xW4Lic8OQ1icdOdAMFFfnVyib73wg2mWuKykom3miaAMfEOSa4tTQfiba0AO5BAzQoQOkbvibxTicX6udhQsPiaZHquvtQo0RSABhA/640?wx_fmt=svg&from=appmsg)

意思是：所有可能输出所组成的空间。

它的维数叫 **rank（秩）**：

![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM6z6xWZ83QxpZcp2sT4lME8BjISKQUsvuPTC0sKHic2BicHaVtAZRyicQGPczRzWbiapaHxBj6CTH26RYHZNB5XuRRsC02sPFibJAJEjC5sy7sMcDw/640?wx_fmt=svg&from=appmsg)

也就是：**输出里真正能产生多少个独立方向**。

### Complement（补空间）

图里左边把输入空间 V 分成两块：

-   一块是 **Kernel**
    
-   另一块是 **Complement**
    

这第二块不是唯一的，但它的作用是：  
它和 kernel 合起来正好拼成整个输入空间，而且这块里面的方向**不会被压成 0**，它们会被 T 有效送到输出空间里。

所以直观上：

-   **Kernel**
    
     = 被浪费掉的维数
    
-   **Complement**
    
     = 被真正利用起来的维数
    

而这“被利用起来的维数”，恰好就等于 rank。

## 2\. 定理到底在说什么

秩-零度定理说：

> 输入空间的总维数 = 被压扁的维数 + 被保留下来的有效维数

写成公式就是：

![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM4rr9OMcCULYvu316Fa8wApbezBxmZQunRRpYWeDb8T9Nl3O2xNLqru0cIjlsibcBtRacZ6STG3DHjrNAn79zUVVsHWNa89OIrnq0LWjJN5jkg/640?wx_fmt=svg&from=appmsg)

这就是图1底部写的：

**Dimension conservation!**  
**Flattened + effective = total original dimension**

这个说法非常好。  
它不是“长度守恒”，也不是“体积守恒”，而是**维数分账**：

-   一部分维数进了 kernel
    
-   另一部分维数进了 image

## 4\. 从几何上看，这件事为什么必然成立

把输入空间想成由若干“独立方向”组成。

线性变换 ![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM5VfxQjjBdmYFCeEOUanGKkD183tx37kgh1Z3TYlSEVrvx7icMYrAxEtzIcibbkamZ9EHDjc5kqF5SFqLVENTe99RoJZoyu6dxicyPjPugChLgEg/640?wx_fmt=svg&from=appmsg) 对这些方向做处理时：

-   有些方向被压到 0 —— 这些方向属于 kernel
    
-   剩下的方向在输出中形成独立方向 —— 这些方向贡献给 image
    

注意关键点：

**一个方向不可能既“被压成 0”又“贡献输出独立方向”。**

所以这两部分不会重叠计数。

而输入空间的全部方向，要么落入 kernel，要么通过某个补空间贡献给 image。  
因此总维数必然分解成两部分之和。

## 8\. 它的本质意义是什么

秩-零度定理的本质不是一个“孤立公式”，而是在告诉你：

### 线性变换不会无缘无故“制造维数”

它只能：

-   把某些输入方向压没
    
-   把剩下的方向映成输出中的独立方向
    

所以输入维数的去向是可追踪的。

它解释了两个核心问题

#### 问题1：为什么 ![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM4Pzgx5Znm201x0kp8Uj37hPmEhWiczpP61uCyOtFdjIqia7L3NoPHWgsyYFhcT2ibxb0B8Jo1gzeibuEQAJia1Fiag4kw7Yo0Ftqpljp4qUWe5Bsdw/640?wx_fmt=svg&from=appmsg) 会有多少自由度？

因为自由度就是零空间维数，也就是 nullity。

#### 问题2：为什么矩阵能输出多少独立信息？

因为那就是 rank。

9\. 一句话记忆

你可以把秩-零度定理记成：

> **输入空间的维数 = 被压掉的维数 + 被保留的维数**

或者更形象一点：

> **总方向数 = 消失方向数 + 有效输出方向数**

  

## 10\. 和“行秩 = 列秩”有什么关系

有关系，但不是同一个定理。

-   **秩-零度定理：说的是  
    **定义域维数 = rank + nullity****
-   **行秩 = 列秩：说的是  
    矩阵的行空间维数和列空间维数相等，都叫 rank**

前者是“维数分账”；  
后者是“rank 这个数从行看、从列看都一样”。

#### 🔍 这段代码揭示了什么？

-   **秩 (Rank = 2)**
    
    在右图中，你会发现所有的点都落在了一个**平坦的平面**上。无论原始立方体有多厚，变换后它都失去了“高度”这个维度，只剩下了面积。
    
-   **零度 (Nullity = 1)**
    
    因为原始是 3 维，现在变成了 2 维，所以有 **1 个维度** 被“杀掉”了。在数学上，这意味着矩阵  的零空间（Null Space）是一条直线。所有落在这条直线上的点，变换后都会重合在原点。
