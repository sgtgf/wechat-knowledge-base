****一、****贝尔曼最优原理简述****

贝尔曼(R. Bellman)说：“An optimal policy has the property that whatever the initial state and the initial decision are, the remaining decisions must constitute an optimal policy with regard to the state resulting from the first decision”。

这让我想起一句英语谚语："The best time to plant a tree is 20 years ago. The second-best time is now"。

简单理解就是，最优策略的任何一部分子策略也必须是最优的，充分体现了动态、面向未来的概念。

****二、****无人机控制实例****

我以1个简单的无人机高度控制来阐述这个原理。

假设无人机从地面升至10m,要求时间最短，另外加速度在-3![](https://mmbiz.qpic.cn/mmbiz_png/RGhGOXAMG41Z3HgbPzb8fHKU3CL4X35icg6PibmCBqf5WyrZicOXpURA8abFccpha7tds1ibiaHPiaZzE5rnc4qeicJow/640?wx_fmt=png&from=appmsg)与2![](https://mmbiz.qpic.cn/mmbiz_png/RGhGOXAMG41Z3HgbPzb8fHKU3CL4X35icg6PibmCBqf5WyrZicOXpURA8abFccpha7tds1ibiaHPiaZzE5rnc4qeicJow/640?wx_fmt=png&from=appmsg)之间，速度在0m/s 与3m/s之间。

将高度与速度离散化，为了方便阐述问题，将高度划分为5个等级：2、4、6、8、10 ；类似，速度也划分为3个等级：1，2，3  

将初始状态（0，0）与目标状态（0，10）标在下图中，然后把中间的4\*4 = 16个状态也标在图中，从初始状态到目标状态，有4\*4\*4\*4种可能，最简单就是暴力搜索，计算各条路径的时间，找出时间最小的即为最优路径。

但这肯定不是最优的方案，以结果为导向，我们先从目标状态开始

注：下面的分析单位都省略了，且假定两点的平均速度为两点速度的平均值

从（0，8) 到（0，10）

速度0，还需要从8m升至10m，这是不可能的，代价J(0,8)\=无穷大，此时加速度为0;

从（1，8)到（0，10）

平均速度v=1/2=0.5, 时间t=2/0.5=4, 加速度a = -1/4 ，故J(1,8) = 4;

从（2，8) 到 （0，10）

平均速度v=2/2=1, 时间t=2/1=2, 加速度a=-2/2=-1 ，故J(2,8)=2;

从（3，8)到（0，10）

平均速度v=3/2=1.5, 时间t=2/1.5=4/3, 加速度a=-3/(4/3)=-9/4 ，故J(3,8)=4/3;

![](https://mmbiz.qpic.cn/mmbiz_png/RGhGOXAMG41Z3HgbPzb8fHKU3CL4X35icAdnO7ALZx0XIgwmdzt4f0AIZPcs7MPZw20vt0lOxszteF8kK53pVicA/640?wx_fmt=png&from=appmsg)

从（0，6)到（0，8）

速度0，还需要从6m升至8m，这是不可能的，代价J1(0,8)\=无穷大，此时加速度为0;

从（0，6)到（1，8）

平均速度v=1/2, 时间t=4, 加速度a=1/4 ，故J1(1,8)=4+4=8;

从（0，6)到（2，8）

平均速度v=1, 时间t=2, 加速度a=1 ，故J1(2,8)=2+2=4;

从（0，6)到（3，8）

平均速度v=3/2, 时间t=4/3, 加速度a=9/4>2 ，故J1(3,8)=无穷大;

故 J（0，6) = 4，a =1

...

继续计算，可得出从每个节点出发，达到最终目标的时间代价和加速度，如下图所示。最优的策略是，

首先，以a=1的加速度，速度从0/m加至2m/s, 花费2s, 运动的距离为2\*(0.5\*2) = 2m；

然后，以a=5/4的加速度，将速度从2m/s加至3m/s, 时间为1/(5/4) = 4/5s，运动的距离为4/5 \* (0.5\*(2+3)) = 2m；

再次，以v=3的速度，匀速行驶2/3 \* 2 = 4/3s, 运动距离为4m；

最后，以a = -9/4的减速度，将速度从3m/s减至0，花费时间3/(9/4) = 4/3s, 运动距离为4/3 \* (0.5 \* 3) = 2m; 

 总共时间 = 2 +4/5 +  4/3 + 4/3 = 82/15，运动距离为10m

![](https://mmbiz.qpic.cn/mmbiz_png/RGhGOXAMG40bDFOVKa3uhWVhRr3FqAsFUk7ic3TV05G6uSH2cyDHicfnHHib9eKiaSNx70bibaY23Xnxuv2hRyFBdyw/640?wx_fmt=png&from=appmsg)

如下图所示，假设初始状态在（2，2）位置，则最优策略就是绿色所示的路径，总共花了4/5 +  4/3 + 4/3 = 52/15s。

如下图所示，假设初始状态在（0，2）位置，则首先以a = 1的加速度，将速度从0 加至 2m/s, 花费的时间为2s, 运动的距离为2 \* （0.5 \* 2）= 2m; 然后，以a = 5/4的加速度，将速度从2m/s加至3m/s, 时间为1/(5/4) = 4/5, 运动的距离为4/5 \* (0.5 \* (2+3) =2m；后面就与最优路径相同了，总共花费的时间 = 2 + 4/5 + 2/3 + 4/3 = 24/5。

从上面的分析可以初步看出，假设我们把高度与速度离散的更细，则不管初始状态如何，最终总有相同的路径，且初始状态离最优路径越近，则与最优路径重合的比例越大，总时间代价就越小，就最优。大家想一想，这给我们的人生会有什么启示呢？
