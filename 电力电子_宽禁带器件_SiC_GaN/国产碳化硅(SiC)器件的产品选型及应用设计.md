# 国产碳化硅(SiC)器件的产品选型及应用设计


> 原文地址: [https://mp.weixin.qq.com/s/a1CMRC\_DqSH9-dL82aV0kQ](https://mp.weixin.qq.com/s/a1CMRC_DqSH9-dL82aV0kQ)

随着电力电子技术发展、国产碳化硅（SiC) 技术成熟度提升以及市场应用加速渗透这三大背景，碳化硅（SiC) 器件正从“高性能选项”转变为“市场主流选择”。其应用市场优势已从单一的性能优势，拓展为 **“性能-成本-供应链-系统价值”的综合优势**。

一、核心驱动力：技术、产业与市场的三重共振

**1.电力电子技术发展的内在需求**：系统正向高频化、高效化、高功率密度化（“三高”）演进。传统的硅基IGBT已接近材料理论极限，成为技术升级的瓶颈。碳化硅是打破此瓶颈的必然路径。

  

**2.国产碳化硅技术的成熟**：这是改变市场格局的关键变量。从衬底、外延到设计、制造、封装，国内已形成完整产业链。国产器件在**650V~1200V**中低压领域性能对标国际主流，价格更具竞争力，且供应稳定可控。1700V~3300V中高压产品也在上量中。

  

**3.市场应用的广泛验证**：新能源汽车、光伏储能等领域已完成从“试用”到“量产”的跨越，成功案例极大降低了新行业、新客户的应用风险和心理门槛。

### **2.碳化硅MOS管（SiC MOSFET）产品线：**

SiC MOSFET在开发与应用方面，与相同功率等级的Si基（MOSFET/IGBT)器件相比，SiC MOSFET器件导通电阻低、开关损耗大幅减小，适用于更高的工作频率，另由于其高温工作特性，大大提高了高温稳定性。

2.1 SiCMOSFET的晶圆片

有自建晶圆厂，SiC MOSFET分立器件现有的产品规格，均可提供晶圆代工及裸芯片服务。产品电压650V~3300V,电流1A~150A.

2.3  SiCMOSFET的封装方式

按照安装在PCB板上的方式来划分，SiC MOSFET管封装主要有两大类：插入式(Through Hole)和表面贴装式(Surface Mount)，还有一种类似模块封装的SOT-227封装。  

![](D:\电脑文件\公众号知识库\电力电子_宽禁带器件_SiC_GaN\国产碳化硅(SiC)器件的产品选型及应用设计_images\img_024_dd1af4cd4475.jpg)

SiC MOSFET产品封装图

  

插入式就是MOSFET的管脚穿过PCB板的安装孔并焊接在PCB板上。插入式封装有晶体管外形封装(TO)。插入式封装主要有 ：TO-247-3、TO247-4、TO220F 。  

插件SiC MOSFET产品是市场通用器件，可用于各种PFC和桥式整流电路，应用市场主要包括：汽车OBC、DC-DC、充电桩、空调变频器、光伏逆变器、UPS、大功率LED电源、通信电源、各种工业设备电源等，功率从几百瓦到几百千瓦不等。

![](D:\电脑文件\公众号知识库\电力电子_宽禁带器件_SiC_GaN\国产碳化硅(SiC)器件的产品选型及应用设计_images\img_025_87626761f59e.jpg)

  

表面贴裝则是SiC MOSFET的管脚及散热法兰焊接在PCB板表面的焊盘上。  

贴片封装主要有：DFN5×6、DFN8×8、TO-263-7、TOLL。

  

贴片封装碳化硅MOSFET产品，主要用于各种小功率电源PFC电流或其他整流电路，功率范围主要在0~3000W，电视电源、家电电源、手机适配器、电脑适配器、新能源汽车DC-DC转换器、小功率OBC、微型逆变器等。

  

SOT-227封装介于单管和模块之间，产品具有模块体积小、热阻低、通流能力强的特点。M4螺丝法蓝底板安装4个引出端口，常用来封装IGBT、各类二极管、MOSFET等。同时，SOT-227为内绝缘封装，安装简便，也更安全。

  

3.碳化硅功率模块（SiC Module）产品线：

  

碳化硅（SiC）功率模块是以碳化硅材料为核心的功率电子器件，由多个SiC MOSFET和SiC SBD通过封装工艺集成而成。其典型结构包括芯片、覆铜陶瓷基板（DBC/AMB）、银烧结层、金属引线框架及外壳，部分模块集成温度传感器和驱动电路。

  

![](D:\电脑文件\公众号知识库\电力电子_宽禁带器件_SiC_GaN\国产碳化硅(SiC)器件的产品选型及应用设计_images\img_026_562acbecdaa5.jpg)

  

与传统硅基IGBT模块相比，碳化硅模块通过材料升级实现了更高的功率密度和效率，显著降低了开关损耗和EMI干扰。 

  

1.  SiC 模块拥有丰富的拓扑结构，包括半桥、三相全桥、三电平以及boost升压电路等封装形式。根据外围器件的集成情况,还有 PIM、IPM 和逆变砖等封装形式。 从散热方式来看, SiC模块可以分为单面冷却和双面冷却。随着客户端需求的多样化，定制化模块也逐渐流行起来。

### **四、SiC器件特性与选型要点**

1\. 碳化硅肖特基二极管

**关键特性**：**零反向恢复电荷**。这是其最核心优势。

**选型核心**：

**电压裕量**：在PFC或桥式电路中，必须考虑母线电压波动和开关尖峰。建议650V器件用于380VAC三相输入（峰值约540VDC）且需留有充足余量；1200V器件用于更高压或对可靠性要求极严苛的场合。

  

**热性能与封装**：关注`RθJA`（结到环境热阻），TO-220AB、TO-247-2/3是主流。**注意：其正向压降Vf随结温升高而降低（负温度系数），理论上有利于并联均流，但实际仍需关注动态均流**。

**选型对比指标**：

![](D:\电脑文件\公众号知识库\电力电子_宽禁带器件_SiC_GaN\国产碳化硅(SiC)器件的产品选型及应用设计_images\img_057_b4ca1d108285.png)

#### **2\. 碳化硅 MOSFET管**

**关键特性**：

**单极性器件、高临界电场、高电子饱和漂移速度**。带来三个核心优势：高速、高压、低导通电阻。

  

**电压等级**：与SBD类似，但更需关注**短路耐受能力（SCWT）**。不同厂商、不同型号的SCWT差异大（2μs到10μs不等），直接影响保护电路设计。

**栅极特性**：

**阈值电压Vth**：SiC MOSFET的Vth通常较低（2-4V），且分布可能较宽。**设计负压关断（-3V至-5V）是必须的，以防止dv/dt导致的误开通。**

**栅极安全工作区**：**绝对不要超过`VGS_max`（通常+19/-5V）**。建议工作在+15~18V/-3~-5V。

****动态特性**：**

**输出电容`Coss`及其非线性**：`Coss`随Vds变化剧烈。计算开关损耗时，不能简单使用固定值，需参考器件手册中的`Eon`、`Eoff`、`Eoss`能量曲线。

  

**体二极管导通压降`VSD`**：在换流过程中会导通，其压降和反向恢复特性（虽小但非零）需评估。

**选型对比指标**：

![](D:\电脑文件\公众号知识库\电力电子_宽禁带器件_SiC_GaN\国产碳化硅(SiC)器件的产品选型及应用设计_images\img_058_805018c81e82.png)

#### **3\. 碳化硅功率模块**

**关键特性**：**低寄生参数集成、高功率密度、优化热路径**。

**选型核心**：

**拓扑与集成度**：半桥、全桥、六单元、PIM等。更高的集成度（如集成驱动、温度采样）可简化外围电路，但定制化程度高。

  

**寄生参数**：**模块内部杂散电感`Ls`是关键**。`Ls`直接影响开关过冲电压（`Vpeak = Vbus + Ls * di/dt`）。选择`Ls`更小的模块，可以降低对缓冲电路的需求，或允许使用更快的驱动。

  

**基板**：AMB（活性金属钎焊）基板比DBC（直接覆铜）具有更高的热导率、更好的热循环可靠性，适用于高功率密度和严苛环境。

**封装与散热**：

**连接端子**：烧结银>焊接>铝线键合。烧结技术大幅提升功率循环和温度循环寿命。

**绝缘耐压**：关注`Viso`（基板对散热器的绝缘电压），根据系统安全标准选择。

### **五、应用设计与注意事项——开发中的“坑”与填坑指南**

这是工程实现的核心，决定方案的成败。

**1.驱动电路设计（重中之重）**

**驱动芯片选型**：选择专为SiC优化的驱动器，具备：

**足够高的峰值拉/灌电流能力**（如>5A），以实现快速开关。

**极短的传输延迟和延迟匹配**。

  

**较高的共模瞬态抑制能力**，以应对高dv/dt。

PCB布局黄金法则：

驱动回路最小化：驱动IC的输出到MOSFET栅极，再经开尔文源极（或最靠近的源极引脚）返回驱动IC的地。此环路面积必须**极小**。

  

分开设置开通(`Rgon`)和关断(`Rgoff`)电阻。`Rgoff`通常更小以确保快速关断和负压建立。

  

**在双脉冲测试平台上精细调试**，在开关损耗、电压过冲、栅极振荡之间取得最佳平衡。  

  

功率回路最小化：直流母线电容正极 -> 模块上管C -> 模块上管E/下管C -> 模块下管E -> 母线电容负极。此环路面积必须极小。

  

使用低电感叠层母排或PCB嵌入式母线是高端设计的常见做法。

  

**2.散热与热管理**

**结温估算**：

使用`Ptot = (P_cond + P_sw) * 热阻`进行初步计算。**必须实测验证**，尤其在开关频率很高时，开关损耗占比大。

  

**导热界面材料**：选择高性能导热硅脂或相变材料，确保接触热阻低且稳定。

  

**散热器设计**：针对高热流密度，可能需要使用铲齿、针翅等高效散热器，或采用液冷。  

  

3.保护与可靠性

**过流/短路保护**：利用去饱和检测或源极串联分流电阻方案。**响应时间必须小于器件标称的短路耐受时间**。

  

建议加入两级保护：快速限流（硬件）和关断（硬件/软件）。

**过压保护**：

**关断过冲**：通过优化`Rgoff`、减小`Ls`、使用RCD吸收电路来抑制。

**浪涌电压**：在母线端使用压敏电阻或TVS管。

**dv/dt与di/dt管理**：

高dv/dt可能通过米勒电容耦合导致桥臂串扰，**确保负压关断和低阻抗驱动回路**是根本。

  

高di/dt会加剧EMI，需在布局时就将高di/dt环路屏蔽或远离敏感信号。

  

**4.EMI设计与测量**

**源头抑制**：优化开关边沿（调节栅极电阻）是第一道防线。

**滤波**：共模电感、X/Y电容的设计需考虑高频特性。SiC的开关频率可达数百kHz，其EMI噪声频谱会延伸至数十MHz甚至百MHz以上。

**测量挑战**：使用高频电流探头和高压差分探头时，务必注意其带宽和共模抑制比是否满足要求。

### **六、开发流程建议**

**1.系统级仿真**：在LTspice、PLECS、Simplis等工具中建立包含器件模型（最好使用厂商提供的精细模型）、寄生参数、驱动电路的仿真，预先评估性能。

  

**2.双脉冲测试**：这是**必须的步骤**。搭建DPT平台，在不同电压、电流、温度、栅极电阻下测试，获取真实的开关波形和能量数据，验证驱动和吸收电路。

  

**3.样机调试**：从小功率开始，逐步提升功率。**务必使用隔离探头、差分探头进行测量**，安全第一。

重点关注：

开关节点的电压振铃。

  

栅极电压的稳定性（有无振荡或平台）。

  

桥臂中点的dv/dt。

  

关键元件的温升。

  

4.寿命与可靠性测试：对于量产产品，需进行高温老化、功率循环、温度循环等测试，验证设计的鲁棒性。

  

七、挑战与未来趋势

**1.当前挑战**：

**成本**：虽在下降，但衬底成本和制造良率仍是制约。

  

**可靠性认知**：车规级、工规级的长寿命可靠性数据仍需时间积累。

  

**应用门槛**：高频高速设计、热管理、驱动保护等对工程师要求高。  

  

2.未来趋势：

**产业链协同降价**：国产6英寸、8英寸衬底量产将推动成本进一步下探。

  

**模块化与集成化**：国产智能功率模块、驱动集成模块将降低应用难度。

  

**全产业链自主可控**：从衬底到模块的国产化，保障了关键基础设施的供应链安全，这是国家战略层面的大优势。

### **结论**

**碳化硅器件应用市场的核心优势，已从“性能领先”的单轮驱动，转变为“性能提升 + 系统成本优化 + 供应链安全 + 赋能创新”的四轮驱动。**

**国产碳化硅技术的成熟是这场变革的加速器**。它不仅仅是提供了一个替代供应商，更是通过**更具竞争力的成本、更敏捷的服务和更可靠的供应保障**，使得碳化硅解决方案的“性价比天平”加速倾斜，从而推动了其在新能源汽车、新能源发电、工业升级等核心战略领域的**规模化、平民化应用**。
