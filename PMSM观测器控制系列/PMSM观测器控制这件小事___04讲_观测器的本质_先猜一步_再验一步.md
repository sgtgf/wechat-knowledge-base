各位同仁，上一篇咱们把三相交流电流变成了dq坐标系里的两个直流量。

这个魔术有个前提：Park矩阵里的  和 ，但 从哪来？

有编码器？直接读。没有？你只能猜。

但"猜"不是瞎猜。观测器每过一个采样周期，都在做同一件事：

先猜一步。再用电流验证一下。猜错了就修。修完下一轮再猜。

这就是预测-校正。

## 盲人拄拐杖：观测器到底在干什么？

各位同仁，想象一个盲人走在陌生的路上。

他看不见前方，但脑子里有一张大概的地图——"往前走十步应该有个台阶"。这是**预测**。

他迈出一步，拐杖往前一探。"笃"的一声，触到地面了。这是**测量**。

台阶的高度和他猜的差不多？继续走。差太多了？赶紧调整步伐。这是**校正**。

再走一步，再探一下，再调一下。周而复始。

观测器干的就是这个。

**盲人** = 观测器。它看不到电机内部的转子角度、磁链分布。

**心里的地图** = 电机模型。它知道"如果角度是30度、速度1000转，电流应该长什么样"。这张地图不是凭空想象的，是电机的电压方程、磁链方程一笔一笔画出来的。模型越准，预测步猜得越靠谱。

**拐杖触地** = 相电流采样。这是它唯一能"摸到"的真实信息。ADC 每过几十个微秒采一次样，就像盲人每走几步就用拐杖点一下地。

**调整步伐** = 校正。模型猜的电流和实际测的电流对不上，说明模型里的角度或速度猜错了，修正。

每采样一次，就摸一次、调一次。摸得越多，调得越勤，心里那台"虚拟电机"就越接近真实的电机。

说白了，观测器不是盲人乱走，是盲人带着地图、拄着拐杖、边走边修正。

这里有个关键点，很多人第一次学观测器时会迷糊：

拐杖触地，盲人能直接感受到的是"地面高不高"，不是"我在哪"。电流测量也一样——ADC 采到的是 、的数值，不是直接告诉你"转子角度是37.5度"。

观测器是通过"电流对不对"来间接推断"角度对不对"。

模型说："如果角度是30度， 轴电流应该是3A。"

测出来是2.8A。差了一点。修正猜测："角度可能不是30度，也许是28度。"

下一轮再验。2.95A。更接近了。再微调。

这就是迭代收敛的直觉。不是一步登天，是一步步逼近。就像你调收音机的旋钮——先拧到一个大概位置，声音有点杂音，往左拧一点，再听，还杂，再往右拧一点，直到最清晰。

拐杖也不是万能的。地面触感只能告诉你"这里有没有台阶"，不能告诉你"前面有没有墙"。电流测量同理——它只能验证"模型预测的电流对不对"，不能直接测量角度。观测器是通过"电流验证对了"来间接推断"角度猜对了"。如果模型本身有系统性偏差（比如电阻参数标错了），拐杖触地再多，盲人也会一直走在错误的路上。

## 为什么不能只猜不验？

有些同仁会问：模型这么好用，直接积分算下去不行吗？

理论上可以。这叫**开环估计**——有模型、有初始状态，一路往前推。

实际不行。

模型不完美，参数会随温度漂移，计算有截断误差。这些小误差每一轮都在累积。就像你闭着眼睛走路，心里默数步数。前十步还挺准，走了一百步，你心里想的方位和实际位置可能差了几米。

电机控制里，这叫**积分漂移**。

下面的时间尺度假设采样频率约 20kHz，仅供理解量级——在参数存在一定失配、模型不够精确的前提下，开环估计只跑十个采样周期（约0.5毫秒），误差小到可以忽略。跑一百个周期（约5毫秒），偏差可能开始冒头。跑两千个周期（约100毫秒），差几十度并不罕见。

几十度意味着什么？

FOC 的 、 解耦依赖于准确的角度。角度差30度，你以为是纯  的电流，实际上约一半转矩电流串到了  轴， 轴只剩下约 86.6% 的有效分量。电机出力打折扣，效率暴跌，严重的时候电流环直接振荡。

角度差90度？那更惨。 轴和  轴的电流分量基本互换，你以为是转矩电流的指令，实际大部分变成了弱磁电流，电机几乎不出力，严重时还可能因为电流方向错乱而失控。

我第三次调观测器的时候就栽在这个坑上。当时觉得模型参数挺准的，就把校正项关掉了，想看看纯模型预测能撑多久。

前两百毫秒，示波器上估计角度和编码器实测几乎重合。我心里还暗喜：模型挺准的嘛。

五百毫秒后，两条线开始慢慢分开。一个往左，一个往右，像分手的恋人。

十秒之后，差距将近九十度。电机还在转，但电流波形已经开始畸变，母线电流里出现了奇怪的谐波。再往下跑，随时可能过流保护。

我赶紧把校正项打开。两秒钟后，估计角度像被一根绳子拽着一样，慢慢回到了编码器实测附近。

这就是只猜不验的后果。预测给你方向，但不验，方向再对也会跑偏。

**闭环估计**（观测器）解决这个问题的办法很简单：每隔几步就睁开眼睛看一眼。

在电机里，"睁开眼睛"就是测电流。"拐杖触地"的触感一回来，立刻对比心里的地图，偏了就修。

没有校正的预测，是盲人闭眼走路。有了校正，是盲人拄拐杖走路——拐杖碰到东西了，就知道方向偏了，赶紧调整。

说白了，预测是信仰，校正是现实。信仰让你有方向，现实让你不跑偏。两者缺一不可。只信现实，会被噪声带偏。只信信仰，会被漂移带偏。观测器的全部智慧，就是在这两者之间找平衡。

## 骨架：一个公式就能讲清楚

这个"猜-验-修"的结构，用数学语言写就是一句话（龙伯格观测器（LO, Luenberger Observer）的形式，仅用于说明骨架）：

别慌，这不是让你推导，是让你**看结构**。

 = 预测项。"根据模型和上一时刻的状态，我猜现在应该长这样。"

 = 实际测到的电流。

 = "如果我的猜测是对的，那测量值应该长这样。"

 = 残差。"我猜的电流和实际电流差了多少？"

 = 增益。"差了多少？补多少回到猜测里。"

整个公式就两层意思：**先猜**（前半截），**再修**（后半截）。

这对应到物理直觉上——观测器内部有一台"虚拟电机"。它的状态和真实电机同步演化，但它还会对比自己的"理论输出"和真实电机的"实际输出"，用误差修正自己的状态。

怎么判断虚拟电机和真实电机是否同步？看电流波形。

虚拟电机预测的电流波形，和真实电机实测的电流波形，越重合说明状态估计越准。示波器上如果能同时看到两条线，贴得越近，观测器调得越好。分道扬镳了，要么模型不准，要么增益不对。

注意上面的公式写成线性形式 ，只是为了说明观测器的结构。真实永磁同步电机（PMSM, Permanent Magnet Synchronous Motor）的状态方程含有 、、电角速度耦合等非线性项，没那么简单。龙伯格观测器用线性化模型设计，扩展卡尔曼滤波器（EKF, Extended Kalman Filter）直接处理非线性，滑模观测器（SMO, Sliding Mode Observer）和模型参考自适应系统（MRAS, Model Reference Adaptive System）走的又是完全不同的路子。但不管血肉怎么长，大多数观测器的骨架都是这个——先猜，再修。

SMO 用开关函数当校正机制，像拐杖触地后"硬拽"一把。EKF 用卡尔曼增益加权融合，像拐杖触地后"温柔地引导"。MRAS 用两个模型并行对比，像两个盲人互相验证。龙伯格用线性反馈修正，像拐杖触地后"按比例调整"。

猜法不同，修法不同，但底层都是"猜-验-修"的三拍循环。今天你只要记住骨架，血肉咱们后面一篇一篇拆。

## 代码里的预测-校正

看公式有点虚，咱们看看真实代码里长什么样。

VESC 的 `foc_observer_update()`（`bldc@c5944554 motor/foc_math.c:89-105`，Ortega 原始观测器分支）：

`// 来源: bldc@c5944554 motor/foc_math.c:89-105   // FOC_OBSERVER_ORTEGA_ORIGINAL 分支内部      // === 校正步：算残差 ===   // 标称磁链 lambda^2 减去估计磁链幅值平方   float err = SQ(lambda) - (SQ(state->x1 - L_ia) + SQ(state->x2 - L_ib));   if (err > 0.0) {       err = 0.0;    // 强制误差非正，帮助收敛   }      // === 预测步 + 校正步合体 ===   // 电压驱动项 = 预测（模型说磁链该怎么变）   // 误差反馈项 = 校正（用磁链偏差修正猜测）   float x1_dot = v_alpha - R_ia + gamma_half * (state->x1 - L_ia) * err;   float x2_dot = v_beta  - R_ib + gamma_half * (state->x2 - L_ib) * err;      state->x1 += x1_dot * dt;   state->x2 += x2_dot * dt;`

注意看 `x1_dot` 的结构：

**`v_alpha - R_ia`** = 预测。电压驱动减去电阻压降，这是电机模型告诉你的"磁链变化率应该长什么样"。

**`gamma_half * (state->x1 - L_ia) * err`** = 校正。`err` 是磁链幅值残差，`gamma_half` 是增益K。模型预测的磁链和理论磁链差了多少？补到变化率里。

两个项合在一个微分方程里，同时做预测和校正。每一轮 `dt` 积分一次，就是"猜一步，修一步"的代码实现。

通俗来讲：`v_alpha - R_ia` 是盲人心里的地图在说"前面应该平坦"，`gamma_half * ... * err` 是拐杖触地后的修正——"不对，有个坑，往左偏一点"。

这段代码出自 Ortega 等人提出的非线性磁链观测器，是 VESC 支持的无感磁链观测器分支之一（VESC 默认使用 Mxlemming 带磁链补偿的变体）。它的巧妙之处在于：不直接估计角度，而是估计磁链。磁链的物理特性比角度更"稳重"——角度会周期性地从0跳到 ，磁链不会。估计完磁链再用  或 PLL 提取角度，稳定性更好。

再看 ODrive 的 `sensorless_estimator.cpp`（`ODrive@3a2e4dd1 Firmware/MotorControl/sensorless_estimator.cpp:60-82`）：

`// 来源: ODrive@3a2e4dd1 Firmware/MotorControl/sensorless_estimator.cpp:60-82      // === 预测步 ===   float y = -axis_->motor_.config_.phase_resistance * I_alpha_beta[i]             + V_alpha_beta_memory_[i];   flux_state_[i] += y * current_meas_period;      eta[i] = flux_state_[i] - axis_->motor_.config_.phase_inductance * I_alpha_beta[i];      // === 校正步 ===   float pm_flux_sqr = config_.pm_flux_linkage * config_.pm_flux_linkage;   float est_pm_flux_sqr = eta[0] * eta[0] + eta[1] * eta[1];   float bandwidth_factor = 1.0f / pm_flux_sqr;   float eta_factor = 0.5f * (config_.observer_gain * bandwidth_factor)                      * (pm_flux_sqr - est_pm_flux_sqr);      flux_state_[i] += eta_factor * eta[i] * current_meas_period;`

两段代码，两种实现，同一个结构。

VESC 的预测和校正合在一个微分方程里，紧凑。ODrive 的预测和校正分成两步，清晰。

VESC 的残差 `err` 是标称磁链和估计磁链幅值的平方差，校正项把这个磁链偏差反馈到磁链变化率里。ODrive 的残差 `pm_flux_sqr - est_pm_flux_sqr` 也是磁链幅值偏差，校正项直接修正磁链估计。形式不同，但底层思路一样：用电压和电流估计磁链，再用永磁体磁链的幅值约束去修正估计。

从工程解释角度，大多数常见电机状态观测器都可以抽象成这个结构：**先猜，再验，再修**。但不同算法的"猜法"和"修法"差异很大，不能混为一谈。

## 示波器上的预测-校正

理论说再多，不如看波形。

如果你手边有示波器，该看什么？不同观测器侧重点不一样。

对电流观测器或 LO/EKF，可以对比**预测电流**和**实测电流**。两条线越贴近，说明模型预测越准。

对磁链观测器（如 VESC/ODrive 的 Ortega 分支），硬件测不到"实测磁链"，应该重点看**估计磁链幅值**是否稳定在标称值附近、**磁链幅值残差**是否收敛到零、**PLL 相位误差**是否平稳、**估计角度**有没有高频抖动。

调好增益的时候，残差像一条平静的细线挨着零轴，估计角度稳如老狗。这说明虚拟电机和真实电机同步了，观测器收敛了。

增益太小的时候，遇到负载突变，估计磁链或估计角度慢吞吞地跟不上，像老牛拉车。残差变大，持续时间长——校正力度不够，模型跑偏了追不上。

增益太大的时候，估计角度跟着测量噪声高频抖动。残差在零轴附近疯狂震荡——校正过度了，噪声被当成信号在追。

最理想的波形是：稳态时残差几乎为零，估计角度平滑；动态加减速时，估计量快速响应，残差短暂变大后迅速回落。这个"快速响应"又不"过度震荡"的边界，就是增益K的甜点区。

找到这个甜点区没有公式能一次性算出来。不同电机、不同负载、不同温度，甜点区都在变。这就是调试观测器的核心挑战——不是算出来的，是试出来的。

## 信任的博弈：K 调大了会怎样？

公式里的 （代码里的 `gamma_half` 或 `observer_gain`）是个关键角色。它回答一个问题：

**你更信模型，还是更信测量？**

 大 = 极度信任测量。实测电流一偏差，立刻大力修正猜测。响应快，但测量噪声也会被一起放大。就像一个近视的人戴了过度矫正的眼镜——确实看得清了，但头晕目眩。

 小 = 更信任模型。实测有偏差？只微调一下猜测。平滑，但动态响应慢，模型漂移了也追不上。就像拐杖触地了也不太理会，坚持按心里的地图走，撞到墙了才反应过来。

这个权衡不是抽象的，是每天都在工程现场发生的真实抉择。

夏天车间温度升高，电机绕组电阻随温度漂移——铜的电阻温度系数约 0.4%/°C，温升几十度时参数偏移不容忽视（下面的数字只是为了帮助理解量级，不是精确阈值）。你的模型还是按标称参数在猜，预测步已经开始偏了。这时候如果K太小，模型跑偏了校正追不上，角度估计稳态偏差变大。如果K太大，测量噪声被放大，估计值抖动，电机嗡嗡响。

负载突变的时候更明显。突然加载，电流纹波变大，ADC 采样里的噪声成分增加。K 太大，观测器会把纹波当信号追着跑，估计角度高频抖动。K 太小，负载变了转速掉了，观测器反应迟钝，速度环觉得电机"不听话"。

观测器工程师的日常，就是在"模型不准"和"测量不纯"之间走钢丝。走好了，电机稳如老狗。走偏了，电机抖如癫痫。

这个权衡没有标准答案。风机泵类负载，转速变化慢，K 可以偏小，优先平滑。伺服关节，动态响应要求高，K 可以偏大，但要加滤波抑制噪声。具体怎么调，咱们在后续的子专题里专门讲调试方法论。

今天你只需要记住：**K 不是越大越好，也不是越小越好，它是一个信任度的调节旋钮。**

## 两个最要命的坑

### 坑 1：模型参数不准，观测器永远调不顺

**症状**：角度估计偏差大，低速抖动，高速发散。

**根因**：观测器的预测步依赖电机模型。、、 严重失配时，预测偏差会变大，校正步的压力也会增加。就像你手里的地图是错的——地图上画的是直路，实际是弯路，拐杖触地了你也修不对方向。

**排查思路**：先把校正项关掉，跑开环估计。如果开环估计一开始就有明显偏差，说明参数有问题。用 LCR 表或自动辨识程序重新测量  和 。温度变化大的场景，考虑在线参数辨识（本系列的子专题会单开一章专门讲这个）。

### 坑 2：增益太大，观测器抖振

**症状**：角度估计值高频抖动，电机嗡嗡响，电流纹波大。

**根因**：校正增益  太大，测量噪声被过度放大。拐杖太敏感，路上每一块小石头都让你绕个大弯。

**排查思路**：逐步减小增益，观察抖动是否减弱。同时检查 ADC 采样质量——如果电流采样本身就有较大噪声，先把硬件问题解决，再调增益。不同观测器的"增益"形式不同——SMO 叫滑模增益，EKF 叫噪声协方差，MRAS 叫 PI 参数——但本质都是在调校正力度。

## 🔧 调试 Checklist

\[ \] 确认电机参数 、、 已精确测量（LCR 表或辨识程序）  
\[ \] 确认观测器增益适中：稳态时估计角度无高频抖动，动态加减速时跟踪无过大滞后  
\[ \] 查看观测器输出稳定性：对磁链观测器（如 VESC/ODrive），关注估计磁链幅值、磁链幅值残差、PLL 相位误差和估计角度抖动；对电流观测器或 LO/EKF，可对比预测电流和实测电流的吻合度  
\[ \] 验证闭环估计和开环估计的收敛差异：闭环应能快速拉回，开环应持续漂移
