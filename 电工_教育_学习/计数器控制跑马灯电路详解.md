# 图③ CD4017内部逻辑工作原理

CD4017如图所示。它是由十进制计数器电路和时序译码电路两部分组成。其中的D触发器F1一F5构成了十进位的约翰逊计数器，门电路5一14构成了时序译码电路。约翰逊计数器的结构比较简单，它实质上是一种串行移位寄存器。除了第3个触发器是通过门电路15、16构成的组合逻辑电路作用于F3的D3端以外，其余各级均是将前一级触发器的输出端连接到后一级触发器的输入端D的，计数器最后一级的端连接到第一级的D1端。这种计数器具有编码可靠，工作速度块，译码简单，只需由二输入端的与门即可译码，且译码输出无过渡脉冲干扰等特点。通常只有译码选中的那个输出端为高电平，其余输出均为低电平。

# 图④ CD4017控制的LED跑马灯

见图，由555集成电路形成的多谐振荡器电路由3脚输入CD4017的14脚电压控制，CD4017的15、16脚门电路构成的组合逻辑电路作用于各级的触发端而控制逐行LED灯的顺序光亮变换。

CD4017集成电路十进位计数器译码电路，在电子电器电路中广泛应用，可靠，速度快，译码简单等优点。
