## 1\. PI 足够好，为什么还要改？

读到这里，你应该已经熟悉了这个公式：

经典 PI 自适应律的好处是明摆着的：两个参数、在满足经典 MRAS 模型假设和前向通道 SPR 条件时可用 Popov 框架证明稳定、每个 PWM 周期十几条浮点指令就能跑完。[第43讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486846&idx=1&sn=20da599fedfdf713b37f80bcc908d0b2&scene=21#wechat_redirect) 里我们花了不少篇幅讲它为什么不会发散——那不是废话，那是你敢于把它放进产品的底气。

但 PI 有个结构性矛盾，工程师在产线上迟早会撞上。

**P 项管响应，I 项管精度，但两者的最优增益在不同工况下是打架的。** 电机从静止加速到额定转速，误差信号  的幅值和频率跨度可能差两个数量级。你用高速区调好的 ，放到低速区会把噪声一起放大；你用低速区调好的 ，放到动态加减速时收敛慢得像蜗牛。

这就是 PI 的天花板：它用同一组增益去覆盖整个速域，本质上是在不同工况之间做妥协。

更隐蔽的问题在参数漂移。定子电阻  从冷态到热态可能变化 30%~50%（铜绕组温度系数约 0.00393/°C，80°C 温升对应约 +32%），磁链  在高温下缓慢退磁。这些变化不剧烈，但足够让固定增益的 PI 在特定工况下偏离最优工作点。

问题来了：改它，值得吗？

## 2\. 三种"导航升级"路线

先把技术放一边，想一个你每天都在用的东西——导航。

**经典 PI 就像自动导航。** 规则写在代码里：偏左就打右、偏右就打左。高速公路上好用，因为路况线性、可预测。但遇到堵车、施工、行人乱穿，它照样按固定规则走，死板。

**模糊逻辑 MRAS 就像老司机。** 他不按固定规则打方向，而是凭经验："偏左很多而且速度很快，那就多打一点；偏左一点点但速度很慢，那就轻点修。"

**分数阶 MRAS 就像可调记忆深度的导航。** 经典 PI 的积分项是"全历史平均"，从开机到现在的每一个误差都同样计入。分数阶把积分的"记忆权重"变成可调的——你可以让它更关注近期误差，也可以让它更看重长期趋势。

**神经网络 MRAS 就像让 AI 看几百万小时驾驶视频自己学。** MRAS 的参考模型和可调模型框架仍保留，只是把 PI 自适应律中的解析误差-转速映射换成 RBF 网络的数据驱动拟合。潜力大，但黑箱，不好把控。

## 3\. 路线一：模糊切换 PI——最务实的升级

参考文献 \[2\] 的做法，说出来不复杂：**不扔掉 PI，而是根据电流误差的幅度自动切换不同的 PI 增益组。**

误差大的时候（比如启动、负载突变），你需要快速收敛，于是上高增益组；误差小的时候（稳态运行），你需要抑制噪声，于是切低增益组。本质上是在 PI 框架内做"增益调度"（gain scheduling）。

这里需要做一个关键区分，很多人容易搞混：

参考文献\[2\] 里提到的"模糊逻辑控制器（FLC）"，主要用在**速度环和电流环**——用模糊规则替代传统的速度 PI 和电流 PI。而**MRAS 观测器本身的改进**是"切换 PI 控制"：根据电流误差幅度设置不同阈值，自动选择合适的 PI 自适应机制。

也就是说，MRAS 的自适应律仍然是 PI 结构，只是增益不是固定的，而是根据误差大小在几组预存的  之间切换。

### 实验证据

参考文献\[2\] 做了硬件实验（不是纯仿真），有几个值得一看的数据：

-   • **定子电阻跟踪**：电阻变化序列 ，验证了在线跟踪能力。
    
-   • **参数鲁棒性**：在电感和永磁磁链同时变化（ 和 ）的条件下，基于 FLC 的速度估计仍保持精度。
    

### 代码示意（示意用）

`// 切换 PI 自适应律（示意用，非直接引用）   // 输入：误差幅值 |e|，当前速度估计 omega_hat   // 输出：下一拍速度估计 omega_hat_next      float abs_e = fabsf(A_e);  // A_e 为误差矢量的非线性函数输出      if (abs_e > ERROR_THRESHOLD_HIGH) {    // 误差大：快速收敛       Kp = KP_HIGH;       Ki = KI_HIGH;   } else if (abs_e > ERROR_THRESHOLD_LOW) {    // 误差中等：折中       Kp = KP_MID;       Ki = KI_MID;   } else {    // 误差小：抑制噪声       Kp = KP_LOW;       Ki = KI_LOW;   }      // 位置式 PI：直接计算转速估计值（与 参考文献[1] 的 PI 自适应律结构一致；A(e) 的具体定义取决于误差模型）   integral += A_e * Ts;   integral = clampf(integral, -INTEGRAL_MAX, INTEGRAL_MAX);   omega_hat = Kp * A_e + Ki * integral;   omega_hat = clampf(omega_hat, -OMEGA_MAX, OMEGA_MAX);`

### 计算代价

切换 PI 增加的额外开销很有限（粗略估算，未做 DWT cycle count）：

-   • 两次阈值比较 + 条件分支：约 3~5 条指令
    
-   • 查表选增益组（若增益组多于 3 组）：约 5~10 条指令
    
-   • 总计额外开销的量级：约 **10~20 条浮点指令/周期**
    

额外开销通常远小于分数阶或神经网络方案。这是**工程上最可行的升级路径**。

### 代价转移

你省了手动调节  的时间，但换来了设计切换阈值和增益组的时间。阈值设得太宽，切换不频繁，效果不明显；阈值设得太窄，频繁切换可能导致增益抖动。通常的做法是先离线仿真扫一遍误差幅值分布，再定阈值。

## 4\. 路线二：分数阶 FOPI——数学上的优雅，工程上的重

分数阶微积分在电机控制领域不算新鲜，但把它塞进 MRAS 的自适应律里，参考文献 \[3\] 是一个代表性的尝试。

核心改动只有一处：把整数阶积分换成分数阶积分。

当  时，这就是经典 PI。当  时，积分行为的"记忆特性"发生了变化。

**关键直觉**：

-   • ：远期权重快速衰减，积分更"健忘"。对突变的响应更快，但稳态精度可能稍差——因为历史记忆不够深，持续的小误差可能被"遗忘"。
    
-   • ：远期权重反而增长，积分更"记仇"。历史误差被过度累积，对持续偏差的消除能力强，但突变响应会变钝，且更容易积分饱和。
    

\[3\] 的仿真结果显示，PSO 优化后的 FOPI 在不同工作点下均优于整数阶 PI。但注意——这是**仿真结果**，而且是 PSO **整定**的结果。

### PSO 离线整定

参考文献\[3\] 用粒子群优化同时搜索三个参数：。优化目标是在多个工作点下最小化综合性能指标（通常包含速度误差、电流纹波、超调量等的加权组合）。

PSO 的粒子数和迭代次数需要预先设定。\[3\] 提到"PSO 在极低的迭代次数下即可收敛到最优代价函数值"，但没有给出具体的粒子数和迭代次数。对于三参数搜索，一般经验范围是 20-50 个粒子、50-200 次迭代，每轮仿真评估一个代价函数值。总计算量相当于运行数千次电机仿真——这是在 PC 上**离线**完成的，不是在 MCU 上实时跑的。

也就是说，PSO 帮你找了一组好参数，但电机参数一变（比如换了一个电机型号，或者永磁体退磁了），你原则上需要重新跑优化。

### 计算代价

分数阶在离散域的实现路线有多种：RL/GL 有限记忆卷积、Oustaloup 近似、连分数展开（CFE）等。参考文献\[3\] 的内容转攻 "discretized RL-fractional integral"，即采用 RL 离散实现；Oustaloup 和 CFE 是工程上常见的替代路线，但不应把它们直接等同于 \[3\] 的实现方式。

不同离散路线的计算量差异很大。RL 有限记忆卷积需要存储历史误差并按幂律加权累加，记忆长度直接决定计算量；Oustaloup 近似通常需要 5~7 阶滤波器级联。无论哪种路线，计算量都显著高于经典 PI，且具体开销需按实际实现方式和 MCU 条件做 cycle count 实测。

## 5\. 路线三：神经网络 RBF-MRAS——潜力最大，门槛最高

参考文献 \[4\] 的做法是**完全替代**：不用 PI 了，直接把误差送进 RBF（径向基函数）神经网络，网络输出就是转速估计值 。

网络结构很简单：

-   • **输入层**：1 个节点，输入 q 轴电流误差 
    
-   • **隐含层**：若干个神经元，激活函数为高斯径向基函数
    
-   • **输出层**：1 个节点，输出 
    

### 为什么只用一个输入？

参考文献\[4\] 选  作为唯一输入，我猜测原因之一是因为若按 SPMSM 假设（），q 轴电流直接对应转矩/转速动态；d 轴误差主要对应磁链方向，对转速的灵敏度较低。但 \[4\] 未明确电机类型，若为 IPMSM（），d 轴和 q 轴的耦合更强，单输入设计可能丢失关键信息。

### 黑箱问题

这是神经网络 MRAS 最致命的工程障碍。

经典 PI 的自适应律有解析形式，在满足经典 MRAS 模型假设和 Popov 条件时，可用 Popov 框架构造稳定性证明——你能数学上说明"在这些前提满足时，系统可收敛"。但 [第43讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486846&idx=1&sn=20da599fedfdf713b37f80bcc908d0b2&scene=21#wechat_redirect) 已经提醒过，离散实现、噪声和参数边界仍需校核。

参考文献\[4\] 全文没有提供可直接用于闭环稳定性验收的 Lyapunov 或 Popov 证明。网络权值是通过梯度下降或误差反向传播在线（或离线）训练的，训练目标是最小化模型输出误差，而不是保证闭环稳定。**训练收敛 ≠ 闭环稳定。**

更麻烦的是泛化能力。\[4\] 是纯仿真验证，训练数据覆盖的工况有限。如果电机跑到训练数据没覆盖过的转速、负载组合，网络可能输出完全离谱的 ，而你没有解析工具来预测这种情况什么时候发生。

### 计算代价

RBF 网络的计算开销主要来自两部分：

1.  1. **前向传播**：每个隐含层神经元需要计算高斯函数 ，涉及一次向量距离计算和一次指数运算。指数在 MCU 上通常用 `expf()` 库函数，开销显著高于乘加指令。
    
2.  2. **权值更新**（若在线训练）：需要计算梯度、更新权值矩阵，额外增加大量指令和存储访问。
    

若采用在线 RBF，其 `expf()` 调用、权值更新和存储需求会显著高于 PI；具体开销需由网络规模、神经元数量和实现方式实测决定。

## 6\. 第四种路线：不碰 MRAS 内部，包在外面

讲到这里，必须插入一个容易被忽略的视角：

**改进不一定发生在 MRAS 内部。**

参考文献\[1\] 的完整架构是：HOT-STA-SMC 用于速度环、ERL-SMC 用于电流环、MRAS 观测器本身仍保持经典 PI 自适应律。这个组合在四种先进方法的横向对比中展现出最优的综合性能（估计效率 92%，对比方法 60%~80%）。

这意味着什么？

MRAS 的观测精度很大程度上取决于速度环和电流环的控制品质。如果速度环的 PI 控制器在负载突变时产生大的速度超调，MRAS 看到的电流和电压信号就会包含更多瞬态噪声，自适应律的收敛环境就会变差。反之，如果速度环用 HOT-STA-SMC 实现了 ±0.2 rpm 的稳态精度和 0.5 ms 的恢复时间，MRAS 工作在一个"更干净"的工况里，固定增益的 PI 自适应律也能表现得很好。

所以，"改进 MRAS"有两条路：

1.  1. **改 MRAS 内部**：换掉自适应律（模糊、分数阶、神经网络）
    
2.  2. **改 MRAS 外部**：用更高级的速度/电流控制器把 MRAS 包在里面，让它工作在更优的工况
    

参考文献\[1\] 走的是第二条路，而且在它自己的仿真对比集合中表现最好（估计效率 92%，对比方法 60%~80%）。但不能据此推出它普遍优于多数内部改进方案——毕竟 参考文献\[1\] 没有和 \[2\]/\[3\]/\[4\] 在同一电机、同一工况下直接对比。这是选型时不能忽略的事实。

### 选型 Checklist

面对具体项目时，按以下顺序问自己：

**第一步：看 MCU 天花板**

-   • STM32F1/G0 级别（72 MHz，无 FPU）→ **优先经典 PI**。模糊切换 PI 的查表和条件判断通常也能跑，但分数阶和神经网络需要谨慎评估实时裕量。
    
-   • STM32F4/H7 级别（168~480 MHz，带 FPU）→ 经典 PI 或模糊切换 PI。分数阶需要评估实时裕量。
    
-   • DSP/C2000 或更高级 → 三种内部改进路线都可以考虑。
    

**第二步：看参数漂移范围**

-   •  温漂 < 20%、磁链基本不变 → 经典 PI 够用。
    
-   •  温漂 20%~50%、磁链缓慢退磁 → 考虑模糊切换 PI 或 M-001 式的外部高级控制器。
    
-   • 参数剧烈变化（电感饱和 > 30%、宽温域 -40°C~+125°C）→ **优先考虑**在线参数辨识 + MRAS（[第45讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486860&idx=1&sn=cb9d19001b04a692df665f4d9d94b6b4&scene=21#wechat_redirect) 的双辨识思路）或改用 SMO；分数阶可在参数变化相对温和、但需要优化动态/稳态权衡时作为备选。
    

**第三步：看团队能力**

-   • 没有自动优化工具链 → 不要用分数阶（PSO 离线整定需要 MATLAB + FOMCON 或自己写优化脚本）。
    
-   • 没有神经网络训练经验 → 不要用 RBF-MRAS。
    
-   • 想尽快出产品 → 经典 PI 或模糊切换 PI。
    

**第四步：看稳定性验证要求**

-   • 需要做形式化稳定性分析（汽车功能安全、航空）→ **经典 PI** 在满足模型假设和 Popov 条件时可构造稳定性证明；**模糊切换 PI** 需为每组增益分别验证 Popov 条件，若面向形式化审查，通常还要检查切换逻辑是否具备共同 Lyapunov 函数、迟滞或 dwell time 等条件。分数阶需要扩展分析；**神经网络 MRAS** 形式化审查难度高，通常需要额外稳定性论证和测试覆盖。
    

## 8\. 结尾：不要为了先进而上先进

写这一篇的时候，我一直在想一个问题：**为什么在工业界和开源社区中，一旦决定用 MRAS，工程师几乎总是选经典 PI 自适应律？**

不是因为工程师们不知道有模糊、分数阶、神经网络这些东西。而是因为经典 PI 在大多数工况下足够好，而且它的"好"在满足模型假设和 Popov 条件时可以被数学证明、被调试器验证、被同行复现。

改进自适应律的论文每年都有几十篇，但产线上的 MRAS，大多数还是 。

这不是保守，这是工程判断。

一个调好的经典 PI，在正常的速域和参数范围内，不会输给一个没调好的神经网络。升级之前，先确认你真的碰到了 PI 的天花板——而不是自己的天花板。
