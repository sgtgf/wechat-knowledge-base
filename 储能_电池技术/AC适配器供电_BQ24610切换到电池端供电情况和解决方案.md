# 背景：

  

我们有个设备设计是带电池供电功能的，当AC适配器不在位时。系统自动切换到电池供电，当电池在位时通过BQ24610给电池充电同时给系统供电，类似于笔记本的电源场景。在设备老化测试的过程中发现，如果不带电池一起老化测试的话，系统间歇性偶发自动掉电关机的情况，重启又能工作。  

  

排查了板卡情况，发现没有硬件损坏的情况，根据现象初步怀疑是电源管理路径出现了问题，因此就把充电管理电路作为重点怀疑对象，下图为BQ24610部分的原理图(抹去了无关问题分析的部分细节信息。)。  

  

![](D:\电脑文件\公众号知识库\储能_电池技术\AC适配器供电_BQ24610切换到电池端供电情况和解决方案_images\img_001_35c02006b187.png)

  

发现只有软件打开时（软件打开时 MCU会控制BQ24610给电池充电的电流的大小），SRN引脚（充电电流检测电阻负端）电压才会升高，根据示波器波形发现当CS拉低时，SRN(BAT)会被拉高，当CS为低时，SRN(BAT)会降低。下图紫色为BAT使能信号CS，当CS为高时，BAT电压为低电压；当CS信号被拉低后，BAT电压开始充电 更多资料关注@电路一点通

# 现象分析：

  

**1、 当CS为高时，BAT电压为低**

测得HIDRV为1VDC，PH为1VDC，LODRV为0VDC，Q7不导通，输出为1V左右，VFB为125mV，VFB<VLOWV，VFB>VRECH，检测到电池不在位。

  

2、**当CS为低时，BAT电压为高**

如下图所示，测试发现当CS关断时，BAT会被充电到15V6DC左右，怀疑是感应电通过寄生电容进行充电导致。

  

![](D:\电脑文件\公众号知识库\储能_电池技术\AC适配器供电_BQ24610切换到电池端供电情况和解决方案_images\img_003_e84b60018e88.jpg)

  

在电池端增加一个20K电阻，负载电流约为0.78mA，测试发现BAT电源无法提供这么大的电流，如下图所示，当CS为低时，感应电没有产生。  

  

# 结论：

1、BQ24610RGET充电端不使能情况下会产生感应电，导致在特殊条件下切换电池。

2、导致系统掉电原因为ACN-SRN < 200mV，如下图所示为掉电切换波形。

  

![](D:\电脑文件\公众号知识库\储能_电池技术\AC适配器供电_BQ24610切换到电池端供电情况和解决方案_images\img_004_8dcfdd35b5f1.png)

  

# 解决办法：

1、调节分压电阻比例，增加负载电流；

2、修改MCU固件，CS始终使能。

  

**解决方案对比刨析：**

**a.调节电阻比例，增加负载电流>0.78mA**

好处：1.简单可靠。

  

坏处：

1.对于机器上时间存储及运输不利，会带来额外的电池电量消耗。

2.需要修改BOM，对于发货机器无法进行整改。

**b.修改后端板MCU固件，让充电使能信号一直有效，仅通过控制充DAC输出来控制是否充电。  
**

好处：1.纯软件方案，实施成本较低，不会带来电池额外电量消耗。

坏处：无。

  

综合评估使用方案b.
