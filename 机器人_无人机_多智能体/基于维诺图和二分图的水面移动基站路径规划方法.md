# 基于维诺图和二分图的水面移动基站路径规划方法

原创 自动化学报 2016-08-30 16:38 北京

> 原文地址: [https://mp.weixin.qq.com/s/haJDR7RF5OxjE6LxJEmznQ](https://mp.weixin.qq.com/s/haJDR7RF5OxjE6LxJEmznQ)

水面传感器网络(Surface Sensor Networks, SSNs)是由部署在水面环境中的多个浮标式传感器节点组成的无线传感器网络。该网络中的节点配以多种传感器采集水面或水下信息，并通过无线射频通信进行数据传输和汇聚，可用于海洋、河流、湖泊等环境的监测，具有重要的应用价值。

图1示出了水面传感器网络的组成。其中水面传感器节点SSN (Surface Sensor Node)负责采集水面或水下信息，并采用射频通信进行数据传输；移动基站MS (Mobile Sink)完成对整个网络中SSN数据的收集。与节点密集布置的陆地传感器网络相比，水面传感器网络通常具有节点稀疏布置的特点，即节点间距离大于节点通信半径，因此难以通过节点间的多跳路由汇聚数据，而采用移动基站MS历经各个SSN收集数据成为目前主要的数据汇聚方法。如何在监测水域中规划出一条基站移动路径，在完整收集所有传感器节点数据的基础上，达到路径长度短、能量效率高以及节点能耗均衡成为一个关键问题。

近年来，一些学者提出了多种基站移动方法。按移动基站数量不同，这些方法可以分为单基站移动方法和多基站移动方法两类；按数据收集方式不同，可分为“节点单跳通信下的基站移动方法”和“节点多跳路由下的基站移动方法”两类。

在节点稀疏布置的水面传感器网络中，由于节点之间通常无法直接通信，难以建立节点间的数据传输和路由，因此节点多跳路由下的基站移动方法在实际的水面传感器网络中难以实用。

在节点单跳通信下的基站移动方法中，传感器节点以单跳方式将数据发送给移动基站，不需要通过其它节点转发，因此能够有效减少网络中节点的能耗，且易于实现，这一点值得肯定。但在此类方法中，基站一般是随机移动的，其移动的盲目性使得数据收集的完整性无法得到保障，也使得完成数据收集所需的路径长度和耗时不可预期。即使不是随机移动，依次访问每个节点仍会造成路径较长且效率较低。

因此，本文重点研究节点单跳通信下的基站移动方法，提出一种基于维诺图和二分图的水面移动基站路径规划方法。首先利用维诺图理论生成数据收集候选点，然后以二分图和支配集理论求解出可以收集网络中所有节点数据的最小候选点集合，并依此形成最优路径。仿真实验结果证明了该方法具有生成路径短，有助于降低网络总能耗和平衡节点间能耗负载等优点。

本文研究了水面传感器网络中水面移动基站路径规划问题，提出了一种基于维诺图和二分图的路径规划方法。该方法首先利用维诺图理论在水面传感器网络区域生成一系列维诺图顶点，作为数据收集候选点；然后以二分图描述维诺图顶点对传感器节点的支配关系，并通过提出的理论和方法求解出最小有效支配集；最后针对最小有效支配集形成优化路径。图2示出了本文方法核心思想及其功能和优点的逻辑框图。
