# 一、什么是稳压器？

**稳压器**是一种用于**将输入端的波动电压改变为输出端定义的稳定电压**的设备。电压调节器可以是机械的、电动的、交流的或直流的，这里主要是关于**直流电子线性稳压器**。

# 二、稳压器的应用

**大多数电路需要独立于消耗电流的恒定电源电压**，因为即使是很小的过电压也可能具有破坏性。稳压器也有**助于消除音频放大器中的电源噪音**。在信号发生器和振荡器中，输出频率奖随电源电压而变化，还必须进行良好调节以保持此恒定。

# 三、稳压器的类型

稳压器主要分为三类或类型：**输入电压为正的正调节器**、**输入电压为负的负调节器**、**双电压调节器**，是两者的集合。例如运算放大器电路，最后是可调的**稳压器**，可能是上面3种的任意一种，就是有一个控制旋钮可以根据需要改变输出电压。

简单的齐纳稳压器

在上面的简单稳压器中，Vin 为 12V，Vout 为 5V，I 为 10mA。

**如果没有齐纳 R1，则 R=V/I = 12-5/0.01 = 700Ω。**

但是齐纳二极管不会导通。根据经验，齐纳二极管需要传导两到五倍的负载电流，比如 50mA。鉴于此，它应该是 I = 50 + 10 = 60mA，所以 R1 = 7/0.06 = 116Ω。

然而，问题是大负载电流时 R1 和 D1 中的功耗会过大。但这是一个非常适合将信号电平转换为 5V 到 3.3V 模块的电路。

**3、固定稳压器**

在电路中，有固定电压三端稳压器。M78xx系列稳压器 IC具有多种不同的电压。比如LM7812输出12V，LM7809输出9V，LM7805输出5V。

![](D:\电脑文件\公众号知识库\电工_教育_学习\如何构建稳压器(实际电路案例)_images\img_007_2ea969ac402c.jpg)

固定稳压器

不要将 C4 和 C10 与平滑电容混淆，它们用于噪声和稳定性，并且应该是低 ESR（等效串联电阻）。**C4**通常为10uF，**C10**为1uF。请注意，**二极管 D9 用于对负载中的任何大电容进行反向放电，以防止稳压器在输入变低时反向偏置。**

**4、可调稳压器**

最后，用**可调式三端稳压器——著名的LM317 稳压器**。

![](D:\电脑文件\公众号知识库\电工_教育_学习\如何构建稳压器(实际电路案例)_images\img_008_2ca3a3c45791.jpg)

  

**C2** 用于噪声，可以是 1uF。R20 和 R23 的比率设置输出电压。它们可以是两个固定电阻或一个可调电位器。**R20** 在数据表中显示为非标准 240Ω，但如果将其设为标准 220Ω，则对于 V max和 V min 之间的任何电压， R7 = (176\* V out ) – 220。

所以如果你想要 9V，**R23** 可以是一个固定值，即 176\*9 – 220 = 1k4。不过要注意，由于内部参考电压为 1.25V（稳压器可以达到的最低电压），**因此输入和输出之间至少需要 2V，并且最大电压为 32V**，因此它可以提供 1.2V 至 30V 的调整。使 R23 为 10k。

**稳压器消耗的功率为 (Vin-Vout)\* Iout**。因此，对于 1A 的 12V 输入和 5V 输出，功率为 (12-5)\*1 = 7W，这意味着稳压器在设置为最低输出电压时会消耗大部分功率。

如果要从调节器中取出超过1A的电流或太热而无法用手指握住，则需要一个**散热器**，也可以尝试将其安装在正在使用的铝盒的外壳上，或者安装在一块扁平铝材上，更好的是，安装在合适的散热器上。
