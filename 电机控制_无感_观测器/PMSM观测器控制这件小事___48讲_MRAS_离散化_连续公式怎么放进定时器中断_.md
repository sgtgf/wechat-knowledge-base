## 连续公式进了中断，为什么磁链开始"漂移"？

你读完了 [第41讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486835&idx=1&sn=d4af136833c5b8e10f19d77dbb0f46b4&scene=21#wechat_redirect) 到 [第47讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486888&idx=1&sn=9bb0ab5997c126ec3e9e89f164bcd098&scene=21#wechat_redirect)，公式都会了，心里大概已经能写出一套 MRAS 的 MATLAB 仿真用代码了。但当你打开 MCU 的定时器中断，准备把这套东西塞进去时，第一个问题就来了：

**连续域里的积分号 `∫`，在代码里怎么写？**

最直觉的想法：

`// 示意用代码   psi(k+1) = psi(k) + Ts * (u(k) - R * i(k));`

这就是前向 Euler——每个 PWM 周期做一次乘法、一次加法，快得连 72 MHz 的 STM32F1 都眨不了眼。你去跑中低速电机，10 kHz PWM、基波 200 Hz，载波比 C/F = 50，一切正常。电压模型算出来的磁链稳如老狗，自适应律调的转速和编码器读出来的差不了多少。

但你去跑高速电机——比如 20,000 r/min、4 极，基波频率 666.7 Hz，PWM 只开到 4 kHz——载波比 C/F 才 6。这时候你发现，电压模型算出来的磁链像喝醉了酒，越飘越远。自适应律拼了命地调转速，结果调出一个越来越离谱的数字。电机还没失控，但你的信心已经失控了。

问题不是自适应律的参数没调好。**是离散化的根没扎稳。**

连续域里那个漂亮的积分 `ψ = ∫(u-Ri)dt`，在数字控制器里变成了数值近似。近似得好不好，取决于你用什么方法、采样周期多大、信号频率多高。方法选错了，误差不会停留在"一点点不准"，它会通过电压模型的积分项逐周期累积，再被自适应律当成"模型不匹配"去修正——结果越修正越歪。

这不是自适应律的锅。**是离散化的误差被放大了。**

## 不同精度的尺子，量一个会"长高"的人

想象你要每隔五分钟量一次一个人的身高，用来判断他长得多快。你有三种工具：

**卷尺，最小刻度 1 厘米。** 量得快、看得清，但如果这个人其实只长了 2 毫米，你读出来的可能是"没变"或者"长了 1 厘米"。这就是**前向 Euler**——矩形法近似积分，一个周期内的曲线下面积被粗暴地当成以 `T_s` 为底、`u(k)-R·i(k)` 为高的矩形。T\_s 越大、信号频率越高，矩形和真实曲面的缝隙就越大。

**钢尺，最小刻度 1 毫米。** 用梯形代替矩形，面积算得更准，但你得多看几眼、多记几个数。这就是**Tustin**（双线性变换/梯形积分）——隐式差分，含上一时刻的状态，推导和实现都比 Euler 复杂。2012 年 Comanescu 对特定全阶时变观测器做了统计：Tustin 每周期约 163 次乘法、63 次加法，Euler 只要 14 次乘法和 12 次加法 \[D-005\]。**但这个"约 9 倍"的计算量统计针对的是状态向量为 `[i_α, i_β, e_α, e_β]^T` 的全阶观测器，MRAS 的电压模型积分项结构更简单，不能直接套用该数字。**

**激光测距仪。** 不近似，直接解析求解——假设这五分钟里"长高速度"不变，把积分算到底。这就是**ZOH 精确离散化**。2025 年一篇针对低载波比龙伯格观测器的论文推导了 SPMSM 的精确离散模型，显式包含了反电动势非齐次解引入的相位偏移和幅值缩放，实验表明在 C/F=12.27 时，精确离散化的位置观测误差仅为 Euler 离散（TLO）的 10.7% \[D-001\]。

**但这里有个陷阱**：量身高是一次性的，误差不会累积；MRAS 每周期都量，而且电压模型的积分项会把上一周期的偏差带进下一周期。离散化误差不是"脏了测量值"，而是**污染了测量值之后，还让污染后的结果继续参与下一轮的积分**——它是误差的放大器。

打个比方：你用卷尺量身高，第一次读高了 5 毫米。第二次量的时候，你不是从真实身高开始量，而是从"读高了的身高"开始量。再读高 5 毫米。第三次、第四次……几十次之后，你以为这个人长高了 5 厘米，其实他根本没长。MRAS 的自适应律看到的就是这个"虚高的身高差"，然后忠实地把它翻译成转速修正量——修正量也是虚的。

## 为什么电压模型是"放大器"，而电流模型不是？

模型参考自适应系统（MRAS, Model Reference Adaptive System）有两条路在跑：

**电压模型（参考模型）**：

它有一个**纯积分项**。离散化误差每周期漏一点面积，漏着漏着，磁链估计就偏离真实值了。而且这不是普通的累加误差——磁链是反电动势的积分，反电动势又是位置的微分。磁链歪了，自适应律算出来的角度和转速都会歪。

**电流模型（可调模型）**：

没有积分，只有代数运算和三角函数。离散化对它几乎没影响，因为 `i(k)` 和 `θ̂(k)` 都是当前采样点的值。你用 Euler 还是 Tustin，这里的 `ψ̂_adj` 基本一样——除非 `θ̂` 本身已经被电压模型的漂移带偏了。

所以误差 `e = ψ_ref - ψ_adj` 里，**ψ\_ref 的漂移是主要贡献**。自适应律看到的是一个"被污染的误差"，它不知道这是离散化造成的，只会忠实地把它翻译成转速修正量。于是转速估计也开始跑偏。

这就是为什么离散化问题不能靠"把自适应律调猛一点"来解决——自适应律消化的是**模型误差**（两个模型谁对谁错），不是**离散化误差**（数值积分本身漏了面积）。来源不同，药方也不同。

## 方法 1：前向 Euler——快，但粗糙

公式最直接：

`// 示意用代码   psi_ref_alpha += Ts * (u_alpha - Rs * i_alpha);   psi_ref_beta  += Ts * (u_beta  - Rs * i_beta);`

每个周期：2 次乘法、2 次加法、2 次减法（算 `u-Ri`）。在 20 kHz 控制频率下，这段代码的执行时间以微秒计，对 CPU 负载的贡献可以忽略不计。

**但 Euler 的隐患在于相位超前和幅值漂移。**

从 s 域到 z 域，Euler 的映射是 `s → (z-1)/T_s`。这相当于把连续域的极点沿着一条射线往左推。当信号频率升高、T\_s 相对变大时，离散化后的极点会偏离连续域的设计位置。IEEE Access 2021 年的一篇综述指出：Euler 在高速下极点明显左移至高度振荡区域 \[D-002\]；而在另一组实验中，**连续域设计的全阶观测器**在 f\_ratio=30（即 C/F=30）时也已经失稳 \[D-002\]。

**那是不是 C/F>30 就万事大吉？不一定。** 电压模型的积分项还有一个更隐蔽的问题：**直流偏置累积**。真实的电机电压测量总有微小的直流偏置（ADC 零点漂移、逆变器死区不对称），连续域里一个理想积分器会把这点偏置无限放大。所以工程上通常不会让理想积分器裸跑，常用准低通滤波器、SOGI、反馈校正或限幅等方式抑制漂移：

`// 准低通替代理想积分，抑制直流漂移   #define OMEGA_C 100.0f  // 截止角频率，rad/s      psi_ref_alpha += Ts * ((u_alpha - Rs * i_alpha) - OMEGA_C * psi_ref_alpha);   psi_ref_beta  += Ts * ((u_beta  - Rs * i_beta)  - OMEGA_C * psi_ref_beta);`

> 示意用代码。`OMEGA_C` 的选取需权衡低频增益损失与直流抑制强度，需按电机参数与工况实测整定。

这个改进不是离散化方法的升级，而是**积分器本身的工程化处理**。但即使加了准低通，Euler 的矩形近似误差依然存在——它只是不会无限发散了，该偏还是偏。

注意右边出现了 `u(k+1)` 和 `i(k+1)`——这是下一时刻的量，在当前周期还不知道。对于**纯积分项**`dψ/dt = u-Ri`，实时实现中可以直接用上一拍和当前拍的输入做梯形积分，不需要解代数方程。但如果是**全阶时变观测器**（状态矩阵含时变元素），Tustin 是隐式的，需要引入中间变量才能实时实现——Comanescu 的思路是引入一个中间状态 `w`，把隐式方程拆成两步：先递推更新 `w`，再用 `w` 还原 `ψ`，代价是每周期需要维护额外的状态变量 \[D-005\]。MRAS 的电压模型积分项属于前者，比全阶观测器简单得多。

**Tustin 的好处是精度显著优于 Euler。** 在同样的采样周期下，梯形法的 **单步（局部）** 近似误差为 `O(T_s³)`，Euler 为 `O(T_s²)`；其 **累积（全局）** 误差分别为 `O(T_s²)` 和 `O(T_s)`。当 T\_s 较大（即 C/F 较低）时，这个差距会被放大。

**坏处是计算量。** 如前所述，D-005 对特定全阶时变观测器的统计是 Tustin 约 9 倍于 Euler。MRAS 的电压模型积分项比全阶观测器简单，所以倍数不会这么高，但额外的中间变量、上一时刻状态存储、以及可能的矩阵运算，都会实打实地吃掉 CPU 周期。在 10 kHz 控制频率的 STM32F4 上可能还撑得住，但如果你的中断里还要跑 FOC、通信、保护逻辑，余量就会被压缩。

**一个折中做法**：只给电压模型的积分项上 Tustin，电流模型和自适应律保持 Euler。这样用最小的计算增量换取最关键的精度提升。

## 方法 3：ZOH 精确离散化——理论上最准，但有前提

2025年的参考文献\[D-001\]把这个思路用到了 SPMSM 的龙伯格观测器上 。他们假设一个采样周期内反电动势幅值不变（即转速不变），把反电动势视为标准正弦波，解析求解得到了精确离散模型。模型里有两个关键修正项：

1.  1. **相位偏移 `θ_y(k)`**：非齐次解（反电动势驱动项）与瞬时反电动势之间存在相位差，直接用 `arctan` 提取位置会引入误差。
    
2.  2. **幅值缩放 `A_ps(k)`**：离散化过程中反电动势的幅值会被一个与转速和采样周期相关的系数缩放。

**精确离散化的代价是计算复杂度。** 矩阵指数 `e^(A·T_s)` 的解析表达式通常包含三角函数和指数函数，每周期都要重新计算——如果 A 矩阵含时变元素（比如与转速 `ω_e` 相关），那就更重了。D-001 的实验平台是 DSP28335，论文未给出 ALO 相对于 TLO 的具体执行时间增量，但从公式复杂度判断，精确离散化的 CPU 负载显著高于 Euler 是确定无疑的。

**还有一个更打的限制**：D-001 的推导基于 SPMSM（Ld=Lq）。如果换成 IPMSM，α-β 轴之间存在交叉耦合（`L_d ≠ L_q`），A 矩阵变得更复杂，精确离散模型的推导会困难得多。这是工程上采用精确离散化时必须考虑的前提。

## 方法 4：混合离散化 HY——给 Euler 做加法，给 RK4 做减法

2026 年 Lin 等人提出了一种巧妙的折中方案 \[D-004\]：把系统拆成两部分，**线性/慢变部分用 Euler，非线性/快变部分用四阶 Runge-Kutta（RK4）**。

D-004 的 ADRC-ACRFO 系统包含外部驱动项和内部 ESO/PI 反馈补偿，作者观察到前者变化慢、后者变化快，因此提出 HY 拆分。MRAS 的电压模型本身虽是开环积分器（没有内部反馈补偿），但**整个 MRAS 系统**也可以借鉴这种"分区处理"思想——把对离散化敏感度不同的模块分开处理，贵的精度只花在值得花的地方。

具体到实现：

`// 线性部分：外部电压驱动，用 Euler   psi_linear += Ts * (u - R * i);      // 非线性部分：内部反馈校正，用 RK4   // RK4 需要在该步长内评估 4 次斜率   k1 = f_nonlinear(psi_current, omega_hat, e_alpha, e_beta);   k2 = f_nonlinear(psi_current + Ts/2 * k1, ...);   k3 = f_nonlinear(psi_current + Ts/2 * k2, ...);   k4 = f_nonlinear(psi_current + Ts * k3, ...);   psi_nonlinear += Ts/6 * (k1 + 2*k2 + 2*k3 + k4);      // 总状态更新   psi_total = psi_linear + psi_nonlinear;`

> 示意用代码，展示 HY 的分割思想。实际函数拆分方式取决于具体观测器结构。

## 工程判断：不要一开口就"上 Tustin"

离散化方法的选择，核心判据是**载波比 C/F = f\_PWM / f\_e**。你的电机基波频率越高、PWM 频率越低，这个比值越小，离散化误差的问题就越严重。

**C/F > 20**（如 10 kHz PWM、基波 < 500 Hz）：Euler 够用。D-004 实验显示 ACRFO + Euler 在 C/F≈17 时失稳 \[D-004\]，工程上通常取 **C/F > 20** 作为 Euler 的舒适区，留有一定安全裕度。电压模型通常不让裸积分器独自承担磁链估计，准低通滤波器、SOGI、反馈校正和限幅都是处理漂移的手段。不要为了追求"更精确"而上 Tustin——计算量不是免费的，那点精度提升在这个 C/F 下通常很难带来可感知的性能提升。

**C/F = 15~20**：Euler 开始吃力。电压模型积分项可以考虑后向 Euler（比前向 Euler 稳定一些）或 Tustin；自适应律和电流模型保持 Euler 就行，没必要全观测器都上高精度。后向 Euler 的映射是 `s → (z-1)/(z·T_s)`，其稳定性区域包含前向 Euler 的稳定性区域，对同一连续系统更不易因离散化而失稳（即"更保守"）。对于电压模型加准低通后的标量形式 `dψ/dt = (u-Ri) - ω_c·ψ`，后向 Euler 离散为 `ψ(k+1) = (ψ(k) + Ts·(u(k)-R·i(k))) / (1 + Ts·ω_c)`，比前向 Euler 多了一次除法，但计算增量很小。（严格的后向 Euler 应使用 u(k+1)，但实时系统中该值尚未采样，工程实现常以 u(k) 代替。）

**C/F < 15**（高速电机、大功率低开关频率场景）：必须升级。可**考虑混合离散化 HY**——线性部分 Euler、关键非线性部分 RK4，在计算量和精度之间取平衡，前提是你能清晰拆分 MRAS 的线性驱动项和快变状态更新项；C/F 在 10~15 之间可评估 Tustin，C/F 更低时优先 RK4/HY/ZOH 精确离散化，或直接采用离散域设计。如果 MCU 算力充裕（双核 DSP 或高主频 STM32H7），可以考虑 ZOH 精确离散化，但如果你的电机是 IPMSM，精确离散化的推导会很痛苦。

**一个常被忽略的点**：无论用什么离散化方法，**PWM 更新延迟**（一拍延迟）都会进一步恶化低 C/F 下的性能。D-001 在模型中引入了 `u(k-1)` 项来处理这个延迟 \[D-001\]。如果你的观测器模型只考虑了离散化方法，但没考虑"当前算出来的电压指令要到下一个周期才生效"，那精度还是会打折扣。这个延迟在 C/F<10 时尤其致命，因为它相当于额外引入了一个采样周期 Ts 的相位滞后（φ = 360° / C/F，C/F=10 时约 36°）。

## 三个常见误区

**误区一："自适应律有积分，能消化离散化误差。"**

错误。自适应律的积分消化的是**模型误差**（参考模型和可调模型之间的系统性偏差），不是**数值误差**（积分近似漏掉的面积）。离散化误差污染的是自适应律的输入，输入错了，输出只会跟着错。你把尺子读错了，根据读数修正的"长高速度"当然也是错的。

**误区二："所有观测器都用同一种离散化方法就够了。"**

MRAS 内部三个模块对离散化的敏感度完全不同：电压模型积分项最敏感，电流模型几乎不敏感，自适应律的敏感度介于两者之间。合理的做法是**分区处理**：最敏感的模块上高精度方法，其他模块保持低成本方法。

**误区三："Tustin 好，所以所有场景都该上 Tustin。"**

Tustin 的"好"是有代价的。D-005 的统计虽然是特定全阶观测器的结果，但它传递了一个明确信号：更精确的离散化意味着更高的计算开销。在 C/F>20 的场景下，Tustin 带来的精度提升在工程上不可感知，却实实在在地吃掉了 CPU 余量——余量被挤占后，万一哪天要加一个新的保护逻辑或通信协议，你会发现中断周期已经满了。在资源受限的嵌入式系统里，**够用就好**是一种美德。

离散化精度再高，也救不了参数失配。Rs 温漂了、L 饱和了，MRAS 的电流模型本身就会歪，这时候再精确的积分也算不出对的磁链。

参数鲁棒性的边界在哪里？经典 MRAS 和带在线辨识的 MRAS 差距有多大？这是我们明天要聊的事。
