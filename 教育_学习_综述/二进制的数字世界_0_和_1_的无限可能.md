**二进制：数字世界的基石**

  

进制，或者说进位制，是人们规定的一种计数的进位方法。对于任何一种进制——X 进制，就意味着某一位置上的数运算时是逢 X 进一位。例如，十进制是逢十进一，十六进制是逢十六进一，二进制就是逢二进一。生活中最常用的是十进制，而在计算机中则是以二进制的形式来存储数据的。**所有进制间都可以相互转换**，这也就是电信号存储数据的理论基础。

### 1\.  二进制

二进制的进位规则是“`逢二进一`”，所以在二进制中，只有 0 和 1 两个数码，这就对应了电路“通”和“断”的逻辑关系，0 和 1 也可以用来描述许多只有两种对立逻辑关系的事物，比如：开关的“开”和“关”，事件的“真”和“假”，线路电压的“高电平”和“低电平”等等。

十进制的进位规则是“`逢十进一`”，在十进制中，有 0 ~ 9 共十个数码，这是我们日常生活中普遍用的进制，数学里学的运算法则和定理公理，都是以十进制为基础的运算。这里就不作过多的阐述。

**文字信息的存储**

  

在计算机中，所有信息都是通过编码后再存储的，也就是说所有的数据最后都要转换成二进制的形式存储于计算机中。根据前面讲的进制转换，十进制的**数字**就是利用进制转换编码成二进制码，然后才被计算机识别和存储的。

由此可以推出，如果我们不满足只能存储十进制数字，还要存储**字母**、**符号**等等，那我们就需要用更多位的二进制数来代表字符或者符号，而这个过程就称作**编码**。将这些二进制还原成字符或者符号呈现给我们的过程称作**解码**。而计算机最通用的 **ASCII 码**就是利用 8 位二进制数来编码的，如下图，里面包含了 26 个字母的大小写，标点符号和一些特殊符号。


比如我们要查找小写字母 `a` 的 ASCII 编码，由上图得到低 4 位是 0001，高 3 位是 110，合起来就是二进制数 110 0001，转换成十进制数就是 97，所以 `a` 的 ASCII 编码数为 97。

这里用 MATLAB 中的 char 函数检验：

 \>> char(97)  
   
 ans =  
   
     'a'

还可以看出，一个字节的内存就可以完成 ASCII 表的编码。

> **字节(Byte)**是计算机信息技术用于计量存储容量和传输容量的一种计量单位，1 个字节等于 8 位二进制。
> 
> 1 Byte = 8 bit
> 
> 1 KB = 1024 Byte
> 
> 1 MB = 1024 KB
> 
> 1 GB = 1024 MB
> 
> 1 TB = 1024 GB

然而，仅仅存储一些英文字母和符号还是不能满足我们，还有中文和其他语言的字符呢？那就多用几个字节来存储，于是就有了后面的 **GBK 编码**和 **Unicode 编码**等更强大的编码标准。

**图片信息的存储**

  

既然我们已经知道了用二进制去表示所有进制的数字，利用编码去表示字符，那我们怎么使计算机利用编码来存储图片呢？我们继续利用 MATLAB 来分析两种类型的图片：灰度图和彩色图。

### 灰度图

灰度图是黑白或不同深浅级别的图像，它们通常用于科学计算和图像处理领域。灰度图像的每个像素值表示该点的灰度级别，通常量化为 256 个灰度级，范围从 0（纯黑）到 255（纯白）。在 MATLAB 中，我们可以将上面的彩色图片转换为灰度图进行分析：

 \>> img = imread('dog.jpg');   
 gray = rgb2gray(img);  
 imshow(gray)

生成图片为：


我们输入 `whos` 指令查看上面的数据，结果为：

 \>> whos  
   Name         Size                   Bytes  Class    Attributes  
   
   gray      2026x3840               7779840  uint8                
   img       2026x3840x3            23339520  uint8

分析上面的图片数据，我们知道了灰度图数据 `gray` 是一个 2026x3840 的二维数组，数据类型为 8 位无符号整型，对应了 256 个灰度级。正是这些数据完整地记录了灰度图片的全部特性。

### 彩色图

继续分析上面的图片数据，我们发现彩色图数据 `img` 是一个三维数组，它的前两个维度与灰度图数据是一样的，而第三个维度的值为 `3`。这是因为彩色图包含了三个颜色通道：红色（R）、绿色（G）和蓝色（B）。每个像素点在这三个颜色通道上都有不同的值，范围也是 0 至 255。通过组合这三个颜色通道的不同强度值，可以产生超过 1600 万种颜色。同样地，我们可以通过 MATLAB 来提取并显示这些颜色通道：

 \>> img = imread('dog.jpg');   
 % 红色图层  
 red = img;  
 red(:,:,2:3) = 0;       %其他色层赋值为0  
 figure  
 imshow(red)  
 % 绿色图层  
 green = img;  
 green(:,:,1) = 0;       %其他色层赋值为0  
 green(:,:,3) = 0;       %其他色层赋值为0  
 figure  
 imshow(green)  
 % 蓝色图层  
 blue = img;  
 blue(:,:,1:2) = 0;      %其他色层赋值为0  
 figure  
 imshow(blue)

**音频信息的存储**

  

音频文件的存储原理与图像类似，但它是基于声音波形的数字化表示。数字信号通常是通过对模拟声音信号进行采样和量化而得到的。采样频率决定了每秒采集多少个样本点，而量化位数决定了每个样本点的精度。

利用 MATLAB，我们同样可以读取音频文件，并绘制出音频波形图：

 \[y Fs\] = audioread('melancholy.mp3');  
 plot(1:size(y),y)

其中，`Fs` 为采样频率；`y` 为输出的音频数字信号，默认是 n 行 2 列的二维数组，其中 2 表示这个音频信号是两个声道的，n 的值等于该音频信号的时长乘以采样频率 `Fs`。
