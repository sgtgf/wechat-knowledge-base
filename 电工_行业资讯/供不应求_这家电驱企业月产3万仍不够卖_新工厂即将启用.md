# 供不应求！这家电驱企业月产3万仍不够卖，新工厂即将启用

原创 月酱 电机新视界 2024-10-16 16:58 上海

> 原文地址: [https://mp.weixin.qq.com/s/QslOW21hBb5WlVHsMbRsXw](https://mp.weixin.qq.com/s/QslOW21hBb5WlVHsMbRsXw)

![](https://mmbiz.qpic.cn/mmbiz_jpg/vibkgHlPVq0tlGYYnI1X80vmnTNfpxZp6PUCYWiabBhoxXQLVibuapnxsuKtetMicy8ia6GjfxZg1hDpIodPkWSMeHQ/640?wx_fmt=jpeg&from=appmsg)


  

10月14日最新消息显示，重庆青山工业有限责任公司正紧锣密鼓筹备其电控三线建设项目，预计将于下个月正式投产，旨在强化第四季度产能的快速提升。据悉，青山工业的三工厂已全面激活自动化生产线体系，涵盖2条电控生产线及1条PCBA生产线，全力应对市场需求。

![](https://mmbiz.qpic.cn/mmbiz_jpg/levg2oh00bYJylCBNTNQtaoxxq3QZHib4HCJKCOkYQPXbeuoicQKGN13O4T3IZxZZxUqVw7yibjq2tWuAictxgltaQ/640?wx_fmt=jpeg&from=appmsg)

当前，青山工业的EDS3、EDS2及双电控产品订单量持续上扬，公司正朝着10月底前达成3万台产能目标稳步前进。作为成立于1965年的资深企业，重庆青山工业专注于汽车变速器的研发、制造与销售，现已具备年产300万台各类变速器的强大生产能力，累计产销量已突破2800万台大关。其产品广泛应用于轿车、SUV、MPV、轻卡及微客等多种车型，并与长安、上汽、一汽、东风、海马、奇瑞、江淮等知名企业建立了长期合作关系。
