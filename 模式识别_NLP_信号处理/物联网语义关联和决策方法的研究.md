# 物联网语义关联和决策方法的研究

原创 自动化学报 2016-12-06 15:58 北京

> 原文地址: [https://mp.weixin.qq.com/s/J1Uk5xZ3JtidHB3eIzNwRQ](https://mp.weixin.qq.com/s/J1Uk5xZ3JtidHB3eIzNwRQ)

随着物联网应用的不断发展，物联网系统规模的日益庞大，不同系统间的关系也越来越复杂。大量的智能设备产生了海量的、多源的、异构的感知数据，形成数据孤岛，这些数据给系统内和系统间的资源交互、数据关联和推理等带来了极大的困难。

针对以上问题，日益成熟的语义 web 技术提供了新的解决思路。目前已有许多机构和学者基于传感器网络或物联网系统的具体应用构建适合的本体模型，从而屏蔽多源感知数据的语义异构性，实现各种智能设备的互操作。最著名的是 W3C 的语义传感器网络孵化群开发的一个语义传感器网络本体 SSN(Semantic Sensor Net)，它采用了一个高层模型来表示传感器设备、能力、观测和采集数据等内容。不过 SSN 本体对感知设备、观察和测量数据及平台方面的描述并不能直接扩展到物联网领域的具体组件的描述中。这是由于物联网系统远比无线传感器系统复杂的多。首先物联网系统往往跨多个应用领域，拥有更多的智能设备，这些设备中除了大量的传感器之外，还有 RFID 、智能仪器、智能家电、智能机械等多种情况。其次物联网是一个高度动态的环境，每时每刻都有新的节点加入或者原有节点离开, 随时会有新的不可预知的数据格式或者协议需要被系统支持和处理。最后，物联网系统还是一个高度受限的网络，除了像传统的无线传感器网络一样受到时空等限制之外， 智能设备本身对系统的限制更加多样化、复杂化。因此, 物联网系统的复杂性给物联网系统的语义建模带来了更多的挑战。同时，仅仅为物联网系统增加语义信息并不能完全解决各种智能物体间复杂的交互方式、行为预测、智能响应等诸多问题。 

为了实现异构物联网系统间的语义一致性和消除数据孤岛，本文采用语义建模的方法构建了一种基于环境—资源—行为的领域本体模型，实现了高度受限的行为和资源的语义描述。基于关联数据方法构建以行为关联模型和资源关联模型为核心的物联网语义关联网络。并设计了基于多事件触发机制的物联网推理决策模型， 实现智能决策。该模型从四个方面入手来设计推理算法：既定事件推理、有期望的非既定事件推理、无期望的突发事件推理和多事件联合推理。最后，构建了一个智能家居原型系统，通过两个具体的实例测试所提算法的可行性，并进行算法分析和比较，验证本文所提方法的优越性。图1是智能家居原型系统的部分本体图；图2是智能家居原型系统的数据关联模型。
