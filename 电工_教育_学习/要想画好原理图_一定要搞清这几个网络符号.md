# 要想画好原理图，一定要搞清这几个网络符号

在电路原理图或PCB上

你可能会碰见过这些电源的标号

VCC、VDD、VEE、VSS

![](https://mmbiz.qpic.cn/mmbiz_png/NMBmZoISq1L8WeQAYGrxmS9L2qsWLK6yjAkyKrtVajF8YCKbagkMZUpe0DTiayABLEbqkqOU4m3abrmq5g22Whg/640?wx_fmt=jpeg&wxfrom=5&wx_lazy=1&wx_co=1)

它们到底有什么区别？

表示什么意思？

下面我们一起来了解一下

![](https://mmbiz.qpic.cn/mmbiz_png/NMBmZoISq1L8WeQAYGrxmS9L2qsWLK6yW9ppgsQLS9ia5Btic5ou8Vn2jbjSricicBlzxA94kTZwHPxmqKQoFgsu7Q/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1)

简单说来，可以这样理解：

VCC：C=circuit 表示电路的意思

即接入电路的电压

  

VDD：D=device 表示器件的意思

即器件内部的工作电压

  

VSS：S=series 表示公共连接的意思

通常指电路公共接地端电压

  

VEE：负电压供电

  

VPP：编程/擦除电压

  

对于数字电路来说

VCC是电路的供电电压

VDD是芯片的工作电压(通常Vcc>Vdd)

VSS是接地点

  

有些IC既有VDD引脚又有VCC引脚

说明这种器件自身带有电压转换功能

  

在场效应管(或COMS器件)中

VDD为漏极，VSS为源极

VDD和VSS指的是元件引脚

而不表示供电电压

  

![](https://mmbiz.qpic.cn/mmbiz_png/NMBmZoISq1L8WeQAYGrxmS9L2qsWLK6yFrKpKozcw5fyOYvXUmMC5pEeKttxXdz1AudkbIAboGNkhgBSTSdKNg/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1)

VPP：编程/擦除电压

VEE：负电压供电;场效应管的源极(S)

VSS:地或电源负极

VCC：电源电压(双极器件)

VDD:电源电压(单极器件)

漏极电压(场效应管)

  

  

![](https://mmbiz.qpic.cn/mmbiz_png/NMBmZoISq1L8WeQAYGrxmS9L2qsWLK6ySGO2iaNM3NqsdvdBhhNSdgLRDER8uQ3jp3rR2MHtqsX4I6kWzG5TnQg/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1)

通常VCC和VDD为电源正

而VEE和VSS为电源负或者地

  

VSS表示连接到场效应管的源极(S)的电源

  

VDD表示连接到场效应管的漏极(D)的电源

  

VEE表示连接到三极管发射极(E)的电源

  

VCC表示连接到三极管集电极(C)的电源

它们是这样得名的：

VCC、VDD、VEE、VSS是指芯片、分解电路的电源集结点

详细接电源的极性需视器件材料而定

 VCC一般是指直接连接到集成或分解电路内部的三极管C极

VEE是指连接到集成

或分解电路内部三极管的E极

 同样，VDD、VSS就是指连接到集成内部、分解电路的场效应管的D和S极

例如是采用P沟E/DMOS工艺制成的集成

那么它的VDD就应接电源的负

而VSS应接正电源

  

![](https://mmbiz.qpic.cn/mmbiz_png/NMBmZoISq1L8WeQAYGrxmS9L2qsWLK6ymwhtRvzLiaM3HuuruLcJjjgfqs5U68yCEOcVodhnQQ0w3D2Yp18mapA/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1)

Vcc和Vee出现在双极型晶体管电路中

和集电极(collector)发射极(emitter)有关

所以一正一负。

Vdd,Vss在MOS电路中出现，

和漏级(Drain)，源极(Source)有关，

也是一正一负。

![](https://mmbiz.qpic.cn/mmbiz_png/NMBmZoISq1JnMhoPTCKeXfJeGX656mUKe128zlD4sSr1RS4iboXqplIicYrjDAyjzQxOibRZsY4sPUgPU1icfk1M2Q/640?wx_fmt=jpeg&wxfrom=5&wx_lazy=1&wx_co=1)

Vcc和Vdd是器件的电源端

Vcc是双极器件的正

Vdd多半是单级器件的正(例如：二极管)

下标可以理解为NPN晶体管的集电极C、

和PMOS or NMOS场效应管的漏极D

同样你可在电路图中看见Vee和Vss含义一样

因为主流芯片结构是硅NPN所以Vcc通常是正

如果用PNP结构Vcc就为负了

建议选用芯片时一定要看清电气参数

  

单片机中Vpp多数定义为编程电压，

有的资料上把Vddf为Flash供电的外部电压
