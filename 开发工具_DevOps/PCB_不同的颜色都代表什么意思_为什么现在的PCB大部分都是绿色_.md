# **一、PCB颜色代表什么意思？**

**PCB颜色**一般是指拿到一块PCB板时最直观看到的板子上的油色，**PCB表面的颜色**就是**阻焊剂的颜色**。PCB板染色颜料是一种硬化树脂，主体树脂是无色近透明的，绿色和其它颜色一样都是色粉的配色。

我们**通过丝网印刷将颜色印刷到 PCB 上**。PCB 颜色有绿色、黑色、蓝色、黄色、紫色、红色和棕色。还有一些厂家别出心裁地开发出了白色、粉色等多种颜色的PCB。

# **二、PCB颜色不同有区别吗？**

1、绿色PCB

**绿色 PCB** 是**最流行的颜色**。因此有很多人一直误以为 PCB 是绿色的或者说大部分是绿色的，绿色增加了**PCB 的清晰度**，因为绿色的 PCB 会与 白色 的文字产生鲜明的对比，从而**增强可读性**。

此外，绿色 PCB 表面处理会反射更少的光线，有助于减少眩光。

2、白色 PCB

**白色PCB** 在各种环境下**看起来干净利落**，越来越受欢迎。但由于白色PCB**容易隐藏走线，所以白色PCB仍不是首选**。但白色 PCB 在黑色丝网印刷中看起来对比特别明显。

3、黄色PCB

之前用**黄色 PCB** 比较多，但现在已经没有那么实用了。黄色PCB可以快速满足风格、清洁度和可见性等不同需求。黄色PCB有一个明显的缺点：**与走线和丝网印刷的对比度差**。

4、蓝色PCB

**蓝色 PCB** 被认为是用于标签的厚板，因为它提供了**显着的丝网印刷对比度**。这种PCB 颜色不像绿色 PCB、黑色 PCB或白色 PCB那样引人注目，但蓝色 PCB 是PCB 颜色的首选，因为它提供了极好的审美选择。蓝色 PCB 安装在 LCD 上是比较好的，因为蓝色 PCB 不会产生鲜明的对比边缘和明亮的背景颜色。

![](PCB_不同的颜色都代表什么意思_为什么现在的PCB大部分都是绿色__images/img_006_8d8d45a0dca8.jpg)

蓝色PCB

5、红色PCB

由于**红色 PCB**的一些优势，许多 PCB 制造商热衷于采用红色。红色PCB提供了**极佳的可视性**，并清楚地**定义了迹线**、**平面和空白区域的对比度**。丝印在红色PCB的映衬下显得非常漂亮。

![](PCB_不同的颜色都代表什么意思_为什么现在的PCB大部分都是绿色__images/img_007_126adb6df9f1.jpg)

红色PCB

6、黑色PCB

**黑色 PCB** 与白色 PCB 一样受欢迎。这两种PCB 颜色产生低对比度，可以**轻松标记重要组件**。但是，黑色PCB和白色PCB的主要缺点是特定细节可能**会聚光并有小阴影**。这个阴影使追踪变得困难。因此，在各种高温应用中不宜使用黑色PCB，因为黑色PCB可能会**使丝网印刷变色**。而且，黑色PCB板是钴和碳的混合物，**导电性可能会比较差。**

# **三、PCB颜色是由哪个工序完成？**

**不同的颜色不会影响PCB 的制造方式**。铜仍然放置在一侧或两侧，随着铜的添加或去除，PCB 变得光滑。PCB 上的铜层非常薄，这就是绿色如此突出的原因。

**薄铜层最终在焊接过程中被覆盖，以防止其氧化，阻焊层就是这样做的。**在许多情况下，它也是绿色的标准配置。在其他颜色中，铜不会清楚地显示出来，因此很难看到痕迹在哪里。

绘制完痕迹后，将组件放置到位。这些需要根据电路板图焊接到位。最后，在组件就位后，对电路板进行测试。如果可行，它们就会投入生产。

大多数印刷电路板需要由工程师设计，在投入生产之前需要制作原型。

# **四、为什么现在大部分PCB为绿色？**

这主要是因为**绿色阻焊工艺**最为成熟简单，绿色pcb板也比较环保。电路板的颜色除了绿色，还有白、黄、红、蓝、哑光，甚至还有菊花、紫、黑、亮绿等。白色之所以存在，是因为我们必须用它来制作灯具。

而使用其他pcb颜色主要是为了区分不同的产品样品。在公司的整个阶段，从研发到产品落地，取决于PCB的各种用途。**实验pcb板颜色可能为紫色，按键pcb颜色为红色，电脑内部pcb颜色为黑色。**

![](PCB_不同的颜色都代表什么意思_为什么现在的PCB大部分都是绿色__images/img_009_bd7f231479e4.jpg)

下面列出了几点选用绿色PCB的原因：

1、玻璃环氧树脂材料

**玻璃环氧树脂**是一种**用于制造电路板阻焊层的材料。**这种材料过去呈绿色，成为行业中所有装配工使用相同玻璃环氧树脂的标准颜色。后来玻璃环氧树脂也引入了一些颜色，但装配商总是考虑使用绿色。

2、绿色与白色印刷文字的对比

装配工经常发现**扫描绿色电路板既简单又省时**，因为他们已经习惯并且非常熟悉这种颜色。他们说扫描一些不同颜色的电路板需要很多时间。另一个原因是与其他颜色相比，绿色在扫描时对眼睛造成的压力较小。使用绿色是因为它还**与电路板布线上以白色打印的文本形成对比。**

3、在军事上用的比较多

**军事标准如何对电路板的绿色影响很大**。很多人认为绿色用于军事目的的电路板中非常有效。军方要求供应商提供绿色电路板，而这些供应商也向其他客户供货。这些电路板最终成为军方供应商的剩余产品。因此，不仅装配工、生产线工人或其他客户考虑绿色，军队也接受电路板的绿色。

4、阻焊层的暴露率

**电路板需要更高的焊接率，**也有其他颜色，但它们不能为电路板提供更高的阻焊层。那些具有深色的颜色，如蓝色、白色或棕色，具有高色素沉着，因此它们具有深色阻焊层。主要是白色和黑色阻焊层曝光率高。但是**绿色为工人的暴露率和设计中的高容忍度提供了深色阴影。**

5、绿色PCB机器识别性更好

一般来说，电子产品都要经过制板和元器件的贴片焊接。在黄色灯房中制作电路板有几个步骤。**PCB颜色为绿色时，在黄灯房视觉效果更好**。但这不是主要的。

焊接贴片时，必须通过在焊膏、贴片和背面的AOI上刷锡来检查。这些工序都需要光学定位和校准，**绿色PCB底色对仪器的识别效果更好。**

![](PCB_不同的颜色都代表什么意思_为什么现在的PCB大部分都是绿色__images/img_010_8acfff071ee3.jpg)

绿色PCB

6、绿色PCB会更舒适

部分检测过程靠工人观察（但现在大多用飞针检测代替人工），在强光下盯着板子看，**绿色pcb板对眼睛比较友好**。

7、绿色PCB可降低生产成本

由于绿色PCB具有广泛的用途，因此在生产和采购领域都可以使用绿色PCB。此外，在大批量生产时，可以使用同色涂料，降低生产线成本，因此绿色涂料的采购成本会低于其他成本。因此，**绿色是最常见的抗蚀剂，在制造成本和交货时间方面具有优势**。

8、绿色PCB相对环保。

**废旧板在高温回收时不会释放有毒气体。**其他PCB颜色，如蓝色和黑色，分别掺杂了钴和碳，因为它们的导电性较弱，存在短路的风险。

另外，像**黑灯、紫灯、蓝灯等，电路板颜色太深，会增加主板的检修难度**，工艺也不易控制。

以黑板为例，黑板最容易在生产工艺和原料配比上出现问题。稍有不慎就会造成明显色差，导致PCB不良率偏高。黑**色电路板的走线不易分辨，会增加后期维护调试的难度。**很多PCB厂都不太用黑色PCB。
