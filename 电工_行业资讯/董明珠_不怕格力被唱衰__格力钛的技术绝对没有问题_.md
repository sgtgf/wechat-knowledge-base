# 董明珠：不怕格力被唱衰，“格力钛的技术绝对没有问题”

“外界唱衰不要紧，关键要保证自己的身体是健康的。”6月30日，格力电器在珠海总部召开了2022年年度股东大会，格力电器董事长兼总裁董明珠回应了投资者对公司增长放缓、分红以及格力钛的发展等问题。她有自信，明年格力电器的现金分红能达到“每股派2元”的标准，也相信格力钛的技术，并且会尽快让格力钛成为能自己养活自己的公司。

  

![](https://mmbiz.qpic.cn/mmbiz_png/vibkgHlPVq0uqCy72Gg0ic85zxZws6HqgwbJIfC1IDrsO2SjfHVFwVpjcGSHP7WfiaoTCfXl7bveRjELBw9bCibriaw/640?wx_fmt=png)格力电器股东大会现场  来源：中国证券报记者 万宇 拍摄

计划“每股派2元”

  

“近期网上经常唱衰格力。”在格力电器的股东大会上，董明珠开门见山直面近期市场上对格力电器的讨论。她表示，外界唱衰格力电器不要紧，关键要保证自己的身体是健康的，“我不在乎外表，我们更在乎内涵。”

  

董明珠还表示，股东应该允许企业有调整期，应该给企业一个空间，没有理由要求企业每年都要以20%、30%的速度增长。她表示，格力电器近几年增长不快的原因，有疫情因素，同时互联网冲击实体经济，格力电器也要顾及线下几万家经销商门店的生存问题。

  

董明珠在股东大会上还回应了部分股东对分红减少的担心，“什么叫同舟共济、有福同享？格力坚持让股东受益的原则，让分红有可持续性，同时，也要让格力保留可持续发展的空间。”

  

自1996年上市至2022年，格力电器累计分红总金额超过1000亿元。格力电器2022年有两次分红，中期分红为每股派1元（含税），年度分红预案为每股派1元（含税），将实现年度累计分红2元/股。

  

董明珠透露，格力电器分红计划是2022年-2024年每年每股分红派现2元。她有自信，明年格力电器的现金分红能达到“每股派2元”的标准。

  

有投资者现场提问，降低分红比例是否意味着未来一两年有较大的资本投入？对此，董明珠表示，“大投资肯定有，但暂不能披露。”“我就是投资搞项目，这两块钱（分红）是不会变的。”

  

格力钛拉长格力电器产业链

  

作为格力电器布局新能源产业的重要一步棋，2021年，格力电器成功控股银隆新能源，随后，银隆新能源更名为格力钛新能源。

  

格力电器认为，公司与格力钛新能源在汽车工业产品、储能相关的电器产品、精密模具、新能源、再生资源等多个业务板块拥有协同空间。公司储能相关的电器产品可以借助格力钛新能源的电池及相关技术进行优化、提高产品竞争力；**公司可以利用格力钛新能源提高公司汽车工业产品在电机、控制器等汽车核心零部件行业的市场份额；此外，公司再生资源板块也可以与格力钛新能源电池材料回收形成合力、规模化发展，实现“1+1>2”的效果。**

  

但受原实控人涉嫌利益侵占等负面因素影响，格力钛新能源近年来业绩表现不佳，去年亏损幅度还有所扩大，有投资者现场提问格力钛新能源何时能有转机。

  

面对格力钛的亏损，董明珠仍然对格力钛的发展充满信心，她表示，格力钛的技术绝对没有问题。之所以收购格力钛，是希望借格力钛打开汽车空调的销售。“我当时举债都要赌这一局，就是为了把格力电器的产业链拉得更长。”她介绍，“如果当时不收购（格力钛），现在的光储空调也没办法实现。”格力电器在控股格力钛后，不仅推出了光储空调，还开始研究将储能技术应用到冰箱等其他产品上。

  

“这个坑太大了，我们尽快把（格力钛的）坑填平。”董明珠坦言，这还需要时间，但曙光就在面前。“尽可能以最快的速度让它（格力钛）成为能自己养活自己的公司。”
