# 低空经济报告：动力系统方案讨论，电机电控，飞行汽车动力核心，国内供应商稀


> 原文地址: [https://mp.weixin.qq.com/s/6ao\_OZoOASMffizzFHyiNw](https://mp.weixin.qq.com/s/6ao_OZoOASMffizzFHyiNw)

# 今天分享的是：《低空经济报告：动力系统方案讨论，电机电控，飞行汽车动力核心，国内供应商稀》。

# 内容出品方：申万宏源研究。

# 报告共计：35页

# 本报告指出，低空经济产业在政策支持下快速发展，eVTOL为主要产品形态，其电机电控系统是核心动力单元。不同构型的eVTOL采取的动力结构等存在差异，市场空间巨大，预计2030/2040/2050年全球eVTOL电机市场规模将达到42/357/1890亿元。

# eVTOL电机的进入壁垒高，包括材料、设计、政策和应用等方面，竞争格局较为集中，主机厂自研或与第三方合作。混合动力作为低空飞行的另一种解决方案，续航能力优势明显，但目前玩家较少，处于早期研发阶段。

# 报告分析了国内领先企业的产品及技术分析，包括小鹏汇天、亿航智能、沃飞长空、卧龙电驱、英搏尔、宗申动力和应流股份等公司。报告提示了政策效果、市场竞争和技术突破等风险。

# 核心观点如下： 政策支持：低空经济政策支持推动产业发展。

# 技术差异化：电机电控方案因构型不同而有所差异。 

# 市场潜力：eVTOL电机市场空间巨大。

# 高进入壁垒：性能要求严苛，研发验证周期长。

# 竞争格局：自研与第三方供应商共存，格局较为集中。

# 混合动力方案：提供续航优势，作为纯电的补充方案。
