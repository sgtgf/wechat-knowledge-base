# 共模电感应用不当导致电源接口打火现象

# 一、摘要

很多工程师都会使用共模电感用来滤波，但是估计很少人指导共模电感的双线并绕和分组绕法的区别。从而导致一些事故的发生。

# 二、问题描述

公司之前做过一个产品，产品最开始设计是应用在商业应用，后来销售开拓工业市场，在工业行业中，客户反馈我们的产品在电源输入端口这里偶尔会出现打火的现象，由于是阻燃性较高的应用，不允许出现任何的打火现象，客户要求我们整改。

**三、原因分析**

由于是行业转换带来的问题，因此我们研发重新拿我们的产品去做工业的EMC实验，商业原来的浪涌测试是通过1KV，更换到工业以后，我们要求通过2KV的实验，经过EMC实验室的实测，使用2KV的时候，确实会出现电源端口打火的现象，打火的位置主要是共模电感。  
后来经过咨询厂家，共模电感的绕法有两种，一种是双线并绕，另一种是分组绕线。两者之间的区别如下表：

**区别项目 双线并绕 分组绕法**

外观工艺区别 两根线重叠沿着磁芯并绕，工艺操作较为简单 两根绕组分开，各占磁芯一边沿着磁芯接近180°半绕，工艺操作相对复杂.漏感与分布电容区别：漏感较小，但两组之间的电容值较大，两组电感值差异较小；漏感较大，但两组之间的电容值较小，两组电感值差异较大

**滤波电路配置区别：**

建议采用“共模+差模”滤波方式 ，不适合共模+共模 滤波方式。采用“共模+共模”滤波方式，利用电感本身的漏感，可代替差模电感的功能。  
EMI传导、辐射区别 若采用“共模+差模”滤波方式，则不容易通过EMI，即使传导通过，辐射也很难通过，很难以兼顾；若采用“共模+共模”滤波方式，适当的调整圈数、电感、漏感、和绕线的手法，可以兼顾。

耐压性能 间距较小，耐压较低 间距较大，耐压较高

# **四、解决方案**

原因找到了：主要就是由于我们使用了双线并绕的共模电感，共模电感之间的间距较小，导致耐压较小，因此在浪涌测试过程中，因此了打火，后里在厂家的建议下，我们更换了分组绕法的共模电感，经过了严格的EMC测试，并且也没有重现打火的现象，客户拿我们的产品去做第三方认证，也顺利通过了测试。

# **五、总结**

共模电感的两种绕法是很多工程师容易忽略的问题，以为共模电感主要关注电感量、电流值就可以了，用作电源滤波 共模电感，经常放在电源的端口处，需要通过EMC的 ESD （静电）、 EFT（瞬态脉冲干扰）、DIP(电压跌落）、CS（传导抗干扰） 、RS（辐射抗干扰）、Surge（浪涌，雷击）、 PFM(工频磁场抗扰度）等测试，因此，在电源端口的共模电感，设计之初尽量考虑使用分组绕法的电感。

**Q1、Q2、D1和D2应力分析**

由于Q1和Q2同时导通，所以A、B两点电位近似于AGDN,D1和D2承受的反压大致等于母线电压。所以管子的电压应力不存在风险。但是电流应力会比较大，需要测量MOS电流应力，查器件资料，核算是否满足器件的单次不重复电流限值要求。

Vs=Vl105+Vl106
