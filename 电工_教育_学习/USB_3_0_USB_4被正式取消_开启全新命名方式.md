# USB 3.0/USB 4被正式取消，开启全新命名方式

但凡接触过电子产品的朋友，恐怕最熟悉的接口就是USB了。

  

USB是英文Universal Serial Bus（通用串行总线）的缩写，在USB接口诞生前，电脑上都是采用排针公母类型的串口、并口、圆口进行连接，速率慢而且占空间。

  

USB传输协议是于1994年由Compaq、DEC，IBM，Intel，Microsoft，NEC以及Nortel等多家公司联合提出研发和制定的，并于1994年11月11日公布了USB V0.7版本。后来这几家公司于1995年建立了一个推广和支援USB的非营利性组织，名为USB Implementers Forum，也就是我们熟悉的USB-IF，USB-IF也就是现在的USB标准化组织。

  

1996年USB1.0正式开始正式应用，传输速率为12Mbps，2000年USB2.0协议出台，传输速率大幅度提升至480Mbps，他们均采用D+D-（接口4个触点中间的那两个就是）触点进行数据传输，USB成为使用最广泛的接口一直沿用至今。

  

之前了解过USB命名规范的朋友应该都知道USB标准化组织“瞎改”USB接口的名字已经不是一次两次了。

  

比如早在USB还是2.0那会，USB标准化组织就曾把USB1.0的称呼改成USB2.0LowSpeed，USB1.1的称呼改成USB2.0FullSpeed。

  

同时USB 2.0则被改成了USB 2.0HighSpeed。

  

在USB 3.0时代，USB接口的命名开始出现前所未有的混乱，起初是USB 3.0、USB 3.1到USB 3.2这样的演进，后来又被集体更改为USB 3.2 GenX。

  

到了USB 4时代，小数点的命名意外消失。就在前不久，USB4 v2.0横空出世，再度让人摸不着头脑。

  

几乎每次有新的USB标准发布，USB标准化组织就会给老接口改个名字让它看起来像是新接口。

  

也许是决定痛定思痛，USB-IF组织现在做出两项重大决定，一是正式删除USB 3.x/USB 4的商用命名方式，二是取消SuperSpeed USB品牌。

  

现在，USB 3.X和USB4将变更为“USB+传输速度”的命名方式，即USB 5Gbps、USB 10Gbps、USB 20Gbps和USB 40Gbps。因为USB4 v2.0还处于草案阶段，所以没有获得正式命名，不出意外的话，它最终会叫作USB 80Gbps。

那么问题来了，USB 2.0呢？

  

USB-IF解释，因为USB 2.0的传输速度只有480Mbps，如果也同时变更为USB 480Mbps，后面的数字太大可能会误导部分用户，所以USB 2.0和USB 1.0继续保留。

  

按照USB-IF的想法，使用代际命名很容易出现混乱，不如直接标记出速度直观，新的命名规则将适用于接口、线缆、包装等各种印刷场景，如果是快充设备，还必须标记出最大功率。

这样看起来，的确更加直观了，可是先别高兴，更凌乱的事情在后面。

  

因为USB是开放标准，而非强制标准，所以如果厂商们愿意继续使用USB 3.x/3.2 GenX/USB 4甚至USB4 v2.0，依然不受限制...

  

目前的计划是，全新命名方式将在本季度开始陆续生效。
