# 遥控器背光照明延时控制电路

原创 电路一点通 2025-08-25 12:05 广东

> 原文地址: [https://mp.weixin.qq.com/s/3Ycvn-BqGyZT0GjjSPTBog](https://mp.weixin.qq.com/s/3Ycvn-BqGyZT0GjjSPTBog)

想通过红外发射管取信号。拆开看了下，红外发射管一端直接接地，另一端通过一个三极管接VCC。  
因为遥控器不带背光，晚上开遥控器的时候需要开灯才可以看清，所以想自己加个背光，用起来方便点。  
  

[![图片](D:\电脑文件\公众号知识库\电工_教育_学习\遥控器背光照明延时控制电路_images\img_000_fe8342348f8b.png)](https://mp.weixin.qq.com/s?__biz=MzU3MDU1Mzg2OQ==&mid=2247537957&idx=2&sn=6074857c7c862f7626b6ab35f157c9ff&scene=21#wechat_redirect)**👆查看更多目录👆**

要求是：  
1，供电为两个AA电池（3V）。  
2，待机低功耗。  
3，延时5秒左右关闭，关闭时“干脆利落”（因为自己之前做过锂电池供电单按键的开关，延时后有一段时间会微亮，过很久才会完全关闭，用在这里肯定不合适了）  
4，不干扰发射管正常工作

己有常见的容阻，三极管只有8050和8550，电路是越简单越好。  
电路效率无所谓，只要低待机功耗就好。  
另外想把遥控器改锂电池（手头有不少100MAH的小锂电池），想改到遥控器上，不知道能不能做一个低待机功耗的锂电池降压电路，吧锂电池降压到2个1.5V电池的电压范围内？

锂电池供电

如果把原来的干电池换成使用锂电池，电路会比较简单：

![](D:\电脑文件\公众号知识库\电工_教育_学习\遥控器背光照明延时控制电路_images\img_001_ea6f3b421b2c.png)

注意红外发射管最好串联一个限流电阻，锂电池的内阻比较小，放电电流较大。  
  
实际测试了一下，使用10uF 延时电容，大概在3秒，换成22uF电解，延时时长约8 ~ 10秒。

普通AA 电池供电

如果还是使用普通AA 电池供电，白光二极管会亮度不足，需要增加升压驱动电路。  
  
升压电路使用节能灯小磁环自制的升压变压器：
