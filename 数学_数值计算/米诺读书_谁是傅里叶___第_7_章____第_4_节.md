# I 导读：锯齿波的傅里叶系数计算

（Supplement 2 + Supplement 3 + Coffee Break）

这节内容超级有意思！它用一个最简单的“锯齿波”例子，彻底解答了书开头提出的那个大谜题：

> **“由直线组成的锯齿波，真的能用光滑的正弦波和余弦波无限叠加出来吗？”**

答案是：**能！** 而且我们会亲手算出来。

* * *

### 1\. 先把锯齿波“翻译”成数学语言

书里把一个周期的锯齿波画成从 **−π 到 π** 的一条斜直线：

-   当 t = −π 时，f(t) = −π
    
-   当 t = π 时，f(t) = π
    

所以这个周期内，波的公式就是：  
**f(t) = t**

周期 T = 2π（从 −π 到 π 正好一个来回），角频率 ω = 1。

**为什么选 −π 到 π 这个区间？**  
因为这样 f(t) 就等于 t，最简单！书里说：“只要能选，就选最简单的表达式。”

* * *

#### **① a₀（直流分量 / 平均值）**

### 4\. 补充3：小高斯的故事（数学界的励志短片）

### 5\. 咖啡时间：为什么积分后要加常数 C？

书里用一个简单例子说明：

对 y = 2x + 3 求导 → 得到 y' = 2  
再把 2 积分回去 → 得到 y = 2x + C（而不是 2x + 3）

**原因**：  
微分只看“斜率”（变化率），常数 3 的斜率是 0，被微分“吃掉”了。  
积分是求面积，必须把这个被吃掉的常数补回来。

**结论**：

以后写不定积分，永远别忘了 + C！

3.  **配对法** 是求和的聪明技巧（小高斯同款）。
    
4.  **积分常数 C** 是微积分里最容易被遗忘却最重要的小细节。

既然复杂波是由很多简单波组成的，那就会有一个新问题：

-   ：整体有没有往上或往下偏

**今天我们要做的，不是“背公式”，而是把锯齿波拆开，看看里面到底装了哪些正弦波、余弦波。**
