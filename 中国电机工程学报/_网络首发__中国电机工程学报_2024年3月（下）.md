# 作者：张琛，吕泽鹏，徐子航，曹丹，张馨月，吴锴

### 单位：电力设备电气绝缘国家重点实验室(西安交通大学)

DOI：10.13334/j.0258-8013.pcsee.232669

 

摘要：介电弹性体(dielectric elastomers， DE)常与柔性电极配合广泛应用于聚合物换能设备中，低频下会受到高压直流分量的影响。研究DE材料在直流电场作用下的空间电荷积聚和输运过程是掌握实际工况中电场分布进而预防绝缘损伤失效，提高换能设备长期运行可靠性的理论基础。该文通过红外光谱，热刺激电流，宽带介电谱，电导测量和直流击穿测试表征了聚二甲基硅氧烷(polydimethylsiloxane， PDMS)及其纳米复合材料的宏观介电性能；采用电声脉冲法(pulse electroacoustic method， PEA)得到20 kV/mm下不同样品的动态空间电荷分布。结果表明，添加适量的纳米二氧化硅可以有效降低材料低频下的介电损耗和电导率，提高直流击穿场强。较高掺杂浓度 (>2 phr)的复合材料中，经过表面处理的纳米粒子由于疏水基团相互排斥在PDMS中具有更好的分散性，击穿和电导性能仍有所缓慢提升。引入纳米二氧化硅增大了深陷阱电荷量和陷阱密度，降低了PDMS的离子电离率和负载流子迁移率，进一步解释了直流高压下复合材料中的空间电荷积聚得到抑制的现象。

# **交流故障电弧作用下电缆碳化的实验与仿真研究**

# 作者：唐昭晖，许志红，叶骁勇

### 单位：1\. 福州大学电气工程与自动化学院；2. 福建省新能源发电与电能变换重点实验室

DOI：10.13334/j.0258-8013.pcsee.231786

 

摘要：电缆碳化路径是电气火灾的一类重要致因。电缆绝缘材料经故障电弧烧蚀后形成碳化路径搭接在电缆之间或电缆与大地之间构成导电回路，极易导致短路和电气火灾，严重威胁电力系统的安全稳定运行。探究电缆碳化路径的机理是业界关注的重要问题。该文依托课题组研发的实验平台的工况条件对故障电弧引起电缆绝缘材料碳化过程进行实验与仿真研究。通过热重试验，初步构建了绝缘材料的热解动力学模型。通过神经网络将热解动力学参数衍伸到电弧的高升温速率条件，为建立电缆碳化路径仿真提供反应机理和参数的基础。在此基础上，提出一种电路-电弧-热解耦合模拟方法，建立了交流故障电弧作用下电缆碳化路径的三维数值模型，计算了电弧的热、流耦合作用下电缆的碳化发展过程，探讨了热解动力学参数及热解产气流速对故障电弧及电缆碳化的影响。结果可为研究电缆电弧故障的机理奠定理论基础。
