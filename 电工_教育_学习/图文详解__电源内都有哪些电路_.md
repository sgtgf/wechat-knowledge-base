# **抓住关键，不再眼晕**

从外面看起来，电源的个头也就比一块“板砖”大一点，但它“肚子”里装的东西可着实不少。拆开外壳，我们能看到数以百计的、各式各样的电子元器件和复杂交错的线缆，不免让人眼晕。俗话说“擒贼先擒王”，在观察电源时，我们也应该着重留意以下几个部分。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/iayzTbicUDics6UvKToEYesxQyqHgU9rSX5zoF83ibLqrcZ2NPQe51wtnJIKpsfCA6I7BUFnaEviauVtQnVaiahUM2Kg/640?wx_fmt=jpeg&wxfrom=13)

  

某电源的内部结构图，序号1～6分别标识出了大家应该着重观察的部分。

1.  一、二级EMI滤波电路。这部分的作用是将外部电网进入的市电进行过滤，得到比较纯净的交流电供后续使用。
    
2.  PFC电路。它的作用是在交流电转换成直流电的过程中减少谐波，降低对室内电网和市电电网的干扰，减少市电损耗。
    
3.  高压滤波电容。它的作用是净化高压直流电，为后续的高低压转换提供相对“纯净”的电流。
    
4.  电源拓扑。拓扑就是指电源的整体结构，它直接影响到电源的转换效率。
    
5.  低压滤波电路的电感线圈。其作用是稳定输出端的电压和电流，与电脑硬件系统的稳定使用有直接的关系。
    
6.  散热片。在变压器和开关电路进行电压转换时，会产生大量的热量，因此需要散热片迅速转移热量。
    

  

# **二级EMI滤波电路**

国家3C认证强制要求上市的电源必须通过EMI防电磁辐射认证，因此合格的电源都应该具有EMI滤波电路。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/iayzTbicUDics6UvKToEYesxQyqHgU9rSX57JNTXZjUDoAXruN1vxwjlsJVkfZRjLeLWD8w2O9yuH1W7ZKuuNg5uQ/640?wx_fmt=jpeg&wxfrom=5&wx_lazy=1&wx_co=1)

  

一级EMI滤波电路位于电源接口处，做工更好的电路还具有独立PCB板和电感线圈  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/iayzTbicUDics6UvKToEYesxQyqHgU9rSX5MMhFohND8E9kegKFh6OS5fw5CJ6FjrkqMHYV7j4f7uLiaiboS9cf5H5A/640?wx_fmt=jpeg&wxfrom=5&wx_lazy=1&wx_co=1)

  

二级EMI滤波电路通常在电源的主PCB板上，由电感线圈和电容等元器件组成。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/iayzTbicUDics6UvKToEYesxQyqHgU9rSX5bZXyzUPFjhgLBJGaqTQXEYhyqgK5V65lmKuLzvkJn9OUjaGpBERIMQ/640?wx_fmt=jpeg&wxfrom=5&wx_lazy=1&wx_co=1)

  

某劣质电源上的二级EMI滤波电路唱了“空城计”

不过低端电源往往只有一级EMI滤波电路，稍好一点的电源都应该具有完整的一、二级EMI滤波电路。

  

# **PFC电路**

PFC电路分为被动式和主动式两种，现在大部分电源都是采用的主动式PFC。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/iayzTbicUDics6UvKToEYesxQyqHgU9rSX55h1ibVkcaAAeCv4Te6VA01icwMx2WBqZsKroAhVJBy0PfDDe4tfP30Xg/640?wx_fmt=jpeg&wxfrom=5&wx_lazy=1&wx_co=1)

  

被动式PFC均采用这种“大个头”的电感

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/iayzTbicUDics6UvKToEYesxQyqHgU9rSX5MUwlL2EGJIfMVscq3KWvBCOGicIZ5IGa898ic5rr3asVtEQqNxiafalJw/640?wx_fmt=jpeg&wxfrom=5&wx_lazy=1&wx_co=1)

  

主动式PFC的电感线圈往往位于高压滤波电容的前方

  

被动式PFC的功率因数普遍在0.7左右，主动式PFC的功率因数则高达0.9以上，明显优于被动式PFC。两者的分辨也相当容易。

# **高压滤波电容**

哪些是高压滤波电容?很简单，电源里面最高、最大的电容即是(1～2颗)。比较电容时，原则上只能与同类型的电源相比，因为在相同功率下，被动式PFC电源所需的电容容量比主动式要大。在同级比较时，我们可以看到高压滤波电容的容量、耐压值和耐温值，理论上这三项数值越大越好。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/iayzTbicUDics6UvKToEYesxQyqHgU9rSX53l7A4U7qqfBxFtVibwzTJKcql8qNnJtlRibND9DrI1qvpJ7QsegGicz1g/640?wx_fmt=jpeg&wxfrom=5&wx_lazy=1&wx_co=1)

  

电源采用主动式PFC，因此使用容量为330μF的高压滤波电容就能满足需求。该电容的耐压值为400V，耐温值为85℃。

# **电源拓扑**

简单说来，在前几年电源的拓扑可分为半桥式和正激式两种，现在基本以正激式为主。半桥式是传统的电源结构，通常转换效率不高;而正激式结构转换效率容易做到80%以上。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/iayzTbicUDics6UvKToEYesxQyqHgU9rSX5IuWJR21pzFR1LwxtKfibWMnicZjqK9mqZpCCmYe6OvZvDKJyJGdmauog/640?wx_fmt=jpeg&wxfrom=5&wx_lazy=1&wx_co=1)

  

传统的半桥式拓扑

# **正激式拓扑有助于提高转换效率**

  

在进行分辨时，我们不妨采用排除法：在半桥式电源的中央，必定有三个变压器，并且一大两小，排成一条直线;如果你的电源不是这种结构，那么恭喜你，这多半是正激式电源。

# **低压虑波电路的电感线圈**

在低压滤波电路部分，我们主要看电感线圈的大小、匝数和颜色。自然是线圈越大、匝数越多越好;至于颜色，理论上从优到劣分别为灰色、黑色、浅绿色和黄色，电感越好损耗越小。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/iayzTbicUDics6UvKToEYesxQyqHgU9rSX56YyiafFLKxBPj008cKaC1RKXCxy6iaIiaZzQsvnOp9bVv2MdLqkWhXtrA/640?wx_fmt=jpeg&wxfrom=5&wx_lazy=1&wx_co=1)

  

低压滤波电路部分主要看电感线圈

# **散热片**

散热片的作用不需多说，发热量较大的开关管和肖特基管都常常安装在散热片上。目前市售电源普遍采用铝质散热片，通常越厚越好;同时为了在有限的空间内扩大散热面积，大部分散热片都开有鳍片，理论上鳍片越多越好。
