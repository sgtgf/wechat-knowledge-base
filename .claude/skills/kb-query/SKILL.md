# Knowledge Base Query — 公众号知识库检索

## 触发条件

当用户提出**技术问题**，且**很可能在你的公众号知识库中有相关文章**时，自动执行本技能。

典型触发问题模式：
- "γ-δ坐标系是什么"
- "I/f启动怎么实现的"
- "phobia里怎么写的"
- "有没有讲V/f的文章"
- "帮我查一下负载角怎么算"
- "之前存的那篇关于xxx的文章"

## 三层检索策略

### 第1层：查主题记忆摘要（0 额外 token，自动已加载）

记忆文件在 `memory/` 下，**每次会话自动加载**。

**做法：**
1. 从已加载的记忆中，找到与问题**主题匹配的记忆文件**
2. 看该主题下的「融合摘要」能否回答问题

**输出判断：**
- ✅ 摘要足够回答 → 直接给出答案，末尾附上来源（"详见电磁散人05讲"）
- ❌ 摘要提示了方向但不具体 → 进入第2层

**参考记忆文件示例：**
```
memory/pmsm-sensorless-series.md
  ├── 已收录文章（表格）
  ├── 主题融合摘要
  │   ├── γ-δ坐标系定义
  │   ├── 开源代码实现
  │   └── 已明确的后续文章预告
  └── 关联
```

### 第2层：Grep 跨全文搜索（按需花 token）

当记忆摘要不足以回答时，在知识库的 .md 文件中搜索。

**做法：**
```
Grep(搜索关键词, 路径=D:\电脑文件\公众号知识库\, 输出模式=content)
```

**选择关键词的策略：**
- 先用最精确的关键词（如"γ-δ"、"负载角"、"I/f"）
- 没结果再放宽（如"无感启动"、"开环启动"）
- 限定文件类型为 `*.md`

**输出判断：**
- ✅ 匹配段落足以回答问题 → 整合后回答，标注具体文章名
- ❌ 匹配段落缺少上下文/公式/代码 → 进入第3层

### 第3层：读特定文章的特定章节（最高 token 消耗）

**做法：**
```
Read(路径=知识库\某文章\某文章.md, offset=...)
```

**只读需要的部分，不读全文：**
- 根据第2层的匹配行号，确定哪几个章节相关
- 只读那几段（offset + limit 控制）
- 涉及公式/代码的章节优先读取

## 回答格式

### 格式模板

```
## 回答

（你的答案，综合记忆+搜索+全文的结果）

---

**来源：**
- 电磁散人 05讲《γ-δ坐标系》第3节
- 知识库索引：D:\电脑文件\公众号知识库\PMSM无感启动_05讲_γ-δ坐标系\
```

### 重要原则

1. **你的知识库优先**：如果文章里有相关内容，以文章为准，不从我自己的知识编造
2. **标注来源**：每个结论都要标注是来自哪篇文章，方便你查证
3. **区分已知与未知**：
   - "根据你知识库中XX文章..."（有来源）
   - "根据我的训练知识..."（你库里没有，但我知道）
   - "这个在你的知识库里没找到相关文章"（你库里没有，我也不确定）
4. **交叉比对**：如果多篇文章对同一问题有不同说法，明确指出差异让你判断
