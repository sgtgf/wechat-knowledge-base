# 12V 铅酸蓄电池专用充电器电路

（**LM317 可调三端稳压器 U1 + 运算放大器 U2 双检测**，含电流限流电阻R、充满指示灯逻辑）完全按照你的需求设计：

1.  U1
    
    ：LM317 可调三端稳压核心，构成主充电恒压回路；
    
2.  R
    
    ：充电电流采样 + 硬件限流电阻；
    
3.  U2
    
    ：通用运算放大器，**同时检测电池电压 + 充电电流**；
    
4.  逻辑：电池电压达到充满阈值 → U2 输出**低电平** → 三极管 VT1 饱和导通 → LED 点亮，指示充满。

自动充放电电路，可以很好地避免“过充”或“欠充”问题。

### 前提

开关 S1 置于**位置 1**，LM317 稳定输出 3V 给 IC3 (+) 端。

1.  **电池未充满（VE<3V）**电池电压低于基准，IC3 反相端电位 < 同相端，**IC3 输出高电平**。高电平驱动 VT1 饱和导通 → VT2 基极被拉低、也饱和导通。+6V 电源 → VT2 → R8 → 电池 E 形成充电回路，**LED 点亮**，表示正在充电。
    
2.  **电池充满（VE\>3V）**充电过程中电池电压逐步上升，当电压略高于 3V 时，IC3 反相端电位 > 同相端，**IC3 输出低电平**。VT1、VT2 同时截止，充电回路断开，**LED 熄灭**，充电停止。
    
3.  **充满后稳态**电池电压通过 R3 持续送至 IC3 反相端，电位保持高于 3V 基准，IC3 持续输出低电平，两只三极管保持截止，**永久停充**，彻底避免过充；电压回落也不会立即复充，解决欠充反复启停问题。
