## 推导 1：用余弦定理（最经典）

在平面或三维里，把向量 a,b 都从原点出发，考虑三角形的三条边：

-   一条边长度：∥a∥
    
-   另一条边长度：∥b∥
    
-   第三条边是 a−b长度：∥a−b∥
    
-   夹角就是 a 与 b 的夹角 θ
    

**余弦定理**告诉你：

![$\|a-b\|^2=\|a\|^2+\|b\|^2-2\|a\|\|b\|\cos\theta$](https://mmbiz.qpic.cn/mmbiz_png/sVzeakRoocuSibic9ETht0OgOOGfzqONPRsOHicV3KJtUuotXz9JaXTVRiajnbkTkR2TcKVgEKJod1rJJukVvQDfR8qbcYOcvLgTlyvYJZeicYxg/640?wx_fmt=png&from=appmsg)

另一方面，利用点积恒等式展开：

![$\|a-b\|^2=(a-b)^\top (a-b) = a^\top a -2a^\top b + b^\top b = \|a\|^2 - 2a^\top b + \|b\|^2$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trqLmdN6UhKVTCtlm1z7UbnR3wlF5pfCTH2Niade9eo9UNkqffYiapHVqgRGaCXfPwTJ52V1PicsicwQQ/640?wx_fmt=png&from=appmsg)

把两条对同一个量 ![$\|a-b\|^2$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trqLmdN6UhKVTCtlm1z7UbnLEYFf4jibuu7gpZ3vaFicWOibq3ecaXAc6AQiajjKb0oWQgSVM4l1wvo6Q/640?wx_fmt=png&from=appmsg) 的表达式相等：

![$\|a\|^2 - 2a^\top b + \|b\|^2 = \|a\|^2+\|b\|^2-2\|a\|\|b\|\cos\theta$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trqLmdN6UhKVTCtlm1z7UbnXC7KYOLNib85Z3DIUCucL2WicIYvbYZ0ab3nXj0lCPj8aqvFSwCFTRqQ/640?wx_fmt=png&from=appmsg)

两边消掉 ![$\|a\|^2+\|b\|^2$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trqLmdN6UhKVTCtlm1z7UbnngVJSVtYeVXrJ7ibWvt3v60JmWNIq1uIiaUOPCZ9gM9n8Fs3Nkia3IK6w/640?wx_fmt=png&from=appmsg)，再除以 −2：

![$a^\top b=\|a\|\|b\|\cos\theta$](https://mmbiz.qpic.cn/sz_mmbiz_png/sVzeakRoocuYdGSybKDzRRxGoVoqBNNLH8m6bJBLg7x2wO1TDWFoMO4ImCox5S8XJxUOXytticVMswIZNtnL0HwFibuzuOHT9jkia0iaUaOAKibY/640?wx_fmt=png&from=appmsg)

✅ 得证。

> 所以这个公式是“点积和几何距离（余弦定理）兼容”时必然成立的关系。

点积 **a · b** 的几何解释是：

-   取向量 **b** 的模长 **|b|**（即 OB 的长度）
    
-   乘以向量 **a** 在 **b** 方向上的**投影分量**（即 OL 的长度 **|a| cos θ**）
    

所以： **a · b = |b| × (|a| cos θ) = |a| |b| cos θ**

这正是图片底部公式展示的。

![$a^\top b=\|a\|\|b\|\cos\theta$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trqLmdN6UhKVTCtlm1z7Ubne1bhD9p6Ysib0ic5vWKoUHjazzs7tuuHSicLcFnMYTwO6vyZ83WOuabjQ/640?wx_fmt=png&from=appmsg)

✅ 得证。

**如何用点积求夹角 θ**

从公式反推： **cos θ = (a · b) / (|a| |b|)**

只要知道两个向量的坐标，就能：

-   先算出点积 a · b（用坐标分量相乘求和）
    
-   算出各自的模 |a| 和 |b|
    
-   除一下得到 cos θ
    
-   再反余弦得到 θ 本身（θ = arccos( (a · b) / (|a| |b|) )）
    

  

θ 的范围是 0° 到 180°：

-   θ = 90° 时，cos θ = 0 → 点积 = 0（垂直）
    
-   θ < 90° 时，cos θ > 0 → 点积 > 0（锐角）
    
-   θ > 90° 时，cos θ < 0 → 点积 < 0（钝角）

## 一句话总结它“为什么必然成立”

在欧氏空间中：

## 重要补充：它对什么情况下成立？

-   ✅ 对\*\*标准点积（欧氏内积）\*\*成立：![$a^\top b$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trqLmdN6UhKVTCtlm1z7UbnStdQGsn4m7Rb6jJB8ydby1V1nIxZBrAeddKsLwkz6qy9tulibabqOicA/640?wx_fmt=png&from=appmsg)
    
-   ✅ 对更一般的“内积空间”也成立，但公式写成：
    
    ![$\langle a,b\rangle=\|a\|\|b\|\cos\theta$](https://mmbiz.qpic.cn/mmbiz_png/sVzeakRooctUqP6y7sicU9wMkBbK7CCJfunOIl32m7Uo7hxpficmYHq9E2ZbMn3kb0bPd2Eqm4FdZSILuLJmzko5TiaOzYWBWbEKKDukibKEJlU/640?wx_fmt=png&from=appmsg)
    
-   ⚠️ 如果你用的不是欧氏内积（比如某些非标准度量），那“θ”的定义也要跟着内积变，否则就不再是同一个几何角度了。

## 演示 1：用 (3,4,5) 直接把 cosθ 算出来

取两个向量（都从原点出发）：

![$\begin{array}{c} a=\begin{bmatrix}3\\4\end{bmatrix},\qquad b=\begin{bmatrix}5\\0\end{bmatrix} \end{array}$](https://mmbiz.qpic.cn/mmbiz_png/sVzeakRoocsXy7yeatPpTibUrl1OafOQibP4Wou0SoVic2d1NxxYtom2I1J9MrbsDM9LVGv1TKm3AobxJAuMutMhQbJFKKemDiaib2toqGdqKp8E/640?wx_fmt=png&from=appmsg)

### ① 先算长度（都是整数，很舒服）

![$\|a\|=\sqrt{3^2+4^2}=\sqrt{25}=5,\qquad \|b\|=\sqrt{5^2+0^2}=5$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trqLmdN6UhKVTCtlm1z7UbnNLEKWMZFu1MQbk6MqY3yulYk2jUoA4VmQvSZBiaO4tQTANOzH8Tibbiag/640?wx_fmt=png&from=appmsg)

### ② 算点积

![$a^\top b = 3\cdot 5 + 4\cdot 0 = 15$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trqLmdN6UhKVTCtlm1z7Ubn56qInwUknGQicOo6pU2VXQZMEECib54CbaPibYE8572XGHwzGyAvnUr0Q/640?wx_fmt=png&from=appmsg)

### ③ 代入公式求 cosθ

![$\cos\theta=\frac{a^\top b}{\|a\|\|b\|} =\frac{15}{5\cdot 5} =\frac{15}{25} =\frac{3}{5}$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trqLmdN6UhKVTCtlm1z7UbnTiaic8ngFno7JKm37UgwRjyPrFyNNPSwgTODibBKJ44k1JUrB83FcUylw/640?wx_fmt=png&from=appmsg)

\*\*结论：\*\*夹角 θ 的余弦就是 3/5。

## 为什么这就是“勾股数”的几何意义？

注意 b=(5,0) 就是 **x 轴方向长度 5** 的向量。  
而 a=(3,4) 和 x 轴夹角的那个直角三角形，正好是：

-   斜边：∥a∥=5
    
-   邻边（在 x 轴上的投影长度）：3
    
-   对边：4
    

所以几何上本来就有：

## cos⁡θ=邻边/斜边=3/5

你看，**点积推出来的 cos⁡θ**，和**勾股三角形的 cos⁡θ** 完全一致。

## 例子：两根斜向量都来自勾股三角形

选两条长度都为 5 的向量（都是 3-4-5）：

![$\begin{array}{c} a=\begin{bmatrix}3\\4\end{bmatrix},\qquad b=\begin{bmatrix}4\\3\end{bmatrix} \end{array}$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trqLmdN6UhKVTCtlm1z7UbnYAbJy1X7P73AJ1zpoNNXQHLSSjj7sp0jkPNHia0mwNjYXv2R8pkvIKg/640?wx_fmt=png&from=appmsg)

### ① 长度

![$\|a\|=\sqrt{3^2+4^2}=5,\qquad \|b\|=\sqrt{4^2+3^2}=5$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trqLmdN6UhKVTCtlm1z7Ubn2THej6IZwqrsianIpucgcQFMunzcfMP6cLEPWxbgfkPvJuOrJ7wicoicw/640?wx_fmt=png&from=appmsg)

### ③ 余弦相似度（也就是 cos⁡θ）

![$\cos\theta = \frac{a^\top b}{\|a\|\|b\|} =\frac{24}{5\cdot 5} =\frac{24}{25} =0.96$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trqLmdN6UhKVTCtlm1z7UbnoNCZ2RHbrF8E4OuQLJZMbApcun964eSEonkzict9Jx7LlUzY468STiaA/640?wx_fmt=png&from=appmsg)

\*\*解释：\*\*0.96 非常接近 1，说明两向量夹角很小、方向非常接近。

![$\theta \approx \arccos(0.96)\approx 16.26^\circ$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trqLmdN6UhKVTCtlm1z7UbnuPH2icptGZnJgHicFOojexNsYGYAvxo5HV45MhJtQ6H4FjPlAicD7A9ibA/640?wx_fmt=png&from=appmsg)

## 为什么这个结果“很合理”？（用投影直觉解释）

把 a 投影到 b 的方向上：

-   b 的单位向量是 ![\hat b=b/\|b\|=\frac{1}{5}(4,3)](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trqLmdN6UhKVTCtlm1z7Ubn1xFAztCfN4XIs2ug9bq6faficrDJJdHk7tRMiaNcJoIfxZQOaJC7t78Q/640?wx_fmt=png&from=appmsg) 
    
-   投影长度（标量投影）：
    
    ![$a^\top \hat b = \frac{a^\top b}{\|b\|} =\frac{24}{5}=4.8$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trqLmdN6UhKVTCtlm1z7UbnYkF5Kfj64NvC2gNYyicRAVb1sXRLt4z6wg0I3PyODlanKu2hzB0FWoA/640?wx_fmt=png&from=appmsg)
    

而 ∥a∥=，说明 a 在 b 方向上的“有效分量”是 **4.8/5 = 0.96**，也就是：

## 投影长度/∥a∥=cos⁡θ=0.96

这就是“余弦相似度”最直观的意义：

> **A 沿着 B 的方向，能“投影出”A 的多少比例。**  
> 越接近 1，说明 A 基本都沿着 B。

## 最后把“余弦相似度”一句话钉死

![$\text{cos\_sim}(a,b)=\frac{a^\top b}{\|a\|\|b\|}$](https://mmbiz.qpic.cn/mmbiz_png/jlXjovro0trqLmdN6UhKVTCtlm1z7UbnGKW6DkqfWdBQaWsNWNCqALcuBZibopWlibTgeEb5YaG5MkNNBE44wvYg/640?wx_fmt=png&from=appmsg)

它等于 cos⁡θ，所以：

-   只看夹角（方向）
    
-   不受长度影响
    
-   范围固定 \[−1,1\]，特别适合做“相似度打分/排序”
