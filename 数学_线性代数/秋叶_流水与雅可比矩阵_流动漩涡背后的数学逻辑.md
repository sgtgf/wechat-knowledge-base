# 秋叶、流水与雅可比矩阵：流动漩涡背后的数学逻辑


> 原文地址: [https://mp.weixin.qq.com/s/A2HD1DSM87BMZtL3Vepj2g](https://mp.weixin.qq.com/s/A2HD1DSM87BMZtL3Vepj2g)

日常生活中，我们经常能看到各种各样的“流动”：秋天的落叶被卷入风中的漩涡、洗脸池放水时旋转陷落的水流，或是空调出风口向外吹出的强劲冷气。

这些错综复杂的流动现象，在物理上都与一种称之为向量场的概念对应。面对一团乱麻的复杂向量场，我们该如何去精确地描述、分类并预测它们的动态行为呢？

其实，向量场在数学上正好对应着一类特殊的多元函数，也就是向量值多元函数。借由这种对应关系，我们就可以通过多元函数的微积分工具雅可比矩阵，对非线性向量场做局部线性近似，以此解析各类复杂流动的内在规律。

# 1．多元函数与向量场

自然界中，随处可见成片流动的现象，比如风的吹拂、水流的汇聚。如果我们去仔细观察这些现象，就会发现空间中的每一个点，其实都携带了一个代表流动方向和强度的向量（速度）。这种在空间各处都分布着向量的物理现象，就是向量场。

在数学上，向量值多元函数正好就对应了向量场。因为函数的输入是一个空间的坐标，比如二维坐标![](秋叶_流水与雅可比矩阵_流动漩涡背后的数学逻辑_images/img_000_351b702d5d0f.png)；而函数的输出不是一个单一的数，而是一个多维的向量![](秋叶_流水与雅可比矩阵_流动漩涡背后的数学逻辑_images/img_001_f9cfaafcfe7d.png) 。

所以，当我们在黑板上写出![](秋叶_流水与雅可比矩阵_流动漩涡背后的数学逻辑_images/img_002_2f451943292e.png)时，它既是一个向量值多元函数，在几何上也是一个完整的向量场。这种对应关系，让我们能用数学的眼光去审视这团流体的走势。

# 2\. 雅可比矩阵

既然向量场可以用函数来表达，那么当我们想研究这团流体在某一个特定点附近的局部变化时，自然就需要用到微积分。

一元函数![](秋叶_流水与雅可比矩阵_流动漩涡背后的数学逻辑_images/img_003_264947f10a95.png)的导数是一个数字，代表切线的斜率。但如果面对一个输入是多维、输出也是多维的函数，情况就变了。为了看清函数因变量的局部在受到微小扰动时的线性变化趋势，我们需要把每一个输出分量，对每一个输入分量都求一次偏导数。把这些偏导数排成矩阵，就得到了雅可比矩阵：

![](秋叶_流水与雅可比矩阵_流动漩涡背后的数学逻辑_images/img_004_24094574e8a8.png)

简单来说，雅可比矩阵就是向量场的多维导数，是我们在局部进行线性分析的代数工具。

# 3\. 根据雅可比矩阵分析向量场类型

既然向量场在任意一点的微小变化可以用雅可比矩阵描述，那么局部形变的类型，就能通过雅可比矩阵的特征值与特征向量精确刻画。为简化分析，下文仅讨论向量场的平衡点，也就是向量取值为零向量的空间点。

以气流、水流这类流体场为例，平衡点处整体流速为0，不存在整体平移，这使得雅可比矩阵的特征值能够清晰刻画该点周围流体的运动形态。下图直观地展示了平衡点附近的几种经典流线结构。

![](秋叶_流水与雅可比矩阵_流动漩涡背后的数学逻辑_images/img_005_f2459cd6884a.png)图1. 向量场在平衡点处的六种常见结构

第一种情况：实数特征值

当特征值为实数时，流体主要在特定的方向上进行拉伸或挤压。具体而言：

如果两个特征值均为负数且不相等，相应的平衡点被称为稳定结点（图1.a）。它在物理上类似一个地漏，周围所有流体都笔直地向这个中心汇聚。

如果两个特征值均为正数且不相等，相应的平衡点被称为不稳定结点（图1.b）。它类似于一个泉眼，流体向四周笔直地喷涌扩散。

如果特征值一正一负，相应的平衡点被称为鞍点（图1.c）。它像个山谷的马鞍处，流体从一个方向流入汇聚，但随即顺着另一个方向流走。

上面仅讨论平衡点处雅可比矩阵具备可对角化实特征值的情形。从理论层面来说，这并未涵盖不可对角化对应的剪切变换情形。对于流体场，剪切流动仅存在于带有整体流速的非平衡点；在流速为0的平衡点邻域，单向剪切结构物理稳定性极差，难以长期存在，因此本文不将其纳入讨论范围。

注：实特征值并不代表向量场无旋。若雅可比矩阵非对称，向量场旋度就非零；仅因缩放效应主导，流线不会形成螺旋。

第二种情况：复数特征值

如果雅可比矩阵的特征值为复数（虚数），这意味着对应的线性变换包含旋转。此时局部的几何特征由实部决定。

当实部为负数时，相应的平衡点被称为稳定焦点（图1.d）。它类似于浴缸放水时的漩涡，流体一边绕圈，一边向着中心盘旋汇入。

当实部为正数时，相应的平衡点被称为不稳定焦点（图1.e）。它类似于旋转洒水器，流体从中心甩出，向外螺旋扩散。

当实部为0时，特征值为纯虚数，相应的平衡点被称为中心点（图1.f）。流体在原地做闭合圆周运动，既不外扩也不内缩。

# 4\. 总结

物理中的流体向量场与向量值多元函数一一对应，因此我们可以借助雅可比矩阵对复杂流动做局部线性近似。进一步地，既然线性变换的类型完全由对应矩阵的特征值和特征向量描述，那么我们就可以通过对雅可比矩阵进行特征分析，来完整描述向量场在局部的变化形态。

在实际分析中，最终的分类依据完全取决于特征值的类型。特征值是否包含虚部，决定了流体在局部是直来直往的缩放，还是拧麻花式的旋转；而特征值实部的正负号，则决定了流体是在向内汇聚还是向外扩散。

借助雅可比矩阵及其特征分析这一套工具，任何非线性流动系统在平衡点处的局部特征，都可以被非常清晰、严谨地拆解出来。
