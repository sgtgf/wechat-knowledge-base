# PWM驱动led亮灭原理

    了解PWM驱动LED亮灭已经呼吸原理，主要涉及到两方面的知识  

        1.PWM原理

        2.LED点亮工作原理

  

        1.PWM原理

                一般我们在电路中，只有高电平低电平之分，当需要点亮一个LED灯时，给予LED正极高电压即可点亮，移除LED正极电压，LED随即熄灭。当我们引入一个时间的概念之后，即可理解PWM工作方式。

                一般我们说点亮LED，但是不提及点亮多久。一般默认就是一直点亮，也可以理解为周期时间内，持续高电平点亮。

                PWM利用了周期时间这个概念，当在周期时间内，一部分时间点亮，一部分时间熄灭。

                        A：![](D:\电脑文件\公众号知识库\电工_教育_学习\PWM驱动led亮灭原理_images\img_000_c19b061314e8.png)

                        B：![](D:\电脑文件\公众号知识库\电工_教育_学习\PWM驱动led亮灭原理_images\img_001_75708f3c1df8.png)

                如上图，PWM在周期内电平变化如上，在一个T周期内，一半为高电平一半为低电平。

                那么由此可以计算，在T1周期内，一半周期有电流一半周期没有电流。

                根据电流的定义：一定时间通过导体横截面的电量除以时间，I = q / t 。此时因为V和R不变，所以q不变，当 t 等于T/2时，上图两者电流相等，当 t 等于T时，I(b)等于一半I(a)。此时如上B图，我们也可以称之为占空比50%的PWM波形。占空比就是这么由来的。占空比的计算公式为：

                        Duty Cycle = (Th / T) \* 100%

                PWM的原理就是在T周期内，动态调整高电平持续时间，也就是调整高电平占空比，从而实现在周期内输出不同的电流大小。在实际计算中我们不使用I = q / t公式计算PWM的电流。一般使用：

                         I(pwm) = I(max) \* D       ，D为占空比。

  

  

                2.LED点亮工作原理

                        LED灯放大解析其实就是一个PN结：

                        ![](D:\电脑文件\公众号知识库\电工_教育_学习\PWM驱动led亮灭原理_images\img_002_ba7be4df8549.png)

                                ![](D:\电脑文件\公众号知识库\电工_教育_学习\PWM驱动led亮灭原理_images\img_003_ac600e9079f7.png)

                LED里面的PN结，在电压驱动作用下，内部的电子和空穴会复合，复合的过程能量会以发光的形式释放，这就是LED灯的工作原理。当电子与空穴相遇复合的时候，电子跌落到较低的能阶，根据能量守恒定律，此时电子与空穴相遇复合会以两种形式将电能转换成其他物质，第一种为热辐射，第二种为光子形式的光转换。那么此时就可以区分，白炽灯和led灯了。并且光的亮度，以及LED温度都与电子的流动息息相关。这就是LED内部原理。

  

                那么结合如上的PWM控制周期内电流，就可以实现类如呼吸灯，不同温度的白炽灯等。当我们使用PWM控制LED呼吸的时候，涉及到一个开关频率的问题，即T周期时间。这个T周期时间不能太长，原因是我们要让人眼观测时无感。当T周期太长时，人眼观测会发现闪烁的过程。一般我们使用200Hz到30kHz之间，人眼的最低辨别频率在60hz左右。

  

                3.不同颜色的LED灯

                        不同颜色的LED灯原理在与P-N结的参杂材料不一样决定的，如下图：

                ![](D:\电脑文件\公众号知识库\电工_教育_学习\PWM驱动led亮灭原理_images\img_004_98127509b0ba.png)

                        其区别在于，不同的材料，产生的光子的波长不同，那么就会有不一样的颜色。

                        一般在电子电路中，我们较常使用的是三原色LED灯，即RGB红绿蓝灯。通过PWM控制各个颜色的发光程度，从而融合出其他需要的颜色，如白，黄等。
