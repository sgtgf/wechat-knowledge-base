# 重线性函数与张量


> 原文地址: [https://mp.weixin.qq.com/s/F4TN28zac2qOxV0LpMkjeQ](https://mp.weixin.qq.com/s/F4TN28zac2qOxV0LpMkjeQ)

自然界中很多线性关联并非只由单一因素界定，而常牵涉多个变量的协同作用。比如物理中力对物体做功，需同时关联 “力” 与 “位移” 两个变量；统计中分析多组数据的联合影响，也离不开多个变量的共同参与。但单一变量的线性映射（如线性泛函），只能刻画 “一个因素到结果” 的线性关系，完全无法覆盖 “多因素共同决定结果” 的需求。此时就需要一种新的映射：它既要对每个独立变量分别保持线性，又能容纳多个变量的协同作用。这种兼顾 “多变量独立性” 与 “单变量线性性” 的映射，就是重线性函数。

则称_f_为_V_1×_V_2×…×_Vk_上的_k_**重线性函数**，如果_V_1\=_V_2\=…\=_Vk_\=_V_，也称_f_为_V_上的_k_重线性函数。

关于线性空间_V_上的_k_重线性函数_f_，如果对于_k_阶置换群_Sk_中的任何一个元素_σ_，都有_f_(**α**_σ_(1),…,**α**_σ_(_k_))\= _f_(**α**1,…,**α**_k_)，则称_f_是**对称**的。如果_f_(**α**_σ_(1),…,**α**_σ_(_k_))= sgn(_σ_)_f_(**α**1,…,**α**_k_)_，则称__f_是**交代**（或**交替**）的。其中，当_σ_为偶置换时，sgn(_σ_)=1；而当_σ_为奇置换时，sgn(_σ_)=-1；可以验证，_σ_的奇偶性与其逆序数的奇偶性一致。

综上，在给定基底的前提下，实线性空间中的每个重线性函数都唯一对应一个实张量。重线性函数可捕捉自然界复杂非线性关联深层的基础结构，而张量则通过具体数值，将这种抽象的多变量关联具象化，进而成为探究自然现象深层规律的基础工具。
