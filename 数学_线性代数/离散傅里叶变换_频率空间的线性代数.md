# 离散傅里叶变换：频率空间的线性代数

## 心智锚点

一首音乐，在时间域是一串数字（每秒 44100 个采样值）。听起来是旋律，看起来是混乱的波动。

换到频率域：同一段音乐变成几个清晰的峰——基频、泛音——杂音消失在低幅背景中。

这个从"时间"到"频率"的切换，不是信号处理的魔法，是一次矩阵乘法。

**DFT 是在一个特殊的正交基（复指数函数）下对信号做坐标展开。**

## 现实映射

**DFT 和 FFT 是信号处理和科学计算的基础设施。**

-   **音频处理：** MP3 压缩通过 MDCT（修正离散余弦变换，DFT 的变体）在频域丢弃人耳不敏感的高频分量。
    
-   **图像压缩（JPEG）：** 对每个  像素块做 2D DCT，在频域量化（低频系数高精度，高频系数低精度）。
    
-   **多项式乘法与大整数乘法：** 两个多项式乘法等价于系数向量的卷积，用 FFT 将复杂度从  降至 。大整数乘法（如 RSA 密钥计算）依赖此技术。
    

**核心法则：DFT 是在"频率正交基"下做坐标展开；卷积定理是循环矩阵被 DFT 对角化的必然结果；FFT 是这个矩阵的稀疏因式分解的算法实现。三者构成一个完整的线性代数故事。**
