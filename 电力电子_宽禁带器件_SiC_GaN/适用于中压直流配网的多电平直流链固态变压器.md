# 适用于中压直流配网的多电平直流链固态变压器


> 原文地址: [https://mp.weixin.qq.com/s/sxfdhIi6fcosyuV6Y0sQbA](https://mp.weixin.qq.com/s/sxfdhIi6fcosyuV6Y0sQbA)

文章来源：中国电机工程学报

作者：李建国1，赵彪2，宋强2，黄永章1，孙谦浩2，王裕2，刘文华2(1．新能源电力系统国家重点实验室(华北电力大学)，北京市昌平区102206；2．电力系统及发电设备控制和仿真国家重点实验室(清华大学)，北京市海淀区100084)

摘要：该文提出一种适用于中压直流配网的多电平直流链固态变压器方案，和传统直流变压器方案相比，所提方案可以始终保持双主动全桥高频链环节的电压匹配，从而改善电力电子器件的电流应力，提高系统的传输功率和效率；当发生子模块故障时，可以快速旁路故障的子模块，从而提高系统的可靠性；当发生外部故障时，可以工作在直流断路器模式，快速切除与中压直流配网的连接，且不需要增加额外的直流断路器。文章详细分析所提方案的拓扑结构、电压电流和功率特性、运行控制策略以及故障处理策略，在此基础上搭建物理样机，验证了所提方案的正确性和有效性。  

关键词：直流配电；直流输电；多电平；直流变压器；固态变压器；双主动全桥  

0.引言  

近年来，直流配网受到了越来越多的关注，但相关的研究还处于探索阶段。在直流配网的研究中，目前还主要集中在低压直流微网，对中高压配网的研究还主要针对交流配网。但随着柔性直流输电技术的迅速发展，新能源分布式电源和储能设备的接入，以及直流负荷的发展，对中高压直流配网的研究也提出了更迫切的需求。  

在直流配网中，必须使用直流变压器(direct current transformer，DCT)实现中高压直流配网和低压直流微网的电压变换、能量交换和电气隔离。直流配网不能像交流配网那样采用磁耦合变压器实现电压的变换和能量的传输，必须采用基于电力电子器件的固态变压器(solid state transformer，SST)。由于直流配网发展时间相对较短，目前对固态变压器的研究还主要集中在交流固态变压器，对直流固态变压器的研究却很少。虽然很多文献研究了DC\-DC变换器，但主要还集中在单方向的功率变换，包括升降压变换器或者隔离型直直变换器，这些变换器还不能满足直流变压器对双向功率传输、电气隔离和高电压大功率的应用需求。一些文献也研究了基于隔离型双向逆变器(isolated bidirectional dc\-dc converter，IBDC)的直流变压器，主电路拓扑主要有双向半桥、串联谐振变换器和双主动全桥(dualactivebridge，DAB)3种，文献\[17\]对此做了比较系统的研究，结果表明DAB是最适合构成直流变压器的子模块拓扑。  

目前，直流变压器的方案主要采用了DAB串并联的拓扑结构，虽然可以实现高低压侧的电气隔离、电压变换和功率的双向传输，但在中压直流配网的应用中还存在很多问题，尤其是DAB高低压侧均存在集中电容，这在很大程度上限制了其应用。当发生外部故障时，直流变压器在不借助直流开关的情况下，不能从中压直流配网侧断开，当故障消失后，由于集中电容需要重新充电，使得恢复时间变长。当发生子模块故障时，不能旁路子模块运行，很大程度上降低了装置的可靠性。另外，当高低压侧直流电压不匹配时，高频链环节的环流迅速增大，也使得开关器件的电流应力迅速增加，系统的传输功率、效率和功率密度降低。  

基于上述的研究现状，本文提出适用于中压直流配网的多电平直流链固态变压器方案，相对基于DAB的传统直流变压器(traditionalDCT，TDCT)，所提方案在本文中均称为NTCT(newTCT)，文中对NTCT的拓扑结构、电压电流和功率特性，控制策略和故障处理等均进行理论分析，并通过物理试验进行验证。

图1所示为多电平直流链固态变压器，主要由多电平直流链级(multilevel dc link interface，MDLI)和高频链级(high frequency link interface，HFLI)构成，MDLI级由N个完全相同的SC子模块构成，子模块的交流输出端首尾相接串联连接，然后通过电抗L接入中压侧直流配网，模块的直流输出端分别独立输出，对应直流电压V11、V21、…、VN1。HFLI级则由N个完全相同的DAB子模块构成，其输出端的一端分别接到MDLI的直流端Vi1，另一端则并联在一起，然后直接接入低压微网。相对TDCT来说，NDCT增加了MDLI级，使得直流电容由集中式变为了分散式，并且SC子模块可以工作在旁路开关、直流断路器和电压变换等多种模式，带来了很多的技术优势。  

当中压直流配电网电压发生变化时，MDLI级可以工作在DC/DC变换模式，调节输出电压Vi1，使得HFLI级的高频链始终处于电压匹配状态，从而降低高频链环流和电力电子开关的电流应力，并提高系统的传输功率、效率和功率密度。当DAB子模块发生故障时，NDCT可以迅速旁路故障的子模块，其它模块仍可正常工作，从而提高了系统的可靠性。当发生直流配电网的外部故障时，NDCT可以工作在直流断路器模式，完全切断与直流母线的电气连接，而不需要增加额外的直流断路器。另外，由于直流电容没有放电，不会产生过电流，当故障消失后，不需要重新开始充电，可以快速的重新投入运行，提高了系统快速恢复的能力。

4.NDCT故障处理策略  

由上节的分析，NDCT可以始终保持HFLI级高频链的电压匹配状态，从而提高了装置的有功传输能力和功率因数，并很大程度上降低了由于环流造成的电力电子开关的电流应力和有功损耗。此外，在子模块故障时的冗余运行以及外部故障切除后的快速恢复方面，NDCT都表现了很大的优点。  

当子模块发生故障时，由于直流端存在集中电容，子模块不能被旁路，使得TDCT不能实现冗余运行，因此当子模块发生故障时，TDCT就必须退出运行，这很大程度上降低了装置的可靠性。由于增加的MDLI级，NDCT可以在旁路故障的子模块情况下继续运行，控制的逻辑如图6所示。

![](https://mmbiz.qpic.cn/mmbiz_png/w7mE225tvpPPLp8JsVZqcZ7DkibicAU2ib1KUYrrZ4TIQvt1NL1Fw7o9QRKYLzxCmx0YVCz784NMQX80WYrYibHiclNEN9mOplBQAgybclVP6ichs/640?wx_fmt=png&from=appmsg)

图11为子模块发生瞬时性故障旁路运行，故障延时消除并恢复运行时的电压和电流波形。其中：iT1、iT2和iT3分别为各DAB高频链的电流；VLV和ILV分别为低压微网侧的电压和电流。开始时，NDCT工作在N=3稳态运行状态，在t4时刻模拟DAB3发生瞬时性故障，DAB3瞬时被旁路，NDCT切换至级联数为N-1=2的运行方式，DAB1和DAB2的传输功率增大，DAB3的传输功率变为0，低压侧电压和电流经暂态过程很快达到新的稳态，且新稳态的电压和电流和故障发生前一致。在t5时刻模拟DAB3瞬时性故障恢复，DAB3重新投入运行，NDCT切换至级联数为N=3的运行方式，DAB1、DAB2和DAB3的传输功率恢复到故障发生前的数值，低压侧电压和电流经暂态过程也很快达到新的稳态，且新稳态的电压和电流和故障发生前一致。

5.3效率分析试验

![](https://mmbiz.qpic.cn/mmbiz_png/w7mE225tvpOanlEwKqSIcjLf7tJ2cOs3oBOGe6KmEVkSeQI19jd3G1BNq94eBxghmW0BcCO6FemreJQtaFlb1Ajh81bZeYkcKIXcoGvBhWE/640?wx_fmt=png&from=appmsg)

由前面的分析可知，NDCT相对于TDCT增加了MDLI级，从直观来说，这使得装置的导通损耗和开关损耗增加。但MDLI不仅增大了NDCT的输入电压范围，也使得HFLI级始终工作在直流电压匹配状态，这减小了电力电子器件的电流应力，提高了装置的功率因数，也降低了环流造成的导通损耗。综合考虑，如果MDLI级选用导通损耗较小的电力电子器件，且采用较低开关频率的调制方式，考虑到中压配网电压的波动，TDCT不可能一直工作在直流电压匹配状态，在全电压工作范围内，NDCT的效率有望和TDCT的效率相当或甚至更高。  

图12分别为级联数为N=2且中压配网电压300~400V时和级联数为N=3且中压配网电压400~600V时，NDCT和TDCT的效率特性比较。在N=2且VHV=400V和N=3且VHV=600V两种直流电压匹配状态时，TDCT的效率明显高于NDCT的效率，但当中压配网电压偏离匹配值时，TDCT的效率明显降低，而NDCT的效率在一定电压范围内基本保持不变，而且当中压配网电压偏离匹配值越多，NDCT的效率优势也越明显。试验的结果和前面的理论分析相吻合，也证明了理论分析的正确性。

6.结论  

本文提出了一种应用于中压直流配电的多电平直流链固态变压器方案，文中从拓扑结构、多电平直流链电压电流特性、功率和功率因数特性、控制策略和故障处理逻辑等多方面做了理论的分析。在此基础上，还搭建了3级串联的物理试验样机，给出了系统的实验分析结果，验证了理论分析的正确性。理论和实验分析均表明所提出的NDCT系统方案，不仅增加了输入电压的工作范围，降低了输入电流的纹波，也使得高频链始终工作在电压匹配状态，降低了电力电子器件的电流应力和导通损耗。此外，当DAB子模块发生故障时，NDCT可以有效的提供冗余运行，提高了装置的可靠性。本文的研究为中压直流配电网中直流固态变压器的提供了一种有效、实用的解决方案。
