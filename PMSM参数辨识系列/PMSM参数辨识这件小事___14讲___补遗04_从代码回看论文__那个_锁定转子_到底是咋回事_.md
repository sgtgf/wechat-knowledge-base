这一讲，咱们就来揭秘：**为什么要锁定转子？以及代码是如何巧妙地实现这一过程的？**

**一、为什么要“按住”电机？——创造一个理想的“手术台”**

在给病人做手术之前，医生第一件事是什么？**打麻药，让病人一动不动！**

给电机做参数辨识也是一个道理。如果我们想精确测量它的电感、电阻，最怕的就是它自己乱动。为什么？

**1\. 排除反电动势（Back-EMF）的干扰：**

-   **物理模型**上： 电机一转，它自己就会发电！这个“自己发的电”就是反电动势。
    
-   **数学模型**上： 回看论文的公式 (2.14) 和 (2.15)： 
    

![](https://mmbiz.qpic.cn/mmbiz_png/Z8Iha3NiaCRHkPOMKzNgibOxOeYvZ7E36bckpbaopLewcjB2uSGErk1QKZ85rHSugWySd4ShvawiaYWlzOdOpZNIA/640?wx_fmt=png&from=appmsg)  

看到那个 ωr 了吗？它就是电角速度。只要 ωr ≠ 0，电压方程里就会多出来好几项跟速度相关的“干扰项”。

-   **结论**是： 如果电机在转，我们测出来的电压就不只是电阻和电感上的压降了，还混了反电动势。这就像你在测一个人的体重，结果他身上还背着个大书包。这怎么测得准？
    
-   **所以，第一步，必须让 ωr = 0，也就是让电机静止！**
    

**2\. 转子位置（凸极轴）的固定：**

-   **物理模型**上： IPMSM 的电感像个椭圆。你从不同角度去看它，看到的“宽度”（电感值）是不一样的。
    
-   **数学模型**上： 我们要测的是 Ld 和 Lq，这两个值是在 **d-q 坐标系**下定义的。如果我们不知道 d 轴在哪，我们测出来的 Lxx 和 Lyy 就会随着转子的位置变来变去。
    
-   **结论**就是： 为了能准确分离出 Ld 和 Lq，我们必须把转子**固定在一个已知的角度上**。这样，我们测量的坐标系和电机的 d-q 轴之间就只有一个固定的夹角，我们才能通过特征分解把它算出来。
    

**因此**： “锁定转子”的目的，就是**创造一个干净、稳定、已知的测量环境，**排除掉“反电动势”和“转子位置变化”这两个最大的干扰源。

**二、代码是如何实现“锁定转子”的？—— 通过“磁力手铐”**

文末论文第 3.2 节提到：

> "a current in the d-direction of an arbitrarily selected d-q frame can be applied, and since the motor has no load the rotor will freely align to the applied current resulting in a known rotor position."

翻译成大白话就是：我在空间中随便定一个方向（比如 A 相方向），然后往这个方向通上直流电。电机里的永磁体（转子）就像一个指南针，它会自己转动，直到它的 N 极对准我这个人工磁场的 S 极。**一旦对准了，它就被“吸住”了，动弹不得！** 这就是“磁力手铐”。

-   `ramp_A`：这是一个从 `0` 慢慢增加到 `probe_current_hold` 的电流幅值。
    
    为什么要斜坡增加，而不是直接给个大电流？
    
    这是非常重要的工程实践！如果你瞬间给一个大电流，电机会“Duang”地一下猛地转过去对齐，产生巨大的机械冲击和电流过冲。用斜坡（Ramp）的方式，电流慢慢增加，转子就会平顺地、温柔地转到锁定位置，对电机和逆变器都更友好。
    

-   `i_track_D/Q`：这就是我们给电流环的目标指令值。比如 `probe_hold_angle` 是 0 度，那么 `probe_HOLD` 就是 \[1, 0\]，最终目标就是 `i_track_D = ramp_A, i_track_Q = 0`。这意味着我们命令电流环，在静止的 X 轴方向上，施加一个逐渐增大的电流。
    

**总结一下“转子锁定”过程：**

1.  **选定方向**： 软件工程师决定把电机锁在哪个角度（`probe_hold_angle`）。
    
2.  **下达指令**： 代码计算出这个方向上的单位向量。
    
3.  **温柔施加**： 电流环以斜坡方式，慢慢地在这个方向上建立起一个直流电流（`probe_current_hold`）。
    
4.  **转子对齐**： 电机转子像个指南针，自动旋转，直到它的磁场和我们施加的这个直流磁场对齐（通常是 d 轴，形成最小磁阻路径）。
    
5.  **锁定成功**： 一旦对齐，转子就被“吸”住了，一动不动。我们的“手术台”搭好了！
    

**三、学以致用：锁定转子后辨识参数的代码实现**

至此，我们已经成功地用“磁力手铐”（locking current）把电机给“按住”了，创造了一个完美的“手术台”。现在，电机静止不动，转子位置也固定了，我们可以开始真正的“体检”——**参数辨识**了。

**3.1 测量电阻 Rs：最朴素的欧姆定律，但加了点“佐料”**

通俗地讲就是，我不只测一个点的电压电流，我让电流从一个值慢慢变化到另一个值，一路上测好几组 U，I 数据。然后，我把这些点画在图上，用最小二乘法画一条“最完美的”直线。这条直线的**斜率**，就是最准的电阻值！

更详细的内容，请参考这篇文章：[《PMSM参数辨识这件小事》| 13讲：电阻的直线——Rs 与“那一点点偏置”](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247485081&idx=1&sn=4c4bd5c41a80b43a62f93caa99bff375&scene=21#wechat_redirect)

**3.2 测量电感 Ld，Lq：高频注入 + DFT + 特征分解的“三连击”**

测量电感就不能用直流了，因为电感的特性是 u = L·di/dt，必须有**电流变化**。

**文末论文和代码A的思路是**： 在直流锁定电流的基础上，叠加一个**高频的、旋转的**电压/电流“噪声”（激励），然后用我们第二讲学的 DFT 把高频响应“听”出来。

**四、全局图景：这套“自整定”到底有什么用？**

2.  **为高性能控制打下基础**
    

准确的 Rs，Ld，Lq 不仅仅能用来整定 PI，它们还是所有高性能控制算法的基石：

-   **FOC 解耦**： 电流环前馈解耦项（ωrLqiq 和 ωrLdid）需要准确的电感值。
    
-   **MTPA控制**： 计算最优的 id, iq 分配策略，严重依赖 Ld, Lq 和磁链 φm。
    
-   **弱磁控制**： 计算电压极限圆和电流极限圆的关系，同样需要精确的电感参数。
    
-   **模型观测器**： 无论是代码A里的 Ortega/Kalman 观测器，还是其他基于模型的无感算法，模型参数的准确性直接决定了估算精度。
    

**五、本文小结：从理论到实践的完美闭环**

我们来回顾一下文末论文和代码A中针对参数辨识的这套行云流水的操作：

-   **为什么要锁定？**为了创造一个 ωr = 0，转子位置固定的“理想手术台”，从而排除反电动势和转子位置变化的干扰。
    
-   **怎么锁定？**用 PI 电流环施加一个**斜坡上升**的直流“锁定电流”，把转子温柔地“吸住”并固定在某个方向。
    
-   **怎么测电阻？**在锁定状态下，通过改变直流电流大小，采集多组 (U, I) 数据，然后用**最小二乘法（LS）**拟合出 U = R·I + UOffset 这条直线的**斜率 R**，同时还能得到一个反映逆变器非线性的**截距 UOffset**。
    
-   **怎么测电感？**在直流锁定的基础上，叠加一个**旋转的高频电压激励**，用**同步DFT**精确提取出高频电压和电流的复数响应，然后用**LS**解出完整的**阻抗矩阵**，最后通过**特征值分解**，像“摆正照片”一样，直接读出电机的“真实三围”—— **Ld，Lq和凸极轴的角度**。
    

这整个过程，完美地体现了“**系统辨识**”的核心思想：

1.  **设计激励信号（Input Design）**：直流扫描用于测电阻，旋转高频正弦用于测电感。每种激励都是为了最大化地激发我们想测量的那个参数的响应。
    
2.  **数据采集与处理（Data Acquisition & Processing）**：使用同步DFT从强噪声中提取微弱信号，使用高精度累加（Kahan求和）保证数值精度。
    
3.  **参数估计（Parameter Estimation）：**使用数值稳定的最小二乘法（QR分解）来拟合模型，得到最可靠的参数估计。
