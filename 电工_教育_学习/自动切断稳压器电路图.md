# 自动切断稳压器电路图

这是一种保护电路，可保护电器免受高压损坏。该电路连接到稳压器的输出。当电压升高到所需的设定水平以上时，该电路将激活继电器，然后输出断开，不会有高压损坏的风险。电路简单易用。

使用 0-18v 或 9-0-9v 500ma 变压器。按照给定的图表连接所有组件。在正常供电下，继电器将处于停用模式，但当电压超过固定电压时，继电器将自动激活，继电器的 NO（常开）引脚将连接。将负载与继电器的 NC 引脚连接。

完成全部连接后，接通电源，并通过移动要设置的电压水平的预设来调整自动切断。使用最小值为 50v 的电容器，不应低于 50v，因为电路中有高压电源流动。如果您使用 12-0-12v 变压器，则使用 24v 继电器。

这是 Autocut 手动稳定器的另一个简单电路。在这个电路中，与第一个电路有细微的变化。如果您使用 12-0-12 变压器，则使用 24v 继电器。您也可以通过将 0-12 变压器与 12v 继电器连接来检查此电路。使用 500ma 至 1 A 变压器。
