# 1.电源电路的功能和组成

电子电路中的电源一般是低压直流电，先把220v交流电变换成低压直流电，再用整流电路变成脉动的直流电，最后用滤波电路滤除掉脉动直流中的交流成分后才能得到直流电。有的电子设备对电源的质量要求很高，所以有时还需要增加一个稳压电路。

#  因此，整流的组成一般有四大部分，見图①

图①，整流电路四大部分组成

見图①，首先需要一个变压器把高压电变成低电压电，需要介绍的是后面三种单元电路。

2.整流电路: 整流电路是利用二极管的单向导电性能，把交流电变成单向脉动直流电的电路。

  

#  ①半波整流: 半波整流电路只需一个二极管，見图②

![](D:\电脑文件\公众号知识库\电力电子_DC_DC变换器\常见电源基本电路详解_images\img_001_991d57de8c8e.png)

图②，半波整流电路

見图②，在交流电正半周时D导通，负半周时D截止，负载RL上得到的是脉动的直流电。

  

#  ②全波整流: 全波整流电路，可以看作是由两个半波整流电路组会成的。变压器次级线圈中间需要引出一个抽头，把次级线圈分成两个对称的绕组，从而引出大小但极性相反的两个电压e2a、e2b，构成e2a、D1、Rfz与e26、D2、Rfz，两个通电回路。

  

#  ③全波桥式整流: 用4个二极管组成的桥式整流电路可以使用只有单个次级线圈的变压器，見图③

  

![](D:\电脑文件\公众号知识库\电力电子_DC_DC变换器\常见电源基本电路详解_images\img_002_9649efa20a2f.png)

图③，全波桥式整流电路

  

#  ④倍压整流: 倍压电路主要功能是将整流后的电压峰值以数倍增加后输出。它常用在高电压，低电流的电源电路中(如灭蚊灯，捕鼠器等电子电路)，見图④

![](D:\电脑文件\公众号知识库\电力电子_DC_DC变换器\常见电源基本电路详解_images\img_003_017a8d55633a.png)

图④，倍压整流电路

#  3.滤波电路，整流后得到的是脉动直流电，如果加上滤波电路滤除脉动直流电中的交流部分，就得到平滑的直流电。

#  ①电容滤波电路: 把电容器和负载并联，如图①

![](D:\电脑文件\公众号知识库\电力电子_DC_DC变换器\常见电源基本电路详解_images\img_004_b96926707bf0.png)

图①，电容滤波电路

見图①，正半周时电容被充电，负半周时电容放电。就可以使负载上得到平滑的直流电。

#  ②电感滤波电路: 当通过电感线圈的电流增大时，电感线圈产生的自感电动势与电流方向相反阻止电流增加起保护作用，見图②

图②，电感滤波电路

③RC滤波电路: 用一个电感和一个电容组成的滤波电路，一般少用。
