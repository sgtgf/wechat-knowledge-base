## 十二、板书设计

```
通过直接代入法求极限一、核心公式若 f(x) 在 x=a 处连续，则：lim f(x) = f(a)x→a二、方法步骤1. 把 x=a 代入2. 看结果：   实数      → 极限值   0/0       → 不定型，先化简   非零/0    → 判断无穷或不存在三、常见可直接代入的函数多项式、三角函数、指数函数、对数函数有理函数：分母不为 0 时可以四、例题lim (x² - 5x + 2) = -4x→3lim (x+3)/(x²+1) = 1x→2
```

本节课的关键不是复杂计算，而是先判断函数是否连续、代入后是否得到合理的实数。直接代入法是求极限最基础、最常用、也最应该优先尝试的方法。
