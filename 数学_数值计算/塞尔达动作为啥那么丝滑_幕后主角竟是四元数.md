# 塞尔达动作为啥那么丝滑？幕后主角竟是四元数


> 原文地址: [https://mp.weixin.qq.com/s/TtSTJgA9HuXygUxWNfS3og](https://mp.weixin.qq.com/s/TtSTJgA9HuXygUxWNfS3og)

**熟悉《塞尔达传说》系列的玩家都深有体会。操控林克完成精准转身 凌空滑翔挥剑出招等炫酷动作，流畅质感至关重要。很多人却不知道造就这份丝滑体验的并非游戏魔法。有一种特殊的数学工具始终在底层默默发挥作用。它就是四元数**(Quaternions) 。

**1. 四元数简介**

复数可以完美刻画二维平面内的旋转变换。但数学家试图将复数体系直接拓展到三维空间时发现：不存在满足乘法封闭性的三维数系。

1843年，哈密顿在布鲁姆桥漫步时灵光乍现：放弃乘法交换律，额外引入一个新虚数单位，构建出由四个分量组成的四元数体系，从数学层面完美解决了三维空间旋转的表征难题。四元数的标准形式为：

![](https://mmbiz.qpic.cn/mmbiz_png/iagCqyDH0KskiapKlngmQn3U0WnlBicwpWTPFh73W02F4cPhZwwNrEQWbeI3AbavpC4rr4FhIMyCxvRb3TSScUEPytIwGXpMHHk8PablUjHgH4/640?wx_fmt=png&from=appmsg)

普通四元数很难直观看出几何内涵，但若将其分解为模长与单位四元数的乘积，几何意义便清晰明了。

不难推导，任意单位四元数都可表示为旋转轴与旋转角度的组合形式：

其中：θ是旋转角度；![](https://mmbiz.qpic.cn/sz_mmbiz_png/iagCqyDH0KsmrKSvTFeRrrhZNj95Q0eYRtOAJGdEuPSy1PbeQ6rnfxltnqSfwTR5MfsCgesbI30E58F3UVfKEAn7ACAwtwusW26CqKHQQSm4/640?wx_fmt=png&from=appmsg)是归一化的旋转轴方向（单位向量，定义了旋转的方向）。该公式揭示了四元数的核心价值：它是对三维旋转的整体性数学描述，仅靠四个分量即可同时封装旋转轴与旋转角度两大核心信息。

2. **四元数球面线性插值（Slerp）**

在《塞尔达传说》里，林克诸多丝滑转身、姿态切换的动作，本质都是游戏引擎在已知初始姿态和目标姿态之间做平滑插值过渡。玩家拨动右摇杆操控林克转向，就是最典型的应用场景。

游戏会先捕捉林克当下的身体朝向，作为初始姿态；再根据右摇杆的输入，算出需要偏转的角度与方位，生成目标姿态。而实现这一顺滑转动的核心，正是四元数球面线性插值（Slerp）。引擎通过该算法在初始四元数与目标四元数之间做球面插值，让林克的转身动作连贯自然、毫无生硬顿挫。相应的四元数插值公式为：

![](https://mmbiz.qpic.cn/sz_mmbiz_png/iagCqyDH0KsnjhTNT15j2NfKncJ3GFw6YcdCcvKuPLPwmceibGxHhaYCxZyMyIKzl844RBDyIotcFKEhuG8yKD7cj4icibmR0tBiaibd2aw7albNk/640?wx_fmt=png&from=appmsg)

注：Slerp适用于仅发生朝向偏转、无位置平移、无形体形变的纯刚体旋转；而掺杂了位置平移、模型缩放、肢体骨骼弯曲变形、整体位移行走等情况，一般需要结合普通线性插值来实现过渡。

3. **旋转矩阵插值**

有同学可能会好奇：对于刚体旋转，明明可以用更易理解的旋转矩阵来做插值，为什么游戏引擎偏偏要用四元数插值？

比如林克的初始姿态、目标姿态，完全可以分别用两个旋转矩阵![](https://mmbiz.qpic.cn/sz_mmbiz_png/iagCqyDH0Kslp3ExmNka6IL4hDZI1tfYFtryhpHlwRYJ8XpDA6qh7fBxCvrQB4LaABJ59xhpg2X6mkDoTtjAjichGpXiaClSbdVDqAAK8DnMoA/640?wx_fmt=png&from=appmsg)来描述。如果仿照普通数值的思路做过渡，很自然会想到对矩阵元素直接做线性插值：

![](https://mmbiz.qpic.cn/sz_mmbiz_png/iagCqyDH0Ksl3BLUpjkQFKFqgSLCiarcQjXNGdmGC9bo4aGJ47uBS2xlalqAA27hU4XPSQNJafmKNnxn3HE8xEH9vvehN435rMoiaFqDicubq0o/640?wx_fmt=png&from=appmsg)

但这里存在一个致命问题：两个合法旋转矩阵的线性组合，一般不再是合法的旋转矩阵。不仅会引发模型缩放、扭曲形变，违背刚体不可变形的物理特性，还会造成旋转角速度忽快忽慢，让人物转身动作显得生硬、不流畅。

聪明的同学马上想到了如下的解决方案：既然从![](https://mmbiz.qpic.cn/sz_mmbiz_png/iagCqyDH0KsmqjWzQC0eo45wYFoUtIdvSkxQkptrVXb9DsTwicBen2GPnptxoTLicpGe9sKdhJiaARHHr1ksBIS4IUone2jiaYf1pXpXoGrMictlM/640?wx_fmt=png&from=appmsg)到![](https://mmbiz.qpic.cn/mmbiz_png/iagCqyDH0Ksnbhj379cQ1pGyfzhl603jeaFJpe7pgiakcjWBdvSe3oMWHv0ehFTSuic65ubiazPHBZia3bQvicXBAruFvDjFjFyKRJbSafyH2IE2E/640?wx_fmt=png&from=appmsg)的相对旋转矩阵为![](https://mmbiz.qpic.cn/mmbiz_png/iagCqyDH0KslkQLr0WKKQwMjmmib050NBgdBoNys1iciaibnjv6icGXEcYxVyPuI9DhLg7HajP3sbpIXx28skcP13QFibNW1UrlKQK4nDLLWlfkvicM/640?wx_fmt=png&from=appmsg)，我们完全可以借助矩阵幂运算，实现从![](https://mmbiz.qpic.cn/sz_mmbiz_png/iagCqyDH0KsmqjWzQC0eo45wYFoUtIdvSkxQkptrVXb9DsTwicBen2GPnptxoTLicpGe9sKdhJiaARHHr1ksBIS4IUone2jiaYf1pXpXoGrMictlM/640?wx_fmt=png&from=appmsg)到![](https://mmbiz.qpic.cn/mmbiz_png/iagCqyDH0Ksnbhj379cQ1pGyfzhl603jeaFJpe7pgiakcjWBdvSe3oMWHv0ehFTSuic65ubiazPHBZia3bQvicXBAruFvDjFjFyKRJbSafyH2IE2E/640?wx_fmt=png&from=appmsg)的球面光滑插值过渡，即：

![](https://mmbiz.qpic.cn/sz_mmbiz_png/iagCqyDH0KslIACRm1fHKNvdFs6qTv6ZCFE9mVDOPrfMycD4mwRmq3oaV0fbSqr1q0g5vMOOVChGc89LQSH8voYj2E0Nna7pGpSzCb6jrYEQ/640?wx_fmt=png&from=appmsg)

这套矩阵插值方法，本质等价于如下李代数插值映射：

![](https://mmbiz.qpic.cn/mmbiz_png/iagCqyDH0Ksn3SDX27SpQOa8ice8pe0fhIY5r3icrmKe29jqp7liauGZKNIO1iaJ0QuR40bXZ2fh78YXKEgfWM5yia4Jm6NVXibZNPD3cmMVWJibz4A/640?wx_fmt=png&from=appmsg)

其核心思想是：李群上的球面非线性插值，等价于李代数上的线性插值。先通过对数映射将过渡旋转矩阵映射到李代数空间，进行线性比例缩放，再经由指数映射还原回旋转群。整个过程严格恪守旋转正交约束与刚体特性，既能做到姿态过渡无畸变，又能保证角速度均匀平稳。

4. **四元数插值的优势**

四元数Slerp插值公式完全可由旋转矩阵的李代数插值公式严格推导而来，二者本质是同一套旋转流形插值逻辑的不同数学表达。既然旋转矩阵依托李代数也能实现平滑无畸变的旋转插值，游戏引擎却依旧偏爱四元数，核心原因有三点：

第一，存储更精简。旋转矩阵需9个参数，四元数仅4个分量即可表征三维旋转，存储动画关键帧、角色姿态时更省内存。

第二，运算更轻便。姿态叠加、连续旋转等操作，四元数运算浮点开销远低于3阶矩阵相乘，实时渲染效率更高。

第三，数值维护更简单。浮点误差累积后，四元数只需一次归一化就能恢复合法旋转属性；旋转矩阵则要做复杂正交校正，繁琐且成本更高。

**结语**

从数学层面完美刻画三维旋转，到落地赋能游戏画面表现，四元数堪称藏在《塞尔达传说》背后名副其实的旋转大师。它以四个分量就能完整封装旋转轴与旋转角度，依靠Slerp球面插值，让林克的转身转向流畅自然；不仅如此，角色挥剑攻击的动作轨迹、自由视角下游戏镜头的环绕转动，乃至**游戏骨骼动画驱动、IK反向运动****求解、相机轨道旋转调校、人物凌空滑翔与空中姿态矫正**，底层全都依托四元数实现平滑旋转，全程杜绝生硬顿挫与卡帧感。

虽然旋转矩阵结合李代数理论，同样能完成无畸变的刚体旋转插值，但四元数凭借更少的参数存储、更轻量化的运算开销，在工程应用中优势显著。它简化了三维旋转的计算逻辑，成为开放世界游戏里姿态与镜头旋转算法的标配。

看似抽象的数学工具，默默撑起了游戏里细腻丝滑的动作与镜头体验。四元数既是简洁高效的三维旋转神器，更是隐藏在游戏画面背后，默默提升玩家游玩质感的数学英雄。
