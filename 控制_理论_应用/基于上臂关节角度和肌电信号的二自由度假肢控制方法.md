# 基于上臂关节角度和肌电信号的二自由度假肢控制方法

原创 自动化学报 2018-05-21 17:26 北京

> 原文地址: [https://mp.weixin.qq.com/s/BOqysbEJyjyJqnlq\_x2-Kw](https://mp.weixin.qq.com/s/BOqysbEJyjyJqnlq_x2-Kw)

**主动假肢**是指：自带驱动和能源，佩戴者能够通过诸如肌肉电信号，脑电信号等人机交互手段实现随意识控制的机电假肢系统。

![](基于上臂关节角度和肌电信号的二自由度假肢控制方法_images/img_000_f680dd3829a0.jpg)

机械式假肢

智能的主动假肢是未来的发展趋势。目前，市面上的假肢主要为被动假肢和功能比较简单的主动假肢，被动假肢是指通过机械式的绳驱动实现控制的假肢，其通过一根连接到佩戴者背部的绳索实现操作，因此该假肢功能单一，操作起来比较费力。而简单的主动假肢，指的是采用简单方法实现控制的假肢，这类假肢普遍仅采用基于肌电信号幅值实现的开关控制，就如同一个开关一样，当幅值超过阈值时开关打开，否则关闭。

![](基于上臂关节角度和肌电信号的二自由度假肢控制方法_images/img_001_f29931211ca8.jpg)

主动假肢

随着机械加工技术、集成技术等技术的高速发展，假肢也变得越来越精巧，功能、自由度也变得越来越多，但是人体能够提供给假肢的控制信息并没有跟上假肢机械结构的发展，因此如何利用人体的信息实现对多自由度假肢的控制成为越来越受到人们关注的领域，当然拓展人机交互信息量的脑机接口、神经接口等技术也在迅速发展，但是其离日常生活使用还是有很多的困难需要突破。

![](基于上臂关节角度和肌电信号的二自由度假肢控制方法_images/img_002_9feffbb66f01.png)

6个人进行三种不同的抓握时肩关节角度曲线，从图中可以看出三种动作能够明显区分

  

将上肢运动的运动学信息作为肌肉电信号控制假肢的辅助控制源。目前，运动学信息作为控制源的控制方法在下肢假肢上取得了广泛的应用，通过惯导模块配合足底压力能够准确地判断人体在步行中所处的相位，使得下肢假肢能够配合人体的行走步态。但是，同样的方法在上肢假肢上却难以应用，这是因为人体下肢的运动具有明显的周期性，而上肢的运动却是以被抓取的物体为导向的，这使得上肢运动变化多样，周期性不明显。虽然上肢运动变化多样，但是上肢的运动中也蕴含了大量对控制假肢有意义的信息，只是这些信息利用起来不那么直接而已，得益于近些年来机器学习技术的高速发展，利用信号时可采用端到端的方式，而不用过多考虑信号背后的物理意义。我们通过人体抓握最后手腕的方向，将抓握过程中肩关节的动作分为三类，分别对应掌心向上，掌心向下以及掌心直立，也就是人们常采用的托、提和横向抓取三个动作，这三个不同的动作在肩关节角度变化上有明显的区别，这样通过肩关节的运动可以控制手腕的运动，相比于只利用肌电信号，这种控制方式对于佩戴者的抓握体验有明显的提升，我们利用单位时间内试验者对物体的抓握次数评价方法对抓握体验的提升效果。
