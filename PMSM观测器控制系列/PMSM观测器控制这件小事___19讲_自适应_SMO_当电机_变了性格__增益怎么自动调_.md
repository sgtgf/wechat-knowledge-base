去年十一月，你在实验室调好了一台压缩机的 SMO 参数。K = 800（代码里的归一化标幺值，不是 800 V 的物理电压），边界层 Φ = 0.05，低通滤波器切在 500 Hz。电机在 20°C 的空调房里跑得稳，位置误差压在 2° 以内。

到了七月，客户现场的微信群里开始炸锅。同一套代码，同一台电机，温升之后角度估计飘到了 8°，电流环开始抖动。

你远程排查了一周，示波器上的波形怎么看怎么不对劲。最后让客户测了一下绕组温度——78°C。定子电阻 Rs 从 0.35 Ω 涨到了 0.42 Ω。

电机没变，参数变了。你的增益 K = 800，是给"那个人"调的，不是给"这个人"用的。

这就是固定增益观测器的死穴。它假设电机模型永远和你推导时一样，可现实中温度在变、磁饱和在变、负载在变。增益一旦写死在代码里，电机"变了性格"的那天，观测器就会跟着翻车。

自适应 SMO 要做的，就是让增益学会"察言观色"——工况变，增益跟着变。

## 固定增益的舒适区，只有一瞬间

经典 SMO 的开关项长这样：

K 是个常数。你冬天花了一下午扫参，找到 800 这个"最适宜参数"：抖振不大，跟踪不慢。但这个最适宜参数的前提是 Rs = 0.35 Ω，电感 L 没饱和，反电势模型和你推导时用的完全一致。

夏天 Rs 涨了 20%，电流模型的"斜率"变了。同样的 K = 800，在升温后的电机眼里，要么太软（滑模面外推不动，估计值懒洋洋地跟在真实值后面），要么太硬（进了边界层还在猛冲，抖振炸开）。

你当然可以每个季节重新扫一遍参，但这不现实。客户现场可没有实验室里的空调。更麻烦的是，磁饱和还会让 L 随负载电流变化——负载从 20% 拉到 80%，L 可能掉 10%。

说白了，固定增益的观测器，像一把只开定焦的镜头。对焦距离对了，画面清晰；距离一变，全盘模糊。

自适应 SMO 的思路，就是给这把镜头装备上自动对焦的功能。

## 相机自动光圈怎么就知道该开多大？

各位同仁用过相机的 A 档吗？

光线暗的楼道里，相机自动把光圈拧到 f/1.8，孔径大开，进光量拉满。到了正午的户外，同一台相机默默把光圈收到 f/16，孔径缩成针眼，防止画面过曝。

全程不需要你动手。相机内部有个测光表，实时评估环境亮度，然后指挥光圈叶片调节开孔大小。

但，这跟我们的 SMO 有什么关系？

**光圈孔径 = 增益 K(t)**。孔径大（高增益）= 收敛快，但景深浅（抖振大）。孔径小（低增益）= 抖振小，但进光少（收敛慢）。

**环境亮度 = 工况指标**。可以是电流误差 |ĩ| 的大小，也可以是转速的高低，或者是负载突变的剧烈程度。

**测光表 = 自适应律**。一条简单的数学规则，告诉增益该增大还是减小。

固定增益的问题，相当于你把相机永远锁在 f/5.6。阴天刚好，正午过曝，晚上黑屏。自适应 SMO 要做的，就是让增益像光圈一样，根据"亮度"自动呼吸。

这里有个关键区别得说清楚。咱们 [第16讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486604&idx=1&sn=f221f7e9a9ba7e4a05ca6e2daf3f474c&scene=21#wechat_redirect) 和 [第17讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486609&idx=1&sn=fcfc3e44b3c0a835bd3b2e00a59d7b1d&scene=21#wechat_redirect) 的边界层法（sat、sigmoid），相当于给镜头装了个手动调焦环——你可以拧，但拧到一个位置就固定了。自适应 SMO 的 A 档，是测光表在实时指挥叶片开合，你手指根本没碰镜头。

## 第一种自适应：误差大时自己"睁大眼"

最简单的自适应律，是让增益和电流误差的幅值挂钩 \[S-003\]。

电流误差大，说明估计值离真实值还远，这时候需要大力出奇迹：

K₀ 是基准增益，像光圈的最小档位，保证基本的抗扰能力。γ 是自适应系数，决定增益对误差的"敏感度"。|ĩ| 是电流误差的绝对值，相当于测光表读到的"亮度"。

误差大的时候，|ĩ| 大，K(t) 自动胀大，观测器"睁大眼"，快速把估计值拽回真实值。误差收敛后，|ĩ| 趋近于零，K(t) 缩回到 K₀，观测器"眯起眼"，避免在稳态时抖振。

量纲上要注意：u\_switch 直接作为电压修正项注入电流模型，所以 K 的单位是 **V**（不是 V·A⁻¹）。

代数形式 K(t) = K₀ + γ·|ĩ| 中，γ 的单位是 **V/A**。微分形式 Ḱ = γ·|ĩ| - λ·(K-K\_min) 中，右边整体单位必须是 V/s，所以 γ 的单位是 **V/(A·s)**，λ 的单位是 **s⁻¹**。

这个系数不是拍脑袋定的，后面会讲怎么调。

你可以把它写成积分形式，记忆历史误差：

## 第二种自适应：转速变了，增益也得跟着换挡

另一种思路不跟误差走，而是跟转速走 \[S-006\]。

但要注意：转速和增益的关系不是"转速高就增益小"这么简单。不同工况下，转速对增益的需求方向可能完全相反。

**高速跟踪型**（S-006 的做法）：高速电机跑到 10,000 rpm 时，反电势的变化率 ∝ ω²，固定增益 STA 跟不上这种剧烈变化。\[S-006\] 把超螺旋 STA 的两个增益都和转速挂钩：

**低速补偿型**（另一种常见思路）：低速区反电势幅值小，ADC 量化噪声相对突出，信噪比差。这时候也可以把增益设计成随转速反比变化——转速越低，增益越大，用来"放大"微弱的有效信号。

两种策略瞄准的是不同痛点。高速跟踪型解决的是**动态跟踪能力**，低速补偿型解决的是**信噪比**。你不能把口诀记成"转速高就增益小"或者"转速高就增益大"——得先问自己：我的电机瓶颈在哪？

\[S-006\] 选择了高速跟踪型。效果很直观：固定增益 STA 在 4000 rpm 处的位置误差约 1.14 rad（~65°），换成变增益 VGLSTA 后"显著降低"。更夸张的是，把自适应反电势优化和 ESO-PLL 也叠上去之后，稳态位置误差从 1.74° 掉到了 0.0005°——这个极致精度是多项改进叠加的结果，变增益是其中关键的一环。负载突变时，固定增益 LSTA 转速掉下去就再也回不来，VGLSTA 能在 0.41 秒内恢复。

## Lyapunov：证明自动光圈不会乱调

读到这里，各位同仁心里可能有个疑问：增益自己变来变去，系统不会发散吗？

不会。自适应律不是拍脑袋写的，它是从 Lyapunov 稳定性理论里"长"出来的。

η 是个正数。这个不等式说明：只要滑模面 σ 还没到达零，能量就在泄漏。最终 σ 会被压到零附近，系统进入滑模状态。

注意这里证明的是**误差有界收敛**，不是"增益一定收敛到某个真实最优值"。自适应增益 K(t) 会稳定在一个有界范围内，但具体稳态值取决于初始条件、噪声和扰动上界，不一定是某个确定的 K\*。就像相机的自动光圈：环境稳定后光圈会停在一个合适的档位，但这个档位不一定是理论上最完美的那个，只是够用了。

当然，上面的推导是连续域的理想情况。离散化之后，采样噪声和模型误差会让 V̇ 不完全满足这个不等式。持续激励条件不足时，增益还可能在某个区间里来回晃荡。这就涉及到后面要讲的坑了。

通俗来讲，Lyapunov 证明的就是：测光表不会发疯。环境暗了它开大光圈，亮了它收小，但它永远不会把光圈拧到镜头外面去。

## 伪代码：把自动光圈写进 ISR

理论讲完，看看代码怎么写。以下是在 FOC 主循环 ISR 中的实现框架。

基于误差幅值的自适应（对应第一种策略）：

`// 经典 SMO 电流估计（α 轴）   float i_est_alpha = ...;          // 上一时刻估计值 + 模型递推   float i_err_alpha = i_est_alpha - i_alpha;   // 电流误差      // 自适应增益（积分形式，K 本身是状态变量）   static float K = K0;              // 初始化时设为 K0   float abs_err = fabsf(i_err_alpha);   K += (gamma * abs_err - lambda * (K - K_min)) * DT;      // 限制范围   if (K > K_MAX) K = K_MAX;   if (K < K_min) K = K_min;      // 开关输出，sign(0)=0 防漂移（第18讲过的教训）   float sign_err = (i_err_alpha > 0.0f) ? 1.0f :                     ((i_err_alpha < 0.0f) ? -1.0f : 0.0f);   float u_switch = -K * sign_err;      // β 轴同理`

基于转速的变增益（对应第二种策略，STA 框架）：

`// 估计转速（从 PLL 或反正切输出获得）   float N_est = ...;                // rpm 或 rad/s      // 转速函数 f(N_est)，线性形式   float f_N = 1.0f + a_gain * fabsf(N_est) / N_RATED;      // STA 两项增益   float Z1 = sigma1 * f_N;          // 快速收敛项   float Z2 = sigma2 * f_N * f_N;    // 积分记忆项      // STA 输出   float sqrt_err = sqrtf(fabsf(i_err_alpha));   float u1 = -Z1 * sqrt_err * sign_err;        // 第一项   static float u2_integral = 0.0f;   u2_integral += -Z2 * sign_err * DT;          // 第二项（积分）   float u_sta = u1 + u2_integral;               // STA 总输出`

然后用 g\_e 去乘 STA 的基准增益，例如统一调度因子 h = g\_e · f(N̂\_est)，令 Z₁ = σ₁ · h。注意 Z₂ 也要同步调整——STA 的收敛条件要求 Z₁ 和 Z₂ 保持特定比例关系（回顾 [第18讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486614&idx=1&sn=3b99c2b3b1736b43b5474ef24d2ffd17&scene=21#wechat_redirect) 的 Levant 条件），不能单独调 Z₁ 而不管 Z₂。简单做法是让 Z₂ = σ₂ · h²，保持两项的耦合比例。这样误差和转速两个维度都参与了增益调节，而且量纲干净，相当于相机同时测光和对焦，光圈和快门联动。

执行时间方面，\[S-003\] 在 TMS320F28379D 上估计整个观测器算法（含自适应增益）小于 50 μs，控制周期 100 μs，留了 50% 裕量。浮点乘法开销很小，但 sqrtf 的周期数取决于编译器优化和 FPU 实现，具体需以编译结果和 cycle 计数实测确认。

## 三个坑：自动光圈也不是万能的

### 坑 1：γ 过大，增益会发疯

自适应系数 γ 像积分器的输入增益。调太大，一个小误差就能让 K(t) 瞬间飙到 K\_MAX，观测器进入"过曝"状态，抖振炸裂。

更隐蔽的是稳态时的测量噪声。数字 ADC 有量化误差（12 位 ADC 约 ±1 LSB），这个噪声让 |ĩ| 永远到不了真正的零。γ 大的时候，噪声会被放大成增益的剧烈震荡。

调参顺序：先固定 K₀ 到一个保守值，把 γ 从零开始慢慢往上加。观察到抖振开始变大的时候，往回退 20%。

### 坑 2：λ 太小，增益 WIND-UP

积分形式的自适应律里，λ 是衰减系数。如果 λ = 0（纯积分），稳态噪声会让 K\_integrator 持续单向爬升，最后顶到 K\_MAX 天花板。这和 PID 积分 WIND-UP 是一个毛病。

λ 的选取原则：让衰减时间常数 τ = 1/λ 与系统动态响应时间**相当**——瞬态时增益要跟上误差变化，稳态时又要及时回落。具体说，如果电机从 0 加速到额定转速需要 0.5 s，λ 可以取 2-5 s⁻¹，对应 τ = 0.2-0.5 s，和加速时间同一个数量级。τ 太长（λ 太小），增益回落慢，稳态抖振下不来；τ 太短（λ 太大），误差还没收敛增益就先衰减掉了，自适应形同虚设。

### 坑 3：自适应和参数辨识别一起开

有些同仁会想：既然增益能自适应，那我同时在线辨识 Rs，岂不是双保险？

危险。增益自适应和参数辨识（比如 RLS 在线估 Rs）是两条独立的反馈回路。增益变的时候，电流模型的"参考线"在变；同时 RLS 也在改模型参数。两个回路互相干扰，可能导致谁都不收敛。

工程上不是说绝对不能同时开，而是需要谨慎。\[I-001\] 里有把 IAORLS 参数估计和 STA-SMO 组合的方案，证明这条路走得通。但前提是要做三件事：第一，时间尺度分离——参数辨识的时间常数要比增益自适应慢 5~10 倍；第二，限幅——两条回路都加饱和，防止互相冲击；第三，冻结条件——瞬态过程中先冻结参数辨识，等增益稳定了再让辨识启动。不做这些隔离，两条回路互相踢皮球，系统大概率发散。

说白了，自适应 SMO 不是让观测器变得更聪明，而是让它承认一件事：我不知道明天的电机是什么性格，但我可以今天看着它的脸色调。

固定增益是"以不变应万变"——好听，但容易翻车。自适应增益是"随机应变"——多几个参数，多一分活着的底气。
