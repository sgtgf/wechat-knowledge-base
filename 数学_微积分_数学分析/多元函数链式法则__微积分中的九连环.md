# I 概述

多元函数的链式法则（Multivariable Chain Rule）看起来公式繁多、符号复杂，但它的核心思想其实非常直观，用八个字就能概括：**“分路追踪，求和汇总”**。

为了让你最轻松地攻克这个概念，我们可以从一个生活中通俗的例子出发，然后总结出一套万能的“看图写公式”法则。

### 二、 万能法宝：依赖树与“口诀”

在实际学习中，变量的关系可能会极其复杂（比如中间有3层变量，底层有4个自变量）。只要画出**依赖树（Dependency Tree）**，并记住两句口诀，任何复杂的公式都能瞬间写出来。

#### 1\. 画树状图

从顶层的**目标变量**开始，向下连线到**中间变量**，最后连到底层的**自变量**。

#### 2\. 两句黄金口诀

-   **上下相乘（链式传导）：** 沿同一条分支从上往走，每经过一条连线，就把对这条线的导数**乘**起来。
    
-   **左右相加（多路汇总）：** 只要能从顶层走到你指定的目标自变量，把所有可行路径的结果**加**起来。
    

#### 3.  与  怎么分清？（偏导 vs 全导）

记住一个超级简单的规则：**“单选 ，多选 ”**

-   从某个节点往下看，如果它**只有一条向下**的分支，说明它只依赖一个变量，用直写 （全导数，如 ）。
    
-   如果它**有多条向下**的分支，说明它同时依赖多个变量，用弯写 （偏导数，如 ）。

# 一、整张图究竟在讲什么？

这张图是【概述】的具象化，所谓“一图胜千言”，我们通过图形能更好的理解**多元函数的链式法则**。

它的核心思想只有一句话：

> 当最外层的量通过多条“依赖路径”受到某个变量影响时，  
> 每条路径上的影响要相乘，不同路径的影响要相加。

可以把它记成八个字：

> **沿路相乘，异路相加。**

图中反复出现的“依赖树”，就是用来帮助我们找出所有路径，防止漏项。

# 十六、最终记忆图景

可以把多元链式法则想象成一张“影响网络”。

每条边上的导数表示：

> 下面这个量变化 1 个单位，会让上面那个量变化多少。

沿一条路线，影响一层一层传递，所以要乘：

局部影响局部影响

多条路线同时对结果作出贡献，所以要加：

路线的影响路线的影响

因此，整张图片最重要的结论就是：

沿路径相乘，所有路径相加

用公式表示：

所有从到的路径该路径上所有导数的乘积

这就是多元链式法则最统一、最直观的理解。
