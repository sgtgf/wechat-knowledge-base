## 墙壁开关太硬，调光器刚好

各位同仁，想象一下你家客厅有两套照明系统。

一套是老式墙壁开关。啪一声，灯全亮；再啪一声，全灭。没有中间状态。开关动作的瞬间，电流从 0 冲到额定值，灯丝猛地一热，偶尔还会闪一下。如果你以极快的速度反复按这个开关，灯不会稳定发光，而是不停闪烁——因为灯丝有热惯性，跟不上你手指的速度。

另一套是调光器。旋钮从 0 拧到 100，亮度渐变。你想开 30% 的亮度，它就真的给你 30%。没有突变，没有闪烁。

SMO 的 sign 函数，就是那个墙壁开关。边界层法，就是给系统装一个调光器。

在 sign 的世界里，误差 s 只有两种命运：正或负。控制器输出的推力恒定为 ±K\_slide，要么全力往左推，要么全力往右推。误差刚过零点的那一瞬间，推力立刻翻转——这就是抖振的源头。

边界层的思路很简单：**在零点附近挖一个"渐变区"**。误差小的时候，不要全力推，按比例推。误差大的时候，该出力还是全力出。

## 边界层内外，两个不同的世界

把 sat 拆成两段来看，你会更清楚它在干什么。

**饱和区（|s| ≥ Φ）：一切照旧**

当误差大到超出边界层，sat 的输出就是严格的 ±1，和 sign 没有区别。观测器方程里的校正项还是 -K\_slide/L\_s 或 +K\_slide/L\_s，满格推力，全力把状态往滑模面方向压。

换句话说，**边界层不是把 sign 扔了，而是给它加了一个"减速带"**。只有在接近目的地的时候，系统才松油门。

引入边界层后，情况变了。当状态进入线性区，推力不再是恒定的 K\_slide/L\_s，而是与 s 成正比。状态不会再以固定速率"冲过头"，而是越接近滑模面越慢。

工程上的保守判断是：**边界层的存在把抖振振幅的上限"钳"在了 Φ 附近**。原因很直观——当状态从滑模面向外漂，一旦漂到 |s| ≈ Φ，系统立刻退回饱和区，满格推力把它往回压。Φ 就像一个围墙，状态很难冲出去太远。

**Φ 小于 |Δs|\_sign 时，边界层形同虚设。** 状态绝大部分时间在线性区外面振荡，sign 的行为主导一切。

## 边界层厚度 Φ 怎么选

Φ 不是算出来的最优值，是"试"出来的妥协值。但它的选择有明确的工程上下限。

**下限：鲁棒性约束**

这里有两个层级的"增益"需要分清楚：

-   • **切换项增益**：，单位 V/A。这是 sat 函数本身的斜率，决定 z\_a 随 s 的变化有多快。
    
-   • **电流误差动态增益**：，单位 1/s。这才是真正决定电流误差 s 收敛速度的——它直接进入观测器方程，决定 ds/dt 的量级。
    

各位同仁调 Φ 的时候，心里该算的是 ，不是 。后者只是中间变量。如果  太低（也就是 Φ 太厚），状态在边界层里蜗牛爬，响应当然迟钝。

扰动从哪里来？参数失配（R\_s 温漂、L\_s 饱和）、电压重构误差（死区、管压降）、ADC 零漂、电流采样噪声。这些可以等效为一个"扰动电压" d\_v（单位 V）。

在饱和区边缘（s = Φ），推力恢复到满格 K\_slide，足以对抗任何 |d\_v| < K\_slide 的扰动——这和 sign 完全一样。

问题在于线性区内部。如果扰动把状态推到边界层内某个位置 s，此时的推力是 K\_slide·(s/Φ)。推力随着 s 减小而减小。

这里有个关键的工程直觉：**线性区本身不负责维持鲁棒性，鲁棒性是靠边界层边缘的 sign 行为"兜底"的**。当扰动把状态推出边界层，sign 接管，满格推力把它压回来。线性区的作用是"柔化"接近滑模面的过程，不是"替代"sign 的鲁棒性。

所以鲁棒性下限的判据不是"线性增益必须大于扰动"——量纲都对不上——而是：**边界层不能厚到让状态在扰动下长时间在线性区内挣扎出不来**。

工程上，Φ 可先取 sign 估算振幅的 1~3 倍作为调试起点。先算 |Δs|\_sign，然后从 Φ ≈ |Δs| 开始往上试。

**上限：抖振容忍度**

Φ 越大，线性区越宽，抖振越小。但上一条说了，Φ 太大，状态在扰动下在线性区里"滑行"太久，响应变慢，角度估计出现低频摆动。

低频摆动比高频抖振更难处理。高频抖振可以被 LPF 滤掉一部分，低频摆动几乎可以无损穿过 LPF ，直接污染角度估计。

工程上可先把额定电流的 10%~20% 作为警戒线，超过这个范围要格外谨慎——你牺牲的可能不只是鲁棒性，还有系统的整体稳定性。最终以负载突变和角度误差验证为准。

**实操流程**

1.  1\. 先用 |Δs| ≈ (K/L)·T\_s 估算 sign 的抖振幅值
    
2.  2\. 设初值 Φ = |Δs|（或略大一点，如 1.2×|Δs|）
    
3.  3\. 上机跑，看 z\_a 波形：从方波变成"梯形波"或"三角波"，说明边界层在起作用
    
4.  4\. 逐步加大 Φ，每次增加 20%~30%
    
5.  5\. 观察两个信号：相电流毛刺（应该减小）和负载突变时的角度跟踪（不能明显变差）
    
6.  6\. 当角度跟踪开始变差时，回退一档，这就是你的 Φ 上限
    

## 代码里怎么改

边界层的实现简单到令人发指。核心就是把 `sign()` 换成 `sat()`。

`// 示意用示意：饱和函数在 SMO 中的替换   float sat(float s, float phi) {    if (s > phi)       return 1.0f;    if (s < -phi)      return -1.0f;    return s / phi;   }      // 观测器 ISR 中的切换项   float s_alpha = i_alpha_est - i_alpha;           // 电流误差，单位 A   float z_a = K_slide * sat(s_alpha, phi);         // 切换项输出，单位 V      // 观测器电流方程中的校正项   float correction = -z_a / L_s;                   // 单位 A/s      // LPF 提取等效控制   float e_alpha_est = lpf(z_a, alpha);             // 单位 V`

各位同仁注意代码里的符号约定：和 [第14讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486575&idx=1&sn=fe3185fabee5ccffc85fbb321318e41b&scene=21#wechat_redirect)、[第15讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486583&idx=1&sn=07efedecbfa99de3ffdf9e03ffa1aafc&scene=21#wechat_redirect) 中提到的对应内容保持一致，`z_a = K_slide * sat(s_alpha, phi)`，观测器方程中注入的是 `-z_a / L_s`。这个负号确保当估计电流大于实测电流（s > 0）时，校正项把估计电流往下拉。

`sat()` 函数只有三行：两个 `if` 处理饱和区，一个除法处理线性区。运算量通常不是主要瓶颈——现代 MCU 上除法可能多花几个时钟，但和整个 FOC 运算相比可以忽略。资源紧张的 MCU 可考虑预计算  避免运行时除法。

有个实现细节值得提：如果 `phi` 设得特别小（比如接近 0），`s/phi` 可能溢出或产生极大值。工程上建议加下限保护：

`// 边界层厚度下限保护   #define PHI_MIN (0.05f)   // 根据电机额定电流调整   float phi_clamped = phi;   if (phi_clamped < PHI_MIN) phi_clamped = PHI_MIN;   float z_a = K_slide * sat(s_alpha, phi_clamped);`

这个保护的意义是：防止在参数在线切换或误操作时，Φ 意外变成零或极小值，导致 `s/phi` 数值爆炸。

## 三个容易掉进去的坑

**坑 1：边界层不是死区**

死区（dead zone）的定义是：当 |s| < Φ 时，输出为零——系统完全不动。边界层的定义是：当 |s| < Φ 时，输出按比例减小——系统还在动，只是动作更温柔了。

如果你把 sat 写成了死区，滑模面附近的状态会失去驱动力，在边界层内自由漂移。等效控制提取失真，角度估计出现随机偏移。死区是 bug，不是 feature。

检查方法：在 `sat()` 的线性区分支里，确认返回值是 `s/phi` 而不是 `0.0f`。

**坑 2：边界层不是越厚越好**

有些工程师一看抖振小了，就继续加大 Φ，心想"反正效果这么好，再大一点岂不是更安静"。

问题在于：Φ 太大时，等效增益 K\_slide/Φ 太低。负载突变时，状态要穿越整个线性区才能到达饱和区获得满格推力。这个穿越过程可能长达几个甚至十几个采样周期。

在这段时间里，角度估计在低频摆动，Park 变换坐标系歪来歪去，q 轴电流指令跟着抖，电机发出低沉的"嗡嗡"声——这不是高频啸叫，是低频振荡，更难处理。

判断标准：如果加大 Φ 后，相电流的**高频**毛刺小了，但出现了**低频**包络摆动，说明 Φ 过厚了。

**坑 3：边界层内用线性反馈，不等于回到 Luenberger 观测器**

Luenberger 观测器是全程线性反馈。边界层法只有在线性区内是线性反馈，一旦状态被扰动推出边界层，立刻切回 sign 的非线性满推力。

这个区别至关重要。Luenberger 对参数失配和扰动的抵抗能力有限，因为它的增益是固定的、有限的。边界层法保留了 sign 的"兜底"能力——大误差时它就是不讲道理的开关。

不要把边界层法理解为"用线性观测器替代 SMO"，它理解成"给 SMO 的开关加了一个柔化区"更准确。

## 示波器上怎么看边界层起没起作用

调试现场，你需要对比 sign 和 sat 的波形差异。

**第一步：看 z\_a 的形状**

sign 的 z\_a 是方波，±K\_slide 之间硬翻。引入边界层后，z\_a 变成了"梯形波"或"三角波"——在 ±K\_slide 之间有一个倾斜的过渡区。

过渡区的斜率反映边界层厚度。Φ 越薄，过渡区越陡，接近方波；Φ 越厚，过渡区越平缓，接近三角波。

如果你看到的 z\_a 还是方波，没有过渡区，说明 Φ 太小，系统绝大部分时间在饱和区 oscillate。

**第二步：量 s\_alpha 的振幅**

sign 时 s\_alpha 的振幅约等于 |Δs|\_sign ≈ (K/L)·T\_s（需通过 DAC 或高速日志导出后观察）。引入边界层后，振幅应该被限制在 Φ 附近或以下。

如果振幅仍然明显大于 Φ，说明状态频繁穿越边界层，边界层效果不佳。考虑加大 Φ 或检查是否有其他噪声源。

**第三步：看 LPF 后的 e\_est**

边界层的目标是减小 LPF 后的残留纹波。如果边界层生效，e\_alpha\_est 的"毛刺"应该比 sign 时明显减少，波形更"圆润"。

但要注意：e\_est 太"圆"、峰值明显低于实际 BEMF，说明 LPF 截止频率可能同时太低了——边界层的改善和 LPF 的滞后可能混在一起。建议一次只调一个参数，先固定 LPF，只调 Φ。

**第四步：负载突变对比**

用同样的负载突变（比如从空载突加 50% 负载）对比 sign 和 sat：

-   • sign：角度估计快速跟上，但伴随高频抖振
    
-   • sat（Φ 合适）：角度估计跟上速度略慢一点点，但后续稳态抖振明显减小
    
-   • sat（Φ 太厚）：角度估计跟上明显变慢，甚至出现低频回弹
    

这个对比实验是验证 Φ 选得是否合理的金标准。

## 这笔账到底该怎么算

边界层法不是给 sign 打补丁，而是重新分配了鲁棒性预算。

sign 把全部预算花在理论上的"无限增益裕度"上——任何误差都满格推力，鲁棒性拉满，但抖振也拉满。

边界层法把预算拆成两半：

-   • **大误差时（饱和区）**：预算全部释放，鲁棒性和 sign 一样
    
-   • **小误差时（线性区）**：预算按误差比例释放，抖振减小，但小扰动的抵抗能力下降。具体表现是：恒定扰动下会留下与 Φ 成正比的稳态残余误差——sign 可以通过高频切换让等效控制自适应到精确抵消扰动的值，sat 在线性区内做不到这一点。
    

换句话说，你不是在"升级"SMO，而是在"调整 SMO 的性格"。从"不管对手多弱都全力出击"的莽夫，变成"看情况出力"的老手。

这个调整有明确的适用边界：

-   • **适合用边界层**：负载相对平稳、参数漂移可控、对噪声容忍度低的场景（如家电中的风机、水泵）
    
-   • **不适合厚边界层**：负载突变剧烈、参数漂移大、对角度精度要求极高的场景（如注塑机、CNC、机器人关节）
    

对于后者，如果抖振确实不可接受，边界层最多只能设得很薄（Φ 略大于 |Δs|\_sign），配合其他手段（如 Sigmoid、Super-Twisting）使用。

最终判断还是那句话：

**先保证鲁棒性下限，再拿剩下的空间换安静。顺序不能反。**
