# 消元不改变体积：高效计算的秘诀

## 心智锚点

高斯消元的每一步——"某一行减去另一行的倍数"——是一次剪切变换。

剪切变换把正方形变成平行四边形，但面积不变。把立方体变成斜棱柱，但体积不变。

**消元是等体积变换。行列式在消元过程中恒定不变。**

这个事实直接给出了行列式的高效计算路径。

## 现实映射

**等价变换思维的核心法则：寻找不改变目标量的等价操作，用这些操作简化计算。**

-   消元不改变行列式 → 用消元简化矩阵。
    
-   旋转不改变距离 → 用旋转简化坐标。
    
-   重新编码不改变信息量 → 用高效编码压缩数据。
    

**找到"守恒量"，然后利用守恒性质选择最简的计算路径。这就是数学家的优化策略。**
