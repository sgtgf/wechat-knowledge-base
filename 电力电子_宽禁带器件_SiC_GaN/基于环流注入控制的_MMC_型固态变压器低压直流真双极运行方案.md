# 基于环流注入控制的 MMC 型固态变压器低压直流真双极运行方案


> 原文地址: [https://mp.weixin.qq.com/s/VPCia2ITsGFMQl4rNMhnfQ](https://mp.weixin.qq.com/s/VPCia2ITsGFMQl4rNMhnfQ)

文章来源：中国电机工程学报

作者：张建文 1，周剑桥 1，施刚 1\*，王晗 1，冯欣 1，蔡旭 1，黄华 2，赵乐 2(1．电力传输与功率变换控制教育部重点实验室(上海交通大学)，上海市闵行区 200240； 2．华东电力试验研究院有限公司，上海市虹口区 200437) 

摘要：多端口固态变压器(solid state transformer，SST)是多电压等级交直流混合配电网的核心设备。模块化多电平(modular multilevel converter，MMC)型SST 可构建中压交流、中压直流和低压直流等端口，其中压直流端口可接入中压直流配电网及构成多区域交流配电网的柔性互联，从而提升区域网络间功率灵活调节能力。对于低压侧，具有不平衡运行能力的真双极直流母线能够满足低压用户对多电压等级、供电可靠及用电安全等需求，而常规的MMC-SST 仅能提供单极或伪双极低压直流端口。因此，文中提出一种真双 极型MMC-SST 拓扑及基于主动环流注入的桥臂电压平衡优化运行方案，该结构同时具备中压交流、中压直流及低压真双极直流等端口。文中的主要工作包括：简述真双极型MMC-SST 连接方式，并基于能量平衡原理，探索低压真双极运行工作机理；建立基于环流的动态模型，揭示双极不平衡功率、桥臂电容电压及环流之间的耦合关系；基于环流注入的稳态模型，获得基于主动环流注入的桥臂电压平衡运行方法，并优化注入环流的幅值和相位；提出基于环流主动注入的桥臂电容电压平衡控制策略。最后，搭建2MVA的MMC-SST仿真模型及4.8kVA 的MMC-SST 实验样机，验证所提拓扑及控制的可行性和有效性。  

关键词：模块化多电平换流器；固态变压器；真双极低压直流；主动环流注入  

0 .引言  

随着分布式电源的不断渗透，储能、电动汽车及可控负荷等的大量接入，以分布式电源为核心的多元化分布式电力供应系统将改变配电网的现有形态，并对配电网的功率可控性、运行灵活性、供电可靠性等方面提出了更高需求。而基于固态变压器的交直流混合配电架构，为本地用户与分布式电源提供中低压可控交直流端口，从而极大提升配电系统控制及设备接入的灵活性，是未来配电网的重要发展方向之一。  

中压固态变压器(solid state transformer，SST)主要为级联H 桥型SST(cascaded H-bridge type  SST，CHB-SST)与模块化多电平型SST(modular  multilevel converter type SST，MMC-SST)等拓扑结构。CHB-SST 适用于电力牵引场合，取代传统的工频变压器+变换器结构，提升装置功率密度与效率。相对于CHB-SST，MMC-SST 可提供中压直流端口，具有更为灵活的组网方式，适用于交直流混合配电系统，实现多网互联与潮流互动。而针对低压直流用户，文献\[8\]提出了真双极型直流微网架构，相比于单极结构，具有不平衡运行能力的真双极直流系统具有如下优势：为直流源荷提供不同等级的直流电压；单极故障时不影响另一极的运行；可采用TN 及TT 型接地方式，保障人身安全。 因此，低压真双极直流能满足配电复杂多样的应用 需求。而MMC-SST 仅提供单极或伪双极直流端口。

真双极型直流系统的关键在于如何解决双极不对称运行下的功率平衡问题，常见的方案如图1所示：方案A 采用两套独立运行的装置分别接入正负极直流线路，以实现双极解耦运行，其常见于高压直流输电应用，但是两套装置将增加成本与占地空间。方案B 则在单极直流线路上加装电压平衡器，一方面是将单极转换为双极直流母线；另一方面是转移双极之间的不对称功率，以维持双极电压的稳定。由文献\[13\]可知，电压平衡器可采用非隔离型双向DC/DC 变换器，如Buck/Boost/  Buck-Boost 等多种拓扑，但是同样需要增加额外的设备，亦会对系统的成本、维护和保护都带来一定的影响。

因此，本文提出一种具有中压直流及低压真双极直流端口的MMC-SST 设计方法，利用MMC 丰富的能量路径和控制的灵活性，以实现双极不对称功率的平衡，与方案A、B 相比，无需增加变换器装置或电压平衡器。本方法通过改变MMC-SST 的连接方式，且在MMC 侧主动注入优化的正序基频环流，以转移上下桥臂间的不平衡功率，保证桥臂之间电容电压平衡的同时，实现低压直流侧双极不对称运行。

文中主要工作包括：  

1）提出真双极型MMC-SST 连接方式，分析低压真双极运行工作机理；  

2）建立基于环流的动态模型，揭示双极不平衡功率、桥臂电容电压及环流之间的耦合关系；  

3）构建基于环流的稳态模型，提出基于主动环流注入的上下桥臂电压平衡控制及注入环流的幅值和相位优化方法；  

4）提出基于环流主动注入的上下桥臂电容电压平衡控制策略。

最后，通过搭建2MVA 的MMC-SST 仿真模型以及4.8kVA 的小功率MMC-SST 实验样机，验证了所提拓扑及控制的可行性和有效性。  

本文的创新点包括：  

1）提出一种真双极型MMC-SST 拓扑，可在双极负载不对称工况下稳定运行；  

2）建立真双极型MMC-SST 的动稳态数学模型，分析了不对称功率对MMC-SST 稳态运行性能的影响；  

3）设计一种基于环流注入控制的真双极型MMC-SST 运行方案，并通过选取环流相位，实现最小环流注入，从而消除桥臂间子模块电容电压偏差，优化装置的稳态运行性能。  

1. 真双极型 MMC-SST 拓扑及能量平衡

![](D:\电脑文件\公众号知识库\电力电子_宽禁带器件_SiC_GaN\基于环流注入控制的_MMC_型固态变压器低压直流真双极运行方案_images\img_001_6e3021a1a755.png)

本文所提出的真双极型MMC-SST 结构如图2 所示。MMC 侧可接入中压交流(MVAC)和中压直流(MVDC)配电网；采用隔离型双向DC-DC(isolated  bi-directional DC-DC converter，IBDC)模块和MMC子模块(submodule，SM)的直流侧级联，实现电压变换、功率传递和电气隔离等功能，本文所述的IBDC 以双有源桥(dual active bridge，DAB)为例；MMC 上下桥臂所级联的DAB 输出侧分别并联，形成正极低压直流(P-LVDC)及负极低压直流母线(N-LVDC)。  

真双极型MMC-SST 具有以下特点： 

1）具有MVAC、MVDC、LVAC 和真双极LVDC共4 类交直流端口。 

2）低压直流通过内联MMC 的多个DAB 单元并联形成，其和中压交流网间的功率交互不受中压直流侧故障的影响，保障了低压用户侧的供电可靠性。 

3）各SM 和DAB 形成一个独立的模块单元，便于生产制造，通过冗余模块配置，该多模块结构可提高装置的运行可靠性。  

 4）功率模块和高频变压器(HFT)数目众多，控制系统较为复杂，且拓扑的成本、体积较高；可根据设计需求，灵活采用多电平子模块方案与多绕组变压器方案，从而大幅降低模块数量，提高装置功率密度，实现装置的轻型化与集成化。

![](D:\电脑文件\公众号知识库\电力电子_宽禁带器件_SiC_GaN\基于环流注入控制的_MMC_型固态变压器低压直流真双极运行方案_images\img_002_b32789138bcc.png)

图2 所示的 MMC-SST 为一种四端口变换器，其端口间的功率交互关系如图3 所示。假设P\_LVDC、N\_LVDC 与MVDC 3 个直流端口输出功率分别为P1、P2、P3，忽略MMC-SST 内部损耗，则MVAC 端口需提供总功率为Pε=P1+P2+P3。在常规的MMC控制方案下，MVAC 端口功率将均分到上下桥臂，并由桥臂将功率传递至中、低压直流侧。由图3 中黑色箭头所表示的功率走向可知，由于上下桥臂连接不同极低压母线，双极负载功率不对称时，即P1≠P2 时，上下桥臂的输入输出功率不平衡，桥臂内部能量发生变化。由下节的分析可知，此时上下桥臂电容电压之间将出现偏差，MMC 自然产生不可控无功环流，恶化桥臂侧电流、电压应力和运行损耗，双极功率不对称度高时，甚至影响MMC-SST 的稳定运行。  

因此，在双极不对称运行时，需要维持上下桥臂的功率均衡和子模块电容电压恒定。常见的上下桥臂功率均衡控制采用子模块调制波的直流分量进行调节，但是在双极运行极度不平衡时，将引起子模块的过调制，尤其在MMC-SST 应用中桥臂直流电流为零的工况，无法通过直流分量进行调节；采用如图3 中的红色箭头所示的解决方案，通过主动环流功率控制的方法进行MMC-SST 上下桥臂之间的功率转移，并优化主动注入的环流的相位，可降低环流幅值和避免过调制。因此，本文提出一种基于环流主动注入的优化方案，以实现在低压直流双极不对称运行时保持桥臂间功率均衡和子模块电容电压恒定。  

2. 真双极型 MMC-SST 环流分析与设计  

由第1 节分析可知，LVDC 双极不对称功率将会影响桥臂间能量平衡，进而恶化MMC-SST 的运行，需通过基频环流注入以解决桥臂间的功率交互。因此，本节将深入分析主动环流注入的机理，并优化环流参数。首先，建立基于环流的动态方程，阐述双极不平衡功率、桥臂电容电压及环流之间的耦合关系；随后，基于环流回路方程的稳态分析，提出主动环流注入的方法，以消除无功环流，且平衡电容电压；最后，优化注入环流的幅值和相位，减少运行损耗。

6. 结论  

本文提出了一种具备中压交流、中压直流、低压直流真双极端口的MMC-SST 结构，并针对LVDC 真双极中不对称运行所导致的MMC 上下桥臂功率不均衡问题，提出了一种主动环流注入的控制方案，并分析运行原理、建立环流方程、设计控制策略、仿真和实验验证，主要结论如下： 

1）真双极型MMC-SST 在保有中压直流端口的前提下，可通过基频环流主动注入，实现低压直流端口真双极不对称运行，和现有方案相比，不需额外装置或外接电压平衡器；且该正序环流不影响端口间的功率交互。 

2）建立动态方程，揭示了环流、电容电压、不对称功率三者间的交耦关系，分析了无主动环流注入时自平衡下的运行特性，可知不对称功率将会恶化装置的性能，甚至无法维持装置的正常运行。 主动环流注入后，可平衡上下桥臂间电容电压，消除无功环流，实现真双极不对称运行。 

3）基于环流注入的稳态方程分析，控制注入的基频环流相角与桥臂电压一致，可实现环流优化注入，降低了系统损耗。并提出了基于桥臂间电容电压平衡的环流主动注入双闭环控制策略，实现了真双极型MMC-SST 的优化运行控制。
