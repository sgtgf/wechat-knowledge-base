# 什么是矩阵的特征多项式


> 原文地址: [https://mp.weixin.qq.com/s/xSTX9z43uRnmaexEjyvykA](https://mp.weixin.qq.com/s/xSTX9z43uRnmaexEjyvykA)

矩阵的**特征多项式**（characteristic polynomial）是线性代数中一个非常重要的概念，它就像是给矩阵“做基因检测”——通过一个多项式，就能找出矩阵的“特殊行为模式”，也就是它的**特征值**（eigenvalues）。

### 通俗比喻：矩阵像一台“变形机器”

想象一个矩阵A是一台神奇的机器，它能把一个向量（比如一个箭头）变成另一个向量。  
大多数向量被丢进去后，会被拉伸、旋转、扭曲，方向和长度都变了。

但总有一些特殊的向量，它们被机器处理后，**方向完全不变**（或者只反向），只是长度被整体缩放了λ倍。这种特殊的向量叫**特征向量**（eigenvector），而那个缩放倍数λ就叫**特征值**（eigenvalue）。

数学上描述这个现象的方程是：  
**A v = λ v**  
其中v是特征向量，λ是特征值。

要把这个方程整理成能求解的形式，就需要引入**特征多项式**。

## 四、为什么叫“多项式”

因为 det(A−λI) 最后一定会变成一个关于 λ 的 n 次多项式。

如果 A 是 n×n 矩阵，那么它的特征多项式的次数就是 n。

例如：

-   2×2 矩阵 → 二次多项式
    
-   3×3 矩阵 → 三次多项式
    
-   n×n 矩阵 → n 次多项式

-   |λ| > 1 的方向会爆炸式增长；
