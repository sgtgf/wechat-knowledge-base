# 复向量空间 

它要表达的核心思想其实很简单：

> 我们以前在线性代数里大多把向量写在实数域  上；  
> 现在把“数”从实数换成复数，就得到 **复向量空间**。

也就是说，原来是“实数做标量”，现在变成“复数做标量”。

# 四、这说明了什么几何意义

在实平面里，旋转  会把任何非零实向量都“拐弯”，所以找不到一个方向只被拉伸、不被转向。

因此没有实特征向量。

但到了复空间里，向量的“方向概念”更丰富了，复数乘法本身就带有“旋转 + 缩放”的效果。  
于是原本在实空间里解释不了的旋转，在复空间里就可以解释成：

> 沿某个复方向，被乘上  或 

而乘上  的几何意义，就是“旋转 ”。

这就把“旋转矩阵没有实特征值”的现象，统一解释进了复数框架里。
