# 数据驱动的可靠性评估与寿命预测研究进展:基于协变量的方法

原创 自动化学报 2018-05-07 17:22 北京

> 原文地址: [https://mp.weixin.qq.com/s/0s\_afIXG1ATUeUidlxV7jw](https://mp.weixin.qq.com/s/0s_afIXG1ATUeUidlxV7jw)

![](数据驱动的可靠性评估与寿命预测研究进展_基于协变量的方法_images/img_000_6137672e6a6f.png)

数据驱动的可靠性评估与寿命预测是指：通过对系统运行状态数据的检测和建模，推导出被监测系统在未来时间段内的性能退化规律，从而提前进行维修和替换，以避免灾难发生。

![](数据驱动的可靠性评估与寿命预测研究进展_基于协变量的方法_images/img_001_3b364d59814c.png)

现代装备的复杂程度越来越高，造价越来越贵，同时这些“大国重器”对系统可靠性的要求也十分苛刻。这类装备一旦出现故障，轻则造成巨额经济损失，重则引发亡人事故。例如，2010年4月发生在墨西哥湾的原油漏油事故，就是由于“深水地平线”钻井平台发生爆炸时，最后一道安全防线-防喷阀的失效，造成原油不断冒出，多名工作人员失去了生命，当地大量生物死亡，对生态环境造成了永久性的破坏。

![](数据驱动的可靠性评估与寿命预测研究进展_基于协变量的方法_images/img_002_99c8f18336d2.jpg)

“深水地平线”钻井平台发生爆炸

目前，许多装备的维修与管理还依靠传统的“经验式”方案，即按照制造商提前制定的方案进行部组件替换保养。但是制造商给出的意见往往过于保守，从而引起诸如维护保养成本高、间隔短等问题。据统计，各类行业在维修中的投入占到生产总成本的15%~70%，因此维修活动安排及维修资源管理的不当，将会影响整个生产过程并造成浪费。

![](数据驱动的可靠性评估与寿命预测研究进展_基于协变量的方法_images/img_003_261670fdecd9.jpg)

泄露原油造成海鸟死亡

对于这类随机退化系统，如果能在其性能退化的初期，尤其在尚未造成重大危害时，根据监测信息，及时发现异常或定量评价系统健康状态、估计系统的剩余使用寿命（即当前时刻到系统失效时刻的有效时间间隔），并据此确定对系统实施维护的最佳时机，对于切实保障复杂系统的运行安全性、可靠性与经济性具有重要的意义。

**如何进行系统的可靠性评估与寿命预测？**目前，寿命预测方法主要分为两大类：基于失效机理分析的方法和基于数据驱动的方法。基于失效机理分析的方法需要研究人员对系统的失效物理有充分的理解，但是随着科学技术的发展和进步，现代工业过程、生产制造系统、航空航天系统、军事装备等现代化水平不断的提高，系统的复杂性和不确定性也随之增加，难以建立准确的机理模型。基于数据驱动的方法则完全根据数据统计得出规律，从而建立模型推导剩余寿命，因此不受到系统复杂度的影响，从而为上述系统的可靠性评估与寿命预测提供了可行的途径。

基于协变量方法的数据驱动寿命预测同其他类型数据驱动方法的区别在于：协变量方法不仅考虑部组件性能指标的退化，还同时监测系统的运行环境数据。基于协变量的寿命预测方法认为系统的退化会受到运行环境的影响，在处理退化数据时不同的运行环境变量应该区别对待。因此，本文根据现有文献，总结了基于三类不同状态的协变量寿命预测方法：固定协变量模型、时变协变量模型、随机协变量模型。

固定协变量模型主要应用于协变量固定不变的情况，其主要包含：

1）比例风险模型(Proportional hazard model, PHM)

2）分层比例风险模型(Stratified proportional hazard model, SPHM)

3）两步退化模型(Two-step regression model, TSRM)

4）加性风险模型(Additive hazard model, AHM)

5）加速失效时间模型(Accelerated failure time model, AFTM)

6）扩展风险退化模型(Extended hazard regression model, EHRM)

7）比例优势模型(Proportional odds model, POM)

时变协变量模型能够处理协变量为时变函数的情况，其主要包括：

1)比例强度模型(Proportional intensity model, PIM)

2)Logistic回归模型(Logistic regression model, LRM)

3)比例协变量模型(Proportional covariate model, PCM)

4)威布尔比例风险模型(Weibull proportional hazard model, WPHM)

5)显式风险模型(Explicit hazard model, EHM)

随机协变量模型中协变量为随机过程，其主要包括：

1)泊松振动模型

2)Markov随机模型
