# I 概述

### 深入浅出：普朗歇尔定理 (Plancherel Theorem)

要通俗易懂地理解普朗歇尔定理，我们可以先从一个生活中的物理直觉出发，然后再将其升华到更为严谨的数学结构中。

#### 1\. 直观理解：数学世界中的“能量守恒定律”

想象你正在听一段音乐。要衡量这段音乐蕴含的“总能量”，你有两种完全不同的观察视角：

-   **时域视角（看波形）：** 你可以记录每一微秒的声波振幅，把所有这些振幅的平方加起来。这就像是看着示波器上的波形起伏来计算能量。
    
-   **频域视角（看频谱）：** 你也可以通过均衡器（EQ）来观察，看看低音、中音、高音分别有多强，然后把各个频率成分的能量加总。
    

**普朗歇尔定理的核心结论就是：这两种方式计算出的总能量必定完全相等。** 用一句话概括：**信号在时域中的总能量，等于其在频域中的总能量。** 傅里叶变换只是改变了我们观察信号的“坐标系”，但绝不会凭空创造或消灭信号的能量。

在平方可积函数空间 （这是一个完备的内积空间，即希尔伯特空间）中，函数的“能量”本质上就是该函数在空间中的**范数的平方**，即 。

这意味着，傅里叶变换本质上是希尔伯特空间  上的一个酉算子 (Unitary Operator)。 你可以把傅里叶变换想象成无穷维空间中的一次“完美旋转”。当你把一个物体（函数）在空间中旋转时，它的坐标（具体表达式）完全改变了，但它的长度（范数/能量）以及它与其他物体的夹角（内积）保持绝对不变。

# 普朗歇雷尔定理（Plancherel Theorem）

**一个函数在时域里的“总能量”，等于它在频域里的“总能量”。**

说得更直白一点：

-   你把一个信号看成“随时间变化的波形”，可以计算它有多少能量；
    
-   你也可以把这个信号变成“由各种频率组成的频谱”，再计算这些频率成分加起来的总能量；
    
-   **最后算出来，完全一样。**
    

这就是图里反复强调的核心思想：  
**Energy Conservation（能量守恒）**。

# 六、把整张图压缩成一句最核心的话

就像：

-   一个向量可以用直角坐标表示
    
-   也可以用旋转后的坐标表示
    

两种表示不同，但对象是同一个。

> 整体看几乎一样，而不是每个点都完全一样。
