# 前言

> 生活中有各种频率的信号，如果像漏筛一样过滤不必要的，保留需要的，在电子学中称为滤波

  

# 为什么要滤波？

比如如果要录制声音的时候，声音往往是伴随着噪音的，如何能去除噪音呢？

![](D:\电脑文件\公众号知识库\电磁兼容_EMC\秒懂滤波_images\img_002_4db102d898d1.jpg)

这时候就需要有滤波器来滤除不必要的噪音

  

# 如何滤波？

根据电容有隔直通交的特性，便可搭建一个滤波电路

![](D:\电脑文件\公众号知识库\电磁兼容_EMC\秒懂滤波_images\img_003_b92fa718d5d3.jpg)

  

高通滤波器（只有频率高的信号才能通过）

![](D:\电脑文件\公众号知识库\电磁兼容_EMC\秒懂滤波_images\img_004_c16093df1949.jpg)

  

这里提到了增益（输出和输入之比）

  

假如增益为70%，输入为 10V的交流电，输出就是 7V的交流电

![](D:\电脑文件\公众号知识库\电磁兼容_EMC\秒懂滤波_images\img_005_afd3524433b1.jpg)

  

如图所示，为增益的幅频特性

![](D:\电脑文件\公众号知识库\电磁兼容_EMC\秒懂滤波_images\img_006_70b4eef40004.jpg)

  

可以看出，频率越低，增益就越小，反之亦然

  

当增益为1时，输入等于输出

![](D:\电脑文件\公众号知识库\电磁兼容_EMC\秒懂滤波_images\img_007_fda90ac99d81.jpg)

  

容抗的计算公式如下

![](D:\电脑文件\公众号知识库\电磁兼容_EMC\秒懂滤波_images\img_008_5f0c385a3065.jpg)

  

显然当频率为0时，容抗无穷大，反之亦然

  

只要频率高，容抗就低，容抗低，信号就可以通过（这就是高通滤波器）

![](D:\电脑文件\公众号知识库\电磁兼容_EMC\秒懂滤波_images\img_009_baa630943fe3.jpg)
