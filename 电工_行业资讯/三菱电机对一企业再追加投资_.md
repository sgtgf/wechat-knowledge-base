# 三菱电机对一企业再追加投资！

原创 电机新视界 2024-06-07 17:00 上海

> 原文地址: [https://mp.weixin.qq.com/s/fkhsskDCTnvd6ciIV6\_nIQ](https://mp.weixin.qq.com/s/fkhsskDCTnvd6ciIV6_nIQ)

**来源：维科网智能制造**

近日，三菱电机(Mitsubishi Electric，TOKYO: 6503)宣布将增加对位于美国马萨诸塞州的Realtime Robotics公司的投资。该公司是一家美国初创公司，正在开拓计算轨迹的运动模拟技术，使工厂自动化（FA）设备能够避开障碍物并生成优化路线。   

  

![](D:\电脑文件\公众号知识库\电工_行业资讯\三菱电机对一企业再追加投资__images\img_001_53f3e579ff5f.other)

  

通过扩大Realtime Robotics的先进技术在三菱电机FA解决方案软件产品和控制系统设备中的应用，双方希望进一步加强制造现场自动化生产的数字化和优化。自2019年5月三菱电机首次投资Realtime Robotics以来，两家公司一直在推动Realtime的运动规划技术与三菱电机的工业机器人之间的技术合作。

  

![](D:\电脑文件\公众号知识库\电工_行业资讯\三菱电机对一企业再追加投资__images\img_002_24890b0ccb80.other)

  

据新闻稿指出，三菱电机正在努力转型为“循环数字工程公司（Circular Digital-Engineering Company）”，其FA系统业务正在投资并与软件公司合作，以加强设计、制造、测试、运营和维护等多样化制造流程的自动化和数字化，最终为客户提供一流的产品和解决方案。

  

据悉，通过股份增持，三菱电机计划进一步将Realtime的尖端运动规划技术集成到3D模拟器和其他软件中，以通过数字孪生（digital twins）的力量优化制造。之后，三菱电机还希望将Realtime的技术整合到FA控制系统设备中，如可编程逻辑控制器（PLC）、伺服电机和计算机数控系统（CNC），以通过响应扩展自动化功能的需求，确保工厂不间断运行，简化工厂操作以提高效率并快速响应意外事件。

  

**01**

**关于Realtime Robotics**

Realtime Robotics，自2016年3月11日由布朗大学机器人学教授George Konidaris联合创立以来，便致力于为制造业、物流和其他行业提供前沿的机器人技术与解决方案。如该公司通过研发具有开创性特点的产品，如风险感知驾驶、高效多机器人工作单元以及自动校准的机器人视觉等，持续推动自动化技术的进步。   

  

Realtime Robotics的核心技术在于其RapidPlan处理器解决方案。这一创新技术为机器人自动化领域带来了显著的效益。RapidPlan的一大亮点在于其无碰撞自主运动规划功能。该技术能够有效避免机器人碰撞，并极大减少了手动耗时调整的需求。这不仅提高了自动化操作的效率和有效性，而且显著缩短了设置和管理的时间，为企业节省了大量的人力和物力成本。

  

此外，RapidPlan还简化了机器人编程过程，使其速度比传统方法快五倍。这一创新使得机器人编程更加高效便捷，降低了技术门槛，促进了自动化技术的普及和应用。

  

![](D:\电脑文件\公众号知识库\电工_行业资讯\三菱电机对一企业再追加投资__images\img_003_464242e89ea3.other)

  

资料显示，Realtime Robotics的合作伙伴包括宝马、舍弗勒、西门等知名企业，甚至其技术也被集成在ABB、电装、发那科、川崎、库卡、三菱电机、优傲、安川电机等品牌的机器人产品中。

  

该公司自成立至今，共完成3轮融资，轮次走到B轮，已披露筹集金额超4580万美元（约3.3亿人民币），股东中不乏Toyota Ventures（丰田风投）、上汽投资、SPARX Group等知名机构。  

  

![](D:\电脑文件\公众号知识库\电工_行业资讯\三菱电机对一企业再追加投资__images\img_004_d909b0331296.png)

  

公司CEO彼得·霍华德（Peter Howard）曾在三菱有长达12年的工作经历，曾担任三菱商事项目经理、Tri-M Technologies创始人兼董事总经理、SM2E创始人兼首席执行官，与三菱渊源颇深。

**02**

**三菱电机强化自动化领域收购**

三菱电机株式会社在自动化领域的投资布局进一步扩大，通过一系列有针对性的收购活动，显著增强了其在全球工业自动化市场的软件开发能力和市场份额。

  

Iconics（美国标志软件）的软件产品在全球超过100个国家得到了广泛应用，累计实现超过35万次的软件应用。三菱电机通过收购Iconics，不仅获得了先进的软件开发技术，还扩大了其全球市场覆盖范围。

  

据悉，三菱电机自2011年起便开始了对美国工业自动化软件开发商Iconics（美国标志软件）的收购之路。经过多年的增持，该公司已完全收购Iconics，使其成为三菱电机旗下100%控股的子公司。Iconics专注于制造业、工业和建筑领域的自动化市场，提供SCADA、物联网、移动、分析和云软件产品。此次收购将进一步整合Iconics的软件开发技术与三菱电机的工厂自动化技术，共同提升在边缘计算等领域的软件实力。

此后，三菱电机于2023年6月宣布全资收购Iconics UK。Iconics UK是Iconics在英国的产品经销商，同时经营着一家SaaS和云应用程序开发公司。这一收购将进一步增强三菱电机和Iconics在工厂自动化领域循环数字工程业务的软件开发能力，为三菱电机在欧洲市场的业务拓展提供有力支持。   

  

此外，三菱电机还收购了Realtime Robotics的部分股权。Realtime Robotics是一家专注于开发运动规划技术并推进其项目商业化的初创型公司。通过收购Realtime Robotics，三菱电机旨在加速工业机器人系统的研发，推出更安全、更高性能的解决方案。Realtime Robotics的实时运动规划解决方案Rapid Plan处理器解决方案，以其每秒30帧的速度和高达80万次动作的能力，为三菱电机的工业机器人系统提供了强大的技术支持。

  

业内专家表示，三菱电机通过这一系列收购活动，不仅加强了其在自动化领域的软件开发能力，还进一步巩固了其在全球工业自动化领域的领先地位。
