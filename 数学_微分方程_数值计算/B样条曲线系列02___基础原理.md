# B样条曲线系列02---基础原理


> 原文地址: [https://mp.weixin.qq.com/s/0NjTBQRDQQJRvZ4PHKBwPQ](https://mp.weixin.qq.com/s/0NjTBQRDQQJRvZ4PHKBwPQ)

一般来说，大家通常会从贝塞尔曲线引入B样条曲线，但我觉得没必要，读者只要知道B样条曲线的性能最好，在很多场景下(比如移动机器人的的轨迹拟合等)都需要它，直接从控制点权重的角度来理解更方便。当然如果想再深入弄清楚其来龙去脉，再返回去理解也可以。

**一、****控制点、节点与次**

因为生成曲线，本质上就是在**控制点前增加一个权重**，然后**累加即可**。那么B样条中权重是如何计算的呢？在理解B样条曲线之前，有几个概念需要理解。

**控制点**：也就是控制曲线的点， n+1 个控制点,![](https://mmbiz.qpic.cn/mmbiz_png/RGhGOXAMG415E8SGDfj4SjYENK0ENcpWlbibDm8rZlEcF4OGkJibFVZtGsMGBDP9ltqxHn1RJGdT5fXLicnfZ4E1Q/640?wx_fmt=png&from=appmsg).

**节点**：人为将目标曲线分为若干个部分，其目的就是尽量使得**各个部分有所影响但也有一定独立性**，这也是为什么B样条中，有时一个控制点的改变，不会很大影响到整条曲线，而只影响到局部的原因。节点划分影响到权重计算。假设我们划分了 m+1 个节点![](https://mmbiz.qpic.cn/mmbiz_png/RGhGOXAMG415E8SGDfj4SjYENK0ENcpWSrejwNI8kKSbInM8IEW0aiaaUAEMNg9KlSxQbEHlOdgRJwOJvZjt5aw/640?wx_fmt=png&from=appmsg)。

**次与阶** ：次即权重中参数t 的最高幂次。而 阶=次+1。假设我们用 k 表示次，即 k 次。

![](https://mmbiz.qpic.cn/mmbiz_png/RGhGOXAMG415E8SGDfj4SjYENK0ENcpWcNkiclMQIBSPCuhgquedYxo6MbCDnNbjDicpibcCmC2fdCDIkEXXv2Icw/640?wx_fmt=png&from=appmsg)

上图中的控制点个数 n + 1 = 5, n = 4, 即![](https://mmbiz.qpic.cn/mmbiz_png/RGhGOXAMG415E8SGDfj4SjYENK0ENcpWS5DJA4VkFo1zcSf9yapVf5g6QEnPHFQmSjLDJMLsWZLQWvJEKZp8vg/640?wx_fmt=png&from=appmsg)。

节点个数为m + 1 = 10, m = 9, 即![](https://mmbiz.qpic.cn/mmbiz_png/RGhGOXAMG415E8SGDfj4SjYENK0ENcpWcnZyicZaYDotRCqzbicbTHESm0t4ibKPk3907BBmhKv0LyaLuvH7DtLfw/640?wx_fmt=png&from=appmsg)。该节点将目标曲线分成m = 9 份，t 取值一般为 0-1的一系列非递减数。如 0 代表起始位置，1 代表末位置，0.5 代表一半的位置。 等分的节点表为，

![](https://mmbiz.qpic.cn/mmbiz_png/RGhGOXAMG415E8SGDfj4SjYENK0ENcpWmj4jiccFMsEicv2BlmS3iaM77Via649yoZkSTO43TwoodewSZMRxcFDq8Q/640?wx_fmt=png&from=appmsg)

次为 k 。必须要满足的关系式为 **m = n + k + 1**， k = m − n − 1 = 4。
