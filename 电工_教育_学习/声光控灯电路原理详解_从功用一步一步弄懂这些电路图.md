# **电路图之一**

  

![](D:\电脑文件\公众号知识库\电工_教育_学习\声光控灯电路原理详解_从功用一步一步弄懂这些电路图_images\img_000_4ab17bf144c6.other)

  

在这张电路图中，白炽灯要想点亮，就必须使串接在回路中的单向可控硅PCR606J阳极与阴极导通，而可控硅PCR606J阳极与阴极导通的条件是其控制极(G)有高电平触发并形成成电流回路。

![](D:\电脑文件\公众号知识库\电工_教育_学习\声光控灯电路原理详解_从功用一步一步弄懂这些电路图_images\img_001_4bc9a5b4e491.other)

  

从上图可以看出:单向可控硅PCR606J的控制极(G)只通过R8与芯片HD14011BP相连，这是一颗含有四个与非门的逻辑芯片，它的四个与非门的两个输入脚都是连在一起使用的，由此可以看出它们是作为非门使用的，非门在前面已做铺垫形式讲解，如果还是不太明白的话，就记住非门的输入输出关系为:只要输入是低电平，那输出就是高电平；输入的是高电平，输出的就是低电平。把输入的电平取反就是输出的电平。

好了继续找寻高电平的来源，倒推开始。

单向可控硅PCR606J的控制极(G)得到高电平。

![](D:\电脑文件\公众号知识库\电工_教育_学习\声光控灯电路原理详解_从功用一步一步弄懂这些电路图_images\img_002_686563744741.other)

  

那第4与非门输出11脚就必须是高电平，继续第4与非门输入12、13脚必须是低电平。

![](D:\电脑文件\公众号知识库\电工_教育_学习\声光控灯电路原理详解_从功用一步一步弄懂这些电路图_images\img_003_20efe104c097.other)

  

接着第3与非门输出10脚也必须是低电平，因为它们是相连的，继续第3与非门输入8、9脚必须是高电平。

![](D:\电脑文件\公众号知识库\电工_教育_学习\声光控灯电路原理详解_从功用一步一步弄懂这些电路图_images\img_004_c997c2946e5a.other)

  

接着第2与非门输出4脚就必须是高电平，继续第2与非门输入5、6脚必须是低电平。

![](D:\电脑文件\公众号知识库\电工_教育_学习\声光控灯电路原理详解_从功用一步一步弄懂这些电路图_images\img_005_20b3abe058d3.other)

  

接着第1与非门输出3脚也必须是低电平，因为它们是相连的，继续第1与非门输入1、2脚必须是高电平。

![](D:\电脑文件\公众号知识库\电工_教育_学习\声光控灯电路原理详解_从功用一步一步弄懂这些电路图_images\img_006_63b1e1615d79.other)

  

逻辑芯片HD14011BP的第1与非门输入1、2脚与A点相连，那A点必须为高电平。

  

**小结一下**

白炽灯要想点亮，就必须有高电平对单向可控硅控制极触发，并使其导通。通过上面的倒推，而高电平是来源于图示的A点，即A点是高电平时，白炽灯就点亮。  

  

# **电路图之二**

  

![](D:\电脑文件\公众号知识库\电工_教育_学习\声光控灯电路原理详解_从功用一步一步弄懂这些电路图_images\img_007_05f3026646f6.other)

  

看上图，A点的电平高低是受R1、光敏电阻CDS串联分压电路和三极管S9014C的集电极(c)发射极(e)支路影响的。

R1、光敏电阻CDS支路是对(市电交流220V整流后得到的198V脉动直流经R1限流分压、C1滤波后的)15V进行串联分压的来影响A点。当夜晚或光线暗到一定程度时，光敏电阻CDS的阻值会显著增大，约为5—8MΩ，这样和R1串联分压在A点的电压至少为:5/6\*15=12.5V(对于HD14011BP与非门逻辑芯片的输入来说为高电平)。

三极管S9014C的集电极(c)与A点相连，三极管S9014C的基极通过R4和整流滤波后的平滑15V相连，并形成电流回路，三极管S9014C的集电极(c)发射极(e)饱和导通，因发射极(e)接地，故A点又被拉低为接近0V的低电平。但由于R5、MIC1、C2支路，MIC1为驻极体电容麦克，在有人活动或较大声响时，此支路可把所获的声音信号放大为电信号，施加给三极管S9014C的基极，使三极管S9014C的基极发射极截止，从而使三极管S9014C的集电极(c)发射极(e)截止，最终使A点为高电平。

**小结一下**

在夜晚有人活动时，由于R1、光敏电阻串联分压，三极管S9014C处于截止，使A点为高电平，白炽灯点亮。

  

  

# **电路图之三**

![](D:\电脑文件\公众号知识库\电工_教育_学习\声光控灯电路原理详解_从功用一步一步弄懂这些电路图_images\img_008_1d27894eb5b7.other)

  

学习过单向可控硅的友友们都知道，单向可控硅只要是被触发，即使把触发电平撤掉，单向可控硅仍然导通，只有关掉电源，或单向可控硅的阳极与阴极的电流有断流，瞬间没有电流，用专业的说法电流有过零点，这时单向可控硅才由导通变为截止状态。在这个声光控制电路中也用到单向可控硅的这个特性，那就是单向可控硅的导通供电为整流后的脉动直流。请看解析:220V交流电的L端接入整流桥的2脚交流输入端，N端接入白炽灯出来接入整流桥的3脚另一个交流输入端，在整流桥的输出端输出198V脉动直流。整流前后波形如下图。一路输出给单向可控硅所在回路。公众号@电路一点通

![](D:\电脑文件\公众号知识库\电工_教育_学习\声光控灯电路原理详解_从功用一步一步弄懂这些电路图_images\img_009_30fd3ea0a559.other)

  

另一路经R2限流分压、C1滤波在A点得到较为平滑的直流电，电压约为15V，这个电压是多个电流回路并联后再串联分压得到的。下面我们逐一来看各个回路的具体细节。以正半周为例:第1回路交流输入端L、整流桥交流输入2脚、直流(+)1脚、R2、R3、接地、直流(-)4脚、整流桥交流输入3脚、灯泡、交流输入端N，构成电流回路。

![](D:\电脑文件\公众号知识库\电工_教育_学习\声光控灯电路原理详解_从功用一步一步弄懂这些电路图_images\img_010_180be0236598.other)

  

第2回路交流输入端L、整流桥交流输入2脚、直流(+)1脚、R2、R1、CDS、接地、直流(-)4脚、整流桥交流输入3脚、灯泡、交流输入端N，构成电流回路。其中的CDS为光敏电阻，白天的时候它的阻值。

  

# **电路图之四**

![](D:\电脑文件\公众号知识库\电工_教育_学习\声光控灯电路原理详解_从功用一步一步弄懂这些电路图_images\img_011_e0d95ba93880.other)

  

声光控灯在白天即使有人活动有声响它也不会点亮。前面已介绍声光控灯要想点亮必须A点为高电平。

![](D:\电脑文件\公众号知识库\电工_教育_学习\声光控灯电路原理详解_从功用一步一步弄懂这些电路图_images\img_012_d1d977a03620.other)

  

在白天的时候，CDS为光敏电阻的阻值一般为几十KΩ，按高一点算100KΩ,和R1串联分压在1点(A点)的电压为100/(1000+100)\*15=1.4V，这对于HD14011BP逻辑芯片的与非门输入端来说是低电平。公众号@电路一点通

![](D:\电脑文件\公众号知识库\电工_教育_学习\声光控灯电路原理详解_从功用一步一步弄懂这些电路图_images\img_013_db55bb0255ce.other)

  

从图中可以看到，HD14011BP逻辑芯片在15V供电，环境温度25℃，与非门的输入低电平范围为6.75V以下。

再来说说Q1，Q1三极管S9014C的导通与截止，不会使A的电压高于1.4V。

故A点1.4V电压给到HD14011BP逻辑芯片与非门输入端1、2引脚为低电平，经其内部四个与非门逻辑运算，芯片11引脚与非门输出端输出低电平(0V)，该脚通过R8与单向可控硅PCR606J的控制极(G)相连，因控制极无高电平触发，单向可控硅PCR606J不能导通，白炽灯因此不能点亮。

  

# **电路图之五**

  

![](D:\电脑文件\公众号知识库\电工_教育_学习\声光控灯电路原理详解_从功用一步一步弄懂这些电路图_images\img_014_a44ceab41147.other)

  

当夜晚有人活动或声响时，声光控灯会点亮，但过一会声光控灯就熄灭了，我们来看看这部分电路是如何来实现其功能的。

![](D:\电脑文件\公众号知识库\电工_教育_学习\声光控灯电路原理详解_从功用一步一步弄懂这些电路图_images\img_015_1d74dc14add2.other)

  

当夜晚有人活动或声响时，前面已讲过A点为高电平，经HD14011BP与非门逻辑芯片进行电平转换，单向可控硅的控制极获得高电平，单向可控硅导通，白炽灯点亮。由于白炽灯点亮，光敏电阻CDS的阻值快速降低，降低到一定程度，由于和R1串联分压，使A点的电压下降，当降低到6.75V以下，对于HD14011BP的第1与非门输入端第1、2脚来说这个电压就成了低电平输入。这时应该白炽灯马上熄灭，原理前面已讲过这里不再赘诉，但实际情况是过一会才熄灭，有一段时间的延时。

这是由于

![](D:\电脑文件\公众号知识库\电工_教育_学习\声光控灯电路原理详解_从功用一步一步弄懂这些电路图_images\img_016_8eb4e588d306.other)

  

在A点为高电平时，HD14011BP的第2与非门输出端第4脚输出是高电平，这个高电平经D1二极管给第3与非门输入端提供高电平的同时，也给C3电容充电，公众号@电路一点通 使C3电容的端电压充到HD14011BP逻辑芯片的供电电压15V。

当在A点变为低电平时，HD14011BP的第2与非门输出端第4脚输出也成低电平，但由于D1二极管反向截止特性所起的隔离作用及C3电容放电，第3与非门输入端仍维持在高电平，单向可控硅的控制极仍获得高电平，单向可控硅仍导通，白炽灯仍发光点亮。

电容C3在没有高电平对其充电的情况下，电容C3开始经R7电阻放电的，经过一段时间放电，电容C3的端电压会逐步下降，当降低到6.75V以下，第3与非门输入端第8、9脚的输入就变成低电平，单向可控硅的控制极也变成低电平，再加上整流后的脉动直流电流过零，单向可控硅变为截止，白炽灯熄灭。
