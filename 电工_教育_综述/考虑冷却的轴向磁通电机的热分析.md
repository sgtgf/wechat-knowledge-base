# 1 前言

在高转矩/高输出区域运行的电动汽车/混合动力汽车驱动电机会产生显著的损耗，这些损耗作为热源会提高零件的温度。由于仅靠空气冷却无法满足这些电机的热阻极限，冷却系统至关重要。轴向磁通电机采用扁平结构，轴向尺寸较小。由于内部油冷通道空间有限，这类电机倾向于使用冷却套。

结合磁场分析（用于获取铜耗和铁损）与热分析的耦合分析，能够精确评估零件的温度。虽然在实际机器中难以确定每个零件的温度，但通过仿真可以轻松验证每个零件是否满足热阻极限。

本案例研究评估了在 WLTC 驾驶循环中，带有和不带冷却套的轴向磁通电机各部件温度的变化情况。

关键词：多学科评估、冷却、冷却套、温度、轴向磁通电机、轴向气隙电机

# 3 将真实现象转化为分析模型的方法

3.1 评估选择

本案例研究选取JMAG -Express中的磁热设计场景，通过磁场分析生成效率Map图并获取驱动巡航中的损耗，同时进行热分析将这些损耗作为热源。

3.2 电磁设计场景

电磁设计场景可生成效率图并获取驱动巡航中的损耗。

JMAG -Express系统提供两种运行模式：\[Machine Characteristics (Efficiency Map)\]模式和\[Machine Characteristics (Efficiency Map) (Considering Spatial Harmonics)\] 模式，用于计算轴向磁通电机在驱动巡航中的损耗。其中，\[Machine Characteristics (Efficiency Map) (Considering Spatial Harmonics)\]模式在计算电磁力变化时会综合考虑空间谐波因素，而 \[Machine Characteristics (Efficiency Map)\] 模式则是计算速度更快但未考虑空间谐波的简化版本。本案例研究采用 \[Machine Constant (Efficiency Map)\]模式，旨在精准评估导致温度波动的损耗因素。

**3.2.1** **匝数**

本节描述匝数设置。

当\[Type\]设置为\[Axial Flux Motor/PMSM (Double Rotor/Single Stator)\]时，JMAG -Express沿轴向采用半模型。由于仅仿真线圈的一半，匝数设定为全模型的一半。但相电阻（欧姆）及其他线圈参数仍采用全模型的设定值。

**3.2.2** **并行运行的作业**

\[Machine Characteristics (Efficiency Map)\]场景通过多次评估生成轴向磁通电机的效率图。分析所需时间随并行任务数量增加而减少。但用户应根据计算机的配置选择并行任务数量，同时每个任务均需三维瞬态磁场分析的求解器许可证。

3.3 热设计

热分析可利用磁场分析获得的损耗作为热源，获取驱动巡航过程中的温度。

JMAG -Express系统提供 \[Temperature (Transient State)\]分析场景、 \[Temperature (Steady State)\]分析场景、\[Continuous Operation Characteristics\]分析场景和 \[Short Time Operation Characteristics\]分析场景以获取温度数据。其中\[Continuous Operation Characteristics\]分析场景和\[Short-time Operation Characteristics\]分析场景通过反映磁钢温度变化对效率图的影响来评估温度。若评估无需考虑磁钢温度变化对效率图的影响，可选择\[Temperature (Transient State)\]场景来评估特定时间后的温度，或选择\[Temperature (Steady State)\]场景来评估稳态温度。本案例研究选用 \[Temperature (Transient State)\]场景，评估30分钟后温度变化，且未将磁钢温度变化纳入效率图分析。

3.3.1 参考磁场分析模型的建模

热分析参考了磁场分析获得的数据。

当选择\[Machine Characteristics (Efficiency Map)\]分析场景和\[Temperature (Transient State)\]分析场景时， JMAG -Express会优先运行\[Machine Characteristics (Efficiency Map)\]场景，以便热分析能够参考磁场分析获得的数据。将热源类型设为恒定热源的场景会评估任意运行工况下的温度值。而将热源类型设为效率图的场景则会评估驱动模式下的温度变化。这些评估结果在运行时会自动反映磁场分析结果，即为各部件获取的热源数据。本案例研究将热源类型设为效率图，用于评估驱动巡航期间的温度变化。

3.3.2 时间离散化

本案例研究评估了温度随时间的变化，这是一种瞬态状态。

JMAG-Express 中的 \[Temperature (Transient State)\]分析场景规定了从加热开始到评估结束的时间。因此，评估需要应用一个能够获取温度变化的时间间隔。通常，该时间间隔应将加热时长划分为约20个等分。本案例研究对一台运行30分钟的电机进行评估。因此，时间间隔设定为20秒，将评估时间划分为90个等分，以便获得发热量变化足够平滑的温度变化图。

3.3.3 线圈与铁心间传热的数学模型

<Contact Pressure>

接触压力模拟了方形导线与铁心之间的热传递。接触压力设定为通过实际测量获得的线圈与铁心之间的作用压力。

JMAG-Express 中的\[Temperature (Transient State)\] 场景默认将接触压力设置为0.21 MPa。该默认值指定了在大多数情况下紧密接触的线圈和铁心。因此，该评估模型模拟了具有最小热阻的线圈。本案例研究使用默认的接触电阻，即0.21 MPa。

3.3.4 转子铁心与轴/磁钢及铁心间传热的数学模型

<Fit Type>

装配类型仿真部件之间的热传递。评估过程基于配合类型，使用热传递系数来仿真部件之间的热传递。

JMAG-Express 中的\[Temperature (Transient State)\]场景设置了轴向磁通电机转子铁心与轴（前/后）之间以及磁钢与铁心之间的配合类型。良好配合指定两个部件紧密接触，代表部件之间的距离为0.01毫米。如果部件之间存在较大间隙，用户可以指定不良配合，其部件之间的距离为0.1毫米，或直接设置自定义的部件间距。在全局坐标系中，转子铁心的前部位于+Z侧，后部位于\-Z侧（图 3.1）。本案例研究指定了转子铁心与轴之间以及磁钢与铁心之间的良好配合。

3.3.5 冷却水套建模

等效电路模拟了冷却套提供的冷却效果。

JMAG-Express中轴向磁通电机的\[Temperature (Transient State)\]场景会自动布置电路组件并指定条件设置，以模拟冷却套。电机结构决定了冷却套的冷却液流道。单转子双定子电机的冷却液流道位于外壳表面。双转子单定子电机的冷却液流道位于外壳和线圈表面。本案例研究评估了一款双转子单定子电机，该模型模拟了在外壳和线圈表面设有冷却液流道的冷却套。

3.3.6 电动机台架建模

等效电路模拟了电机台架的传热过程。

JMAG-Express 中轴向磁通电机的\[Temperature (Transient State)\] 场景提供了法兰安装和底座安装两种电机试验台选项。评估时应保留正在使用的电机试验台，移除未使用的电机试验台。若不考虑电机试验台的影响，评估可同时移除两者。本案例研究保留法兰安装的电机试验台，移除底座安装的电机试验台，以使用法兰安装的电机试验台。
