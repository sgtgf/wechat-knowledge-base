# 什么是矩阵主元


> 原文地址: [https://mp.weixin.qq.com/s/IbFhAcJeBLniIVVxOdF7Uw](https://mp.weixin.qq.com/s/IbFhAcJeBLniIVVxOdF7Uw)

在矩阵的世界里，_主元（Pivot）**和**主元列（Pivot Column）_就像是建筑的“承重柱”。理解了它们，你就能一眼看穿线性方程组是否有解、有多少个解。

我们要从矩阵的_行阶梯形（Echelon Form）_说起。

1\. 什么是主元？（直观理解）

想象你在玩通关游戏，每一行都是一个关卡。你从左往右走，**遇到的第一个非零数字**就是这一行的“领头羊”，也就是**主元**。

#### 规则：

-   它是每一行第一个跳出来的非零数。
    
-   在化简后的阶梯矩阵中，每一行的主元必须位于上一行主元的**右侧**。
    

**例子：**在下面这个矩阵中，被圈出来的数字就是主元：

![](什么是矩阵主元_images/img_000_96a4759283e7.svg)

-   第一行的主元是 **2**。
    
-   第二行的主元是 **5**（因为前两个数都是0，5是第一个非零数）。
    
-   第三行的主元是 **3**。
    

  

### 2\. 什么是主元列？

主元所在的**那一整列**，就叫作**主元列**。

在上面的例子中：

-   第 1 列是主元列。
    
-   第 3 列是主元列。
    
-   第 4 列是主元列。
    
-   **第 2 列不是主元列**
    
    （因为它上面没有主元，通常对应线性方程组中的“自由变量”）。
    

  

### 3\. 图解：从普通矩阵到主元

为了找到主元，我们通常使用**[高斯消元法](https://mp.weixin.qq.com/s?__biz=MzkzODgwODczMw==&mid=2247486821&idx=1&sn=c533b3c13fe0dfd182541e91ee83f67b&scene=21#wechat_redirect)**将矩阵变成“阶梯状”。

#### 视觉特征：

就像楼梯一样，每一行的主元都比上一行更靠右。

```
  [ (P)  *   *    * ]  <-- 第一级台阶 (P 是主元)
```

* * *

### 4\. 为什么要关注主元？（核心用处）

主元不仅仅是几个数字，它们决定了空间的结构：

1.  **判断线性相关性：**
    
     如果每一列都是主元列，说明这些向量是线性无关的，没有“多余”的信息。
    
2.  **解方程组：**

-   **主元列**
    
    对应的变量是**基本变量**。
    
-   **非主元列**
    
    对应的变量是**自由变量**（你可以随便给它赋值，从而产生无数个解）。
    

3.  **矩阵的秩（Rank）：**
    
     矩阵中主元的总个数，就是这个矩阵的**秩**。它代表了这个矩阵到底包含多少“硬货”信息。
    

* * *

### 5\. 总结

-   **主元：**
    
     每一行最左边的非零“顶梁柱”。
    
-   **主元列：**
    
     包含主元的那些垂直列。
    
-   **阶梯形：**
    
     寻找主元的标准姿态，就像下楼梯，一级比一级往右缩。

### 4\. 进阶：主元与 [SVD](https://mp.weixin.qq.com/s?__biz=MzkzODgwODczMw==&mid=2247487629&idx=1&sn=d4f5d86e3152a876d6ed5a9faa1c0f06&scene=21#wechat_redirect)（奇异值分解）

虽然主元是高斯消元法的产物，但它与 **SVD** 有内在联系：

-   **主元的个数 = 矩阵的秩（Rank）**。
    
-   在 SVD 中，**非零奇异值的个数** 同样等于矩阵的秩。
    
-   本质上，主元告诉你这个矩阵在变换时，真正起作用的“独立维度”有多少。

#### 2\. 主元的核心“潜台词”

我们可以把主元的概念升华一下：

-   **主元 = 独立的方向**
    
    在3D 旋转模型中，如果一个变换矩阵有 3 个主元，说明它能把物体投影到完整的 3D 空间；如果只有 2 个主元，说明它把 3D 物体压扁成了一个 2D 平面（也就是秩亏，Rank Deficient）。
    
-   **主元列 = 基向量**
    
    主元所在的原始列，构成了矩阵_列空间（Column Space）_的一组基。就像在 LaTeX 里写向量一样，主元列是那些真正“撑起”向量空间的骨架。

#### 4\. 主元与3D 投影研究

在 **Perspective Transformation（透视变换）** 中：

-   如果矩阵是**满秩**的（3个主元），说明透视投影是可逆的（或者是射影空间里的有效变换）。
    
-   如果主元少了，说明你的投影相机“瞎了”——它把不同的点重叠到了同一个位置，你无法再通过逆矩阵找回原始的 3D 坐标。
    

**如何利用这些“主元列”来提取这个压扁后的平面的基向量（Basis Vectors）？这对你理解空间重构非常有帮助。**

既然矩阵被“压扁”了，那些_主元列（Pivot Columns）_就是剩下的“残余维度”里最强有力的支柱。

当我们说一个 3D 空间被压扁成 2D 平面时，主元列告诉我们：**在这个 3 维世界里，哪两个方向是独立存在的，哪一个方向是多余的。**

#### 3\. 深度解析：为什么不选第三列？

在图3中：

-   **红色和绿色向量**
    
    （第 1, 2 列）是主元列，它们分得很开，共同撑起了一个黄色的平面。
    
-   **蓝色向量**
    
    （第 3 列）正好躺在那个黄色平面上！它没能为空间增加任何新的高度或深度。
    
-   **结论**
    
    在线性代数中，我们称蓝色向量是“线性相关”的。在做 **Perspective Transformation** 时，如果你的变换矩阵选了这一列作为方向，你的图像就会在那一维度上“塌陷”。

#### 4\. 总结：主元给我们的“避坑”指南

1.  **检查健康度**
    
    拿到一个 3D 变换矩阵，先看主元个数。不满 3 个？你的 3D 模型会被压成照片（2D）甚至一条线（1D）。
    
2.  **提取本质**
    
    主元列对应的原始向量，就是该变换所能到达的“最真实”的空间边界。
    
3.  **计算自由度**
    
    `总列数 - 主元个数 = 自由变量个数`。在解方程时，自由变量就是你可以随意滑动的“滑块”，它们代表了系统的冗余。
