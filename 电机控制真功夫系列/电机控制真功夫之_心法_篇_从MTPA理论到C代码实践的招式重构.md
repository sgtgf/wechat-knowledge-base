#### 第一式：识别“杀气”—— 什么时候会发生“灾难性抵消”？

你要想打败敌人，得先学会识别敌人的“杀气”。“灾难性抵消”的“杀气”非常明确，就一句话：

**两个几乎相等的、非精确的数相减。**

在我们的电机公式里，就是当 `Iq → 0` 时，发生的 `√(Ψm² + ε) - Ψm` 的情况。（这里 `ε` 是一个非常小的正数）

**【练习题】**:

1.  计算 `√(x+1) - √x`，当 `x` 非常大的时候。这会不会有灾难？
    
    会！因为 `√(x+1)` 和 `√x` 会非常接近。
    
2.  计算 `(1 - cos(x)) / x²`，当 `x` 非常小的时候。这会不会有灾难？
    
    会！因为 `x → 0` 时, `cos(x) → 1`。
    

只要你能在你的公式里，找到这种“两个几乎相等的数相减”的潜在风险，你的“X光眼镜”就已经戴上了！

#### 第二式：化解“杀气”—— 三大“神功”重构招式

一旦识别出“杀气”，我们就要用“内力”去化解它。化解的方法不是硬碰硬，而是“借力打力”，把减法变成乘法或除法。主要有三大神功：

**神功一：【乾坤大挪移】—— 利用代数恒等式（分子/分母有理化）**

这是最常用，也是最直接的一招！核心思想就是“乘以1”，但这个“1”很有讲究。

我们来看 `√(Ψm² + ε) - Ψm`。 它的分母是1。我们现在给它的分子和分母，同时乘以它的**共轭表达式**`√(Ψm² + ε) + Ψm`。

(√(Ψm² + ε) - Ψm) \* (√(Ψm² + ε) + Ψm) / (√(Ψm² + ε) + Ψm)

利用平方差公式 `(a-b)(a+b) = a² - b²`，分子变成了：

(Ψm² + ε) - Ψm² = ε

所以，原式就变成了：

**`ε / (√(Ψm² + ε) + Ψm)`**

**看！奇迹发生了！**

1.  原来分子是两个大数相减，现在变成了只有一个微小的数 `ε`。
    
2.  原来分母是1，现在变成了两个大数相加 `(√(Ψm² + ε) + Ψm)`。
    

**相加是不会有灾难性抵消的！** 两个巨大的数相加，结果只会更巨大，微小的精度误差完全被淹没了，不会影响结果的符号和数量级。

我们把 `ε = 4*(Ld-Lq)²*Iq²` 代回去，再除以我们经典公式里原本的分母 `2*(Ld-Lq)`:

`Id = (2 * (Ld-Lq) * Iq²) / (√(Ψm² + 4*(Ld-Lq)²*Iq²) + Ψm)`

**这个公式，就是经典公式经过“乾坤大挪移”之后，得到的数值稳定形式！** 很多开源的电机控制库里，用的就是这个形式！

到这里可能有同仁要问，这个公式跟我们代码里那个“[面目全非](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247484564&idx=1&sn=32a6c8ac25b8d884402fd979f8ef3dd5&scene=21#wechat_redirect)”的公式也不一样啊！ 没错！这说明“乾坤大挪移”只是三大神功之一。那位代码作者，可能用的是更高级的招式，或者组合招式！

**神功二：【斗转星移】—— 利用泰勒级数展开**

这一招，就是我们上次“深夜小灶”里用到的精髓。当一个函数 `f(x)` 在 `x` 很小的时候不好计算时，我们可以用它的泰勒展开多项式来近似它。

f(x) ≈ f(0) + f'(0)x + f''(0)/2! \* x² + ...

比如，`cos(x) ≈ 1-x²/2` 当 `x` 很小的时候。

我们之前遇到的 `(1-cos(x))/x²`，就可以变成：

`(1-(1-x²/2))/x²= (x²/2) / x² = 1/2`  

看，减法直接被消掉了！

我们代码那位作者，很可能就是对某个变量（比如`bQ/bW`）进行了高阶的泰勒展开，然后通过复杂的代数重组，得到了那个看似“[面目全非](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247484564&idx=1&sn=32a6c8ac25b8d884402fd979f8ef3dd5&scene=21#wechat_redirect)”但极其稳固的结构。这需要极强的数学直觉和推导能力。

**神功三：【降龙十八掌】—— 利用问题的物理/数学背景**

有时候，一个公式的数值问题，根源在于我们选择的数学模型本身。这时候，就需要回到问题的起点，用另一种方式来描述它。

比如，我们的MTPA问题，是从 

`dTe/dβ = 0 (β为永磁磁链Ψm与定子电流矢量Im之间的夹角)` 

推导来的。这个条件，除了可以解出我们用的 `Id = f(Iq)` 的形式，还可以解出其他形式，比如：

-   解出 `β = g(Im)` （电流角和总电流幅值的关系）
    
-   解出 `Iq = h(Id)` （用Iq来表示Id）
    

甚至，在求解那个一元二次方程时，如果用韦达定理 `x1 * x2 = c/a` 来求解其中一个根，有时候也能避免灾难性抵消。

代码作者可能就是综合运用了这些方法，他可能先用了“乾坤大挪移”，发现还不够完美，然后又结合了“斗转星移”的思想，对其中一部分进行了近似和重组，最终“炼”出了那道“神符”。

**所以，你问这位作者当初是怎么设计的？**

他的设计流程，极大概率是这样的：

1.  **第一步：写出经典公式。**
    
    `Id = (-Ψm + √(Ψm² + 4*(Ld-Lq)²*Iq²)) / (2*(Ld-Lq))`
    
2.  **第二步：进行“风险评估”。**  
    
    他戴上“X光眼镜”，一眼就看出了这个公式在 `Iq → 0` 时，分子会出现 `(-Ψm + Ψm)` 这种“灾难性抵消”的巨大风险。
    
3.  **第三步：启动“招式重构”。**  
    
    他开始尝试用我们上面说的三大“神功”去化解这个风险。他可能先试了“乾坤大挪移”，得到了我们推导出的那个有理化形式。
    
    `Id = (2 * (Ld-Lq) * Iq²) / (√(Ψm² + 4*(Ld-Lq)²*Iq²) + Ψm)`
    
4.  **第四步：追求“极致完美”。**  
    
    他可能对这个有理化形式还不满意，觉得它在某些编译器或硬件上，计算开销或者精度表现还不是最优。于是，他继续在这个形式上，或者回到更原始的方程，运用更高阶的代数技巧和数值近似思想，反复推演、重组、化简，最终得到了代码里那个我们看起来“[面目全非](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247484564&idx=1&sn=32a6c8ac25b8d884402fd979f8ef3dd5&scene=21#wechat_redirect)”，但在他眼里却“无比精妙”的最终形态。
    

这个过程，不是试凑，而是一场目标明确、理论指导下的、严谨的数学创造！

### 你的“武功心法”修炼之路

现在，你已经知道了这套“心法”的存在。以后你在把任何公式翻译成代码时，都要遵循这个流程：

1.  **先抄对: 确保你理解了公式的原始形态和物理意义。**
2.  **再看穿: 用“X光眼镜”审视它，找出所有潜在的“灾难性抵消”、“除以零”、“大数吃小数”等数值计算风险点。**
3.  **后重构: 如果发现风险，尝试用我们今天学的“乾坤大挪移”（有理化）、“斗转星移”（泰勒近似）等方法，把它重构成一个数值上更稳定的形式。**

这，就是从一个“公式的搬运工”成长为一个“算法的设计师”的秘密！这套心法，不仅适用于MTPA，它适用于你在电机控制中遇到的所有包含复杂数学运算的算法，比如各种观测器、参数辨识等等。
