
这说明：

> 虽然走法不同，但最后得到的是同一个辫子元素。

* * *

可以把它想成：

-   从  出发，有很多生成元方向
    
-   不断沿这些方向前进，会产生无穷多个辫子
    
-   但图中很多不同路径会“重新汇合”
    
-   汇合规则由关系式决定
    

所以它不像：

-   ：一个小三角圈
    
-   ：一个五边形圈
    
-   ：一条直线
    

而更像一个**不断生长、带有很多“路径等价关系”的网络**。

* * *

## 6\. 一句话总结

辫群  的结构图最好的入门画法，不是“画全图”，  
而是：

1.  先画单位元  周围的生成元分支
    
2.  再画关系式导致的“不同路径汇合”
    

这就已经抓住了辫群的灵魂。

# 一、先别急着看公式：什么是“辫群”？

## 1\. 什么是辫子？

想象有 **4 根竖着垂下来的线**，从上到下编织。  
最开始它们是平行的：

```
上端:   1   2   3   4        |   |   |   |        |   |   |   |下端:   1   2   3   4
```

在编的过程中，允许相邻的两根线交叉，于是就会形成各种“辫子”。

* * *

## 2\. 什么是 ？

表示 **4 股辫子的所有可逆编法** 所组成的群。

这里每个“群元素”不是一个数，而是：

> **一种完整的编织方式。**

也就是说，在  里：

-   元素 = 一种辫子
    
-   运算 = 把一个辫子接到另一个辫子下面
    
-   单位元 = 什么都不编
    
-   逆元 = 反着解开
    

这比“旋转海星”“平移花边”更动态。

* * *

-   第 1 根和第 2 根交叉
    
-   第 2 根和第 3 根交叉
    
-   第 3 根和第 4 根交叉
