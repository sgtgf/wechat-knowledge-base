## 一、“被冤枉的磁钢”

一个已经量产了一年的项目，突然收到了客户的批量投诉：电机的输出转矩，相比早期样机，普遍下降了约10%。

团队立刻紧张起来，第一个怀疑对象就是——**磁钢发生了不可逆退磁**。

算法工程师小王，用驱动器的自整定功能，对几台返修回来的电机进行了磁链辨识。他用的方法，就是我们之前提到过的，类似代码B的**“两点法解方程”**（`SynTuneBemf`）。结果显示，辨识出的磁链ψm确实比设计值低了10%左右。

“证据确凿”，小王得出结论：磁钢供应商的材料有问题，导致了批量退磁。

但磁钢供应商坚决否认，他们拿出了自己的出厂检测报告，证明磁钢的性能完全符合要求。项目陷入了僵局，没人知道该相信谁。

**问题出在哪里？**

问题出在小王的“证据”不够“硬”。他用来辨识磁链的方法，虽然巧妙，但它本身也依赖于其他参数，比如**定子电阻Rs**。

后来，一位经验丰富的老工程师提醒他：“这些返修回来的电机，是不是都在一个非常热的环境下工作？”

他们一查，果然如此。这些电机长期在高温下运行，导致**定子电阻Rs比冷态时增加了20%以上**。而小王的辨识程序里，用的还是冷态下的Rs值。当他把这个**真实的、热态下的Rs**代入磁链计算公式后，发现辨识出的ψm值，又回到了正常水平！

原来，不是磁钢退磁了，而是**电阻温升“冤枉”了磁钢**。那“消失的10%转矩”，其实是被增大的铜耗给吃掉了。

**问题的解决方案在哪儿？**

解决方案就在文末给出的标准文件 IEEE Std 1812-2023 的 **Clause 5.2 (Open-circuit voltage test)** 和 **Clause 4.9 (Resistance to demagnetization)**。

标准告诉我们，要判断磁钢的“健康状况”，最可靠、最直接的证据，就是**开路反电动势**。因为它几乎只和磁链、转速有关，与电阻、电感这些“善变”的参数无关。

今天，我们就来深入学习代码B的 `SynTuneBemf` 函数，看看它是如何辨识磁链的。然后，也是最重要的一步，我们将学习如何用IEEE标准的方法，为我们的磁链建立一个**“不可辩驳的、可追溯的健康档案”**，避免再出现“冤枉好人”的情况。

## 二、代码B的磁链辨识：`SynTuneBemf` 逐行走读

代码B的作者，选择了一种**在运行中**辨识磁链的方法。这种方法不需要外部拖动电机，但需要电机能稳定地跑起来。

**1\. 核心思想：“两点法”解方程，但这次解的是磁链**

我们再次回到那个熟悉的稳态电压方程：

`Vq = R_Iq + ωe_(Ld*Id + ψm)`

-   **简化:** 在辨识时，我们可以让 `Iq = 0`，这样转矩为零（或很小），电机可以平稳运行。此时，方程简化为： `Vq = ωe * (Ld*Id + ψm)`
    
-   **问题:** 这个方程里有两个未知数：`Ld` 和 `ψm`。一个方程解不出两个未知数。
    
-   解决方案: 做两次实验，用两组不同的`Id`值。
    

1.  实验1: 让 `Id = Id1`，测得 `Vq1`。得到 `Vq1 = ωe * (Ld*Id1 + ψm)`。
    
2.  实验2: 让 `Id = Id2`，测得 `Vq2`。得到 `Vq2 = ωe * (Ld*Id2 + ψm)`。
    

-   **求解**: 现在我们有了一个二元一次方程组。通过简单的代数消元，把`Ld`消掉，就能解出`ψm`。

为什么要消元？因为同步电机的电压方程里，Vq 不仅包含反电动势（ω·Flux），还包含电感压降（ω·Ld·Lq）。

如果我们只测一个点，因为不知道 Ld 是多少（或者 Ld 不准），算出来的磁链 Flux 就会有巨大误差。

通过设置两个不同的电流 Id1（1500）和 Id2（3000），我们巧妙地把 Ld 这个讨厌的未知数给消掉了！物理学的美感，就在这一减之间。

-   **硬核知识点二：为什么只开到 40% 的速度？**
    

在 `Case 1` 里，有这么一行代码：

```
gEstBemf.TuneFreqAim = (long)gMotorInfo.FreqPer * 2L / 5L; // 40% 额定频率
```

为什么要定在 40%？为什么不直接飙到 100%？或者只开 1%？

这里面是有讲究的：

1.  **太低不行**：反电动势 E = ω·Flux。如果速度 ω 太低，E 就很小，会被逆变器的噪声、死区效应淹没，算不准。
    
2.  **太高不行**：
    

-   **安全问题**：万一参数还没辨识准，电机就飙到高速，一旦失控（比如弱磁没做好），电压可能会瞬间冲高，炸毁逆变器。
    
-   **电压极限**：如果速度太高，反电动势接近母线电压，电流就灌不进去了（弱磁区），这时候 Id 很难维持恒定，导致辨识失败。
    

所以，40% 是一个**黄金分割点**：既有足够大的反电动势信号（信噪比高），又远离电压极限区（安全可控）。

-   **硬核知识点三：如何画出完美的“梯形波”？（余数补偿）**
    

在 `Case 2`（加速）和 `Case 6`（减速）里，有一段看似啰嗦的代码：

```
gEstBemf.FreqStep = (FreqPer + FreqRem) / AccDecTick;
```

这是在干什么？这是在做**整数运算的精度补偿**（DDA算法思想）。

在嵌入式里，如果使用的是没有浮点数功能的MCU或DSP，那么里面只能做整数除法。假设你要在 3000 个周期内，把频率从 0 加到 1000。

每一步加多少？`1000 / 3000 = 0`。完了，加了个寂寞，频率永远是 `0`。

有了这个 `FreqRem`（余数）：

-   第 1 次：商 0，余 1000。加 0。
    
-   第 2 次：(1000+1000)/3000，商 0，余 2000。加 0。
    
-   第 3 次：(1000+2000)/3000，商 1，余 0。加 1！
    

这样平均下来，频率就能平滑、准确地达到目标值，不会因为整数除法的截断误差而跑偏。这就是**数字积分**的魅力。

**只有老鸟才懂的彩蛋**

**彩蛋1：大车和小车的起步区别**

在 `Case 1` 里：

```
gEstBemf.AccDecTick = (gInvInfo.InvTypeApply <= 20) ? (30L*1000L/2) : (60L*1000L/2);
```

这又是在根据机型（InvTypeApply）做区分：

-   **小机型（<=20）**：30秒加速。
    
-   **大机型（>20）：**60秒加速。
    

为什么要这样？因为大电机转动惯量（J）大！

如果你让一个几十吨重的大飞轮像小风扇一样 5 秒钟飙到高速，需要巨大的转矩电流。但我们在辨识过程中，为了保证磁场定向准确，通常电流给得比较保守。

如果加速太快，大电机根本跟不上，就会**失步**，电流狂飙，过流保护跳闸。

所以，**大车要慢起步。**这行代码背后，是无数次跳闸换来的教训。

**彩蛋2：数据清洗与稳态等待**

各位同仁注意看 `Case 3` 和 `Case 5`：

```
if(gEstBemf.Cnt <= 2048)
```

这里有两个细节：

1.  **取平均**：累加 2048 次再除以 2048。这是为了滤除 PWM 的开关噪声和电流纹波。
    
2.  **稳态等待**：在 `Case 2`（加速）和 `Case 4`（电流切换）之后，都留了 `Cnt > 500` 的等待时间。这是为了让电机的机械惯性和电感惯性稳定下来。**没有稳态，就没有真相。**这是一个合格的控制工程师必须铭记的信条。
    

简单点评一下这个φm辨识函数：

有**优点**：

-   可以在没有外部拖动电机的情况下，在控制器内部完成辨识。
    
-   通过两点法，理论上消除了Ld和Rs（如果Iq严格为0的话）的影响，比单点法更鲁棒。
    

但也有**缺点/风险点**：

-   **强依赖于速度稳定。**如果在采样期间速度波动，ωe就在变，会引入巨大误差。
    
-   **强依赖于电流环性能。**如果电流环跟踪Id指令有静差，那么实际的Id就不是你以为的1500或3000，结果也会偏。
    
-   **忽略了温度变化。**整个过程持续数秒甚至数十秒（根据代码B的原注释，机型22以下: 30sec；机型22以上: 50sec），电机的Rs会温升。但计算时如果用的还是冷态Rs（虽然公式里消掉了，但实际PI控制和解耦里还在用），就会引入误差。这就是开头案例的根源。
    

## 四、建立“不可辩驳的证据链”：用IEEE 1812给磁链做“公证”

为了避免“冤枉磁钢”，我们需要一套比 `SynTuneBemf` 更权威、更纯粹的“**地面真值**”测量方法。这就是IEEE 1812的用武之地。

**4.1 核心方法：开路电压测试 (Open-circuit Voltage Test)**

-   **IEEE坐标: Clause 5.2**
    
-   **为什么它最可靠？**
    

因为在开路状态下（`I=0`），电机的电压方程极度简化：`Vq=ωe*ψm, Vd=0`。此时，端电压的大小**只和转速、磁链有关**。与Rs、Ld、Lq这些“善变”的参数完全无关。因此，在特定温度下，`Voc/ωe` 应该是一个常数。这个常数就是**反电动势常数Ke**，它和磁链ψm只有一个极对数的换算关系。

**4.2 如何在各位同仁的台架上实现“司法级公证”？**

用对拖电机，这是实现“黄金标准”的关键。建议各位同仁的测试团队建立一个**标准作业程序（SOP）**：

**4.2.1 冷态基线测试:**

-   将电机静置足够长时间，使其温度与环境温度一致（比如25°C）。
    
-   用对拖电机，从低速到高速，分多个速度点（比如额定速度的10%, 20%, ..., 100%）拖动被测电机旋转。
    
-   在每个速度点，记录：**转速(rpm)、三相线电压有效值(Vrms)、电机温度。**
    
-   计算每个点的 `Ke = Vll/(sqrt(3) * rpm * 2*pi/60 * p)` (p是极对数)。
    
-   画出 `Ke vs Speed` 曲线。理想情况下，它应该是一条水平直线。这条线，就是这台电机在25°C下的“指纹”。
    

**4.2.2 热稳态基线测试:**

-   让电机在额定负载下运行足够长的时间，直到温度稳定（遵循 **IEEE 5.5.1** 的判据：30分钟内温升变化<1°C）。
    
-   记录下此时的稳定温度（比如80°C）。
    
-   重复步骤1，得到一条**80°C下的**`**Ke vs Speed**`**曲线。**
    
-   你会发现，这条线会比25°C的线整体偏低一些（对于钕铁硼磁钢）。这个下降的百分比，就是磁钢的**正常温度系数**，不是退磁！
    

**4.2.3 建立“健康档案”:**

-   把这两条（或更多温度点的）曲线，连同测试条件，一起存入各位同仁实验室的**“基准参数库”**。
    

**4.3 如何使用这个“健康档案”？**

**4.3.1 验证辨识算法:**

-   在电机冷态时，运行代码B的`SynTuneBemf`，得到**fluxRotor**。把它换算成Ke，看是否落在刚刚测的25°C基线上。
    
-   在电机热态时，再运行一次`SynTuneBemf`，看结果是否落在80°C基线上。
    
-   如果偏差很大，优先怀疑`SynTuneBemf`方法本身引入的误差（如Rs不准、电流环静差），而不是磁钢。
    

**4.3.2 诊断退磁 (IEEE坐标: Clause 4.9):**

-   当客户返修一台电机时，不要急着跑辨识。先把它弄到和基线测试**相同的温度下**（比如也加热到80°C）。
    
-   然后做一次开路电压测试。如果测出的Ke值，显著低于80°C那条基线（比如又低了5%以上），那么你就有**强有力的证据**，证明它发生了**不可逆的退磁**。
    

## 五、本讲落地：给三类工程师的行动指南

1.  **对算法工程师**
    

-   **理解方法的局限:**`SynTuneBemf`是一种很好的**在线估算**方法，但不要把它当成“真理”。它的结果会受到Rs温升、电流环精度等因素的影响。
    
-   **引入温度补偿**: 在各位同仁的FOC代码中，Rs和ψm都应该被建模成温度的函数。各位可以从测试团队那里拿到`Rs(T)`和`ψm(T)`的曲线，做成查找表，在运行时根据温度传感器反馈，动态修正这两个参数。
    

2.  **对硬件工程师**
    

-   **温度传感器的重要性**: 今天的文章再次证明了温度传感器的价值。它不仅是用来做过温保护的，更是精确辨识和控制的“眼睛”。传感器的位置（贴近绕组热点还是外壳）、精度、响应速度，都直接影响算法的补偿效果。
    

3.  **对测试工程师**
    

-   **建立和维护“基准参数库”**: 各位最重要的任务之一，就是为每一款新电机，都建立一套完整的、基于IEEE标准的“黄金标准”参数集。这份档案，将是整个研发团队所有讨论和决策的基石。
    
-   **测试报告要“讲故事”**: 不要只给一个数字。各位的测试报告，应该满足“三句话规则”，清晰地写明：**测的是什么，在什么条件下测的，用什么方法测的。**
