# 《PMSM观测器控制这件小事》| 11讲：滑模观测器的物理直觉：用开关逻辑"捏"出反电动势

你调过滑模观测器（SMO, Sliding Mode Observer）吗？

我第三次调的时候，把估计角度通过 DAC 导出到示波器上，看到它高频抖动——稳态时在真实角度附近快速震荡，幅度不大，但肉眼清晰可见。电机也跟着发出一种细微的嗡嗡声，不刺耳，但让人坐立不安。

我把时基调到 10 ms/div，触发模式设成正常，盯着那条线在真实角度上下翻飞，幅度大概 ±3 度，在慢时基下看起来像一条带状抖动。切到更快时基或用示波器的 cursor 量一下，频率在 kHz 量级——远在速度环带宽之上，却在电流环的敏感区边缘游荡。

我的第一反应是：增益要调小一点。

我把滑模增益从 800 降到 500。抖振弱了，波形变得温驯，像被顺过毛的猫。但负载突变时角度跟不上，像老牛拉车——加了 50% 负载，估计角度愣是慢了半拍才反应过来，速度环觉得电机"不听话"，开始振荡。

于是我又把增益调回 800，再往上加到 1200。跟踪倒是快了，但抖振凶得像发了疯的蜜蜂。电机嗡嗡声变大了，母线电流里出现了奇怪的高频谐波。

如果你也遇到过类似的情况，当你盯着示波器上那条高频抖动的线时，有没有想过一个问题：

**为什么偏偏要用这么粗暴的开关？**

用个平滑的线性反馈不行吗？像 PID 那样，误差大就多给点，误差小就少给点，温和又优雅。电机又不会投诉你态度不好，干嘛非得像按门铃一样，要么不响，要么狂响？

SMO 说不行。它的灵魂就是那个粗暴的 sign 函数——非黑即白，没有中间态。理解了为什么开关能估计连续信号，你就理解了滑模观测器的一半。

## 橡皮泥里的硬币

各位同仁，咱们先来打个比方。

你面前有一块半透明的橡皮泥。淡蓝色的，像那种小孩玩的手工泥，软塌塌地瘫在桌面上，表面还留着上次被捏过的痕迹。里面藏着一枚硬币，但橡皮泥太厚，你直接看不见硬币在哪。只凭肉眼，你只能看到一团模糊的蓝色，偶尔在光线下折射出一点金属的反光——但那也可能是气泡。

你的任务只有一个：用手指"捏"出硬币的轮廓。

规则很变态：你的手指只有两个动作——要么用力捏下去，要么完全松开。没有"轻轻按一下"这种中间选项。捏，或者松。二选一。

你开始捏。

第一下，捏在左边。硬硬的——硬币在这？你赶紧松开，换到右边再捏。也是硬的？不对，硬币没那么大。你再换到上面捏。软的，没有。下面呢？也是软的。回到左边，还是硬的。

就这么捏了成千上万次。左、右、上、下、再左、再右……

每次捏，橡皮泥表面都会产生纹路和涟漪。你捏得狠，纹路深，橡皮泥表面像被犁过的田。你松开的时候，那些纹路慢慢回弹，但痕迹还在。

捏到一百次的时候，你觉得自己在瞎忙活。捏到一千次的时候，你开始感觉左边和右边有点不一样。捏到十万次的时候，你闭上眼睛回想——虽然单次动作极其粗暴，但你的手指好像知道了一件事：左边和右边经常捏到硬东西，上面和下面总是软的。

硬币的轮廓，在"平均"中浮现出来了。

回到咱们的观测器。

你的手指就是 sign 函数。它只认识两个状态：电流误差为正？用力往负方向修（输出 -1）。电流误差为负？用力往正方向修（输出 +1）。它不会说"修一点点"——没有中间态。

橡皮泥里的硬币就是反电动势（Back-EMF, Back-Electromotive Force）。它是转子旋转时在定子绕组中感应出的电压，正比于转速，相位与转子角度锁定。它是连续的真实信号，藏在电机电压方程里，你看不见，只能间接感知。

橡皮泥表面的纹路就是抖振（chattering）。每次 sign 切换都会在系统里激起高频噪声。你捏得越狠（增益越大），纹路越深。示波器上那条高频抖动的线，就是纹路在电信号里的倒影。

而你捏了十万次之后，手指感受到的"平均硬度"——就是把那些纹路抹平之后剩下的东西——就是低通滤波器从噪声里掏出来的真实信号。

说白了，滑模观测器的聪明之处不在于 sign 函数本身有多粗暴，而在于"高频切换 + 低通滤波"的组合拳。单次切换粗糙得要命，但平均下来，它并不比 PID 笨。

## PID 为什么不行？

说到 PID，各位同仁可能会问：线性反馈哪里不好？

想象你捏橡皮泥的时候，允许"轻轻按"了。你按到左边，感觉到硬币，但按得很轻，只给一点点反馈。然后你慢慢加大力度——按得越深，反馈越强。误差大的时候按得重，误差小的时候按得轻，像按摩一样循序渐进。

听起来更温和，对吧？

但问题是：PID 的线性反馈在观测器里有个天然的短板。误差小的时候，PID 只给一点点修正量。但电机参数漂移或负载扰动会让实际电流偏离模型预测，这时候你需要的恰恰是强有力的修正，而 PID 还在慢吞吞地爬坡。线性观测器的增益不能无限放大——太大就放大噪声——所以它在鲁棒性和收敛速度之间总要折中。

我给你讲个具体的场景。

夏天车间温度升高，电机绕组电阻随温度漂移。铜的电阻温度系数约 0.4%/°C，温升三四十度的时候，标称 0.5 Ω 的电阻可能实际变成了 0.55 Ω 甚至更高。你的观测器模型还在按 0.5 Ω 算，预测步已经开始偏了。电流实测值和模型预测值之间出现了一个持续的小误差。

PID 看到这个误差："才差 0.2A？小意思，给个 0.05 的修正量就行。"然后慢吞吞地往上加。但电阻漂移是持续的，误差在不断累积。PID 还在优雅地爬坡，实际角度已经跑偏了好几度。

sign 函数走的是另一条路。它不需要知道误差有多大，只需要知道方向。

电流估计值比实测值大？全力往下拉。哪怕只大了 0.01A，sign 的输出幅度依然是 ±K\_slide，不犹豫、不渐变、不拖泥带水。这种不连续注入在满足滑模条件时，能让系统对参数不确定性和外部扰动更强韧。

这种"方向优先"的响应方式，对滑模趋近过程来说，误差方向优先，让系统更快地把误差压进滑模面；BEMF 的幅值仍影响速度估计和低速信噪比，不能简单说"大小不重要"。

当然，代价就是你看到的高频抖动。sign 的粗暴在时域里表现为噪声，但在频域里，这些噪声的高频成分刚好可以被低通滤波器滤掉，剩下低频的真实信号。

抖振不是 bug。它是 sign 函数在工作时必然产生的"副作用"，也是你获取真实信号必须支付的"信息税"。

## 从"捏"这个动作到信号处理：SMO 到底是怎么运作的？

橡皮泥的比喻讲完了，但工程师肯定要问：电机里没有橡皮泥，sign 函数捏的到底是什么？

咱们把直觉往工程上再推一步。

在永磁同步电机（PMSM, Permanent Magnet Synchronous Motor）的 αβ 坐标系里（本文采用幅值不变的 Clarke 变换，α 轴与 A 相轴线对齐，电角度从 α 轴正方向逆时针计量），电压方程大概长这样：

> 电压 = 电阻压降 + 电感压降 + 反电动势

前两项可以用模型算出来——电阻乘以电流，电感乘以电流变化率。第三项——反电动势——包含了你最想要的东西：转子位置和转速的信息。

问题是：这三项混在一起，你怎么把反电动势单独拎出来？

SMO 的思路很直接：

**建一个"虚拟电机"，让它和真实电机并联运行。**

想象你在电脑上开了一台"虚拟电机"，给它和真实电机一样的电压指令。虚拟电机里有一个"估计电流"，是根据你猜测的角度和速度算出来的。

如果猜测的角度是对的，虚拟电机的电流应该和真实电机的电流长得一样——波形重合，幅值相同，相位对齐。

不一样？说明估计的角度或速度错了。

差多少？sign 函数说：我不管差多少，我只管方向。估计电流比实测电流大？全力往下拉。估计电流比实测电流小？全力往上推。

这个"全力推拉"的动作，就是 sign 函数在"捏"电流误差。

捏的频率极高——观测器每秒更新几万次。控制周期如果是 100 μs，那每秒就是一万次更新；实际 sign 是否翻转取决于电流误差是否过零、边界层/滞环和具体实现。但这里要注意：sign 的切换项首先作用在观测器内部，用来修正估计电流，不是直接塞进 PWM 去驱动真实电机。真实电机的电流由逆变器电压和负载决定，变化速度受电机电气时间常数限制，远跟不上观测器里 sign 的切换速度。

但这团噪声不是随机噪声。它的高频切换里藏着一条低频的包络线——在滑模条件下，这条包络线对应的就是反电动势的大小和方向。

打个比方：你捏橡皮泥，左边硬，你捏左边的时间就长，松手的时间就短。右边软，你捏一下立刻松开，根本不逗留。这个"捏的时间比例"虽然粗略，但它隐含了硬度的信息——不是硬度的精确数值，而是"需要多大力气才能抵消这里的硬度"。

此时低通滤波器登场。它的工作是把那些高频切换抹平，提取出切换项的短时平均值。在经典 SMO 的滑模条件下，这个平均值收敛到反电动势本身 \[S-003\]，所以低通滤波器的输出就是对 BEMF 的估计。

这里有个频域直觉，理解了它能帮你调参。

sign 的切换会在采样频率或实现所限的切换频率附近及更高频段产生强高频分量。频谱形态取决于采样方式、误差过零特性、边界层厚度和具体实现，不一定是理想方波。真实电机的电气响应（电流、BEMF）频率远低于 sign 切换频率，所以这些高频分量对电机电气响应的直接影响有限——但有一个重要前提：它们不能通过估计角度耦合进电流环和速度环。

低通滤波器的作用就是衰减/隔离这条耦合路径。它把 sign 的高频分量削弱到可接受的水平，让低频的真实信号通过，进入后续的角度提取环节。就像一扇半开的门：低频信号弯腰穿过，高频抖振被挡回去大半——但不是全部，总有些残余会漏过来。

这就是 SMO 的工程美感：sign 在观测器内部粗暴切换，但它的"粗暴"被低通滤波器精确地隔离在了角度估计之前。

再往后，用反正切或锁相环（PLL, Phase-Locked Loop）从反电动势里提取角度——这就是咱们在前10讲里讲过的内容了。

说白了，SMO 的整条链条就是：

电流误差 → sign 函数"捏" → 高频切换 → 低通滤波"抹平" → 反电动势估计 → 反正切/PLL 提取角度

sign 函数在这条链里扮演的角色，就是那个只会"用力捏/松开"的手指。它不聪明，但它够快、够果断、够鲁棒。

"反电势观测→位置提取"的思路最早由 Kim 和 Sul 在 1997 年系统化提出 \[S-001\]，为后续无感控制奠定了基础。经典 signum 型 SMO 的完整框架则可参考 S-002b 或 AN1078 等文献，它们在电流观测器结构中引入 sign 切换项，并通过等效控制提取 BEMF。

## 代码里的"捏橡皮泥"

看直觉有点虚，咱们看看代码里长什么样。

下面是一段基于经典 SMO 结构的简化示意代码（仅用于说明原理，非特定开源项目提取），展示了 sign 函数在电流误差上的"捏"动作：

`// 经典 SMO 简化示意：αβ 坐标系下的电流观测   // 核心思想：电流误差 → sign → 高频切换 → LPF → BEMF      // 1. 用估计电流和实测电流算误差   //    经典写法：err = i_est - i_meas，对应"虚拟电机"和真实电机的偏差   float err_alpha = i_alpha_est - i_alpha_meas;   float err_beta  = i_beta_est  - i_beta_meas;      // 2. sign 函数"捏"误差：非黑即白，没有中间态   //    要么用力捏，要么松开   //    K_slide 的单位与 z 相同，通常为电压等效量（V）   float z_alpha = K_slide * sign(err_alpha);   float z_beta  = K_slide * sign(err_beta);      // 3. 用"捏"出来的修正项更新电流估计   //    模型预测 + sign 粗暴修正   //    注意：z 作用在观测器内部，修正的是估计电流，不是直接写 PWM   di_alpha_est_dt = (v_alpha - R * i_alpha_est - z_alpha) / L;   di_beta_est_dt  = (v_beta  - R * i_beta_est  - z_beta)  / L;      i_alpha_est += di_alpha_est_dt * dt;   i_beta_est  += di_beta_est_dt  * dt;      // 4. 低通滤波器（LPF）从抖振中提取平均信号 = 反电动势估计   //    把纹路抹平，露出硬币轮廓   //    这里用前向 Euler 近似：alpha ≈ omega_c * dt，仅当 omega_c*dt << 1 时成立   //    更精确写法：alpha = 1 - exp(-omega_c * dt)   lpf_update(e_alpha_est, z_alpha, lpf_fc * dt);   lpf_update(e_beta_est,  z_beta,  lpf_fc * dt);      // 5. 从反电动势提取角度   //    标准 BEMF 约定：e_α = -K·sin(θ), e_β = K·cos(θ)   //    故 atan2(-e_α, e_β) = θ，即转子电角度   float angle_est = atan2(-e_alpha_est, e_beta_est);`

注意 `sign(err_alpha)` 这一行。`err_alpha` 是连续变化的电流误差，可能是 0.1A，可能是 -0.05A。但 `sign()` 不管这些，只返回 +1 或 -1。一个连续信号被硬生生切成了两电平切换信号。

`lpf_update` 把两电平切换信号的尖锐边缘磨圆，提取出切换项的短时平均值。在滑模条件下，这个平均值收敛到反电动势 \[S-003\]，所以低通滤波器的输出就是对 BEMF 的估计。

## 示波器上该看什么？

理论讲完，咱们回到调试现场。下面提到的变量（`z_alpha`、`e_alpha_est`、估计角度、编码器角度）都是数字信号或内部变量，不是示波器探头直接能碰到的。你需要通过 MCU DAC、实时调试上位机、数据记录器，或把信号归一化后输出到模拟通道，才能在示波器上看到。编码器角度也需要经过解码/换算输出。

**看 `z_alpha`（sign 切换项，需通过 DAC/调试通道导出）。**

如果你把 `z_alpha` 通过 DAC 或调试接口接出来，示波器上应该是一团高频切换波形——正峰值和负峰值快速交替。这是 sign 在观测器内部"捏"电流误差的实时画面。

注意：`z_alpha` 是观测器内部变量，不是示波器上直接能看到的那种"估计角度抖动"。估计角度的抖动是 `z_alpha` 经 LPF、atan/PLL 后残留的耦合效应，两者不是同一个波形。

`z_alpha` 的短时平均值随反电动势正弦变化，这是正常的——因为等效控制量本身就要跟踪 BEMF。如果你观察跨整数电周期的滑动平均，发现存在明显 DC 偏置，再排查电流采样偏置或电阻/电感参数失配。

**看 `e_alpha_est`（LPF 后的反电动势估计）。**

这应该就是一条相对平滑的正弦波，频率对应电角频率（也就是机械转速乘以极对数）。如果它上面还叠加着明显的高频毛刺，说明 LPF 的截止频率太高，纹路没抹干净。如果它滞后于真实反电动势太多（可以用编码器角度和转速、结合磁链常数生成参考 BEMF 来对比），说明截止频率太低，相位延迟过大。

**看估计角度和编码器实测角度的差值。**

这是观测器调得好不好的终极判据。稳态时，差值应该在零附近小幅波动——波动幅度反映的是角度估计精度。动态加减速时，差值允许暂时变大，但应在目标动态指标内收敛回来。如果差值持续偏离零越来越大，说明观测器发散，要么增益太小，要么模型参数严重失配。

我通常把编码器角度和估计角度同时导出到调试上位机，先计算 `wrap_to_pi(theta_est - theta_enc)` 消除角度 wrap 带来的假跳变，再把差值信号输出到示波器。稳态时这条差值线应该像一条平静的细河，贴着零轴。如果它单向漂移，像失去控制的汽车，说明模型参数有问题，赶紧查电阻和电感。如果有规律地起伏，可能是 LPF 相位延迟、PLL 带宽、逆变器非线性或延迟补偿不足——需要逐项排查。

## 两个直觉陷阱

### 陷阱 1："抖振是 bug，要想办法彻底消除"

我第一次调 SMO 的时候，盯着示波器上的高频抖动，心里只有一个念头：把这该死的噪声干掉。

加滤波。在 LPF 后面再串一个 LPF。不行，相位延迟太大，角度滞后明显。

降增益。K\_slide 从 1000 降到 200。抖振小了，但负载一变，估计角度慢悠悠地跟不上，速度环开始振荡。

甚至想换 smooth 函数替代 sign——用饱和函数、用 Sigmoid、用双曲正切。波形确实平滑了，但如果边界层太厚、斜率太小，或者替换后没有重新整定增益与补偿策略，零附近的等效增益会下降，参数漂移时更容易出现稳态误差或动态响应变慢。

后来才明白：抖振不是 bug，但需要管理。

sign 的高频切换是 LPF 提取等效控制量的信息来源。如果你用过度平滑的方式（比如极厚的边界层或级联多阶 LPF）把抖振彻底抹平，零附近的等效增益会被大幅压低，等效控制量的信息就可能受损。这就像你把橡皮泥表面的纹路全部抹平了，手指也就摸不出硬币在哪了。

但换个思路：用饱和函数、滞环或适度边界层来抑制抖振——这是工程常态——并不会切断信息渠道，只是在抖振幅度和零附近增益之间做折中。工程文档 AN1078 里提到的 MaxSMCError 内线性输出、学者 Kim 等人提出的 sigmoid 替代 signum，走的都是这条路。

工程上不是消除抖振，而是**管理抖振**。

具体怎么做？我总结了三条实战经验。

第一，让抖振的周期足够短，远小于电机机械时间常数（或者说，抖振频率远高于机械系统带宽）。控制周期通常在数十微秒级，电机机械时间常数在毫秒级，这个条件一般天然满足。抖振频率越高，对机械系统的耦合影响越小。如果你发现电机在低速时抖得特别厉害，有时候不是 K\_slide 的问题，是控制周期太长——sign 切得不够快，平均效应弱了。试试把电流环周期从 100 μs 缩短到 50 μs，抖振往往会有明显改善。

第二，让抖振的幅度足够小，不引起电流环振荡。K\_slide 不是越大越好，找到一个"能跟踪、不震荡"的平衡点。K\_slide 的单位与 z 相同（电压等效量），整定起点可参考电机额定转速下的最大 BEMF 幅值，再结合模型不确定性留一定裕量。不同实现可能使用归一化值或定点缩放值，不能直接照搬 V 单位。实际工程中通常先给一个保守值，逐步加大，直到导出的角度估计信号出现明显高频抖动，再往回退 20%-30%。

第三，靠低通滤波器把抖振隔离在角度估计之外。LPF 的截止频率需要高于目标最高电角频率（或 BEMF 基波频率），让真实信号顺利通过；同时低于抖振/采样相关的高频分量，把噪声衰减掉。具体数值因电机最高转速、极对数、采样率、LPF 阶数和相位补偿策略而异。AN1078 的做法是让截止频率跟随电频率以保持固定相移；对大多数中小功率 PMSM，若采用一阶 LPF 且无额外相位补偿，角频率设在 500-2000 rad/s 是一个可尝试的起点。

说白了，抖振是 SMO 的"呼吸"。你不需要让它停止呼吸，只需要不让它的呼吸声吵到邻居。

### 陷阱 2："sign 函数太粗暴，换平滑函数更好"

这个念头几乎每个调过 SMO 的人都想过。饱和函数、Sigmoid、双曲正切——都是"更温和"的选择。

温和确实能减抖振，但代价是鲁棒性。

sign 函数的理想特性是：无论误差多小，输出幅度永远是 ±K\_slide。这意味着它在零附近提供"无限增益"——哪怕误差只有 0.001A，sign 也会按全额 K\_slide 修正。这种极端响应是 SMO 不怕参数漂移的底气。

我给你对比个数值。

假设 K\_slide = 10（单位：V，示意值），电流误差是 0.01A。

sign 的输出：10 × 1 = 10。全额修正，毫不犹豫。

饱和函数（边界层厚度 0.1A）的输出：误差 0.01A 在边界层内，线性输出 = 10 × (0.01 / 0.1) = 1。只有 sign 的十分之一。

误差再小一点，0.001A。sign 依然输出 10。饱和函数输出 0.1。差距拉到一百倍。

参数漂移了，小误差累积起来。如果边界层厚度远大于实际误差范围，饱和函数的输出被压缩得几乎为零，等效增益大幅下降，估计值就慢慢跑偏。理想 sign 不管多小的误差，一律按全额 K\_slide 修正。

说白了，sign 的粗暴不是缺点，是它在"参数不确定"环境下的生存策略。

平滑函数像 Diplomat（外交官），讲究策略、留有余地。sign 函数像 Bouncer（夜店保安），不讲道理，只认方向。电机参数漂移的时候，你更需要保安，而不是外交官。

当然，很多工程实现会用饱和函数、滞环或边界层替代理想 sign——纯理想 sign 在零点附近会无限震荡。但理解 sign 的理想特性，是理解所有折中方案的前提。

饱和函数的本质是什么？它在零附近给 sign 套了一个"缓冲垫"——小误差的时候轻轻按，大误差的时候才用力捏。这个缓冲垫的厚度叫"边界层"，是我们本周及下周要细讲的内容。现在你只需要记住：边界层越厚，抖振越小，但鲁棒性越差。边界层越薄，越接近理想 sign，鲁棒性越好，但抖振越凶。

工程上选边界层厚度，就像选床垫的软硬——没有 universally 最好的，只有最适合你的电机的。风机泵类负载，转速变化慢，边界层可以厚一点，优先平滑。伺服关节，动态响应要求高，边界层要薄，宁愿抖一点也要跟得上。

## 调试 Checklist

\[ \] 确认抖振周期远小于电机机械时间常数（控制周期通常在数十微秒级，电机机械时间常数在毫秒级，一般满足条件；具体数值因电机而异）  
\[ \] 确认低通滤波截止频率高于目标最高电角频率（或 BEMF 基波频率）、低于抖振/采样相关高频分量（典型经验值需结合电机最高转速、极对数、相位补偿策略调整）  
\[ \] 观察估计角度：稳态时无低频漂移，动态加减速时跟踪无明显滞后  
\[ \] 区分"抖振"和"发散"：抖振是围绕真实值的高频震荡；发散是估计值持续偏离真实值，越来越大  
\[ \] 检查电流采样质量：ADC 噪声大时，即使 K\_slide 合理，抖振也会加剧——先解决硬件，再调软件
