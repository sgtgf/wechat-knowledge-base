# 基于混合特征的非刚性点阵配准算法

原创 自动化学报 2016-12-06 15:58 北京

> 原文地址: [https://mp.weixin.qq.com/s/t05obNxQqli-VUy6ktfvog](https://mp.weixin.qq.com/s/t05obNxQqli-VUy6ktfvog)

非刚性点阵配准（Non-rigid Point Set Registration）是将某一点阵与其发生形变后的点阵进行匹配的过程。该技术在计算机视觉、机器学习、医学图像处理、模式识别、地理信息系统中都有着极其广泛的应用。

我们提出了一种基于混合特征的非刚性点阵配准算法。本文算法包含了对应关系评估与空间变换更新两个相互交替的步骤。我们首先定义了两个特征描述法用于描述两个点阵之间的全局和局部几何结构差异，随后合并这两个特征描述法建立一个基于混合特征的能量优化方程。该能量优化方程可以利用线性分配技术进行求解，同时可以灵活地选择使用最小化全局结构特征差异或最小化局部结构特征差异来评估两个点阵之间的对应关系。为了增强前述两个步骤之间的协调性，我们利用能量权重调节算法使在整个配准过程中控制能量优化从最小化局部结构特征差异逐步转变为最小化全局结构特征差异，同时控制用于空间变换的薄板样条函数（Thin Plate Spline）的更新从刚性逐步转变为非刚性变换。我们对本文算法进行了各项性能测试, 同时也与当前8 种流行算法进行了性能比较。本文算法展现了卓越的非刚性配准性能，并在大部分实验中超越了当前的相关算法。图1给出了本文算法的伪代码。

Line、Fish1、Fish2、Chinese character 和3D Face 是非刚性点阵配准算法在轮廓点阵配准测试中普遍使用的流行点阵。我们将本文算法与CPD、TPS-RPM、GMMREG进行了实验测试，本文算法都展现了良好的配准性能，在大多数实验中，都超越了其它算法。图2给出了Fish1点阵配准实例。

  在序列图像配准中，我们采用CMU House和Hotel序列图像进行测试。本文算法都给出了最高的配准率。图3给出了CMU House序列图像配准实例。

  在图像特征点实验中，我们从Pascal 2007 Challenge数据库中挑选出测试数据集。本文算法同样给出了最高的配准率。图4给出了Pascal 2007 Challenge Car Datasets 配准实例。
