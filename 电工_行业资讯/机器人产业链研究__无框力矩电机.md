# 01

机器人中用到的电机类型有哪些

在机器人领域，电机作为关键的驱动部件，其类型多样，主要包括以下几种：

1.  **步进电机：**以精确控制步进角度著称，适用于需要精确定位的应用。
    
2.  **伺服电机：**提供快速响应和精确控制，广泛应用于需要高动态性能的场合。
    
3.  **力矩电机：**以输出较大的扭矩和转速范围广而受到青睐，适合力矩控制应用。
    
4.  **异步电机：**结构简单，成本较低，但控制精度相对较低。
    
5.  **永磁同步电机：**高效率和高性能，适用于需要高功率密度的应用。
    

不同类型的机器人根据其设计和功能需求，会选择适合的电机类型。例如，工业机器人倾向于使用伺服电机和步进电机，**而人形机器人则更多采用无框力矩电机和空心杯电机。**

# 02

无框力矩电机是什么

  

  

无框力矩电机是力矩电机的一种，它以输出的扭矩大小作为性能指标，通常也是永磁电机的一种。这种电机通过磁场的相互作用驱动转子转动，产生扭矩，适用于驱动人形机器人的关节。

与有框力矩电机相比，无框力矩电机省略了电机的外壳，仅保留转子和定子两个核心部件。这种设计使得电机能够更直接地集成到机器人关节中，提供了更大的设计灵活性，并且减少了机械传动损失，提高了扭矩密度、散热性能和静音能力。

无框力矩电机通常具有较多的极数，能够在低速甚至堵转的情况下持续工作而不损坏。在低速运行时，它能提供稳定的力矩，且在负载增大时能够自动降低转速并增加输出扭矩。这种电机具有低转速、大扭矩、过载能力强、响应快、线性度好和力矩波动小等特点。

# 03

无框力矩电机在人形机器人中的应用

  

  

  

无框力矩电机因其快速响应、高功率密度、高效率和高灵活度等特性，非常适合人形机器人关节的需求。

**快速响应：**无框电机从获得指令信号到完成指令所要求的工作状态的时间应短，适用于需要频繁启停、灵敏响应的人形机器人领域。

**高功率密度：**无框电机消除了传统电机的铁芯，结构紧凑小巧，可实现更高的功率密度。适用于需要高功率输出的人形机器人关节部件。

**高效率：**无框电机采用了新型的电磁铁和轴承结构，具有低能耗和低摩擦的特点。适用于工作强度大，承载需求高的人形机器人应用场景。

**高灵活度：**无框电机体积小、质量小、轴向尺寸短、设计灵活性高，适合机器人关节这种空间受限并且高度定制化的应用。

# 04

无框力矩电机市场现状

  

  

无框力矩电机的价格因功率段和尺寸不同而有所差异，但整体价格区间大致在几百元到一千多元之间。随着生产规模的扩大和制造工艺的创新，预计价格有进一步下降的空间。

目前，全球力矩电机市场规模正在增长，预计到2030年，随着人形机器人的商业化，无框力矩电机的市场空间将进一步扩大。根据海外市场研究公司Technavio的统计数据，2023年全球力矩电机市场规模增长6.95%至6.57亿美元。而到2030年，由于人形机器人中无框力矩电机需求量级较为可观，随着人形机器人逐渐实现商业化，无框力矩电机市场空间亦将随之增长。若以2030年人形机器人出货量达100万台，同时无框力矩电机产品单价下降一半到500元/台来估算，预计人形机器人领域无框力矩电机市场空间将达到23.97亿美元，叠加传统领域市场空间的平稳增长，总市场规模将达到33亿美元。
