# 降压电路在实际工作时处于哪种导通模式

原创 电源先生 电路一点通 2025-05-19 11:28 广东

> 原文地址: [https://mp.weixin.qq.com/s/6UyRe6-HROxkBQtApZb8Lg](https://mp.weixin.qq.com/s/6UyRe6-HROxkBQtApZb8Lg)

_**01**_

_**/ 简介 /**_

![图片](D:\电脑文件\公众号知识库\电力电子_DC_DC变换器\降压电路在实际工作时处于哪种导通模式_images\img_000_4fe9ef2e87f4.other)

图 2.33 非同步和同步降压电路拓扑

首先，从功率电感上的电流是否连续的角度看，降压电路最基本的三种电流传导模式分别为连续导通模式CCM（Continuous Conduction Mode）、临界导通模式BCM（Boundary Conduction Mode）或CRM（Critical-Conduction Mode）、断续导通模式DCM（Discontinuous Conduction Mode）。

其次，强迫连续导通模式FCCM（Forced Continuous Conduction Mode），是使用技术手段强制电路工作在CCM模式下，本质上仍然属于CCM。FCCM有时也被称为FPWM（Forced Pulse Width Modulation）。

再次，降压电路控制器或转换器都能够在CCM、BCM和DCM模式之间自动切换（也就是所谓的“Auto Mode”），这需要在IC设计之前充分考虑尤其是CCM和DCM两种模式在控制策略上的差异。

最后，图 2.33所示，在同步降压电路工作在轻载条件下，可以通过始终保持低边MOSFET关断，利用其体二极管实现等同于非同步降压电路DCM模式，被称为DEM（Diode Emulation Mode）导通模式（参考\[ [什么是DCM？什么是DEM？二者等同吗？](http://mp.weixin.qq.com/s?__biz=MzIyMzY1NjcxMg==&mid=2247486344&idx=1&sn=8eafc9bb7264d8ea4a4d99d5fe60dfdd&chksm=e81ba5efdf6c2cf9127973a92c46c3498f29e50d55d71a029d66a6e15fbe794ef250fa04472b&scene=21#wechat_redirect) \]）。

另外，需要说明的是，针对非同步降压电路，低边开关为续流二极管（图 2.33所示，因为续流二极管D1的单向导通特性，不能支持反向电流），只支持CCM、BCM、DCM和Auto Mode这4种导通模式。而在同步降压电路中，低边开关通常为N-MOSFET，能够实现CCM、BCM、DCM（DEM）、FCCM和Auto Mode这5种导通模式。

综合来看，降压电路通常有CCM、BCM、DCM、DEM、FCCM和Auto Mode这6种导通模式。

_**02**_  

_**/ 连续导通模式 CCM /**_

![图片](D:\电脑文件\公众号知识库\电力电子_DC_DC变换器\降压电路在实际工作时处于哪种导通模式_images\img_001_b09c428942c2.png)

图 2.35 连续导通模式 CCM

在一个开关周期（T\_SW）内，电感电流（或电感存储的磁场能量）始终大于零，或者说电感从不“复位”，意味着在开关周期内电感磁通从不回到零，电感线圈中始终有电流流过。

在开关管导通（T\_ON）期间，电感电流是上升的；在开关管关断（T\_OFF）期间，电感电流是下降的（但是，电感电流不会减小到零，下个周期开关管导通时，电感电流重新上升）。

图 2.35所示，降压电路工作在CCM模式的条件是，负载电流大于纹波电流（峰峰值）的一半（即 I\_OUT > ∆i\_L/2 ）。

_**03**_  

_**/ 临界导通模式 BCM /**_

![图片](D:\电脑文件\公众号知识库\电力电子_DC_DC变换器\降压电路在实际工作时处于哪种导通模式_images\img_002_a240857d165b.png)

图 2.36 临界导通模式 BCM

控制器始终监测电感电流，当检测到电感电流为零时，立即打开功率开关管Q1（控制器总是等电感电流“复位”来打开功率开关管Q1，参考图 2.34）。

图 2.36所示，降压电路工作在BCM模式的条件是，负载电流等于纹波电流（峰峰值）的一半（即 I\_OUT = ∆i\_L/2 ），这是显而易见的，所以也被称为CCM与DCM的“关键条件”（参考\[ [BUCK电路CCM与DCM的临界条件是什么？](http://mp.weixin.qq.com/s?__biz=MzIyMzY1NjcxMg==&mid=2247484760&idx=1&sn=2fb59822b16c4517b9fd00b632f26fd2&chksm=e81bab3fdf6c22293a36432392e7568ae587b53b2e32d7cb29da06a821a4b7afb801bb213ac7&scene=21#wechat_redirect) \]）。

_**04**_  

_**/ 断续导通模式 DCM /**_

![图片](D:\电脑文件\公众号知识库\电力电子_DC_DC变换器\降压电路在实际工作时处于哪种导通模式_images\img_003_80458bd3c2e1.png)

图 2.37 断续导通模式 DCM

在非同步降压电路中，因为纹波电流峰峰值不随输出负载电流而变化，如果电感电流试图下降到零以下，它只会在零处停止并保持（图 2.33所示，因为续流二极管D1的单向导通特性，不能支持反向电流），直到下一个开关周期开始，这就是断续导通模式（DCM）。

图 2.37所示，降压电路工作在BCM模式的条件是，负载电流小于纹波电流峰峰值的一半，即 I\_OUT < ∆i\_L/2 。

_**05**_  

_**/ 强迫连续导通模式 FCCM /**_

![图片](D:\电脑文件\公众号知识库\电力电子_DC_DC变换器\降压电路在实际工作时处于哪种导通模式_images\img_004_8477c97da497.png)

图 2.38 强迫连续导通模式 FCCM

FCCM （ Forced Continuous Conduction Mode ），有时也称为FPWM（ Forced Pulse Width Modulation ）模式，这是一种特殊的CCM模式，即使电源工作在轻载条件下，整个关断期间（T\_OFF）内都强制低边开关管持续导通实现电感电流始终连续。

这里需要注意的是，只有同步降压电路才能实现FCCM模式，因为同步降压电路中使用的低边开关管MOSFET是双极性器件，导通电流可以是从源极到漏极，也可以从漏极到源极；非同步降压电路因为其低边开关管是续流二极管，不支持反向电流，从而不能支持FCCM模式。

_**06**_  

_**/ 实际工作于哪个模式？ /**_

降压电路在实际工作时处于哪种导通模式，取决于负载电流大小：

当负载电流大于纹波电流的一半（即 I\_OUT > ∆i\_L/2 ）时，降压电路工作在CCM模式；

当负载电流等于纹波电流的一半（即 I\_OUT = ∆i\_L/2 ）时，降压电路工作在BCM模式；

当负载电流小于纹波电流的一半（即 I\_OUT < ∆i\_L/2 ）时，降压电路工作在DCM模式。
