# 工作原理如图: 普通电烤箱有上.下两个加热器，加热器一般采用金属管状加热元件。如图所示电路为家庭普通型电烤箱电路，开关S1.S2分别控制上下加热器的接通与断开，同时两只指示灯分别显示上、下加热器的工作状态。

# 恒温器在设定的温度范围内交替地接通与断开，实现恒温功能，温度控制采用金属片调温器，温度控制范围为100~250℃，定时器一般采用发条式定时器(見图)。

![](D:\电脑文件\公众号知识库\电工_教育_学习\家用普通电烤箱工作原理电路图_images\img_003_d0be0641fa9a.jpg)

# 当食物加热时，S1.S2开关同时开通上下加热器RL1.RL2(250℃)，这时EL1显示亮;当食物加热到适中时，S1开关断开，只有S2工作(RL2加热)，双金属片跳开处于恒温状态(100℃)，这时EL2指示灯亮。

# 发条定时器调到你食物所适合时间，自行关断电源。
