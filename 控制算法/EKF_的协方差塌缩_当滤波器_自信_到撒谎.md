# EKF 的协方差塌缩：当滤波器"自信"到撒谎

原创 傅存敬 电磁散人 2026-07-04 07:04 广东

> 原文地址: [https://mp.weixin.qq.com/s/q\_tc6OX54M96qQqBznjB8g](https://mp.weixin.qq.com/s/q_tc6OX54M96qQqBznjB8g)

先讲一个你大概率见过的场景。

一台压缩机驱动器，无感 FOC，转子位置全靠一个扩展卡尔曼滤波器估出来。台架上跑了三个星期，波形干净得像教科书，估计角和实际角贴得严丝合缝，你甚至有点得意。于是它出厂了。

装到现场，头半个钟头一切正常。然后电机慢慢热起来。定子铜阻随温度往上爬，永磁体的磁链悄悄往下掉——现场这台电机，其实已经不是台架上那台电机了。估计角开始漂，一开始一两个电角度，你没在意；五度、十度，电流波形肉眼可见地歪了，效率往下走；再往后，转子干脆丢步。

你把日志拉回来复盘，最先让你不安的，不是那个越来越大的角度误差，而是它旁边那一列数——滤波器自己报告的协方差 P。小得可怜，漂亮得像什么事都没发生过。

一个估计已经错得离谱的观测器，正用一个极小的 P 告诉你：我很准。

它并不是坏了，只是太相信自己了。这件事值得慢慢想一想。

我们都愿意相信，卡尔曼滤波器是一个很聪明的裁判。

它手里有两份证词。一份来自模型：根据电压方程和上一时刻的状态，它能算出这一时刻的电流大概是多少，这是预测。另一份来自传感器：采样电阻上真实测到的电流，这是测量。两份证词往往对不齐，滤波器要做的，就是在中间找到一个恰当的落点。

这个落点落在哪儿，取决于一个叫卡尔曼增益的东西。把它写成最朴素的标量形式：

**K = P⁻ / (P⁻ + R)**

P⁻ 是预测的方差，代表模型这份证词有多不可靠；R 是测量噪声的方差，代表传感器那份证词有多不可靠。你盯着这个式子看一会儿，会发现它其实就是一个信任的旋钮。

R 大了，传感器一身杂波，K 就趋近于 0，滤波器几乎不理测量，闷头信自己的模型。P⁻ 大了，模型自己都心虚，K 就趋近于 1，滤波器扭头跟着测量走。它总是把权重投给那个此刻看起来更靠谱的一方。

这套逻辑漂亮得让人安心，于是我们顺理成章地推想：温度升上来，模型算不准了，P 这边该心虚了，滤波器自然会转过去多信传感器，把温漂带来的误差纠回来。取其精华，去其糟粕，多好。

可惜，那个“自然会转过去”，是我们一厢情愿的推想。

拆开来看就知道了。一个 Q、R 都固定的普通 EKF，增益 K 并不会随着温度实时变化，它会在开机后收敛到一个稳态值，然后就基本钉在那儿不动了。绕组电阻每升高一度涨千分之四，磁链一点点掉下去，模型于是带上了一个持续的、单向的偏差。而这个死心眼的滤波器压根不会意识到这是参数出了问题——它只会拿着那个早就算好的旧增益，继续不紧不慢地融合，稳稳地留下一个纠不回来的估计误差。

也就是说，面对温漂，一台默认配置的 EKF，干的恰恰不是你想象中的那件聪明事。

更麻烦的是 Q 的影响。Q 是过程噪声的方差，你把它调小，等于在对滤波器说：我的模型极准，你放心信。滤波器听话了，于是 P 随着每一步递推越缩越小，增益也跟着越来越小，测量越来越推不动它。到某个点上，只要真实状态开始漂移，它已经追不回来了——因为那个唯一能纠正它的证据，它已经不怎么听了。

这就是开头那一幕的由来。它一边错得离谱，一边报告一个极小的 P，这两件事不是自相矛盾，恰恰是同一件事的两面：它之所以敢报告这么小的 P，正是因为它早就不听测量了；而它之所以错，也正是因为它不听。

![](EKF_的协方差塌缩_当滤波器_自信_到撒谎_images/img_001_779f46ad72b7.png)

这个失效模式在教科书里有自己的名字，叫滤波器发散。它的机理也有名字，叫协方差塌缩。

而它对应的那个认知现象，同样早有人研究过。你可能会联想到 “知识的诅咒” 这个说法，放到更精确的语境里，它叫保守性偏误：面对新证据，更新得太少，把它系统地看轻了。往深了说，是信念固着——手里的信念一旦足够强，新来的东西就撼不动了。写成数学不过一句话：P 越小，增益越小，测量几乎进不来。不是没看见，是看见了，却不再采信。

在人的脑子里，先验偏见有时候还只算一种思维倾向。可是在滤波器里，它是一个实实在在的 bug。

不过话说到这里，容易滑向另一个极端——既然毛病出在太固执，那把 Q 使劲调大，让滤波器多听听测量，总行了吧。

其实也不行。Q 一大，P⁻ 长期居高不下，增益长期趋近于 1，滤波器就被每一个测量噪声推得东倒西歪，估计值抖成一片，平滑不下来。它等于没有了记忆，风往哪吹就信哪个最新的数。

所以滤波器其实有两种截然相反的病。

![](EKF_的协方差塌缩_当滤波器_自信_到撒谎_images/img_002_001ed0318d76.png)

Q 太小，是教条——错得笃定，听不进新证据。Q 太大，是轻信——谁说最后一句它信谁，被噪声牵着满地跑。一个太硬，一个太软。而调卡尔曼滤波器这件事的本质，就是在这两种病之间，找到那个信得够狠、又谦虚得住的地方。硬到能滤掉杂波，软到能追上变化。

与其说最优增益是一个数字，不如说它是一次校准得恰到好处的信念。

那件聪明事——你一开始以为滤波器天生就会的那个 “该信谁信谁” ——其实得靠工程师亲手造进去。造法不止一种，但你把它们摆到一块儿看的时候会发现，开的全是同一味药：给滤波器灌谦逊。

最直接的一招，是把参数本身也当成状态来估。定子电阻、磁链，本来是模型里写死的常数，现在把它们也塞进状态向量，让滤波器一边估转子位置，一边估这两个会随温度漂的家伙。温度一变，它能跟着把参数修正过来，模型就不会一直拿着过时的自己去算了。这叫增广——说白了，就是不许模型把 “我是谁” 当成一劳永逸的定论。

而更有意思的一招，在更高一层：让滤波器去检查自己的自信本身准不准。

这里要请出一个量，叫新息，就是测量值减去预测的测量值：

**ν = z − Hx̂⁻**

它是现实和预期之间的那道缝。这道缝该有多大，滤波器心里其实有数，它能算出新息应有的协方差：

**S = H P⁻ Hᵀ + R**

关键就在这一步了。如果实际跑出来的新息，长期比 S 预测的还要大一大截，这说明什么呢？说明现实在反复给滤波器一个信号：你以为你有多准——那个小小的 P——其实是你高估了自己。这时候自适应算法就该出手了，把 P 撑大一点，让增益回升，让滤波器重新听得进测量。

这一层的味道和前面不太一样。前面所有的融合，都是滤波器在用证据修正它对世界的估计；到这一层，它开始用证据修正它对自己的估计——修正它对 “我到底有多大把握” 这件事的把握。它不光在问 “世界是什么样” ，还在问 “我凭什么这么确信” 。

![](EKF_的协方差塌缩_当滤波器_自信_到撒谎_images/img_003_fecce44a5481.png)

剩下的招数也都顺着这个方向走。加遗忘因子，让老数据按指数打折，先验的自信就没法一年年无限攒下去。给 P 硬设一个下限，不许它缩到零，等于按住滤波器的肩膀跟它讲：话别说太满。

回头看这一整箱工具，没有一件是在教滤波器变得更聪明，全是在教它别那么轴。

讲到这里，关于滤波器，该说的其实已经说完了。危险不在它知道得多，在它知道得太硬；解药不在让它少知道，在别让它把已知的东西攥死。

而两千三百年前，有个人拿一把刀，把同样的话也讲完了。

《庄子·养生主》开篇一句话，大概是全篇被引用得最多、也被误读得最深的一句：

> 吾生也有涯，而知也无涯。以有涯随无涯，殆已。

几乎所有人读到这儿就停了，然后得出一个有些丧气的结论：知识无穷无尽，拿有限的一生去追，是自寻死路，所以人还是别较劲、少知道点好。

可你只要再往下读几句，就会撞见庖丁。

这是中国文学里最锋利的一个匠人。他解牛十九年，一把刀「若新发于硎」，跟刚从磨刀石上下来一样。凭什么？「依乎天理，批大郤，导大窾」——顺着筋骨天然的缝隙走，避开骨头，专挑空当下刀。他知道得极多，却从不拿一套固定的招式往牛身上硬抡；每一头牛的真实纹理，他都当成新的，重读一遍。

这就有些奇怪了。庄子要真觉得「少知道点好」，他为什么紧接着就捧出一个技艺登峰造极的人？

大概只有一个解释：开篇那句不是结论，是设问。真正的答案，在庖丁那把刀上。

现在不妨把这个故事和前面那台滤波器叠在一起，慢慢看。

那个「族庖，月更刀」的普通厨子，一个月就得换一把刀，因为他拿死办法硬砍骨头。他像不像那台协方差塌缩的滤波器？模型攥得死死的，撞上现实照旧硬来，很快就崩了。

而庖丁呢，知道得极多、却让每一刀都跟着眼前这头牛的真实纹理走——他像不像那台调好了的自适应滤波器？

那把十九年不卷刃的刀，说到底，就是长期维持的、极低的估计误差。

你看，两个相隔两千三百年的故事，讲的竟然是同一件事。庄子没有把危险安在 “知道得多” 上，卡尔曼也没有。他们都把它安在同一个地方：知道得太硬。而他们开出的药方，也是同一味——别让你已经知道的东西，硬到听不见下一个证据。

庖丁的办法，是每一头牛都重新读一遍纹理，不拿昨天的经验替今天的现实做主。滤波器的办法，是往自己的确信里不停地兑入谦逊，留一条缝，让新息还能走进来。

说到底，真正锋利的，从来不是那些最硬的东西。刀如此，滤波器如此，人大概也是如此。

保持锋利的办法，不是把自己磨得更硬，而是别让自己硬到不肯顺着纹理走。
