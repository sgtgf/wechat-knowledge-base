#### 一、 “幽灵”在哪里？—— 经典公式的“阿喀琉斯之踵”

我们先把那个“眉清目秀”的经典公式请上台：

Id = (-Ψm + √(Ψm² + 4\*(Ld\-Lq)²\*Iq²)) / (2\*(Ld\-Lq))

这个公式在数学家的纸上，是完美的，是无懈可击的。但在MCU的“眼里”，它有一个致命的弱点，一个“阿喀琉斯之踵”！

这个弱点，就藏在电机空载或极轻载的时候！

请同仁们跟我一起做如下的情景模拟：

当电机几乎不出力的时候，转矩电流 `Iq` 会非常非常小，趋近于0。 这时候，我们来看根号里的那一大坨：`√(Ψm² + 4*(Ld-Lq)²*Iq²),``Iq²` 接近0，那么 `4*(Ld-Lq)²*Iq²` 这一项也无限接近于0。 所以，根号下的结果就无限接近于 `√(Ψm²)`，也就是 `Ψm`！

好了，最恐怖的一幕发生了！我们再看整个分子：`` (-Ψm + `√(Ψm² + 4*(Ld-Lq)²*Iq²)` ``它就变成了： `(-Ψm + 一个和Ψm极其接近的数)`

这叫什么？这在数值计算领域，有一个臭名昭著的名字——“灾难性抵消” (Catastrophic Cancellation)！

这就像什么呢？想象一下，你有两根百米长的钢尺，它们的长度只有一粒灰尘的差距。现在，我让你把这两根钢尺并排摆好，然后用你手里的小学生尺子，去测量它们末端的那个微小差距。

你能测准吗？绝对不能！因为两根钢尺本身的制造误差、热胀冷缩，都会远远大于那个微小的差距。你用一个巨大的、不精确的量，去减掉另一个巨大的、不精确的量，想得到一个微小的、精确的结果，这本身就是一场灾难！

在单片机里，`Ψm` 是一个浮点数，它本身就不是100%精确的，只能存储有限的有效数字。`√(Ψm² + √(Ψm² + 4*(Ld-Lq)²*Iq²)` 的计算结果也是。当你用一个“约等于`Ψm`”的数，去减另一个“约等于`Ψm`”的数时，它们前面那些相同的大部分有效数字都被相互抵消了，最后剩下的，几乎全是之前计算过程中累积的“噪声”和“垃圾”！

后果是什么？

当 `Iq` 应该等于0时，我们理论上算出来的`Id`也应该等于0。但是因为“灾难性抵消”，你的MCU算出来的`Id`可能是一个非常小的、毫无意义的、甚至在正负间疯狂抖动的“垃圾数”！

这个“垃圾数”被送到电流环里，你的电机就会在空载的时候发出“嗡嗡”的异响，轻微抖动，电流不稳定！这就是那个“浮点数幽灵”在作祟！

我们再来一次情景模拟

当 `Iq` 趋近于0时，`bQ = Iq²*(Ld-Lq)²` 也趋近于0。 我们来看里面的那个根号：`√(4*bQ + bW) = √(0 + Ψm²) = Ψm`。

再看外面那个大根号：`√(16*bQ - 4*Ψm*√(4*bQ+bW) + 5*bW)``≈ √(0 - 4*Ψm*Ψm + 5*Ψm²)` `= √(-4*Ψm² + 5*Ψm²)` `= √(Ψm²) = Ψm`

最后，我们看整个分子：`(√(16*bQ - 4*Ψm*√(4*bQ+bW) + 5*bW) - Ψm ) ≈ (Ψm - Ψm) = 0`

**关键区别在哪里？**

可能有同仁会问：“这最后不还是 `Ψm - Ψm` 吗？怎么就不灾难了？”

问得好！关键在于**计算的路径**！

这就像，你不是用两根百米钢尺去比了，而是通过一套精密的、由多个齿轮和杠杆组成的仪器，把那个微小的差距给**放大**了，然后再去测量。虽然看起来笨重又复杂，但结果却精准得多！

**我们的目标**：证明下面这两个`Id`表达式是等价的。

**嫌疑人A：教科书公式**

**嫌疑人B：代码中的公式**

为了方便推导，我先把它还原一下，把`bQ`和`bW`代回去：

`bQ = Iq² * (Ld-Lq)²`

`bW = Ψm²`

则有：

Id = (√(16\*Iq²\*(Ld\-Lq)² - 4\*Ψm\*√(4\*Iq²\*(Ld\-Lq)² + Ψm²) + 5\*Ψm²) - Ψm) / (4\*(Ld\-Lq))

**侦破思路：**

直接从A推到B或者从B推到A，都像在走迷宫，太复杂了！我们换个思路：如果A和B是同一个人，那么他们“整容”前的样子——也就是推导出他们的那个“一元二次方程”——应该是同一个！

从我[上一讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247484410&idx=1&sn=41857e59fb5e8ef4f6af2cc9ae5a656e&scene=21#wechat_redirect)的推导中，我们有一个中间步骤，在代入`Im² = id² + iq²`之后、化简成最终`Id=f(Iq)`之前，可以得到这样一个关系式（这是很多论文里的标准形式）：

**`Ψm*Id + (Ld - Lq) * (Id² - Iq²)`** 

这个关系式就是MTPA的“DNA”！所有正确的MTPA公式，都必须满足这个方程！

处女座情节犯了，再在此附录证明过程中俄罗斯套娃式地简单讲一下这个DNA公式是怎么来的，要不担心同仁们有疑问。

PMSM输出的电磁转矩为：永磁磁链**`Ψm`**与定子合成电流矢量**`Is`**的叉乘结果的极对数**`p`**倍，即

**`Te = pΨm×Is`**

不考虑作为常数项的极对数**`p`**的影响，电磁转矩在dq坐标系下的标准表达式为

**`Te ∝ ψd·Iq − ψq·Id`**，

且有

**`ψd = ψm + Ld·Id`**

**`ψq = Lq·Iq`**

则：

**`Te ∝ (ψm + Ld·Id)·Iq − (Lq·Iq)·Id = ψm·Iq + (Ld − Lq)·Id·Iq`**

记 **`f(Id, Iq) = ψm·Iq + (Ld − Lq)·Id·Iq`**，  

在电流圆约束下的MTPA的约束条件为：

**`g(Id, Iq) = Id² + Iq² − Im² = 0`**，  

用拉格朗日乘子法，构造

**`L(Id, Iq, λ) = f(Id, Iq) + λ·(Im² − Id² − Iq²)`**

求驻点条件：

①**`∂L/∂Id = (Ld − Lq)·Iq − 2λ·Id = 0`**  

②**`∂L/∂Iq = ψm + (Ld − Lq)·Id − 2λ·Iq = 0`**  

③**`∂L/∂λ = Im² − Id² − Iq² = 0`**（即约束）

由①得：

**`λ = (Ld − Lq)·Iq / (2Id)`**

由②得：

**`λ = [ψm + (Ld − Lq)·Id] / (2Iq)`**

两式相等，消去 λ：

**`(Ld − Lq)·Iq / (2Id) = [ψm + (Ld − Lq)·Id] / (2Iq)`**

两边乘以 2Id·Iq：

**`(Ld − Lq)·Iq² = ψm·Id + (Ld − Lq)·Id²`**

移项并整理，得到

**`ψm·Id + (Ld − Lq)·(Id² − Iq²) = 0`**

### 第一步：验证“嫌疑人A”（教科书公式）

我们把“嫌疑人”A公式变形一下：

2\*(Ld\-Lq)\*Id + Ψm = √(Ψm² + 4\*(Ld\-Lq)²\*Iq²)

两边平方，得到：

4\*(Ld\-Lq)²\*Id² + 4\*(Ld\-Lq)\*Id\*Ψm + Ψm² = Ψm² + 4\*(Ld\-Lq)²\*Iq²

两边的`Ψm²`消掉：

4\*(Ld\-Lq)²\*Id² + 4\*(Ld\-Lq)\*Id\*Ψm = 4\*(Ld\-Lq)²\*Iq²

两边同时除以`4*(Ld-Lq)`（假设`Ld≠Lq`）：

(Ld\-Lq)\*Id² + Ψm\*Id = (Ld\-Lq)\*Iq²

移项，得到：

**`Ψm*Id + (Ld - Lq) * (Id² - Iq²) = 0`**

**【结论】**：**完美匹配！嫌疑人A的DNA比对成功！** 它确实是MTPA的正统解。

### 第二步：验证“嫌疑人B”（代码中的公式）

这步是硬骨头！大家跟紧了！ 我们把B公式也变形一下。为了书写方便，我们令 `Lrel = Ld - Lq`。则有：

`4*Lrel*Id + Ψm = √(16*Iq²*Lrel² - 4*Ψm*√(4*Iq²*Lrel² + Ψm²) + 5*Ψm²)`

两边平方，得到：

`16*Lrel²*Id² + 8*Lrel*Id*Ψm + Ψm²` 

`= 16*Iq²*Lrel² - 4*Ψm*√(4*Iq²*Lrel² + Ψm²) + 5*Ψm²`

把带根号的项单独移到一边，其他的都移到另一边：

4\*Ψm\*√(4\*Iq²\*Lrel²+Ψm²)=-16\*Lrel²\*Id²-8\*Lrel\*Id\*Ψm\+ 16\*Iq²\*Lrel²+4\*Ψm²

两边同时除以 `4*Ψm`：

√(4\*Iq²\*Lrel²+Ψm²)=(-4\*Lrel²\*Id²-2\*Lrel\*Id\*Ψm+4\*Lrel²\*Iq²+Ψm²)/Ψm

再两边平方！这将是本次侦破行动中最“暴力”的一步！

Ψm² \* (4\*Iq²\*Lrel² + Ψm²) 

\= \[ (4\*Lrel²\*Iq² + Ψm²) - (4\*Lrel²\*Id² + 2\*Lrel\*Id\*Ψm) \]²

我们观察一下右边的中括号里。`4*Lrel²*Iq² + Ψm²` 看着是不是很眼熟？

从我们第一步验证A的结果中，我们已经知道：

`(Ld-Lq)*Id²+Ψm*Id=(Ld-Lq)*Iq²` => `Iq²=Id²+(Ψm*Id)/(Ld-Lq)`

代入到`4*Iq²*Lrel² + Ψm²`里试试？

`4*(Id² + (Ψm*Id)/Lrel)*Lrel² + Ψm²`

`= 4*Id²*Lrel² + 4*Ψm*Id*Lrel + Ψm²``= (2*Id*Lrel + Ψm)²`

哇！我们发现了一个惊人的事实！

√(4\*Iq²\*Lrel² + Ψm²) = 2\*Id\*Lrel + Ψm

当然 Id<0 时要取绝对值，这里我们先假设代数关系成立。

现在，我们把这个惊人的发现，代回到我们刚才推导B的那一步：

√(4\*Iq²\*Lrel² + Ψm²) 

\= (-4\*Lrel²\*Id²-2\*Lrel\*Id\*Ψm+4\*Lrel²\*Iq²+Ψm²)/Ψm

左边变成了 `2*Id*Lrel + Ψm`。

我们来看看右边是不是也等于它。 

右边`=(-4*Lrel²*Id²-2*Lrel*Id*Ψm+(2*Id*Lrel+Ψm)²)/Ψm`

`=(-4*Lrel²*Id²-2*Lrel*Id*Ψm+4*Lrel²*Id²+4*Lrel*Id*Ψm+ Ψm²)/Ψm`

`=(2*Lrel*Id*Ψm + Ψm²)/Ψm`

`=2*Lrel*Id+Ψm`

**左边 = 右边！**

**【案件告破！】**刚才那一步 `左边 = 右边` 的证明，意味着我们把“嫌疑人B”代入“DNA方程”后，经过一系列化简，得到了一个**恒等式**！这说明，“嫌疑人B”也100%满足MTPA的“DNA”方程！

附录2：手算浮点数，亲手抓住那只“鬼”

为了让大家看得懂，我们做一个极端的简化。假设我们的MCU是一台古老的“**四位有效数字浮点计算器**”。也就是说，它存储和计算任何数字，都只能保留4位有效数字，多余的就要四舍五入。

#### **一、我们的已知条件**

假设我们的电机参数经过换算后（为了计算简单）：

-   `Ψm= 1.000`
-   `Ld-Lq= 0.5000`
-   Iq 非常小，我们取 `Iq` = 0.0100
    

那么：

-   `Ψm² = 1.000² = 1.000`
-   `(Ld-Lq)² = 0.5000² = 0.2500`
-   `Iq² = 0.0100² = 0.0001000`

#### **二、用“经典公式”计算，看“幽灵”如何现身！**

Id = (-Ψm + √(Ψm² + 4\*(Ld\-Lq)²\*Iq²)) / (2\*(Ld\-Lq))

我们一步一步地，模拟这台“四位有效数字计算器”的工作：

1.  **计算根号里的 `Iq²` 相关项**：`4 * (Ld-Lq)² * Iq²` = `4 * 0.2500 * 0.0001000` = `1.000 * 0.0001000` = `0.0001000`
    
2.  **计算根号里的加法**：`Ψm² + 0.0001000` = `1.000 + 0.0001000` = `1.0001000`**【第一个“鬼”出现了！】** 我们的计算器只能保留4位有效数字啊！`1.0001000` 必须被四舍五入。它被存储为 **`1.000`**！ 看到了吗？那个微小的`Iq`贡献的信息，在第一步加法运算中，就已经被“吃掉”了！它因为太小，根本没办法撼动`1.000`的第四位有效数字！
    
3.  **计算开方**：`√1.000` = `1.000`
    
4.  **计算分子**：`-Ψm + 1.000` = `-1.000 + 1.000` = **`0.000`**
    
5.  **计算最终结果**：`Id` = `0.000 / (2 * 0.5000)` = `0.000 / 1.000` = **`0.000`**！
    

**【结论】**：当`Iq=0.0100`（一个不为0的真实负载）时，我们的经典公式因为精度问题，算出来的`Id`指令竟然是`0`！它完全“感觉”不到`Iq`的存在了！如果`Iq`再小一点，或者我们的计算器精度再低一点，这个误差会更严重。这就是“灾难性抵消”的真面目——**有用的微小信息，在与巨大数字相加时被精度所“吞噬”**。

     = `0.00002500`
    

好了，开始计算！

1.  **计算最里面的根号**：`√(4*bQ + bW)` = `√(4 * 0.00002500 + 1.000)`\= `√(0.0001000 + 1.000)`\= `√1.0001000`**【同样的“鬼”又来了！】** 我们的计算器只能存4位有效数字，`1.0001000` 还是被存成了 **`1.000`**。 此时你可能会想：“完了，这不还是一样吗？” 别急！好戏在后头！
    
2.  **计算大根号里的各项**：
    

-   `` 16 * bQ = `16 * 0.00002500` = `0.0004000` ``
-   `` 4 * Ψm * (上一步的结果) = `4 * 1.000 * 1.000` = `4.000` ``
-   `` 5 * bW = `5 * 1.000` = `5.000` ``

4.  **计算大根号里的加减法**：`(16*bQ) - (4*Ψm*√(4*bQ+bW)) + (5*bW)`\= `0.0004000 - 4.000 + 5.000`\= `1.0004000`**【第二个“鬼”又出现了！】** 计算器再次进行四舍五入，结果存为 **`1.000`**。 你是不是更绝望了？感觉这个公式也没什么了不起的嘛！
    

**不要眨眼！见证奇迹的时刻到了！**

我们刚才的计算，是完全按照人类的思维，先把里面的根号算完，再算外面的。但如果，我们先不急着对中间步骤四舍五入，而是**在数学上，把这个公式用泰勒展开（Taylor Expansion）近似一下**呢？这才是这个公式设计的精髓所在！

当 `x` 非常非常小的时候，我们有一个近似公式：`√(1+x) ≈ 1 + 0.5*x`

我们来近似里面那个根号：

`√(4*bQ + bW) = √(bW * (1 + 4*bQ/bW)) = √bW * √(1 + 4*bQ/bW)`

`≈ Ψm * (1 + 0.5 * (4*bQ/bW))`

`= Ψm * (1 + 2*bQ/Ψm²)`

`= Ψm + 2*bQ/Ψm`

现在，把这个近似结果，代入到大根号里面去！ 

大根号 ≈ `√(16*bQ - 4*Ψm*(Ψm + 2*bQ/Ψm) + 5*Ψm²)`

`= √(16*bQ - 4*Ψm² - 8*bQ + 5*Ψm²)`

`= √(8*bQ + Ψm²)`

现在，我们再对这个新的、简化后的大根号，用一次泰勒展开！

`√(8*bQ + Ψm²) = √(Ψm² * (1 + 8*bQ/Ψm²))`

`≈ Ψm * (1 + 0.5 * (8*bQ/Ψm²))`

`= Ψm * (1 + 4*bQ/Ψm²)`

`= Ψm + 4*bQ/Ψm`

好了！最最关键的一步来了！我们把这个近似后的大根号结果，代入最终的分子！ 

分子 ≈ `(Ψm + 4*bQ/Ψm) - Ψm` = **`4*bQ/Ψm`**！

**看到了吗！**`Ψm` 被干净利落地**解析抵消**了！剩下的，是那个包含着我们宝贵`Iq`信息的 `bQ`！“灾难性抵消”的数字问题，被转化成了一个在纸上就能完成的**代数问题**！

我们来算最终结果：

`Id` ≈ `(4*bQ/Ψm) / (4*(Ld-Lq))`

`= bQ / (Ψm * (Ld-Lq))`  

把`bQ`代回去：

`` `Id=(Iq²*(Ld-Lq)²)/(Ψm*(Ld-Lq))` ```= (Iq²*(Ld-Lq))/Ψm`

现在，我们用这个最终的近似公式，来算一下`Id`:

`Id` ≈ `(0.0100² * 0.5000) / 1.000`

`= (0.0001000 * 0.5000) / 1.000`

`= 0.00005000`  

虽然还是一个很小的数，但它**不再是0**了！它是一个与`Iq²`成正比的、有意义的、精确的负`Id`值（我们这里推导忽略了符号，但大小是对的）。

虽然真正的计算机浮点运算比泰勒展开要复杂，但其内在的原理是相通的。**这个“面目全非”的公式，它的代数结构，就是为了在`Iq`很小时，其行为能无限逼近我们刚刚推导的这个近似结果，从而在数学层面就避免了两个大数直接相减，保留了微小项`bQ`的信息！**
