# 列空间：方程可解的绝对疆域

## 心智锚点

一个国家的军队只能在自己的领土上行动。领土之外，指挥权无效。

**列空间就是矩阵的领土。** 落在列空间内的目标 ，方程有解。落在列空间外的目标，无论如何都无法触达。

没有商量余地。没有例外条款。这是数学结构决定的绝对边界。

## 列空间的几何

在  中：

-   如果  的秩 = 3：列空间 = 整个 。任何  都有解。
    
-   如果  的秩 = 2：列空间是一个过原点的平面。 必须恰好落在这个平面上才有解。
    
-   如果  的秩 = 1：列空间是一条过原点的直线。 必须恰好在这条线上才有解。
    
-   如果  的秩 = 0：列空间只有原点。只有  才有解。
    

**秩越低，领土越小，能到达的目标越少。**

## 如何计算列空间？

注意：基是原矩阵的列，不是消元后矩阵的列。消元改变了列向量的具体坐标，但主元位置指出了哪些列是独立的。

## 列空间与零空间的互补

列空间的维度告诉你有多少个方向被成功映射到输出端。零空间的维度告诉你有多少个方向被吞噬了。

两者之和 = 输入空间的总维度。

**列空间是"有效输出"的世界。零空间是"被吞噬的输入"的世界。两者合起来，精确覆盖了输入空间的全部。**

## 现实映射

**势力范围思维的核心法则：在采取行动之前，先划定你能影响的范围。**

-   你的产品能解决的问题集 = 列空间。客户需求不在这个范围内，就不是你的目标市场。
    
-   你的团队能完成的任务集 = 列空间。超出能力范围的项目，接了也做不好。
    
-   你的模型能拟合的数据模式 = 列空间。数据中存在你的模型无法表达的模式时，残差不可消除。
    

**不要高估你的列空间。列空间有多大，由独立方向的数量决定——不由意愿决定。**
