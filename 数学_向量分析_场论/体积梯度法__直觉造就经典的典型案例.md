# 体积梯度法——直觉造就经典的典型案例


> 原文地址: [https://mp.weixin.qq.com/s/7QUMTJIwpWIC05ydZz3jSQ](https://mp.weixin.qq.com/s/7QUMTJIwpWIC05ydZz3jSQ)

在“[基于体积法波段选择的两个常用贪心策略：前向法和后向法](https://mp.weixin.qq.com/s?__biz=Mzk4ODA1MDUyOQ==&mid=2247484304&idx=1&sn=4b649eb9d70923aee1d564f1a42c6047&token=1681204838&lang=zh_CN&scene=21#wechat_redirect)”一文中，我们发现，在基于体积指标的波段选择方法中，后向法的效果通常优于前向法。因此，本文将对后向法展开进一步的深入探讨与分析。

大约是在十几年前的某一天，我脑海中突然浮现出一个关于三角形的问题：对于任意一个普通三角形，其三个顶点的重要性想必存在差异，那么该如何衡量这种差异呢？一个直观的思路随即浮现：可通过各顶点到其对边的距离，来界定该顶点的重要性。具体而言，顶点到对边的距离越近，意味着该顶点越容易被其到对边的垂足所替代，因此其重要性越低；反之，距离越远，表明该顶点越难被其他点替代，其重要性也就越高。

![](体积梯度法__直觉造就经典的典型案例_images/img_000_909b6474f039.png)

图1.三角形面积相对于三个顶点的偏导数

在图1所示的直角三角形中，点A到其对边BC的距离，小于点B到对边AC、点C到对边AB的距离，因此点A在该三角形中的重要性最低。事实上，我们无需逐一计算三个顶点到各自对边的距离，仅通过各顶点对边的边长大小，便能判断出其重要性：显然，对边长度最大的顶点，其重要性最低。

接下来，让我们转向高光谱图像的波段选择。假设**X**为包含_N_个像元，_L_个波段的高光谱图像，且各波段图像满足线性无关性。则在图像空间（**X**的行空间）中，这_L_个向量可以张成一个_L_维平行多面体。

基于波段选择的后向法，在去除第一个冗余波段时，需要分别尝试删除每一个波段：首先参照公式（4），得到_L_个(_L_\-1)×_N_的数据矩阵**X**_i_ (_i_ = 1, 2, …, _L_)；再分别计算这_L_个数据矩阵对应的平行多面体的体积，vol(**X**_i_) (_i_ \= 1, 2, …, _L_)；最终删去与最大体积对应的顶点。

在移除第一个冗余波段后，继续沿用上述相同策略逐一移除其余冗余波段，直至剩余波段数量达到预设要求。

由上述后向法的核心过程可知，其波段选择的关键在于反复计算各维度子平行多面体的体积。当波段数与像元数较大时，这一计算任务的复杂度会显著升高。

然而，幸运的是，基于公式（5），我们发现，可以把子平行多面体体积的计算，转化为向量模长的计算，而后者带来的复杂度降低是显而易见的。
