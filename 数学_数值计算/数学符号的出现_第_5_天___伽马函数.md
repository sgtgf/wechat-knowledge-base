# 六、一张图理解伽马函数

可以把它理解成：

```
普通阶乘1!  2!  3!  4!  5! |   |   |   |   | v   v   v   v   vΓ(2) Γ(3) Γ(4) Γ(5) Γ(6)--------------------------------伽马函数继续向左延伸Γ(1/2)Γ(3/2)Γ(5/2)Γ(2.7)Γ(3.14159)全部都有意义
```

因此：

> 阶乘只是一串离散的点，
> 
> 而伽马函数把这些点连成了一条连续曲线。

这正是伽马函数最伟大的地方——**把整数世界的阶乘扩展到了整个连续世界。**

下一步再学习时，我们会发现：

-   贝塔函数（Beta Function）
    
-   高斯积分
    
-   概率论中的正态分布
    
-   斯特林公式
    

都与伽马函数密切相关，它堪称“连接阶乘与高级数学的桥梁”。
