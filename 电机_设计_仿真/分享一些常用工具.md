## 1常用开发工具

差生文具多，分享一些平时常用的开发环境和库

### PyCharm

用来配置python集成开发环境，同时配置pytorch环境，用来开展机器学习。最近2024年的诺贝尔物理学奖，颁发给了约翰·J·霍普菲尔德（John J. Hopfield）和杰弗里·E·辛顿（Geoffrey E. Hinton），表彰他们在使用人工神经网络进行机器学习的基础性发现和发明。是否真的合适先且不论，但足以说明当前机器学习在各行各业的广泛应用。

### Qt

用来配置c++及桌面程序集成开发环境，开发一些小程序，例如网格显示程序（ShowMesh）、有限元求解器（SiMag）等。

### Visual Studio Code

学习、验证算法与程序的轻量级编辑器。

### Visual Studio

有了Qt以及Visual Studio Code，还需要Visual Studio吗？因为需要用到Windows的COM机制与Ansys Maxwell进行交互，做二次开发，需要用到Visual Studio的MSVC编译器。

### Dependencies

一个开源程序，可方便查看应用程序依赖的动态链接库。

### StraUML

顾名思义，可以用来绘制UML图，我目前主要用来描述程序系统中的类、接口、关系和其属性与方法，展示类之间的继承、关联、聚合等关系，帮助理解梳理程序系统的静态结构。

### Sourcetrail

一个开源的源代码浏览工具，可帮助更好地理解和导航代码库。它通过可视化的方式展示代码结构和关系，从而让用户能够快速找到代码的定义、引用和调用关系，可用来学习开源库。

### Inno Setup

一个免费的安装程序创建工具，主要用于在 Windows 平台上生成软件的安装包。

### TexLive

一个广泛使用的 TeX 发行版，它提供了丰富的 TeX 相关工具和宏包。TeX 是一个强大的排版系统，通常用于科学和学术文献的排版，尤其擅长处理复杂的数学公式和文档布局，用来写相关理论技术文档。

### OpenCASCADE

一个开源的计算机辅助设计（CAD）、计算机辅助工程（CAE）和三维建模的开发平台。它提供了一系列用于几何建模、数据交换、可视化以及仿真等方面的工具和库。

### Fitten Code

一个基于 Transformer 模型的 AI 代码助手。它的主要功能是帮助开发者进行编程相关的任务，包括代码生成、代码改进、调试建议等。
