# 电路

  

![](D:\电脑文件\公众号知识库\电工_教育_学习\汽车电路__电路基础（电路维修必修课）_images\img_001_c92a9d8a1f2e.png)

  

-   定义:各种电子元件按一定方式连接起来的总体
    
-   基本组成:电源、导线、开关、负载、接地
    
-   基本类型:串联、并联和混联
    

  

# 串联电路

  

![](D:\电脑文件\公众号知识库\电工_教育_学习\汽车电路__电路基础（电路维修必修课）_images\img_002_1d243e7fb992.png)

  

-   定义:两个或多个元件首尾相接在电路中，使电流只有一条通路的连接方式
    
-   基本特点:
    

1.  电路中各处的电流强度相等
    
2.  电路两端的总电压等于各部分电路两端的电压之和
    
3.  串联电路的总电阻等于各个电阻之和
    
4.  串联电路中各个电阻两端的电压与它的阻值成正比

# **并联电路**

  

![](D:\电脑文件\公众号知识库\电工_教育_学习\汽车电路__电路基础（电路维修必修课）_images\img_004_470b2f7e5112.png)

  

-   定义:若干个元件首与首连接，尾与尾连接，接到一个电源上的连接方法
    
-   基本特点:
    

  

1.  电路中各支路两端的电压相等
    
2.  电路中的总电流强度等于各支路的电流强度之和
    
3.  并联电路总电阻的倒数，等于各个电阻的倒数之和
    
4.  并联电路中通过各个电阻的电流强度与它的阻值成反比
    

  

**并联电路示例**

  

![](D:\电脑文件\公众号知识库\电工_教育_学习\汽车电路__电路基础（电路维修必修课）_images\img_005_c1a91ca0662a.png)

  

-   工作原理:
    

当转向信号开关置于左转或右转位置时，车身控制模块通过收到的转向信号控制电路搭铁，构成回路，点亮转向灯和转向复示灯电路走向(左前转向)左前转向灯和左前转向复示灯构成并联电路，如左侧电路图中红色线路所示

# **开路**

  

![](D:\电脑文件\公众号知识库\电工_教育_学习\汽车电路__电路基础（电路维修必修课）_images\img_009_5f38efe1911e.png)

  

-   定义:电路出现断点时，电流回路被切断，导致电路开路，电流无法
    

流动的现象

-   原因:
    

1.  断开的导线
    
2.  断路的连接器
    
3.  内部开路的部件
    
4.  松动的连接
    
5.  熔断的保险丝
    

-   后果:
    

电路中无电流，负载不工作

  

# **电阻过大**

  

![](D:\电脑文件\公众号知识库\电工_教育_学习\汽车电路__电路基础（电路维修必修课）_images\img_010_dbd03a48438e.png)

  

-   定义:电路中存在过大电阻的现象
    

-   原因:
    

1.  线路的腐蚀
    
2.  负载的氧化
    
3.  回路接触不良
    
      
    

-   后果:
    

1.  电流低于正常值
    
2.  电流通过被腐蚀的线路时会产生电压降，降低对正常负载提供的有效电压，导致元器件工作不正常
    

  

# **短路**

  

![](D:\电脑文件\公众号知识库\电工_教育_学习\汽车电路__电路基础（电路维修必修课）_images\img_011_c23448288440.png)

  

-   定义:
    

原因:电流不经过负载直接导通导线或元器件意外接地的现象后果:

-   后果：
    

-   产生极高的电流
    
-   保护装置被烧断
    
-   损坏导线和电气元件
    

  

# **汽车线路检查要点**

汽车线路经过长时间的使用后，可能会出现接头松动脱落的现象，导致开路或接触不良情况的发生;

绝缘层老化破损的导线，易引发短路故障的发生，导致电气元件无法正常工作甚至烧损。

因此，在日常的维护保养工作中，维修技师需加强汽车线路的检查。
