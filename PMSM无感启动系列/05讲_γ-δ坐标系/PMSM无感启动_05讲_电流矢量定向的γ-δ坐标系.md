## 一、核心问题

> γ-δ 是工程师必须会写的坐标变换吗？还是说它只是论文推导时临时搭的脚手架，代码里根本不存在？

**答案：** γ-δ 是分析 I/f 控制的"默认语言"，但源码通常不会单独实现 `gamma_delta_transform()`——它被"藏"在一个以强制电流角为 Park 角的虚拟 d-q 帧后面。

---

## 二、d-q 坐标系 vs γ-δ 坐标系

### d-q 坐标系（转子磁场定向）
- **d 轴**：绑在转子永磁体磁链 ψ_f 的方向上
- **q 轴**：超前 d 轴 90°
- **前提**：需要知道转子真实位置（编码器或观测器）
- **适用**：FOC 闭环运行

### γ-δ 坐标系（电流矢量定向）
- **γ 轴**：与定子电流矢量 i_s 同向（**按定义 γ 轴电流恒为 0**）
- **δ 轴**：超前 γ 轴 90°
- **前提**：不需要转子位置，只需要知道电流方向
- **适用**：I/f 启动（开环）

### 核心理解：两把尺子

| 坐标系 | 绑定的对象 | 已知条件 |
|--------|-----------|---------|
| d-q   | 转子永磁体磁链方向 | FOC 时已知转子位置 |
| γ-δ   | 定子电流矢量方向 | I/f 时已知电流方向 |

两把尺子之间的夹角就是 **负载角 θ_L**（也叫转矩角）。

> **关键直觉：** FOC 闭环时，知道转子真实位置 → 用 d-q。I/f 启动时，看不到转子位置，但手里握着 γ-δ——知道电流方向，也知道电流以什么角速度旋转。

---

## 三、γ-δ 坐标系的数学定义

### 基本关系

- γ 轴与定子电流矢量 i_s 同向
- δ 轴超前 γ 轴 90°（电气角）
- 负载角 θ_L：γ 轴与 d 轴的夹角

### 旋转变换

从 γ-δ 到 d-q 的变换矩阵：

```
[d]   [cos θ_L   -sin θ_L] [γ]
[q] = [sin θ_L    cos θ_L] [δ]
```

### ⚠️ 重要约定

1. **γ 轴沿电流矢量，d 轴沿转子磁链**——这个关系不能反
2. 本文约定：θ_L 为 γ 轴（电流矢量）**超前** d 轴（转子磁链）的角度
3. 不同论文对 γ、δ 轴的命名可能相反，读文献时务必先看坐标图

---

## 四、γ-δ 下的电压方程

### 动态方程

将 d-q 电压方程通过旋转变换换到 γ-δ 系：

```
u_γ = R_s·i_γ + L_s·(di_γ/dt) - ω_γ·L_s·i_δ - ω_r·ψ_f·sin θ_L
u_δ = R_s·i_δ + L_s·(di_δ/dt) + ω_γ·L_s·i_γ + ω_r·ψ_f·cos θ_L
```

其中：
- ω_γ：γ-δ 坐标系本身的旋转速度（电流矢量的旋转速度）
- ω_r：转子磁链的真实旋转速度（转子电角速度）
- 坐标旋转项用 ω_γ，永磁磁链反电势项用 ω_r

### 稳态方程（同步稳态）

在 I/f 控制同步稳态下（ω_γ = ω_r，θ_L 恒定，i_γ = I_m、i_δ = 0）：

```
u_γ = R_s·I_m - ω_r·ψ_f·sin θ_L
u_δ = ω_r·L_s·I_m + ω_r·ψ_f·cos θ_L
```

若记电压矢量与电流矢量的夹角为 β，则：
- sin β = u_γ / |u_s|
- cos β = u_δ / |u_s|

### 滑差关系

负载角变化率 = 电流矢量旋转速度 - 转子旋转速度：

```
dθ_L/dt = ω_γ - ω_r
```

这是 I/f 启动最核心的动态关系之一。

## 五、开源代码中的 γ-δ（实际实现方式）

| 项目 | 实现方式 |
|------|---------|
| **phobia** | `pm_loop_current()` 中 `PM_LU_FORCED` 模式斜坡化 `forced_track_D`，电流给定赋给 `track_D`（强制 D 轴）/ `track_Q=0`。虚拟 d-q 帧的旋转角人为给定，与 γ-δ 数学等价 |
| **VESC** | `CONTROL_MODE_OPENLOOP` 或 `mcpwm_foc_set_openloop_current()`，电流给在 q 轴，`m_openloop_speed` 积分出 `m_openloop_angle` 作为 Park 角。注意电流给在 q 轴时，Park d 轴角与电流矢量角相差 90° |
| **ODrive** | `OpenLoopController::update()` + `Axis::run_lockin_spin()`，给定 D 轴电流和目标电角速度，内部积分出开环相位作为 Park 角 |

### 三句话总结代码中的 γ-δ

1. γ-δ 是分析问题时的**语言**：电流已知、位置未知时，先理清 θ_L、ω_γ、ω_r 的关系
2. d-q 是代码实现时的**数据通路**：复用现成 Park/D-Q 代码，把 Park 角从"真实转子角"换成"强制转子角/电流角"
3. **坐标系的本质由参考角决定，不由变量名决定**

## 六、三个必须记住的硬性约定

1. **γ 轴跟电流矢量走，d 轴跟转子磁链走**——不能反。γ 轴上电流按定义恒为 0（理想跟踪下）
2. **θ_L 的符号必须前后一致**——本文约定 γ 轴超前 d 轴。电磁转矩 T_e = (3/2)·p·ψ_f·I_m·sin θ_L 在此约定下成立
3. **不要把 γ-δ 下的 i_γ 和 d-q 下的 i_d 混为一谈**——前者电流矢量全部沿自身方向（i_δ = 0 是给定的）；后者电流全部落在 q 轴

---

## 七、物理图像总结

> I/f 控制器让电流矢量在转子前面"**领跑**"，转子以稳定负载角 θ_L 跟随。

- **领跑者**：电流矢量，转速 ω_γ 被人为给定
- **跟随者**：转子，转速 ω_r 由电磁转矩和机械负载共同决定
- **滑差**：ω_γ - ω_r = dθ_L/dt，是负载角变化的原因
