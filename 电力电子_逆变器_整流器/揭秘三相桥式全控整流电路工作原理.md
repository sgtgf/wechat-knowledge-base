# 1\. 主电路的工作原理

三相桥式全控整流电路的核心在于其主电路的设计。该电路通过六个可控硅的巧妙排列，实现了对三相交流电的有效整流。当交流电的某一相到达正半周时，其对应的可控硅被触发导通，从而将交流电转换为直流电。这样的设计不仅提高了整流效率，还确保了电路的稳定性和可靠性。

习惯上，我们将阴极连接在一起的三个晶闸管（VT1、VT3、VT5）称为共阴极组，而阳极连接在一起的三个晶闸管（VT4、VT6、VT2）则被称为共阳极组。为了确保晶闸管能够按照1至6的顺序顺畅导通，我们按照图示的编号方式进行编号，即共阴极组中与a、b、c三相电源相连的晶闸管依次为VT1、VT3、VT5，而共阳极组中相连的晶闸管则为VT4、VT6、VT2。根据后续的分析，我们可以得知，按照这种编号方式，晶闸管的导通顺序将会是VT1－VT2－VT3－VT4－VT5－VT6。

# 3.2主电路原理详解

整流电路所带负载为具有反电动势的阻感负载。若将电路中的晶闸管替换为二极管，即相当于晶闸管触发角α=0o的情况。在此状态下，共阴极组的三个晶闸管中，阳极所接交流电压值最高的那个将首先导通。同时，共阳极组的三个晶闸管中，阴极所接交流电压值最低（即负值最大）的那个将随后导通。因此，在任意时刻，共阳极组和共阴极组中都只有一个晶闸管处于导通状态，从而施加于负载上的电压为某一特定的线电压。此时，电路的工作波形如图2所示。  
![](D:\电脑文件\公众号知识库\电力电子_逆变器_整流器\揭秘三相桥式全控整流电路工作原理_images\img_002_5c5be540167b.png)  
α=0o时，各晶闸管均在自然换相点处进行换相。观察变压器二绕组的相电压与线电压波形，可以发现各自然换相点既是相电压的交点，也是线电压的交点。在分析ud的波形时，我们可以从相电压波形或线电压波形入手。

从相电压波形来看，以变压器二次侧的中点n为参考点，共阴极组晶闸管导通时，整流输出电压ud1为相电压在正半周的包络线；而共阳极组导通时，整流输出电压ud2为相电压在负半周的包络线。因此，总的整流输出电压ud = ud1－ud2，它表示的是两条包络线间的差值。将这个差值对应到线电压波形上，我们就可以得到线电压在正半周的包络线。

另外，从线电压波形直接分析，也可以得出类似的结论。在共阴极组中，处于通态的晶闸管对应的是相电压中最大的值；而在共阳极组中，处于通态的晶闸管对应的是相电压中的最小值。因此，输出整流电压ud即为这两个相电压的差值，它代表了线电压中最大的部分。所以，输出整流电压ud的波形也是线电压在正半周的包络线。

此外，负载端接有电感且其阻值趋于无穷大，这使得电感对电流变化产生抗拒作用。当电流变化时，电感在其两端产生感应电动势Li，该电动势的极性总是阻止电流的变化。这种电感的特性使得电流波形变得平直，特别是在电感无穷大时，电流波形几乎成为一条直线。

由此可见，6个晶闸管的导通顺序为VT1、VT2、VT3、VT4、VT5和VT6。

图3展示了α=30o时的波形情况。若从ωt1角开始，将一个周期细分为六段，每段依旧为60o，与α＝0o时的情况相比，我们会发现，ud波形依旧由六段线电压组成，且每段的导通晶闸管编号仍遵循表1的规律。然而，此时晶闸管的起始导通时刻较之前推迟了30o，因此，构成ud的每一段线电压也相应推迟了30o，导致ud的平均值有所降低。同时，晶闸管的电压波形也发生了相应的变化，如图所示。此外，图中还给出了变压器二次侧a相电流ia的波形。该波形呈现出一种特点：在VT1通态的120o期间，ia为正值，且由于大电感的作用，其波形近似为一条直线；而在VT4通态的120o期间，ia的波形也近似为一条直线，但此时为负值。

# 4\. 参数计算

在带阻感的反电动势三相桥式全控整流电路中，我们需要计算几个关键参数，包括ud的平均值、id的波形以及α角的移相范围。这些参数的计算对于理解和优化电路性能至关重要。通过上述分析，我们可以得出一些重要的结论和计算公式，为实际电路的设计和调试提供有力的支持。

# 5.1 输出值的计算

在三相桥式全控整流电路中，整流输出电压的波形呈现出周期性的脉动，且在一个周期内会脉动6次，每次脉动的形态保持一致。因此，在计算其平均值时，我们仅需针对一个脉波，也就是1/6的周期进行详尽的分析即可。同时，由于电压输出波形具备连续性，我们可以线电压过零点为时间坐标的起点，来推导出整流输出电压在连续状态下的平均值。

# 6.2 输出波形的深入剖析

三相桥式全控整流电路的输出波形，如图11所示，呈现出一种周期性的脉动特征。这种脉动在一个完整的周期内会出现6次，且每次的脉动形态都保持高度一致。这种特性使得我们在计算其平均值时，可以仅聚焦于一个脉波，即周期的1/6部分，进行深入的分析。此外，由于输出电压波形具有连续性，我们以线电压过零点为时间坐标的起点，能够进一步推导出整流输出电压在连续状态下的平均值。  
![](D:\电脑文件\公众号知识库\电力电子_逆变器_整流器\揭秘三相桥式全控整流电路工作原理_images\img_008_3975a15afbf5.png)  
如图11所示，我们可以将一个周期细分为6个时段，从ωt1时刻开始计时。在Wt1时刻，共阴极组的VT1晶闸管接收到触发信号并导通，此时阴极输出电压Ud1达到幅值最大，即a相相电压。随着时间推移，到Wt2时刻，下一个触发脉冲到来，a相输出电压降低，而b相输出电压升高，因此阴极输出电压切换为b相相电压。到了Wt3时刻，第三个脉冲触发，VT1晶闸管关断而VT2晶闸管导通，此时输出电压为c相相电压，这是该时段内最高的。这一过程将不断重复，形成共阴极组输出电压Ud1在正半周的包络线。

共阳极组的输出波形原理与共阴极组相似，但触发脉冲相差180度。表1详细列出了6个时段的导通次序，其中Wt1从零时刻推迟30度开始。最终，整流输出电压为共阴极组与共阳极组输出电压的差值，即Ud=Ud1-Ud2。同时，由于电路中的大电感L作用，输出的电流保持近似平滑的直线形态。图中还展示了变压器二次侧a相电流ia的波形，其特点是在VT1通态的120o期间为正，形状近似直线；而在VT4通态的120o期间为负值，波形同样近似直线。

# 7\. 逆变原理图详解

逆变原理图如图12所示，该图清晰地描绘了逆变过程的工作原理。在逆变过程中，直流电源被转换为交流电源，实现了电能的转换。这一转换过程对于许多应用场景都至关重要，如电力系统、电机驱动等。通过逆变原理图，我们可以更深入地了解逆变过程的工作原理和电路构成，为实际应用提供有力的理论支持。

当电机M开始工作时，我们通过调整整流电路的触发角α，使其满足α<90°的条件。在此状态下，整流电路将进入整流模式，为电机M提供电力，使其以电动方式运转。这一过程实现了电能的转化，即电能被转换为动能，进而驱动汽车行驶。
