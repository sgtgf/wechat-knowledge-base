# **三维互穿结构Cu-W触头接触器合闸弹跳抑制**

# 作者：韩颖，刘东睿，张钧涵，侯春光，安跃军，李述军

### 单位：1\. 特种电机与高压电器教育部重点实验室(沈阳工业大学)；2. 中国科学院金属研究所

DOI：10.13334/j.0258-8013.pcsee.232644

 

摘要：接触器触头合闸弹跳引起的触点磨损及粘连，直接影响接触器可靠性及电寿命。该文利用3D打印技术和熔渗技术制备立方体(cube，CB)与菱形十二面体(rhombic dodecahedron，RD)三维互穿结构Cu-W触头材料，从触头材料结构参数和缓冲吸振特性的角度分析了触头合闸碰撞弹跳过程影响机制，并与商用无序结构触头进行了对比。基于Hertz接触理论及其延伸理论，对接触器触头碰撞能量损耗进行分析；测试3种结构Cu-W触头应力应变曲线及阻尼性能；利用触头弹跳检测实验装置得到接触器不同参数下，3种结构触头合闸弹跳运动曲线；最后，通过仿真手段对某型号实际接触器进行建模，得到不同结构Cu-W触头在接触器触头系统中的弹跳抑制效果。结果表明：触头材料结构的改变能够使其力学性能和阻尼性能发生变化。RD结构Cu-W触头具有最大的阻尼系数，在受到碰撞压缩时形变量大、内摩擦多、吸能效果好，能利用其自身在碰撞时相对更多的能量耗散抑制触头弹跳，在高速合闸下具有更优异的抗弹跳性能。
