# 基于更新样本智能识别算法的自适应集成建模

原创 自动化学报 2016-08-01 14:54 北京

> 原文地址: [https://mp.weixin.qq.com/s/\_ifH1h8I5oEsvmxhpjLhIw](https://mp.weixin.qq.com/s/_ifH1h8I5oEsvmxhpjLhIw)

工业过程对象受原料属性、产品质量和产量及环境气候等因素的影响而具有动态特性，这些动态变化通常包括传感器漂移和过程漂移，在机器学习领域将其统称为概念漂移。基于历史数据构建的软测量模型难以适应这些变化，导致预测性能下降。集成学习模型的更新包括基于样本和基于批两种方式，其中基于批的在线集成更新方式的较长更新时间周期常导致更新模型难以反映当前状态，基于样本的在线集成更新方式则可以快速适应过程对象变化。

采用每个新样本均进行模型更新并不符合工业实际情况。为选择能够代表过程对象概念漂移的新样本进行模型更新，已有策略的特点包括：（1）基于主元分析(Principal component analysis, PCA)模型识别更新样本的方法不设定更新阈值，难以有效控制模型更新次数，预测模型精度与更新速度间的均衡较难控制；（2）采用(Approximate linear dependence, ALD)条件条件在建模样本的核特征空间和原始空间中判断新样本与建模样本库的线性独立关系的方法，虽然通过设定阈值可有效控制模型更新次数，但对模型预测性能的变化未予以考虑；（3）基于预测误差限(Prediction error band, PEB)的方法考虑模型预测性能，难以准确涵盖过程特性漂移，而且对于某些难以在短时间内获得预测变量真值的复杂工业过程不能实现更新样本的识别。实际上，复杂工业过程的时变特性(概念漂移)的影响不仅体现在当前单个新样本相对于建模样本的变化(ALD值)和相对于旧模型预测精度的变化(PE值)，还表现某段时间内ALD值和PE值的累计变化。

针对具体工业实践，领域专家通常综合考虑过程特性变化和软测量模型预测性能等指标，依据自身经验知识决策是否有必要进行软测量模型更新。何有效的结合领域专家知识，融合近似线性依靠(Approximate linear dependence, ALD)条件和模型预测误差(Prediction error, PE)所代表的具有不同视角的概念漂移程度，即基于领域专家的经验和知识获取模糊规则，对是否对软测量模型进行更新采用智能化识别是本文的关注焦点。

集成学习算法具有较好的概念漂移处理能力。若不对集成模型的结构进行更新，难以有效地适应概念漂移。如何构建面向回归问题的学习速度快、性能稳定的在线集成模型，尤其基于高维小样本数据，是目前研究难点。选择适合的子模型构建方法对集成模型的快速更新极为重要。随机向量泛函连接网络 (Random vector functional link, RVFL)求解速度快，但在面向小样本数据建模时存在预测性能不稳定的问题，难以直接用于高维数据建模等问题。将SVM中的核技术引入RVFL构建改进的RVFL(IRVFL)模型可有效克服上述问题。RVFL作为一种单隐层的人工神经网络模型，难以直接采用高维数据建模。维数约简是首先需要面对的问题。基于偏最小二乘(Partial least squares, PLS)的特征提取方法克服了PCA提取的潜在特征只关注输入数据的缺点，并且其递推算法较为容易实现。

综上，本文首先提出一种采用模糊规则融合新样本的相对ALD（Relative ALD, RALD）值和相对PE（Relative PE, RPE）值的智能更新样本识别算法，然后采用改进的递推PLS(Recursive, RPLS)对潜在特征进行递推更新，最后重新训练并优化选择具有快速学习能力的IRVFL集成子模型。采用合成数据仿真验证了所提算法的合理性和有效性.
