# 同样在国家电网上班，正式工和农电工待遇为什么差这么多？

**国家电网编制的问题**一直是同学和家长们关注的重点，那么通过国家电网招聘考试进去之后有没有编制呢？是不是国家电网的正式员工呢？现在很多央企、国企或事业单位都有正式工、合同工、临时工、劳务派遣等多种用工形式，那么**国家电网有哪些用工形式呢？**他们之间有没有区别呢？今天玖石君就带大家来了解一下！

  

首先来看考入国网后**有无编制的问题。**

  

**0****1**

**考入国网有无编制？**

首先来明确一点，国网是没有编制的。**国家电网是国企也是央企，单位性质属于企业，既不是机关单位也不是事业单位，**因此并无编制一说。但为何还会出现国网编制的相关疑问？  
  
这就要介绍一下**另外一种编制——国企编制。**国企编制就是国有企业正式职工的用工编制，简单说就是直接和该国有企业签订劳动合同，**称为国企职工。**国企编制通常是指国企正式员工(也称编内员工正式工)，比如银行编制就是国企编制的一种，国企编制一般与国家财政无关。

  

**那除了正式工，国网还有哪些用工形式？**

  

**0****2**

**国网的用工形式**

  

国家电网是大型央企，其用工性质也分为多种形式，**一般分为正式职工、农电工、合同工、劳务派遣等**，分别对应不同的管理措施、工作岗位和工资待遇。下面我们来详细了解一下。

  

**正式工**

主要是包括两部分：一部分是指国家电网改革之前原电力局的正式干部和职工，是国家电网目前用工的主力军；还有一部分是近年来通过国家电网招聘正式招考进来的应届大学毕业生，会和国家电网签订不定期劳动合同，**享受国家电网终生制合同，国家电网不会轻易辞退正式工，并且工资待遇都很不错，并且也是国家电网的新鲜血液和未来的中流砥柱。**

  

**薪资待遇情况：**

基本工资：基本工资不高，各地有差异，一般在市局会高一点；

绩效工资：绩效工资与本省份企业效益挂钩，个人差异不大，通过打分得到；

各项补助：医疗保险补助，纳凉费，取暖补助，高温补贴等；

五险一金：社会保险，8% 公积金，12%；

隐含福利：各地区各时期有差异，医疗补助，节假日；

  

**农电工**

是国家电网以前的合同工、临时工。在国家电网改革过程中，因为工作年限符合《劳动合同法》规定的“无固定期限”劳动合同用工模式，成为电力公司的另一类正式职工。由于个人文化程度，技术职能等方面原因，虽然承担着基层电力最辛苦的工作任务，**但工资待遇较正式职工稍低，工作地点一般也较为偏远。**

  

现在的农电工招聘一般是国家电网下属的**三新公司、光明公司、供电服务公司(每个省份叫法不同)来负责招聘管理，**合同不是与国家电网签订，是与三新公司签订劳动合同，各供电服务公司将依照国家法律法规为录用人员缴纳各类保险和公积金。

  

农电工是历史遗留问题，是特定称谓，随退随销。改革后招聘的农电工是合同制管理人员，并不是传统意义上的农电工。从近两年颁发的政策来看，国家电网开始更多的关注和培养农电工的发展，对农电工进行重新培训、选聘上岗，将来会有越来越多的农电工被纳入正式工的体制，享受正式工的待遇，实现同工同酬。

  

**薪资待遇：**

1.同工不同酬，待遇肯定比正式员工要低一些，不同地区待遇差别也比较大。

2.退休后按照社保标准领取退休工资；农电工和劳务派遣公司、外包公司签订用工合同，按照国家法定标准缴纳社保和公积金，退休按照缴纳标准领取退休工资。

3.缺少晋升途径，农电工因为要求不高，工作基本处于一线工作，获得职业晋升的渠道比较少。

  

**合同工**

是指省、市、县电力公司雇佣的临时工作人员，由电力公司与劳动者签订劳动合同，承担合同工的人员管理、工资待遇、社会保障措施，为其按时足额缴纳“五险二金”。这其中还包括省、市级人事代理。签订劳动合同的主体，是根据人事管理权限，由具备劳动人事管理权的分公司与劳动者签订劳动合同。

  

**薪资待遇：**

合同工没有正式编制，期满了以后有可能会被解聘。**合同工的待遇低于正式员工，社保按5%交，公积金按10%交。**合同工的工资水平也会因岗位和学历有所差别，一般在3000-6000元之间，各省区间不大相同。

  

**劳务派遣工**

是指省、市、县电力公司雇佣的临时工作人员，由电力公司与劳动者签订劳动合同，承担合同工的人员管理、工资待遇、社会保障措施，为其按时足额缴纳“五险二金”。这其中还包括省、市级人事代理。签订劳动合同的主体，是根据人事管理权限，由具备劳动人事管理权的分公司与劳动者签订劳动合同。

  

**薪资待遇：**

劳务派遣工在电力公司**用工中通常是待遇最低，社保措施最差的，**很多地方都没法按足额交保险和社保。劳务派遣工的工资水平也会因岗位和技能有所不同，一般在2000-4000元之间。

  

**国家电网一般的工资待遇：正式工＞农电工＞合同工＞劳务派遣工**

  

对于国家电网来说，临时工和正式工无论从工资待遇还是工作环境上看，差距还是很大的，所以同学们有成为正式职工的机会一定要好好把握哦!凡是没有通过校园招聘(提前批)、统一招聘考试、定向招聘的方式与国家电网签约的，都不是所谓的“正式工”。

  

**0****2**

**薪资差距根本原因**

根本原因，签约主体不同，分属两家独立法人

1.国网正式工

直接和省 / 市供电公司（国网主业） 签劳动合同，属于国网核心编制，纳入央企主业人力成本核算，享受全套央企薪酬福利制度。

2.农电工（供电服务员工）

和地方供电服务公司签约（江苏三新、山东光明、安徽阳光等），这类公司是国网全资下属独立子公司，有单独财务、薪酬体系，不属于主业编制，两套薪酬池完全分开，不存在 “同一套工资标准”。

简单说：看似都在供电所干活，但发工资、交社保的不是同一家单位，成本预算互不打通。
