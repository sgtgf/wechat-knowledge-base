# 在微波超材料中“点亮”电磁托卡马克场


> 原文地址: [https://mp.weixin.qq.com/s/gijUVpC6GOxlX1-dwJDaUg](https://mp.weixin.qq.com/s/gijUVpC6GOxlX1-dwJDaUg)

教研室在环偶极超材料诱导局域准均匀场方面取得新进展

近日，教研室联合南洋理工大学团队提出一种亚波长环偶极金属超材料阵列，在微波频段实现了类似托卡马克的电磁场约束效应：在紧凑无源结构中形成局域、准均匀且显著增强的电磁场分布，为高强度局域场源、近场探测、无线能量传输和精密场调控提供了新的物理平台。

一、从“托卡马克”到电磁场调控

托卡马克装置是受控核聚变研究中的重要平台，其核心特征是在环形几何中形成闭合、约束的磁场构型，从而实现对等离子体的磁约束。这样的场拓扑不仅在聚变物理中重要，也启发了微波、光学、近场成像、波前调控等方向中的“受限场操控”问题：如果能够在紧凑电磁平台中构造局域且相对均匀的场分布，就有望服务于高灵敏传感、局域增强和精密探测。

然而，传统托卡马克依赖庞大复杂的高功率线圈系统，不适合直接移植到小型电磁器件中。本工作关注的问题是：能否不依赖大型线圈，而是利用人工设计的亚波长超材料结构，在微波频段诱导出类似托卡马克的局域电磁场效应？

这项工作的关键思想是：利用“环偶极”这种特殊多极响应，把托卡马克式的环形约束场拓扑转化为可由金属超材料实现的微波局域场结构。

二、核心设计：八个开口谐振环构成环偶极超材料单元

环偶极是多极展开中的一种特殊电磁多极矩，其典型特征是极向电流沿环形几何的子午面循环，从而形成闭合磁场环和强局域电磁能量。论文指出，环偶极响应的电流拓扑与托卡马克场效应中的极向电流分布具有天然相似性；同时，环偶极模式通常具有较弱远场辐射和较强能量局域，也与托卡马克式场约束的物理图像相吻合。

基于这一联系，研究团队设计了由八个金属开口谐振环（split-ring resonators, SRRs）组成的环形超材料单元。八个 SRR 等间距排布在环形几何中，并采用互补朝向，使结构在入射平面波激励下能够形成沿子午面循环的电流分布，从而激发主导的环偶极模式。

三、仿真结果：416 MHz 处形成局域准均匀场，场增强达 13.6 倍

论文首先通过多极展开分析验证了结构的主导环偶极响应。仿真结果显示，在 416 MHz 附近，环偶极矩对总辐射功率的贡献明显强于普通电偶极和磁偶极，表明该超材料单元确实工作在以环偶极为主导的响应模式。

进一步的电磁场仿真显示，在结构中心附近约 45 mm 半径范围内，电场形成局域准均匀分布，并出现显著场增强。以入射电场幅值 1 V/m 为基准，多位置探针得到的场响应在 416 MHz 处具有一致峰值，最大可实现约 13.6 倍的谐振场增强。与此同时，磁场矢量在结构中心附近形成闭合环状分布，呈现出类似托卡马克场效应的环形约束特征。

四、结构鲁棒性与可调控性

为了验证该效应并非某一组参数下的偶然结果，论文进一步研究了 SRR 数量 N 和环形半径 R 对电磁托卡马克场效应的影响。结果表明，在不同 N 和 R 条件下，结构仍能保持空间一致的谐振增强和局域场约束能力，说明该效应具有较好的鲁棒性。

同时，结构参数也为共振频率和场增强强度提供了调控自由度。例如，改变 SRR 数量会影响极向电流的方位密度和模式纯度；改变环形半径则会改变环形磁场的空间范围和整体电尺寸。论文选择 N = 8 作为兼顾场增强强度、场均匀性和模式纯度的设计方案。

五、实验验证：3×3 超材料阵列实现空间一致场增强

在实验上，团队加工了 3×3 环偶极超材料阵列，并在微波暗室中进行近场测量。实验系统采用喇叭天线产生近似平面波激励，通过可调探针和可编程位移平台在超材料结构内部多个位置获取电场响应。由于所诱导的托卡马克场效应高度局域，3×3 阵列已经能够为中心单元提供所需的周期性环境和互耦条件。

实测结果显示，x 分量和 z 分量电场在 5 个代表位置均在约 404 MHz 处出现一致的谐振增强峰值。该频率与仿真预测的 416 MHz 相比偏差约 2.76%，主要来源于聚乙烯支撑结构、近场探针扰动以及有限阵列与无限周期模型之间的差异。更重要的是，在谐振频率处，归一化场强在多个位置保持较高一致性，波动低于 0.81 dB；在中心区域内，x 和 z 分量场强波动均被抑制在 10% 以下。

六、研究意义与应用前景

本工作将托卡马克式场约束思想与环偶极超材料相结合，在微波频段提供了一种紧凑、无源、可实验验证的局域准均匀场生成平台。与传统大型有源线圈系统相比，该方案尺寸更小、结构更简单，并可通过平面波激励产生受限场分布；与以往仅关注环偶极或无辐射模式的超材料工作相比，本文进一步通过结构内部多位置探测验证了空间一致的场增强和准均匀场约束。

• 物理机制上：建立了环偶极响应与托卡马克式场拓扑之间的联系。

• 结构实现上：提出由八个 SRR 构成的亚波长金属超材料单元，并扩展为 3×3 阵列。

• 性能表现上：仿真实现 416 MHz 处约 13.6 倍场增强，实验在 404 MHz 处观察到一致谐振增强。

• 应用潜力上：可服务于电磁屏蔽、三维传感、超分辨成像、近场无线能量传输和精密场塑形等方向。

七、结语

这项研究展示了人工超材料在构造复杂电磁场拓扑方面的能力：通过环偶极金属超材料阵列，研究团队在微波频段实现了类似托卡马克的局域准均匀电磁场效应。该工作不仅为环偶极电动力学和结构化电磁场研究提供了新的实验平台，也为小型化、可设计的高强度局域场源开辟了新的实现路径。
