概念厘清：两类 “四臂螺旋” 的核心差异

01

“四臂螺旋天线” 并非单一产品，而是两类几何形态、性能侧重完全不同的圆极化天线家族，选型的首要前提是明确两者差异：

1\. 柱面四臂天线（QHA：Quadrifilar Helix Antenna）

  
![](https://mmbiz.qpic.cn/mmbiz_png/cOD9tYRcCnzkHNx9SrLILLHeAoSdv1AoWPLHUrtYUUtaZRjypOE5UicmofOpZYJmgib7P4icEXWjCBLba9wuvLFwQ/640?wx_fmt=png)

四条导体沿圆柱面螺旋上升，分为 “两对等长” 或 “一长一短” 的双臂组合（常见短臂≈λ/4、长臂≈3λ/4，λ 为中心频率对应波长），通过等幅正交馈电（四路电流幅度相等、相位依次差 90°）生成右旋 / 左旋圆极化（RHCP/LHCP）。

主打半球形覆盖，仰角 30°~90°（中高仰角）能量分布均匀，避免局部信号盲区；带宽中等，实用带宽通常为 10%~30%（如中心频率 1.5GHz，覆盖 1.35~1.95GHz）；结构立体，适配小型化设备集成。

手持 GNSS 终端（如北斗 / GPS 导航仪，适配姿态变化避免 “掉星”）、气象 / 遥感卫星接收（需稳定捕捉中高仰角卫星信号）、低轨（LEO）卫星通信（如卫星电话，半球覆盖满足移动需求）。

2\. 平面四臂天线（四臂平面螺旋 / 对数螺旋天线）

![](https://mmbiz.qpic.cn/mmbiz_png/cOD9tYRcCnzkHNx9SrLILLHeAoSdv1Ao7iaI17lSQx7lH3E34ezlMKCAvkmYQwiaNRVRS6nq3OicfNgpypiaWLyRAg/640?wx_fmt=png)

四条辐射臂在同一平面内绕中心，按等距或等角规律螺旋展开，多采用金属箔（铜箔）或印刷电路工艺制作（可直接集成在 PCB 板上）；若在背部加装金属腔或吸波材料，可将双向辐射改为单一半球辐射。

核心优势是超宽带 + 纯圆极化，带宽普遍≥50%（如覆盖 1~2GHz，可同时兼容多频段），全频段轴比稳定性好；辐射依赖 “活动区”（周长≈λ 的环形区域），外半径决定低端频率（f_L）、内半径决定高端频率（f_H），属于 “近似频率无关天线”。

电子对抗系统（需覆盖多频段干扰信号）、信号测向设备（依赖宽带相位中心稳定）、宽带接收终端（如电磁环境监测仪）、多频 GNSS 实验平台（需同时接收 L1/L2/L5 等频段，无需频繁换天线）。

工作机理：圆极化生成与尺寸带宽关联

02

两类天线的圆极化生成逻辑一致，但因结构差异，电流特性与尺寸对带宽的影响截然不同，这是理解其性能差异的核心：

![](https://mmbiz.qpic.cn/mmbiz_jpg/cOD9tYRcCnzkHNx9SrLILLHeAoSdv1AoPEts4LYxAoU4Ifuvke7pPmvzSm3y2a9aUek1bzuSkk4m9S6xNjouWQ/640?wx_fmt=jpeg)

1\. 圆极化生成的共性原理

无论柱面还是平面，核心均是 “通过相位控制实现旋转电场”：通过馈电网络，使四路幅度相等、相位依次相差 90° 的电流（相位序列：0°→90°→180°→270°）沿四条辐射臂传播。这些电流在空间中激发两个正交的电场分量（如 x 轴与 y 轴），因相位差 90°，叠加后形成 “时间维度随周期旋转、空间维度呈螺旋分布” 的电场，最终生成 RHCP 或 LHCP 圆极化波 —— 这是所有四臂螺旋天线的核心工作逻辑。

2\. 电流特性与尺寸 - 带宽的关联

（1）平面四臂天线：行波型电流与超宽带原理

臂上电流为 “行波型”，即电流沿臂向外侧传播，仅在 “活动区”（周长≈λ 的环形区域）产生有效辐射；远离活动区的电流（如靠近中心或边缘）因相位抵消，辐射效率极低。

低端频率 f_L：由外半径 R_out 决定，经验公式为R_out≈λ_L/(2π)（λ_L 为 f_L 对应波长，系数随臂宽、间距微调，通常取 0.8~1.2 倍）；例如 f_L=1GHz（λ_L=300mm），R\_out≈300/(2×3.14)≈47.8mm。

高端频率 f_H：由内半径 R_in 决定，需满足 “内周长≈λ_H”（λ_H 为 f_H 对应波长），且 R_in 不能过小（通常≥5mm）—— 否则会导致 PCB 加工精度不足、边缘效应增强，信号损耗上升。

螺旋圈数：2~4 圈最优，圈数过少则阻抗带宽窄，过多则增加尺寸；

臂宽与间隙：臂宽增大可拓宽阻抗带宽（如臂宽从 0.5mm 增至 2mm，带宽可从 40% 扩至 60%），但会提升电容性，需配合馈电网络（如串联电感）补偿；

背腔设计：金属背腔（深度≈λ/4~λ/2）可实现单向辐射，但可能引入腔模共振，需加薄型吸波材料（如羰基铁粉片）压制，代价是效率下降 5%~15%。

（2）柱面四臂天线（QHA）：驻波型电流与半球覆盖原理

臂上电流为 “驻波型”，电流分布受臂长、螺距、柱径共同调控，通过优化三者比例可将辐射能量集中于上半球，避免向地面方向浪费。

柱径：柱径周长需与工作波长同量级（如 1.5GHz 频段，λ≈200mm，柱径取 60~70mm），此时半球覆盖均匀性最优；柱径过小会导致高仰角增益下降，过大则增加设备体积。

臂长比例：采用 “短臂 + 长臂” 组合（短臂≈λ/4、长臂≈3λ/4），目的是抬高中仰角（30°~60°）能量、压低天顶过高增益（如天顶增益从 + 6dBic 降至 + 4dBic），实现半球能量均衡。

螺距与匝数：螺距取 λ/8~λ/4（如 1.5GHz 频段，螺距≈25~50mm），过小会增强臂间耦合、收窄带宽（如从 20% 缩至 10%），过大则难以保证电流相位稳定，极化纯度下降；匝数通常为 3~5 匝，平衡极化纯度与尺寸。

实用带宽通常为 10%~30%，若需突破 30%，需增大螺距、增加匹配节，但会导致尺寸增大（如柱高增加 20%）、损耗上升（插入损耗从 0.5dB 增至 1.2dB）。

设计要点：馈电网络的稳定化方案

03

馈电网络是确保 “四路电流幅相等、相位差 90°” 的关键，若设计不当，即使天线结构完美，也会导致极化不纯、方向图畸变，需重点关注拓扑、容差与工程技巧：

![](https://mmbiz.qpic.cn/mmbiz_png/cOD9tYRcCnzkHNx9SrLILLHeAoSdv1Ao2ozu6aJ1uxGp7DKnR6a6lDHGR6uGcVy3yqvdCv1c5tqcFB8gMGUcxg/640?wx_fmt=png)

1\. 核心拓扑结构

（1）四功分 + 90° 混合器：相位与幅度控制

功能：将输入功率均匀分为四路，同时精准控制相位。具体流程为：输入信号经第一级 90° 混合器分为 0° 与 90° 两路，再经第二级 90° 混合器各分为两路，最终输出相位依次为 0°/90°/180°/270° 的四路基带信号，确保幅度差≤0.2dB。

常用器件：90° 混合器优先选分支线混合器（窄带场景，插损小）或 Lange 耦合器（宽带场景，带宽可达 10:1）；四功分器采用威尔金森功分器，抑制端口间隔离度不足导致的串扰。

（2）平衡 / 不平衡转换（Balun）：抑制共模电流

必要性：天线辐射臂为对称负载（如两臂对地阻抗相等），而前端同轴电缆 / 微带线为单端馈电（一端接地、一端信号），若不转换会产生 “共模电流”（沿馈线外壁流动），导致方向图漂移、轴比劣化。

选型建议：宽带场景选 Marchand 巴伦（带宽可达 10:1，适配平面四臂），窄带场景选变压式巴伦（效率更高，适配柱面四臂）；共模抑制比需≥20dB，避免共模干扰影响性能。

（3）信号净化：滤波与抗干扰

应用需求：GNSS 等敏感场景中，需抑制蜂窝通信（如 5G 3.5GHz）、其他卫星系统（如铱星 1.6GHz）的强干扰，避免淹没弱信号（GNSS 接收灵敏度通常≤-150dBm）。

实现方案：前端加装微带带通滤波器（如中心频率 1.575GHz，带宽 20MHz）或 SAW 滤波器（声表面波滤波器，插损更小）；若为有源头端，可增加低噪声放大器（LNA），噪声系数≤1.5dB。

2\. 关键容差要求

幅度与相位：幅度失配≤±0.5dB、相位误差≤±5°（宽带端点可放宽至 ±1dB/±8°），否则轴比会从 2dB 劣化至 5dB 以上，圆极化纯度显著下降。

走线对称性：四条馈电线的电长度偏差≤0.1λ（对应中心频率），优先采用带状线 / 带状线腔（Stripline） 工艺 —— 带状线被上下地平面包裹，可减少自身辐射与外界耦合，比微带线抗干扰能力强 30% 以上。

3\. 工程优化技巧

![](https://mmbiz.qpic.cn/mmbiz_png/cOD9tYRcCnzkHNx9SrLILLHeAoSdv1AonY4dDFzyKibts5TPWBq5DTTQOoSibzp1c14UT1cicF6qnSWvFBnHsZ8Pw/640?wx_fmt=png)

分层解耦：馈电网络与辐射体上下分层设计（如辐射体在顶层 PCB，馈电在底层），中间用地平面隔离，辐射体下方地平面开窗（仅露馈电端口），四周加过孔墙形成电磁屏蔽，降低耦合干扰。

共模抑制：在同轴电缆进线处设计 λ/4 套筒（金属套筒长度 =λ/4，一端接地）或套铁氧体扼流环，可将共模电流抑制比再提升 10dB，避免方向图畸变。

量产适配：预留电阻 / 电容微调位（如每路输出端串联 0.1~1kΩ 电阻、并联 1~10pF 电容），量产时若某路幅度 / 相位偏差，可通过微调快速补偿，返工率从 30% 降至 5% 以下。

性能评估与选型权衡

04

评价四臂螺旋天线需聚焦核心指标，同时结合场景与其他圆极化天线对比，避免盲目选型：

1\. 核心性能指标解读

（1）极化纯度（轴比）

定义：衡量圆极化纯度的关键（理想圆极化轴比 = 0dB，线极化→∞），优先选择仰角 20°~90° 范围内轴比 < 3dB—— 该区间是卫星通信、GNSS 的主要工作仰角。

特殊关注：平面四臂的低仰角（≤20°）轴比直接影响多径抑制，轴比每增加 1dB，多径误差从 0.5m 增至 1m，需重点控制。

（2）方向图与增益

方向图：平面四臂加背腔后为单向宽波束（半功率波束宽度≥60°），需保证波束内增益波动≤1.5dB；柱面四臂需关注 “天顶 - 中仰角” 均衡，不追求天顶峰值（如 + 6dBic），而追求整半球 “可用即可”（天顶 + 4dBic、中仰角 + 3dBic）。

增益与效率：平面四臂裸天线增益 0~+4dBic（加背腔后 + 2~+7dBic），效率≥80%；柱面四臂半球中值增益 + 2~+5dBic，效率≥75%；需关注 “频段一致性”（增益波动≤1.5dB），而非单一峰值。

（3）输入回波与幅相一致性

输入回波（|S11|）：反映天线与馈线的匹配程度，通常要求 | S11|≤-10dB（反射功率≤10%），宽带天线边缘频段可放宽至≤-8dB，无需强求全频段 “一刀切”。

幅相一致性：四端口幅度差≤0.5dB、相位差≤5°，量产时需抽测四端口 S 参数（S21/S31/S41），提前发现馈电网络偏差。

（4）群时延与相位中心

定位 / 测向场景必备：群时延波动≤5ns（避免信号失真），相位中心随频率 / 仰角漂移≤0.5λ（如 1.5GHz 频段漂移≤100mm），否则定位误差会从 2cm 增至 5cm 以上。

3\. 选型核心逻辑

聚焦 “四大要素”，无需追求 “万能天线”：

频段跨度：窄带 / 中带宽（≤30%）选柱面四臂，超宽带（≥50%）选平面四臂；

覆盖形状：半球覆盖选柱面四臂，单向覆盖选平面四臂（加背腔）；

安装空间：小型化设备（如手持终端）选柱面四臂，空间充裕场景（如实验平台）选平面四臂；

效率目标：效率要求≥80% 选柱面四臂（无吸波损耗），可接受 70% 以上选平面四臂。

落地实践：材料、流程与避坑指南

05

从设计到量产，需关注材料选型、标准化流程与常见问题规避，避免 “纸面性能” 与 “实际性能” 偏差过大：

1\. 材料与结构选型：避免隐性损耗

（1）导体与基材

平面四臂：基材优先选低损耗板材（PTFE 复合板，Dk=2.65、Df=0.001；Rogers 4350B，Dk=3.48、Df=0.003），避免用 FR-4（高频段 Df=0.02，损耗大）；导体用 18μm 无氧铜箔，确保电流趋肤效应损耗小。

柱面四臂：导体用 0.1~0.3mm 厚铜带或 1~3mm 直径铜管（纯度≥99.9%），焊缝需连续完整，表面粗糙度≤0.8μm（减少反射损耗）；支撑件选 PEEK（Dk=3.2、Df=0.002）或聚四氟乙烯，避免 ABS 塑料（损耗导致效率下降 10%）。

（2）背腔与罩体

背腔：平面四臂的金属背腔用 6061 铝合金，内壁做发黑 / 阳极氧化消光处理，或贴 0.5mm 厚吸波材料，抑制腔模共振；深度取 λ/4~λ/2（对应中心频率），避免触发共振导致增益突降。

罩体：户外应用需满足 IP67 防护、-40℃~85℃工作温度、抗紫外（UVB 照射 1000h 无老化）；材料选玻璃纤维增强 PTFE（Dk=2.5、Df=0.002），厚度误差≤0.1mm—— 否则会导致频移（如 1.5GHz 频段厚度差 0.2mm，频移 50MHz）、轴比劣化。

（3）连接与走线

连接器：选 SMA/TNC 型，回流焊或压接工艺，外壳接地电阻≤0.1Ω（避免共模干扰）；

馈电线：同轴电缆进线处做滴水弯（弯曲半径≥电缆直径 5 倍），套铁氧体扼流环，防进水与共模。

2\. 标准化落地流程（7 步走）

（1）需求定义（任务书）

明确核心参数：频段 / 带宽（如 1.5~1.6GHz）、极化方向（RHCP）、覆盖形状（半球）、效率≥75%、安装空间≤Φ50mm×40mm、环境等级（-40℃~85℃、IP67），避免模糊表述。

（2）拓扑选型

半球覆盖 + 中带宽→柱面四臂；超宽带 + 单向覆盖→平面四臂 + 背腔。

（3）初算与仿真

尺寸初算：平面四臂 R_out≈λ_L/(2π)，柱面四臂柱径≈λ/π；

仿真验证：用 HFSS/CST 扫频分析轴比、方向图、|S11|，ADS/AWR 验证馈电网络 S 参数（插入损耗≤1dB）。

（4）样机验证（V1 版）

制作 “裸天线” 与 “带罩体 / 背腔样机”，对比测试量化罩体影响（如轴比变化≤0.5dB、效率下降≤10% 为可接受）。

（5）馈电收敛优化

暗室测试四端口幅相，用 RC 微调补偿偏差，确保仰角 30°~60° 轴比≤3dB。

（6）系统联调与验收

加装实际支架、线束、接地板后复测；GNSS 场景额外测试 C/N0≥45dB-Hz、低仰角 “掉星” 次数≤5 次 / 小时。

（7）量产管控

锁定基材规格、电镀工艺、弯折治具，建立 “来料 - 在制 - 成品” 抽检标准（如基材 Dk 偏差≤0.05，成品轴比≤3.5dB）。

结合实际场景明确用法，并通过清单核对关键参数，确保选型无遗漏：

1\. 典型应用场景（以 GNSS 为例）

![](https://mmbiz.qpic.cn/mmbiz_jpg/cOD9tYRcCnzkHNx9SrLILLHeAoSdv1AoTaviau0WlFfiaa4MmZDPI0ZMR08e0TZMg4ibRA5a6Ijn0y5Dq1QlicHcEg/640?wx_fmt=jpeg)

（1）手持 / 背负式 GNSS（如户外导航仪、测绘仪）

选型：柱面四臂（QHA），优先选 Φ50mm×40mm 小型化设计，重量≤20g；

优化：多径干扰严重场景（城市峡谷、林地），加小型接地板（直径≈柱径 1.5 倍）或吸波裙边，多径抑制提升 15%~20%。

（2）多频宽带 GNSS 实验平台（高校 / 科研机构）

选型：平面四臂 + 背腔，覆盖 L1（1575.42MHz）、L2（1227.6MHz）、L5（1176.45MHz），外半径≈50mm；

注意：吸波背腔效率损失≤10%，前端 LNA 噪声系数≤1.5dB，确保弱信号接收。

（3）GNSS 测向系统（干扰源定位）

选型：多单元平面四臂阵列（4~8 单元），阵元间距≥0.5λ，加隔离墙抑制互耦；

关键：馈电同步相位误差≤3°，相位中心漂移≤0.1λ，测向精度≤1°。

（4）车载 / 舰载 GNSS（宽域接收）

选型：柱面四臂或平面四臂 + 背腔，若上方有结构遮挡（如车顶行李架），优先选 “低仰角增益饱满” 型号（仰角 20° 增益≥+2dBic）；

防护：满足 IP67、-40℃~85℃、抗振动（10~2000Hz，5g），适配恶劣环境。

3\. 总结：选型核心逻辑

“四臂螺旋天线” 的应用关键不是 “选哪种”，而是 “哪种适配场景”：

锁定频段 / 带宽、覆盖形状、安装空间、效率底线，避免模糊表述；

半球 + 中带宽→柱面四臂，超宽带 + 测向→平面四臂；

严控幅相一致性、背腔 / 罩体影响、共模抑制，确保落地性能与设计一致。

若有明确频段（如 1.5~1.6GHz）与安装边界（如尺寸≤Φ50mm×40mm），可基于上述逻辑快速确定初始方案，直接开展仿真与打样，缩短研发周期。
