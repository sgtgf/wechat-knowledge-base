# SiC MOS+模块，深度赋能新能源与工业领域


> 原文地址: [https://mp.weixin.qq.com/s/DnpBtN0tUzEYNDkNEiyVFg](https://mp.weixin.qq.com/s/DnpBtN0tUzEYNDkNEiyVFg)

专注于第三代半导体碳化硅（SiC）SBD+MOSFET芯片设计、晶圆制造及功率模块封测的国家高新技术企业、专精特新小巨人企业。覆盖芯片设计、晶圆制造及模块的封装测试、驱动应用等关键环节。先后通过了IATF16949汽车行业质量管理体系、ISO9001/45001/14001三体系、AEC-Q101和AQG-324产品可靠性认证。  
  
1.SiC 晶圆片（Wafer）#半导体#芯片  
  
设计研发SiC MOSFET/SBD芯片，电压650V~1200V~1700V~2000V~3300V,电流：1A~150A，自建6吋兼8吋SiC晶圆厂。  
  
2.SiC MOSFET/SBD单管#大电流低损耗技术#电源  
  
研发及生产SiC MOSFET/SBD单管，电压650V~1200V~1700V~2000V~3300V,电流：1A~250A。  
  
3\. 碳化硅功率模块#逆变器#光储充 #新能源应用#车规级三相全桥模块#工业级半桥模块  
  
专注SiC功率模块的自主研发和生产，自建模块工厂。SiC模块电压等级从650V~1200V~1700V全系量产，封装齐全，满足车规级和工业级要求，电流30A~1000A，产品性能与国外主流品牌性能相当。  
  
4.碳化硅器件的应用#新能源汽车  
  
相较于传统硅基器件，碳化硅（SiC）功率器件具有耐高压、耐高温、抗辐射、散热能力佳、更低的导通损耗和开关损耗、更高的开关频率、可减小模块体积等特性，在高压系统中有望快速替代，具有更紧凑的空间设计以及更高的功率密度。  
  
目前主要应用于以下领域：#半导体行业趋势 #工业控制应用  
  
# 新能源汽车：主驱逆变器、车载充电机（OBC）、直流快充桩；  
  
# 光伏与储能系统：组串式逆变器、储能变流器（PCS）；  
  
# 数据中心与通信电源：服务器电源、UPS不间断电源；  
  
# 轨道交通：牵引变流器、辅助电源；  
  
# 智能电网与能源基础设施：固态变压器(SST)、高压直流输电（HVDC）；  
  
# 工业电机驱动：高频变频器、伺服驱动器；  
  
# 航空航天与国防：高功率特种电源、机载电源系统；  
  
随着技术的成熟和成本的降低，SiC MOSFET器件正在逐步替代传统的硅基IGBT和MOSFET，成为高效、高功率密度系统的首选。
