DOI：10.13334/j.0258-8013.pcsee.182217

 

//

**一、****什么是求解OPF问题的凸松弛技术？相比于其他OPF求解方法，该方法有何优点与缺点？**

//

 

是一种通过将OPF模型中的非凸约束松弛为凸约束，将难以求解的非凸OPF问题转化为凸优化问题进行求解的技术。

其优势有：

- 在松弛精确的情况下，可保证在多项式求解时间内获得OPF的全局最优解
 
- 在松弛不精确的情况下，可为原OPF问题提供最优值的一个下界
 
- 可通过松弛后的凸问题无可行解来判定原非凸OPF问题无解
 

其劣势有：

- 实际运用中难以保证松弛的精确性。在松弛不精确的情况下，所得到的松弛后优化问题的解没有实际物理意义
 
- 有时会遇到计算量过大的挑战（多见于半正定松弛中）
 

 

//

**二、****目前主流的凸松弛技术有哪些？**

//

 

- SDP（semi-definite programming）松弛：在OPF模型中引入新矩阵变量_W_\=_V_(_V\*_)_T_，之后松弛掉（舍弃）模型中_rank_(_W_)=1这条难以处理的非凸约束再进行求解
 
- SOCP（second-order cone programming）松弛：特殊的SDP松弛，将原模型的非凸约束松弛为旋转二阶锥约束 |_Wij_|2≤_Ｗ_ii_W_jj后进行求解
 
- QC（quadratic convex）松弛：利用“凸包络”概念完成的凸松弛。引入该松弛的初衷是在进行凸松弛时尽可能多的保留线路两端电压变量间的信息，使松弛后求得的解与原问题的解相近甚至相同
 

 

//

**三、****如何提高凸松弛的精确程度？** 

//

 

目前主要有两类研究方向：

- 寻求精确凸松弛的充分条件，即不对松弛过程本身作处理，而是寻求外生的、被证明可以保证松弛精确的应用场景
 
- 对松弛过程本身进行“加强”，构造尽可能紧的凸松弛，使其精确度内生化地提高
 
 
 

//

**四、对凸松弛技术的展望？** 

//

 

从技术手段来看：

- 构造更紧的松弛应是未来OPF凸松弛技术研究的主流
 
- 进一步探索精确凸松弛的充分条件
 
- 进一步探索OPF问题的目标函数及可行域对凸松弛的影响
 
- 探求凸松弛技术与其他OPF求解方法相结合的可能性
 
- 利用OPF问题自身的物理性质或通过模型变换寻找新的松弛方法
 

从应用场景来看：

- 探究特定应用场景（如多时段OPF、鲁棒OPF）下最适合的OPF松弛技术
 
- 在高渗透率可再生能源的接入下，研究反向潮流情形下的OPF凸松弛技术的适用性以及适用条件
 

 

//

**结    论**

//

 

凸松弛技术为OPF问题的求解提供了全新的思路。该项技术可将非凸的OPF问题转化为可以采用数学规划方法求解的凸 问题，并在精确松弛的前提下获得原问题的全局最优解。与其它求解方法相比，凸松弛技术的优点是在松弛精确的情况下可获得全局最优解，缺点是在应用过程中松弛的精确性难以保证，可能导致松弛后获得的解在原问题中不可行且没有明确物理意义。

 

展望未来OPF凸松弛技术在理论方法层面的研究方向，除了构造更紧的松弛与探索精确松弛的条件以外，还可以研究OPF问题的可行域、目标函数对凸松弛的影响，探寻凸松弛与传统OPF求解方法结合的可行性以及利用OPF问题的物理性质或通过模型变换构造新的松弛。
