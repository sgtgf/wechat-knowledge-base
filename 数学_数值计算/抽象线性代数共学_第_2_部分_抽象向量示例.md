# 一、这页的核心主题

标题是：

**Abstract Linear Algebra – Part 2**

这一页的中心问题其实是：

**“向量空间到底是什么？”**

很多人一看到“向量空间”，脑子里就想到平面上的箭头、三维空间里的向量。但这页图想告诉你：

**向量空间不一定是几何箭头。** 只要某个“集合”上定义了两种运算，并且满足一组规则，它就可以叫做向量空间。

# 二、向量空间的抽象定义

图中间那个蓝框，概括了定义：

一个 **vector space（向量空间）** 需要有：

-   一个**集合** set
    
-   一种**加法** addition
    
-   一种**数乘** scalar multiplication
    
-   这两种运算满足 **8 rules**（8条规则）
    

并且这些数乘里的“标量”来自某个 **field** （域）。

图上还特别写了：

**important cases:**

-   实数域 
    
-   复数域 
    

所以平时最常见的是：

-   **实向量空间**
    
-   **复向量空间**
    

* * *

# 三、这里的“抽象”到底抽象在哪里

抽象之处就在于：

它不关心元素长得像不像箭头， 只关心：

1.  你这个东西是不是一个集合；
    
2.  能不能做“加法”；
    
3.  能不能做“数乘”；
    
4.  这些运算是否满足向量空间公理。
    

也就是说：

-   可以是普通向量
    
-   可以是矩阵
    
-   可以是函数
    
-   可以是多项式
    

只要规则满足，就都是向量空间。

这就是“抽象线性代数”的味道。
