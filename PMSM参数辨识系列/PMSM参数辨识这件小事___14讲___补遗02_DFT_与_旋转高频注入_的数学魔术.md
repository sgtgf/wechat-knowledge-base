## 一、DFT 的“魔法”：为什么“相乘再累加”就能滤掉噪声？

想象一下，各位在一个**盛大的交响乐团**里，要精确测量出**小提琴声部**的音量。

-   **乐团演奏**： 这就是电机测得的原始电流 i(t)，里面有大提琴的低音（基波）、长笛的高音（谐波）、还有观众席的咳嗽声（随机噪声）。
    
-   **你要测的小提琴声**： 这就是注入频率 ωc 对应的电流分量 Acos(ωct + φ)。
    

你怎么才能只听到小提琴的声音？

**DFT 的方法是：** 你自己也拉一把一模一样音高（频率ωc）的小提琴，然后把它的声音和整个乐团的声音“**对齐**”并“**比较**”。

这个“对齐比较”的过程，在数学上就是**相乘再积分（累加）**。

**关键的物理特性：正交性**

-   **当你用一个 cos(ωct) 的标准音**去和乐团的声音相乘：
    

-   **频率不同的声音（比如大提琴的 cos(ω1t)）**： 乘出来的结果是cos(ωct)cos(ω1t) 。根据积化和差公式：cosA·cosB = \[cos(A - B) + cos(A + B)\]/2。 结果是两个更高频的波，它们的波形有上有下。当你把它们在一个周期内积分（累加）时，正负部分会互相抵消，最后结果趋近于 0。
    
-   **频率相同的声音（小提琴的 Acos(ωct + φ)）**：乘出来是 Acos(ωct + φ）·cos(ωct)。根据公式，它会分解出一个**直流分量！**根据积化和差公式：Acos(ωct + φ）·cos(ωct) = A·\[cos(φ) + cos(2ωct + φ)\]/2 ，当你积分（累加）时，那个高频的 cos(2ωct + φ) 部分会被抵消，但那个**常数项** Acos(φ)/2 会被留下来，并且越加越大！
    

-   **同理，当你用一个 sin(ωct) 的标准音**去乘**：**
    

-   **频率不同的声音**： 同样会被抵消。
    
-   **频率相同的声音**： Acos(ωct + φ)·sin(ωct) = A\[-sin(φ) + sin(2ωct + φ)\]/2积分后，会留下一个**常数项**\-Asin(φ)/2。
    

**结论：**

-   用 cos(ωct) 做乘法积分，得到的是信号在 ωc 频率上**与 cos 同相的分量**（即**实部**）。
    
-   用 sin(ωct) 做乘法积分，得到的是信号在 ωc 频率上**与 sin 同相的分量**（即**虚部**）。
    

这两个分量合起来，就完整描述了小提琴声音的**音量（幅值 A）**和**节奏偏差（相位 φ）**。

现在我们来看 `pm_fsm_state_probe_const_inductance()` 里的这几行关键代码，这次我们看得更细：

```
// 在循环中，hfi_wave = [cos(ωc*t), sin(ωc*t)]
```

-   `probe_DFT[0]` 累加的是 iX(t)·cos(ωct)，它最终提取出 IX 在 ωc 频率上的**实部分量**。
    
-   `probe_DFT[1]` 累加的是 iX(t)·sin(ωct)，它最终提取出 IX 在 ωc 频率上的**虚部分量。**

-   `probe_DFT[0]` 和 `probe_DFT[1]` 就代表了电流 IX 在 ωc 频点上的**复数表示**。
    
-   `probe_DFT[2]` 和 `probe_DFT[3]` 代表了电压 UX 在 ωc 频点上的**复数表示**。
    

**这就是代码A实现DFT的方式：没有复杂的库函数，就是最底层的“相乘再累加”，但它用得非常巧妙和高效。**

## 三、“旋转高频注入”的“探测手法”

既然我们有了这么强大的“顺风耳”，那我们应该发出什么样的“探测音”，才能最高效地完成“体检”呢？

-   **脉动注入**： 只在一个方向上喊话，听回声。
    

-   **优点**： 简单。
    
-   **缺点**： 如果喊话的方向刚好对着一堵吸音墙（比如电机的某个“盲区”），那回声就很弱，信息不全。
    

-   **旋转注入**： 拿着喇叭，一边转圈一边喊话。
    

-   **优点**： 360度无死角探测，能得到全方位的信息，结果更鲁棒。
    

代码A在**探测模式**（`pm_fsm_state_probe_const_inductance()`）中，正是采用了**旋转注入**！

在 `pm_fsm_probe_loop_current()` 中：

```
// hfi_wave 在每个周期都会旋转 ωc*Ts
```

这相当于在（临时的）dq 坐标系里，注入了一个旋转的电压矢量。当这个 dq 坐标系本身静止时，就等效于在静止的 XY 坐标系（或αβ坐标系）里注入一个旋转的高频电压。

**旋转注入 + 同步DFT，是天作之合：**这是在用一个旋转的“暗号”（注入信号）去探测，再用同一个旋转的“密码本”（hfi\_wave）去解调。这样**信噪比最高，抗干扰能力最强！**

## 四、小剧透：Kahan 求和 (`m_rsumf`)

代码A的作者在使用DFT进行信号解调时，使用了大量的`m_rsumf`函数：

```
// 在循环中，hfi_wave = [cos(ωc*t), sin(ωc*t)]
```

咱们来提前揭秘一下它的作用。

```
void m_rsumf(float *sum, float *rem, float x)
```

-   `sum`：计算时用到的的**大金库**。
    
-   `rem`：计算时用到的的**零钱罐**。
    
-   `x`：这次要存的钱。
    

这个函数执行的**流程**就是：

1.  **从新钱里，先减去上次找的零钱。**
    
2.  **把这个“凑整”的钱存进金库。**
    
3.  **计算一下，这次存钱操作又产生了多少新的“零钱”误差，然后把它存进零钱罐，下次用。**
    

这个小小的函数，保证了 `probe_DFT` 数组在经过成千上万次累加后，结果依然精确。这就是高质量嵌入式代码的细节所在！

## 五、本文小结：

旋转HFI + 同步DFT是一套精妙的组合拳：

1.  **DFT 的本质**： 利用三角函数的**正交性**，通过**相乘再累加**的方式，像“调谐收音机”一样，从嘈杂的信号中精确锁定并提取出特定频率的分量（实部和虚部）。你的 `probe_DFT` 数组就是这个过程的记账本。
    
2.  **旋转高频注入**： 相比于只在一个方向注入，旋转注入能提提供更丰富的激励，360度无死角地探测电机，使得参数辨识结果更准确、更鲁棒。
    
3.  **代码的实现**：代码A将**旋转高频电压注入**（产生丰富的响应）和**同步DFT**（精确提取响应）结合起来，并且用 **Kahan 求和** 保证了计算精度。这套组合拳，为后续用最小二乘法解出精确的阻抗矩阵，打下了坚实的数据基础。
