# 负电压的产生电路图解析  

在电子电路中，负电压的应用十分广泛，例如在运放电路中，为其提供稳定的负电压是必不可少的。接下来，我们将以正5V电压转换为负5V电压为例，简要介绍其电路原理。

在电子电路中，当需要负电压时，通常会选用专为负压产生而设计的芯片，例如ICL7600和LT1054等，但这些芯片的成本相对较高。接下来，我们将介绍单片机电子电路中常用的两种负压产生电路。  
![](D:\电脑文件\公众号知识库\电工_教育_学习\电路中产生负电压的多种方法_images\img_001_7076264e209f.png)  
现今，许多单片机都配备了PWM（脉冲宽度调制）输出功能。在实际应用中，PWM输出往往被忽视，然而，它却可以被巧妙地利用来产生负压。接下来，我们将介绍一种简单的负压产生电路，该电路仅需一个PWM输出即可实现。  

这种电路的设计极为精简，仅需提供约1kHz的方波信号。但需注意，由于该电路的负载能力较弱，且在加入负载后电压降幅较大，因此在实际应用中可能需要进行改进。基于此，我们进一步发展出了更为复杂的电路设计。

# 负电压产生电路分析

电压，这一衡量单位电荷在静电场中能量差的物理量，其本质在于电势的差异。简单来说，某点的电压即为该点与参考点之间的电势差。在常规情况下，我们将供电电源的负极作为参考点，此时电源电压可表示为Vcc=E电源正-E电源负。若要产生负电压，关键在于降低某点的电势，使其低于参考点。这通常需要引入另一个电源，通过串联的方式实现。具体来说，将电源2的正极与参考电源1的负极相连，而电源2的负极便可作为负电压的输出端。  
![](D:\电脑文件\公众号知识库\电工_教育_学习\电路中产生负电压的多种方法_images\img_003_d7225f633b3c.png)  
一个负电压产生电路的实例：通过电容充电，我们可以等效地构建出一个新的电源。  
在这个例子中，电容被串联在接地端（GND）之后，从而等效为电源2。这样的配置即可产生所需的负电压。  
![](D:\电脑文件\公众号知识库\电工_教育_学习\电路中产生负电压的多种方法_images\img_004_503cef00ddf5.png)  
1、电容充电过程：在PWM信号为低电平的阶段，三极管Q2导通，而Q1则处于关闭状态。此时，VCC电源通过Q2向电容C1充电，形成的充电回路为VCC-Q2-C1-D2-GND。经过充电后，电容C1的左端呈现正电势，右端则为负电势。  
![](D:\电脑文件\公众号知识库\电工_教育_学习\电路中产生负电压的多种方法_images\img_005_58a8fdf5d26d.png)  
2、电容C1的充电完成

在PWM信号为低电平的阶段结束时，电容C1的充电过程也随之完成。此时，由于VCC电源通过三极管Q2向电容C1持续充电，直至其达到满电状态。完成充电后，电容C1的两端将分别呈现出正负电势，为后续电路提供稳定的电压。  
![](D:\电脑文件\公众号知识库\电工_教育_学习\电路中产生负电压的多种方法_images\img_006_977e1e7ec7be.png)  
3、电容C1作为电源，其高电势极与参考点串联。在C1放电时，电流会通过C2和D1续流，从而产生负电压。

当PWM信号变为高电平时，三极管Q2将关闭，而Q1会打开，这使得电容C1开始放电。放电的回路为C1-C2-D1，这一过程同时也为C2进行充电。一旦C2充满电，其上下极性将为正负相反，若VCC的电势为5伏左右，便可输出-5伏的电压。  
![](D:\电脑文件\公众号知识库\电工_教育_学习\电路中产生负电压的多种方法_images\img_007_62970ace8c42.png)

# 产生负电压（-5V）的原理与实现

在电路中，通过特定的组件配置，可以产生负电压。一种常见的方案是利用电容C1作为电源，并串联其高电势极与参考点。当PWM信号变为高电平时，三极管Q2关闭而Q1打开，从而启动电容C1的放电过程。这个放电回路包括C1、C2和D1，同时为C2进行充电。一旦C2充满电，其上下极性将变为正负相反，进而在VCC电势约为5伏时，能够输出-5伏的电压。  
![](D:\电脑文件\公众号知识库\电工_教育_学习\电路中产生负电压的多种方法_images\img_008_65fa2150043b.png)  
7660和MAX232的输出能力有限，无法满足高速运放的需求，因此需要采用4片并联的方式来扩大电流输出。最初，我们尝试了两片7660并联的设计。实际上，使用普通的DC/DC芯片就能产生负电压，且其电压精度与正电压相当，同时具有强大的驱动能力，电流可达到300mA以上。此外，一般的开关电源芯片也能产生负电压，若需求更大的电流，可以利用开关电源输出的PWM来驱动电荷泵，这样不仅成本低廉，而且经过LC滤波后的电荷泵纹波非常小。值得注意的是，7660本身为电荷泵，因此电流相对较小。

在示波器的设计中，数字电源的+5V和模拟电源的+5V是分开供电的。然而，对于数字地和模拟地的处理却是一个关键问题。数字地和模拟地必须相连通，否则电路将无法正常工作。在连接时，需确保数字部分的地返回电流不会流经模拟部分的地线，而是应该在稳定的地参考点处汇合。这样，负电压在电路中就起到了至关重要的作用。  

2、通讯接口需求。例如，RS232接口在通讯过程中必须使用负电压。其协议规定，-3V至-15V表示逻辑“1”，而+3至+15V表示逻辑“0”。这种设计必须遵循。值得注意的是，MAX232等接口芯片内置电荷泵，可自行产生负电压。

3、运放电源轨需求。老式运放如OP07不具备轨到轨输入/输出能力，其输入电压范围始终比电源电压范围小1V，输出小2V。若VEE设为0V，则输入电压必须超过1V，输出电压不会低于2V，这可能不满足某些电路设计要求。为在接近0V的输入/输出条件下工作，需为运放提供负电压，如-5V，以确保其在0V附近能正常工作。但随着轨到轨运放的普及，此类情况已逐渐减少。

4、电路保护。芯片内部保护电路通常对负电压无防御能力，因此高电流或电压稍高的负电压作用于芯片上，就可能造成芯片损坏。
