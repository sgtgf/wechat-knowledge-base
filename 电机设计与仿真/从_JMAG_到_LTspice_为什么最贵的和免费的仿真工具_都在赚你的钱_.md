# 从 JMAG 到 LTspice：为什么最贵的和免费的仿真工具，都在赚你的钱？

原创 傅存敬 电磁散人 2026-06-28 07:06

> 原文地址: [https://mp.weixin.qq.com/s/SX-1RMHC2ClIbjCY-mNS7g](https://mp.weixin.qq.com/s/SX-1RMHC2ClIbjCY-mNS7g)

这是我打过的最漂亮的一仗。

一台电机控制器，用在低速新能源车牵引电机上。客户说自家软件人手不够，要我们联合开发；工期压得死紧，指标提得老高。为了一次就把它做成，我们把家底全搬上了台面。

电机本体设计，用日本的 JMAG，把电磁性能和热性能算到位；控制器硬件设计，用 PSIM 和 LTspice，抠功率器件的热和电磁；算法开发，用 Simulink 和 PSIM 一起搭。难的不是单独哪一样，是把它们焊成一个整体——JMAG 的电机模型，嵌进 PSIM 的控制器架构；PSIM 的硬件架构，再嵌进 Simulink。一整套机电一体化的思想压下去，把电机的极限、控制器的极限、功率器件的极限、算法的极限，四样一起，顶到了最优。

这里头的分量，同行自会掂量。

可交付那天，我看着那张报价单。

电机，有价。控制器，有价。物料一项一项，都有价。

只有"开发费"那一行——写着 0。

不是漏填。是老板定的。他算过账：只要这客户的订单能续上一两年，这点开发费，就当白送。客户要是还想要，物料清单可以给，原理图可以给，甚至源代码本身，也能一并奉上。

"换一两年的单子，"他说，"值了。"

我没接话。

那套四个极限顶到最优的系统、那些焊在一起的仿真模型、那场我口里最漂亮的仗——折算到这张纸上，真的就值一个 0。

而老板没算错。这笔账，从头到尾，算得通。

# 一 · 一块招牌，五样东西

先别急着替我憋屈。那张报价单的账，后面再算。

我想先退一步，说说我刚才一口气念出来的那几样——JMAG、PSIM、LTspice、Simulink。它们，连同一类我那次没用上的，在我们这行，全被塞进同一个词里：仿真软件。

可你盯着这"仿真软件"四个字，看看底下都装着什么，就该觉出不对劲了。

JMAG 算的是电机本体里那团电磁场，几吨重的硅钢和磁钢的事；Simulink 管的是另一头，纯软件里的 FOC 和观测器，一行行代码的事；PSIM 蹲在功率回路上，盯着逆变器和器件发烫；LTspice 再往里钻一层，只伺候栅驱、电源那几颗料；还有 HIL——dSPACE、Typhoon 这些，干脆把一整台真控制器，接进一座虚拟的实时工厂。

从几吨重的铁，到一行代码，再到一颗芯片——这五样东西，盯的根本不是同一个世界。价钱更离谱：同样这四个字，有的一分不要，有的一套顶你一年工资。

可我们偏偏顺手就把它们当成了一类。反正都在电脑里算模型，都在屏幕上吐波形、吐云图，一个词打包了事，然后下意识地抄起尺子，给它们排座次：这里头哪个最强？哪个最值这个价？

这个问法，听着天经地义。

可你要真信了它，就会一路被它带偏——从该买哪样工具，到怎么给自己手里那点活儿定价。

说到底，这五样东西压根不是一类。同一块招牌底下，蹲着五副完全不同的骨头——也就是，五门做法天差地别的生意。

# 二 · 换一把尺子：别问谁更准，问错了能不能收回

那，怎么把这五门生意分清楚？最顺手的两把尺子——比谁算得准，比谁卖得贵——偏偏都量错了地方。

"谁更准"这把尺子，会让你把 JMAG（或 Ansys）和 LTspice 搁到同一根轴上排名次——可它俩压根不在一条道上。一个管电机本体的电磁场、热场和机械场，一个管栅驱回路那几颗器件，准不准各有各的判法，硬比就是关公战秦琼。"谁更贵"那把尺子更误事，它让你默认贵的就好、免费的就是将就；可你跟着我的文字往下走你会看见，最高明的一手，恰恰是把软件白送。

真正能把这五样东西劈开的，是另一把尺。而且这把尺你天天在用，只是从没拿它去量过软件——

**它替你拦下的，是哪一类错？那个错，一旦犯了，收不收得回来？**

工程师对这事的体感，比谁都真。你改错一行 FOC，大不了重编译、重烧录，半小时的事，一分钱不花；可你模具开错了、磁钢牌号定错了、样机照着错参数做出来了——那是几周，是几十万，是回不去的。同样一个"错"字，一类错在比特上，改回来几乎免费；一类错在钢和铜上，改回来要命。

按"拦的是哪种错"把这五类重排一遍，它们立刻各归各位。

**最收不回的那种错，归电机设计 CAE 软件和 HIL 系统管。** Ansys、JMAG 替你拦的，是开模、定材料、做样机之前的那几个决定；一步踏错，代价就砸进物理世界，再也收不回来。开场那个项目，我咬牙上 JMAG，就是冲这个：电机本体的错，开了模、定了材料才发现，神仙也救不回来。HIL 更直白，它替你拦的是真控制器接上真高压前的那一下——真炸了，板子没了，运气差的话人也伤了。这两样守的，是那道"过去就回不来"的门。它俩，也最贵。

**错了能收回、但收得肉疼的那种，归 PSIM、PLECS 这类电力电子系统级仿真管。** 拓扑挑错、开关频率定偏、环路没调好，赔进去的主要是时间和几块烧掉的板——能改，改起来得熬几个通宵、来回烧几轮。它们守的不是"不可逆"那道门，是"别让你反复试错试到天亮"那道门。

**错了基本能白收回的那种，最轻。** 比较器选型不对、滤波网络配岔、采样前端没整明白，屏幕上改改连线、换换器件，几乎不花钱。有意思的是，住在这一格的，不止 LTspice 一个——MATLAB里的Simulink 也在这儿。控制算法、软件实现上的错，说到底也是比特上的错，能改，能重写。这两样替你拦的错，同样都收得回来。

到这儿，那把"可不可逆"的尺，已经把五类排得清清楚楚。可你要是再抄起另一把尺——**谁掏的钱**——会发现它跟前一把尺，大半是合得上的。

电机 CAE 软件，是平台预研、中央研究院拍的板，签字的常是技术总监——因为它管的不是一个项目，是往后好几代产品的底子；HIL 更得跨部门一起背，扯上实验室建设和功能安全；PSIM、PLECS 多半是驱动器团队自己从下面买上来的，决策快、额度小。错越收不回，花钱越往上走、越得郑重其事。两把尺，对得严丝合缝。

偏偏到了最轻那一格，两把尺打起架来。

同样是"错了能白收回"的工具，LTspice 压根不走采购流程——它免费；可 MATLAB 端坐在研发管理的预算里，是核心基建，公司一旦用上，就再难拿掉。一样轻的错，一个白送，一个你掏着大钱还离不开。

这就怪了。

按理说，越是错误收不回的，你越该多掏钱——这条规律，大半是对的。可 LTspice 和 MATLAB 这道裂缝告诉你：定价这件事，根子上跟"那个错有多严重"没多大关系。是另一样东西，躲在背后，给这些软件标着价。

那是什么？

# 三 · 一把刀：创造价值，和拿走价值，是两道分开的工序

要回答它，得先承认一件怪事。

LTspice 这么好用——画电源、画栅驱、画采样前端，多少工程师离不开它——可它一分钱不要。如果"价值就是钱"这句话成立，那免费的东西就不该这么有用；可它偏偏极其有用。

这件怪事逼出一个结论，而这个结论，是一个很可能让你揪心的结论：

**创造价值，和把价值收进自己口袋，是两道分开的工序。**

一个工具能卖多少钱，从来不取决于它替客户创造了多少价值，只取决于它能从这些价值里，截下多少留给自己。

我们前面把仿真软件分成了五类。现在换一个问法——不问"它创造了多少价值"，只问"它能截留多少，以及，是什么拦着客户不换它走"。这一问，五类东西的命，就分出来了。

## 最能截留的那一档：Ansys、JMAG、Maxwell，还有 Typhoon、dSPACE 这些 HIL

## 它们凭什么敢开高价？两件事叠在一起：**错误不可逆，加上，卖家极少。**

你在 Maxwell 里把磁路算错了，代价是开错一次模、选错一个磁钢牌号、推倒一台样机重来——这是物理世界的钱，花出去就回不来。你把一台真控制器接到 HIL 上跑边界工况，省下的是不必拿真板子去碰高压大电流、不必炸一块板才知道哪里错。所以客户掏的那笔钱，买的从来不是"软件"，是一份**保险**：在设计冻结之前，先在屏幕上，把该犯的错都犯完。

而能卖这份保险的，全球就那么三五家。保险，加上寡头，等于你不敢不买，也没几家可换。这就是为什么——我以前专门写过一篇——Ansys 敢年年涨价，而你只能年年降本。它截留的，不过是你"少开一次错模"省下那笔钱里的一个零头；可那个零头，就够覆盖你好几年的 license 费。这门生意的"准"，直接接在你的物理制造成本上。

## 第二档，MATLAB 和 Simulink，截留率一样高，可它靠的是另一样东西——不是风险，是组织，和人

它的护城河，根本不在哪个求解器精度高，而是在两处。

一处，是你全公司的模型、脚本、测试基准，连同每个工程师手上的肌肉记忆，全沉在这套体系里。哪天想换掉它，你换的不是一个软件，是十年攒下的组织资产。

更狠的是第二处——人。所有学生一毕业就会 Simulink，论文、教材、招聘要求，全是它。你招一个会 Simulink 的人进来，不用培训就能干活；可你要是换了平台，等于让往后招进来的每一个新人，先替你交一笔学习税。

所以 MATLAB 卖的压根不是仿真，是**行业的通用语**。语言这东西的规律是：谁用的越多，谁越离不开。它的定价权，就长在这条规律上。

## 第三档，LTspice。它的截留率是零——而且是这四个里头，唯一一个故意把自己截留率清零的

ADI 在软件上一分不收，因为它要收的钱根本不在软件这边——在硅片里。免费的仿真器、免费的器件模型、免费的参考设计，干的是同一件事：在工程师"还在画方案、还没定 BOM"的那一刻，先把人请进 ADI 的工具链。等你 layout 收尾、BOM 定稿，里头那颗芯片，大概率姓 ADI。

它把"创造价值"和"捕获价值"拆到了两个产品上：仿真器负责创造，硅片负责收钱。这不是做慈善，是这四种里设计得最精的一手——拿一个不要钱的东西，去占住一个要钱的位置。

回到我那个项目——LTspice 我用得最凶，栅驱、电源、采样前端全靠它推演，没掏一分钱。当时只当白捡了便宜。可这便宜，是 ADI 早设计好的：我每用它一次，就往它的器件库里，又挪近了一步。

## 第四档，PSIM 和 PLECS。这是最尴尬的一个，截留薄，而且薄得有结构上的原因——它上下都被夹着

往上看，它俩顶着 MATLAB 那套"全公司平台 ＋ 人才网络"，挤不进企业级标准那个位置；往下看，它能干的不少活，SPICE 和那些免费工具也能凑合，随时可能被做成白菜。

它的价值是实打实的——搭得快、跑得快、贴功率级、调起来顺手。可"快"这种好处，护城河天生就浅：今天你快，明天别人也能快。于是你看它的定价都是拧巴的：有的产品明码标价，有的只能找销售要报价。它能活下来，是因为在驱动器工程师那张桌子上，它确实趁手；但"趁手"这两个字，撑不起 Ansys 或 JMAG 那种价。它不是护城河中庸，而是真的薄。

把这四档摆到一块，一条规律就自己冒出来了：

凡是能狠狠截留的，手里要么攥着别人**不可逆的风险**（CAE、HIL），要么占着一门别人**离不开的语言**（MATLAB），要么干脆把收钱的口袋**挪到了别处**（LTspice）。而那个截留薄的，恰恰是只顾着创造价值、却没攥住任何一条"让客户走不掉"的理由的——PSIM、PLECS。

道理讲到这儿，问题其实已经不在这些软件身上了。它转过身，对着你了——你写的那套 FOC 算法、那套无感观测器算法，在这张图里，站在哪一格？

# 四 · 你就是那个免费工具

答案你可能不爱听。

你，和 LTspice 同格。

那套四个极限顶到最优的系统，那些焊在一起的模型，那场我口里最漂亮的仗——在报价单上，它值 0。不是因为它不值钱，恰恰因为它太像 LTspice 了：极其有用，却一分钱也收不上来。开场那张纸上的 0，到这儿你该看懂了——那不是一笔账，那是你自己，被标了价。

可你比 LTspice 还惨。

LTspice 免费，是它心甘情愿。ADI 把仿真器白送出去，因为它要的钱在硅片里收——撒出去的是钩，钓上来的是鱼，钩和鱼，都归 ADI。那是它精心设计的一手。

你呢？你那套算法也白送了，钩是真撒了，鱼却不归你。

ADI 白送，是为了自己收回来；你白送，是替别人收。

替谁？替那个几乎什么都没干的客户。

他们没写一行代码，没爬一条温升曲线，没开一套模，没拧一颗螺丝。他们只做了一件事：把自己的 logo，连同那纸 IP 授权，盖在了你的杰作上。

然后——同一个东西，挂你的牌子，没人买；贴上他们的 logo，一群人抢着付钱。

技术是你的，想法是你的，商业头脑是你的，连产线、连那双拧螺丝的手，都是你的。你什么都不缺——只差一样：那个 IP，不姓你。

而在这门生意里，谁攥着 IP，谁就把价值全收走，哪怕他半根指头都没出力。

这就是为什么，你明明站着把活干完了，挣到手的，却是一份跪着的钱。

——这套道理，我在这公众号上来回讲过很多次。可你看，讲得明白，和挣得出来，是两码事。

别以为这是我一个人的倒霉。

你翻开这行里随便哪家控制器厂的账，"开发费"那一行，多半也蹲着一个一模一样的 0。我们整整一个行业，集体站在 LTspice 那一格上，集体把自己手里最硬的东西，白送给攥着 logo 的人。

为什么没人挣扎？[因为成交那一刻，唯一算数的那本账——BOM——上面，压根没有你这套东西的位置。](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486501&idx=1&sn=c64bc0bcd6c4027d5a2ceb7f437c678b&scene=21#wechat_redirect)

BOM 记的是有重量的东西：几克铜，几克硅，几克铁，几克塑料。可你的算法没有重量。它称不出来，也就写不进任何一行。于是在那本唯一算数的账里，你那场最漂亮的仗，干脆不存在。

可它不是真的不存在。

你那套东西创造出来的价值，一分没少——它只是没留在你这儿。它顺着那行称不出重量的缝，悄没声地，淌进了贴 logo 那个人的兜里。

中国的古人说，福往者福来，爱出者爱返。可你这份"爱"出去了，返回来的那条道，通的偏偏是别人家的门。

# 五 · “爱出者，爱不返”

可这一"返"，怎么就返进了别人家的门？要弄明白，得回到这句老话出生的地方。

"爱出者爱返"——今天它多半被当成鸡汤，印在台历和锦旗上。可它出自贾谊的《新书》，底下压着的东西，比锦旗那行字重得多。贾谊讲了个人——邹穆公。这位国君爱民如子，把国家治得路不拾遗；等他死的那天，举国哭了三个月，像死了亲爹。他就此收一句：爱出者爱返，福往者福来。你把爱付出去，爱会回到你身上。

可你要拿工程师的眼睛看这个故事，会忍不住多问一句：那份爱，为什么偏偏回到了邹穆公身上？

因为他是君。民心这条返回的道，系在他的位子上，跑不掉。他付出爱的身份，和接住回报的身份，是同一个——爱出去，绕一圈，除了回到他这儿，没有别的地方可去。

爱出者爱返，原来压着一个谁都没说破的前提：**回来的那条道，得是你自己的。**

攥紧这个前提，再来看老子。

《道德经》第二章：为而不恃，功成而弗居。夫唯弗居，是以不去——你做了，却不去占；正因为不占，它反而不离你而去。

这是圣人的境界。可同样一句话，落到你头上，整个翻了过来。

你那套算法，为而不恃了：你做了，没占住，IP 不归你。照《道德经》字面上的意思，接下来该是"不去"。

可它去了。它顺着报价单上那行看不见的缝，去了客户兜里。

同一个"去"字。老子拿它说"功不会流失"，你的处境拿它说"价值流走给了别人"。你也许要说，这两个"去"不是一回事——老子的"去"是凭空消失，你的"去"是被人拿走。可在你自己那本账上，被人拿走和凭空消失，有什么分别？都是从你这儿，没了。两个"去"，到你这儿，合成了一个。

于是你看明白了：老子的"不去"，和贾谊的"爱返"，本是同一条律——付出，而不失去。可这条律要成立，得有一个前提里的前提：要么，你脚下踩着一条**属于自己**的返回通道——邹穆公的君位、ADI 的硅片，爱出去绕一圈只能回到自己；要么，你活在一个**讲理**的世道里，那个世界本身会托住不占的人，像老子说的天道。

你两样都没有。

通道不在手——客户关系、品牌、IP，全姓别人。天道也不在场——BOM 这本账，恰恰是冲着把你的价值流向别人去设计的。

通道不在手，天道不在场。两句千年的老话，一起对你失了灵：

爱出者，爱不返。功成者，其功去。

不是老话错了。是你——既没占着那个位子，又没赶上那个世道。

世道，你改不了。可那条返回的通道——能不能，自己造一条出来？

# 六 · 自己的那条道

能。可你最先想到的那几种造法，多半是坑。照老规矩，写到这种地方，该端上一碗鸡汤了：去做芯片，去卖 IP，去把算法做成自己的产品。

可你我都在这行里泡过，知道这三句话有多轻。做芯片要烧多少钱、熬多少年，你比我清楚；你那点开发费连价都没标上，拿什么去流片？卖 IP——客户从签约第一页就把归属写死了，你卖给谁？把算法做成产品——你自己挂牌的东西没人买，这事第四段刚讲完。

所以这一段我不灌那个。我们老老实实，说两条真路，外加一句更老实的话。

**第一条，是 ADI 那条，也是邹穆公那条：给自己弄一条返回的通道。**

通道，就是那个让你"爱"出去之后、还收得回来的位置。ADI 的位置是硅片，邹穆公的位置是君位。你未必占得起硅片，可通道不止硅片一种——

它可以是一个拆不开的模块：把算法和硬件焊成一个你自己卖的整体，让客户没法把算法那块单拎出来、在 BOM 上标成 0。它可以是一段离不开你的关系：要是价值在持续的调校和迭代里，那就卖这段关系——卖订阅、卖维护、卖"以后还得找你"，别卖一锤子买卖的板子。它甚至可以是一个名字：像 Simulink 那样，让人一碰这类活就先想到你——这条最慢，可一旦成了，是最硬的通道。

这几条说到底是同一件事：**给自己挣一个位子。** 而位子这东西，贵，慢，难。我不骗你说它容易。

**第二条，是从那本账下手：让你的东西，在账面上显出形来。**

价值会蒸发，是因为它没重量、上不了 BOM。那就别让 BOM 做唯一的那本账：把开发费单列出来，而且真去收，别再写成 0；把 IP 留一部分在自己手里，别在第一页就签得干干净净；能的话，卖结果，别卖铁——卖你那套算法换来的效率、续航、可靠性，给它标价，让客户为"它干成了什么"掏钱，而不是为"它有几克重"掏钱。

这条听着比第一条容易，其实未必。改账本，要么你手里攥着客户离不开的真本事、敢摊牌；要么这一行一块儿改。你一家硬要给软件标价，客户扭头找个肯写 0 的，你立马出局——这，恰恰就是你老板当年摁下那个 0 的原因。

说到这儿，那句最老实的话，也该说了：

这两条路，多数人短期内，一条都走不通。价值链就横在那儿，你是 OEM 格局里一个小供应商，胳膊拧不过大腿。这是实情，我不替你粉饰。

可你也别急着泄气。因为光是看清这个结构，就已经在改一些东西了——哪怕你今天一步都还迈不动。

看清了，你谈价就不一样：你至少知道自己在白送什么，于是能把它折进价里、能留一手 IP、能为那段关系多要一分。看清了，你押注的方向就不一样：往"攒一个位子"那头走，而不是在纯辛苦钱里越陷越深。看清了，连你看自己的眼神都不一样：你不会再把报价单上那个 0，错当成你这身手艺的价钱。

看清，不等于上岸。我不骗你说想明白了账就变了——BOM 还是那个 BOM。可一个看清了的人，和一个没看清的人，哪怕此刻困在同一张报价单上，往后那条路，也会越岔越开。

而岔开的第一步，是先承认一件你一直没太愿意承认的事。

# 七 · 那张报价单，和那个 0

你以为你在卖控制器。

其实，你一直在白送算法。那个铁疙瘩，客户掏了钱；可真正让它转得动、比别人省电、比别人稳的那套东西——你那场最漂亮的仗——是搭着铁疙瘩，一起白送出去的。

这事，LTspice 也天天在干。区别只有一个：**ADI 是故意的，你是不知不觉的。**

ADI 白送仿真器，是设好的局，专等在硅片上收回来。你白送算法，是连自己在白送，都没怎么当回事——直到那张报价单摊在面前，"开发费"那一行，写着 0。

回头再看我老板那句"值了"。

他没算错。在那本只认重量的账上，你的算法本来就是 0，送掉，确实"不亏"。可他算的是这一单的账。他没算的是：每白送一次，你就把"自己到底有没有一条返回通道"这个问题，又往后拖了一年；离那个"给自己挣个位子"的可能，又远了一步。一单一单看，单单都值；一年一年看，你 把能站起来的本钱，当辛苦钱，一笔笔花光了。

我没法在这篇文章的末尾，替你变出一条通道，或者改写你手里那本 BOM。这两样，得靠你往后很多年，一寸一寸去挣。

但有一件事，今天读完就能做到：**别再把那个 0，当成你的价。**

那个 0，是这门生意记账方式的结果，不是你那套算法的真身。看透这一点，你那场最漂亮的仗，至少在你自己心里，先从 0，变回它本来的分量。

把白送出去的东西收回来，很难，也许要熬很多年。

但承认自己在白送——

这是第一步。

也是从"跪着"，到"站着"，最短的那一步。
