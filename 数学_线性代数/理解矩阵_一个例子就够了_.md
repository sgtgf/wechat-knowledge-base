# 理解矩阵，一个例子就够了！


> 原文地址: [https://mp.weixin.qq.com/s/1tyawQP9iXsGxLB2NXEbxw](https://mp.weixin.qq.com/s/1tyawQP9iXsGxLB2NXEbxw)

在“特征值与特征向量”系列推文中，我们已经探讨了矩阵各种类型的特征值和特征向量所对应的基本线性动作。在本文，我们将给出一个涵盖以上所有动作类型的矩阵，通过对该矩阵的特征分析，加深读者对矩阵基本内涵的全面理解。本文所使用的矩阵如下：

为了拆解该矩阵所对应线性变换的核心构成——即其包含的各类基本线性动作，我们首先从特征值求解入手。通过计算可得，该矩阵有5个特征值，具体数值分别为：

![](https://mmbiz.qpic.cn/mmbiz_png/tbsNyKAwjm5vCJzSQpPdxbkBTdibVVIq2chx2Bf4XbVj6oib4dDMkKk6J2nbn8ogSwibKpe0StwkAGP9Gc4OXqVbw/640?wx_fmt=png&from=appmsg)

从矩阵的特征值可直接看出，其对应的线性变换至少包含反射、缩放、旋转这三个基本线性动作。

  

又由于矩阵**A**存在代数重根_λ_4\=_λ_5\=2，需要进一步验证其是否可对角化。经分析可知，该重根对应的线性无关特征向量仅有1个，即其代数重数与几何重数不相等。由此可明确判定，该矩阵不可对角化，其对应的线性变换还额外包含剪切动作。

  

为更精确地定位矩阵**A**所对应基本线性动作的发生场所，我们可将该矩阵转化为若尔当标准型，有**A**\=**PJP**\-1，其中

![](https://mmbiz.qpic.cn/mmbiz_png/tbsNyKAwjm50mblLQEXy853aQuRXrWVIfJs4nruZMNNwLLfhgsrsdvJoML7Gq30N89bDJft8pP9ziaVia69XIfvg/640?wx_fmt=png&from=appmsg)

接下来，我们即可完整梳理出该矩阵所包含的各项基本线性动作：

（1） 反射动作。_λ_1\=_\-_2，**p**1\=\[0 0 0 1 -1\]T，由于特征值为负值，表明矩阵**A**所对应的线性变换在**p**1方向有一个反射动作。

（2） 缩放动作。_λ_1\=_\-_2，**p**1\=\[0 0 0 1 -1\]T，由于特征值的大小不为1，这意味着矩阵**A**所对应的线性变换在**p**1方向有一个2倍的缩放动作。

（3） 旋转动作。_λ_2\=_\-i_，**p**2\=\[1+_i_  -1-_i_  -2-2_i_  1-3_i_  1-3_i_\]T，由于![](https://mmbiz.qpic.cn/mmbiz_png/tbsNyKAwjm5vCJzSQpPdxbkBTdibVVIq2IFbCich1Ep22HWMTa9GhmLToASjUic1HicTOG6tjv7tkUGwmuBzIlKvdQ/640?wx_fmt=png&from=appmsg)，因此矩阵**A**所对应的线性变换包含了一个90度的旋转变换，并且这个变换发生在其特征向量（**p**2）的实部和虚部所张成的平面上，其中**p**2的实部和虚部分别为

![](https://mmbiz.qpic.cn/mmbiz_png/tbsNyKAwjm50mblLQEXy853aQuRXrWVIRKdAZQnN5wTzc7g9Xiba4aO3DvZGOM8ibFxXq8wxLibww1LDqwemzibHbg/640?wx_fmt=png&from=appmsg)

需要注意的是，这里的角度指的是以Real(**p**2)，Imag(**p**2)为基底的平面上的赝角度。关于赝角度的定义请参考[“特征值与特征向量（4）”](https://mp.weixin.qq.com/s?__biz=Mzk2NDk3NjgzOA==&mid=2247487630&idx=1&sn=fa9d7b2d38076fe7d5d699e65d134c58&scene=21#wechat_redirect)一文的详细阐释。

（4） 剪切动作。与代数重根_λ_4\=_λ_5\=2对应的若尔当块为

![](https://mmbiz.qpic.cn/mmbiz_png/tbsNyKAwjm5vCJzSQpPdxbkBTdibVVIq2eic3DR3peamYMswTO9SNBJfJ8kHW786ickAicSuEDHMCWfkic3Oz83LpFQ/640?wx_fmt=png&from=appmsg)

该若尔当块对应的特征向量和广义特征向量分别为 ，  

![](https://mmbiz.qpic.cn/mmbiz_png/tbsNyKAwjm5vCJzSQpPdxbkBTdibVVIq28MUOEXdaiaA45IHEMQZmucOplmJVXbibSfus7bsAcxTgH8ib2CXfN2mnQ/640?wx_fmt=png&from=appmsg)

这表明矩阵**A**所对应的线性变换在**p**4和**p**5张成的平面上存在一个剪切变换。又由于_λ_4\=_λ_5\=2不为1，该平面上还伴随一个2倍的缩放动作。

将**J**按照基本动作类型分为三个部分，分别对应反射（缩放）、旋转、剪切三个基本动作，则有**J**\=**J**1**J**2**J**3，其中

![](https://mmbiz.qpic.cn/mmbiz_png/tbsNyKAwjm5vCJzSQpPdxbkBTdibVVIq2hicgdQKFlszO2hllEkDdOmaGvZmdfBia5ibRoh0Fa5vhwa4vdMRUByQtA/640?wx_fmt=png&from=appmsg)

再加上动作发生的场所，则可得到三个完整的基本动作

![](https://mmbiz.qpic.cn/mmbiz_png/tbsNyKAwjm5vCJzSQpPdxbkBTdibVVIq2C9GbNj75VlEa57L7wjW64Ej09oWYVicgRHKjj3ezL7Y7NwDoibEjjjicg/640?wx_fmt=png&from=appmsg)

其中矩阵**A**1所对应的线性变换在**p**1方向有一个反射和缩放2倍的线性动作，而在别的特征方向保持不变；矩阵**A**2所对应的线性变换在**p**2的实部和虚部张成的平面上有一个旋转90度（赝角度）的动作，而在别的特征方向保持不变；矩阵**A**3所对应的线性变换在**p**4和**p**5张成的平面上有一个剪切动作，同时还伴随一个2倍的缩放动作。

而矩阵**A**可以表示为这三个基本动作的复合，即**A**\=**A**1**A**2**A**3，且与这三个矩阵的乘积顺序无关。

通过本文对具体矩阵的完整拆解——从特征分析切入，到若尔当标准型转化，再到反射、缩放、旋转、剪切等基本线性动作的逐一剖析，最终实现了抽象的矩阵与具象的线性变换过程的精准对应。在这一过程中，读者可以清晰地认识到，矩阵对应的线性变换即这些基本线性动作的复合，进而推动对矩阵本质的理解从概念转向实践。至此，我们已成功完成对任意实矩阵及其对应线性变换的完整解构，这将为后续更深入的矩阵复杂应用构建起稳固的认知基石。
