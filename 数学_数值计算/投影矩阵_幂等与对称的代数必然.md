# 投影矩阵：幂等与对称的代数必然

## 心智锚点

把一个球从空中投向地面，它停在了地面上。

再投一次——它还在地面上。位置不变。

**投影完成后，再次投影不会改变结果。这就是幂等性。**

## 幂等性：

几何含义：**一旦一个向量已经在子空间内，再投影一次不会移动它。**

投影后的向量是"固定点"。投影操作在第一次执行后就"固化"了结果。

这就是"结果固化"的算子特性：**投影是一个一次性操作。它把向量拉到子空间上，然后永远固定在那里。**

## 对称性：

（利用了  对称 →  →  也对称。）

几何含义：投影在"施加方"和"接收方"之间是**对称的**。投影的距离度量不偏向任何一方。

对称性保证了投影矩阵的特征值都是实数——具体来说只有 0 和 1。

## 现实映射

**幂等思维的核心法则：最好的系统操作是幂等的——执行一次和执行多次的结果完全相同。**

-   HTTP 的 PUT 方法是幂等的：上传同一份文件多次，结果和上传一次相同。
    
-   数据库的 UPSERT 操作是幂等的：插入或更新记录，重复执行不产生新的副作用。
    
-   好的投影思维是幂等的：一旦你做出了"在当前约束下的最优选择"，重新评估不会改变这个选择。
    

**如果一个操作不是幂等的——重复执行会产生不同的结果——那它一定不是投影。它一定引入了某种累积效应。**
