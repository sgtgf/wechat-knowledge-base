# 从技术方面如何判断硬件工程师的水平？

公司新入职了3个硬件工程师，想考察一下技术实力，单从技术方面如何判断硬件工程师的水平？

![](D:\电脑文件\公众号知识库\电工_行业资讯\从技术方面如何判断硬件工程师的水平__images\img_002_b24010206dab.png)

顺便说一下行业，机器人行业，目前所涉及工作为四轮驱动的机器人底盘、机器人工作执行端、桁架工作末端的应用。

  

_**01**_

  

很简单啊，给你小信号采集的任务。

比如：声音 超声波 小电流 都可以。

设计完成电路，来讲讲问什么这么设计，器件为什么这么选型。怎么考虑的使用场景和应用场景。

![](D:\电脑文件\公众号知识库\电工_行业资讯\从技术方面如何判断硬件工程师的水平__images\img_003_b2c99a1f4769.png)

基本功就差不多了，适用于所有方向的硬件工程师，包含射频方向。

看你有没有潜力，培养一下。

就一般的条件是：1年内可以完全HOLD住公司所有的产品，包括：问题定位，售后解答，客户问题收集。

如果能搞定，小公司就会放独立的项目给你，包括器件选项啊，功能需求文档啊，生产工艺文件啊。

大公司就会把之前产品的几个产品线交给你维护：产品改版 定制 等等。

如果你还可以坚持干3年，基本上也会给你释放一些管理权限：

小公司就是一把抓，产品基本都你管了。

如果你有些管理能力的话，大公司就会安排个小组，管理下人力统筹和任务安排，新人培养。

当然，你说我也能干，但是没有管理才能，基本上小公司你干不久。因为，小公司的本质就是一分钱多分活。和你本职业务关系不大，你哪怕不精但是能扛担子小公司也愿意培养。

但是，大公司好处就是你可以技术钻技术，内部职称：工程师助理(实习/试用)—>初级（工程师）->高级->专家。基本就这样，其实活是差不多的。就是新项目可能要求你去审核和评估。但是相对于工资等级也会涨。

  

_**02**_

**个人觉得，硬件工程师的能力有以下几方面：**

1、基础学科和电路相关学科的理论能力，主要涉及高等数学、复变函数、大学电路、大学物理、模拟电路、数字电路、高速电路设计、信号完整性、电磁仿真、EMS/EMI设计等；

2、器件选型、电路设计能力；

3、故障定位、联合调试能力；

4、电路板焊接、手工工具使用能力;

5、万用表、示波器、频谱仪、时序分析仪、矢量网络分析仪等仪器仪表的使用能力；

6、常见数字信号的总线和接口的理解和测试能力；

7、文档阅读、撰写能力；

8、新方案和平台的学习能力；

9、代码debug能力；

10、问题描述和沟通能力。

![](D:\电脑文件\公众号知识库\电工_行业资讯\从技术方面如何判断硬件工程师的水平__images\img_004_a0a0017c8d30.png)

这些是硬件工程师理论上是都得具备的，但其实很难全部精通，不过能够学习，大部分硬件工程师都能够完成上述的任务。

想要考察别人，遇到几次问题，分配几个新方案和任务，看看会不会，或者不会的时候怎么尝试解决，自然就知道能力够不够了。

  

_**03**_

这个要看岗位本身需求。水平高低就看，这个人是否是能解决公司现在和将来要面临的问题。

![](D:\电脑文件\公众号知识库\电工_行业资讯\从技术方面如何判断硬件工程师的水平__images\img_005_46353df0b969.png)

硬件工程师也是一个集合，硬件的方向也是好多。高速电路，射频电路，功率电路，模拟电路，都很不一样。虽然都是硬件的方向，但使用的开发工具，行业标准，测试方法，器件选型方案都不一样。

比如电源方向，saber，psim，spices，mathcad这些做仿真的，jmac做变压器设计等等。估计这些做射频的工程师是不太会用，而且电源方向对emc，散热，安规的标准，和射频或者高速电路所需求大相径庭。

抛开这些专业能力，还有一些业务上的能力。比如说对成本方案的把控，对硬件交期设定，方案风险的评估，团队沟通和协调，物料交期的和供应商PK等等。

个人观点，能力高低主要看需求和业务能力。如果用高速电路标准去评判做模拟电路的，或调转过来，这会闹笑话。

  

_**04**_

可以考察两个方面的能力，第一个是经验，如果现在的工作内容以前有做过，那么上手很快，很容易做出成果。第二个是成长力，不管有没有经验，遇到问题是否可以主动研究并学习，有效解决。如果有，时间长了，经验也就有了。

![](D:\电脑文件\公众号知识库\电工_行业资讯\从技术方面如何判断硬件工程师的水平__images\img_006_5d65b1172295.png)

不管什么职位，都会有自己擅长的东西和不会的。公司希望员工可以胜任工作内容，理论考试可能不准，直接看项目完成效果。员工希望公司的工作可以有成长或有足够的好处，没有追求的人都会变成老油条。能自主成长的员工其实不多，更多的需要管理，改造成满意的工具人。

  

_**05**_

笔试面试应该有初步的判断了吧。剩下的，就看实际干活好不好了。分派一些不关键的活，几天下来，基本有数了。

如果真不知道怎么评判水平，还让入职了，只能说贵司钱多。
