# 单片机复位功能RC电路，工程师选择什么电路方案可以解决

单片机，作为工程师研发电子产品的关键元器件，它的电路稳定工作能力显得尤为重要；作为项目开发的工程师，如何去设计相应的电路来保证单片机的可靠工作就非常有必要；面对这一研发问题，工程师选择什么电路方案可以解决呢？

单片机电路系统

众所周知，单片机工作的最小系统包含电源、晶振与复位等相关电路；处理单片机的稳定工作，也就是设计相应的电路保证最小系统的稳定；在一些实际的项目开发中，工程师一般都会使用单片机的内部晶振，因此只需要处理电源与复位的问题，就可以完成这个单片机系统的稳定性问题；

RC复位电路调试

在设计单片机的复位电路，工程师采用比较多的电路是RC复位电路，其电路特点是设计简单，只需要一个电阻与一个电容即可完成功能要求；

RC复位电路

RC复位电路虽然能满足单片机的复位功能要求，但由于不具有可控性，因此很难满足一些复杂的电路系统；除了RC复位电路，还有其他的复位电路可以选择的吗？

多功能复位芯片就是处理这种复杂电路系统复位问题的最佳解决方案，如STM6503复位芯片，它的特点包含

![](D:\电脑文件\公众号知识库\电工_教育_学习\单片机复位功能RC电路_工程师选择什么电路方案可以解决_images\img_003_746bf51b62dd.png)

STM6503引脚图

1，延时时间：复位芯片的延时时间可以通过控制TSR引脚的高低电平选择

-   当TSR = 0；复位延时时间为2S；
    
-   当TSR = 1；复位延时时间为10S；
    

2，复位逻辑：复位芯片产生复位芯片的控制逻辑为SR0与SR1均为逻辑低电平，否则复位芯片将不会对外输出复位信号；

![](D:\电脑文件\公众号知识库\电工_教育_学习\单片机复位功能RC电路_工程师选择什么电路方案可以解决_images\img_004_74056e25d974.png)

STM6503复位芯片应用系统图

在两个电路系统中，A电路系统可以通过逻辑控制B电路系统的STM6503复位芯片输出的复位信号，从而间接控制B电路系统的功能，也有效互相监督系统的稳定工作；

STM6503复位芯片，除去这两个特点，在电路设计还存在一些不足之处

-   成本：使用STM6503复位芯片，增加电路的研发BOM元器件成本费用
    
-   功能：A电路系统可以通过控制B电路系统的单片机其他信号，比如两个电路系统之间通过SPI通信达到信息交互，也能实现互相监督的功能
    
-   封装：STM6503复位芯片的封装为TDFN8，对于一般焊接水平的工程师，在打样调试阶段，需要制作功能样品时候不易焊接；

电路板焊接

最后综合比较两种复位电路的效果：RC复位电路简单，适合独立电路系统；专用复位芯片复位电路，设计复杂，适合多功能的电路系统；工程师在实际的项目研发阶段，大多数是处理独立的电路系统，如面包机，电饭煲等等，所以RC复位电路就得到工程师的广泛使用；
