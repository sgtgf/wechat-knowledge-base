# 真实物理世界是连续的（S域），而微处理器是离散的（Z域）

只要你想用微控制器去观测、控制、改变真实的物理量（电压、电流、光子、声音），你就必须把物理世界的传递函数（比如电感电容的充放电特性）离散化。而离散化之后的数学表达，不是 FIR 就是 IIR。**它们是数字世界干涉物理世界的“唯一接口”**

### 两个截然不同的平行宇宙

作为一名嵌入式控制工程师，你每天其实是在两个规则完全不同的宇宙里反复横跳：

**1\. 物理世界（模拟域）** 这是你板子上的真实世界。你的 LCL 拓扑、IGBT 开关管、电感器里奔涌的电流、电容器上堆积的电压。这个世界是**绝对连续**的。你要描述它们，必须请出牛顿和莱布尼茨，用微积分来表达（比如电感电压公式 _V_\=_L**d**t**d**i_）。

**2\. 数字世界（离散域）** 这是你手里的那颗 DSP 芯片。老实说，它是个地地道道的“纯粹数字机器”。**它根本不懂什么是“连续”，什么是“积分 (∫)”，什么是“求导 (\*d\*/\*d\*\*t\*)”。** 它的世界观极其狭隘：它只能看到 ADC 隔一段时间抓进来的一组组离散数字（数组）；它的技能树极其贫乏：只会做加法、减法、乘法，以及把数据存进寄存器里睡大觉（延迟）。

**那么，灵魂拷问来了：一个只会做加减乘除的数字芯片，怎么去控制一个遵循微积分规律的真实物理电路？**

### 唯一的桥梁：离散化与差分方程

为了让“数字脑”能指挥“物理躯体”，我们必须做一件事：把物理世界的微积分方程，“翻译”成数字世界能听懂的加减乘除算式。这个翻译过程，在数学上叫**离散化**（比如你常听说的前向差分、后向差分、双线性/Tustin变换）。

奇妙的事情就在这里发生了：**任何线性的物理微积分方程，经过离散化“翻译”后，最终在 C 代码里呈现出来的数学形态，有且只有一种——那就是“差分方程”。**

什么是差分方程？说白了，就是用“现在的输入”、“过去的输入”以及“过去的输出”，去算出“当前的控制量”。

根据你算账时用不用“过去的输出”，控制学界把它死死地分成了两大门派。这也就是搞通信的人常说的——**滤波器**。

#### 第一派：只看输入的 FIR（有限脉冲响应）

如果你的代码逻辑是这样的：

_y_\[_n_\]=_a_0_x_\[_n_\]+_a_1_x_\[_n_−1\]+_a_2_x_\[_n_−2\]

_（当前输出 = 现在的输入 + 上次输入 + 上上次输入...）_

因为你算结果时，完全没有用到历史输出数据，这就意味着没有“闭环反馈”。这在信号处理的黑话里，就被定义为 **FIR 滤波器**。它就像个只按当前和刚发生的指令干活的工人，干完就忘，绝不回头看自己做出来的成品。

#### 第二派：带反馈记忆的 IIR（无限脉冲响应）

如果你的代码逻辑加了一点点料：

_y_\[_n_\]=_b_0_x_\[_n_\]+_b_1_x_\[_n_−1\]−_a_1_y_\[_n_−1\]

_（当前输出 = 输入的组合 + **上次的输出 \*y\*\[\*n\*−1\]**）_

只要你的算式里用到了哪怕一个历史输出（产生了反馈），这就叫 **IIR 滤波器**。它带有了记忆效应，现在的每一次输出，都缠绕着过去无数次输出的影子。

### 见证奇迹的时刻：PI 控制器到底是什么鬼？

好了，理论铺垫结束。我们来看看你最熟悉的、闭着眼睛都会写的 **PI 控制器（比例积分控制）**。

在连续的物理世界里，它的原貌是高大上的微积分方程：

_u_(_t_)=_K**p**e_(_t_)+_K\*\*i_∫_e_(_t_)_d\*\*t_

但 DSP 算不了积分啊！于是我们用“后向差分法”把它暴力拍扁，离散化成 C 代码能跑的增量算式，稍微一推导就会变成这样：

_u_\[_n_\]=_u_\[_n_−1\]+_K\*\*p_(_e_\[_n_\]−_e_\[_n_−1\])+_K**i**e_\[_n_\]

**盯着这行代码仔细看！** 你要算当前的 PWM 占空比 _u_\[_n_\]，等号右边赫然出现了一个 _u_\[_n_−1\]（上一次算出的占空比）。 这完美符合了谁的定义？没错，**它用到了“历史输出”！**

**也就是说，在数学的底层逻辑上，一个高大上的数字 PI 控制器，完完全全、如假包换地就是一个“一阶 IIR 滤波器”！**

顺着这个思路，你再看看你写的其他算法：

-   你为了抑制 80A LCL 拓扑的强烈谐振尖峰，在环路里痛苦调试的**陷波器（Notch Filter）**？——**本质是个二阶 IIR 滤波器（Biquad）。**
    
-   你为了做电网电压前馈、消除高频毛刺写的**低通平滑代码**？——**本质是一阶或多阶 IIR 滤波器。**
    
-   你为了做无功补偿、相角锁定写的**延时或移相代码**？——**本质依然是 FIR 或 IIR 滤波器。**

### 万物皆可“线性组合”

现在我们再回头看这句话：**“它们是数字世界干涉物理世界的唯一接口。”**

在数字微控制器的宇宙里，你写不出微积分。你写出来的任何用来稳压、恒流的线性算法，最终在硅片内部，绝对逃不出“当前输出 = 输入组合 + 历史输出组合”这个差分方程的壳子。

_搞通信的人，叫它滤波器；搞控制的人，叫它补偿器。_ 但如果你站得再高一点，戴上**线性代数**的透视眼镜，你会发现更震撼的真相：

你抓进来的 10 个历史采样点，构成了一个“10 维空间里的向量”。 你设定的 _K\*\*p_、_K\*\*i_ 或者滤波系数，构成了另一个“权重向量”。 **你每天在中断里写的那些枯燥的乘法和加法（MAC 操作），其实全都是在极高维度的数学空间里，拉扯、缩放并叠加这些向量——这叫“线性组合”。**

当你下一次再坐在工位上，看着示波器上完美的 113A 恒流波形时，不妨在脑海里想象一下：在那个看不见的无穷维空间里，你写的代码正在精准地进行着一场几何向量的折叠与投影。

这不是码农的搬砖，这是工程师的魔法。
