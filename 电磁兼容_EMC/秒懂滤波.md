# 前言

> 生活中有各种频率的信号，如果像漏筛一样过滤不必要的，保留需要的，在电子学中称为滤波

  

# 为什么要滤波？

比如如果要录制声音的时候，声音往往是伴随着噪音的，如何能去除噪音呢？

![](https://mmbiz.qpic.cn/mmbiz_jpg/2vmCEf4iaGjgibgS2juPrZWhsflxvl7BeCv9vPzXVicX8DbSsfTz4v3yktCKzthWsd12UNFLlUxLehbyTYnzILeHg/640?wx_fmt=jpeg&wxfrom=5&wx_lazy=1&wx_co=1)

这时候就需要有滤波器来滤除不必要的噪音

  

# 如何滤波？

根据电容有隔直通交的特性，便可搭建一个滤波电路

![](https://mmbiz.qpic.cn/mmbiz_jpg/2vmCEf4iaGjgibgS2juPrZWhsflxvl7BeCM1CxiamtrAuXQOYGPQBC3ylU8aLugtGIeXcEjUkWmybvJVMziaHCDntQ/640?wx_fmt=jpeg&wxfrom=5&wx_lazy=1&wx_co=1)

  

高通滤波器（只有频率高的信号才能通过）

![](https://mmbiz.qpic.cn/mmbiz_jpg/2vmCEf4iaGjgibgS2juPrZWhsflxvl7BeCPcrdOTOcqfFkEnSBeVj0Ets7DHakmicNs41RP70243nHFPFBwWefP3A/640?wx_fmt=jpeg&wxfrom=5&wx_lazy=1&wx_co=1)

  

这里提到了增益（输出和输入之比）

  

假如增益为70%，输入为 10V的交流电，输出就是 7V的交流电

![](https://mmbiz.qpic.cn/mmbiz_jpg/2vmCEf4iaGjgibgS2juPrZWhsflxvl7BeCbbicNVpwdI9leNdJ4pAicOaFZOJh5z977H4x7HXE4VDBsyWibh0mQbICw/640?wx_fmt=jpeg&wxfrom=5&wx_lazy=1&wx_co=1)

  

如图所示，为增益的幅频特性

![](https://mmbiz.qpic.cn/mmbiz_jpg/2vmCEf4iaGjgibgS2juPrZWhsflxvl7BeC2x8APviau0ZVN6fA0x4Y6ahzHNVFhb3aUjzkudKkyD2zqx7cuHeBODA/640?wx_fmt=jpeg&wxfrom=5&wx_lazy=1&wx_co=1)

  

可以看出，频率越低，增益就越小，反之亦然

  

当增益为1时，输入等于输出

![](https://mmbiz.qpic.cn/mmbiz_jpg/2vmCEf4iaGjgibgS2juPrZWhsflxvl7BeCwM4Ppcs4GSIG6JZtWcibHCx3JkQtmxoKJqMepXu7WQHwjrfYibK3V88w/640?wx_fmt=jpeg&wxfrom=5&wx_lazy=1&wx_co=1)

  

容抗的计算公式如下

![](https://mmbiz.qpic.cn/mmbiz_jpg/2vmCEf4iaGjgibgS2juPrZWhsflxvl7BeCKqCiaM24ews9v9HZhM2iburJPZavQtJjX0To7qhwJEocfVTr1s3PtibXw/640?wx_fmt=jpeg&wxfrom=5&wx_lazy=1&wx_co=1)

  

显然当频率为0时，容抗无穷大，反之亦然

  

只要频率高，容抗就低，容抗低，信号就可以通过（这就是高通滤波器）

![](https://mmbiz.qpic.cn/mmbiz_jpg/2vmCEf4iaGjgibgS2juPrZWhsflxvl7BeCmIvE5oqlLDZ1TMAy8lHBbM4nticfrEMb8tXnPJnNRzjNeF3dpam2JHw/640?wx_fmt=jpeg&wxfrom=5&wx_lazy=1&wx_co=1)
