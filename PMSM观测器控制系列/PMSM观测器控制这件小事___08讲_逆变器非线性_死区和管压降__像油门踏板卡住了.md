你接过来，上电，空转。一千转以下，确实响。不是轴承的机械噪声，是电磁噪声——那种有规律的、和转速挂钩的吱吱声。

你打开示波器，夹上电流探头，先看 A 相。正弦波的过零点附近，每隔 180° 电角度有一道极细的凹槽。换到 B 相、C 相，也一样。三相电流轮流过零，一个电周期内总共有六次过零——平均下来每 60° 电角度就有一相在"被死区啃一口"。凹槽的深度不大，但位置极其规律。

你第一反应是观测器增益没调好。调了一下午，凹槽还在。然后怀疑是 PWM 分辨率不够，换了更高的开关频率——这可能改变电流纹波的观感，但固定死区时间下，死区占空比误差并不会因此减小，凹槽也不会消失。

直到你翻开 IGBT 的 datasheet，看到一页叫"Switching Characteristics"的参数表——、、、——才突然意识到：**大概率不是观测器的问题，而是逆变器在偷偷改你的电压指令。**

## 油门踏板的盲区

各位同仁，咱们先来想一个开车的场景。

你踩下油门踏板，车加速。松开，车减速。这个因果关系在你脑海里根深蒂固。

但如果油门踏板有个盲区呢？你踩下去的前两毫米，引擎完全不响应。你得踩过这个盲区，动力才来。松油门的时候也一样，你松了两毫米，引擎还在喷油。

**逆变器的死区时间，就是这个"盲区"。**

三相逆变器有六个开关管——上桥臂三个，下桥臂三个。同一相的上下桥臂绝对不能同时导通，否则直流母线直接短路，炸管。

所以控制器在切换上下桥臂的时候，必须先关断一个，等一小段时间，再打开另一个。这一小段"等待时间"，就是**死区时间（Dead Time）**。

死区时间里，两个管子都不导通。那电流从哪走？主要靠体二极管或反并联二极管续流（死区结束后才可能转入同步整流通道，具体路径随器件类型和驱动策略而异）。电流方向为正时，下桥臂二极管续流；电流方向为负时，上桥臂二极管续流。

问题是——续流二极管导通时的压降和 MOSFET/IGBT 本身的导通压降（MOSFET 按  估算，IGBT 的饱和压降  通常在 1~3V 量级），会让实际输出到电机的电压，和控制器"以为"输出的电压，之间产生一个偏差。具体数值随器件型号、温度和电流大小变化，需查 datasheet。

**这个偏差，就是逆变器非线性。**

说白了，控制器以为单个桥臂相对直流负母线的平均极点电压是 。但实际上，因为死区和管压降，真实电压和指令之间存在偏差 。这个  不是常数，它和电流方向、电流大小、温度、器件老化都有关系。

观测器用什么来算角度？电压和电流。电压不准了，观测器算出来的角度自然也不准。

**逆变器在偷偷改你的电压指令，而观测器毫不知情。**

## 在死区的时间里到底发生了些什么？

咱们把死区的物理过程拆开看看。

假设 A 相上桥臂正在导通，电流从母线正极流入电机 A 相。现在要换到下桥臂导通。

**第一步**：控制器发出关断指令，上桥臂开始关断。但器件不是瞬间关断的——载流子需要时间扫出。

**第二步**：上桥臂完全关断后，控制器不能立刻打开下桥臂。必须再等待一段**死区时间**，确保上桥臂彻底关断。

**第三步**：死区结束后，下桥臂导通。

在这整个过程中，A 相的输出端电压不是由控制器决定的，而是由电流方向和续流二极管决定的。电流为正时，输出端被钳位在母线负极电位（约 0V，忽略二极管压降）；电流为负时，被钳位在母线正极电位（约 ）。

**关键点**：在死区时间里，输出电压不是 ，而是被电流方向"绑架"了。控制器想要的电压和实际电压之间的差，就是死区引入的误差。

这个误差的极性取决于电流方向。电流为正时，实际电压比指令低；电流为负时，实际电压比指令高。

## 60°凹槽从哪来？

三相逆变器有三相电流：、、。每一相电流每经过一个周期（360°电角度），会过零两次（正→负一次，负→正一次）。三相加起来，一周期内总共有 **6 次过零**。

每次过零，该相死区误差的极性翻转一次。三相轮流过零，一周期内总共有 6 次极性翻转——平均下来每 60° 电角度就有一相在"被死区啃一口"。因此观测量中常见 **6 次脉动**，相电流中常见 **5 次、7 次** 等  次谐波。

**如果你看到电流 FFT 里 5 次和 7 次谐波显著增大，同时三相中任意一相的电流波形在过零点附近有 180° 间隔的规律凹槽——三相轮流过零，系统层面每 60° 就有一相受影响——这是一个强线索，大概率与死区有关。** 但 5/7 次谐波也可能来自过调制、母线纹波、电流采样偏置、磁饱和等其他因素，需要结合补偿开关对比一起判断。

死区效应在位置估计中引入 6 倍频波动。现有文献中，中等转速（240 r/min）、中等负载、较大死区时间（3 μs）的工况下，不做补偿的位置误差约 12.5°；做了补偿后降到约 8.9°。到了低速（120 r/min），同样的负载下无补偿位置误差可达 42°，补偿后仍有 22° 左右。\[S-011\]

反电动势幅值低时，同样的电压误差在总电压中占比更大。低速区的位置误差明显比中高速区严重。

## 代码不会撒谎：VESC 怎么补

聊了这么多理论，看看工程上怎么补。

VESC 的做法简单粗暴但有效：**根据电流方向，在观测器/电压估算用的调制信号上叠加一个补偿量。** 注意——这不是直接修改真实 PWM 输出指令，而是修正观测器侧"看到"的电压，让观测器模型更接近真实电机状态。实际 PWM 仍使用未经补偿的原始调制信号。

`// 来源: bldc/motor/mcpwm_foc.c:5081-5100   // 节选自 VESC 死区补偿核心逻辑（观测器/电压估算侧）   // bldc@c5944554      // 步骤1：从滤波后的 id/iq 推测三相电流方向   const float i_alpha_filter = c * state_m->id_filter - s * state_m->iq_filter;   const float i_beta_filter  = c * state_m->iq_filter + s * state_m->id_filter;   const float ia_filter = i_alpha_filter;   const float ib_filter = -0.5 * i_alpha_filter + SQRT3_BY_2 * i_beta_filter;   const float ic_filter = -0.5 * i_alpha_filter - SQRT3_BY_2 * i_beta_filter;      // 步骤2：计算三相电流的符号   const float mod_alpha_filter_sgn = (1.0/3.0) * (2.0*SIGN(ia_filter) - SIGN(ib_filter) - SIGN(ic_filter));   const float mod_beta_filter_sgn = ONE_BY_SQRT3 * (SIGN(ib_filter) - SIGN(ic_filter));      // 步骤3：补偿量 = 符号 × 死区补偿时间参数占 PWM 周期的比例   const float mod_comp_fact = conf_now->foc_dt_us * 1e-6 * conf_now->foc_f_zv;   const float mod_alpha_comp = mod_alpha_filter_sgn * mod_comp_fact;   const float mod_beta_comp = mod_beta_filter_sgn * mod_comp_fact;      // 步骤4：修正观测器/电压估算用的调制信号   mod_alpha -= mod_alpha_comp;   mod_beta -= mod_beta_comp;`

四步，完事。

**第一步**，用滤波后的 \- 轴电流推测三相电流方向。这是为了知道每相电流是正还是负。

**第二步**，用 `SIGN()` 函数判断每相电流的符号。然后把三相电流的符号按 Clarke 变换的组合方式，得到  坐标系下的符号向量。这得到的就是  坐标系下电压误差的方向。

**第三步**，计算补偿因子：`死区补偿时间参数 × 开关频率`。这个值本质上是**死区补偿时间占 PWM 周期的比例**。VESC 里 `foc_dt_us` 是观测器/电压估算侧使用的死区补偿时间参数（单位 µs），`foc_f_zv` 是实际的 PWM 开关频率。它可以参考硬件死区时间来估算，但**不等于**硬件实际插入的死区时间——后者由 `HW_DEAD_TIME_NSEC` 决定，写入定时器的死区寄存器。

**第四步**，修正观测器/电压估算用的调制信号。源码执行的是 `mod_alpha -= mod_alpha_comp`，补偿量的符号由  符号向量决定，方向与估算的电压误差相反。

这个方法的优点是什么？**不需要精确建模死区过程。** 它把死区效应等效成一个和电流方向相关的电压偏移，用一个标量因子 `foc_dt_us × foc_f_zv` 来近似。但它**没有显式建模 MOSFET/IGBT 的管压降或二极管压降**——如果调参得当，补偿因子可能吸收一部分未建模的非线性，但不能认为代码已经完整补偿了管压降。

缺点也很明显：**电流过零点附近不准。**

电流从正变负的那一瞬间，`SIGN()` 函数跳变，补偿量的极性也跳变。但真实的死区效应在过零点附近最复杂——电流方向模糊，二极管和 MOSFET 之间切换，电压波形畸变最严重。VESC 的补偿在这个区域是盲区。

更精细的做法是在线估计死区等效电压，不依赖 `SIGN()` 的硬切换，而是通过最小化  轴反电动势中的谐波分量来反推补偿量。精度更高，但计算量也更大。\[S-011\]

## 两个坑，坑坑都要避开

**坑 1：换了更好的 MOSFET，结果低速抖得更厉害了**

> **症状**：把 IGBT 换成 SiC MOSFET（开关速度更快、 更低），以为非线性会改善，结果低速抖动反而加重。
> 
> **根因**：SiC MOSFET 的体二极管压降通常高于硅基续流二极管，续流时的电压钳位效应更强。死区时间虽然可以缩短，但管压降的相对影响可能增大。而且换了器件后，原来的补偿参数可能不再适用。
> 
> **解法**：换器件后必须重新标定死区补偿参数。不要假设"新器件更好就不需要补偿"。

**坑 2：补偿量调大了，电流波形反而更畸变**

> **症状**：VESC 里把 `foc_dt_us` 调大想多补一点，结果相电流波形从"有凹槽"变成"有尖刺"。
> 
> **根因**：过补偿。死区补偿的本质是抵消一个电压偏移，补偿量应该等于真实的电压误差。如果补偿量超过真实误差，就会引入反方向的误差。
> 
> **解法**：用示波器看相电流波形，从小到大调整补偿参数，直到凹槽最小。不要一次到位。

## 示波器看哪里

死区效应在示波器上有非常明确的"指纹"。

**症状 1：相电流波形上的规律凹槽**

-   • **看哪里**：相电流波形
    
-   • **正常**：光滑正弦波
    
-   • **异常**：三相中任意一相，过零点附近每隔 180° 出现一次畸变；三相轮流过零，系统层面每 60° 就有一相受影响
    
-   • **根因**：电流每次过零点，死区误差极性翻转，导致电流斜率突变
    

**症状 2：电流谐波以 5 次、7 次为主**

-   • **看哪里**：电流 FFT 分析
    
-   • **正常**：基波为主，5/7 次谐波很小
    
-   • **异常**：5 次、7 次谐波显著增大
    
-   • **根因**：逆变器非线性会导致相电流中出现  次谐波，典型就是 5/7 次；在  电流、位置误差、速度误差里常表现为  次脉动
    

## 🔧 调试 Checklist

\[ \] 观察相电流波形：单相过零点附近是否有 180° 间隔的规律凹槽？三相轮流过零，每 60° 就有一相受影响，这是死区效应的强线索  
\[ \] 确认死区补偿参数 `foc_dt_us`（这是观测器/电压估算侧使用的补偿时间参数，不是硬件实际插入的死区时间 `HW_DEAD_TIME_NSEC`）：先结合相电流波形、FFT 和补偿前后对比来调节，可以参考硬件死区时间作为起点；硬件死区时间则要按器件关断延迟、驱动传播延迟和温度 worst case 独立设置，写入定时器死区寄存器  
\[ \] 低速（<10% 额定转速）测试：死区效应在低速最显著，是最佳调试工况  
\[ \] 评估补偿效果：用 FFT 看 5 次、7 次谐波含量，补偿前后对比  
\[ \] 温度循环测试：MOSFET/IGBT 的导通压降随温度变化，高温下补偿参数可能失效  
\[ \] 区分死区误差和参数误差：死区误差是 6 倍频周期性抖动，参数误差（如  不准）是直流偏移或低频漂移
