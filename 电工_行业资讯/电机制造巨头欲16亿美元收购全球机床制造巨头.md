# 电机制造巨头欲16亿美元收购全球机床制造巨头

原创 电机新视界 2025-01-03 12:00 上海

> 原文地址: [https://mp.weixin.qq.com/s/cjHXWhTt4vBDwWUhl9bfug](https://mp.weixin.qq.com/s/cjHXWhTt4vBDwWUhl9bfug)

来源：铜价行情

  

**日本制造业巨头尼得科株式会社 (Nidec Corp.)12月27日表示，计划以2570亿日元（16亿美元）的价格收购牧野铣床株式会社 (Makino Milling Machine Co.)。**在日本这个以协议交易著称的国家，这是一次出人意料的主动要约收购（TOB）。

  

由于买盘过多，牧野工具机周五上午没有股票交易，而日本电产在东京股市则上涨了2%。此次收购是日本企业罕见的主动收购案例，尤其是在日本，这类敌意收购通常都是事先达成协议的。

  

![](D:\电脑文件\公众号知识库\电工_行业资讯\电机制造巨头欲16亿美元收购全球机床制造巨头_images\img_001_3b01a6a7d060.png)

**牧野工具机**是一家专注于工业齿轮和机床制造的公司，其产品广泛应用于汽车、航空航天、电子等多个领域。牧野工具机为包括大福（Daifuku）和发那科（Fanuc）在内的工业机器人制造商供货，拥有强大的技术和客户基础。通过此次收购，日本电产将能够进入利润更高的增长领域，特别是在工业自动化和精密制造方面。

  

值得注意的是，这并非日本电产首次尝试潜在的敌意收购。去年，日本电产曾主动出价收购泷泽（Takisawa Machine Tool），最终成功完成了这笔交易。此次对牧野工具机的收购，进一步展示了日本电产在并购方面的决心和执行力。

  

**日本电产**是全球最大的微型电机制造商，但近年来，公司面临着多重市场挑战。首先，硬盘市场需求疲软，导致相关业务收入下降。其次，中国电动汽车市场的激烈竞争也给公司带来了压力。为了应对这些挑战，日本电产在新领导层的带领下，寻求进入利润更高的增长领域，特别是工业自动化、能源和大型电机领域。

  

根据伦敦证券交易所集团（LSEG）的数据，**如果收购牧野成功，这将成为尼得科迄今为止金额最大的一笔收购，**超过其2016年以12亿美元收购法国电机制造商Leroy-Somer。

  

总部位于京都、由创始人永守重信（Shigenobu Nagamori）领导的尼得科遵循日本政府的指导方针，以促进更多的并购，并消除长期以来对主动出价的偏见。东京交易所推动的改革也引发了一系列股票回购、交叉持股解禁和管理层收购活动。

  

永守重信在本月告诉《日经新闻》，**尼得科正在寻找高达1万亿日元的收购目标，并在欧洲和美国盯上了三个潜在目标。**
