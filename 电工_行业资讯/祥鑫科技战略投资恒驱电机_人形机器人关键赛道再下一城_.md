# 祥鑫科技战略投资恒驱电机，人形机器人关键赛道再下一城！

祥鑫科技股份有限公司通过旗下参与的广州远见创新科技创业投资基金，近日完成了对国家级专精特新“小巨人”企业深圳恒驱电机有限公司的战略投资。此次投资标志着祥鑫科技在人形机器人核心零部件领域的布局再落关键一子，进一步完善了人形机器人的全链条技术版图。

  

恒驱电机深耕无刷电机领域十余年，拥有36个系列标准型号及500余种定制化驱动方案，尤其在超静音、高扭矩伺服控制技术上处于行业领先地位。其创新的无框力矩电机设计，为人形机器人的灵巧手和关节模组提供了核心驱动力。

  

随着人形机器人产业化进程加速，祥鑫科技正通过内生研发与外延投资双轮驱动，打造人形机器人的完整解决方案。

  

战略卡位，无刷电机铸就核心动力基石

  

在技术层面，无刷电机作为机器人的核心动力源，其性能直接决定了机器人的运动精度、响应速度、工作效率和使用寿命等关键指标。恒驱电机凭借其在新型传动方案、超低电压应用、高精定位控制以及工业互联网/物联网融合控制等领域的独特技术优势，构建了显著的竞争优势。这些技术壁垒，叠加其基于强大产品力与品牌力建立的全球销售网络，共同构筑了恒驱电机在直流无刷电机领域的深厚护城河。

  

祥鑫科技此次战略投资恒驱电机，意义重大。它不仅使公司得以深度介入无刷电机技术研发前沿，确保第一时间掌握最新技术动态、获取先进资源；更为祥鑫科技的机器人动力系统研发提供了坚实的技术支撑。这将助力公司开发出更高效、更智能、更可靠的机器人动力解决方案，从而在激烈的市场竞争中抢占至关重要的技术制高点。

垂直整合，构建人形机器人全栈能力

  

从产业链整合角度而言，这一投资进一步完善了祥鑫科技在机器人产业链上的布局。公司在机器人结构件、模具制造等领域已具备深厚的技术积累和丰富的生产经验，与众多机器人企业建立了紧密的合作关系。如今通过投资恒驱电机，成功将业务触角延伸至机器人关键零部件的动力系统环节，实现了从机器人结构件到动力系统的产业链纵向拓展，有助于公司打造更为完整、协同性更强的机器人产业链生态，增强公司在产业链中的话语权和影响力，提升公司的综合竞争力。

  

这一系列战略动作并非孤立：

  

2025年1月，祥鑫科技与广东省科学院智能制造研究所联合共建“祥鑫科技股份有限公司-广东省科学院智能制造研究所人形机器人关键零部件联合技术创新中心”， 打通人形机器人从研发到生产的全链条；

  

2025年1月，祥鑫科技成立全资子公司祥鑫（东莞）智能机器人有限公司，作为集团机器人业务的子公司，全面承载并统筹未来所有机器人相关的技术研发、产品孵化及战略投资主体职能；

  

2025年3月，祥鑫科技与三度（佛山）智能科技有限公司签订战略协议，共同推进“人形机器人关键技术”研发；

  

2025年6月，祥鑫科技拟受让女娲机器人有限公司（NUWA Robotics Corp.）1.25%的股权，实现双方的战略协同，快速切入机器人万亿蓝海；

  

2025年6月，祥鑫科技战略投资苏州天肌科技有限公司（持股12%），布局电缸产品，补强执行机构能力。

  

这些布局共同指向一个清晰的战略路径：祥鑫科技正沿着“结构件 → 系统集成 → 整机集成”的路线稳步推进。对恒驱电机（动力）、天肌科技（执行）等关键零部件企业的投资，是构建完整运动控制技术闭环的核心步骤。

  

未来，祥鑫科技将持续通过战略投资，深化在人形机器人关键零部件领域的布局，目标是打造高度协同、自主可控的人形机器人全栈技术生态，从而显著增强其在产业链中的话语权、影响力与综合竞争力。
