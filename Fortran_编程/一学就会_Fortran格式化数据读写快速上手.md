在科学计算领域，Fortran凭借其高效、直接的数值处理能力，至今仍占据一席之地。其中，格式化读写是Fortran编程中不可或缺的一部分，它允许程序员以精确控制的方式读取和输出数据。本文旨在通过简洁明了的语言和实例，带你掌握Fortran中`READ`与`WRITE`语句的格式化读写技巧。

## 1\. 格式化读写的概念

格式化读写，顾名思义，是指在读取或输出数据时，预先定义数据的显示格式，如字段宽度、小数点位数等。这不仅使输出结果整齐易读，也确保了数据在存储和传输过程中的准确性。

## 2\. 格式说明符简介

在Fortran中，格式化读写的核心在于格式说明符（Format specifier）。这些说明符定义在格式字符串中，通过数字、符号和字母的特定组合来指定数据的输出样式或读取规则。常用格式说明符包括：

-   `Iw`：整型数据输出，`w`表示字段宽度。
    
-   `Fw.d`：实型数据输出，`w`为总宽度，`d`为小数点后的位数。
    
-   `Ew.d`：科学记数法输出实数，`w`、`d`含义同上。
    
-   `Aw`：字符型数据输出，`w`表示字符宽度。
    
-   `X`：表示空格
    
-   `/`：表示新行
    

## 3\. `WRITE`语句的格式化输出

`write`语句用于将数据输出到文件或标准输出设备（通常是屏幕）。其基本语法如下：

`write(unit, format) [list]   `

其中，

-   `unit`可以是文件的逻辑标识符，也可以是预定义的输出设备，如果是`*`，则代表标准输出。
    
-   `format`是一个格式字符串，定义了输出数据的格式，如果是`*`，则代表自动根据变量类型进行输出。
    
-   `list`是一个可选的列表，包含要输出的变量或表达式。
    

让我们从一个简单的例子开始，了解如何使用`WRITE`语句进行格式化输出。

`program FormatDemo     implicit none     integer :: i = 100         real :: pi = 3.141592653589793     real :: e = 2.718281828459045     character(len=20) :: str = "Hello, World!"        write(*, '(I5, X, F8.3, E12.4, /, A)') &                i, pi, e, str   end program FormatDemo   `

这段代码中，`write`语句使用了一个自定义的格式字符串`'(I5, X, F8.3, E12.4, /, A)'`。它指示Fortran按以下方式输出数据：

-   `I5`：输出一个宽度为5的整数，即变量`i`。
    
-   `X`：插入一个空格作为分隔。
    
-   `F8.3`：输出一个总宽度为8，小数点后有3位的实数，对应变量`pi`。
    
-   `E12.4`：用科学记数法输出一个总宽度为12，小数点后有4位的实数，对应变量`e`。
    
-   `/`：表示新行。
    
-   `A`：输出一个字符字符串，宽度由字符串本身决定，这里是`str`。
    

执行上述程序，输出结果将是：

  `100    3.142  0.2718E+01   Hello, World!`

## 4\. `READ`语句的格式化输入

与`WRITE`类似，`READ`语句同样可以利用格式化字符串精确控制数据的读取方式。其基本语法如下：

`read(unit, format) [list]   `

它的参数说明和`write`语句完全相同。例如：

`program ReadDemo     implicit none     integer :: number     real :: decimal        write(*,*) "请输入一个整数、一个小数，用空格分隔："     read(*,*) number, decimal     write(*,*) "你输入的是：", number, decimal          write(*,*) "请重新输入一个整数、一个小数，用空格分隔："       read(*, '(I5, F8.3)') number, decimal     write(*,*) "你输入的是：", number, decimal   end program ReadDemo   `

这里，第一个`read(*,*)`是一个通用的简化形式，它会自动根据变量类型读取输入。

第二个`read(*, '(I5, F8.3)')`，指定了格式字符串，以实现更精细的读取控制。此时，实际输入的数据一定要与提供的格式相匹配，否则会产生不可预料的结果。

为了说明格式匹配的重要性，我们用两次相同的输入，测试一下上面的例子，结果如下：

 `请输入一个整数、一个小数，用空格分隔：   10 15.2    你输入的是：          10   15.1999998    请重新输入一个整数、一个小数，用空格分隔：   10 15.2    你输入的是：        1015  0.200000003`

可以发现，第二次的读取结果是完全错误的。因此，`READ`语句的格式化输入一定要多加小心，它更多的是应用于「数据格式非常规则」的文本文件的读取。

## 5\. 进阶技巧：重复与循环

格式字符串还支持重复计数符，形如`nX`、`(nIw)`等，用来控制元素的重复次数。

`program RepeatDemo     implicit none     integer, dimension(3) :: nums = [1, 2, 3]        write(*, '(3(I4, 1X))') nums   end program RepeatDemo   `

这段代码中，`3(I4, 1X)`意味着重复三次`I4, 1X`模式，输出数组`nums`的每个元素及之间的空格。结果为：

   `1    2    3`

## 6\. 格式标签的使用

格式化输入输出还可以通过`format`语句和标签来指定具体的格式字符串，提高代码的可读性和灵活性。

`program LabelDemo     implicit none     integer :: value     real :: ratio        10 format(I5)     20 format(F8.4)     30 format(A20)        write(*, 30) "请输入一个整数和小数："     read(*, 10) value     read(*, 20) ratio        write(*, 30) "你输入的是："     write(*, 10) value     write(*, 20) ratio   end program LabelDemo   `

通过定义不同标签下的格式字符串，可以在多个地方复用，使得代码更加清晰和模块化。

## 7\. 注意事项

-   格式化读写提供了强大的控制能力，但也增加了程序的复杂性。在实际编程中，应根据需要合理使用。
    
-   格式字符串中的格式说明符必须与`list`中的变量或表达式一一对应。
    
-   在输入时，如果提供的格式与实际输入的数据不匹配，可能会导致程序出错或产生不可预料的结果。
    

## 小结

Fortran的格式化读写功能强大而灵活，是进行精确数据处理的重要工具。通过掌握基本的格式说明符、利用格式字符串控制输出样式、以及应用重复计数符和格式标签等高级技巧，你可以编写出既高效又易于维护的代码。希望本篇指南能帮助你更好地理解和运用Fortran的格式化读写功能，在科学计算的道路上更进一步。
