在科学计算和工程领域，求解大型线性方程组是一个核心问题。当方程组的规模达到数千甚至数万维度时，传统的直接法（如高斯消元、LU分解）因存储和计算复杂度的限制（如  时间复杂度）而难以应对。**共轭梯度法（Conjugate Gradient Method, CG）** 作为迭代法的代表，凭借其高效性、低存储需求和快速收敛的特点，成为求解大规模**对称正定（Symmetric Positive definite, SPD）** 线性方程组的首选方法。本文将从原理、算法流程、编程实现及优缺点等方面，深入解析这一经典算法。

## 核心思想

共轭梯度法的本质是通过**共轭方向**的迭代搜索，快速找到线性方程组的解。其理论基础可追溯到**二次函数的最小化问题**。

以下是共轭梯度法求解  的标准步骤：

### 初始化

-   选择初始解 （通常为零向量）。
    
-   计算初始残差 。
    
-   设置初始搜索方向 。
    

### 迭代步骤

对于第  次迭代，执行以下操作：

1.  计算步长 
    
    该步长确保在方向  上函数值下降最快。
    
2.  更新解向量
    
3.  更新残差
    
4.  计算共轭方向系数 
    
5.  生成新搜索方向

## 关键特性

### 核心优势

-   **存储高效**：仅需存储当前迭代的  及少量标量（如 ），适合处理大规模稀疏矩阵。
    
-   **快速收敛**：理论上  步内收敛（ 为方程组维度），实际中常在  步内达到精度（ 为矩阵条件数）。
    
-   **无需矩阵求逆**：仅需矩阵-向量乘法 ，避免了直接法的高计算开销。

### 适用场景

-   **对称正定线性系统**：如有限元分析、电磁场模拟中的刚度矩阵。
    
-   **二次优化问题**：如机器学习中的线性回归、支持向量机（SVM）训练。
    

### 局限性

-   **依赖矩阵性质**：仅适用于对称正定矩阵，否则可能发散。非对称问题需改用 BiCGSTAB 等变体方法。
    
-   **条件数敏感**：矩阵条件数（最大与最小特征值之比）越大，收敛越慢。可通过**预处理技术**（如Jacobi预处理）改善。

输入文件名为input.txt      ! 读取输入文件中的数据   call read_input_from_file(filename, n, A, b)   allocate(x(n), r(n), p(n), Ap(n))      ! 初始化解向量 x 和其他参数     x = 0.0! 初始猜测解     tol = 1.0e-8! 收敛容差     max_iter = 100! 最大迭代次数      ! 计算初始残差 r = b - A * x      r = b - matvec(A, x, n)   ! 初始搜索方向 p = r     p = r   ! 开始共轭梯度法迭代   do iter = 1, max_iter       ! 计算 A * p       Ap = matvec(A, p, n)       ! 计算步长 alpha       alpha = dot_product(r, r) / dot_product(p, Ap)       ! 更新解向量 x       x = x + alpha * p       ! 更新残差 r       r = r - alpha * Ap       ! 计算新的残差范数       norm_r = sqrt(dot_product(r, r))       ! 检查收敛条件       if (norm_r < tol) then         print *, "Converged after", iter, "iterations."         exit       endif       ! 计算 beta       beta = dot_product(r, r) / dot_product(r + alpha * Ap, r + alpha * Ap)       ! 更新搜索方向 p       p = r + beta * p   enddo   ! 输出结果   write(*,*) "Solution vector x:"   do i = 1, n        write(*,'(f12.6)') x(i)   enddo      contains   ! 矩阵和向量读取子程序   subroutine read_input_from_file(filename, n, A, b)       character(len=*), intent(in) :: filename       integer, intent(out) :: n       real(8), allocatable, intent(out) :: A(:, :), b(:)       integer :: i, j       open(unit=10, file=filename)       read(10, *) n  ! 读取矩阵大小n       allocate(A(n, n), b(n))       do i = 1, n         read(10, *) (A(i, j), j = 1, n)  ! 读取系数矩阵A       enddo       do i = 1, n         read(10, *) b(i)  ! 读取常数向量b       enddo       close(10)   end subroutine read_input_from_file      ! 矩阵向量乘法子程序   function matvec(A, x, n) result(y)       integer, intent(in) :: n       real(8), dimension(n, n), intent(in) :: A       real(8), dimension(n), intent(in) :: x       real(8), dimension(n) :: y       integer :: i       do i = 1, n         y(i) = dot_product(A(i, :), x)       enddo   end function matvec      end program conjugate_gradient   `

## 小结

共轭梯度法凭借其**低存储、快收敛**的特点，在科学计算和工程优化中占据重要地位。它巧妙地利用共轭方向的正交性，将复杂问题转化为高效迭代过程，尤其在处理大规模稀疏系统时展现出无可替代的优势。然而，其对矩阵对称正定性的要求也限制了应用范围，但通过预处理技术或结合其他方法（如非线性共轭梯度法），这一限制可得到部分缓解。对于研究者和工程师而言，理解共轭梯度法的原理与实现，是应对高维优化问题的必备技能。
