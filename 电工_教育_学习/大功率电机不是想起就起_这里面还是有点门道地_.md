# 大功率电机不是想起就起，这里面还是有点门道地！

在低压供配电系统中，变压器是被看做电源的，这在以前说过。

既然是电源，它就为后面的负荷提供电压，假如它是一个稳定电源（每个电源都会有内阻，这是无疑的），若所带负载突变，比如电流突然增大，电源内阻分压就会增大，则电源电压将会出现跌落。

![](https://mmbiz.qpic.cn/mmbiz_jpg/9El5O0bATDoW9ib4zJNROINVWDvqMmDebtegNicAFkRG3VUxk201GtJfZEicNVajqiaBDCQNZMacRDRgGdyWicAuqCw/640?wx_fmt=jpeg&wxfrom=13&tp=wxpic)

若你经常在现场，这种事情并不奇怪，比如一台全压起动的电机，在电机起动过程中，变压器会“嗷嗷的”叫唤，母线电压也会拉低，但整个起动过程并没有影响到其他负荷运行，这说明系统设计的还算合理，变压器容量选择的也足够大。反之，若变压器容量选择比较小，全压起动的电机功率又比较大，这时候再起动电机，或许就没那么幸运了，系统下所运行的其他低压设备，没准就能给拽跳了，若进线开关装了欠压脱扣器，没准进线开关都能动作。

![](https://mmbiz.qpic.cn/mmbiz_jpg/9El5O0bATDoW9ib4zJNROINVWDvqMmDebFpvtJzb2CJsVLXwX3JGiaD4wZNXmHuD0HuID6afg28tgr32p6PbnmDw/640?wx_fmt=jpeg&wxfrom=13&tp=wxpic)

所以，变压器容量选择与电机的起动方式是相关的。在系统下，要满足单台最大功率的电机起动不会对系统电压造成影响。当电机起来以后，就不需要考虑了，也就是说，在起动最大功率电机时，可不考虑已经运行的设备，只是对电压降而言，但并不代表系统稳态下的负荷计算。

那么，如何来确定变压器容量与电机功率之间的关系哪？比如说，有一台低压电机要起动，要选择多大容量的变压器才能不至于导致电压拉低哪？或者说，这台电机起动要不要选择降压起动的方式哪？

参照公式加以判断，既简单，又方便，还好使。

公式是这么说的，K=0.75+0.25S/P。简单解读一下，K为比较系数，S为变压器额定容量，P为系统中最大电机功率。如此，就把变压器容量与电机功率通过一个公式的形式给展现出来了。

当K＞6时，电机可选择全压起动，当4＜K＜6时，可选择星三角降压起动，若K＜4时，可选择软起，或是变频起动。若有人说恰好等于哪？都干那么多年了，看着来吧！

![](https://mmbiz.qpic.cn/mmbiz_jpg/9El5O0bATDoW9ib4zJNROINVWDvqMmDebtsv9ibx6MC6nOl56L95iaKe76792rpVkyLf9D4AsdMcKmkGq6Ay1DiaUA/640?wx_fmt=jpeg&tp=wxpic&wxfrom=5&wx_lazy=1&wx_co=1)

举个例子吧！假如有一台75KW的搅拌电机，变压器容量为1600KVA，将两数带入上式，可得K=6.083，明显是大于6，全压起动是没得问题的。若换成110KW哪？得到的K值为4.386，推荐采用降压起动的方式。若再极端一点，电机功率还是110KW，变压器容量换成630KVA了，此时哪？可算得K=2.181，这时再选择全压起动的话，估摸着就得出问题了！

那是为啥哪？因为照此核算，系统电压要下降11.5%，如此，就会对其他负荷造成影响。就是设备不跳，照明设备总得闪那么一下子吧！不能一起设备，照明就得闪一下，那不成了“闪光灯”了，没有这么干的！
