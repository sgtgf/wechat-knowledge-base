我讲到那里的时候，心里其实有个声音在嘀咕：这么粗暴的动作，凭什么保证手指最后一定能摸到硬币？万一捏过头了怎么办？万一越捏越远怎么办？

这个嘀咕不是抬杠。理想经典 SMO 的代码里，常能看到类似这样的一行：

`float z = K_slide * sign(i_est - i_meas);`

一个粗暴的开关，乘上一个增益，直接灌进电流估计器。没有限幅、没有过渡、没有"我看看误差多大再决定使多大劲"——只有硬邦邦的 `+K` 或 `-K`。

如果你第一次看到这个结构，正常反应应该是：这玩意能稳定？

能。秘密就在于，橡皮泥里有一条**看不见的沟槽**。手指不是乱戳，而是被沟槽约束着，只能沿着沟槽滑向硬币。

这条沟槽，就是今天的主角——**滑模面**（Sliding Surface）。

## 山坡上的人工沟槽

各位同仁如果滑过雪，应该见过那种人工修的半管（halfpipe）。两面是光滑的墙，中间是一条 U 形沟槽。滑雪者从山坡上滑下来，不管初始位置偏左还是偏右，最后都会掉进这条沟槽里。一旦进去，两侧的墙就把他"夹"在中间，只能沿着沟槽的方向往下滑。

滑模面干的就是这件事。

在 SMO 里，α 轴和 β 轴各有一条这样的沟槽。我们把估计电流和实测电流的差值，叫做**状态误差**：

`float s_alpha = i_alpha_est - i_alpha_meas;   // α 轴滑模面   float s_beta  = i_beta_est  - i_beta_meas;    // β 轴滑模面`

这个 `s` 就是滑雪者相对于沟槽的**横向偏移**。

-   • `s > 0`，说明估计电流比实测电流大，滑雪者在沟槽右侧；
    
-   • `s < 0`，说明估计电流比实测电流小，滑雪者在沟槽左侧；
    
-   • `s = 0`，滑雪者正好在沟槽中央——估计电流和实测电流完全重合。
    

注意，这里是**两个**沟槽，不是一条。α 轴的 `s_alpha = 0` 是一条约束，β 轴的 `s_beta = 0` 是另一条约束。系统被同时约束在这两条沟槽的交集上运动。不过在直觉层面，你可以先想象一条，另一条是同样的道理。

sign 函数的作用，就是沟槽两侧的那两堵墙：

-   • 当 `s > 0`，`sign(s) = +1`，控制往左推；
    
-   • 当 `s < 0`，`sign(s) = -1`，控制往右推。
    

说白了，不管你在哪边，sign 总是把你往 `s = 0` 推。

这个"推"的动作发生在**观测器内部**，修正的是虚拟的估计电流，不是直接写进 PWM 去驱动真实电机。真实电机的电流变化受电气时间常数限制，根本跟不上 sign 的切换速度。观测器里的"推"只是在数学模型里调整估计值，让它尽快和实测值对齐。

到这里，咱们建立了几何直觉：滑模面是一条"沟槽"，sign 是沟槽两侧的"墙"，系统状态是被墙往沟里挤的滑雪者。

但还有一个关键问题没回答：

**墙凭什么一定能把你挤进沟槽？** 万一墙太矮、坡度太平，滑雪者直接飞过沟槽怎么办？

这就是滑模控制的第一个核心问题——**到达条件**。

## 三个核心问题：到达、粘住、滑行

滑模控制理论里，有三个环环相扣的问题。搞懂了这三个，你就搞懂了滑模面为什么能工作。

### 问题一：为什么一定能掉进沟槽？

滑雪者从山坡上滑下来，初始位置可能离沟槽很远。如果沟槽两侧的墙太矮，或者山坡太平、速度太慢，滑雪者确实可能永远滑不进去。

所以滑模理论有一个**到达条件**（Reachability Condition）：控制必须够"猛"，沟槽必须够"陡"。

在 SMO 里，这个"猛"字体现在增益 `K_slide` 上。

咱们把观测器的误差方程写出来。这里采用经典 SPMSM / 等效电感模型，暂不展开 IPM 凸极项。在 αβ 静止坐标系下，实测电流的变化规律是：

`di_alpha/dt = (v_alpha - R * i_alpha - e_alpha) / L`

估计电流的变化规律是：

`di_alpha_est/dt = (v_alpha - R * i_alpha_est - K_slide * sign(s_alpha)) / L`

两者相减，得到误差 `s_alpha = i_alpha_est - i_alpha` 的变化率：

`ds_alpha/dt = -(R/L) * s_alpha - (K_slide/L) * sign(s_alpha) + e_alpha / L`

这个式子有三项：

-   • `-(R/L) * s_alpha`：电阻项。误差越大，电阻衰减越快，这一项本身就有把误差拉回零的趋势；
    
-   • `-(K_slide/L) * sign(s_alpha)`：切换项。sign 根据误差的符号决定推的方向，始终指向 `s = 0`；
    
-   • `e_alpha / L`：反电动势项。这是外部"干扰"，电机转起来之后，反电势像一个外力在拉着估计电流往反方向跑。
    

到达条件要求：切换项的"推力"必须压倒反电动势的"拉力"。也就是说，`K_slide` 必须足够大，大到 sign 那一巴掌能把反电势扇回去。

反电动势是到达条件整定时需要压倒的**主要**扰动项。工程上通常以额定转速下的最大反电动势幅值为参考起点，再留一定裕量。裕量留给参数漂移、未建模动态和采样噪声——这些东西在实验室里不起眼，到现场全都会跳出来。

你可以这样理解：`K_slide` 是沟槽墙的硬度。墙够硬，滑雪者撞上去才会乖乖转向；墙太软，滑雪者直接撞穿，永远到不了沟槽中央。

说白了，到达条件就是一句话：**增益不够大，观测器连门都进不了。**

### 问题二：掉进去之后，为什么不会又飞出来？

好，假设滑雪者终于掉进了沟槽。但山坡是斜的，滑雪者有惯性，凭什么他不会在沟槽里左右横跳、最后又从另一侧飞出去？

答案是：沟槽两侧的墙不是摆设。只要你稍微偏一点，墙就立刻把你推回去。

这就是**滑模条件**（Sliding Condition）。

数学上，滑模条件说的是：当系统在滑模面右侧接近时，它的速度必须指向左（朝向滑模面）；当系统在左侧接近时，速度必须指向右。用符号写就是：

`lim(s→0⁺) ds/dt < 0      // 从右侧接近，误差在减小   lim(s→0⁻) ds/dt > 0      // 从左侧接近，误差在减小（负得少了）`

回到咱们刚才的误差方程：

`ds/dt = -(R/L) * s - (K_slide/L) * sign(s) + e / L`

当 `s` 是一个很小的正数（在滑模面右侧），`sign(s) = +1`。如果 `K_slide` 足够大，切换项 `-(K_slide/L)` 会压倒其他项，使得 `ds/dt < 0`。误差在减小，系统被往左推。

当 `s` 是一个很小的负数（在滑模面左侧），`sign(s) = -1`。切换项变成 `+(K_slide/L)`，使得 `ds/dt > 0`。误差在增大（从负往零走），系统被往右推。

两边一夹，系统就被"粘"在滑模面上了。

说白了，滑模条件就是一句话：**只要增益够大，沟槽两侧永远是高压墙，滑雪者想飞也飞不出去。**

如果你习惯用数学语言思考，可以把 `V = ½s²` 理解为"到沟槽的距离平方"。`V` 越大，滑雪者离沟槽越远。滑模条件 `s·ṡ < 0` 意味着这个距离在持续缩短——控制始终把滑雪者往沟里推。当 `V` 降到零，滑雪者就正好落在沟槽中央。

但这里有个副作用。在**理想连续时间模型**里，系统一旦被粘住，sign 会在 `s = 0` 附近无限高频切换——滑雪者在沟槽中央左右来回小幅震荡，永远停不下来。这就是**抖振**（Chattering）。

实际数字实现中，切换频率受控制周期、采样率和边界层影响，不会真正无限高频。但抖振的物理根源就在这里：sign 为了把系统死死压在滑模面上，不得不在零点附近反复 flipping。

抖振不是 bug，是滑模控制的**结构性代价**。你要无限精确的跟踪，就得付出无限高频切换的代价。工程上咱们用各种办法削弱它——边界层、饱和函数、Super-Twisting——但那是后面几篇的话题。这里你只需要记住：抖振是滑模条件的直接产物，是它"粘住"系统的代价。

### 问题三：沿沟槽滑行的时候，是什么让他不左右偏离？

滑雪者掉进沟槽、被两侧墙夹住之后，他并不是静止的。沟槽顺着山坡向下倾斜，滑雪者会继续沿着沟槽方向运动。

决定他会不会左右偏离的，不是两侧墙在推他——墙的推力始终垂直于沟槽方向，只负责把他夹在中间。真正让他不左右偏离的，是墙在快速来回推搡中形成的**净横向补偿**——左右推力并不对称抵消，而是形成一个不为零的平均值；这个平均值刚好抵消了外部扰动，让他保持在沟槽正中央。

在滑模控制里，这个"净横向补偿"就是**等效控制**（Equivalent Control）。

咱们回到误差方程。当系统严格停留在滑模面上（`s = 0`）时，误差不再变化（`ds/dt = 0`）。把 `s = 0` 和 `ds/dt = 0` 代入方程：

`0 = -(R/L) * 0 - (K_slide/L) * sign(s)|_eq + e / L`

解出来：

`K_slide * sign(s)|_eq = e`

`z_eq = K_slide * sign(s)|_eq` 就是等效控制——其中 `sign(s)|_eq` 是 sign 函数在无限高频切换下的**平均符号值**（无量纲），乘以 `K_slide` 之后才得到具有电压量纲的连续补偿量。

换句话说，当系统在滑模面上运动时，sign 的高频切换 averaged out 之后，等效控制 `z_eq` 等效于一个连续信号。这个连续信号的大小和方向，**恰好等于反电动势**——它是两侧墙在平均意义上提供的横向补偿力，刚好抵消了外部扰动，让系统能够维持在滑模面上运动。

这就是 Utkin 的等效控制原理。它告诉我们一个反直觉的事实：

**sign 的粗暴切换不是缺陷，恰恰是它能产生精确连续估计的原因。** 在理想滑模条件下，对有界匹配扰动，只要切换增益足够大，切换项的等效值就可以在平均意义上匹配扰动。

而在实际代码里，咱们没有无限高频。工程上用低通滤波器（LPF）从切换项 `z = K_slide * sign(s)` 中提取这个平均值，作为反电动势的估计。LPF 的截止频率设计，本质上就是在"跟踪精度"和"抖振抑制"之间找平衡——滤得太狠，等效控制的动态跟不上；滤得太轻，高频噪声混进来。

咱们下一篇专门聊等效控制和 LPF 的设计，这里你只需要抓住直觉：

**等效控制 `z_eq = K_slide * sign(s)|_eq` = 两侧墙在平均意义上提供的横向补偿力。** 这束力不让你偏离沟槽中央——在 SMO 里，`z_eq` 的幅值和方向恰好等于反电动势，两者在滑模条件下相互抵消，系统因此维持在滑模面上运动。

## 滑模面不止一条：从直沟槽到弯沟槽

到目前为止，咱们聊的滑模面都是最简单的形式：`s = i_est - i_meas`。这在数学上叫**线性滑模面**——误差本身直接作为滑模面，像一条笔直的沟槽。

但沟槽不一定非得是直的。根据具体需求，工程师们设计了各种形状的滑模面：

**对数滑模面**（Logarithmic SM, S-004）：

设电流误差为 `e`，则滑模面定义为：

`s = k₁ * ln(k₂ * |e| + 1) * sign(e) + de/dt`

对数函数的特性是，远离原点时增长缓慢，接近原点时局部增益很高。翻译成沟槽的语言就是：离沟槽很远的时候，沟槽壁很缓，滑雪者不会猛冲；接近沟槽中央的时候，沟槽壁突然变陡，精细调整。这种面适合低速工况，能减小接近稳态时的抖振。

**终端滑模面**（Terminal SM）：

设电流误差为 `e`，则滑模面定义为：

`s = de/dt + β * |e|^γ * sign(e)    (0 < γ < 1)`

非线性项使得系统在滑模运动阶段具有**有限时间收敛**特性——状态误差及其导数能在规定时间内精确收敛到平衡点，而不是传统线性面常见的渐近收敛（理论上无限接近但永远到不了）。沟槽的形状被设计成"越接近终点越陡"，滑雪者像坐滑梯一样，在规定的时间内精确滑到目标点。

**积分滑模面**：

设电流误差为 `e`，则滑模面定义为：

`s = e + λ * ∫e dt`

在传统误差基础上叠加积分项，消除稳态误差。沟槽被设计成"带记忆的"——如果滑雪者长期在沟槽某一侧偏着，积分项会慢慢把沟槽中央往他那挪，直到他回到正中间。

不过，各位同仁，这些花样翻新的沟槽，在工程上都是锦上添花。对于 PMSM 无感控制里的经典 SMO，多数常见工程实现会优先从线性面 `s = i_est - i_meas` 开始。AN1078 等工业参考实现用的就是最朴素的线性面。

改进滑模面的论文每年发几十篇，但很多工程实现仍优先采用线性面。不是因为工程师保守，而是因为直沟槽的物理意义最清晰、参数最少、调试最直观。当你被客户催着下周交样机的时候，相信你是不会去调对数面的 k₁ 和 k₂ 的。

知道有更花哨的沟槽存在就好，真到用的时候，先试试直的。

## 代码里的滑模面长什么样

说了半天理论，咱们看看工程代码里滑模面是怎么实现的。其实简单得离谱——它就是一行减法。

### AN1078 的滑模电流观测器

Microchip 的 AN1078 是工业界最广为人知的 SMO 参考实现之一。它的滑模面定义藏在电流观测器里：

`// 来源: AN1078, Sensorless FOC of a PMSM   // 离散电流观测器，控制周期 50 µs   // 注意：以下示意保留了 AN1078 的核心逻辑，部分系数经归一化处理      // 1. 模型预测电流   i_est = F * i_est_prev + G * (v_prev - e_prev);      // 2. 计算电流误差——这就是滑模面 s   Error = i_est - i_meas;      // 3. 滑模输出（边界层内线性，外饱和到 ±K_slide）   if (fabs(Error) <= MaxSMCError)       Z = (K_slide / MaxSMCError) * Error;   // 边界层内：线性过渡   else       Z = K_slide * sign(Error);             // 边界层外：饱和输出 ±K_slide      // 4. 用 Z 修正模型：Z 为电压量纲（V），经 G = T_s/L 折算为电流增量后修正   i_est = i_est - G * Z;`

注意这里的 `Error = i_est - i_meas` 就是滑模面 `s`。AN1078 没有直接用 sign 函数，而是用了一个**带边界层的饱和函数**：误差在 `MaxSMCError` 范围内时线性输出，超出时才饱和到 `±K_slide`。这是工程上的标准折中——牺牲一点理论上的严格性，换来大幅降低的抖振。

### 演示用示意代码

咱们把刚才推导的数学模型写成一段演示用示意代码。注意，这不是某个特定开源项目的真实源码，而是把理论公式直接翻译成 C 的结构，方便各位同仁对照理解：

`// 演示用示意：经典 SMO 结构（非特定项目源码）      // 1. 电流误差 = 滑模面   float s_a = i_alpha_est - i_alpha;   float s_b = i_beta_est  - i_beta;      // 2. sign 切换项   float z_a = K_slide * SIGN(s_a);   float z_b = K_slide * SIGN(s_b);      // 3. 观测器内部更新   float di_a = (v_alpha - R * i_alpha_est - z_a) / L;   float di_b = (v_beta  - R * i_beta_est  - z_b) / L;      i_alpha_est += di_a * dt;   i_beta_est  += di_b * dt;      // 4. LPF 提取等效控制（反电动势估计）   // 一阶 Euler 近似：α = wc * dt，wc 为角频率（rad/s），要求 α << 1   LPF(e_alpha_est, z_a, wc * dt);   LPF(e_beta_est,  z_b, wc * dt);`

这段代码和咱们刚才推导的数学模型一一对应：

-   • `s_a`、`s_b` 是滑模面；
    
-   • `z_a`、`z_b` 是 sign 切换项（沟槽两侧的墙）；
    
-   • `di_a`、`di_b` 是观测器内部的电流变化率；
    
-   • LPF 从 `z` 中提取等效控制，对应反电动势。

## 调试技巧与常见坑

### 示波器看哪里

**第一，看滑模面 `s` 的波形。**

`s = i_est - i_meas` 是观测器内部的数字变量，示波器探头不能直接看到。你需要通过 DAC 输出、PWM+RC 滤波输出、调试上位机、实时日志或数据记录器把它导出来。

正常状态下，`s` 应该在零附近做高频小幅震荡。如果你看到 `s` 长期偏离零（比如一直为正或一直为负），说明 K\_slide 不够大，系统满足不了到达条件——滑雪者连沟槽都没掉进去。

**第二，看 `s` 的符号切换频率。**

在理想模型里，sign 会无限高频切换。实际中，如果你通过数据记录观察到几乎每个控制周期都发生翻转，说明翻转事件率已接近控制更新率，抖振非常严重，可能需要加大边界层厚度或降低 K\_slide。

**第三，通过实时日志或调试上位机检查 `z` 的幅值和量纲。**

本文示意代码中 Z 按电压量纲（V）理解；实际 AN1078/dsPIC 代码多为 Q15 或归一化变量，不能直接按 V 或 A 读数，必须先查缩放关系。如果你看到的数值在几百到几千，先确认是不是定点 Q 格式或归一化标幺值——AN1078 这类 dsPIC 实现就用了 Q15 定点，数值看起来很大，换算回物理单位后则是正常的。

### 常见坑

**坑一：把滑模面当成"目标值"**

有些同仁第一次看 SMO 代码，会以为 `s = 0` 是"电流应该为零"。不是这样的。`s = i_est - i_meas = 0` 是"估计电流应该等于实测电流"，跟电流本身多大没关系。电机满载时电流 10A，`s` 仍然应该在零附近。

**坑二：以为滑模面越复杂越好**

读了几篇改进 SMO 的论文，就想着在代码里实现终端滑模面或非奇异滑模面。先别急。多数常见工程实现会优先从线性面开始，因为它的物理意义最清晰、参数最少、调试最直观。先把 `K_slide` 和 LPF 截止频率调明白，再考虑换沟槽形状。

**坑三：忽略到达条件，只调 LPF**

有些同仁看到反电动势估计有噪声，第一反应是"LPF 截止频率再调低一点"。但如果根本问题是 K\_slide 太小、系统都没进滑模面，你再怎么滤也是白搭。先确认 `s` 在零附近震荡，再优化滤波参数。

* * *

滑模面是 SMO 的骨骼。

sign 函数是肌肉，负责用力；滑模面是骨架，负责约束用力的方向。没有滑模面，sign 就是无头苍蝇，在电流误差空间里乱撞。有了滑模面，sign 的每一次切换都有了明确的目的——把估计电流往实测电流推。

到达条件保证你一定能进沟槽，滑模条件保证你掉进去就出不来，等效控制告诉你沿沟槽滑行的规律。三个条件环环相扣，构成了滑模观测器收敛的全部理论保证。

而咱们在工程代码里看到的，不过是 `float s = i_est - i_meas` 这一行减法。理论的厚度，藏在最简单的表达式背后。

## 🔧 调试 Checklist

\[ \] 电流误差 `s` 是否在零附近高频震荡？如果长期偏离零，检查 K\_slide 是否够大  
\[ \] K\_slide 是否大于额定转速下的最大反电动势幅值？留出 50%~100% 裕量（经验起点，需实机验证）  
\[ \] LPF 截止频率是否高于目标最高电角频率？低于该频率会导致反电势相位滞后  
\[ \] 如果用了边界层（如 AN1078 的 MaxSMCError），边界层厚度是否在合理范围？太厚会降低跟踪精度  
\[ \] 通过 DAC、上位机或数据记录观察 `s` 的符号切换频率；如果几乎每个控制周期都发生翻转，说明翻转事件率已接近控制更新率，抖振严重，考虑增大边界层或调整增益
