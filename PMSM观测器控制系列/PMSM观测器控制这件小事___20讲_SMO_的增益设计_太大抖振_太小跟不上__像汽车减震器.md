凌晨一点半，实验室只剩你一个人。

电机在台架上空转，示波器里电流波形还算干净。你把 K 从 800 提到 1200，想改善一下动态响应。编译、下载、启动——电机突然发出尖锐的啸叫，电流环开始抖动，（通过 DAC 输出到示波器上的）角度估计在屏幕上疯狂跳变。

你赶紧改回 800。啸叫停了，但加载测试时，负载突变瞬间角度估计滞后了将近 10°，电流环花了三个控制周期才稳住。

> 注意：第19讲 里的 K=800 是归一化标幺值，无量纲；本篇为了讲清物理直觉，把 K 还原成真实电压单位 V。两种编码方式在工程里都常见，但一个项目里只能选一种，不要混用。

你试 1000。抖振比 1200 小，但稳态电流波形上仍能看到细密的高频毛刺。加载时滞后 5°，勉强能用，但不漂亮。

这个 K，到底该写多少？

这不是你一个人的问题。每一个调过 SMO 的工程师，都在深夜盯过这个参数。

## 减震器太硬，石子都能颠进车厢

各位同仁开车过减速带的时候，有没有注意过不同车的感受？

跑车减震器调得硬邦邦。过弯时车身几乎没有侧倾，方向盘指哪打哪。但过减速带就惨了——路面每颗小石子都直接传进你的脊椎，咖啡洒一手。

老派美式大船的减震器软得像海绵。过减速带如履平地，车里的人几乎无感。但高速变道时车身晃三晃，你心里没底。

**SMO 的增益 K，就是这个减震器。**

K 太大，等于减震器太硬。电流误差一有风吹草动，观测器就全力反击，模型内部产生巨大的等效开关校正项。收敛快是快，但高频切换带来的抖振像石子一样直接砸进电流环，电机啸叫、发热、转矩脉动。

K 太小，等于减震器太软。负载突变时，观测器"懒得动"，估计电流懒洋洋地跟在真实值后面。反电势估计滞后，角度估计跟着滞后，电流环稳不住。

说白了，调 K 就是在"响应速度"和"安静程度"之间找平衡。没有完美解，只有适合你的工况的妥协点。

当然，减震器是连续阻尼，而 SMO 是数字开关——这个区别在 [第16讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486604&idx=1&sn=f221f7e9a9ba7e4a05ca6e2daf3f474c&scene=21#wechat_redirect) 的边界层和离散化里专门讲过。这里借用的是直觉，不是一一对应。

说白了，带宽法在 SMO 里更像一个"验证工具"：K 定下来之后，反算一下等效带宽，确认它比 LPF 截止频率高 3~5 倍。如果不够高，说明 LPF 切得太陡，或者 K 偏小。

## 扫参实验：一步一步找到甜点

理论给你画了条起跑线，终点在哪里，只有实验知道。

以下是一套我常用的扫参流程。不需要仿真，示波器 + 编码器基准（或其他高可信位置基准）+ 可控负载装置就够了。

> 事先声明：下面提到的角度误差、恢复时间等数值，是我在 1~3 kW 量级 PMSM 上的经验范围，用于帮你理解趋势，不是跨场景的绝对合格线。你的电机功率、极对数、转速不同，具体数值会差很多，但变化规律是一样的。

### Step 1：算理论下限

先按上面的方法，用电机 datasheet 里的反电势常数和额定转速，算出 。如果没有磁链数据，可以查阅 datasheet 中的线反电势常数 （注意区分峰值/有效值、线电压/相电压口径），通过单位换算和极对数修正得到 。不同厂家给的  口径不同，换算前务必确认是线还是相、峰值还是有效值。

### Step 2：固定其他参数

扫 K 的时候，边界层 Φ 和低通滤波器截止频率  必须固定。否则三个变量同时变，你永远不知道改善或恶化是哪个变量干的。

建议起步组合：

-   • Φ = 0.05 - 0.1（标幺值，或对应实际电流的 5%~10%）
    
-   •  = 2π × 500 rad/s（LPF 截止频率 500 Hz，如果你用经典 SMO+LPF 架构）
    
-   • 如果用 STO 或自适应 SMO，对应参数也先固定
    

### Step 3：从保守值往上扫

K 从 1.2 ×  开始，每次增加 20%~30%。每改一次，观察三个指标：

**指标 A：稳态电流波形**

空转到 50% 额定转速，看相电流的示波器波形。

示波器设置建议：电流探头量程选 2 A/div，时基 2 ms/div，触发模式用正常（Normal）而不是自动（Auto），这样只有真正有信号时才刷新，方便你比较不同 K 值下的波形差异。如果示波器有 FFT 功能，顺便看一下高频分量的频率——如果集中在开关频率附近（比如 10 kHz），那是正常的 PWM 纹波；如果在远低于开关频率、但高于基波频率的频段（如 1~5 kHz，视你的控制周期而定）出现鼓包，可怀疑是 SMO 抖振泄漏。

-   • K 偏小时：波形干净，但偶尔有低频漂移——那是估计滞后造成的电流环补偿。
    
-   • K 偏大时：波形上出现细密的高频毛刺，幅度可能只有几百 mA，但频率很高（接近开关频率或其分频）。
    
-   • K 过大时：毛刺连成一片，电流环开始振荡，电机发出尖锐电磁噪声。
    

**指标 B：角度估计误差**

如果有编码器做基准，直接对比估计角度和编码器角度。计算稳态误差（mean）和抖动（std）。

-   • K 偏小：稳态误差可能只有 1°~2°，但 std 偏大——估计值在目标附近缓慢摆动。
    
-   • K 适中：稳态误差 0.5° 以内，std 最小。
    
-   • K 偏大：稳态误差可能反而增大——抖振通过 LPF 泄漏进反电势估计，角度被噪声污染。
    

**指标 C：负载突变响应**

从空转突然加 50% 负载（磁粉制动器或测功机），看角度误差的最大超调和恢复时间。注意：突然改变速度指令测试的是跟踪能力，不是外部负载扰动，两类测试要分开做。

-   • K 偏小：超调大（可能 8°-15°），恢复慢（>100 ms）。
    
-   • K 适中：超调 3°-5°，恢复时间通常 50-80 ms。
    
-   • K 偏大：超调小，但恢复过程中伴随高频振荡——抖振让电流环"哆嗦"。
    

**三个指标的平衡点通常不重合**。你可能发现 K = 90 V 时电流最干净，K = 100 V 时角度误差最小，K = 110 V 时动态响应最快。这时候没有标准答案——如果客户更在乎安静，选 90 V；如果更在乎动态，选 110 V。这就是工程妥协的艺术。

### Step 5：加载验证

甜点区在空转时找到了，但客户现场不是空转。把负载从 20% 拉到 80%，重复 Step 3 的观察。如果负载大了之后滞后明显增加，说明 K 还是偏小，往高调一档。如果负载下抖振爆炸，往低调一档。

如果你用的是自适应 SMO（见 [第19讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486620&idx=1&sn=996bb4db55b9694d3faa1a6a9a62dabf&scene=21#wechat_redirect)），K₀ 的定法跟这里完全一样——先用固定增益扫出甜点，再把甜点值作为 K₀ 的基准。γ 决定增益自适应的灵敏度，从零开始往上加，直到动态负载时的滞后明显改善，同时稳态抖振仍在可接受范围；λ 取 2~5 s⁻¹，观察增益收敛曲线是否 WIND-UP。没有 K₀ 这个锚点，自适应增益就像没有基准线的浮标，随风乱漂。

## K 和 Φ 不是独立的：先定硬度，再调阻尼

我们在 [第16讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486604&idx=1&sn=f221f7e9a9ba7e4a05ca6e2daf3f474c&scene=21#wechat_redirect) 里共同学习了边界层 Φ。很多同仁容易犯一个错：K 和 Φ 同时调。

这两个参数是耦合的。K 大 + Φ 小，等于一个暴脾气的人拿着小刀——边界层内还在猛冲，抖振大。K 小 + Φ 大，等于一个温吞的人拿着大锤——边界层很宽，但推动力不够，跟踪慢。

**调参顺序必须是：先 K，后 Φ。**

第一步，用上面的扫参流程把 K 定下来。定 K 的时候，Φ 可以先用一个保守值（比如 0.1）。目标是让观测器"能到滑模面且基本跟得住"。这时候可能抖振还有点大，没关系。

第二步，K 固定后，再扫 Φ。Φ 从 0.02 开始往大调，观察抖振是否被压制，同时确认动态响应没有明显恶化。

第三步，如果 Φ 调到头了（比如 Φ = 0.2，超过额定电流 20%），抖振还是太大，说明 K 太高了。回退 K，重新来。

这个顺序不能反。先调 Φ 再调 K，你会发现 Φ 调好了，K 一变，一切重来。

## 转速变了，K 还能一成不变吗？

固定 K 的最大问题，是它没有"转速意识"。

高速时反电势大。比如额定转速 3000 rpm 下 |e|\_max = 63 V，你的 K = 100 V 刚好合适。但低速 300 rpm 时，|e| 只有 6.3 V。K = 100 V 对低速来说太大了——误差只有零点几安，观测器模型内部等效校正项高达 100 V，抖振在低速段被放大。

反过来，如果你按低速需求把 K 压到 20 V，高速时反电势 63 V 直接把你推出滑模面，估计值发散。

这就是固定增益的死锁：高速要的 K 和低速要的 K 不在同一个数量级。

**工程上的折中做法是"取高速值，低速忍一忍"。**

因为高速时反电势大，K 小了根本推不动，而且高速段信噪比好，抖振的影响相对可控。低速时反电势小，K = 100 V 对 6.3 V 的反电势来说确实过剩，但低速电流也小，铜耗和转矩脉动未必比高速大。真正的问题是低速时信噪比差——同样的抖振幅值，在 6.3 V 的信号里占的比例远高于在 63 V 的信号里。抖振"相对高度"变大了。

很多系统在低速段（<10% 额定转速）根本不用 SMO，而是切到 HFI（高频注入法）或 I-F 开环启动。观测器在低速段不工作，自然也就不存在"低速 K 太大"的问题。

但如果你的应用要求从 5% 额定转速到 100% 都要靠 SMO，固定 K 肯定不够用。这时候需要考虑增益调度（Gain Scheduling）——不同转速区间用不同的 K，或者用[上一篇](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486620&idx=1&sn=996bb4db55b9694d3faa1a6a9a62dabf&scene=21#wechat_redirect)的自适应 SMO 让 K 随转速自动漂。这个话题我们在后续的文章里专门拆开讲。

不同功率等级的电机，K 的数量级差异很大。小功率无人机电机（几十瓦）反电势常数低，|e|\_max 可能只有 5-10 V，K 也就 10-20 V。大功率伺服电机（几十千瓦）反电势上百伏，K 相应要到 200-500 V。这不是说你把小车电机的 K 直接放大十倍就能给大巴用——电气时间常数 L/R 不同，边界层 Φ 的绝对值也不同，整套参数都得重新扫。

`// 示意用代码：经典 SMO 增益配置   // 非特定开源项目提取   // 电机参数（从 datasheet 读取）   #define MOTOR_POLE_PAIRS        4   #define MOTOR_BEMF_CONST_VPKKRPM  36.3f   // 线反电势峰值，V/krpm（对应 lambda ≈ 0.05 Wb）   #define MOTOR_LAMBDA            0.05f   // 磁链，Wb      // 观测器增益 K [V]，电压注入项   // 计算：K = 1.5 * |e|_max = 1.5 * w_e_max * lambda   // 3000 rpm 机械 = 314.16 rad/s，电角速度 = 314.16 * 4 = 1256.6 rad/s   // |e|_max = 1256.6 * 0.05 = 62.8 V（相峰值）   // K_initial = 1.5 * 62.8 ≈ 94 V   #define SMO_GAIN_K              94.0f   // [V]，根据扫参结果微调      // 边界层厚度 [A]，电流误差进入线性区的阈值   #define SMO_BOUNDARY_PHI        0.08f   // [A]，扫参第二步调整      // 低通滤波器截止频率 [rad/s]，用于提取等效控制 [AN1078]   #define SMO_LPF_OMEGA_C         (2.0f * 3.1415926f * 500.0f)  // 500 Hz      typedef struct {    float i_hat_alpha;   // 估计电流 alpha    float i_hat_beta;    // 估计电流 beta    float e_hat_alpha;   // 估计反电势 alpha（LPF 后）    float e_hat_beta;    // 估计反电势 beta（LPF 后）   } SMO_State_t;      void smo_update(SMO_State_t *smo,                float v_alpha, float v_beta,                float i_alpha, float i_beta,                float Ts)   {    // 电流估计误差    float err_alpha = smo->i_hat_alpha - i_alpha;    float err_beta  = smo->i_hat_beta  - i_beta;    // 饱和函数（边界层法），见第16讲    float sat_alpha = sat(err_alpha, SMO_BOUNDARY_PHI);    float sat_beta  = sat(err_beta,  SMO_BOUNDARY_PHI);    // 开关项 = -K * sat(err)    // K 单位 [V]，sat 输出无量纲（已归一化到 [-1,1]）    float u_alpha = -SMO_GAIN_K * sat_alpha;    float u_beta  = -SMO_GAIN_K * sat_beta;    // 电流估计更新（前向欧拉离散化）    // u_switch = -K·sign(err)，当 err>0 时 u_switch<0    // 观测器方程用 +u_switch/Ls，展开后等效为 -(K/Ls)·sign(err)    float di_hat_alpha = (v_alpha / Ls) - (Rs / Ls) * smo->i_hat_alpha                          + (1.0f / Ls) * u_alpha;    float di_hat_beta  = (v_beta  / Ls) - (Rs / Ls) * smo->i_hat_beta                          + (1.0f / Ls) * u_beta;          smo->i_hat_alpha += di_hat_alpha * Ts;       smo->i_hat_beta  += di_hat_beta  * Ts;    // 反电势 = LPF(-u_switch)    // u_switch = -K·sign(err)，滑模收敛后 u_switch_eq = -e（反电势的负值） [S-002b]    // 故 -u_switch 的等效值 ≈ e，用 LPF 提取    // 一阶 IIR 近似：y[n] = (1-a)*y[n-1] + a*(-u[n])    // a = wc * Ts，wc = 2*pi*500，Ts = 100us → a ≈ 0.314    float a = SMO_LPF_OMEGA_C * Ts;       smo->e_hat_alpha += a * ((-u_alpha) - smo->e_hat_alpha);       smo->e_hat_beta  += a * ((-u_beta)  - smo->e_hat_beta);   }`

注意第 41 行的注释：**K 的单位是 V**。sat() 函数的标准定义输出在 \[-1, 1\] 之间（已归一化），所以 K × sat() 的单位仍然是 V，和电压方程一致。另一种常见写法是不使用 sat() 归一化，直接令 （err 单位 A），此时  的单位是 V/A。两种都对，但**一个项目里只能选一种，不要混用**。

## 三个常见坑

### 坑 1：只看稳态，不看动态

空转时 K = 80 波形漂亮，角度误差 0.3°。客户一加负载，角度滞后 12°，电流环过流保护跳闸。

根因：稳态时误差小，K 不需要很大就能维持。但负载突变瞬间，反电势变化率大，估计电流跟不上，需要 K 有足够"推力"把误差快速压回去。

解法：扫参时必须做负载突变测试。甜点区不能只看空转。

### 坑 2：K 和 Φ 同时拧

你嫌抖振大，同时把 K 降了 20%、Φ 提了 30%。波形变好了，但你不知道是谁的功劳。下周温升后电机变了，你又不知道该怎么调。

根因：K 和 Φ 耦合。两个变量同时变，无法归因。

解法：严格按"先 K 后 Φ"的顺序。一次只动一个变量，记录变化前后的波形。调参日志比代码更重要。

### 坑 3：一套 K 打天下

实验室用 3000 rpm 调好的 K，客户现场跑 300 rpm 起步，电机抖得像帕金森。

根因：固定 K 假设全速域的反电势上界在同一个数量级。实际上高速和低速的最佳 K 可能差 5~10 倍。

解法：如果你的速度范围很宽（>10:1），要么接受低速抖振（同时加足够的电流滤波），要么上增益调度，要么低速段切到 HFI/I-F 启动。

说白了，K 的设计没有万能公式。理论给你下限，实验给你上限，甜点区是你一拳一拳打出来的。

固定增益观测器像一个只会一种力度握手的人——力气大了捏疼你，力气小了没诚意。[上一篇](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486620&idx=1&sn=996bb4db55b9694d3faa1a6a9a62dabf&scene=21#wechat_redirect)的自适应 SMO 让这只手学会了"察言观色"，但察言观色的基准力度（K₀）从哪来？就是从这一篇的扫参流程里来的。没有 K₀，自适应增益就是无根之水 \[S-003\]。

## 🔧 调试 Checklist

\[ \] 用 datasheet 算出  = ω\_e\_max × λ\_f，确定 K 的理论下限  
\[ \] K 的起步值取 1.2~2.0 倍 ，留裕量应对噪声和参数偏差  
\[ \] 扫 K 时固定 Φ 和 ω\_c，一次只动一个变量  
\[ \] 每个 K 值记录三组数据：稳态电流波形、角度误差 mean/std、负载突变超调/恢复时间  
\[ \] K 定下来后，再扫 Φ（从 0.02 开始），确认抖振被压制且动态未恶化  
\[ \] 在最低工作转速和最高工作转速分别验证，固定 K 是否全速域可用  
\[ \] 换电机必须重新算 K，不要照搬别人的值  
\[ \] 通过高速日志上传到上位机，或 DAC 输出到示波器/采集卡，确认开关项的幅值和理论值一致
