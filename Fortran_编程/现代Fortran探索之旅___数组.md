Fortran 是一种专为数值计算设计的编程语言，在科学计算和工程领域有着广泛的应用。在Fortran中，数组是一个非常重要的数据结构，它允许我们存储和操作一组有序的数据。下面，我们将详细介绍Fortran数组的用法，力求通俗易懂。

### 1\. 数组的基本概念

在Fortran中，数组是由一系列相同类型的元素组成的数据结构。这些元素在内存中连续存储，并通过索引进行访问。数组可以是多维的，最常见的是一维数组和二维数组。数组的每个元素都可以通过其索引来访问和修改。

### 2\. 数组的声明

在Fortran中声明数组时，需要指定数组的名称、类型和维度。以下是一个一维整数数组的声明示例：

 INTEGER, DIMENSION(10) :: arr

上述代码声明了一个名为`arr`的一维整数数组，包含10个元素。`DIMENSION(10)`指定了数组的大小。

对于二维数组，你可以这样声明：

 REAL, DIMENSION(5, 5) :: matrix

这里，`matrix`是一个5x5的二维实数数组。

### 3\. 数组的初始化

在Fortran中，你可以在声明数组的同时初始化它。例如：

 INTEGER, DIMENSION(3) :: arr \= (/1, 2, 3/)

这将创建一个包含3个整数的一维数组，并用指定的值初始化它。

对于二维数组，初始化可能看起来像这样：

 INTEGER, DIMENSION(2, 2) :: matrix \= RESHAPE((/1, 2, 3, 4/), (/2, 2/))

这里，`RESHAPE`函数用于将一维数组重新塑形为二维数组。

### 4\. 数组的访问和修改

在Fortran中，你可以通过索引来访问和修改数组的元素。索引通常从1开始（而不是从0开始，这与许多其他编程语言不同）。例如：

 arr(1) \= 10  ! 设置数组的第一个元素为10  
 PRINT\*, arr(1)  ! 打印数组的第一个元素

对于二维数组，你需要提供两个索引来访问元素，例如：

 matrix(1, 2) \= 20  ! 设置二维数组的第一行第二列的元素为20  
 PRINT\*, matrix(1, 2)  ! 打印二维数组的第一行第二列的元素

索引不从1开始也是可以的。Fortran支持自定义数组的索引范围，只要在声明时显式地指定即可。例如：

 INTEGER, DIMENSION(0:3) :: a  
 ! 合法元素 a(0) a(1) a(2) a(3)  
 INTEGER, DIMENSION(2:3,\-1:1) :: b   
 ! 甚至允许负值作为索引  
 ! 合法元素  
 ! b(2,-1) b(2,0) b(2,1)  
 ! b(3,-1) b(3,0) b(3,1)

### 5\. 数组的切片和范围操作

Fortran还支持数组的切片操作，这允许你轻松地访问和修改数组的一部分。例如：

 arr(2:4) \= (/ 20, 30, 40 /)  ! 设置数组的第2到第4个元素  
 PRINT\*, arr(2:4)  ! 打印数组的第2到第4个元素

对于二维数组，你也可以进行类似的切片操作：

 matrix(1:2, 2:3) \= RESHAPE((/ 2, 3, 4, 5 /), (/2, 2/))  ! 设置二维数组的一个子矩阵  
 PRINT\*, matrix(1:2, 2:3)  ! 打印二维数组的一个子矩阵

### 6\. 数组的运算

Fortran支持对数组进行各种运算，如加法、减法、乘法、除法等。这些运算通常是对数组中的每个元素逐一进行的。例如：

 INTEGER, DIMENSION(3) :: arr1 \= (/1, 2, 3/),  
 INTEGER, DIMENSION(3) :: arr2 \= (/3, 2, 1/)  
 INTEGER, DIMENSION(3) :: arr3  
 arr3 \= arr1 + arr2  ! 对应元素相加  
 PRINT\*, arr3  ! 打印结果：(/4, 4, 4/)

### 7\. 数组与循环结构

在处理数组时，循环结构是非常有用的。你可以使用`DO`循环来遍历数组的元素并进行操作。例如：

 INTEGER, DIMENSION(3) :: arr \= (/1, 2, 3/)  
 INTEGER :: i  
 DO i \= 1, SIZE(arr)  
     PRINT\*, arr(i)  ! 打印数组的每个元素  
 END DO

### 8\. 动态数组

Fortran还支持动态数组，即可以在运行时确定数组的大小。这需要使用`ALLOCATABLE`属性和`ALLOCATE`语句。例如：

 INTEGER, ALLOCATABLE, DIMENSION(:) :: dynamic\_arr  
 INTEGER :: n \= 3  
 ALLOCATE(dynamic\_arr(n))  ! 在运行时分配数组的大小  
 dynamic\_arr \= (/1, 2, 3/)  ! 数组赋值  
 PRINT\*, dynamic\_arr  ! 打印数组的元素  
 DEALLOCATE(dynamic\_arr)  ! 释放数组的内存空间

### 9\. 数组的函数和操作

Fortran提供了许多内置函数和操作来处理数组，如`SUM`、`PRODUCT`、`MINVAL`、`MAXVAL`、`MATMUL`（矩阵乘法）等。这些函数可以帮助你轻松地执行复杂的数组操作。例如：

 INTEGER, DIMENSION(5) :: arr \= (/1, 2, 3/)  
 PRINT\*, SUM(arr)  ! 打印数组元素的和：6  
 PRINT\*, MINVAL(arr)  ! 打印数组中的最小值：1  
 PRINT\*, MAXVAL(arr)  ! 打印数组中的最大值：3

### 10\. 数组的注意事项

-   **数组越界**：在访问或修改数组元素时，确保索引在有效范围内。否则，程序可能会崩溃或产生不可预测的结果。注意，Fortran数组的索引默认从1开始，而不是从0开始，这与C、C++和Java等语言不同。
    
-   **数据类型不匹配**：确保在赋值或操作时数据类型是一致的。例如，不要将实数赋值给整数数组。
    
-   **未初始化的数组**：在Fortran中，未初始化的数组可能包含垃圾值。因此，在使用数组之前最好进行初始化。
    
-   **数组切片与赋值的维度匹配**：在进行数组切片赋值时，确保切片的形状与目标数组的形状相匹配。
    
-   **内存管理**：当处理大型数组时，要多注意内存管理。动态分配和释放内存可以帮助你更有效地管理资源。另外，Fortran有自动内存回收机制，所以不会出现因忘记释放内存造成内存泄漏的情况，这一点要好于C/C++。
