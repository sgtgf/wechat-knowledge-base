# 一种混合型有源中点钳位型三电平逆变器的效率优化与热管理技术


> 原文地址: [https://mp.weixin.qq.com/s/raaFw6bwxfBIPHwryMjegw](https://mp.weixin.qq.com/s/raaFw6bwxfBIPHwryMjegw)

文章来源：太阳能学报

作者：冯之健，赵树哲，孙自祥，张馨元，赵　涛（青岛大学电气工程学院，青岛 266071）

摘　要：针对三电平有源中点钳位型（3L-ANPC）逆变器存在调制复杂、难以同时兼顾高效率和散热均衡等问题，提出一种新型 Si-SiC 混合型 3L-ANPC 逆变器电路拓扑及调制策略。当输出电压被钳位至中性点时，采用上下桥臂双支路同时导通的续流方式，有效降低通态损耗；此外，引入过渡零状态调整驱动时序，使得硬开关损耗集中于两个 SiC 金属氧化物半导体场效应晶体管（MOSFET）以降低开关损耗，同时均衡各开关管的温度。首先介绍 Si-SiC 混合型 3L-ANPC 逆变器的工作原理，然后建立其损耗模型和热模型并进行理论分析，最后搭建单相有源中点钳位型（ANPC）实验平台进行实验验证。仿真与实验结果表明，相较于传统基于 Si 器件的方案，所提方案的效率提高约 2.8%，开关管最高结温降低 3.6 ℃。

关键词：三电平逆变器；SiC MOSFET；损耗建模；效率分析；热管理

0　引　言

为实现“双碳”目标，构建以新能源为主体的新型电力系统，光伏发电已成为中国政府和能源专家关注的重点。截至2022 年底，中国太阳能发电新增装机 8741 万 kW，装机累计达 3.93 亿 kW，相较于 2021 年增长 28%，光伏发电呈现出良好发展前景。光伏发电系统并网接入电网需以逆变器为接口，因此高效率、高功率密度的光伏逆变器成为保障光伏发电系统稳定发展的重要因素。

随着光伏发电系统容量增加 ，二极管中点钳位型（neutral point clamped，NPC）三电平逆变器取代传统两电平逆变器广泛应用在中大功率光伏系统。但 NPC 型逆变器损耗集中于中间两管，存在损耗分配与结温分布不均的问题。为此，文献［11］首次提出有源中点钳位型（active neutral point clamped，ANPC）逆变器拓扑结构，ANPC 逆变器将两个钳位二极管改为电流双向流动的开关管，能够依靠冗余的开关状态下合理的电流路径选择实现损耗均衡与结温平衡。由于传统 Si 器件的半导体性能已达理论极限，用 SiC 器件替代电路中的 Si 器件可进一步提高系统效率和功率密度。但 SiC 器件成本高，大电流 SiC 金属氧化物半导体场效应晶体管（metal-oxide-semiconductor field-effect transistor，MOSFET）价格 通 常 是 同 等 额 定 电 流 下 Si 绝缘 栅 双极型晶体管（insulated gate bipolar transistor，IGBT）的 4 倍以上。相比其他常见三电平电路，一个单相 ANPC 电路包括 6 个有源功率器件。高额成本决定了目前三电平有源中点钳位型（three-level active neutral-point-clamped，3L-ANPC）逆变器一般不会全部采用 SiC 器件，而会混合使用 SiC 与 Si 器件，并利用ANPC 逆变器冗余的开关状态将损耗集中于 SiC 开关管，达到兼顾效率与成本的效果。

目前对于采用 Si-SiC 开关管的 3L-ANPC 逆变器的研究已相当成熟，其已应用于飞机混合动力系统、轨道牵引系统、电池储能系统、光伏系统。关清心总结出 Si-SiC 开关管的 3L-ANPC 逆变器常见调制策略下的损耗模型；徐浩歌提出注入零序分量的中点电容电压平衡控制策略，该策略计算简便且易于实现；桂汉东等利用磁抵消效应设计了3L-ANPC 逆变器母线布置方法，有效解决了高频工作状态下寄生电感的影响。文献［22］提出一种采用 2-SiC 的 3L-ANPC逆变器，其拓扑及调制策略如图 1 所示，其中 T2 和 T3 为 SiC MOSFET，T2 和 T3 工作在高开关频率下并承担硬开关损耗。2-SiC 方案 利 用 SiC 器件 的 优 势 降 低 通 态 损 耗 与 硬 开 关 损耗，适用于小功率和低频场合。但该方案损耗集中在 T2、T3两管，在高频或重载状态下存在损耗分布不均匀、半导体结温分布不对称的问题，限制了逆变器的开关频率和功率输出能力。文献［24］提出一种采用 4-SiC 的 3L-ANPC 逆变器，其拓扑及调制策略如图 1 所示 ，其中 T1、T4、T5、T6 为 SiC MOSFET，4 个开关管工作在高开关频率下并承担硬开关损耗。4-SiC 方案可根据不同运行状态选取对应调制策略，相较于 2-SiC 方案其效率更高，热平衡效果更优，更能适用于大功率或高频应用场合。目前提高 4-SiC 3L-ANPC 逆变器效率的主要优化方案是软开关技术。采用软开关可减小或消除开关损耗，但其缺点是结构与调制过程复杂，且无法减小通态损耗。文献［28］提出一种通过两个并联支路换流减小通态损耗的方法，但该方案难以保证上下桥臂的均流，限制了逆变器的输出能力。

![](https://mmbiz.qpic.cn/mmbiz_png/aJG5QWxqLsluBib5hOaK9tBPPMcDfkoP0PT9IuG20LebnFt4Q5PATvTs1z3Hff1jMhZNnduDsxpzhcjNDluKiczw/640?wx_fmt=png&from=appmsg)

综上，本文提出一种新型 Si-SiC 混合型 3L-ANPC 逆变器，其充分利用了 3L-ANPC 逆变器冗余的开关状态，相较于传统 3L-ANPC 逆变器工作效率更高，开关管结温更低。新型3L-ANPC 逆变器采用双支路换流的方式，以减小系统的通态损耗。并引入过渡零状态使得除中间两管外的所有开关管均实现零电压开通与关断，提高系统效率。本文首先介绍新型 Si-SiC 混合型 3L-ANPC 逆变器的工作原理，然后建立其损耗模型和热模型并进行理论分析，最后搭建单相 ANPC 实验平台进行实验验证。

1.2　工作原理

![](https://mmbiz.qpic.cn/mmbiz_png/aJG5QWxqLsluBib5hOaK9tBPPMcDfkoP0donnAKMOQ8kmYvzzTU30l1ia9UAFbR6iaYhyKUE7rgByoXeu49ETctRw/640?wx_fmt=png&from=appmsg)

P 状态与零状态切换过程如图 3 所示。在正半周期 P 状态下开关管 T1、T2 和 T6 导通，电流流经 T1 和 T2，T6 只开通并无电流流过。随后电路进入死区 1，T3 的反并联二极管 VD3自然导通，电流经 T6 和 VD3 续流。在过渡零状态 OL1，T3 零电压导通，电流仍流经 T6 和 VD3。然后电路进入死区，T1 零电流关断，电流仍流经 T6 和 T3。在主零状态 OUL1，T2 和 T5 零电压导通，电流流经 T5 和 T2 以及 T6 和 T3 两个并联支路。硬开关损耗 只 发 生 在 T2、T3 上 ，有效 地 减 少 开 关 管 损 耗 。 随后 由OUL1 状态切换至 P 状态时仍需经过渡零状态 OL1。T2 关断，经一段死区后 T1 零电压开通，经一段死区后 T2 再次开通。整个换流过程为 P-OL1-OUL1-OL1-P。在这个换流过程中，T2 以二倍开关频率开通与关断，每次开通与关断均承担硬开关损耗。VD5 承担二极管反向恢复损耗，其他开关管均为零电压开通与零电流关断。N 状态与零状态的切换过程如图 3 所示，换流方式与 P 状态和零状态切换方式类似，此处不再赘述。

如果电压和电流方向不同，开关过程为：P 状态与死区 1状态下电流流经 VD1、VD2。OL1 状态下电流流经 T3 与 T6，T3承担硬开通损耗。随后进入死区 2，T1 零电流关断，电流仍流经 T3 与 VD6。OUL1 状态下电流流经 VD2、T5 以及 T3、VD6 两个并联支路，T5 承担硬开通损耗。由零状态切换至 P 状态过程中，T3、T5 仍承担硬关断损耗。N 状态与零状态的切换过程不再赘述。

2.2　损耗分析与建模

SiC 器件在 3L-ANPC 逆变器中具有效率优势。逆变器的功率损耗主要体现在开关管的通态损耗、硬开关损耗和二极管的反向恢复损耗上。本节主要讨论中低频率下新型3L-ANPC 逆变器各开关管的通态损耗、硬开关损耗和二极管的反向恢复损耗建模方法。由于 3L-ANPC 逆变器的对称性，T1 与 T4、T2 与 T3、T5 与 T6 的各项损耗值相等，本节只分析 T1、T2、T5 这 3 个开关管。

3　实验验证

3.1　损耗分布比较

传统 2-SiC 3L-ANPC、4-SiC 3L-ANPC 逆变器拓扑方案的损耗建模可参考文献［32-33］。为比较新型 Si-SiC 混合型3L-ANPC 逆变器拓扑方案与传统 2-SiC 3L-ANPC、4-SiC 3L-ANPC 逆变器拓扑方案的性能，计算 3 种 ANPC 逆变器拓扑方案的开关器件损耗，如图 6 所示。

![](https://mmbiz.qpic.cn/mmbiz_png/aJG5QWxqLsluBib5hOaK9tBPPMcDfkoP0Ql7OxKAcBwmz1VW49CcNYFXB0aibz6xTHyCwLm64FRjyWTO4eTjNYXQ/640?wx_fmt=png&from=appmsg)

Si IGBT选用IKP40N65H5，SiC MOSFET选用C3M0060065D，在此开关管选型下，3 种逆变器的主要损耗均为通态损耗。在零状态换流过程中 Si-SiC 混合型 3L-ANPC 逆变器采用双支路换流的方式，每个支路电流只有负载电流的一半。因此，相较于传统单支路换流方案，新型 3L-ANPC 逆变器拓扑方案通态损耗较低。硬开关损耗只发生在 SiC 开关管上，因此装置开关损耗值减小。所以相较于两传统方案，本文方案功率损耗总值较低，效率较高。由于 T2、T3 在主零状态与 P（N）状态导通，导通角较大，其通态损耗值也较大，所以本文方案损耗主要集中于 T2、T3 两个开关管上。但由于双支路换流方式减小了 T2、T3 通态损耗，且 PF≠1 时 T5、T6 会分担部分硬开关损耗，所以相较于传统 2-SiC 逆变器拓扑方案，新型Si-SiC 混合型 3L-ANPC 逆变器功率分布更为均衡。

4　结论

本文提出一种采用 4-SiC 的兼顾效率优化与损耗均衡的新型 Si-SiC 混合型 3L-ANPC 逆变器拓扑结构及调制策略。实验结果表明：

1）该拓扑结构能够利用过渡零状态，使 Si 器件实现零电压开通与零电流关断，将硬开关损耗集中于 T2 和 T3 两个开关管上，实现了 ANPC 逆变器的损耗均衡。

2）本文提出 Si-SiC 混合型 3L-ANPC 方案及其调制策略，采用并联支路换流 方式 ，相较于传统 2-SiC 3L-ANPC 和 4-SiC 3L-ANPC 方案，很大程度减小了通态损耗，降低了开关管结温。实验结果表明，装置效率相较于采用本文调制策略的全 Si 开关管提高 2.8%，开关管结温降低 3.6 ℃。
