# 卧龙集团签约上纬新材，合作共研机器人核心部件！

**7月18日，WAIC 2026**现场，卧龙集团与上纬新材料科技股份有限公司（688585.SH）签署战略合作协议，锚定"机器人核心部件产线"做深度绑定。卧龙电驱集团董事长庞欣元、机器人模组事业部总经理陈根旺，上纬新材CEO田华、采购部总经理任珂四人到场签字。表面看是两家非同赛道公司的产线合作，但把智元机器人这条暗线拉出来，会发现这是**"卧龙战投智元 → 智元控股上纬 → 卧龙跟上纬签产线"** 的三角供应链闭环里的最新一块拼图。

![](D:\电脑文件\公众号知识库\电工_行业资讯\卧龙集团签约上纬新材_合作共研机器人核心部件__images\img_003_a4586d49d327.png)

合作内容写得克制：聚焦**机器人核心关节部件的定制化生产与精密组装**，持续优化量产工艺与产品稳定性。翻译成产业语言——卧龙出"肌肉"，上纬出"本体"，在消费级个人机器人的关节量产这道坎上做产线级绑定。

卧龙电驱（600580.SH）1984年起家，是全球防爆电机第一股，2025年8月递交港股IPO申请，募资方向里"机器人组件+电动航空"是两大新增长极。

机器人这条线卧龙走了十几年：

-   **2014年**收意大利SIR机器人公司，成立浙江希尔机器人，做汽车领域工业机器人集成；
    
-   **2023年**切入具身智能组件，重点攻空心杯电机、无框力矩电机；
    
-   **2025年3月**与智元机器人双向持股，希尔机器人同时获智元增资，双方绑进"产业共同体"；
    
-   **2025年6月底**人形机器人电机产线投产，高爆发旋转关节模组已完成"电机+减速器+编码器+控制板+控制软件+关节机械组件"全集成试生产，机器狗小功率两个型号已出，正向人形超大功率拓展。
    

庞欣元这次在WAIC给的定位是"行业领先的机器人动力系统解决方案供应商"，产品线已覆盖**无框力矩电机、减速器、伺服驱动器、关节模组、灵巧手**全链条，下游打四足机器狗、两足人形、工业机器人三个方向。智元、宇树、云深处、浙江人形机器人创新中心都在它的客户/合作名单里。

上纬新材本是做风电叶片环氧树脂、环保耐腐蚀材料的科创板公司（2020年9月上市），转折点在**2025年7月8日**——智元机器人通过"协议转让29.99% + 要约收购37% + 原股东放弃表决权"三步走，耗资约21亿拿下63.62%控股权，实控人变更为智元创始人邓泰华。11月稚晖君（彭志辉）当选上纬新材董事长，12月31日启元Q1首发，2026年7月WAIC上可变形个人机器人**启元T1**首秀——从"化工"到"个人机器人"只用了不到一年。

上纬做机器人的底气是材料：26年积累的碳纤维复合材料+可回收环氧树脂（EzCiclo系列），田华在WAIC期间接受采访时放过一个数据——**碳纤维配合拓扑优化，机器人躯干可减重30%以上**，脚掌、连杆等结构件已在研发验证。这是它跟蓝思、卧龙、沪光能玩到一起的底牌：别人做结构件要外购材料，它自己就是材料厂。

WAIC期间上纬的"产线三连签"，卧龙只是其中一块

把7月18日这一天放大看，上纬在WAIC签的不止卧龙一家：

-   **卧龙电驱** → 核心关节部件定制化生产+精密组装
    
-   **蓝思智能**（蓝思科技300433子公司）→ 启元Q1/T1**万台级产线**，覆盖精密零部件加工、关节模组生产、整机组装
    
-   **沪光股份**全资子公司全能具身智能 → 整机组装+机器人专用线束配套
    

三家里的分工很清楚：**卧龙管"关节动力"、蓝思管"结构件+整机组装"、沪光管"线束+电气集成"**——上纬作为启元品牌方，在WAIC这三天把消费级个人机器人的量产供应链拼图一次性铺开。田华说的"率先完成品类定义"背后，是先要把"谁来造"这件事落实。

对卧龙侧同样有现实约束：人形关节产线2025年6月底才投产，目前给国内旗舰人形企业是"批量供应关节模组"、灵巧手还在"试点部署"阶段——跟上纬这条合作签的是"量产工艺持续优化"，潜台词是**消费级关节的量产工艺还没完全跑通**，要两边一起磨。卧龙自己的财报压力也在：传统电机利润率被压缩，人形+低空两条新业务都还在"研发转量产"的投入期。

把这条签约放回WAIC 2026的具身智能展区看，信号不是"又两家公司签了"，而是**消费级个人机器人这条细分赛道，正在用"材料厂（上纬）+ 关节厂（卧龙）+ 整机组装厂（蓝思）+ 线束厂（沪光）"的分工方式跑量产**——跟工业人形那条"本体厂自研关节"的路子不一样，启元走的是更偏向消费电子的供应链分工：每家只做自己最厚的那段，品牌方做集成和品类定义。

卧龙在这盘棋里的位置也值得记一笔：它既是智元的战略股东（绑定工业/通用人形），又通过上纬切到消费级个人机器人关节，再叠加宇树、云深处、浙大人形中心的合作，**"无框力矩电机+关节模组"这套拳头产品，已经在不同形态的机器人本体上多点铺货**——这是它相比步科、昊志、禾川这些纯电机/模组厂的差异化：卧龙有电机底子+希尔的整车厂场景+智元股权绑定，能同时打工业、通用人形、消费级个人机器人三张单。

7月18日那份签约本不厚，但放在"智元-上纬-卧龙"三角和"启元产线三连签"两层语境里，它其实是消费级个人机器人从"发布会产品"往"产线产品"挪的第一步。能不能跑通，看2026下半年启元Q1的批量交付数据就知道了。
