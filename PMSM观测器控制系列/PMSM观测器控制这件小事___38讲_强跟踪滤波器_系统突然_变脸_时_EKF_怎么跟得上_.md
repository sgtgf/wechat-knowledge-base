## 1\. 急性发作：Sage-Husa 治不了的病

[上一篇](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486797&idx=1&sn=695076f38964cdd6f1e44f803709b214&scene=21#wechat_redirect)你刚给滤波器装上 Sage-Husa，让它学会自己"验光"调 Q。客户跑了一周，温度漂移确实被压住了，角度估计的慢漂肉眼几乎看不出来。你长舒一口气，觉得这事算成了。

直到某天下午，测试同事往电机轴上突然挂了 5 N·m 的制动负载。

你盯着示波器——CH1 接的是编码器反馈的实际转速（作为调试基准），CH2 是 EKF 估计转速——眼看着估计值在负载落下的瞬间愣了整整约 30 ms：实际转速已经从 3000 rpm 掉到 2200 rpm，估计值还在 2800 rpm 附近打转，像被人按了暂停键。过了两三百个 PWM 周期（以 10 kHz 为例），Sage-Husa 的滑动窗口终于攒够了"异常样本"，Q 开始往上爬，估计值这才不情不愿地跟下去。等它完全收敛，转速已经稳在新平衡点上了。

这 30 ms 的滞后，对 HVAC 风机可能是小事；但对伺服定位、电梯曳引、机器人关节，就是失步、抖动、甚至撞机械限位的代价。

问题出在哪？

Sage-Husa 的底层逻辑是**统计诊断**：它观察残差的统计分布，判断"Q/R 是不是不匹配了"，然后缓慢修正。这本质上是个**慢性子**——它对缓慢漂移（温度、老化、磨损）很有效，因为漂移的速度远低于滑动窗口的收敛速度；但它对**急性发作**（负载阶跃、转速急变、参数跳变）毫无办法，因为窗口还没攒够数据，突变就已经结束了。

Sage-Husa 就像一位经验丰富的老中医，望闻问切之后给你调方子，适合调理慢性病；但碰上急性心梗，你需要的是除颤器，不是汤药。

这就是强跟踪滤波器（Strong Tracking Filter, STF）要解决的问题。

## 2\. 自动紧急制动：强跟踪滤波器（STF）的技术实现逻辑

想象你开着一辆车，以 80 km/h 的速度巡航。前方车辆突然急刹，你的车距离它只剩 20 米。

如果你是标准 EKF，你的反应是这样的：大脑根据当前速度和距离做预判——"按正常刹车力度，应该能停下来"——于是你匀速踩下刹车踏板，力度适中，姿态优雅。但前面车急刹的减速度远超你的预期，你匀速踩刹车根本来不及，"优雅"地追了尾。

如果你是强跟踪滤波器，你的车里装了一套自动紧急制动（AEB）。碰撞传感器检测到相对距离在几毫秒内骤减，它不等你的大脑做完整预判，**立刻**把刹车力度打到最大。车停住了，虽然乘客被安全带勒了一下，但避免了事故。危险解除后，系统回到正常状态，你继续优雅驾驶。

STF 的核心就是这个"碰撞传感器 + 应急制动"的即时响应机制。

**类比边界差异**：AEB 是二元触发（全力制动或不动作），而 STF 的渐消因子 λ 是**连续调节**的——它可以根据"异常严重程度"决定"制动力度多大"。另一个差异是 AEB 是汽车子系统的一次性动作，STF 的 λ 则是**每帧重新计算**，这一帧触发了，下一帧新息恢复正常，λ 立刻回到 1，无需人工复位。

## 3\. 为什么标准 EKF 对突变反应迟钝？

要理解 STF 做了什么，必须先看清标准 EKF 在突变时刻的**机械结构**。

在预测步，标准 EKF 的协方差传播是这样的：

这个式子说：下一时刻的"不确定性" P⁻，等于上一时刻的不确定性按状态转移矩阵 F 传播一遍，再加上过程噪声 Q。这里的假设是：**模型的传播规律 F 和过程噪声 Q 在一段时间内不变**。

在稳态时，这个假设成立。电机匀速转动，电流按电压方程演化，F 和 Q 都靠谱，P⁻ 的传播如实反映了"我大概有多不确定"。

但突变发生时——比如负载阶跃——电机转速的真实变化率瞬间跳变，你的模型 F 还是按"旧工况"在传播。此时真实状态已经跑远了，P⁻ 却还按原来的节奏慢慢长大，**它严重低估了实际的不确定性**。

P⁻ 低估的直接后果是什么？看更新步的卡尔曼增益：

P⁻ 小 → 分子小 → K 小 → 滤波器"觉得"自己挺准的，只给测量值一个很小的修正权重。结果就是：**测量值告诉你"转速掉了"，但滤波器说"我不信，我的预测更靠谱"**，估计值死死抱着过时的预测不放，滞后就这么产生了。

你可以把 P⁻ 想象成滤波器的"自信度"。突变时滤波器**应该**不自信——"我的模型刚才还好好的，现在可能不准了"——但标准 EKF 没有这个"自我怀疑"的能力。P⁻ 还是按部就班地长大，像温水煮青蛙，等到 P⁻ 终于大到让 K 足够大时，黄花菜都凉了。

STF 的做法极其直接：**既然 P⁻ 不够大，那就人为把它撑大**。

## 4\. 渐消因子：给协方差打一针肾上腺素

STF 的"应急制动"在数学上只引入了一个标量——**渐消因子**（fading factor）λ。

它在预测步的协方差传播中做了一件极其简单的事：

对比标准 EKF，唯一的区别就是在  前面乘了个 λ。

> **符号约定声明**：不同文献对"渐消因子"的方向定义不同。本文采用周东华原始论文的约定——λ ≥ 1 表示**膨胀**协方差（λ = 1 为标准 EKF，λ > 1 时 P⁻ 放大）。部分 fading memory 滤波文献使用 0 < λ ≤ 1（越小表示越遗忘历史），其物理含义与本文**相反**。实现时务必确认所参考文献的方向约定。当 λ = 1 时，这就是标准 EKF，毫发无损。当 λ > 1 时， 被成比例放大，P⁻ 瞬间膨胀。

P⁻ 一膨胀，K 立刻跟着变大——滤波器"突然不自信了"，于是更愿意听测量值的话。状态修正量加大，估计值在突变发生的**头几个 PWM 周期内**就向真实状态靠拢，而不是等滑动窗口攒够数据。

> **理论基础（非必须掌握，但值得了解）**：这针"肾上腺素"不是拍脑袋定的。周东华原始论文的核心理论是**正交性原理**——要求模型失配后的残差序列保持白色（不相关），由此严格推导出渐消因子的最优计算公式。上面的迹比法正是该原理的工程次优实现。你不需要会推导正交性，但需要知道 λ 不是魔法数字，它有扎实的理论根基。

这针"肾上腺素"的剂量怎么定？λ 不能瞎给。给太小，制动没介入，白搭；给太大，K 过大，稳态时噪声穿透过猛，估计值抖得像癫痫。

经典的做法是**让新息协方差匹配**：如果实际新息比理论预期大得多，说明 P⁻ 确实低估了不确定性，需要放大 λ；反之则保持 λ = 1。

> **时序说明**：λ\_k 的计算需要 V\_k（实际新息协方差估计），而 V\_k 是对历史残差序列的统计量（滑动窗口或 EWMA）。这意味着 λ\_k 本质上是基于**过去**的信息对**当前**帧做出的判断，存在一帧的固有延迟。如果你用 EWMA，这个延迟是平滑的；如果你用即时残差 ，可以逼近单帧触发，但会牺牲平滑性。

## 5\. 单渐消因子 vs 多重渐消因子

周东华等人在 1991 年的原始论文里提出的是**多重渐消因子**（multiple fading factors），也就是给每个状态维度配一个独立的 λᵢ，组成对角矩阵 Λ = diag(λ₁, λ₂, ..., λₙ)。预测步变成：

理论上，这更精细：如果转速突变但电流稳如老狗，可以让 λ\_ω 很大而 λ\_i 保持 1，只放大速度维的不确定性，不干扰电流维的稳态精度。

但工程中，多重渐消因子有几个**隐蔽的坑**：

**第一，计算量。** 单渐消因子只需要算两个迹（tr(N) 和 tr(M)）再做一次除法。多重渐消因子需要对 P⁻ 的每个对角块分别求解 λᵢ，计算量随状态维数平方增长。对 5 维 EKF（iX, iY, θ, ω, bias），单渐消因子只需约 20-30 次浮点运算，多重渐消因子可能要几百次。在 10-20 kHz 的 PWM 中断里，这笔开销不能忽视。

**第二，数值稳定性。** 原始论文的 Λ 左乘形式（）会破坏协方差矩阵的对称正定性——你左边乘了 Λ，右边没乘， 可能不再对称。后续改进版 SSTEKF（Symmetric Strong Tracking EKF）用 Cholesky 分解做了对称化处理：

**第三，过拟合与维度串扰。** 每个维度独立调 λ，看似精细，实则容易把某维的噪声误当成突变，导致该维 λᵢ 瞬间跳变、下一帧又掉下来，引入不必要的高频抖动。单渐消因子虽然避免了维度间串扰，但也有自己的弱点：**任何维度的异常都会触发全局 λ 增大**。如果电流测量出现短暂毛刺，单 λ 也会让整个滤波器进入"应急模式"，速度维的稳态精度随之被暂时牺牲。不过，由于 λ 是每帧重新计算的，毛刺只影响一帧，且 λ\_max 上界限制了冲击幅度。在资源受限 MCU 和缺少维度级调参证据时，单渐消因子通常更稳妥。

所以工程上的常见归宿是**单渐消因子**：所有状态共用一个 λ，简单、鲁棒、计算量小。如果确实需要对特定维度差异化处理，更务实的做法是固定一个单 λ，然后在 Q 矩阵的特定分量上手动加权——这与 STF 的框架不冲突，且更可控。

## 6\. STF 与 Sage-Husa：两种自适应，两种脾气

很多人把 STF 和 Sage-Husa 混为一谈，都叫"自适应 EKF"。但它们改变的是滤波器的**不同部位**，解决的是**不同问题**。

维度

Sage-Husa

强跟踪滤波器 STF

**改什么**

在线估计 Q̂ 和 R̂ 的数值

临时膨胀 P⁻，不改 Q/R

**作用时间**

长期：Q/R 一旦更新，永久生效

直接作用于当前预测步；其对状态和协方差的结果会被后续递推继承

**对稳态的影响**

持续改变滤波器的"性格"

当稳态新息统计正常且 λ = 1 时，不改变标准 EKF；误触发会牺牲稳态噪声抑制

**擅长场景**

缓慢漂移（温度、老化、磨损）

快速突变（负载阶跃、转速急变）

**反应速度**

慢（依赖滑动窗口收敛）

快（可接近单帧触发；滑动窗口/EWMA 会引入延迟）

**发散风险**

Q/R 耦合可能导致协方差爆炸

λ 上界 clamp 后风险显著可控，但仍需野值剔除配合

**计算量**

较大（需维护多个统计量）

很小（单迹比 + 乘法）

Sage-Husa 像调相机的 ISO 感光度——环境光变了，你调高 ISO，之后拍的所有照片都用这个 ISO。STF 像运动模式下的快门优先级——检测到运动物体，这一帧把快门速度提上去，下一帧物体停了，自动回到正常模式。

两者不是竞争关系，是**互补关系**。工程上常见的组合策略是：

-   • **稳态**：Sage-Husa 在线微调 Q/R，适应缓慢漂移；
    
-   • **瞬态**：STF 的 λ 在突变瞬间 > 1，让滤波器快速跟上；
    
-   • **突变结束后**：λ 回到 1，Sage-Husa 继续它的长期调理。
    

有些文献直接把两者打包，比如 SH-MSTUKF（Sage-Husa + Modified Strong Tracking UKF），但那是更复杂的融合框架，计算量明显增加。对大多数 MCU 项目，先用单 STF 把突变问题解决了，再考虑要不要叠 Sage-Husa，是更务实的路径。

## 7\. 工程实现要点

如果你决定在实际项目中引入 STF，以下是几个会直接影响成败的细节。

### 7.1 λ 的上界和下界

下界必须是 λ ≥ 1。有些文献把渐消因子定义成 0 < λ ≤ 1（遗忘因子方向），那套框架里 λ 越小表示"越不信任历史"。STF 的原始定义是 λ ≥ 1，**只膨胀、不收缩**。如果 λ < 1，P⁻ 会被压缩，K 变小，滤波器更自信——这与 STF 的目标完全相反。

上界 λ\_max 是工程保护的核心。没有上界，若传感器短暂失效或出现野值，实际新息协方差 V 会瞬间爆炸，λ 跟着上天，P⁻ 和 K 一起失控，估计值会被测量噪声彻底带偏。λ\_max = 5~10 是工程初始扫描范围 （经验值，需按具体工况仿真标定），然后在你的具体硬件上实测：给一个额定负载阶跃，逐步放宽 λ\_max，观察估计曲线的跟踪速度和稳态抖动，找到拐点。

### 7.2 V\_k 的实际估计

迹比法里的 V\_k 是"实际新息协方差"，和 Sage-Husa 里的 Ĉᵥ 是同一回事，可以用同样的方法估计——滑动窗口或 EWMA。这里不再重复推导，直接复用 [上一篇](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486797&idx=1&sn=695076f38964cdd6f1e44f803709b214&scene=21#wechat_redirect) 的实现方式即可。唯一需要注意的是：**STF 对 V\_k 的延迟比 Sage-Husa 更敏感**。因为 λ 是每帧即时计算的，如果 V\_k 本身有半个窗口的延迟，λ 的触发就会晚半拍。所以 STF 场景下，EWMA 的遗忘因子 b 可以适当取大（比如 0.05-0.1 (经验值，需按实际 PWM 频率和工况标定)，对应统计等效窗口约 20~40 点），让 V\_k 对最新样本更敏感。

> **触发延迟的权衡**：如果你追求极致的触发速度，可以用当前帧的即时残差  作为  的粗略估计，实现近似单帧触发；但噪声会随之进入 λ 的计算，稳态时 λ 可能出现不必要的小幅跳动。EWMA 是平滑性与灵敏度的折中。

> **初始化时的注意点**：V\_k 的估计器在启动阶段容易出现 underestimation（窗口未满时统计量偏低），导致 N\_k 偏小甚至为负，λ 被钳在 1，突变早期可能漏触发。与之相对，如果 V\_k 因野值被 overestimation，则可能导致 λ 不必要地放大。复用 上一篇 文章中讲到的 first-frame 初始化策略——用前几帧的即时残差先填满窗口，或设置一个保守的初始 V\_k 值，避免 startup 阶段的误判。

### 7.3 与 lockout\_guard函数 的配合

在 [第33讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486783&idx=1&sn=3da8ae74c88861a06c2991aa7bbadf8b&scene=21#wechat_redirect) 里我们讲过 phobia 的 `pm_kalman_lockout_guard()`——当 EKF 估计出现 DQ 轴反向锁死或收敛异常时，触发重启并翻转 DQ 轴。STF 的 λ > 1 会让 K 增大，理论上增大了"信测量"的比例，如果这时候测量链路出现异常值，lockout\_guard 的存在就显得更重要。两者应该配合使用：STF 负责"该快的时候快"，lockout\_guard 负责"别快过头掉沟里"。

### 7.4 不要和 Q/R 自适应同时放开

如果你是第一次引入 STF，建议**冻结 Q/R 在 [第36讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486792&idx=1&sn=c2519e9f97c11bb4c04542f2ae259f68&scene=21#wechat_redirect) 中标定好的值**，只引入单渐消因子 λ。同时放开 STF + Sage-Husa，等于同时改两个互相耦合的变量，出了问题很难定位是 λ 太猛还是 Q 估计偏了。先把单 STF 跑稳，再考虑叠加 Sage-Husa。

## 8\. 示意代码与计算开销

以下是单渐消因子的关键插入点示意代码/伪代码（仅限示意用，未在 phobia 源码中实际存在）。它假设你已经有标准 EKF 的预测步和更新步框架，只需在预测步插入 λ 的计算：

`// 单渐消因子强跟踪 EKF（仅限示意用）   typedef struct {    float lambda;           // 当前渐消因子    float lambda_max;       // 上界保护     float V_trace;          // 实际新息协方差迹（EWMA/滑动窗口估计，复用 [上一篇](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486797&idx=1&sn=695076f38964cdd6f1e44f803709b214&scene=21#wechat_redirect) 逻辑）    float N_trace, M_trace; // 渐消因子计算的中间量   } stf_t;      // 预测步：标准 EKF + 渐消因子   void stf_forecast(pm_t *pm, stf_t *stf, float *P, float *F, float *Q) {    // 先计算 λ（基于上一帧的新息统计）       stf->lambda = compute_fading_factor(stf);    // P^- = λ * (F * P * F^T) + Q    // 这里省略 F*P*F^T 的具体计算，只展示 λ 的插入点    for (int i = 0; i < 5; i++) {        for (int j = 0; j < 5; j++) {               P_pred[i][j] = stf->lambda * FPFt[i][j] + Q[i][j];           }       }   }      // 渐消因子计算（迹比法）   float compute_fading_factor(stf_t *stf) {    // N = V - H*Q*H^T - R    float N_trace = stf->V_trace - HQHt_trace - R_trace;    // M = H * F * P * F^T * H^T    float M_trace = HFPFtHt_trace;    float lambda = 1.0f;    if (M_trace > 1e-6f) {  // 避免除以零           lambda = N_trace / M_trace;       }    // 下界：λ 不得小于 1（不压缩协方差）    if (lambda < 1.0f) lambda = 1.0f;    // 上界：防止极端情况下爆炸    if (lambda > stf->lambda_max) lambda = stf->lambda_max;    return lambda;   }`

**计算开销分析**：单渐消因子的额外开销包括：

-   • 计算 tr(N) 和 tr(M)：各需要一次矩阵迹运算（H·Q·Hᵀ 和 H·F·P·Fᵀ·Hᵀ），但 H 在 PMSM 电流测量场景下是稀疏的选择矩阵，实际只需提取对应元素，计算量很小；
    
-   • 一次除法和两次比较；
    
-   • 预测步中 P⁻ 的每个元素乘一次 λ。phobia 的协方差矩阵采用对称紧凑存储（15 个独立元素），仅缩放操作就需要 15 次乘法。
    

总计额外开销大约 **20~30 次浮点运算**（含 15 次缩放乘法、迹运算、除法和比较），对现代 MCU 来说仍属轻量。相比之下，多重渐消因子的计算量可能要大一个数量级，而且还需要处理对称正定性问题。

## 9\. 什么时候该用 STF，什么时候不该用

STF 不是万能药。它的价值集中在**特定的痛苦场景**：

**值得引入 STF 的场景：**

-   • **频繁负载突变**：冲压机械、往复压缩机、机器人抓取-释放循环；
    
-   • **转速急变**：主轴加减速、电动汽车急加速/能量回收；
    
-   • **模型参数跳变**：磁链随温度分段衰减、绕组电阻在不同冷却工况下切换。
    

**不值得引入 STF 的场景：**

-   • **稳态精度是第一优先级**：当稳态新息统计正常且 λ = 1 时，STF 不改变标准 EKF 的最优性；但如果你的系统几乎没有突变，引入 STF 就是纯增加代码复杂度，ROI 为零；
    
-   • **测量噪声极大**：如果 R 本身已经很大（电流传感器信噪比差），K 天生就小，STF 把 P⁻ 撑大也改变不了"测量不可信"的本质；
    
-   • **算力已经吃紧到极点**：虽然单 λ 开销极小，但如果你的 MCU 跑 EKF 已经用了 90% 的 算力，再加任何东西都要谨慎。
    

**最务实的判断标准**：先在你的硬件上跑标准 EKF，给一个额定负载阶跃，用示波器（CH1 编码器实际转速作为基准，CH2 EKF 估计转速）或日志记录**转速估计的滞后时间**（从实际转速开始变化到估计值跟上的延迟）。如果滞后时间超过你控制环容忍的上限（根据你的速度环性能指标和允许的最大估计误差自行确定），且 Sage-Husa 无法改善（因为窗口太慢），再考虑引入 STF。

## 10\. 该快的时候快，该稳的时候稳

强跟踪滤波器给 EKF 增加了一种稀缺的能力：**情境感知**。

标准 EKF 像个书呆子，不管外界风云变幻，永远按同一套数学流程走。Sage-Husa 像个老会计，发现问题后慢慢调账。STF 则像个经验丰富的急诊医生——平时该干嘛干嘛，但病人一进门就瞳孔散大，立刻按急救流程走，不搞那些慢慢问诊的虚头巴脑。

在电机控制里，这种"该快的时候快"的能力尤为珍贵。负载阶跃不会提前打招呼，转速急变不会等你窗口攒够数据。STF 用最小的代价——一个标量 λ、若干次乘法、一次除法——在突变发生的头几个 PWM 周期就做出反应，然后在新息恢复后默默退场，不带走一片云彩。

这不是魔法，这是工程师对协方差矩阵的深刻理解：**P 不是客观真理，它是你对"自己有多不确定"的主观判断。当现实告诉你"你错了"，最诚实的做法不是死撑，而是立刻承认自己确实不确定，然后多听测量值的话。**

自动紧急制动再灵敏，也不能替代安全驾驶。STF 再快，也不能替代 [第36讲](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486792&idx=1&sn=c2519e9f97c11bb4c04542f2ae259f68&scene=21#wechat_redirect) 里讲述到的扎实的 Q/R 标定。它只是在你标定的基础上，给滤波器加了一层"应急反射"。
