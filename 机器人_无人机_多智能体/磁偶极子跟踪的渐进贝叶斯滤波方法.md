# 磁偶极子跟踪的渐进贝叶斯滤波方法

原创 自动化学报 2017-09-27 15:01 北京

> 原文地址: [https://mp.weixin.qq.com/s/-bil9imWKzVaIgJfJPftiQ](https://mp.weixin.qq.com/s/-bil9imWKzVaIgJfJPftiQ)

铁磁性目标，如大型舰船、车辆以及包含有铁磁性物质的物体，在较远距离上可等效为点源, 他们的目标信号可以用一个简单的磁偶极子模型来建模. 磁偶极子跟踪则是利用接收到的目标磁场信号, 基于磁偶极子模型实时反演出目标状态的过程. 准确估计出磁性目标状态及参数, 即位置,速度及磁矩等。这对于水中目标跟踪、掩埋爆炸物定位以及医疗探查实时定位等应用具有重要意义。

![](磁偶极子跟踪的渐进贝叶斯滤波方法_images/img_000_8e54bd7fca02.jpg)

磁偶极子跟踪的主要问题在于滤波性能对初始条件误差是十分敏感的。对此，在对现有卡尔曼类型滤波器进行矩近似分析的基础上，引出渐进贝叶斯理论，提出一种新的渐进贝叶斯滤波器(Progressive Bayesian filter, PBF)来应用于磁偶极子跟踪问题。

基本原理

01

从渐进贝叶斯基本框架出发，在线性高斯条件下推导了其解析解，表明了该条件下连续时间的渐进贝叶斯更新可等效为定常状态系统的Kalman-Bucy滤波器，再利用一阶Taylor展开得到非线性条件下的近似解，得到渐进贝叶斯滤波器。

实验验证

02

为测试PBF算法在实际应用中的有效性，采用两个低成本三轴数字式磁传感器分别与上述六种算法配合进行目标跟踪试验。由于传感器分辨率较低, 因此, 为保证试验尺度, 便于试验验证, 以图1所示的多个强磁性汝铁硼永磁体作为磁偶极子目标。试验中建立的参考坐标系如图1所示, 其中参考坐标系原点取两个磁强计之间中点(如图中“O”所示), 则测量点分别位于参考系内( ± 0.129, 0, 0)m位置(如图中“s0”与“s1”所示)。观测噪声矩阵及背景磁场可在无目标通过时由测量样本的方差和均值得出。

研究结论

03

本文针对磁偶极子跟踪中的初始误差敏感问题,从渐进贝叶斯基本框架出发, 将经典贝叶斯更新过程等效为求解连续时间上的渐进贝叶斯问题, 导出了渐进贝叶斯滤波器. 仿真分析以及实测试验结果表明, 对于磁偶极子跟踪问题, 渐进贝叶斯滤波器能够有效提高大初始误差条件下的初值鲁棒性和目标接近测量点时的滤波稳定性, 且具有较低的计算代价. 若进一步与多初值假设方法结合, 则可大幅减少并行滤波器数量, 相比现有磁偶极子跟踪滤波方法更适合工程实现. 需要指出, 本文的研究对象是磁偶极子跟踪问题, 而对于一般非线性滤波应用, 渐进贝叶斯滤波器作为通用算法的性能需针对具体问题,尤其是包含非线性过程模型的情况进行分析和验证.
