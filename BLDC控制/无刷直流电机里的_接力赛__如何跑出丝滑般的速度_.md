# 无刷直流电机里的“接力赛”：如何跑出丝滑般的速度？

原创 傅存敬 电磁散人 2025-10-14 07:06 广东

> 原文地址: [https://mp.weixin.qq.com/s/c15yCP01PfUnXJYMpVmtRA](https://mp.weixin.qq.com/s/c15yCP01PfUnXJYMpVmtRA)

大家有没有发现，咱们现在的生活越来越“电”气化了？小到手里的电动牙刷、剃须刀，大到路上的电动车、天上的无人机，甚至咱们家里的空调、洗衣机，里面都有一个小小的“心脏”在跳动，那就是电机。特别是其中一种叫无刷直流电机（BLDCM）的，因为它效率高、寿命长、还好控制，所以现在是“当红炸子鸡”。

但是，再好的东西也有烦恼。比如说，你花大价钱买了个无人机，想拍个特别平稳的视频，结果发现画面总有点儿微弱的抖动。或者你骑着你的小电驴，感觉在某些速度下车身会传来一阵“嗡嗡”的震动。这是为什么呢？很多时候，这个“罪魁祸首”就叫——转矩脉动（Torque Ripple）。

今天，咱们就借助一篇非常厉害的技术论文，来把这个“转矩脉动”的原理给它讲透彻，并且看看科学家们想出了什么“神仙办法”来解决它！

一、什么是转矩脉动？一场不完美的“接力赛”

首先，咱们得搞明白，BLDC电机是怎么转起来的。你可以把它想象成一个运动场，跑道上有好几个运动员（定子线圈），跑道中间站着一个拿着磁铁棒的巨人（转子永磁体）。

我们通过给不同的运动员（线圈）通电，让他变成一个临时的小磁铁，来吸引或者排斥中间那个巨人（转子）。比如，先让1号运动员通电吸引巨人，巨人一跑过来，我们就赶紧给1号断电，让2号运动员通电吸引，巨人就又被吸引过去了……周而复始，这个巨人（转子）不就转起来了吗？

这个不断切换通电线圈的过程，就叫做“换相（Commutation）”。

你看，理想情况下，我们希望这个巨人（转子）受到的力（转矩）是完全平稳的，就像你匀速推一个箱子一样。但问题就出在这个“换相”上，它就像一场接力赛里的“交接棒”。

你想啊，1号运动员要把棒交给2号。完美的交接是：1号的速度刚开始减，2号的速度就正好提起来，保证整个队伍的速度一点儿没变。但现实中呢？1号运动员跑累了（电流要衰减），他慢下来需要时间；2号运动员刚起步（电流要建立），他加速也需要时间。就在这交接棒的一瞬间，队伍的速度是不是就可能会“抖”一下？

这个“抖”一下，就是电机的转矩脉动！它会导致振动、噪音，还影响控制精度。

二、“接力赛”为什么会慢？罪魁祸首——反电动势

那有同仁就要问了，为啥电流的变化会这么“磨磨蹭蹭”呢？这里就要引入一个非常关键的概念——反电动势（Back-EMF）。

物理学告诉我们，导体在磁场里运动会产生感应电动势，对吧？电机转子在转的时候，它的磁场也在扫过定子线圈，这同样会在线圈里产生一个“反方向”的电动势。它就像你迎着风跑步，风给你一个阻力一样。电机转得越快，这个“逆风”（反电动势）就越大！我们用E来表示它。

在换相的瞬间，即将断电的线圈（我们称之为“离去相”）里的电流想减小，但反电动势撑着它，不让它那么快减小；即将通电的线圈（“进入相”）里的电流想增大，反电动势也顶着它，不让它那么快增大。

这一来二去，就导致了电流切换的延迟，造成了转矩的凹陷，也就是我们说的“脉动”。

三、大力出奇迹：四倍电压的“神来之笔”

好了，问题找到了。那怎么解决呢？这篇论文的作者们就提出了一个非常绝妙的思想。

既然电流的变化是因为“力气”不够大，没法快速克服“逆风”（反电动势E），那我们就在换相的这一瞬间，给它加一把劲！怎么加劲？提高输入电压Udc！

这就好比运动员交接棒的时候，教练在旁边猛推一把，让他们瞬间完成交接。

那问题来了，这个电压要提高到多大才正好呢？是两倍，还是三倍？论文通过一系列严谨的数学推导，得出了一个惊人的结论。我们来看论文里的核心公式！

![](https://mmbiz.qpic.cn/mmbiz_png/Z8Iha3NiaCRHKWAwcN2TfmA3ciaPgn9ENibztwLsgia8ZO01znOvnzn1QKbVS1w4UlP8dWNuNicqv0ibxic7ddwpaU8tQ/640?from=appmsg)

这个公式非常关键，它揭示了换相期间，进入相电流的变化率（did/dt）和输入电压（Udc）、反电动势（E）之间的关系。

-   did/dt：就是电流的变化速度。我们希望它不大不小，正好能弥补离去相电流的下降，让总转矩保持平稳。
    
-   Udc：就是我们施加的直流母线电压，是我们的“推力”。
    
-   E：就是反电动势，是那个“逆风”。
    
-   Kb：是和电机自身结构相关的系数，咱们可以先看作一个常数。

这篇论文经过分析得出，要使得总转矩在换相期间保持恒定，也就是让转矩脉动ΔSc趋近于零，那么这个电流变化率did/dt必须达到一个理想的值。而要达到这个理想值，最关键的就是分子 (Udc - 4E) 这一项。

大家想一想，怎样才能让转矩脉动ΔSc为0？通过论文上下文的逻辑我们可以推断，要实现最理想的平滑换相，就需要让 (Udc - 4E) 这一项等于零！

所以，我们得到了一个石破天惊的结论：

Udc - 4E = 0

移项一下，就是：

Udc = 4E

看到了吗，这就是答案！为了在换相瞬间彻底抑制转矩脉动，我们需要在那一刹那，将输入电压Udc精准地控制为当时电机反电动势E的四倍！

不多不少，正好四倍！这就是科学的精确和美妙之处！这就相当于教练不但知道要推一把，还精确地算出了要用多大的力气推，才能让交接棒的过程如丝般顺滑！

四、如何实现这神奇的“四倍电压”？

这时候可能又有同仁有疑问了：“那我总不能为了那零点几毫秒的换向，长期用一个四倍的电压给电机供电吧？那平时不是太浪费电了，而且电机会被烧坏的！”

问得非常好！当然不能这么干。所以，工程师们设计了非常巧妙的电路，称之为DC-DC变换器。比如论文里提到的Cuk变换器或者DVM（Double Voltage Method）方案。

我们来看论文里关于DVM的图4。

![](https://mmbiz.qpic.cn/mmbiz_png/Z8Iha3NiaCRHKWAwcN2TfmA3ciaPgn9ENib7UmxNPryeZR67OGgCbKtNtAIfqCFHOW1CI6emdibabFpag81C1fibCNQ/640?from=appmsg)

这个电路的原理，你可以把它想象成一个“电压增压泵”。在平时，开关S1打开，S2闭合，电机就用普通的Udc电压工作。当需要换相的瞬间，控制器会立刻让S1闭合，S2断开，通过电容的串联，瞬间将作用在逆变器上的电压提升一倍（这里展示的是倍压原理，其他更复杂的拓扑可以实现更高倍数的电压提升）。论文的核心思想是，通过这种方式，在换相的短暂时刻，提供一个远高于正常值的电压，比如我们推导出来的四倍反电动势，来“冲”过这个换相过程。

这个过程就像汽车的涡轮增压，平时不工作，在你需要急加速的时候，它介入一下，给你强大的动力。换相一完成，电路马上切回正常电压。整个过程快如闪电，既解决了脉动问题，又保证了整体的能效。

五、总结

今天的内容信息量有点大，我们来回顾一下。

1.  BLDC电机因为效率高而应用广泛，但它在“换相”时，会因为电流无法瞬时改变而产生转矩脉动，导致振动和噪音。
    
2.  电流之所以“磨蹭”，是因为受到了电机自身转动产生的“反电动势（E）”的阻碍。
    
3.  这篇论文给出的解决方案是：在换相的瞬间，通过特殊的电路，将输入电压（Udc）短暂地提升到反电动势（E）的四倍，即Udc = 4E。
    
4.  这个“神来之笔”般的结论，是通过对电机动态过程进行严谨的数学建模和推导得出的。它为我们精确控制电机、实现平稳运行提供了坚实的理论基础。
    

所以啊，以后当大家看到一架无人机在空中稳如泰山，或者坐上一辆平顺安静的电动汽车时，你就可以自豪地跟身边的人说：“这里面可有大学问！为了消除那恼人的‘抖动’，工程师们可能就用上了‘四倍反电动势’这种神奇的物理魔法！”

物理就是这样，它从我们身边最熟悉的现象出发，通过观察、假设、推演，最终得出一个简洁而深刻的规律，反过来又指导我们去创造更美好的世界。
