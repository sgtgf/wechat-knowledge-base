## 从 Q 到 R：调试现场的新困惑

继[上一篇](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486784&idx=1&sn=238354c08301da9d376e85b4516f6111&scene=21#wechat_redirect)文章对Q的拆解后，有同仁可能会有如下的问题：

> "Q 我大概懂了，那 R 呢？我把 `kalman_gain_R` 从 0.5 改成 0.1，电机低速抖得更厉害了；改成 5.0，高速时角度估计又发飘。这 R 到底该怎么理解？"

这个问题问到了点子上。

Q 和 R 是 EKF 的两大调参旋钮，但它们的物理含义完全不同。Q 问的是**模型有多不靠谱**——你闭眼走路时，步子会歪多少？R 问的是**传感器有多不靠谱**——你睁眼瞄一眼的时候，看到的东西有多模糊？

两个按钮扭错一个，估计都会崩。[上一篇](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486784&idx=1&sn=238354c08301da9d376e85b4516f6111&scene=21#wechat_redirect)把 Q 拧明白了，这篇来拧 R。

为了说清楚 R，我先讲一个真实会遇到的调试场景。

假设你正在调一台 48V、100A 的伺服驱动器，电机额定电流 50A。Q 已经按[上一篇](https://mp.weixin.qq.com/s?__biz=MzE5MTYzNjgzOA==&mid=2247486784&idx=1&sn=238354c08301da9d376e85b4516f6111&scene=21#wechat_redirect)的思路调过了一遍——Q\[0\]=0.5，Q\[1\]=2.0，Q\[2\]=2e6，Q\[3\]=0.2。低速空载时电机还算平稳，但当你把转速提到 3000rpm 以上，突然听到电机发出一种"呜呜"的低频喘振声，示波器上看相电流波形，不是干净的正弦，而是带着明显的抖动。

你第一反应是电流环 PID 没调好。你把速度环带宽往下压，抖动稍微轻了点，但响应变慢了。你又怀疑是死区补偿有问题，调了半天 `dcu_deadband`，没什么效果。

这时候你注意到 `kalman_gain_R = 0.5`。你试着把它改成 2.0，重新上电——高频喘振居然消失了。

为什么？因为 R 决定了 EKF 对电流测量的**信任程度**。你以为是电流环的问题，其实是状态估计把测量噪声喂进了速度环。R 没设对，EKF 对传感器的"视力"判断错了。

## R 的物理意义：不是电流值，是不确定度

先给结论：**R 不是电流值，而是"对电流读数的不确定程度"，单位是 A²（电流的平方）。**

在 phobia 的代码里，R 是个标量，默认 0.5：

`pm->kalman_gain_R = 5.e-1f;   // 0.5  (pm.c:223)`

R=0.5 意味着：EKF 认为电流测量的**方差**是 0.5 A²，对应的标准差是：

也就是说，如果你拿一个精密电流传感器同步对比，EKF 预期自己的电流读数会有大概 ±0.7A 的散布（按 3σ 算，约 ±2.1A 的极端偏差）。

注意这个"±0.7A"是**方差层面的统计描述**，不是说你每次采样都会偏差 0.7A。它描述的是传感器噪声的"典型幅度"。就像天气预报说"降水概率 30%"，不是指 30% 的地区会下雨，而是指在类似气象条件下，有 30% 的日子会下雨。

### R 和 Q 的本质区别

很多工程师容易把 R 和 Q 混为一谈，觉得"反正都是噪声，调哪个都一样"。这是大误区。

  

Q（过程噪声）

R（测量噪声）

**描述对象**

**影响环节**

**物理来源**

工况变了，模型不准了，调 Q

A²（phobia 中统一为电流平方）

用一个更直白的说法：**Q 是你对自己"闭眼走路"水平的诚实评价，R 是你对自己"睁眼瞄一眼"水平的诚实评价。** 两个维度，不能互相替代。

### R=0.5 到底大还是小？

这取决于你的量程和硬件。

假设驱动器满量程 100A，0.7A 的标准差约占满量程的 0.7%。对于一颗 12-bit 模数转换器，量化步长是：

纯量化噪声的标准差（假设均匀分布）是 ，对应的方差约 ——远小于 0.5。

所以 phobia 里的 R=0.5 **不可能只是 ADC 量化噪声**。它是把采样电阻温漂、运放零偏、PWM 开关耦合、布线电磁干扰等所有噪声源打包在一起的一个**经验默认值**。

## R 就像验光单上的近视度数

想象你去验光。验光师让你看视力表，你看到的是一片模糊。验光单上写着：近视 500 度。

R 就是这个"近视度数"：

-   • **R 小 = 视力 5.0**：你看东西清楚，别人信你。EKF 更新步时，实测电流一巴掌拍过来，预测值乖乖跟着走。
    
-   • **R 大 = 近视 500 度**：你看东西模糊，别人不敢全信。EKF 觉得测量噪声太大，宁可多信模型预测，修正动作很克制。
    

但眼睛（传感器）的视力不是天生的，而是由镜片（采样电阻）、角膜（运放）、视网膜（ADC）共同决定的。你戴了一副好眼镜（高精度采样电阻 + 低噪声运放 + 高分辨率 ADC），R 就应该小；你戴了副山寨眼镜，R 就得大。

但有几点需要注意：

人眼的"近视"一般是稳定的——你今天 500 度，明天不会突然变成 200 度。但电流传感器的"视力"会随工况变化：

-   • **低速时**，PWM 占空比小，电流纹波大，采样时刻容易踩到开关噪声，等效 R 变大。
    
-   • **高速时**，电流波形更平滑，但反电势大、电压裕度小，采样精度可能受共模干扰影响。
    
-   • **温升后**，采样电阻阻值漂移，运放零偏漂移，等效 R 也会变化。
    

所以 R 不像眼镜度数那样"一配定终身"。但在工程实践中，我们通常**把 R 当作相对固定的硬件属性**，把这些工况变化留给 Q 去吸收——因为 Q 的四个分量已经各自对应了不同的模型失配来源。

## 代码走读：R 在更新步中的数学角色

R 出现在更新步 `pm_kalman_update()` 里（pm.c:1177-1240）。为了理解 R 的作用，我们先回顾 EKF 更新步的标准公式：

在 phobia 的实现中，测量向量  是 `[lu_iX, lu_iY]`，即 αβ 坐标系下的两相电流。H 矩阵直接取前两个状态分量：

`/*    * H(1) = [ 1  0  0  0  0 ]    * H(2) = [ 0  1  0  0  0 ]    *    * */`

这意味着：EKF 的"测量"就是电流本身，没有复杂的观测模型。预测步算出了预测的电流 ，更新步用实测电流来修正。

### 逐行解读 R 的参与

`float iR = pm->kalman_gain_R;   // 0.5  (pm.c:1181)      // 计算 HP = H * P（对第一个测量分量 iX）   HP[0] = P[0];    // H(1,1)*P(1,1) = 1*P[0]   HP[1] = P[1];    // H(1,2)*P(2,1) = 1*P[1]   HP[2] = P[3];    // H(1,3)*P(3,1)   HP[3] = P[6];    // H(1,4)*P(4,1)   HP[4] = P[10];   // H(1,5)*P(5,1)  (pm.c:1197-1201)      // 新息协方差 S = HPH' + R   // 对第一个测量分量：   u = 1.f / (HP[0] + iR);         // pm.c:1203      // 卡尔曼增益 K = PH' / S = HP / S   K[0] = HP[0] * u;               // pm.c:1205   K[2] = HP[1] * u;               // pm.c:1206   K[4] = HP[2] * u;               // pm.c:1207   K[6] = HP[3] * u;               // pm.c:1208   K[8] = HP[4] * u;               // pm.c:1209`

注意这个 `HP[0] + iR`。`HP[0]` 是什么？它是 ，也就是**预测电流 iX 的方差**（来自预测步的协方差传播）。`iR` 是测量噪声方差。两者相加得到新息协方差 。

分母  越大，`u` 越小，K 就越小。这意味着：

**R 直接决定了"测量值能撬动预测值多少"。**

-   • **R 小** → 分母小 →  大 → K 大 → 实测电流的一点点偏差都会剧烈修正状态估计。
    
-   • **R 大** → 分母大 →  小 → K 小 → 实测电流抖上天，估计值也稳如老狗。
    

### 两个测量分量共享同一个 R

代码中对第二个测量分量（iY）重复了同样的逻辑（pm.c:1227-1239），同样使用 `iR` 作为测量噪声：

`u = 1.f / (HP[1] + iR);         // pm.c:1233`

这意味着 phobia 用**一个标量 R** 同时覆盖 iX 和 iY 两个分量。这是工程简化——假设两个电流通道的噪声水平相当。在三相采样且通道噪声近似相同的前提下，Clarke 变换后的 αβ 电流噪声可以近似用标量 R 描述；但两相采样或通道明显不对称时，应考虑二维 R 矩阵甚至非零交叉项，而不是简单用一个标量硬撑。

**还有个细节**：phobia 的更新步采用**序贯更新**（sequential update），先处理 iX、更新 P，再用更新后的 P 处理 iY，最后对卡尔曼增益做联合修正（pm.c:1257-1263）。这避免了 2×2 矩阵求逆，在 MCU 上更轻量。标准线性高斯 KF 的序贯处理与批量处理理论等价，差异主要来自有限精度或实现近似。

如果你的硬件两相采样精度明显不对称（比如 A 相用了高精度霍尔，B 相用了廉价采样电阻），这个简化就会引入不对称误差。这时候你应该考虑把 R 改成**对角矩阵**，必要时甚至使用完整的二维协方差矩阵（含非零交叉项），而不是继续用一个标量硬撑。

### 残差计算：测量值从哪来？

更新步的残差（innovation）计算在 `pm_flux_kalman()` 中（pm.c:1305-1308）：

`// 先根据预测状态算出预测的电流   A[0] = pm->flux_F[0] * pm->flux_X[0] - pm->flux_F[1] * pm->flux_X[1];   A[1] = pm->flux_F[1] * pm->flux_X[0] + pm->flux_F[0] * pm->flux_X[1];      // 残差 = 实测电流 - 预测电流   E[0] = pm->lu_iX - A[0];        // pm.c:1307   E[1] = pm->lu_iY - A[1];        // pm.c:1308`

这里的 `pm->lu_iX` 和 `pm->lu_iY` 就是**实测电流**，它们从哪来的？

从 `pm_feedback()`（pm.c:3490-3611）的电流采样链来：

-   • ADC 寄存器在 `hal/adc.c` 中先转换为 `hal.ADC_current_*`
    
-   • `main.c` 写入反馈结构 `fb->current_*`
    
-   • `pm_feedback()` 中经线性缩放：`scale_iA[1] * fb->current_A + scale_iA[0]` → `pm->fb_iA`
    
-   • 再经 Clarke 变换（或零序消除）得到 `lu_iX`、`lu_iY`
    

所以整个测量链是：**物理电流 → 采样电阻 → 运放 → ADC → hal 层转换 → main 层反馈 → scale 缩放 → Clarke → lu\_iX/iY**。R 描述的是这条链路上**所有噪声的集合方差**。

## 电流测量链：噪声从哪来？

要理解 R 应该设多大，先得知道电流测量的噪声从哪来。一条完整的电流传感器链路通常包含以下环节：

### 1\. 采样电阻噪声

采样电阻把电流转成电压：。噪声来源包括热噪声、温漂和寄生电感。

热噪声在典型配置下折算到电流端只有约 0.4mA——远小于 R=0.5 对应的 0.7A 标准差，可以忽略。温漂产生的是**比例误差**（系统性的），不是 R 描述的随机噪声，会被 EKF 残差吸收。寄生电感在高频时可能产生电压尖峰，影响采样精度。

### 2\. 运放噪声

电流采样信号通常只有几十到几百毫伏，需要运放放大。运放的输入噪声电压密度典型值 10-50 nV/√Hz，折算到电流端约 0.01-0.05A 的等效噪声——仍然远小于 R=0.5。零偏漂移产生的是系统性偏差，不是 R 直接描述的随机噪声。

### 3\. ADC 量化噪声

ADC 量化噪声方面，12-bit ADC 在 100A 满量程下量化步长约 0.024A，标准差约 0.007A，方差约  A²——这在第二节已经算过，再次远小于 0.5。

### 4\. PWM 开关耦合（最重要的噪声源）

以上三种噪声加起来，等效方差也只有  量级，和 R=0.5 差了**三个数量级**。那剩下的噪声从哪来？

答案是：**PWM 开关噪声**。

逆变器的功率管每次开关都会产生电压跳变（dV/dt 可达 kV/μs 量级）。这些瞬态通过以下路径耦合到电流采样——这是脉宽调制（PWM, Pulse Width Modulation）开关噪声的主要来源：

-   • **共模干扰**：功率地线和控制地线之间的寄生电容耦合；
    
-   • **差模干扰**：PCB 走线的寄生电感与 dI/dt 产生的感应电压；
    
-   • **采样时刻不准**：如果 ADC 触发时刻和 PWM 边沿没有精确对齐，可能踩到开关瞬态，导致单点采样值严重偏离真实电流。
    

PWM 开关噪声不是白噪声，而是**与开关频率相关的确定性干扰**。但 EKF 的 R 假设噪声是高斯分布的，所以这种"非理想噪声"只能被 R 粗略地覆盖。R=0.5 这么大的值，很大程度上就是为了**兜底 PWM 开关耦合**。

PWM 开关耦合的噪声方差很难从第一性原理精确计算——它依赖于 PCB 布局、功率管 dV/dt、采样时刻对齐精度等太多因素。工程上更实际的做法是：先确认纯电子学噪声远小于 R，然后把 R 的绝大部分余量归因于 PWM 耦合，再结合调试表现微调。

### 5\. 零序偏移

三相电流之和理论上为零（），但由于采样通道的零偏不一致，实际采样的三相电流之和不等于零。phobia 的代码在 `pm_feedback()` 中处理了零序偏移（pm.c:3553-3559）：

`iA = pm->fb_iA - Q;   iB = pm->fb_iB - Q;`

其中 `Q` 是三相平均值（零序分量）。零偏残留会作为直流分量进入电流测量，EKF 的残差机制会把它当作"测量偏差"的一部分进行修正——但这不等于 R 在统计意义上描述了零偏。R 描述的是随机散布，零偏是系统性偏移。

## R 调大/调小的工程后果

这是现场调试最关心的：R 从 0.5 改成 0.1 或者 5.0，电机到底会怎样？

### R 太小（比如 0.1）：过度信任测量

EKF 觉得电流采样"高清无码"，实测电流抖一下，估计值就跟着抖一下。电流环还好，但角度和速度的估计会引入高频噪声。

**具体表现：**

-   • 空载或轻载时，电机发出**低频啸叫或抖动**（频率通常在速度环带宽附近，几百 Hz 到一两 kHz）。
    
-   • 上位机或日志查看 `lu_iX`/`lu_iY`，波形上叠加了明显的高频毛刺。
    
-   • 速度估计 `flux_wS` 在稳速时呈现小幅锯齿状波动。
    
-   • 速度环 PI 控制器把这些噪声放大，进一步激励电流环，噪声在速度-电流双环中来回传播，形成耦合振荡。
    

**为什么轻载最明显？** 因为轻载时电机本身没有负载阻尼，机械系统对转矩脉动最敏感。重载时负载惯量大，同样的转矩脉动被惯量"吃掉"了，人耳和触觉都不容易察觉。

**调试判断：** 如果你发现低速空载抖，把 R 从 0.5 往上加到 1.0~2.0，抖动明显减轻，R 太小是重点嫌疑——但也要同步查看残差大小、Q 设置和采样时刻是否踩到 PWM 边沿。

### R 太大（比如 5.0）：过度忽视测量

EKF 觉得电流采样"近视眼 500 度"，宁可信模型预测。问题是模型预测会漂移——尤其是负载突变、参数温漂时。

**具体表现：**

-   • 高速运行时（通常 > 60% 额定转速），角度估计**出现滞后**，电机效率下降，发热增加。
    
-   • 负载突变时（比如突然加减速），角度估计**跟不上**，电流环出现短暂的过流或欠磁。
    
-   • 严重时估计值**发散**，电机突然失步、电流飙升，触发过流保护。
    
-   • 上位机或日志查看 `lu_iX`/`lu_iY` 和预测电流的偏差（残差）持续偏大，但 EKF 修正力度很小。
    

**为什么高速最明显？** 因为高速时反电势大、电压裕度小，模型对参数误差更敏感。如果 Rs 或 Lq 的实际值和模型中的 `const_Rs`、`const_im_Lq` 有偏差，模型预测的电流就会系统性地偏离实测值。R 太大意味着 EKF 拒绝用实测值去修正这个系统性偏差，偏差就会累积。

**调试判断：** 如果你发现高速发飘、负载突变时失步，把 R 从 0.5 往下减到 0.2~0.3，现象明显改善，R 太大是重点嫌疑——EKF 可能过度忽视测量了。

### 一个常见的调试误区

有人低速抖了就猛加 R，高速飘了又猛减 R，最后 R 在一个很大的范围内来回震荡，问题始终没根治。

这是因为他没分清**低速抖和高速飘的根因不同**：

-   • **低速抖** → 通常是 R 太小（过度信任测量噪声），或者 Q\[0\]/Q\[1\] 不够大（模型在低速下不准）。
    
-   • **高速飘** → 通常是 R 太大（过度忽视测量），或者 Rs/Lq 参数不准导致模型系统偏差。
    

正确的做法是先**固定一个合理的 R**（基于硬件精度估算），然后用 Q 去吸收工况变化。如果 Q 调到位了还有问题，再回头审视 R。

## R 的标定思路：从硬件规格出发

R 不应该靠"感觉"瞎拧，它应该有物理来源。下面给出一个从硬件规格出发的标定思路。

### 第一步：估算纯电子学噪声基线

结合第二节和第五节的分析，对于典型配置（12-bit ADC、1mΩ 采样电阻、增益 50、满量程 100A），纯电子学噪声（ADC 量化 + 运放 + 采样电阻热噪声）的总方差约在  A² 量级。

这个值和 phobia 的默认值 0.5 差了**超过三个数量级**。这说明 R=0.5 绝大部分成分不是电子学噪声，而是 PWM 开关耦合。

## 结论：R 是传感器的诚实度自白

让我们回到文章开头的问题：R=0.5 到底是什么意思？

R=0.5 对应的电流标准差约 0.7A。对于 100A 量程的驱动器，纯电子学噪声（ADC 量化 + 运放 + 采样电阻）只有约  A² 量级，与 0.5 差三个数量级以上；从数值量级反推，R=0.5 不太可能只代表 ADC 量化噪声，更像是为了兜底 PWM 开关耦合等工程余量。

R 不是玄学参数，它应该有物理来源。但 R 也不是一个可以精确算出来的"唯一正确值"——因为 PWM 耦合、布线干扰等因素很难精确建模。工程上的做法是：

1.  1. **从硬件规格出发**，估算一个合理的 R 基线；
    
2.  2. **结合调试表现**，在基线附近微调；
    
3.  3. **固定 R 后，用 Q 去吸收工况变化**。
    

### Q 和 R 的分工口诀

记住这个简单的判断逻辑：

> **工况变了抖，先调 Q；硬件换了飘，再看 R。**

-   • 低速空载抖 → Q\[0\]/Q\[1\] 可能不够大（模型在低速不准），或者 R 太小（过度信任测量噪声）。
    
-   • 高速重载飘 → R 可能太大（过度忽视测量），或者 Rs/Lq 参数不准（模型系统偏差）。
    
-   • 负载突变失步 → Q\[2\]（转速项）可能需要加大，或者 R 太大导致修正滞后。
