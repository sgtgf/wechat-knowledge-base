# 光耦器件电路与参数计算

> 原文地址: [https://mp.weixin.qq.com/s/u9oUv9sIITzaUPufzK7kLw](https://mp.weixin.qq.com/s/u9oUv9sIITzaUPufzK7kLw)

> 介绍了光耦器件的工作原理及应用，包括LED电流的最小和最大值选择，确保LED正常工作且不被损坏。电流转换比（CTR）的概念被解释，用于理解光耦合器的效率。通过计算，确定了R1电阻值以保证4.1mA的LED电流，并计算出在不同条件下的CTR值，从而理解光耦右侧的电流变化。同时，讨论了右侧电阻的计算方法，考虑了三极管的压降和不同连接情况下的电流值

而最小值是怎么看呢？我们再看看数据手册。

还有就是。他们的关系就是左侧的发光二极管的强度影响到了右侧的三极管。  
他们之间的关系为：  
IC=N x IF  
IC 光耦三极管端。  
N Ctr的比值。  
IF 电流值发光二极管的电流值。

一般做普通的LED发光工作电流4毫安到5毫安。

#### 确定R1电阻值计算

电源电压为3.3V LED正向导通压，降为1.2伏。电流流过发光二极管有4mA  
（3.3-1.2）/ 4 = 0.525 R  
实际上没有525欧的电阻。所以直接采用常规的510欧电阻。  
最终流过的电流约为4.1mA。

计算他的Ctr值  
从第三幅图中。可以看出4毫安传输比约为110% 的电流转换比。  
带入CTR公式可得：  
4.1 x 1.1=4.5mA

这个4.5毫安什么意思呢？就是光偶右侧裸接电源。他流过的电流为4.5毫安。如果接了其他电阻或二极管。电流数值就改变了。

光耦右侧的4.5mA可以参考5mA。

右侧电阻是如何算的？  
通常规管的压降为0.3伏。  
可算出4.7V 对应流过的电流值为4.3ma

假设。5伏再连接二极管街道。三极管的集电极。  
那么它的电压为（5.5-1.5）3.5伏。对应的电流值为4.5mA。
