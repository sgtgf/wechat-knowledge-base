# 维修电路板测不到元件引脚，需自制测试工具

原创 电路一点通 2024-06-30 19:50 广东

> 原文地址: [https://mp.weixin.qq.com/s/KPri2ljyJbKA-c-lBwMVKQ](https://mp.weixin.qq.com/s/KPri2ljyJbKA-c-lBwMVKQ)

在维修时，有很多工具都不合适，都需要改装一下，或者自制测试工具。可以提高维修效率。

4V转12升压电路

现在的电路板为了防潮，防水，防腐蚀，抗绝缘，都涂上了一层绝缘漆，给维修增加了很多困难，用普通万用表表笔测试电路板，基本不容易测量到引脚焊盘，明明电路时通的，测试发现不通，到头来发现是表笔没接触到电路板上的焊盘上。

现在市场上也有很多特别尖的表笔，但购买过使用发现不好用，还容易断，如果购买好的，又比较贵，所以还是需要自己改装一下，有合适的工具，对维修可以事半功倍。

![](D:\电脑文件\公众号知识库\电工_教育_学习\维修电路板测不到元件引脚_需自制测试工具_images\img_002_1d99d43c7488.other)

  

首先去五金店买一包针，对就是缝衣服的针，留好长度，用斜口钳剪短。

用一段电阻腿引脚，把针绕在表笔上，用焊接焊接上，这样就不会松动。

![](D:\电脑文件\公众号知识库\电工_教育_学习\维修电路板测不到元件引脚_需自制测试工具_images\img_003_5fa0a872ff80.other)

![](D:\电脑文件\公众号知识库\电工_教育_学习\维修电路板测不到元件引脚_需自制测试工具_images\img_004_8419b6b66428.other)这样焊接好后，就非常容易测试电路板了，不管电路板的绝缘漆有多厚，都可以一插到底，如果断了，在重新焊接，可以节省成本。
